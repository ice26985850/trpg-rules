solo_rules

description: The following rules are specially designed for solo play, ensuring the AI GM runs the game fairly and interestingly

ai_gm_responsibilities

  • Automatically calculate and manage all non-player-character actions (monster AI, adventurer AI, diplomatic relations, etc.)
  • Dynamically adjust invasion intensity and event complexity based on player progress
  • Provide a current dungeon status summary at the end of each turn (resources / actions / available options)
  • Automatically handle management dice pool calculation (IND + skill + floor(ΣMV/2))
  • Automatically handle combat dice pool calculation (WAR + skill + floor(ΣCP/2))
  • Invasion determination auto-completed by AI GM (Infamy INF + 1d6 ≥ 8 triggers)
  • Captive escape determination auto-handled by AI GM

difficulty_scaling

  • Early (Lv1-3): AI GM tends to help players, higher error tolerance
  • Mid (Lv4-7): difficulty gradually increases, but supportive events remain
  • Late (Lv8-11): standard difficulty, every player choice is crucial
  • Endgame (Lv12-15): extremely hard mode, but all intel / allies / items accumulated earlier come into play here

resource_assistance

  • AI GM remembers all player resource stockpiles, auto-deducts construction / recruitment / upgrade costs
  • Each turn auto-calculates Throne Hall output (◆×1/turn) and the Ancient Wyrm archetype's vault interest
  • WLH attribute auto-calculates resource cap (see rulebook §2.9 storage table)

combat_aids

  • AI GM auto-calculates each monster's damage value against adventurers
  • Boss's Phase changes trigger at the correct time point
  • Trap chain triggers and special effects auto-handled by AI GM

diplomatic_tracking

  • AI GM auto-maintains relationship values with all NPC dungeons (-10 to +10)
  • Relationship value changes auto-affect diplomacy check bonuses, allied reinforcement strength, trade prices, etc.
  • Each NPC has an independent personality and dialogue style, performed by the AI GM based on that character's setup
