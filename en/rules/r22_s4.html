S4 — The Forgotten Save Point

Difficulty: Advanced | Suggested Memory Value: Memory 7-10, 7-12 cycles | Time Range: Ten days Core Skills: Memory (MEM), Will (WIL), Insight (INS) Players: 1 player + 1 GM

Opening Description

In the depths of the Old City Ruins you found it — a Save Point. Not an ancient, shared-by-all Save Point like the Eternal Well. This Save Point bears your signature.

You touch it. Then you remember.

You remember you have been here before. You remember you set this Save Point. You remember why you hid it from yourself — because that truth was too heavy.

You remember — you yourself pushed someone toward the fate they now have.

Core Mechanic — Memory Fragment Overload

Accessing the forgotten Save Point triggers a memory overload:

  1. Gain 3-5 Memory Fragments from "past cycles"
  2. Must pass a Will (WIL) check (DC 16)
  3. Success: Memory is clear, gain key intelligence
  4. Failure: Memory is muddled — true or false is hard to tell, some may be false
  5. Accessing three or more times in a row: Permanently lose part of your memory (random intelligence removed from the character sheet)

Hidden Truth (GM Only)

A past player discovered in the Nth cycle: a certain NPC in the game (Archbishop Ethlyn or Chief Scholar Victor) was actually a companion from a past cycle — and the player themselves pushed them toward their current fate.

More specifically: the player made a decision in a past cycle that directly caused a current major crisis. The past player could not bear this truth: 1. Created a hidden Save Point 2. Sealed the key memory within it 3. Deliberately let themselves die in the following cycles 4. But left this Save Point — in case a future self was ready to face the truth

Ten-Day Timeline

Day Phase Content
Day 1-2 Discovery Accidentally trigger the Save Point while exploring the Old City Ruins. The first vague Memory Fragments flood in
Day 3-5 Pursuit Track the clues within the fragments. An NPC says something strange: "You're here again... the last time you left, you said you'd never come back"
Day 6-7 Truth Fully access the Save Point, gain key memories. Face the past choice
Day 8-10 Choice Accept the truth and try to make amends? Or try to forget again?

Multiple Endings

Ending Condition Result
Reconciliation Accept the truth, confess to the affected NPC, try to make amends Will permanently +1. The NPC may or may not forgive
Burden Accept the truth but tell no one Will strengthened, but grief hidden in Social
Forget Again Reject the truth, seal the memory again The Save Point is permanently destroyed. Short-term calm, but a fiercer return in the future
Collapse Repeated overload failures, cannot process the fragments Enter a fragmented state — random past memories surface, approaching Time Devourer transformation

Clear Conditions

  • Main Objective: Access the Save Point and obtain the full truth
  • Perfect Clear: Choose Reconciliation, Will +1
  • Minimum Clear: Obtain the truth without demanding a perfect handling

"Some truths, the past you would rather die — again and again — than face. But are you, now, ready?"

Multiplayer GM Tips

This scenario is designed for solo play (1 player + 1 GM). If you start with 2-3 players per GM Rulebook 14-3, note:

  • Each player manages their own Rift Mark (RM) and Memory Fragments (MF); the Will check for memory overload (DC 16) may become a Team Check — if only some succeed, those who pass may relay the key intelligence to others, easing the penalty of muddled memory.
  • S4 leans psychological, with very little combat; enemy scaling is almost never triggered. With multiple players it is recommended to advance the ten-day timeline separately: one pursues fragment clues, one dialogues with key NPCs, then gather on Day 6-7 to fully access the Save Point.
  • Multiple endings (Reconciliation / Burden / Forget Again / Collapse) are decided by squad consensus; the "hidden truth" — that an NPC was actually a companion from a past cycle — hits players with different relationship histories harder, and the GM may adapt accordingly.
