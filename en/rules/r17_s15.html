Scenario S5: Factory Infiltration [Level (Lv.) 5]

Suitable: Level (Lv.) 5 × 1 Player + 1 Companion | Duration: 3-4 hours | Map: Rusted Factory (Industrial Zone)

Commission

The Blacksmith needs a military-grade metal sample. He recommends infiltrating via the underground pipeline—"The Brotherhood's patrols won't go there. But there may be other things in the pipeline." Reward: 5,000 ₽. Time limit: 90 minutes.

Scene Sequence

Scene 1: Entry—West Pipeline Entrance

Pipeline navigation (Tech Target Number (TN) 11; automatically succeeds if the Companion is a Technician). - Inside the pipeline: Mutant Rats ×2. Solo Option: Use a smoke grenade for cover to pass through (after the smoke grenade, Stealth automatically succeeds).

Scene 2: Furnace Workshop Perimeter

Iron Brotherhood patrol ×2 (fixed route, looping every 45 minutes). Can be fully bypassed by stealth (Stealth Target Number (TN) 11, +2 advantage → Target Number (TN) 9). - If the Companion is a Scout: can report the patrol's exact position; Stealth automatically succeeds.

Scene 3: Furnace Workshop—Metal Sample

The military-grade metal sample is near the furnace control console (Purple ×1). - Retrieving it triggers a vibration sensor (Perception Target Number (TN) 17 to detect and disarm it beforehand, Tech Target Number (TN) 14) - If discovered: Iron Brotherhood soldiers ×2 (combined Threat Value 14; manageable for a solo Level (Lv.) 5 + Companion)

Scene 4: Extraction

  • Return via the pipeline (safe)
  • If the vibration sensor was triggered: Iron Brotherhood patrol ×3 blocks the pipeline exit → you must find an alternate route (the underground pipeline leads to the east scrap yard; requires Perception Target Number (TN) 14 to locate)

Solo Adjustment

  • Too Hard: Iron Brotherhood soldier ×1; the vibration sensor is already disabled (old pipeline)
  • Too Easy: A patrol captain ×1 also appears in the workshop (Threat Value 9, can be avoided)
