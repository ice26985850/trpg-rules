Case File: The Underworld Train of the Cross-Harbour Tunnel

Suggested Level Range: Levels 8–9 Difficulty (Case Urgency): Grade A (Lethal; 3–4 people + outside aid) Case Type: Fierce Ghost (ferrier) + Hopping Corpse + Black Zombie + Yin-Crossing Array (Nine Nether Hall Yin channel) Case-Closing EXP: 800 Core Mystery: Recovers S3 foreshadowing ① (the Master). Nine Nether Hall has laid a "Yin-Crossing Array" in the cross-harbour tunnel, refining traffic-accident dead into Hopping Corpses / Black Zombies to guard a Yin channel leading to the opposite-shore main altar; a Fierce Ghost ferries the dead. The Master's Agent appears to command, and after the array is broken slips away — confirming the "Life-Restoring Rite" is being prepared.

One-Line Hook: A veteran officer from the CID Miscellaneous Section discreetly refers the case: "A string of cross-harbour tunnel accidents — CCTV caught a driverless train, the driver woke up rambling about dreaming of taking a ferry to the opposite shore. This one, we can't handle it."

I. Take Case

Referred by the police CID Miscellaneous Section; Council Chair Cheng Guiyao simultaneously forwards Bing's tunnel warning.

Uncle Choi (lowering his voice, away from colleagues): "Young ones, I've been in the Miscellaneous Section twenty years. The cross-harbour tunnel's had a run of linked accidents lately — CCTV caught a driverless train. The driver woke up talking about 'the opposite shore is so warm,' but he clearly passed out in the tunnel. You... handle it if you can, just don't make it bigger."

Cheng Guiyao (forwarding Bing's note): "Bing says the Yin channel in the tunnel was opened by Nine Nether Hall. Go cut that path, and while you're at it, get a look at the opposite-shore main altar."

Level-Design Hint: Roll Social (Persuasion) check Difficulty Class (DC) 15 to persuade the veteran officer to provide the CCTV footage; Knowledge (KNW) + Folklore check Difficulty Class (DC) 16 to identify the "driverless train" from the footage as an illusion of the Yin channel.

II. On-Site Investigation

Scene 1: Tunnel Mouth and Monitoring Room (Extreme Yin)

The tunnel mouth carries a cold wind mixed with the smell of rust and seawater; the monitoring room screen is speckled with static, and in the footage a driverless train slowly pulls deep into the tunnel. As you draw near, your phone signal vanishes entirely, and a chill pierces straight through your spine from the nape of your neck. - Environment Yin Value (YIN): Base 11 (Extreme Yin). - Witness: Veteran officer "Uncle Choi." - Uncle Choi (pointing at the screen): "After the driver came to, he kept saying 'the opposite shore is so warm,' but he clearly passed out in the tunnel. Look at the footage — the train goes in and never comes out." (GM Note: Social (Interview) check Difficulty Class (DC) 15 to confirm the Yin channel's location.) - Spirit Identification: Roll Intuition (INS) + Spirit Perception check Difficulty Class (DC) 16 to see Black Zombies (Challenge Rating (CR) 3, Hard-Skin Mitigation −3) and Hopping Corpses (Challenge Rating (CR) 4, Hard-Skin Mitigation −5) patrolling deep in the tunnel, with a ferrying Fierce Ghost perched on the beams (Challenge Rating (CR) 5); Knowledge (KNW) + Folklore check Difficulty Class (DC) 16 to identify the "Yin-Crossing Array."

Scene 2: Mid-Tunnel "Yin-Crossing Array Eye" (Hidden Information)

  • Appraisal (Knowledge (KNW)) check Difficulty Class (DC) 16 to find the array eye (traffic-accident dead refined into "array stakes"), the talisman tablet reading "Life-Restoring Rite · Countdown."
  • Hidden Information: The array eye hides the Master's handwritten order "Before the rite, first open the path to receive" — confirming the S8 finale. Requires Intuition (INS) check Difficulty Class (DC) 16 to read the talisman tablet's hidden layer.

Combat / Non-Combat Options - Non-Combat (Key to Breaking the Case): Hopping Corpses / Black Zombies require spirit tools; the Fierce Ghost must be captured/destroyed; the key is to break the array eye and sever the channel. - Combat (Main Axis): If attacking by force, the Extreme Yin environment prioritizes draining Composure (CMP).

Level-Design Hint (Scene Order): 1. Watch the footage in the monitoring room (Knowledge (KNW) check) → lock onto the channel illusion. 2. Spirit Sight confirms patrolling zombies and the ferrying Fierce Ghost (Intuition (INS) check). 3. Find the array eye (Appraisal Knowledge (KNW) check) → obtain the "Life-Restoring Rite · Countdown" talisman tablet. 4. Read the talisman tablet's hidden layer (Intuition (INS) check) → confirm S8.

III. Prepare Rite (Required Spirit Tools / Materials / Rite Scale)

  • Materials: Century Peachwood Sword (required for Hopping Corpse), Coin Sword (Paralysis), Thunder-Struck Wood (ignores hard-skin vs zombies), Demon-Sealing Array (consumes Mana Pool (MP) 12), Purification Talisman (Yin Value (YIN) −3), Ink Line Reel (Warding), Deliverance materials.
  • Rite Scale: Large. Scholar breaks the array eye, Warrior guards, Main Caster + Medium set the Demon-Sealing Array to trap the Fierce Ghost (maintained with Dao Attainment (DOW) check Difficulty Class (DC) 15).
  • Time Pressure: The tunnel's Extreme Yin (Yin Value (YIN) 11+) requires a Composure (CMP) check Difficulty Class (DC) 15 each round; the channel is strongest at Zi Hour, so the array must be broken before dawn.
  • Level Hint: Setting the altar requires Dao Attainment (DOW) + Altar Opening check Difficulty Class (DC) 16; sealing the channel with the Ink Line Reel requires Dao Attainment (DOW) + Warding check Difficulty Class (DC) 16.

IV. Exorcise & Collect

Best Plan: Break the Array and Sever the Path

  1. Scholar rolls Knowledge (KNW) + Lineage Knowledge check Difficulty Class (DC) 16 to break the array eye.
  2. Warrior uses Thunder-Struck Wood / Century Peachwood Sword to suppress the Hopping Corpse (roll Prowess (PHS) + Melee Combat check Difficulty Class (DC) 15), Black Zombie (Corpse-Still Talisman for Paralysis).
  3. Main Caster + Medium set the Demon-Sealing Array to trap the Fierce Ghost (Challenge Rating (CR) 5), break the warding with Five-Thunder Palm (Level 3+) then capture with the Soul-Gathering Gourd.
  4. Sever the channel and deliver the traffic-accident dead.

Potential Risks

  • Hopping Corpse Hard-Skin Mitigation −5, Black Zombie −3: Non-century tools are ineffective.
  • Extreme Yin Assimilation Risk: In the dead-zone environment, pass a Composure (CMP) check Difficulty Class (DC) 15 each round; two consecutive failures → Yin Assimilation.
  • If the Master's Agent appears: May release a Flying Corpse (Challenge Rating (CR) 5, Hard-Skin Mitigation −8, requires century-grade tool) as an elite encounter.

Alternative Plan

  • Without Thunder-Struck Wood, force suppression with Invite Deity Possession (Level 3+, Attribute +2); a Composure (CMP) check Difficulty Class (DC) 15 is required after to avoid losing control.

V. Cleanup

  • Purification: Full-tunnel purification requires Dao Attainment (DOW) + Purification check Difficulty Class (DC) 16, several Purification Talismans (Yin Value (YIN) −3), bringing Yin Value (YIN) back below 8 and closing the channel.
  • Client Feedback: Uncle Choi offers a cigarette; the Guild records a major "Blocked Nine Nether Hall's Channel" reputation gain; CID closes the case discreetly.
  • Case-Closing Reward: Nether Coin (COIN) 900–1200; EXP = base 350 (Grade A) + investigation discoveries +20×5 + correct array-breaking handling +120 + cleanup +100 + unresolved hook (Life-Restoring Rite countdown) +40 + breaking the Yin-Crossing Array +90 = total approx. 800.
  • Unresolved Mysteries (leads to S8):
  • The Master's Agent before slipping away: "Opposite-shore main altar — the Life-Restoring Rite is about to begin";
  • Though the channel is severed, the living names on the register are not yet removed.

Closing Hook: Bing and Cheng Guiyao stand together at the tunnel mouth: "We've found the location of the opposite-shore main altar. This case calls for a full squad."
