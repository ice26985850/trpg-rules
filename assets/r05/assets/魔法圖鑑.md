# 勇者之證（The Hero's Proof）— 魔法圖鑑（Spell Catalog）

> 數值來源：系統定稿（第六章 職業技能＋第七章 法術施放（7.9）），繁體中文，術語採「中文全稱（縮寫）」格式。
> 通用規則：
> - 施放＝一次「主動技能」動作，消耗 **行動點（AP）1–3 ＋ 魔力點（MP）**。
> - 攻擊法術傷害 ＝ `基礎值（B） × f(技能等級) × (1 + 魔力加值（M_MAG） / 6)`；治療／結界 ＝ `B × f(技能等級) × (1 + M_MAG / 6)`。
> - 技能等級（SkillLv）倍率 `f(n) = 1 + n(n−1)/8` → **Lv1–5 = 1.00 / 1.25 / 1.75 / 2.50 / 3.50**。
> - 傷害類型抗性／弱點／免疫：×0.5／×1.5／×0（於減傷後再乘）。物理（穿刺／劈砍／鈍擊）／元素（火焰／冰凍／雷電／酸蝕）／神秘（神聖／暗影／心靈）。
> - 射程：近戰 1格／短程 2–4格／中程 5–10格／遠程 11+格。範圍效果（AOE）＝ 中心格＋半徑 R 格。

## 〇、魔法習得規則（學習／解鎖）

法術並非出生即全數掌握，須經以下途徑之一習得，並受「等級解鎖」與「媒介」約束：

1. **職業固有（Class Spell）**：七職的「魔法型」主動技能（如火球術、冰霜新星、閃電鏈、治癒之光等）於創卡即隨職業獲得，與《技能圖鑑》第一章至第七章對應條目為**同一法術**（見下方「重疊說明」），不另佔 技能點（SP）。
2. **法術位（Spell Slot）解鎖**：非魔法職（戰士／格鬥家／盜賊／獵人／舞者）可於 職業等級（ClassLv） 達 5／10／15 時，各解鎖 1 個「通用法術位」，用以習得《魔法圖鑑》「七、通用魔法」中的法術（如 魔法飛彈、偵測魔法）。
3. **卷軸／媒介（Scroll / Medium）**：戰利品或神殿兌換取得的法術卷軸，消耗 影響力點（IP） 或 金幣（G） 抄錄後永久習得（跨職可用，消耗成本與限制見 GM 書 第十四章 14.4）；一次性卷軸則單場消耗。
4. **等級解鎖門檻**：高階法術（魔力點（MP）消耗 ≥10，或 三階精通同名法術）須 職業等級（ClassLv） ≥ 對應階段（二階 11／三階 21）方可施放；未達門檻者即使習得也無法詠唱。

**與《技能圖鑑》重疊說明**：《技能圖鑑》第一章至第七章依「職業」羅列該職技能（含魔法職的攻擊／治療法術），與本圖鑑「一～六」學派條目**數值完全一致、屬同一法術兩種視角**——前者供創卡與職業平衡查閱，後者供法術機制／學派／跨職習得查閱，請擇一引用、勿重複計算。本圖鑑「七、通用魔法」為跨職專屬，不見於職業技能表，任何職業皆可經上述途徑 2／3 習得。
