# 凍結廢土 TRPG —— 單人模式規則補充 v1.0

> **適用對象：** 1 名玩家 + 1 名 GM（雙人團／一對一跑團）
> **引用基礎：** 本文件為《凍結廢土 TRPG 核心規則書 v1.0》的補充模組。所有未修改的規則沿用原規則書。

---

## 一、單人模式概述

凍結廢土的標準規則預設 2–5 名玩家組成掠奪隊。核心機制中有多處依賴「隊友存在」的設計——救援行動、恐慌安撫、戰鬥分擔、技能互補等。本補充模組提供將單人遊玩變為可能所需的全部調整。

### 單人模式的設計目標
- 保持凍結廢土「緊繃神經質」的核心調性——孤獨只會放大恐懼
- 讓單一玩家角色能夠獨立完成掠奪任務
- 透過 NPC 夥伴填補技能缺口，但不取代玩家的決策權
- 維持倫理抉擇的重量——獨自面對被凍結者時，沒有隊友可以分擔責任

## 二、NPC 夥伴系統

### 2.1 夥伴的定位

NPC 夥伴不是「第二個玩家角色」。他們是：

- **功能補充者**：填補玩家角色屬性上的短板
- **敘事催化劑**：與玩家的互動創造角色成長空間
- **戰術資源**：在戰鬥和救援中提供協助
- **風險來源**：夥伴也會受傷、恐慌、需要保護——他們不是無敵的

### 2.2 夥伴創建

#### 屬性配點
夥伴使用簡化屬性系統，**12 點自由分配**至五大屬性（範圍 1–6）：

| 屬性 | 說明 |
|---|---|
| 速度（SPD） | 移動和反應 |
| 知覺（PER） | 觀察和預判 |
| 膽量（GUT） | 冷靜和意志 |
| 技術（TEC） | 裝置操作 |
| 交涉（NEG） | 社交和談判 |

修正值公式與玩家相同：**修正值 = 屬性值 − 5**（範圍 −4 到 +1）

#### 衍生屬性
- 生命值（HP） = 膽量 × 2 + 8（略低於玩家）
- 移動力 = 速度 + 2 格
- 恐慌閾值 = 膽量 × 2 + 3
- 時間抗性 = 技術修正值
- 無決心點和靈感點

#### 夥伴特質
每位夥伴選擇 **1 個特質**（不可更換）：

| 特質 | 效果 |
|---|---|
| **敏銳感官** | 知覺相關檢定獲得優勢。可在玩家進行知覺檢定時花費反應提供協助。 |
| **鐵腕** | 搬運重物時視為兩人。近戰傷害 +1。 |
| **醫療訓練** | 使用急救包回復 1d6+3 生命值（HP）。可對玩家進行急救（主要行動，回復 1d6+2）。 |
| **機械天賦** | 技術檢定獲得優勢。可協助玩家操作裝置（提供優勢）。 |
| **社交潤滑** | 交涉檢定獲得優勢。可在基地談判時為玩家提供價格 −10%。 |
| **沉著冷靜** | 恐慌閾值 +3。當玩家恐慌時，可花費反應進行安撫（交涉 難度（DC） 10，成功則玩家恐慌 −1 回合）。 |
| **時空敏感** | 對時間異常有天生的感知。玩家前兆知覺檢定獲得 +2 加值。攜帶結晶時不會增加解凍骰風險。 |
| **戰術掩護** | 當玩家與夥伴相鄰時，玩家獲得 +2 防護值。夥伴可使用反應為玩家擋下一次攻擊（夥伴承受該傷害）。 |

#### 夥伴裝備
夥伴攜帶基礎裝備（與玩家起始裝備相同），但不攜帶武器（除 GM 許可外）。

### 2.3 夥伴行動規則

#### 行動經濟
夥伴在戰鬥/凍結區中每回合可執行：
- **1 個主要行動** 或 **1 個移動 + 1 個次要行動**（不能同時主要+移動）
- **1 個反應**（每輪）

#### 夥伴指令
玩家可以用**自由行動**對夥伴下達簡單指令（「去搬那個箱子」、「躲到掩體後面」、「對我使用急救包」）。GM 根據夥伴的性格和特質判定指令是否被執行。

#### 夥伴自主行動
當玩家未下達指令時，GM 控制夥伴做出合理的自保行動：
- 戰鬥中：尋找掩體或協助玩家
- 解凍瞬間：優先自保（躲藏），除非特質驅使其他行為
- 凍結區探索：跟隨玩家，協助搬運

#### 夥伴恐慌
夥伴與玩家一樣會恐慌。夥伴恐慌時：
- 所有檢定劣勢
- 移動力 −2
- 無法執行玩家的指令
- 玩家可用交涉 難度（DC） 12 安撫（花費主要行動）

#### 夥伴倒下
夥伴 生命值（HP） 降至 0 時進入瀕死（同玩家規則）。玩家必須在 3 回合內急救，否則夥伴死亡。夥伴死亡造成玩家永久恐慌值 +3（不可消除）。

### 2.4 推薦夥伴搭配

| 玩家類型 | 推薦夥伴特質 | 理由 |
|---|---|---|
| 高速度低技術（如偵察兵） | **機械天賦** | 補技術短板 |
| 高技術低速度（如技師） | **鐵腕** 或 **戰術掩護** | 補機動和防禦 |
| 高膽量低交涉（如硬骨頭） | **社交潤滑** | 補社交短板 |
| 均衡型（新手） | **醫療訓練** 或 **敏銳感官** | 提高生存率 |

## 三、單人戰鬥調整

### 3.1 敵人數量縮放

| 原遭遇（多人） | 單人調整 |
|---|---|
| 3–4 個敵人 | 1–2 個敵人 |
| 2 個敵人 | 1 個敵人（生命值（HP） −25%） |
| 1 個強敵（Boss） | 生命值（HP） −30%，傷害 −1 骰 |
| 群體凍結體 | 安撫 難度（DC） −3 |

### 3.2 撤退難度調整
單人撤退時，邊界穿越檢定 難度（DC） **−2**（少了需要等待隊友的壓力）。

### 3.3 瀕死自救
當玩家 生命值（HP） 降至 0 且無夥伴在旁時：
- 可使用 1 決心點（如有）進行**腎上腺素自救**：恢復至 生命值（HP） = 1 並立即獲得 1 個移動行動
- 此能力每次遊戲僅可用 1 次
- 使用後獲得 1 級力竭（所有檢定劣勢，持續至下次休息）

## 四、單人救援替代方案

### 4.1 搬運完全凍結者
原規則要求最少 2 人。單人模式下：

| 方法 | 需求 | 效果 |
|---|---|---|
| **拖拽** | 速度 難度（DC） 12，花費 3 回合 | 使用帆布/外套作為臨時擔架拖拽。移動力 −5 |
| **槓桿搬運** | 技術 難度（DC） 12，需撬棍或類似工具，花費 2 回合 | 利用環境中的物體作為支點。移動力 −3 |
| **時間結晶輔助** | 消耗 1 結晶，花費 1 回合 | 短暫降低被凍結者的「時間重量」。移動力 −2 |

### 4.2 穩定臨界凍結者
原規則 3 回合流程不變，但單人模式中：
- 夥伴可協助（提供優勢）
- 如無夥伴，每個回合的 難度（DC） **−1**

### 4.3 自救凍結
原規則規定完全凍結（3 級）無法自行解除。單人模式下新增：

> **意志解凍**：花費 2 決心點，進行膽量 難度（DC） 18 檢定。成功則凍結等級立即降至 1 級。此能力每次戰役僅可使用 1 次。

## 五、單人恐慌管理

### 5.1 無隊友時的恐慌釋放
原規則中「隊友安撫」不可用。新增替代：

| 方法 | 效果 |
|---|---|
| **自我鎮定** | 花費 1 回合深呼吸/集中精神。膽量 難度（DC） 12，成功則恐慌值 −2（每次遊戲限 2 次） |
| **使用鎮定劑** | 恐慌值 −3，但下次膽量檢定劣勢（藥物依賴） |
| **時間結晶冥想** | 消耗 1 結晶，花費 1 回合。膽量 難度（DC） 10，成功則恐慌值 −1d4 |
| **夥伴安撫** | 夥伴花費主要行動，交涉 難度（DC） 10（如夥伴有「沉著冷靜」特質則自動成功） |

### 5.2 孤獨壓力
單人探索凍結區時，每 3 回合的環境恐慌累積增加為 **+2**（替代原 +1）。孤獨讓時間的壓迫感更加沉重。

## 六、屬性覆蓋建議

單人角色無法像團隊那樣分工。GM 在設計單人戰役時應確保：

| 玩家主要屬性 | GM 應減少的挑戰類型 | GM 應增加的替代方案 |
|---|---|---|
| 低速度 | 減少時間壓力型追逐場景 | 增加潛行繞行路線 |
| 低知覺 | 減少依賴前兆察覺的即死陷阱 | 增加明顯的視覺提示 |
| 低膽量 | 減少連續解凍的高壓場景 | 提供更多喘息窗口 |
| 低技術 | 減少精密裝置操作要求 | 提供「蠻力替代方案」（砸開而非解鎖） |
| 低交涉 | 減少強制社交檢定 | 允許以行動代替言語（展示實力/威脅） |

## 七、單人模式專長調整

部分原專長在單人模式下需要調整：

| 原專長 | 單人調整 |
|---|---|
| **隊友守護者** | 改為「夥伴守護者」：夥伴獲得 +3 防護值（原 +2） |
| **步調同步者** | 改為「孤步」：自身移動力 +2，潛行時不會因單人行動而獲得劣勢 |
| **連鎖型協調者**（經驗） | 經驗直覺改為「自身膽量檢定 +1」（原為隊友 +1） |
| **斷後專家** | 撤退時自身撤退檢定優勢 + 防護值 +3（原隊友獲得優勢） |
