# 勇者之證（The Hero's Proof）— 材料圖鑑（Material Catalog）

> **材料屬性驅動（Material-Driven）**：本圖鑑不窮舉成品，只列 **材料** 及其 **8 統一欄位**；成品數值由材料欄位 × 物品模板（見 `圖鑑/物品圖鑑.md` §一～§二 與玩家書第四章）決定，玩家自由組合。
> **8 統一欄位**：① 傷害基數（DmgBase）② 減傷基數（DRBase）③ 屬性加成（StatBonus）④ 耐久基數（DurBonus）⑤ 特效標籤（Tags）⑥ 等級門檻與稀有度檔（ReqLv／Rarity）⑦ 回復基數（HealBase）⑧ 增益類型與數值（BuffType／BuffVal）。空白「—」表示該材料不取用此欄位。
> **白板原則簡述**：城鎮商店僅售基礎（白板）裝備＋初級治療／魔力藥水＋基礎食物；中高級藥水、炸彈、卷軸、增益料理須經「採集→製造」自製或冒險掉落，不列商店貨架（詳見 `圖鑑/物品圖鑑.md` 頂部白板總原則）。
> **數值約束**：所有欄位值須落入 `設計稿/05_製造系統_數值框架.md` 第 3 節「稀有度→屬性上限」合法區間；成品稀有度＝max(材料稀有度)、成品等級門檻（ReqLv）＝max(材料 ReqLv)。
> **關聯文件**：成品模板示例見 `圖鑑/物品圖鑑.md`；製造／採集規則見玩家書第四章與 `圖鑑/材料圖鑑.md` 附錄（採集類生活技能設計）。

## 附錄 A：驗證錨點（須保留）

材料稀有度嚴格決定武器量級上限，錨定關係如下（期望傷害（EvD）遞增，不得逆序）：

```
普通木 1d2（EvD 1.5）
  ＜ 鐵木 1d5（EvD 3.0）
    ＜ 白板·訓練長劍 1d8（EvD 4.5，商店基準）
      ＜ 精鋼錠 1d10（EvD 5.5，精良）
        ＜ 史詩 2d6（龍鱗片／龍血木，EvD 7.0）
          ＜ 傳說 3d8（龍王鱗，EvD 13.5）
```

→ 低階材料造物落於白板之下（早期過渡／副材料），高階材料造物拉開於白板之上（稀有度差距成立），與 `圖鑑/物品圖鑑.md` 白板原則一致。

> **附錄 A 補充·屬性加成（StatBonus）階梯（CHA／LUK 系列，經 05 §3.4 錨定）**：飾品素材的屬性加成嚴格隨稀有度，不得逆序：
>
> ```
> 普通 +1（媚光石 CHA+1／力量水晶 STR+1）
>   ＜ 精良 +2（虹響碎片 CHA+2／幸運幣礦 LUK+2／敏捷護石 DEX+2）
>     ＜ 稀有 +3（魅語水晶 CHA+3／幸運星砂 LUK+3／魔力結晶 MAG+3）
>       ＜ 史詩 +4（心動之瞳 CHA+4／四葉幻晶 LUK+4／暴擊之眼 CritTh−2）
>         ＜ 傳說 +5（魅影之心 CHA+5／命運之核 LUK+5／龍瞳石 HP+30）
> ```
>
> → 魅力（CHA）與幸運（LUK）現均已具備 普通→傳說 完整屬性加成階梯，與其它飾品素材同級、無超模。
