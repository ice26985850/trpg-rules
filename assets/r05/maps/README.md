# 地圖素材（maps/）

本資料夾收錄地圖的 **SVG 骨架／占位**，供未來製圖時直接套用或精繪。

## 通用模板
- `map_template.svg`：通用地圖模板骨架（網格、標題、圖例、比例尺、指北針、占位區域）。複製後將虛線區域替換為實際多邊形即可。
