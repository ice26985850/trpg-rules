## Chapter I: Formation Array / Seal Compendium

## 1.1 Formation Array Rules Overview

### General Formation Mechanics

```
Array Setup Procedure: 1. Spend the specified action to place the array core (deploy the core array artifact / array flags). 2. Roll d100 ≤ Formation skill value; on success the formation activates. 3. The formation persists: each round it consumes the formation master's Qi (or the formation's built-in Spirit Stones supply power). 4. On Critical Failure → formation backlash (the formation master takes 2d10 damage; materials destroyed).

Breaking a Formation: - Destroy the array core (the core has its own separate HP and defense value). - Interrupt / kill the formation master. - Oppose with a Formation skill check (both sides roll d100, compare Margin of Success). - Use an Array-Breaking Talisman (auto-breaks formations of the same grade or lower).

General Formula: Array Core HP = Array Setter's Formation skill value × Formation Grade coefficient. Formation Grade coefficient: Yellow=0.5, Profound=1.0, Earth=2.0, Heaven=3.5. Dispel DC = 80 + Array Setter's Formation skill value / 2 + Grade bonus (Yellow +0 / Profound +10 / Earth +20 / Heaven +30). Upkeep Cost (Qi/round) = Base cost × (1 − Realm tier / 10) (minimum 30% of base cost).
```

## Chapter II: Talisman Compendium

## 2.1 Talisman Rules Overview

```
Talisman General Rules: - Activation action: support action (crush / activate the talisman) — no Qi required. - Talisman effect: the check result is "infused" at creation; takes effect automatically when used. - Single-use: the talisman self-destructs after use. - Carry limit: at most Comprehension/10 talismans of the same grade (to avoid talisman-spam tactics).

Talisman-Crafting Rules: Talisman-Crafting DC = Base DC + Grade adjustment. Crafting time: Yellow 1 shichen / Profound 2 shichen / Earth 4 shichen / Heaven 8 shichen. Crafting check: d100 ≤ Talisman Dao skill value. Critical Success (difference ≥40): talisman effect ×1.5. Critical Failure (d100 ≥96): materials destroyed, talisman explodes (crafter takes 1d6/grade damage).

Talisman effect strength = Margin of Success of the crafting check. - Bought / found talismans: GM pre-determines (usually takes the standard value). - Self-made talismans: record the Margin of Success tier at creation.
```
