## 第一章：GM 基礎

### 1.1 GM 的三大核心原則

**原則一：「是的，而且……」獸人戰國版**

當玩家提出行動時，肯定其創意（「是的」），再疊加獸人戰國的獨特風味（「而且」）。

> 玩家：「我想用威壓讓守門的牛族衛兵讓路。」  
> GM：「是的——擲威壓檢定。而且如果你成功，附近的鼠族密探會注意到你的『虎威』，這可能成為一個有用的情報來源…也可能是一個麻煩。」

**原則二：妖氣即敘事資源**

妖氣值不只是戰鬥數值——是敘事張力的體溫計。當玩家的妖氣值上升時，描述他們的身體變化（耳朵顫動、尾巴不受控制地甩、毛髮豎立、瞳孔擴張）。讓玩家「感覺到」自己正在失去控制。

**原則三：刀即角色**

大業物以上的刀不是裝備——是 NPC。當玩家與名刀互動時，用 NPC 的方式來扮演刀：刀會抗拒不適格的使用者、會記住背叛、會在關鍵時刻「說話」（透過震動、共鳴、或讓持有者感受到情緒）。

### 1.2 單人遊玩專區

本遊戲預設相容 1 位玩家。以下是單人 GM 的特別指引。

#### 戰鬥平衡調整

| 調整項目 | 規則 |
|---|---|
| 雜兵數量 | 減半（常規遭遇的敵人數量 ÷2，至少 1 名） |
| Boss 生命值（HP） | −25% |
| 玩家可用 NPC 同伴 | 提供 1–2 名 NPC 同伴（使用簡化數據卡） |
| 狀態持續時間上限 | 對玩家施加的狀態最長 2 回合 |
| 敵方暴擊率 | 僅自然 20，不因招式或弱點擴大暴擊範圍 |

#### NPC 同伴系統（單人專用）

GM 為單人玩家提供 1–2 名 NPC 同伴，使用簡化數據：

**NPC 同伴簡化數據模板**：

| 項目 | 內容 |
|---|---|
| 名稱 | （由 GM 命名） |
| 獸族／流派 | 與玩家互補（如玩家是前排，同伴選遠程或治療） |
| 生命值（HP） | 玩家 HP 的 70% |
| 攻擊加值 | 玩家攻擊加值 −2 |
| 傷害 | 1d8 + 3 |
| 特殊能力 | 1 項（由 GM 選擇，如治療、遠程攻擊、輔助招式） |

**四種戰鬥指令**（玩家可以在自己回合用附隨動作下達）：

| 指令 | 效果 |
|---|---|
| 「掩護我！」 | NPC 移動到玩家身邊，本回合替玩家承受一次攻擊 |
| 「攻擊那個！」 | NPC 對指定目標進行一次攻擊 |
| 「用你的招式！」 | NPC 使用特殊能力 |
| 「退下！」 | NPC 後退至安全距離，使用防禦架式 |

**三種 NPC 同伴模板**：

| 模板 | 獸族 | 能力 | 性格 |
|---|---|---|---|
| 忠實從者 | 犬族 | 守護同伴、提高士氣 | 忠誠話少，默默守護 |
| 神秘浪人 | 猴族 | 奇襲、模仿敵人招式 | 輕浮隨性，暗藏實力 |
| 敵方叛逃者 | 蛇族 | 毒素攻擊、情報提供 | 陰沉可疑，正在贖罪 |

#### 單人獨特優勢

單人遊戲有獨特的敘事優勢：
- **深度角色發展**：可以完全聚焦於一位角色的內心世界
- **靈活節奏**：無需協調多人時間，可依玩家偏好加速或減速
- **私密義理抉擇**：沒有其他玩家的意見干擾，義理困境更加個人化
- **浪人路線最適**：浪人（無主武士）的路線在單人模式下特別有張力

### 1.3 遊戲節奏控制

理想的遊戲循環：

```
修行場景（道場練習、冥想、試割）—— 20%
    ↓
探索／外交場景（大名謁見、情報收集、旅行）—— 30%
    ↓
戰鬥場景（遭遇戰、合戰、一騎打）—— 30%
    ↓
義理抉擇場景（重大道德決定）—— 20%
    ↓
後果與回饋（世界因選擇改變，回到修行）
```

## 第二章：完整檢定與難度指南

### 2.1 檢定類型與公式

| 檢定類型 | 公式 | 說明 |
|---|---|---|
| 標準檢定 | d20 + 屬性值 + 技能熟練加值 ≥ DC | 一般行動判定 |
| 對抗檢定 | 主動方總值 > 被動方總值（平手被動方勝） | 角色間直接對抗 |
| 豁免檢定 | d20 + 屬性值 ≥ DC | 抵抗被動效果 |
| 團隊檢定 | 半數以上成功 → 整體成功 | 集體行動 |
| 協助 | 協助方進行 DC 10 檢定，成功則給予被協助方優位 | 團隊合作 |

### 2.2 難度等級（DC）設定指南

| DC | 名稱 | 何時使用 |
|---|---|---|
| 5 | 極易 | 日常動作。例如：爬上矮牆、記住常見情報 |
| 10 | 簡單 | 受過基本訓練即可。例如：砍中訓練用的稻草人、辨識常見藥草 |
| 13 | 普通 | 需要專注與能力。例如：在雨中保持平衡、辨識偽造文書 |
| 18 | 困難 | 只有熟練者能穩定達成。例如：在戰鬥中攀爬城牆、解讀古代龍語碑文 |
| 22 | 極難 | 大師級挑戰。例如：在盲眼狀態下格擋箭矢、在濃霧中射中 50 格外的目標 |
| 26 | 傳說 | 足以載入史冊。例如：一刀斬斷瀑布、與名刀在無言中達成魂契 |
| 30 | 神話 | 超越獸人極限。例如：以一己之力封印大妖禍、鍛造天下五劍級的名刀 |

### 2.3 隱藏 DC 原則

以下 DC 應該由 GM 私下設定，不告訴玩家具體數值：

| 情境 | 原則 |
|---|---|
| 察覺埋伏／陷阱 | DC 取決於埋伏者的潛行檢定結果（對抗檢定） |
| 洞察謊言 | DC 取決於說謊者的欺瞞檢定結果（對抗檢定） |
| 辨識妖刀真名 | DC 20–30，取決於刀的傳說程度 |
| 感知妖氣存在 | DC 15，距離越近 DC 越低 |
| 抵抗妖刀誘惑 | DC 18–25，取決於妖刀的等級 |

### 2.4 情境界定與優位／劣位

| 給予優位的情境 | 給予劣位的情境 |
|---|---|
| 夾擊敵人（2 名以上同伴圍攻同一目標） | 在黑暗中攻擊（無夜視能力者） |
| 從高地攻擊低處目標 | 被震懾狀態下進行任何檢定 |
| 目標處於倒地狀態（近戰攻擊） | 在水中戰鬥（非水棲獸族） |
| 使用與目標獸族相剋的妖氣 | 疲勞狀態（超過 24 小時未長休） |
| 流派招式文本明確給予優位 | 負傷狀態（HP < 30%）進行體能檢定 |
| GM 裁決的其他有利情境 | GM 裁決的其他不利情境 |

> **疊加規則**：多個優位來源不疊加（仍只擲 2d20 取高）。多個劣位亦然。優位與劣位互相抵消。

### 2.5 成功度的應用

成功度（MoS）不只是用來判定流派招式效果。以下是通用指南：

| 成功度 | GM 應給予的額外效果範例 |
|---|---|
| 5–9 | 獲得額外情報、節省時間、給同伴優位、發現隱藏細節 |
| 10+ | 解鎖隱藏選項、獲得意外盟友、敵人震懾或投降、物品品質提升一階 |

### 2.6 屬性檢定快速參考

| 玩家想做什麼 | 對應檢定 |
|---|---|
| 一刀斬斷繩索 | 劍術（刀術）檢定 DC 15 |
| 抬起倒塌的樑柱 | 體魄檢定 DC 18 |
| 感知此地的妖氣殘留 | 魂魄（陰陽道）檢定 DC 15 |
| 在屋頂間跳躍 | 機敏（攀爬）檢定 DC 13 |
| 威壓擊敗的敵方俘虜 | 魂魄（威壓）檢定 DC 15 |
| 說服大名提供援軍 | 魂魄（說服）檢定 DC 22 |
| 製作解毒丸 | 魂魄（調藥）檢定 DC 15 |
| 修復破損的業物 | 魂魄（鍛造）檢定 DC 20 |

## 第三章：完整戰鬥規則

### 3.1 戰鬥管理流程（GM 用）

```
【戰鬥開始】
  1. 確認戰場地圖與地形
  2. 決定所有參與者的初始位置
  3. 所有參與者進行先攻檢定
  4. 建立先攻順序表

【每回合】
  1. 回合開始階段
     ├── 處理持續性效果（燃燒傷害、中毒傷害、妖氣消退）
     └── 觸發「回合開始時」的效果

  2. 行動階段（依先攻順序逐一處理）
     └── 每位角色執行：主要動作 + 移動動作 + 附隨動作 + 可能反應動作

  3. 回合結束階段
     ├── 持續效果時效遞減
     ├── 妖氣自然消退（每位角色 −2 妖氣值）
     ├── 處理「回合結束時」的效果
     └── 判定瀕死角色狀態（HP 0 者進行死亡豁免）

【戰鬥結束】
  ├── 計算修行值獎勵
  ├── 分配戰利品（敵將的刀、情報、俘虜等）
  └── RP 後果（義理抉擇、聲望變化等）
```

### 3.2 死亡與瀕死

當角色生命值（HP）降至 0：

| 回合 | 規則 |
|---|---|
| HP 降至 0 的瞬間 | 角色倒地，失去意識。妖氣值自動歸零 |
| 之後每回合開始 | 進行死亡豁免：d20（不加任何屬性），≥10 則成功，<10 則失敗 |
| 累積 3 次成功 | 角色穩定（HP 保持 0，但不再瀕死，1 小時後恢復意識） |
| 累積 3 次失敗 | 角色死亡 |
| 自然 20 | 立即恢復 1 HP，清醒 |
| 自然 1 | 計為 2 次失敗 |
| 受到傷害 | 自動計 1 次失敗（暴擊則 2 次） |
| 被同伴治療 | 恢復 HP，瀕死狀態解除 |

### 3.3 敵方行為 AI（GM 速查）

#### 獸人敵將行為邏輯

| 妖氣階段 | 行為模式 |
|---|---|
| 平靜（0–30） | 戰術性行動：使用招式、保持陣型、優先攻擊威脅最大目標 |
| 躁動（31–60） | 半獸性：開始使用天賦技能、放棄防禦架式、優先攻擊最近目標 |
| 獸性（61–85） | 獸性主導：每回合須魂魄豁免，失敗則攻擊最近目標（不分敵我）。使用最強招式不計妖氣消耗 |
| 失控（86+） | 完全獸化：GM 直接控制，攻擊最近目標，雙重攻擊，無差別 AOE |

#### 雜兵行為

- 足輕：保持陣型，2–3 人一組圍攻同一目標（夾擊獲優位）
- 弓兵：優先攻擊無掩護目標，保持距離
- 忍者：潛行→現身攻擊→煙玉撤退→再潛行
- 僧兵：優先治療敵將，其次使用結界

#### 鬼哭原（古戰場）

- 魂魄 3 以下者每小時需魂魄豁免 DC 15，失敗則獲得 5 點妖氣（戰場怨念）
- 不死系敵人在此處生命值（HP）上限 +20%

## 第四章：合戰場系統

### 4.1 合戰概述

合戰是大規模的大名間軍事衝突。與個人戰鬥不同，合戰使用宏觀尺度的規則。

**時間與空間尺度**：
- 1 回合 = 約 10 分鐘（戰場時間）
- 距離單位「陣」= 約 50 公尺

### 4.2 戰力值（CP）

合戰的核心數值是「戰力值（CP）」，代表一支部隊的綜合戰鬥力。

**戰力值（CP）= 規模 × 兵種係數 × 士氣修正**

### 4.3 十種兵種

| 兵種 | 兵種係數 | 擅長獸族 | 特性 |
|---|---|---|---|
| 偵察兵 | ×1.0 | 鼠、猴 | 先手情報：合戰首回合獲優位 |
| 輕步兵 | ×1.2 | 犬、猴 | 機動性高：可每回合調整陣型 |
| 重步兵 | ×1.5 | 牛、豬 | 正面突破：對輕步兵 CP ×1.5 |
| 騎兵 | ×1.8 | 馬 | 側翼突襲：對弓兵 CP ×2.0 |
| 弓兵 | ×1.3 | 雞 | 遠程壓制：首回合可攻擊任一敵陣 |
| 僧兵 | ×1.0 | 羊 | 士氣回復：每回合恢復 1 點士氣 |
| 忍者眾 | ×0.8 | 鼠、蛇 | 暗殺敵將：每場合戰可進行 1 次暗殺檢定 |
| 龍騎兵 | ×2.0 | 龍 | 空中優勢：每回合可造成全敵陣 −1 士氣 |
| 巫女隊 | ×0.5 | 兔 | 妖氣淨化：減少全軍妖氣獲取量 |
| 攻城隊 | ×1.5 | 豬、牛 | 對城池 CP ×3.0 |

### 4.4 士氣系統

士氣值範圍 0–20，起始為 10。

| 士氣 | 階段 | CP 修正 | 效果 |
|---|---|---|---|
| 16–20 | 高昂 | ×1.2 | 全軍攻擊獲優位 |
| 11–15 | 穩定 | ×1.0 | 正常表現 |
| 6–10 | 動搖 | ×0.8 | 下一回合開始時可能撤退（魂魄豁免 DC 12） |
| 1–5 | 潰走 | ×0.5 | 每回合自動損失 1d4 規模 |
| 0 | 潰敗 | — | 全軍潰散，合戰結束 |

**士氣變化**：
- 擊破敵方一支部隊：+2
- 敵將被擊殺或一騎打落敗：−3（敵方全軍）
- 遭受火計或奇襲：−2
- 援軍到來：+3

### 4.5 玩家在合戰中的角色

玩家在合戰中可以選擇兩種角色之一：

#### 將領型（戰略指揮）

使用「指揮值」調度部隊：

## 第五章：一騎打系統

### 5.1 一騎打概述

一騎打是合戰中的核心高潮——雙方武將的單挑。一騎打的結果可以逆轉整個合戰局勢。

### 5.2 戰前禮儀

一騎打前，雙方必須進行「名乘」——宣告自己的流派與刀名。

- 雙方各自宣告流派與佩刀名稱
- 宣言後雙方各自獲得 +1 義理值（尊重對手的禮儀）
- 若一方拒絕名乘，該方在一騎打中所有檢定獲劣位（不名譽）

### 5.3 三回合制與三環相剋

一騎打固定進行三回合。每回合雙方各自選擇「氣勢」——類似猜拳的心理博弈：

```
攻之氣 ──→ 剋 ──→ 技之氣 ──→ 剋 ──→ 守之氣 ──→ 剋 ──→ 攻之氣
（猛攻）      （技巧）      （防禦）
```

| 你選擇 | 對手選擇 | 結果 |
|---|---|---|
| 攻之氣 | 技之氣 | 你優位，對手劣位 |
| 技之氣 | 守之氣 | 你優位，對手劣位 |
| 守之氣 | 攻之氣 | 你優位，對手劣位 |
| 相同 | 相同 | 雙方正常對抗 |
| （不利） | （有利） | 你劣位，對手優位 |

### 5.4 每回合判定

雙方擲「氣勢對抗」：

**氣勢值 = d20 + 劍術值 + 流派招式氣勢加值**

- 選擇相同氣勢：正常對抗
- 克制對手：優位
- 被對手克制：劣位

**差距效果**：

| 氣勢差距 | 效果 |
|---|---|
| 0–3 | 小勝：造成武器基礎傷害 |
| 4–6 | 中勝：造成武器基礎傷害 + 劍術值 |
| 7–9 | 大勝：造成武器傷害 + 劍術值 ×1.5，對手下一回合氣勢劣位 |
| 10+ | 完全壓制：造成最大武器傷害 + 劍術值 ×2，對手震懾 1 回合 |

### 5.5 名刀加成

持有名刀在一騎打中獲得額外加成：

| 刀等級 | 氣勢加值 | 額外效果 |

| 無銘 | +0 | — |
| 業物 | +1 | — |
| 良業物 | +1 | 傷害 +1d4 |
| 大業物 | +2 | 傷害 +1d6 |
| 最上大業物 | +2 | 可無視一次對手的氣勢相剋 |
| 天下五劍 | +3 | 傷害 +1d8、可無視一次對手的氣勢相剋、持有者所有氣勢對抗獲優位 |

### 7.2 挑戰等級計算公式

**CR = （攻擊評分 + 防禦評分 + 特殊能力評分）／3（向下取整）**

| 評分項 | 計算方式 |
|---|---|
| 攻擊評分 | 每回合期望傷害／3。期望傷害 = 命中率 × 平均傷害 |
| 防禦評分 | （HP／15）+（DV − 10）／2 + DR |
| 特殊能力評分 | 每項特殊能力 1–3 分（依 GM 判斷） |

> **簡易法則**：CR 值 ≈ 單一玩家角色可以挑戰的等級。CR X 的敵人適合等級 X 的 4 人隊伍。

### 7.5 Boss 設計指南

#### 三階段 Boss 機制

強力 Boss（CR 10+）建議設計三個戰鬥階段：

| 階段 | HP 閾值 | 特徵 |
|---|---|---|
| 第一階段 | 100%–66% | 標準模式。使用 2–3 種基礎攻擊和招式 |
| 第二階段 | 66%–33% | 獸性激發。獲得新招式、攻擊模式改變。可能召喚援軍或改變戰場 |
| 第三階段 | 33%–0% | 瀕死爆發。最強招式解鎖、被動效果啟動。妖氣不受控制（可能攻擊友軍） |

#### Boss 設計檢查清單

- [ ] 有明確的獸族和流派標籤
- [ ] 有至少一把名刀（業物以上）
- [ ] 有 2–3 種不同類型的攻擊
- [ ] 有至少 1 個範圍攻擊（AOE）
- [ ] 有至少 1 個特殊機制（召喚、地形變化、階段轉換等）
- [ ] 有義理相關的背景故事（為什麼他是反派？）
- [ ] 戰敗後有有意義的戰後選擇（斬殺／釋放／招募）

### 8.1 創世神話：十二劍聖神代記

在時間開始之前，獸神以自身十二根肋骨創造了十二位劍聖——他們分別對應十二生肖的原型。每位劍聖被賦予了一種「對刀的理解」，這十二種理解後來成為了十二生肖流派的根源。

劍聖們做了一件事：
1. **開闢百獸列島**——以各自的魂刀劈開混沌，創造了適合獸人居住的列島
2. **創造各自獸族**——每位劍聖以自己的血肉創造了一個獸族
3. **封印大妖禍**——聯手將誕生於混沌的大妖禍封印於天柱山之下
4. **化為魂刀**——封印耗盡了劍聖的力量。他們將自身化為十二把「魂刀」，沉睡於列島各地，等待輪迴之日

> **預言**：「當百獸再次為義而戰，十二魂刀將同時覺醒，新的劍聖將從戰火中誕生——或世界將被妖禍吞噬。」

### 「魂刀編年史」——完整 1–20 級戰役

#### 核心衝突

大妖禍的封印正在崩解。天下五劍開始覺醒。十二魂刀尋找新的持有者。幕後的黑月會企圖利用這場混亂「進化」所有獸人——將他們從半獸半人的武士變成完全的妖獸。而你的角色，將在這場即將顛覆百獸列島的風暴中，找到自己的「義」。

| **入門試煉** | 1 | 前往流派道場參加初傳試煉。展示基本劍術。與其他新人切磋 |

### 第四幕：傳說之道（等級 16–20）

**主題**：終極抉擇、天下五劍、封印或解放

#### 幕間節點

| 節點 | 建議等級 | 內容 |
|---|---|---|
| **皆極意自創招式** | 16 | 創出屬於自己的流派招式。流派認可你為未來宗師候補 |
| **龍族試煉** | 17 | 前往天柱山。龍神司揭示封印真相。你可能需要選擇：幫助封印還是利用封印？ |
| **尋找天下五劍** | 18 | 所有天下五劍的位置被揭露。前往最終試煉場。與各持有者交涉或戰鬥 |
| **黑月會真相** | 19 | 發現黑月會的真正目的——不是釋放大妖禍，而是融合大妖禍的力量「進化」所有獸人。他們的首領是一位墮落的龍族 |
| **最終決戰** | 20 | 在天柱山之巔進行最終決戰。三條結局路線可選 |

#### 最終結局（三條路線）

**路線一：封印之路（正史結局）**
- 犧牲自己的魂魄來強化封印
- 大妖禍被重新鎮壓
- 百獸列島恢復和平
- 你成為傳說中的「十二劍聖再世」
- 你的刀（魂刀）化為新的封印楔子，永遠守護列島
- **代價**：你的角色可能死亡或失去所有力量，成為凡人（但留下不朽之名）

**路線二：解放之路（黑暗結局）**
- 接受黑月會的邏輯：獸人不該壓抑本性
- 主動解開封印，與大妖禍的力量融合
- 所有獸族進化為完全的妖獸——失去「武士」的身分，獲得無與倫比的力量
- 百獸列島變成妖獸的樂園（或地獄）
- 你成為「新世界的神」或「毀滅世界的魔王」
- **代價**：失去所有義理、刀緣歸零、所有羈絆斷絕

**路線三：超越之路（隱藏結局，需特定條件）**
- **條件**：持有天下五劍全部五把、刀緣 100、義理值 20+、流派宗師資格
- 你找到了第三條路：不是封印也不是解放——而是「轉化」
- 將大妖禍的力量轉化為純淨的劍氣，注回百獸列島
- 大妖禍消失，所有獸族的妖氣變為劍氣——獸人不再是獸人，而是「劍人」
- 百獸列島進入新的時代——「劍之時代」
- 你被尊為「超越十二劍聖者」
- **代價**：你必須完全放棄自己的獸族身分和所有天賦技能——成為「無族者」

## 第十一章：可選規則與變體

### 11.1 龍族專屬規則

#### 龍血覺醒（劇情觸發）

龍族角色在特定劇情節點（GM 裁決）可進行龍血覺醒：

| 覺醒前 | 覺醒後 |
|---|---|
| 無飛行能力 | 獲得飛行（移動力 8 格，需消耗主要動作維持） |
| 龍鱗 DR 1 | 龍鱗 DR 3 |
| 龍息 2d6 | 龍息 3d6 |

**龍血代價**：覺醒後每次使用天賦技能，妖氣獲取量加倍。龍血越強，獸性越難控制。

#### 龍之孤獨

龍族無法使用「協助」動作。在多人遊戲中，其他玩家角色與龍族角色進行聯合檢定時獲劣位（龍的氣場排斥協作）。

### 11.2 浪人規則

玩家可以在遊戲中成為浪人（無主武士），可隨時宣布或出身即為浪人。

| 浪人優位 | 浪人劣位 |
|---|---|
| 自由之身：無忠義約束，可隨意更換勢力 | 無藩之犬：對任何大名勢力的交涉檢定獲劣位 |
| 孤狼之魂：單獨戰鬥時攻擊 +1、義理值獲取 +50% | 無主之刀：刀緣成長速度減半 |
| 浪人網絡：可聯繫其他浪人獲取情報 | 無法獲得藩國俸祿，經濟困難 |

### 11.3 雙流派修行

#### 修行條件
- 主要流派達到奧傳（修行值 60+）
- 獲得第二流派宗師同意
- 兩流派衝突度 ≤ 2（衝突度 3 的組合無法同時修行）

#### 修行規則
- 第二流派從初傳開始（修行值從 0 開始計算）
- 不能在同一回合使用兩個流派的主動招式
- 融合招式：皆極意後可自創融合兩流派特性的獨特招式

### 11.4 墮落武士與妖刀（黑暗路線）

#### 墮落三階段

| 階段 | 觸發條件 | 效果 |
|---|---|---|
| 義理之影 | 累積 2 次背義 | 魂魄檢定獲劣位。妖氣消退減半 |
| 獸性解放 | 再累積 2 次背義（總共 4 次） | 劍術 +2、妖力 +2、但魂魄 −4。妖氣值永遠不低於 30 |
| 墮落者 | 再做出一次重大背義（總共 5+ 次） | 不可逆。角色變為 NPC，GM 接管。成為劇本中的反派 |

#### 已知妖刀

| 妖刀 | 效果 | 代價 |
|---|---|---|
| 血染 | 擊殺敵人時恢復 HP（擊殺目標 HP 的 50%） | 每擊殺一名敵人，妖氣 +10 |
| 狂骨 | 暴擊範圍 17–20 | 無法進行防禦架式 |
| 嘆き | 持有者受到的所有精神攻擊無效 | 持有者無法感知任何人的情感（所有社交檢定獲劣位） |
| 黑月（新造） | 黑月會首領的佩刀。效果未知 | 推測：操控持有者意志 |

> **救贖之路**：在第三階段（墮落者）之前，角色可以透過完成 GM 設計的贖罪任務逆轉墮落。進入墮落者階段後不可逆——只能在新戰役中創建新角色。

## 第十三章：鍛造系統

### 13.1 鍛造概述

鍛造是獸人戰國最受尊崇的技藝之一。只有擁有「鍛造」技能的角色才能進行名刀鍛造。牛族刀匠公會（內匠寮）壟斷了魂鋼冶煉技術，但個人刀匠仍可通過修行掌握基礎鍛造。

### 13.2 鍛造需求

| 鍛造目標 | 所需技能 | DC | 所需材料 | 所需時間 | 失敗後果 |
|---|---|---|---|---|---|
| 修復破損的無銘刀 | 鍛造 初傳 | 12 | 鐵礦石 ×1 | 1 天 | 材料損壞 |
| 鍛造無銘刀 | 鍛造 中傳 | 15 | 鐵礦石 ×3 | 3 天 | 材料損壞，成品為破損品質 |
| 鍛造業物 | 鍛造 奧傳 | 20 | 魂鋼碎片 ×1、鐵礦石 ×5 | 7 天 | 魂鋼碎片損壞，普通材料可回收 |
| 鍛造良業物 | 鍛造 皆傳 | 24 | 魂鋼碎片 ×2、鐵礦石 ×5 | 14 天 | 魂鋼碎片損壞一半 |
| 鍛造大業物 | 鍛造 皆傳 | 24 | 魂鋼碎片 ×3、龍脈石 ×1 | 30 天 | 所有材料損壞，刀匠承受 3d6 精神傷害 |
| 鍛造最上大業物 | 鍛造 皆傳 | 30+ | 魂鋼碎片 ×5、龍脈石 ×2 | 90 天 | 所有材料損壞，刀匠承受 5d6 精神傷害，壽命減少 1 年 |

### 13.3 魂鋼碎片獲取

魂鋼碎片無法購買，僅能透過以下方式獲得：
- 劇本獎勵（如 S1 鬼哭原擊敗妖化野獸）
- 擊敗持有業物以上名刀的敵將後，可拆解其刀獲得 1d3 塊碎片
- 在龍脈節點進行 7 天冥想（魂魄 DC 22），成功可感知附近魂鋼礦脈
- 牛族刀匠公會的任務獎勵

### 13.4 鍛造儀式

鍛造業物以上名刀需要進行儀式：

1. **選材**：準備足夠的魂鋼碎片
2. **魂火點燃**：在龍脈節點或使用龍脈石點燃魂火（需魂魄 DC 15）
3. **七日夜鍛打**：每日進行鍛造檢定，需累積成功次數 ≥ 需求天數的一半
4. **血淬**：刀匠滴入自己的血（承受 1d6 傷害），賦予刀初始刀緣
5. **刀銘命名**：為刀命名。此時 GM 可根據鍛造過程決定刀的刀格

### 13.5 刀銘賦予

刀銘可以在鍛造時賦予，也可以在之後的關鍵事件中自然覺醒（見玩家規則書第七章）。鍛造時賦予銘需要滿足觸發條件，並額外消耗 1 塊魂鋼碎片。

## 第十四章：流派試煉框架

### 14.1 試煉概述

流派修行中的關鍵節點需要通過試煉。以下為 GM 設計試煉的框架：

### 14.2 各階層試煉指南

| 階層 | 試煉類型 | 建議難度 | 典型內容 |
|---|---|---|---|
| 奧傳試煉（修行值 60+） | 技藝試煉 | 中 | 在宗師面前展示對流派哲學的理解。例如虎威流：在 3 回合內擊敗一位同等級對手的模擬戰 |
| 極傳試煉（修行值 100+） | 實戰試煉 | 難 | 在實戰中使用奧義擊敗 CR ≥ 自身等級 + 2 的強敵。敵方必須是真正的威脅（不能是練習） |
| 宗師試煉（修行值 200+） | 傳承試煉 | 極難 | 為流派做出足以載入流派歷史的貢獻。例如：擊敗威脅流派的敵人、收復失落的流派秘傳、創造出被宗師認可的新招式 |

### 14.3 試煉設計原則

- **試煉應反映流派哲學**：虎威流的試煉應是公開的正面對決，潛影流的試煉可能是無聲的暗殺
- **失敗不應是終點**：試煉失敗後，可在修行值 +20 後再次挑戰
- **義理介入**：有意義的試煉應涉及義理抉擇（例如：試煉目標是玩家認識的 NPC）

## 第十五章：自創招式框架

### 15.1 自創招式規則

當角色達到皆極（修行值 150+）時，可創出屬於自己的流派招式。GM 與玩家協商設計。

### 15.2 設計參數

| 招式層級 | 妖氣池消耗範圍 | 傷害範圍（單體） | 可附加的效果 |
|---|---|---|---|
| 初傳級（基礎） | 1–2 | 武器傷害 + 1d6 | 1 個小型輔助效果（如移動 +5 格） |
| 中傳級（進階） | 3–4 | 武器傷害 + 2d6 | 1 個中型效果（如震懾、優位、DR 減少） |
| 奧傳級（奧義） | 5–7 | 武器傷害 + 3d6 | 2 個效果或 1 個大型效果（如 AOE、多重攻擊） |
| 宗師級（最終奧義） | 8–12 | 武器傷害 ×2 + 3d8 | 2 個大型效果 + 1 個劇情級效果 |

### 15.3 平衡檢查清單

- [ ] 妖氣池消耗與效果是否匹配？（對照現有同級招式）
- [ ] 是否有明確的使用限制？（每場戰鬥 1 次／須滿足條件）
- [ ] 是否保留了流派的哲學特質？
- [ ] 是否有獸族變體的空間？
- [ ] 是否過強或過弱於同級現有招式？（容許 ±20% 範圍內）

## 第十六章：騎乘戰鬥統整

### 16.1 騎乘需求

- 需擁有軍馬（500 兩）或名馬（2000 兩），或劇情中獲得
- 需騎乘技能初傳以上
- 需在足夠寬敞的空間（騎兵在室內或狹窄洞穴中無法發揮）

### 16.2 騎乘中的規則

| 項目 | 規則 |
|---|---|
| 移動力 | 使用坐騎的移動力（軍馬 12 格、名馬 14 格）取代自身移動力 |
| 攻擊 | 騎乘中使用太刀獲優位；使用和弓不可（需站立射擊）；長槍對步行目標傷害 +1d6 |
| 被攻擊 | 敵人可選擇攻擊騎士或坐騎。坐騎 HP = 20（軍馬）/ 30（名馬），坐騎倒下時騎士需機敏豁免 DC 15 否則倒地 |
| 騎乘衝鋒 | 直線移動至少 6 格後攻擊，傷害 +1d8（需騎乘中傳以上） |
| 馬上招式 | 疾風流招式在騎乘中效果 +1；不動流招式在騎乘中無法使用（需要穩固立足） |

### 16.3 馬族騎乘優勢

馬族獸人騎乘時獲得以下加成：
- 無需騎乘技能即可騎乘戰鬥（天賦能力）
- 騎乘中先攻 +2
- 坐騎 HP +10（馬族與馬匹有天然共鳴）

## 第十七章：聲望系統

### 17.1 聲望概述

聲望代表角色在特定勢力中的知名度和影響力。聲望範圍為 −10（仇敵）至 +10（傳奇）。

### 17.2 聲望等級

| 聲望值 | 等級 | 效果 |
|---|---|---|
| −10～−6 | 仇敵 | 該勢力會主動追殺你 |
| −5～−1 | 厭惡 | 該勢力的成員對你態度惡劣，交易價格 +50% |
| 0 | 中立 | 預設狀態 |
| 1–3 | 友好 | 可在該勢力領地內獲得基本款待 |
| 4–6 | 尊敬 | 可請求小型協助（如情報、補給）；交易價格 −20% |
| 7–9 | 崇拜 | 可請求中型協助（如軍事支援、特殊裝備） |
| 10 | 傳奇 | 可請求大型協助（如調動軍隊）；該勢力可能為你而戰 |

### 17.3 聲望獲取與降低

| 行為 | 聲望變化 |
|---|---|
| 完成該勢力的任務 | +1～+3 |
| 在合戰中為該勢力取得勝利 | +2～+5 |
| 拯救該勢力的重要 NPC | +3 |
| 攻擊該勢力的成員 | −1～−5 |
| 背叛與該勢力的盟約 | −3～−7 |
| 公開侮辱該勢力的大名 | −5 |

### 17.4 多勢力聲望

玩家可同時擁有多個勢力的聲望。但注意：
- 敵對勢力（如虎族 vs 犬族）的聲望會互相影響——提高一方可能降低另一方
- GM 應記錄玩家在主要勢力中的聲望變化
- 中立勢力（鼠族、猴族、豬族）的聲望獨立計算
