# 獸人戰國 TRPG —— 怪物圖鑑

> 所有怪物以繁體中文列出。挑戰等級（CR）為 4 人隊伍的參考難度。

---

## 使用說明

### 數據卡格式

| 欄位 | 說明 |
|---|---|
| 名稱 | 怪物的中文名稱 |
| 類型 | 獸人／精怪／不死／妖獸／人形 |
| 挑戰等級（CR） | 適合 4 人同等級隊伍挑戰 |
| 屬性 | 劍術／體魄／妖力／機敏／魂魄 |
| 戰鬥值 | HP／DV／DR／速度 |
| 攻擊 | 攻擊名稱、命中加值、傷害 |
| 特殊能力 | 怪物的獨特能力 |
| 掉落 | 擊敗後獲得的修行值與物品 |
| AI | 簡易行為邏輯 |

### 批量處理規則

4–5 名相同雜兵 → 合併為 1 個「集群」：
- 集群 HP = 單體 HP × 數量 × 0.7
- 集群攻擊：擲 1 次命中，每超出 DV 3 點多造成 1 次基礎傷害
- 集群 HP 低於 50%：攻擊 −1
- 集群 HP 低於 25%：潰散
