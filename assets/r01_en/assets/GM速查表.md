## Side A: Core Rules Quick Reference

### Resolution Process
```
1. Declare action → 2. Corresponding attribute → 3. Difficulty modifier
4. Check value = attribute + modifier → 5. Roll D100
   ≤ check value = success | 01-05 = critical success
   > check value = failure | 96-00 = critical failure
```

### Difficulty Modifiers
| Very Easy +40 | Easy +20 | Normal +0 | Hard -20 | Very Hard -40 |

### Combat Formulas
```
Hit: D100 ≤ HIT - enemy EVA
Damage: (ATK × multiplier - DEF) × critical × attribute
Critical: D100 ≤ CRT rate → damage ×2
Attribute: advantage ×1.5 / disadvantage ×0.5
```

### Combat Rounds
```
Each turn: 1 main + 1 move + 1 instant
Order: SPD high → low (reconfirmed each turn)
Move distance = AGI ÷ 2 meters (sprint + AGI÷10 per level)
```

### Sword Skill Recovery Lag Table
| Beginner 5-10 SP | 0-turn Recovery Lag | Chainable (after every 3 consecutive, HIT-10) |
| Intermediate 11-20 SP | 1-turn Recovery Lag | |
| Advanced 21-35 SP | 2-turn Recovery Lag | |
| Secret 36+ SP | 3-turn Recovery Lag | |

### Switch Combo Bonus
| 1st: HIT+5 | 2nd: HIT+10, ×1.1 |
| 3rd: HIT+15, ×1.2 | 4th: HIT+20, ×1.3 |
| 5th+: HIT+25, ×1.5 | Fumble → reset! |

### Skill Slot
```
Lv.1: 2 slots | Lv.10: 3 | Lv.20: 4
Lv.30: 5 | Lv.50: 6 | Lv.70: 7
Lv.90: 8 | Lv.100: 10

Weapon Skills: 1 slot | Passive: 1 slot each
General Combat: 1 slot each | Life Skills: separate 2 slots
```

### Abnormal Status
| Poisoned: -VIT÷2 HP/turn (1D6r) |
| Paralyzed: cannot act + EVA=0 (1D4r) |
| Stunned: cannot act + DEF halved (1D3r) |
| Sleep: cannot act until attacked (1D6r) |
| Cursed: checks -20 (until removed) |
| Bleeding: -STR÷2 HP/turn (1D4r) |
| Burning: -5 HP/turn + DEF-5 (1D4r) |
| Feared: cannot act for 1 turn |

## Side B: GM Tools

### Quick Monster Generation
```
Normal: HP=Lv×15 ATK=Lv×1.2+5 DEF=Lv×0.9+4
Elite: HP=Lv×30 ATK=Lv×1.5+10 DEF=Lv×1.2+8
Boss: HP=Lv×100+ ATK=Lv×2.0+15 DEF=Lv×1.5+10

HIT=25+Lv×0.5 | EVA=15+Lv×0.35 | SPD=20+Lv×0.4
EXP=Lv×15(N)/40(E)/120(Boss)
Col=Lv×8(N)/20(E)/120(Boss)(split among party)
```

### Monster Type Quick Reference
| Beast: SPD+5, ATK+5 | Undead: Poison/Bleeding immune, Holy×2 |
| Insect: EVA+5, Fire weakness ×1.5 | Armored: DEF+10, SPD-5, Lightning weakness |
| Dragon: all attributes +10 | Demi-human: intelligent, can use weapons |
| Plant: Poison/Paralysis common, Fire weakness | Magical: floating, Physical×1.2 |
| Mechanical: DEF+15, Poison immune, Lightning weakness |

### Attribute Damage Multipliers
| Advantage Attribute | ×1.5 | Disadvantage Attribute | ×0.5 | Holy vs Undead | ×2.0 |

### Boss Design Checklist
```
□ Theme consistent with Floor
□ At least 2 phases
□ 2-4 skills per phase
□ Has a clear weakness
□ Has area attacks
□ Phase transition has visual description
□ LA Reward set
□ Boss room is a Crystal-Incapacitated Zone
□ Strategy meeting has information to gather
```

### Crystal-Incapacitated Zone Rules
```
Trigger Areas: Boss room, maze trap zone, deep high floors
Effect: Teleport Crystal / Corridor Crystal / Record Crystal all disabled
Boss room door: auto-locks upon entry, opens only when Boss dies
Only exception: pre-set Corridor Crystal outside the Boss room (requires tactical preparation)

GM Tip: Before the Boss battle, be sure to inform players that "this area is a Crystal-Incapacitated Zone"
```

### Duel System Quick Reference
| First-Strike Wins: first to hit wins, 3-turn limit | Training / Entertainment |
| Half-Loss Duel: HP drops below 50% | Dispute resolution |
| Total-Loss Duel: HP to zero → death | Fight to the death |

```
Duel Rules: spectators may not interfere | no recovery items allowed
Total-Loss Duels should occur at key story moments; do not casually initiate them via NPCs
```

## Side D: Adventure Structure Quick Reference

### Adventure Structure Template
```
Prologue → Information Gathering → Field Exploration (1-3 battles) →
Maze Clearing (3-5 battles + traps) → Boss Battle →
Return & Settlement → Interlude (daily life scenes)
```

### Reward Balance (4-player party / 1 session)
- EXP: 100-300 per player
- Col: 200-500 per player
- Drops: 0-1 piece of equipment

### Level-Up Requirements (approximate)
| Lv.1→5 | ~150-700 per level |
| Lv.5→10 | ~700-1500 per level |
| Lv.10→20 | ~2k-5k per level |
| Lv.20→40 | ~5k-15k per level |
| Lv.40→75 | ~15k-40k per level |

### Drop Rate Baseline
| Normal: materials 30%, equipment 5% | Elite: materials 60%, equipment 20% |
| Boss: materials 100%, equipment 100% + LA Reward |

### Rarity Multipliers
| ★Common (×1) | ★★Fine (×0.3) | ★★★Rare (×0.1) |
| ★★★★Legendary (×0.02) | ★★★★★Mythic (Boss-only) |

### Consumable Price Quick Reference
| Small Potion 100 | Medium Potion 300 | Large Potion 800 | Ultra 2000 |
| Small SP 250 | Medium SP 600 | Antidote 150 | Panacea 1000 |
| Teleport Crystal 500 | Corridor Crystal 5000 | Record Crystal 2000 | Bomb 200 |

### Quest Levels
| E: 100-300 Col, Lv1-5 | D: 300-800, Lv5-15 |
| C: 800-2k, Lv15-30 | B: 2k-5k, Lv30-50 |
| A: 5k-15k, Lv50-70 | S: 15k+, Lv70+ |

### Downtime Daily Activities (2×/day)
| Part-time: 50-200 Col | Forging/Cooking practice: +1 exp |
| Information gathering: 1D3 pieces of info | Fishing: ingredients |
| Socializing: raise NPC favorability | Training: Lv×5 EXP |
| Shopping / Exploration / Rest |

### Weapon Durability
| ★100 durability | ★★150 | ★★★250 | ★★★★400 | ★★★★★600 |
| -1 per battle | -2 when critically hit | at zero = ATK drops to 10% |
| Repair cost = missing durability × rarity multiplier |

### Floor Unlock
```
Boss dies → teleport gate appears → reach new Floor's main town
→ activate teleport gate → system-wide server announcement
First activation: EXP+100, title "Pioneer"
```
