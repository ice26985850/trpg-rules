# SAO TRPG — Material Compendium

> *"In SAO, almost everything can be obtained from monsters, gathering, or quests. Nothing is unbuyable — as long as you have enough Col and information."*

---

## How to Use

This compendium collects all obtainable materials in SAO, organized by category. Each material is marked with:

- **Rarity**: ★Common / ★★Uncommon / ★★★Rare / ★★★★Legendary
- **Acquisition**: Monster Drop / Gathering / Fishing / Quest / Shop Purchase
- **Location**: Floor and area
- **Use**: Smithing / Cooking / Potion / Tailoring / Accessory, etc.

## VII. Material Acquisition Check Tables

### 7.1 Mining Check

```
Roll D100 ≤ (STR + Mining Skill×3 + LUK÷2)
Success: Obtain 1-3 random ores from that area's mining table
Critical Success (01-05): Chance of Rare Ore doubled + quantity +1
Critical Failure (96-00): Vein collapses, that mining point disabled for 1 in-game week
```

### 7.2 Gathering Check

```
Roll D100 ≤ (INT + Gathering Skill×3 + LUK)
Success: Obtain 1-3 random materials from that area's gathering table
Critical Success (01-05): Discover rare herb
Critical Failure (96-00): Gather poisonous herb (requires VIT check or become Poisoned)
```

### 7.3 Fishing Check

```
Roll D100 ≤ (DEX + Fishing Skill×3 + LUK÷2)
Success: Catch a fish (species determined by water body and skill level)
Critical Success (01-05): Catch a rare fish or treasure chest (may contain items)
Critical Failure (96-00): Fishing line snaps, lose bait
```

### 7.4 Hunting Check

```
Roll D100 ≤ (AGI + DEX + Hunting Skill×2)
Success: Gain 1D3 extra skinning materials from a beast-type monster corpse
Critical Success (01-05): Obtain rare skinning material
Critical Failure (96-00): Material destroyed, no gain
```

| Potions | Herbs |

| Traps / Tools | Mechanical Materials + Gears |

| Crystals / Teleport Items | Warp Stone + Memory Crystal |
