# SAO TRPG — Aincrad Clearing Map Data

> *"Each Floor of the floating castle is a separate world. Understanding its structure is the first step to clearing it."*

---

## Map General Rules

Aincrad is a vertically structured floating castle, from Floor 1 (the bottom) to Floor 100 (the top). Each Floor is a closed, independent environment with its own terrain, towns, mazes, and Floor Boss.

### Basic Map Structure

Each Floor consists of three core areas:

```
┌─────────────────────────────────────────────┐
│            Floor [X] Map Structure           │
├─────────────────────────────────────────────┤
│                                             │
│  ┌─────────────┐                             │
│  │  Main Town   │  ← Safe Zone — all         │
│  │ (Town)       │     facilities concentrated│
│  └──────┬──────┘                             │
│         │ Teleport Gate (Elevator Tower)      │
│    ┌────┴────┐                               │
│    │Teleport  │ ← vertical passage connecting│
│    │ Gate     │    floors; walking takes     │
│    │          │    1–3 in-game days          │
│    └────┬────┘                               │
│         │                                    │
│  ┌──────┴──────────────────────────────┐     │
│  │  Wilderness Area                      │     │
│  │  plains/forest/desert/swamp/volcano…  │     │
│  │  Normal/Elite monsters distributed    │     │
│  └──────────────┬──────────────────────┘     │
│                 │                            │
│  ┌──────────────┴──────────────────────┐     │
│  │   Dungeon Area                       │     │
│  │   multi-level underground maze,       │     │
│  │   with traps                         │     │
│  │   Boss Room at the deepest point      │     │
│  └─────────────────────────────────────┘     │
│                                             │
└─────────────────────────────────────────────┘
```

### Map Information Tracking

During play, the GM must continuously track the following map information:

| Tracking Item | Description | Update Timing |
|---------------|-------------|---------------|
| **Cleared Floors** | Which floors have been cleared | Each time a Floor Boss is defeated |
| **Explored Areas** | Which maze passages have been traversed | Each maze exploration |
| **Teleport Gate Status** | Whether each floor's teleport gate is activated | When first activated per floor |
| **Boss Alive Status** | Whether the Boss has been defeated | When the Boss battle ends |
| **Crystal Nullification Zone** | Which areas have disabled crystals | When Boss Room is locked / GM design |
| **NPC Location** | Which floor important NPCs are currently on | When the story progresses |
| **Floor Theme Changes** | Each floor's environmental features | When first arriving at each floor |

## GM Map Usage Guide

### Map Update Timing

| Timing | Action |
|--------|--------|
| Player first arrives at a new Floor | Mark that Floor as "explored" and display its map information |
| Clearing Boss Room | Mark Boss as "defeated" and update drops |
| Using Teleport Crystal | Confirm which Floor the Player is currently on |
| After the Death Game declaration | Open Dungeon Area exploration across all floors |
| Clearing a Floor | Activate the next floor's teleport gate, update global progress |
| Entering Boss Room | Mark the Crystal Nullification Zone |

### MAP_UPDATE Example

```
[MAP_UPDATE]
NODE town-beginnings x=0 y=0 type="Town of Beginnings" label="Floor 1 Town of Beginnings" explored=true region="Basic Difficulty Zone"
NODE urbus x=0 y=80 type="Frontline Town" label="Floor 2 Urbas" explored=false region="Basic Difficulty Zone"
EDGE town-beginnings->urbus type="Elevator Tower Passage"
REGION Basic Difficulty Zone color="rgba(16,185,129,0.1)" nodes=town-beginnings,urbas
[/MAP_UPDATE]
```
