# Chapter 1: Light Cone Codex

Light Cones are a character's core equipment, akin to "magical implements" or "magic items," bound to a Path for use. The star rating determines the magnitude of attribute bonuses and the strength of special effects. A character may equip **1 Light Cone** at a time.

## Light Cone Enhancement Rules

Light Cones can be raised by 1 star-rating tier (up to their max) through "enhancement materials," allowing lower-star Light Cones to grow with the character:

| Enhancement | Cost | Effect |
|-------------|------|--------|
| 3★ → 4★ | Same-Path enhancement materials ×2 + 500 Credit Point (CP) | Attribute bonus +1, effect strengthened (GM's discretion) |
| 4★ → 5★ | Same-Path enhancement materials ×4 + 2,000 Credit Point (CP) | Attribute bonus +1, effect strengthened (GM's discretion) |

> **Enhancement Materials**: May be awarded by the GM as dungeon rewards, typically named "Core of ○○" (e.g., "Core of Destruction," "Core of Erudition").

## Relic Slots and Main Affixes

Each Relic occupies one slot and provides that slot's **main affix**:

| Slot | Main Affix | Typical Value Range |
|------|------------|---------------------|
| **Head** | Hit Points (HP) maximum | +5 ~ +30 (by Relic quality) |
| **Hands** | Attack/Damage | +1 ~ +6 to hit or +1d4 ~ +2d6 damage |
| **Body** | Armor Class (AC) / Defense | +1 ~ +5 Armor Class (AC) or 1~3 damage reduction |
| **Feet** | Speed / Initiative | Speed +1 ~ +3m or Initiative +1 ~ +4 |
| **Ornament A** | Attribute boost | Any one attribute +1 ~ +3 |
| **Ornament B** | Special effect | See Ornament set effects |

# Appendix: GM Distribution Guide

## Recommended Distribution Cadence

| Level | Light Cone Tier | Relic Set | Ornament Set |
|-------|-----------------|-----------|--------------|
| 1 (character creation) | 3★ ×1 | None | None |
| 2-4 | 3★ ×1-2 | 2-piece (loose pieces) | None |
| 5-7 | 4★ ×1 | 4-piece ×1 (complete) | 2-piece ×1 |
| 8-10 | 4★ ×2 | 4-piece ×1-2 | 2-piece ×1 |
| 11-13 | 4★ ×2 (may enhance to 5★) | 4-piece ×2 | 2-piece ×2 |
| 14-16 | 5★ ×1 | 4-piece ×2-3 | 2-piece ×2 |
| 17-20 | 5★ ×2 | Multiple switchable sets | Multiple switchable sets |

## Custom Equipment Guidelines

The GM may design custom Light Cones or Relics following these principles:

1. **Light Cone Design**: Name → Bind to a Path → Attribute bonus (star rating corresponds to +1/+2/+2+) → 1 core effect
2. **Relic Design**: Name → Suitable Path → 2-piece effect (weak) → 4-piece effect (strong, requires a trigger condition)
3. **Power Calibration**: Reference the values of existing equipment at the same tier, ensuring it does not exceed the equivalent of a +2 modifier
