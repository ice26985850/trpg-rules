# 後室行者 TRPG —— 實體圖鑑

> 實體不是怪物。牠們是環境的一部分。大多數不該戰鬥——你該跑、躲、或利用環境規則反制。

---

## 笑魘

| 項目 | 內容 |
|------|------|
| **威脅等級** | ★★★（黑暗中）/ ☆（光亮中） |
| **出現樓層** | 所有黑暗樓層 |
| **行為模式** | 黑暗中攻擊——浮現過大笑容，凝視後攻擊 |
| **核心弱點** | 光——任何有效光源立即驅散 |
| **生命值** | 15（實體化時） |
| **防禦值** | 14（黑暗中虛體化——物理攻擊劣勢） |
| **攻擊加值** | +5（僅黑暗中） |
| **傷害** | 1D4 物理 + SP -1D4 |
| **關鍵機制** | 光照系統——全亮（安全）/ 微光（存在但虛體）/ 閃爍（50%實體）/ 黑暗（完全實體） |
| **驅逐方式** | 全亮光源：立即消失。杏仁水投擲：驅逐 1D3+1 回合。火焰：保持遠距。 |

## 電工

> *「你切斷主電源的瞬間，那東西停了下來——然後緩緩轉頭，朝你的方向伸出焦黑的手指。」*

| 項目 | 內容 |
|------|------|
| **威脅等級** | ★★★ |
| **出現樓層** | Level 3（發電站） |
| **行為模式** | 巡邏機房、維修設備；被驚擾或靠太近時釋放電擊 |
| **核心弱點** | 切斷主電源可暫停（1D6 回合）；絕緣材料可防禦電擊 |
| **生命值** | 16 |
| **防禦值** | 13 |
| **攻擊加值** | +4 |
| **傷害** | 2D6 電擊（並 SP -1） |
| **群體規模** | 1-2 |
| **關鍵機制** | 裸露電線區域：機敏 DC 12 通過否則 1D6 電擊。電工本體攻擊為電擊，可透過切斷電源癱瘓。 |
| **驅逐方式** | 切斷主電源暫停；轉入非電力區域可脫離。不直接殺死——重啟發電機才是目標。 |

## 暗影

> *「你看不見牠。但你腳下的影子……不見了。你低頭——什麼都沒有。然後你聽到身後，有東西在笑。」*

| 項目 | 內容 |
|------|------|
| **威脅等級** | ★★★（接觸時）/ ☆（不接觸） |
| **出現樓層** | Level 6（熄燈） |
| **行為模式** | 在黑暗邊緣移動——不直接攻擊，接觸使角色的影子消失 |
| **核心弱點** | 任何光源（應急燈）可驅散；移動緩慢 |
| **生命值** | 12（虛體——物理攻擊劣勢） |
| **防禦值** | 12 |
| **攻擊加值** | +3（接觸） |
| **傷害** | 影子消失——機敏／閃避相關檢定 -1（永久，意志 DC 15 減半為 -0） |
| **群體規模** | 2-4 |
| **關鍵機制** | 接觸規則——角色與暗影接觸→失去自己的影子。影子消失導致敏捷相關檢定 -1。維持光源可阻止。 |
| **驅逐方式** | 恢復光源（應急燈）驅散；無法殺死。 |

| **核心弱點** | 不可直視（直視 SP 永久 -3）；離開水域即安全 |

| **驅逐方式** | 無法殺死。保持安靜、避免直視、快速通過排水管道。 |
