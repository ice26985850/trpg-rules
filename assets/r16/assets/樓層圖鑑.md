# 後室行者 TRPG —— 樓層圖鑑

> 後室由無限多個「樓層（Level）」構成。以下為8劇本中涉及的所有樓層（15+個）完整參考。

## Level 0 — 教學關卡（前廳）

| 項目 | 內容 |
|------|------|
| **劇本** | S1 甦醒 |
| **類型** | 黃色辦公隔間——後室的經典入口 |
| **空間穩定度** | 輕度不穩定（空間微變） |
| **主要威脅** | 孤立感（SP侵蝕）、偶爾獵犬 |

| **出入口** | 出：防火門→L1、黑暗樓梯→L2、電梯→L4 |
