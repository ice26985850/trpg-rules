# 第一章：歡迎來到後室

## 1.1 什麼是後室行者 TRPG？

**後室行者 TRPG** 是一款以「後室（The Backrooms）」為世界觀的桌上角色扮演遊戲。你將扮演一個從現實世界意外「卡穿」進後室的普通人——可能是一個加班到深夜的上班族、一個在地下停車場迷路的送貨員、或一個在自己家裡走錯門的學生。

這不是一個關於英雄的故事。這是一個關於生存的故事。

## 1.2 這款遊戲的核心體驗

| 核心玩法 | 說明 |
|---------|------|
| **樓層探索** | 後室由無限多個「樓層（Level）」組成，每個樓層有獨特的空間結構、物理規則和威脅 |
| **資源管理** | 杏仁水、食物、電池——每一樣東西都要精打細算 |
| **實體回避** | 後室中有「實體（Entity）」——牠們不是你可以打倒的怪物。大多數時候，你該跑 |
| **出口尋找** | 每個樓層有通往其他樓層的出口。你的目標是：找到活下去的路 |

> **設計哲學：** 「後室不在乎你。它沒有惡意——它只是沒有善意。你在這裡不是英雄，你是一個在無限迷宮中試圖不要死掉的普通人。」

## 1.3 你需要什麼來玩？

| 物品 | 用途 |
|------|------|
| 這本規則書 | 了解遊戲規則 |
| 角色卡（空白玩家角色卡.xlsx） | 記錄你的角色資訊 |
| 一顆二十面骰（D20） | 進行檢定 |
| 鉛筆和橡皮擦 | 記錄和修改 |
| 一位遊戲主持人（GM） | 由一位朋友擔任，負責描述世界、扮演NPC、裁決行動 |

## 1.4 第一次遊戲快速開始

如果你急著想玩，以下是五分鐘快速開始：

1. **打開角色卡 Excel 檔案**，按照第三章的六步創建流程填寫
2. **閱讀第二章**了解如何擲骰和檢定
3. **你的 GM 會引導你**進入第一個劇本「S1 甦醒」
4. 遇到不懂的術語，翻到附錄查看術語表

# 第二章：核心規則

## 2.1 基礎擲骰系統

後室行者 TRPG 使用 **D20 系統**。當你嘗試做任何有不確定結果的事情時，擲一顆二十面骰（D20），加上相關的調整值，對抗一個目標難度（DC）。

### 基礎公式

```
D20 + 屬性值（AV）+ 熟練加值（PB）+ 情境調整值 vs 難度等級（DC）
```

- **如果結果 ≥ DC**：你成功了！
- **如果結果 < DC**：你失敗了。事情可能變得更糟。

### 大成功與大失敗（雙軌制）

| 情況 | 效果 |
|------|------|
| 自然骰擲出 **20** | **大成功！** 你做得比預期更好。GM 會描述額外的正面效果。 |
| 自然骰擲出 **1** | **大失敗……** 事情以最糟的方式出錯了。 |
| 結果比 DC **高出 10 或以上** | **大成功！** 即使沒有自然 20。 |
| 結果比 DC **低出 10 或以上** | **大失敗……** 即使沒有自然 1。 |

兩者可以疊加：自然 20 且高出 DC 10 以上 = **傳奇成功**。自然 1 且低於 DC 10 以上 = **災難失敗**。

### 優勢與劣勢

當你處於特別有利或不利的情況下，GM 可能給你「優勢」或「劣勢」：

- **優勢**：擲 2 顆 D20，取較高的結果
- **劣勢**：擲 2 顆 D20，取較低的結果

優勢和劣勢不會疊加——如果你同時有優勢和劣勢，它們互相抵消，你正常擲一顆 D20。

> **小提示**：優勢大約等於 +3.3 的加值。劣勢大約等於 -3.3。它們不改變你可能擲出的範圍（1-20），但顯著改變你的成功率。

## 2.2 五大屬性

你的角色有五個核心屬性，代表你在後室中生存的各個面向：

| 屬性 | 縮寫 | 含義 | 在後室中的角色 |
|------|------|------|---------------|
| **體魄** | PHY | 身體健康、耐力、對物理傷害的承受力 | 長時間行走不疲勞、抵抗實體攻擊、在危險環境中保持行動力 |
| **機敏** | AGI | 速度、反應、靈巧 | 逃離追擊、在坍塌前穿過危險區域、無聲移動 |
| **感知** | PER | 觀察力、對環境細節的敏銳度、直覺 | 察覺出口位置、辨識異常物體、聽到遠處的腳步聲 |
| **理智** | SAN | 精神韌性和心理承受力 | 抵抗後室對心理的侵蝕——無盡走廊、孤獨、不合邏輯的空間 |
| **知識** | KNO | 對後室規則的理解、記憶力 | 回憶樓層資訊、破解環境謎題、與其他流浪者交換情報 |

**屬性值範圍**：1 到 10。普通人類平均值約為 5。

**屬性加值**：在後室行者中，屬性加值**直接等於你的屬性值**。例如：體魄 6 的角色在體魄檢定中獲得 +6 加值。

## 2.3 衍生屬性

從五大屬性可以計算出以下衍生數值：

| 衍生屬性 | 計算公式 | 說明 |
|---------|---------|------|
| **生命值（HP）** | 體魄 × 2 + 5 | 你的身體能承受多少傷害。歸零時你瀕臨死亡 |
| **防禦值（DEF）** | 10 + 機敏值 | 實體攻擊你時需要超越的目標數值 |
| **理智值（SP）** | 理智 × 3 + 10 | 你的精神韌性總量。歸零時你失控 |
| **杏仁水儲備** | 初始 5 單位 | 後室中最關鍵的資源——治療、恢復理智、驅逐實體 |
| **卡路里儲備** | 初始 10 單位 | 每天消耗 1 單位。歸零→體魄每日 -1 |
| **負重上限** | 體魄 × 2（公斤） | 你可攜帶的物品總重量 |
| **移動速度** | 6 + 機敏值（米/回合） | 戰鬥中每回合可移動的距離 |
| **先攻加值** | 機敏值 + 感知值 | 決定戰鬥中的行動順序 |

### 生命值（HP）的意義

HP 不是一個可以隨意消耗的資源。在後室中，你的 HP 非常有限——一個健康的普通人（體魄 5）只有 15 點 HP。一次實體的攻擊可以造成 4-8 點傷害。

**這就是為什麼戰鬥是最後選項。**

### 理智值（SP）的意義

SP 代表你的心智完整度。它不像 HP 那樣會因物理傷害而降低——它因恐懼、孤獨、和目睹不該存在的事物而侵蝕。

當 SP 降低時，你對世界的感知開始扭曲。當 SP 歸零時，你失去對自己的控制。

## 2.4 難度等級（DC）階梯

| DC | 難度標籤 | 典型場景 |
|----|---------|---------|
| 5 | 極簡單 | 打開一扇未鎖的門 |
| 8 | 簡單 | 翻越一道矮牆 |
| 10 | 一般 | 在凌亂的桌面上搜索物品 |
| 12 | 中等 | 撬開一把簡易鎖 |
| 15 | 困難 | 在雜亂環境中搜索有用物資 |
| 18 | 非常困難 | 在黑暗中無聲移動 |
| 20 | 極難 | 強行切出樓層 |
| 25 | 近乎不可能 | 在完全黑暗中辨識方向 |

### 情境調整值

環境會影響你的檢定難度。GM 可能因以下因素調整 DC：

| 因素 | 調整 |
|------|------|
| 光線充足 | DC -2 |
| 微光/昏暗 | DC +2 |
| 完全黑暗 | 自動失敗（除非有特殊能力） |
| 有合適工具 | DC -2 至 -5 |
| 時間充裕 | DC -3 |
| 匆忙/壓力下 | DC +2 |
| 角色已受傷 | DC +2 |

## 2.5 技能系統

技能代表你通過背景和經歷獲得的特定能力。後室行者 TRPG 共有 **18 項技能**，按五大屬性分類：

### 體魄（PHY）技能

| 技能 | 說明 |
|------|------|
| **運動** | 攀爬、跳躍、游泳、長距離移動 |
| **耐力** | 抵抗疲勞、忍受飢餓和口渴、在極端溫度下生存 |
| **力量** | 舉起重物、破壞障礙、推開堵塞的門 |

### 機敏（AGI）技能

| 技能 | 說明 |
|------|------|
| **潛行** | 無聲移動、躲藏、不被實體察覺 |
| **特技** | 保持平衡、翻滾、通過狹窄通道 |
| **巧手** | 撬鎖、拆除陷阱、精細操作 |
| **閃避** | 避開攻擊、逃離危險區域 |

### 感知（PER）技能

| 技能 | 說明 |
|------|------|
| **搜索** | 在環境中尋找物資、線索、隱藏的物品 |
| **追蹤** | 跟隨痕跡、辨識足跡、判斷實體活動區域 |
| **洞察** | 判斷他人意圖、察覺欺騙、辨識偽裝 |
| **危險感知** | 本能地察覺即將到來的危險 |

### 理智（SAN）技能

| 技能 | 說明 |
|------|------|
| **意志** | 抵抗恐懼、保持冷靜、對抗精神控制 |
| **鎮定** | 在高壓環境中保持理智、安撫他人 |
| **冥想** | 通過精神集中恢復理智、抵抗環境侵蝕 |

### 知識（KNO）技能

| 技能 | 說明 |
|------|------|
| **後室知識** | 回憶樓層資訊、實體特徵、已知出口 |
| **急救** | 治療傷口、穩定傷勢、辨識藥物 |
| **製作** | 修理物品、製作工具、改裝裝備 |
| **空間記憶** | 記住路線、不迷路、繪製地圖 |

### 技能熟練度

每項技能有三個熟練等級：

| 等級 | 加值 | 說明 |
|------|------|------|
| **未受訓** | +0 | 你沒有特別訓練過這項技能，只能依靠屬性 |
| **受訓** | +3 | 你接受過相關訓練或有豐富經驗 |
| **專精** | +5 | 你是這方面的專家 |

**技能檢定公式**：`D20 + 屬性值 + 熟練加值 vs DC`

> **範例**：你的角色有「感知 6」和「搜索（受訓）」。你在一個廢棄辦公室中搜索物資。GM 設定 DC 為 15。你擲 D20 得到 11。
> 
> 11 + 6（感知值）+ 3（受訓加值）= 20 ≥ 15 → **成功！**
> 
> 你在一個抽屜深處找到了一瓶未開封的杏仁水和幾顆電池。

# 第三章：角色創建

## 3.1 角色創建總覽

後室行者 TRPG 的角色創建是一個六步驟的敘事過程。你不是在「打造一個職業角色」——你是在定義一個**真實的人**，然後將他/她投入後室。

| 步驟 | 內容 | 產出 |
|------|------|------|
| 1. 你是誰 | 名字、年齡、卡穿前的生活 | 角色背景故事 |
| 2. 屬性配點 | 25 點分配給五大屬性 | 屬性數值 |
| 3. 你口袋裡的東西 | 卡穿時身上的物品 | 起始裝備 |
| 4. 你在這裡多久了 | 決定初始知識值和起始樓層 | 起始狀況 |
| 5. 你見過什麼 | 第一次實體遭遇 | 初始理智調整 |
| 6. 你想回去嗎 | 角色的核心動機 | 劇情掛鉤 |

## 3.2 步驟一：你是誰

回答以下問題來建立你的角色：

- **名字**：你的角色叫什麼？
- **年齡**：多大年紀？
- **卡穿前的生活**：你做什麼工作？你的日常是什麼樣的？
- **卡穿的瞬間**：你在哪裡、做什麼的時候掉進了後室？

> **範例**：李明，32 歲，夜班保全。他在凌晨三點巡邏一棟舊辦公大樓時，走過一條特別長的走廊——走廊盡頭的門打開後，不是停車場，而是 Level 0 的黃色隔間。

## 3.3 步驟二：屬性配點

你有 **25 點**可以分配給五大屬性。每個屬性的範圍是 **1 到 8**（初始創建時單項上限為 8）。

### 配點建議

| 角色類型 | 建議重點屬性 |
|---------|-------------|
| 依靠身體的生存者 | 體魄高、機敏中高 |
| 謹慎的探索者 | 感知高、知識中高 |
| 精神堅韌的獨行者 | 理智高、知識中 |
| 全能型 | 各屬性均勻分配（約 5/5/5/5/5） |

> **配點範例**（夜班保全 李明）：
> 
> 體魄 6、機敏 5、感知 7、理智 4、知識 3
> 
> 總和：6+5+7+4+3 = 25 ✓

### 衍生屬性計算

填完屬性後，立即計算你的衍生屬性：

| 衍生屬性 | 計算 | 李明的數值 |
|---------|------|-----------|
| 生命值（HP） | 體魄 × 2 + 5 | 6×2+5 = **17** |
| 防禦值（DEF） | 10 + 機敏值 | 10+5 = **15** |
| 理智值（SP） | 理智 × 3 + 10 | 4×3+10 = **22** |
| 負重上限 | 體魄 × 2 kg | 6×2 = **12 kg** |
| 移動速度 | 6 + 機敏值 m | 6+5 = **11 m/回合** |
| 先攻加值 | 機敏值 + 感知值 | 5+7 = **+12** |

## 3.4 步驟三：背景選擇

選擇一個「卡穿前背景」。背景決定了你的熟練技能和建議起始物品。以下是八種可選背景：

> **⚠ 創角熟練度分配（必讀）**：每個背景給你三類熟練度，請務必全部完成分配：
> - **受訓技能（選 3）**：從背景列表中的建議技能挑選。
> - **自由受訓（選 2）**：任意不與上述重疊的技能，提升至受訓（+3）。
> - **專精技能（選 1）**：將**任意一項**技能直接提升至專精（+5）。這是創角時**必須**做出的一個選擇——它代表你最擅長的領域，請記錄在角色卡的「技能熟練度」欄位。

### 背景一：夜班保全

> *「我在這棟樓值了三年夜班。我以為每個角落我都認識。直到今晚。」*

| 項目 | 內容 |
|------|------|
| **屬性傾向** | 感知 + 體魄 |
| **受訓技能（選 3）** | 搜索、洞察、危險感知、耐力 |
| **專精建議** | 搜索 或 洞察 |
| **自由受訓（選 2）** | 任何不與上述重疊的技能 |
| **建議起始物品** | 手電筒（含電池）、鑰匙圈（含萬能鑰匙）、保溫瓶（裝滿咖啡） |
| **背景能力** | **夜視適應**：在微光環境中，感知檢定不會因光線不足而獲得劣勢 |

### 背景二：外送員

> *「我每天騎車穿過半個城市。我認識每條捷徑。但今天，導航帶我走了一條不在地圖上的路。」*

| 項目 | 內容 |
|------|------|
| **屬性傾向** | 機敏 + 感知 |
| **受訓技能（選 3）** | 空間記憶、特技、運動、耐力 |
| **專精建議** | 空間記憶 或 特技 |
| **自由受訓（選 2）** | 任何不與上述重疊的技能 |
| **建議起始物品** | 手機（無訊號但可當手電筒）、背包（大容量）、保溫袋（內有食物） |
| **背景能力** | **捷徑思維**：導航相關的空間記憶檢定獲得優勢 |

### 背景三：研究生

> *「我的論文題目是『非歐幾里德空間的理論模型』。教授說這沒什麼實際用途。他錯了。」*

| 項目 | 內容 |
|------|------|
| **屬性傾向** | 知識 + 理智 |
| **受訓技能（選 3）** | 後室知識、製作、冥想、洞察 |
| **專精建議** | 後室知識 或 製作 |
| **自由受訓（選 2）** | 任何不與上述重疊的技能 |
| **建議起始物品** | 筆記本和筆、計算機、圖書館借書證（沒有用，但讓你覺得安心） |
| **背景能力** | **理論應用**：遇到與物理規則相關的異常現象時，可做知識檢定（DC 15）來理解其規律，成功則下一次相關檢定獲得優勢 |

### 背景四：急診護士

> *「我見過很多可怕的東西。車禍、重傷、死亡。但沒有一樣能讓我準備好面對這裡。」*

| 項目 | 內容 |
|------|------|
| **屬性傾向** | 理智 + 知識 |
| **受訓技能（選 3）** | 急救、鎮定、意志、洞察 |
| **專精建議** | 急救 或 鎮定 |
| **自由受訓（選 2）** | 任何不與上述重疊的技能 |
| **建議起始物品** | 急救包、醫療手套、護士服（口袋多） |
| **背景能力** | **緊急處置**：急救檢定獲得優勢。當治療他人時，額外恢復 1D4 HP |

### 背景五：倉儲工人

> *「我每天都在倉庫裡搬東西。水泥地、貨架、堆高機。但我工作的倉庫沒有這麼大——大到沒有盡頭。」*

| 項目 | 內容 |
|------|------|
| **屬性傾向** | 體魄 + 機敏 |
| **受訓技能（選 3）** | 力量、耐力、運動、製作 |
| **專精建議** | 力量 或 製作 |
| **自由受訓（選 2）** | 任何不與上述重疊的技能 |
| **建議起始物品** | 工作手套（防護）、多功能工具刀、鐵鎚（可當武器） |
| **背景能力** | **負重適應**：負重上限增加 50%（變為體魄 × 3 kg） |

### 背景六：攝影師

### 背景七：流浪者（已在後室中待過的人）

### 背景八：上班族

## 3.5 步驟四：你在這裡多久了

這個選擇影響你的初始知識值和起始狀態：

| 時間 | 初始知識值 | 起始理智調整 | 起始樓層 | 說明 |
|------|-----------|-------------|---------|------|
| **第一天** | 0 | 無調整 | Level 0 | 你剛卡穿。什麼都不知道。什麼都沒有。只有你和無盡的黃色走廊。 |
| **一週** | +2 | 理智 -2 | Level 1 或 Level 0 | 你已經學會了基礎。你知道杏仁水是什麼。你可能已經見過 M.E.G. 的人。 |
| **一個月** | +4 | 理智 -4 | Level 1、Level 2 或 Level 11 | 你已經是一個有經驗的流浪者。你知道幾個樓層的出口。你有一些資源——和傷疤。 |

> **知識值（KNO Value）**：知識值是一個**獨立追蹤數值**（不要和「知識」屬性混淆），代表你對後室的直觀理解。創角時由「在後室時間」決定：第一天 +0／一週 +2／一個月 +4。進行**後室知識**檢定時，將知識值直接加在知識屬性上（例如知識 3 + 知識值 2 = 檢定用 5）。知識值可在遊戲中成長——達成里程碑 5「知識者」、或發現某個樓層／實體的關鍵秘密時，GM 可讓它 +1。請在角色卡的「知識值」欄位記錄此數值，並在每次成長時更新。

## 3.6 步驟五：你見過什麼

你已經遭遇了至少一種實體。選擇或擲骰決定（1D6）：

| 擲骰 | 實體 | 遭遇描述 | 初始效果 |
|------|------|---------|---------|
| 1-2 | **獵犬** | 你在黑暗中聽到了牠們——爪子刮擦地面的聲音。你跑了。你沒有回頭看。 | 你對獵犬的行為模式有基本了解。對獵犬的躲藏檢定獲得 +1 加值。理智 -1（記憶困擾你）。 |
| 3-4 | **笑魘** | 燈光熄滅的那一刻，你看到了——黑暗中那張過大的笑容。你把光源對準了它，它消失了。但不是立刻。 | 你永遠不會忘記黑暗中那張笑容。對笑魘的意志檢定獲得 +1 加值。你對黑暗有輕微恐懼（黑暗中理智檢定 DC +1）。 |
| 5 | **派對客** | 你被邀請參加一個「派對」。你差點就接受了。直到你注意到那個人的笑容不曾消失——連一秒鐘都沒有。 | 你對過度友善的陌生人保持警惕。對派對客的洞察檢定獲得 +2 加值。 |
| 6 | **竊皮者** | 你跟一個人同行了三天。第三天晚上，你注意到他的手指數量不對。 | 你不會輕易信任任何人。對偽裝實體的感知檢定獲得 +1 加值。理智 -2（信任的喪失）。 |

## 3.7 步驟六：你想回去嗎

這是最重要的問題。你的答案會定義你的角色在整個遊戲中的核心動機。

| 選擇 | 說明 |
|------|------|
| **「我必須回去。」** | 外面有人在等你——家人、愛人、或一個未完成的承諾。你的每一個行動都是為了找到回家的路。 |
| **「我不確定。」** | 你在後室中看到了現實世界從未給過你的東西——一種奇異的自由、一個重新開始的機會。你掙扎著。 |
| **「不想。這裡才是我的歸宿。」** | 你在現實世界沒有什麼值得回去的。後室是地獄——但至少它是一個誠實的地獄。 |
| **「我想回去——但不是一個人。」** | 你必須回去，但你不能留下其他人。你要找到一個能讓所有人一起回去的方法。 |

### 靈感點機制（選用）

你的「回去的理由」也是一個遊戲機制。每次聚會一次，當你的角色因為這個理由而做出某個重要決定或冒險時，你可以獲得一點「靈感點」。

**使用靈感點**：重擲任意一個 D20 檢定。你必須接受新的結果。

## 4.5 製作系統

後室中的物資永遠不夠。幸運的是，你不需要找到現成的裝備——你可以用撿到的廢料**自己造**。本系統讓「製作」技能真正派上用場（物品列表中的「自製長矛」就是透過它產生的）。

### 製作檢定

`D20 + 知識值 + 製作熟練加值 vs 製作難度（DC）`

| 項目 | DC | 耗時 | 說明 |
|------|-----|------|------|
| 簡單修理（修好撬鎖工具、補好背包） | 10 | 10 分鐘 | 恢復物品使用次數或功能 |
| 簡易改裝（加裝握把、綁繩固定） | 12 | 30 分鐘 | 小幅提升物品效果 |
| **自製武器／工具**（如自製長矛） | 14 | 1 小時 | 從廢金屬／木材製造可用裝備 |
| 複雜設備（重建簡易通訊、維修機械） | 18 | 數小時 | 需要對應零件與圖紙 |

### 材料

製作需要對應的廢料，來自樓層搜刮（金屬零件、電子元件、布料、木材等）。GM 根據樓層豐富度決定可取得的材料——Level 1、Level 4 的機械室與辦公設備是主要來源。

### 製作大成功／大失敗

- **大成功（高出 DC 5+）**：成品品質提升——額外 +1 耐久，或自製武器傷害骰 +1。
- **大失敗**：材料損壞（或部分損失），需重新搜刮材料才能再次嘗試。

### 範例：自製長矛

| 項目 | 數值 |
|------|------|
| 材料 | 長桿（木材／金屬）＋ 尖頭（廢金屬） |
| 檢定 | 製作 DC 14，耗時 1 小時 |
| 成品 | 2 kg，1D6 穿刺傷害，中距範圍——可從安全距離攻擊實體 |
| 稀有度 | 少見（需製作技能） |

> **提醒**：製作是生存工具，不是戰鬥強化。即便造出長矛，後室實體對物理傷害仍有抗性——長矛的價值在於「保持距離」，而非「造成大量傷害」。

# 第五章：生存指南

## 5.1 理智系統

理智值（SP）代表你的心智完整度。它是後室行者 TRPG 中最核心的生存資源之一——在某些方面比 HP 更重要。

### SP 的五個階段

| SP 百分比 | 階段 | 效果 |
|-----------|------|------|
| 100-76% | **穩定** | 無任何負面效果。你對世界的感知是準確的。 |
| 75-51% | **不安** | 感知和知識檢定獲得劣勢。GM 可能在環境描述中加入一個不可靠的細節。 |
| 50-26% | **恐懼** | 所有非體魄檢定獲得劣勢。GM 描述的環境開始扭曲——你可能看到牆上的圖案在移動（但你眨眼後消失了）。 |
| 25-1% | **崩潰邊緣** | 所有檢定獲得劣勢。每次遭遇壓力事件需進行意志檢定（DC 15），否則陷入恐慌狀態。 |
| 0 | **失控** | 你的心智崩潰。擲 D10 決定你的行為：盲目奔逃 / 僵直無法行動 / 幻覺攻擊（攻擊空氣） / 歇斯底里大笑 / 緊張症（無法說話或移動）。此狀態持續 1D6 分鐘或直到有人幫助你。 |

### SP 的損失

| 觸發事件 | SP 損失 |
|----------|---------|
| 獨自在樓層中超過 6 小時 | -1 |
| 目睹實體的恐怖形態 | -1 至 -3 |
| 在「不合邏輯」的空間中停留（循環走廊、方向反轉等） | -2 |
| 長時間飢餓或脫水（每天） | -1 |
| 黑暗中獨處超過 30 分鐘 | -1 |
| 近距離遭遇派對客的轉化儀式 | -3 |

### SP 的恢復

| 方式 | 恢復量 | 限制 |
|------|--------|------|
| 飲用杏仁水 | +1D4 SP | 每次使用 1 單位 |
| 與其他流浪者交流 | +1 至 +3 SP | 每次遭遇限一次 |
| 在安全區域休息 | +1 SP/小時 | 需在確定安全的區域（如前哨站） |
| 完成一個重要目標 | +1D3 SP | GM 裁定 |
| 冥想檢定（知識 DC 12） | +1 SP | 需在安靜環境中花費 1 小時 |
| 寫日記或錄音 | +1 SP | 每日限一次 |

### 意志抵抗

當面對可能損失 SP 的情況時，你可以嘗試進行意志檢定來抵抗：

- **意志檢定**：`D20 + 理智值 + 意志熟練加值 vs DC`
- DC = 潛在 SP 損失 × 5 + 5
- 成功：SP 損失減半（向下取整）
- 大成功（高出 DC 10+）：完全抵抗 SP 損失

> **範例**：你目睹了一個實體的恐怖形態（潛在損失 -3 SP）。你做意志檢定：DC = 3×5+5 = 20。你擲出 15 + 理智 4 + 受訓意志 3 = 22。成功！你只損失 1 SP。

## 5.2 傷害與治療

### 傷害類型

| 類型 | 說明 | 範例 |
|------|------|------|
| **物理——鈍器** | 撞擊、打擊 | 被獵犬撞擊、被墜落物砸中 |
| **物理——利器** | 切割、穿刺 | 被爪擊撕裂、被金屬片割傷 |
| **物理——穿刺** | 穿透性傷害 | 被尖刺刺穿 |
| **環境** | 環境造成的傷害 | 墜落、蒸汽燙傷、溺水、擠壓 |
| **精神** | 直接對理智的傷害 | 目睹不可名狀之物 |

### 受傷狀態

| 狀態 | 觸發條件 | 效果 |
|------|---------|------|
| **輕傷** | HP 低於 60% | 所有檢定 -1 |
| **重傷** | HP 低於 30% | 所有檢定 -2，移動速度減半 |
| **瀕死** | HP 降至 0 | 所有檢定獲得劣勢。每回合需進行體魄檢定（DC 15），失敗則死亡。成功三次後穩定（HP 回到 1，但處於重傷狀態）。 |

### 治療方式

| 方式 | 恢復量 | 限制 |
|------|--------|------|
| 飲用杏仁水 | 1D6 HP + 1D4 SP | 每次 1 單位 |
| 使用繃帶 | 2D6 HP，移除流血 | 每次 1 次使用 |
| 使用急救藥品 | 3D6 HP，移除流血和中毒 | 每次 1 次使用 |
| 完整休息（8 小時） | 恢復所有 HP 的 50% | 需在安全區域 |
| 短暫休息（1 小時） | 恢復 1D6 HP | 需在相對安全的區域 |

## 5.3 休息與恢復

### 短暫休息（1 小時）
- 恢復 1D6 HP
- 可進行一次冥想檢定恢復 SP
- 可進食（消耗卡路里）
- 無法在危險區域進行

### 完整休息（8 小時）
- 恢復所有 HP 的 50%
- 恢復 1D4 SP（與冥想效果疊加）
- 消耗 1 卡路里
- 只能在安全區域進行（前哨站、確認封閉的房間等）

## 5.4 卡路里與生存

| 卡路里狀態 | 效果 |
|-----------|------|
| 卡路里 > 0 | 正常狀態 |
| 卡路里 = 0 | **飢餓**：每日體魄 -1（永久，直到進食）。所有體魄檢定獲得劣勢。 |
| 卡路里 = 0 持續 3 天 | **嚴重飢餓**：每日體魄 -2。移動速度減半。SP 每日 -1。 |

**補充卡路里**：食用食物即可恢復對應的卡路里值。每天的「自然消耗」在每次完整休息時結算。

# 第六章：戰鬥基礎（玩家視角）

> **重要提醒**：本章教你如何戰鬥。但這不意味著你應該戰鬥。後室中的大多數實體不是你可以打敗的——牠們是環境的一部分。戰鬥是最後選項。逃跑幾乎永遠是更明智的選擇。

## 6.1 戰鬥何時發生

戰鬥在以下情況發生：
- 你被實體發現且無法逃離
- 你選擇主動攻擊（不建議）
- 你被迫保護自己或他人

GM 會宣告「進入戰鬥」，然後按照以下流程進行。

## 6.2 戰鬥流程概覽

```
1. 先攻判定 → 2. 回合循環 → 3. 戰鬥結束
```

### 先攻判定

每位參與者進行先攻檢定：`D20 + 機敏值 + 感知值`。結果從高到低排列行動順序。GM 的實體也參與此檢定。

平手時，機敏值高者先行。仍平手則玩家先行。

如果你在實體未察覺的情況下發動攻擊（伏擊），你自動處於先攻序列的第一位。

### 回合結構

每個回合分為三個階段：

| 階段 | 說明 |
|------|------|
| **1. 宣告意圖** | 每位參與者（按照先攻順序）宣告本回合想要做什麼。GM 先宣告實體的意圖。 |
| **2. 執行行動** | 按照先攻順序，每位參與者執行他們的行動。 |
| **3. 環境階段** | GM 描述環境變化——燈光閃爍、天花板掉落碎片、遠處傳來聲音等。 |

> **宣告意圖的好處**：這讓你能夠對即將發生的事情做出反應。如果你的隊友宣告要逃跑，你可能想要調整你的計劃。這個機制也增加了緊張感——你知道實體要做什麼，但你無力阻止。

## 6.3 行動點數（AP）

每回合你有 **2 個行動點數（AP）**。你可以使用 AP 執行以下行動：

| 行動 | AP 消耗 | 說明 |
|------|---------|------|
| **移動** | 1 AP | 移動一個距離區域（近距→中距、中距→遠距等）。你可以移動多個區域，每個區域消耗 1 AP。 |
| **攻擊** | 2 AP | 使用武器進行一次攻擊。 |
| **使用物品** | 1 AP | 飲用杏仁水、使用繃帶、交換手中物品等。 |
| **環境互動** | 1 AP | 打開/關閉門、推動物品、拉動拉桿等。 |
| **躲藏** | 1 AP | 嘗試找掩護並躲藏起來。進行潛行檢定。 |
| **觀察** | 1 AP | 仔細觀察環境。進行感知檢定以獲取更多資訊。 |
| **防禦姿態** | 1 AP | 專注於防禦。本回合內，針對你的攻擊獲得劣勢。 |
| **協助** | 1 AP | 幫助一個隊友的下一次檢定，給予其優勢。 |
| **等待** | 免費 | 將你的行動延後到回合中更晚的時機。不可延至下回合。 |
| **衝刺** | 2 AP | 移動兩個距離區域。 |

### 反應

每回合你有 **1 次反應**。反應可以在不是你回合的時候使用：

| 反應 | 觸發條件 | 效果 |
|------|---------|------|
| **閃避** | 當你被攻擊時 | 在你的防禦值上 +2。必須在被攻擊前宣告。 |
| **借機行動** | 當一個實體（或敵人）從你身邊逃離時 | 進行一次免費的近戰攻擊。 |
| **改變意圖** | 當環境發生重大變化時 | 改變你在宣告意圖階段宣告的行動（但總 AP 消耗不能改變）。 |

## 6.4 距離系統

後室行者 TRPG 使用**區域制**而非精確格子：

| 距離 | 說明 | 典型場景 |
|------|------|---------|
| **近距** | 觸手可及（0-2 米） | 近戰攻擊、遞交物品、低聲交談 |
| **中距** | 同一房間內（2-10 米） | 手電筒有效照明、手槍射程、正常交談 |
| **遠距** | 同一走廊或大空間（10-30 米） | 投擲物品的最大距離、大聲呼喊 |
| **視線外** | 看不到但可能在同一區域 | 轉角之後、隔牆、另一房間 |

移動一個距離區域消耗 1 AP。

## 6.5 攻擊

如果你真的必須攻擊，以下是流程：

### 攻擊檢定

`D20 + 機敏值（近戰）或 感知值（遠程） + 武器熟練 vs 目標的防禦值（DEF）`

- **命中**：你的攻擊命中。擲武器傷害骰。
- **未命中**：你的攻擊落空。
- **大成功**（自然 20 或高出 DEF 10+）：造成最大傷害，或附加一個效果（GM 裁定）。

### 傷害

使用物品列表中武器對應的傷害骰。大多數臨時武器造成 1D6 傷害。

> **重要提醒**：後室實體對物理傷害通常有一定抗性或極高的 HP。一個獵犬可能承受 20+ 傷害才會倒下——遠超過你能造成的傷害。打牠們通常是浪費時間和資源。

## 6.6 非戰鬥行動

### 潛行

當你不想被實體發現時：

- **潛行檢定**：`D20 + 機敏值 + 潛行熟練加值 vs 實體的感知值`
- 光線影響：完全黑暗中你獲得優勢，但實體如果對黑暗有特殊感知則相反。
- 團隊潛行：每個隊員各自檢定。只要有一個人失敗，整個團隊可能被發現。

### 逃跑

逃跑是後室行者中最關鍵的生存技能：

**追逐機制**：當你逃跑時，GM 設定起始「追逐距離」（通常 3-8）。你需要進行連續的機敏對抗檢定來拉開距離。

| 追逐距離 | 狀態 |
|---------|------|
| 0 | 被追上——進入近戰 |
| 1-3 | 危險——實體在下回合可以攻擊 |
| 4-6 | 可控制——拉開了一定距離 |
| 7-9 | 安全——實體在視線邊緣 |
| 10 | **成功逃脫！** |

每次成功拉開距離（你的機敏檢定 > 實體的機敏檢定）：距離 +2。失敗：距離 -2。

### 杏仁水投擲

對特定實體，投擲杏仁水可以創造寶貴的逃跑窗口：

| 目標實體 | 效果 | 持續 |
|---------|------|------|
| **笑魘** | 被驅逐，退開遠距 | 1D3+1 回合 |
| **獵犬** | 被驅逐，退開中距 | 1D3 回合 |
| **其他實體** | 困惑/暫停行動 | 1 回合 |

投擲杏仁水需要 1 AP，不需要攻擊檢定（自動命中），但你需要在中距範圍內。
