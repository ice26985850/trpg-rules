# 第一章：世界觀

## 1.1 世界之名：尹瑟嘉德（Ynserghard）

尹瑟嘉德是「後英雄時代」的中世紀奇幻大陸。距離最後一次大規模魔物戰爭（「裂痕戰爭」）已過去約二十年。魔王被封印，冒險者過剩——三萬多持劍者中，每年只有不到千件討伐任務可接。

這個世界正在經歷一場安靜的革命：**把劍鍛造成鍋鏟，把戰鬥直覺轉化為品管眼光，把冒險者的韌性重新定義為工匠的專注。**

---

## 1.2 創世神話

> 據說在時間開始之前，尹瑟嘉德是一張空白的餐桌。眾神圍坐，各自獻上一道菜餚。最後一位到場的是旅神，祂兩手空空，卻拿出了一本空白的食譜：「我的菜，需要時間來完成。」
>
> 旅神將食譜撕成碎片，撒向大地。每一頁碎片落入凡間，便成了一道配方——藏在魔物的血肉中、藏在礦脈的深處、藏在季節的風裡。

如今尹瑟嘉德的工匠們都相信：每一道被發現的配方，都是旅神食譜的一頁。而每一位退休冒險者走進店舖，不過是換了一種方式，繼續尋找下一頁。

---

## 1.3 冒險者退休潮四大原因

| 原因 | 說明 |
|------|------|
| **經濟過剩** | 戰後三萬冒險者 vs 年需千件任務。公會推出「鋤頭換劍」計劃 |
| **迷宮經濟** | 地下城被視為生態資源，需要懂魔物但不必整天戰鬥的人 |
| **安居令** | 國王艾德溫三世提供稅收優惠和初始貸款 |
| **個人倦怠** | 見過太多戰友倒下，對榮耀祛魅——烤麵包比揮劍更讓人安心 |

| 季節 | 影響 |
|------|------|
| **春**（甦醒） | 植物盛產但易腐；播種栽培最佳時機 |
| **夏**（活躍） | 冒險者顧客增多；高溫區需額外體力檢定 |

每季約 12-15 個遊戲回合。

# 第二章：GM 運行指南

## 2.1 遊戲循環（每週六階段）

| 階段 | 建議時間 | GM 重點 |
|------|----------|---------|
| **1. 經營準備** | 5-10 分鐘 | 投市場波動（1d6）、宣布本週狀況、玩家決定方向 |
| **2. 材料獲取** | 15-25 分鐘 | 引導採集/進貨策略，使用感官語言描述發現——不要只是說「你找到了 3 個蘑菇」 |
| **3. 製作生產** | 15-25 分鐘 | 描述製作過程的聲音/氣味/手感，品質揭曉時製造懸念 |
| **4. 營業販售** | 10-20 分鐘 | 扮演顧客 NPC、計算收入、穿插小事件（回頭客/投訴/驚喜訂單） |
| **5. 事件階段** | 10-20 分鐘 | 觸發隨機事件或推進主線劇情 |
| **6. 成長結算** | 5-10 分鐘 | 經驗值（XP）/聲望/資金統計、更新角色卡 tick |

## 2.2 節奏技巧

### 製作檢定的敘事包裝

❌ 不好的示範：*「你擲了技藝檢定，18，成功，品質卓越。」*

✅ 好的示範：*「你將鐵錠放入爐火中。千次鍛打的記憶在手臂甦醒——第一錘下去，你聽到金屬回應的共鳴。當你把劍身浸入油淬時，蒸氣散去，你看到劍身上浮現出天然的波紋。你不只鍛造了一把劍——你喚醒了金屬中的靈魂。」*

### 大失敗的處理

不要只是說「失敗了，材料報廢」。加入一個小事件：

*「你在調配藥水時手一抖，多加了兩滴龍血萃取液——試管中的液體開始沸騰、變色，然後炸開。濃煙嗆得你睜不開眼。等煙霧散去，你發現實驗台上長出了一朵拳頭大的、發著螢光的蘑菇。它似乎在看著你。」*

這就是下一個劇情 hook。

### 採集/進貨的場景感

- 採集向：讓玩家描述採集策略 → 1-2 次綜合檢定 → 描述發現
- 進貨向：將議價做成一個小場景。扮演供應商的性格——固執的老矮人、奸詐的中間商、緊張的新手供應商

## 2.3 三幕敘事節奏

```
安穩期（30%）→ 動盪期（40%）→ 綻放期（30%）
```

| 階段 | 內容 | GM 做什麼 |
|------|------|-----------|
| **安穩期** | 建立日常、認識 NPC、累積資源 | 讓玩家愛上自己的店舖和鄰居 |
| **動盪期** | 競爭對手、供應鏈問題、舊事上門 | 製造「這家店可能撐不下去」的危機感 |
| **綻放期** | 克服困難、店舖升級、傳奇委託 | 讓玩家的努力獲得盛大回報 |

## 2.5 難度設定參考

| 情境 | 建議 難度（DC） | 理由 |
|------|---------|------|
| 玩家提出合理但簡單的行動 | 6-9 | 不該在瑣事上刁難 |
| 有挑戰性的常規行動 | 12 | 熟練者約 75% 成功率 |
| 需要專業技術 | 15 | 專家才有把握 |
| 大師級挑戰 | 18 | 即使專家也需要運氣或協助 |
| 傳奇難度 | 21 | 需要完美條件 + 團隊協作 |

## 2.6 顧客滿意度系統

滿意度不是隨手寫的數字。以下規則將「品質 → 滿意度倍率 → 收入」的鏈條完整化。

### 每筆交易滿意度判定

```
滿意度基礎值 = 商品品質對應的基礎滿意度 + 服務修正 + 裝潢修正 + 特殊修正
最終滿意度倍率 = 依滿意度總值查表
```

### 品質基礎滿意度

| 品質 | 基礎滿意度 |
|------|-----------|
| 粗製 | −2 |
| 普通 | +0 |
| 精良 | +1 |
| 卓越 | +3 |
| 傳世 | +5 |

### 服務修正

| 檢定結果 | 修正 |
|----------|------|
| 接待技能 0 | −1 |
| 接待技能 1 | +0 |
| 接待技能 2 | +1 |
| 接待技能 3 | +2 |
| 符合顧客偏好 | +1（料理人「客製化調味」可額外 +1） |
| 違反顧客禁忌 | −3（如貴族對龍血過敏卻用了龍血礦石） |

### 裝潢修正

| 裝潢分數 | 修正 |
|----------|------|

GM 可用的最簡單平衡工具（依優先級排列）：

3. **調整隨機事件觸發率**：改成 1d6 結果 5-6 觸發 = 更多事件
4. **調整材料價格**：全局 ±20% = 通膨/通縮
5. **給予/收回 NPC 援助**：爐邊會援手是最強安全網

## 3.9 工具與設備耐久

### 工具耐久系統

製作工具不只會磨損——它們是工匠的第二雙手。以下是簡化耐久規則：

| 工具類型 | 基礎耐久 | 每次使用消耗 | 大失敗額外消耗 | 修理 難度（DC） |
|----------|---------|-------------|-------------|---------|
| 廚師刀具組 | 20 | −1 | −2 | 9 |
| 鍛造工具組 | 30 | −1 | −2 | 9 |
| 煉金工具組 | 25 | −1 | −2 | 9 |
| 採集工具組 | 15 | −1（採集時） | −2 | 8 |
| 研究工具組 | 30 | −1（研發時） | −2 | 9 |
| 秤重天秤 | 無耐久 | — | — | — |

### 耐久歸零

| 耐久 | 狀態 | 效果 |
|------|------|------|
| 10+ | 良好 | 無 |
| 5-9 | 磨損 | 使用時檢定 −1 |
| 1-4 | 嚴重磨損 | 使用時檢定 −2，大失敗機率 +1（nat 3-6 視為大失敗） |
| 0 | 損壞 | 無法使用，需修理（花費材料 ×1 + 技藝 難度（DC） 見上表） |
| −5 | 徹底毀損 | 無法修理，需重新購買/製作 |

### 修理

成功修理恢復 1d3 + 技藝值的耐久。鍛造師修理 難度（DC） −3 且恢復量 +2。

### 無工具懲罰

沒有對應工具時的製作懲罰（已在個別職業中定義，此處統一）：
- 烹飪無刀具 → 難度（DC） +3
- 鍛造無工具 → 無法鍛造
- 煉金無工具 → 難度（DC） +3
- 採集無工具 → 產出 −1
- 研究無工具 → 難度（DC） +2

## 3.10 個人庫存規則

### 角色攜帶上限

店舖有庫存容量（Lv.1 為 20 單位），但角色也有個人攜帶限制——特別是外出採集時。

| 體力值 | 個人攜帶上限（材料單位） |
|--------|------------------------|
| 1 | 4 |
| 2 | 6 |
| 3 | 8 |
| 4 | 10 |
| 5 | 14 |

超過上限 → 移動時體力檢定 −1（每超 2 單位額外 −1）。

### 採集時的庫存管理

每次外出採集結束後，若產出超過個人攜帶上限：
- **選項 A**：丟棄多餘材料
- **選項 B**：花費額外 1行動點（AP）「分批運送」（上限 ×1.5，但該週無法進行其他需體力的活動）
- **選項 C**：有馱馬（採集者 T2 技能）→ 上限 ×2

### 店舖庫存上限

| 店舖等級 | 庫存容量 | 溢位處理 |

| Lv.2 | 30 | |
| Lv.3 | 50 | 空間戒指每枚 +5 |
