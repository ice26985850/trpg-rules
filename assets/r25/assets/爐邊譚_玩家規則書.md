# 第一章：基礎規則

## 1.1 核心公式

```
檢定結果 = 3d6 + 屬性值 + 技能等級
成功條件：檢定結果 ≥ 難度等級（DC）
```

本遊戲使用 **3d6 鐘形曲線**——結果集中在 9-12 區間，極端值稀有。這意味著熟練工匠不會莫名其妙搞砸簡單工作，而傳世之作永遠需要一點命運的垂青。

### 3d6 概率速查

| 目標值 | 無修正 | +2 | +3 | +4 | +5 |
|--------|--------|----|----|----|-----|
| 6+ | 95% | 99% | ~100% | ~100% | ~100% |
| 9+ | 74% | 91% | 95% | 98% | 99% |
| 12+ | 38% | 63% | 74% | 84% | 91% |
| 15+ | 9% | 26% | 38% | 50% | 63% |
| 18+ | 0.5% | 5% | 9% | 16% | 26% |

## 1.5 檢定規則

### 難度階梯

| 難度 | 難度（DC） | 典型情境 |
|------|-----|----------|
| 極易 | 6 | 切蔬菜、打掃店面 |
| 簡單 | 9 | 調配基礎藥水、縫補衣物 |
| 普通 | 12 | 製作標準武器、烘焙麵包 |
| 困難 | 15 | 鍛造精良附魔裝備、研發新甜品 |
| 極難 | 18 | 鑄造卓越品質神器、破解遠古配方 |
| 傳奇 | 21 | 締造傳世之作 |

### 大成功 / 大失敗

| 事件 | 條件 | 概率 |
|------|------|------|
| **大成功** | 自然骰 16-18 | 4.63% |
| **大失敗** | 自然骰 3-5 | 4.63% |

> 只看自然骰面，不計修正值。這是命運的介入。

- **大成功**：檢定成功時品質自動提升一階。卓越+大成功 → 傳世。
- **大失敗**：本應成功 → 品質−1+小意外；本已失敗 → 工具損壞/材料全毀。

### 對抗檢定

雙方各自 `3d6 + 屬性 + 技能`，高者勝出。主動方 +1。平手各獲部分優勢。

### 合作製作

指定**主手**進行主要檢定。每位**副手**先做協助檢定（3d6 + 相關屬性，難度（DC） 10）：

| 結果 | 效果 |
|------|------|
| 成功 | 主手 +2 |
| 大成功（nat 16-18） | 主手 +4，最終品質 +1 階 |
| 失敗 | 無影響 |
| 大失敗（nat 3-5） | 主手 −2 |

最多 2 位副手同時協助。

| 品質 | 難度（DC） 偏移 | 價格 | 說明 |
|------|---------|------|------|
| ★ 粗製 | 難度（DC） − 5 | ×0.5 | 勉強能用 |
| ★★ 普通 | 難度（DC） | ×1.0 | 商業標準 |
| ★★★ 精良 | 難度（DC） + 5 | ×1.5 | 手藝出色 |
| ★★★★ 卓越 | 難度（DC） + 10 | ×2.5 | 令人驚嘆 |
| ★★★★★ 傳世 | 難度（DC） + 15 + 大成功 | ×5.0 | 傳說級工藝 |

> 若結果超過宣告門檻，以實際為準。低於宣告 → 失敗，材料消耗。

# 第二章：角色創建

## 2.1 創角流程（8 步驟）

### 步驟 1：概念構思
回答三問：退休前是什麼冒險者？為何退休？為何選此職業開店？

### 步驟 2：選擇種族

| 種族 | 屬性 | 種族特性 |
|------|------|----------|
| **人類** | 任選 +1 | **凡人韌性**：每週重擲 1 次失敗的非戰鬥檢定 |
| **矮人** | 技藝 +1 | **頑石專注**：製作時無視 1 次環境干擾劣勢 |
| **精靈** | 靈感 +1 | **長者之眼**：每天 1 次鑑定/靈感優勢（4d6 取高 3d6） |
| **半身人** | 交涉 +1 | **幸運日常**：每天 1 次大失敗→普通失敗 |
| **半獸人** | 體力 +1 | **不屈之軀**：體力檢定失敗時可用體力值抵扣傷害 |

### 步驟 3：選擇職業

| 職業 | 主屬性 | 招牌技能 | 店舖角色 |
|------|--------|----------|----------|
| **料理人** | 技藝+靈感 | 秘密食譜 | 產品核心 |
| **鍛造師** | 技藝+體力 | 匠人之魂 | 裝備支柱 |
| **藥劑師** | 鑑定+技藝 | 試藥體質 | 補給專家 |
| **商人** | 交涉+鑑定 | 嗅到商機 | 經營大腦 |
| **採集者** | 體力+鑑定 | 自然的指引 | 供應鏈 |
| **研究者** | 靈感+鑑定 | 逆向工程 | 創新引擎 |

### 步驟 4：分配屬性

| 參數 | 值 |
|------|-----|
| 屬性池 | **15 點** |
| 起始值 | 全部 = 1 |
| 每級花費 | 1 點 |
| 創角上限 | 4（不含加成） |

加成順序：基礎分配 → 種族 +1 → 職業 +1（擇一主屬性）

```
範例：人類料理人
基礎：技4 靈4 體3 鑑2 交2（14點，留1點備用）
種族(+1技) → 技5；職業(+1靈) → 靈5
最終：技5 靈5 體3 鑑2 交2
```

### 步驟 5：分配技能

# 第三章：製作與招牌技能

## 3.1 製作流程

```
選擇配方 → 準備材料 → 進行製作 → 品質鑑定 → 成品入庫
```

### 製作檢定公式

```
3d6 + 技藝值 + 技能等級 + 工具加成 + 材料品質加成 − 疲勞減值
```

### 配方難度

| 難度 | 難度（DC） | 範例 |
|------|-----|------|
| 基礎 | 9 | 恢復藥水、鐵劍、家常燉菜 |
| 進階 | 12 | 魔力藥水、精鋼武器、宮廷料理 |
| 稀有 | 15 | 龍息藥水、附魔裝備 |
| 傳說 | 18 | 不死藥、神話武器 |

### 材料加成

## 3.3 招牌技能

### 料理人「秘密食譜」
- **消耗**：2 靈感點（IP），每 2 回合 1 次
- **檢定**：3d6 + 靈感，難度（DC） 13
- **效果**：研發獨佔菜色，風味值 +3
- **進階**：Lv.2→每回合 1 次/1靈感點（IP）；Lv.3→風味 +5、精良起跳

### 鍛造師「匠人之魂」
- **消耗**：2 體力（臨時疲勞），每回合 1 次
- **效果**：品質下限 +1 級（最低普通）
- **進階**：Lv.2→下限 +2（最低精良）；Lv.3→影響全回合

### 藥劑師「試藥體質」
- **類型**：永久被動
- **效果**：自身飲用藥水效果 ×2（副作用也 ×2）
- **進階**：Lv.2→副作用不再加倍；Lv.3→每回合 1 次免疫副作用

### 商人「嗅到商機」
- **消耗**：1 靈感點（IP），每回合 1 次
- **檢定**：3d6 + 交涉，難度（DC） 12
- **效果**：提前獲知下回合市場波動
- **進階**：Lv.2→2 回合預測+投機；Lv.3→主動影響市場

### 採集者「自然的指引」
- **消耗**：1 體力，每回合 1 次
- **效果**：稀有材料發現率 ×2
- **進階**：Lv.2→×3 + 額外材料；Lv.3→指定稀有材料自動發現

### 研究者「逆向工程」
- **消耗**：1 靈感點（IP） + 1 回合製作階段
- **檢定**：3d6 + 靈感 + ⌊鑑定/2⌋，難度（DC） = 9 + 目標品質 × 2
- **效果**：分析產品獲配方草稿（完整性 −5），消耗物品
- **進階**：Lv.2→不消耗（DC +2）；Lv.3→完整性 +0，可改良

# 第五章：兼職規則

退休冒險者的優勢在於經驗豐富——你的過去不只一種身分。兼職系統讓角色在主職業之外，學習第二職業的基礎能力。

## 5.1 兼職條件

| 條件 | 說明 |
|------|------|
| **屬性門檻** | 目標職業的任一主屬性 ≥ 3 |
| **導師** | 需要一位 NPC 導師或已具備該職業的玩家角色指導 |
| **時間** | 4 週學習期（期間可正常營業，但每週需花費 1行動點（AP） 進行學習） |
| **費用** | 200G 學費（或等值材料/服務交換，GM 裁量） |
| **前提** | 必須至少完成 5 次成功交易（證明你已站穩腳跟） |

## 5.2 學習過程

| 週次 | 內容 | 檢定 |
|------|------|------|
| **第 1 週** | 基礎理論學習 | 靈感檢定 難度（DC） 12，成功則總學習時間 −1 週 |
| **第 2 週** | 基礎工具操作 | 技藝（或鑑定）檢定 難度（DC） 9，成功解鎖初始配方 |
| **第 3 週** | 實習製作（一） | 使用目標職業完成 1 次基礎配方（需導師協助） |
| **第 4 週** | 實習製作（二）+ 結業 | 獨立完成 1 次基礎配方（DC 9），成功即結業 |

> 若任一週檢定失敗，該週需重複（總時間 +1 週）。GM 可根據劇情調整節奏——例如在一次特殊事件中提前領悟。

## 5.3 兼職獲得

| 獲得 | 說明 |
|------|------|
| **招牌技能** | 獲得目標職業的招牌技能，但 **使用次數減半**（最低 1 次），靈感點（IP） 消耗 **+1** |
| **初始配方** | 獲得該職業的 2 個基礎配方 |
| **技能樹 T1** | 可從目標職業 T1 中 **選擇 1 項**（非 2 選 1） |
| **製作特色** | 獲得該職業的製作特色維度（料理人獲風味值、鍛造師獲耐久/附魔等） |

## 5.4 不獲得

| 不獲得 | 原因 |
|--------|------|
| 屬性加成 | 初始 +1 為職業天賦，無法後天獲取 |
| 初始工具/裝備 | 需自行購買 |
| 初始資金 | 無 |
| 初始技能等級 | 相關技能從 0 開始 |
| 技能樹 T2/T3 | 解鎖條件較主職業更嚴格（見下方） |

## 5.5 限制

| 限制 | 規則 |
|------|------|
| **兼職上限** | 最多 1 個兼職（共 2 個職業） |
| **招牌技能 靈感點（IP）** | 兼職招牌技能消耗 靈感點（IP） 額外 +1 |
| **技能樹 經驗值（XP）** | 兼職技能樹解鎖所需 經驗值（XP） × 1.5（T2 需 23 經驗值（XP）、T3 需 53 經驗值（XP）） |
| **品質懲罰** | 使用兼職職業進行製作時，**品質上限 −1**（術業有專攻） |
| **不可逆** | 一旦選擇兼職職業，不可更換（可花 500G + 8 週重新訓練，GM 許可） |

## 5.6 協同效果

某些職業組合在特定情境下產生協同加成——這是冒險者多元經驗的自然體現。

| 主職 + 兼職 | 協同加成 |
|------------|----------|
| **料理人 + 採集者** | 採集食材時鑑定 +1（你知道什麼是最新鮮的） |
| **料理人 + 商人** | 餐館客流 +1（你的口才讓菜色更誘人） |
| **鍛造師 + 商人** | 販售鍛造品時交涉 +1（你懂得如何展示工藝的價值） |
| **鍛造師 + 採集者** | 採集礦石時鑑定 +1（礦脈逃不過你的眼睛） |
| **藥劑師 + 研究者** | 研發藥水配方 難度（DC） −1（理論與實務的完美結合） |
| **藥劑師 + 採集者** | 採集藥草時鑑定 +1（你了解每一株草藥的藥性） |
| **商人 + 研究者** | 市場預測準確率提升（你懂得分析數據） |
| **商人 + 料理人** | 餐館客流 +1（口才 + 美食 = 口碑） |
| **採集者 + 鍛造師** | 狩獵大型獵物時體力 +1（你的武器知識幫助瞄準弱點） |
| **採集者 + 料理人** | 採集食材時產出 +1 單位（你知道哪些部位最美味） |
| **研究者 + 藥劑師** | 逆向工程藥水產品 難度（DC） −1（你對成分格外敏感） |
| **研究者 + 鍛造師** | 分析鍛造品時 難度（DC） −1（你理解金屬的語言） |

> 協同加成不疊加——若角色同時滿足多個條件（如料理人+商人+半身人交涉加成），取最高值。

## 5.7 兼職範例

### 範例：料理人兼職採集者

```
鐵火——退休戰士，現為小餐館「鐵火亭」主廚。

從此以後，鐵火不只會做菜，還能親自進山找最棒的食材——
但用採集者身分做料理時，品質上限 −1。畢竟，廚房才是他真正的戰場。
```
