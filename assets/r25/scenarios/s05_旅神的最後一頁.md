# 劇本 5：旅神的最後一頁

## 基礎資訊

| 項目 | 內容 |
|------|------|
| **難度** | ★★★★★ 傳說 |
| **建議聲望** | 80+（王國馳名 ∼ 傳說之店） |
| **建議等級** | 主屬性 5，核心技能 3 |
| **建議隊伍** | 4-6 人，全職業各有高光時刻 |
| **長度** | 8-15 回合 |
| **核心主題** | 傳承、終極成就、給世界的遺產 |

## 劇情摘要

在尹瑟嘉德的歷史中，旅神的食譜被撕成了不計其數的碎片。大部分被找到了。但有傳言說——旅神保留了最後一頁。

那一頁不是配方。是旅神手寫的一段話。據說誰能讀到那段話，誰就能理解旅神真正的意圖——為什麼要把食譜撕碎撒向大地？

現在，一個來自世界各地的邀請送到了你的店門口。爐邊會、精靈長老會、矮人工匠協會、冒險者公會、甚至萬象行——他們聯名邀請所有傳說級工匠齊聚王都，舉辦第一屆「尹瑟嘉德工藝大會」。

大會的最高榮譽：在眾人面前製作一件「代表你一生最高成就」的作品。優勝者將獲得一項獎品——據說是旅神親自留下的東西。

但你隱約感覺到：這場大會的目的不只是比賽。

## 階段設計

### 第一階段：大會前夜（第 1-3 回合）

世界各地傳說級工匠陸續抵達王都。GM 應在此階段建立每一位競爭對手的立體形象——他們不是敵人，是同道中人。

| 競爭者 | 職業 | 背景 | 特色 |
|--------|------|------|------|
| **「鐵聖」德瓦林** | 鍛造師 | 矮人傳奇鐵匠，八十歲 | 他是鍛造界的活化石。你的鍛造師可能小時候讀過他的書 |
| **「藥聖」伊莎貝爾** | 藥劑師 | 人類，發明了三種重大疾病的解藥 | 溫柔而疲憊——她一生救人，但救不了自己的兒子 |
| **「廚聖」馬可** | 料理人 | 半身人，走遍世界的流浪廚師 | 他吃過所有傳說食材，但從未擁有自己的店舖 |
| **「書聖」卡珊卓** | 研究者 | 精靈，活了三百年 | 她知道旅神食譜的真相，但她還沒決定要不要說出來 |
| **「商聖」奧林** | 商人 | 人類，萬象行的競爭對手創始人 | 他可能是來破壞大會的——或者來贖罪的 |

**關鍵場景**：
- 開幕晚宴：每位競爭者分享一個故事。這是 GM 建立 NPC 深度的黃金時刻
- 私下交流：玩家可與任何 NPC 建立個人關係。這些關係將在大會高潮影響結果

### 第二階段：大會競技（第 4-7 回合）

**規則**：每位工匠展示一件作品。作品將由五位評審（代表五個頂級勢力）共同評分。

這是全遊戲最高壓的製作環節。每位玩家角色（非整個隊伍）各自進行一次製作，目標傳世。

| 玩家職業 | 建議作品 | 所需材料 | 建議 難度（DC） 偏移 |
|----------|----------|----------|-------------|
| 料理人 | 「旅神的盛宴」——一道包含旅神食譜中所有元素的菜 | 至少 3 種傳說食材 | +15 |
| 鍛造師 | 「傳承之鎚」——一把能傳承鍛造記憶的武器 | 餘燼之鱗 + 傳說礦石 | +15 |
| 藥劑師 | 「永恆之藥」——一滴能治癒一種絕症的藥 | 龍心之血 + 千年冰晶蜜 | +15 |
| 商人 | 「公平的契約」——一份能打破萬象行壟斷的商業協議 | 需要所有競爭者的簽名（交涉挑戰） | +15 |
| 採集者 | 「旅神的地圖」——標註所有已知傳說材料位置的地圖 | 親自去過的地點必須 ≥ 10 | +15 |
| 研究者 | 「旅神食譜索引」——整理所有已知旅神配方的百科 | 需要訪問所有競爭者獲取資料 | +15 |

**合作規則**：大會允許團隊協助。但最終作品署名只能一人。這是一個團隊考驗——誰的作品代表全隊？

### 第三階段：真相（第 8-10 回合）

在評審期間，「書聖」卡珊卓私下找到玩家。她終於決定說出真相：

> **旅神的最後一頁，不是一張紙。**
>
> 旅神把最後一頁藏在「傳承」本身裡。當一個工匠教會下一個人，那個人又教會下一個人——每一次傳授，都是在重寫那一頁。
>
> 旅神撕碎食譜的真正原因，不是要讓配方散落。是要讓「尋找」本身成為配方的一部分。最好的料理永遠是下一道——因為只要還有人在尋找，旅神就還活在這個世界上。

**終極轉折**：大會的獎品——旅神的遺物——不是任何人想像中的東西。那是一個小盒子。裡面有一張紙。

紙上只有一行字：

> *「你找到了這麼多。現在——去教下一個人吧。」*

### 第四階段：傳承（第 11-15 回合）

大會結束。但玩家的故事沒有結束。

**終極抉擇**：每位玩家面臨一個選擇：

| 選項 | 內容 |
|------|------|
| **開枝散葉** | 在世界各地開設分店，每一間都培訓一位新工匠（解鎖「多店經營」擴展） |
| **著書立說** | 將畢生所學寫成書，讓知識超越時間（解鎖「學術傳承」路線） |
| **收徒傳道** | 收一位徒弟，全心培養。角色退休後，玩家可使用徒弟角色繼續遊戲（解鎖「世代傳承」擴展） |
| **繼續尋找** | 拒絕答案。旅神說「最好的料理永遠是下一道」——所以繼續找吧。這不是結束。（解鎖「無盡探索」路線） |

## 終局獎勵

| 達成 | 獎勵 |
|------|------|
| 大會優勝 | 傳說之店聲望解鎖，角色成為尹瑟嘉德歷史人物 |
| 全隊傳世 | 「傳世之隊」稱號，店舖永久客流 +3 |
| 所有競爭者成為朋友 | 解鎖「工匠聯盟」——一個比萬象行更有影響力的新組織 |
| 選擇傳承 | 店舖成為傳承之地。百年後，年輕冒險者仍會來此朝聖 |

## GM 注意事項

- **這是終局劇本**：如果玩家希望繼續遊戲，第四階段只是一個開始——世代傳承、多店經營都是可玩的擴展
- **給每個職業高光**：不要讓某個職業成為配角。每位玩家都應該在大會上有一個「這是我的時刻」的場景
- **競爭者的結局**：讓 NPC 也有結局。德瓦林可能在展示後退休，把鐵鎚送給你的鍛造師。馬可可能終於決定開自己的店。這些讓世界感覺有重量
- **旅神的信**：不要急著給。讓玩家先猜測箱子裡是什麼。最好的揭曉時機是——在他們已經理解旅神意圖之後
