# 劇本 4：獨行者的遠征

## 基礎資訊

| 項目 | 內容 |
|------|------|
| **難度** | ★★★★ 高階（單人） |
| **建議聲望** | 40-70 |
| **長度** | 6-10 回合 |
| **核心主題** | 長途旅行、傳說材料、面對過去 |

## 劇情摘要

一封沒有署名的信。信紙很舊——至少有十年了。

信上只有一行字：*「你還記得你為什麼退休嗎？如果你準備好了——來嘆息平原。我在那裡等你。」*

沒有人知道寄信人是誰。但你知道嘆息平原是什麼地方。裂痕戰爭的最後一戰在那裡打響。你也曾在那裡。

你可以選擇不去。店舖會繼續營業，每週穩穩地賺錢。沒有人會怪你。

但這封信會留在抽屜裡。每晚關店之後，你會再看它一眼。

## 關鍵 NPC

| NPC | 角色 |
|------|------|
| **信的神秘寄件人** | 可能是舊戰友、舊敵人，或你自己的過去。GM 根據玩家退休原因決定。 |
| **旅行中遇到的 NPC** | 沿途村莊的居民——他們有自己的故事。有些和戰爭有關。 |
| **你的夥伴** | 他們會跟你去嗎？放著店不管兩個月？還是留下看店？ |

## 旅程設計

### 出發前：抉擇（第 1 回合）

- 是否帶夥伴？帶 → 店舖關閉期間無收入。不帶 → 夥伴看店（基礎收入），但獨自旅行風險更高。
- 準備多少補給？路線如何規劃？→ 玩家做策略性決定。

### 旅途：嘆息平原之路（第 2-5 回合）

路線：你的城鎮 → 翠葉谷（1 週）→ 守望堡（2 週）→ 嘆息平原（1 週）。共 4 週。可使用快速旅行手段（驛站、商隊）。

沿途每個停留點都是一個迷你場景：

| 停留點 | 場景 |
|--------|------|
| **翠葉谷** | 遇到一位精靈老兵，他在戰後隱居於此。他認出了你。他有一件東西要還給你——一枚舊徽章、一把斷劍，或一封未寄出的信。 |
| **守望堡** | 邊境變化很大。當年你認識的哨站現在已經是一座小鎮。酒館老闆的女兒問你：「你認識我父親嗎？他也是裂痕戰爭的老兵。他失蹤了很多年。」 |
| **嘆息平原** | 戰場已經被野花覆蓋。但有些傷痕在地下。你需要找到寄信人。 |

### 嘆息平原：面對過去（第 6-7 回合）

GM 根據玩家的退休原因（d6 退休前傳表的結果）決定寄信人的身分：

| d6 退休原因 | 寄信人身分 | 他/她想要什麼 |
|------------|-----------|---------------|
| 1-傷退 | 當年讓你受傷的敵人——但他已經不是敵人了。他老了。他想道歉。 | 和解。或至少，一杯酒。 |
| 2-厭倦 | 一位年輕冒險者——你當年救過的人。現在他已經退休了。 | 他想說聲謝謝。當年沒機會。 |
| 3-繼承 | 前店主的舊識。他有前店主留下的遺物——「他臨終前說，留給下一個接手的人。」 | 交還遺物。 |
| 4-愛情 | 你愛過的那個人。他/她聽說了你的店。想知道你過得好不好。 | 道別——真正的道別。 |
| 5-使命 | 斷刃盟的獵人——你當年放棄的那個任務，他幫你完成了。 | 把任務的獎勵交給你。 |
| 6-失意 | 你對不起的那個人。他來了。他原諒你了——但他想親口聽你說。 | 原諒。 |

> **核心原則**：這個場景不是戰鬥。是對話。GM 不需要安排敵人——需要安排的是一個有體溫的 NPC，和一段需要被說出來的故事。

### 發現傳說材料（第 8 回合）

在嘆息平原，除了面對過去，玩家還有機會發現一種只在古戰場生長的傳說材料——**幽靈蘭**（材料圖鑑編號）。它在月光下才會顯形。

若玩家在此時已經獲得了內心的平靜（完成了與過去的對話），採集 難度（DC） 從 20 降至 16。若玩家還在掙扎——難度（DC） 保持 20。這不是遊戲難度，是心境。

### 回歸（第 9-10 回合）

帶著傳說材料、一段被說完的故事、和一個更完整的自己回家。

店還是那間店。但你已經不是出發前的那個人。

## 獎勵

| 達成 | 獎勵 |
|------|------|
| 前往嘆息平原 | 解鎖傳說材料「幽靈蘭」的穩定來源（每季可前往採集一次） |
| 與過去和解 | 永久獲得「內心平靜」——靈感枯竭免疫（原規則中連續3次靈感失敗→枯竭的效果不再觸發） |
| 帶回傳說材料 | 可製作一件傳說級作品（自選配方） |
| 夥伴留守有功 | 留守夥伴忠誠 +3（他們證明了自己可以獨當一面） |
