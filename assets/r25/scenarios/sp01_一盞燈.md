# 劇本 1：一盞燈

## 基礎資訊

| 項目 | 內容 |
|------|------|
| **難度** | ★ 入門（單人） |
| **建議聲望** | 0-8 |
| **長度** | 1-3 回合 |
| **核心主題** | 開店第一週、找到方向、遇見第一個夥伴 |

## 劇情摘要

你拿到了店舖鑰匙。門推開的時候，灰塵在午後的陽光裡飛舞。前任店主留下的只有一個佈滿蜘蛛網的櫃檯、兩張歪斜的椅子，和一張寫著「轉讓」的泛黃紙條。

你有 500G。你有你的工具。你還有一雙手。

外面街上沒有人認識你。裡面這間店還不像家。

但你知道——每個傳說都是從第一盞燈開始的。

## 關鍵 NPC

| NPC | 角色 | 關鍵台詞 |
|-----|------|----------|
| **麵包師傅貝蒂** | 友善鄰居 | 「新來的？太好了——這條街上終於又有烤東西的香味了。我那邊有多一個烤爐，你要不要？」 |
| **小石** | 潛在學徒 | （沉默地站在門口，看著你的工具。他的眼睛比他的嘴巴會說話。） |
| **老灰** | 流浪老獵犬 | （趴在店後門。牠的左耳缺了一角。牠看起來已經等了很久。） |

## 回合設計

### 第 1 回合：開張

**經營準備**：GM 不擲市場波動骰——第一週永遠是平穩。讓玩家先感受節奏。

**GM 引導**：
- 讓玩家自己決定店名、第一份菜單/商品目錄。這不是遊戲機制——這是他們的第一個「家」的儀式。
- 貝蒂帶著剛出爐的麵包來敲門。她不是來買東西的。她是來歡迎你的。
- 第一個顧客：一個看起來和你差不多老的退休礦工。他點了一杯最便宜的東西。喝完後沉默了一會，說：「很久沒有喝到這種味道了。」他付了錢。他明天還會來。

**事件**：不打事件骰。第一週唯一的「事件」是發現後門的流浪狗（老灰）。牠的腿有點跛。你可以趕走牠，也可以留一碗水。

### 第 2 回合：選擇

**經營準備**：正常擲市場波動。

玩家累積了一些小額收入。現在要做出第一個重要決定——招募誰？

| 選項 | 內容 |
|------|------|
| **收留老灰（動物夥伴）** | 花 5G 買狗糧和藥膏。老灰康復後狩獵檢定 +1。忠誠自動 10。不佔用夥伴槽位。 |
| **收小石為學徒** | 貝蒂介紹——這孩子父母雙亡，在街上打零工。他想學手藝。週薪 3G（優惠），忠誠起始 7。 |
| **兩者都要** | 如果玩家資金充裕——但這意味著更少的升級資金。 |

### 第 3 回合：站穩

- 第一個夥伴開始工作。讓玩家感受「不再是一個人」的變化——小石第一次成功做出成品，或老灰叼回了第一份獵物。
- 第一張稅單到了。10G。不多——但這提醒你：這不是退休。這是新生活的第一天。
- 投一個事件骰（溫暖向優先）。

## 獎勵

| 達成 | 獎勵 |
|------|------|
