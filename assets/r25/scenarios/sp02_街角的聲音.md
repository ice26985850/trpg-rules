# 劇本 2：街角的聲音

## 基礎資訊

| 項目 | 內容 |
|------|------|
| **難度** | ★★ 基礎（單人） |
| **建議聲望** | 8-20 |
| **長度** | 3-5 回合 |
| **核心主題** | 累積聲望、第一次面對競爭 |

## 劇情摘要

你的店開始有了名字——街坊開始稱呼它，而不是「那間新開的店」。

但隨著聲望而來的，不只有顧客。

街角那間開了十年的老雜貨舖，店主柯林，最近開始對你不太友善。他降了價。他在市場散播了一些話。他說「那種新來的撐不過一年」。

你需要證明：一個人，加上你的夥伴，就夠了。

## 關鍵 NPC

| NPC | 角色 |
|------|------|
| **柯林** | 街角雜貨舖老闆。不是反派——是害怕被取代的老人 |
| **鎮長祕書** | 即將舉辦「街坊評選」——這是拿聲望的好機會 |
| **你的回頭客群** | 那些每週固定來的人——他們是你在這場競爭中最強的武器 |

## 回合設計

### 第 1-2 回合：摩擦

- 柯林開始降價。你的部分顧客流失（客流 −1d2，持續 2 週）。
- 你有三種應對方式：
  - **品質戰**：做出至少一件精良品質商品，讓顧客自己選擇（無需檢定，品質說話）
  - **交涉戰**：主動拜訪柯林（交涉 難度（DC） 14），了解他為什麼這麼做
  - **差異化**：推出柯林沒有的商品（靈感 難度（DC） 12，用夥伴的職業開發新產品線）

### 第 3-4 回合：街坊評選

鎮長舉辦「年度最佳小店」評選。你可以參賽。評選標準：品質 + 聲望 + 街坊推薦。

- 提交一件作品（品質決定基礎分數）
- 顧客推薦信：你擁有多少回頭客？（每位 +1 分）
- 柯林也參賽了。他的作品是穩定的普通品質。但你有機會做出精良——甚至卓越。

### 第 5 回合：和解或決裂

若你交涉成功：柯林承認他是在害怕。他提議合作——你的高品質商品進入他的通路，他的穩定客流為你引流。雙贏。

若你擊敗他：柯林的店在評選後關門了。你可以選擇收購他的店面和庫存。但也可能選擇不——因為你不缺這間店。你只需要自己那間。

## 獎勵

| 達成 | 獎勵 |
|------|------|
| 評選獲勝 | 聲望 +2d4，客流永久 +1 |
| 與柯林和解 | 解鎖「合作夥伴」：雜貨舖為你分銷普通品質商品（每週被動收入 10G） |
| 推出新產品線 | 獲得一個進階配方（由夥伴的職業決定） |
