# SCP: CONTAINMENT PROTOCOL — 單人規則補充 v1.0

**引用基準**：SCP: CONTAINMENT PROTOCOL 規則書 v1.2
**適用場景**：一名玩家（PC）+ 一名主持人（GM）的雙人遊戲
**設計目標**：保留原規則核心體驗，調整多人依賴機制，新增 NPC 夥伴系統

---

## 一、NPC 夥伴系統（Sidekick System）

單人玩家無法覆蓋戰鬥、調查、技術三條路線。本系統提供 **1–2 名簡化 NPC 夥伴**，由 GM 扮演但玩家可在戰鬥中下達指令。

### 1.1 夥伴建立（30 秒）

使用以下精簡模板，不建立完整角色卡：

```
名稱：__________  身份：__________  等級：與 PC 相同
HP：END + 職業加值 + 每級HP × (等級−1) [用公式自動算]
核心技能：2 項（值 = 40 + 等級×3）
弱項：1 項（值 = 20）
資源池：固定 2 點（不隨等級增長）
裝備：按身份初始配發
```

### 1.2 夥伴行動規則

- **戰鬥中**：玩家每回合可用一個快速動作對一名夥伴下達指令（「攻擊那個目標」「治療我」「使用設備」）。夥伴在自己的先攻輪次執行動作
- **非戰鬥中**：夥伴可執行其核心技能檢定（由玩家提議，GM 裁決）
- **SAN/SP**：夥伴無 SAN/SP 系統——他們不是恐怖的主體。但目睹夥伴死亡/轉化的 PC 仍需正常 SAN 檢定
- **瀕死**：夥伴 HP=0 → 立即倒地，穩定需 3 輪內接受急救（d100 ≤ 醫學），否則死亡
- **永久損失**：夥伴死亡後不可復活。新的夥伴需在站點通過「招募」獲取（見 §1.4）

### 1.3 推薦夥伴組合

| PC 身份 | 推薦夥伴 A | 推薦夥伴 B | 覆蓋缺口 |
|---------|-----------|-----------|---------|
| MTF特遣隊員 | 研究員（異常學+密碼學） | 醫療專員（戰地分診） | 知識+治療 |
| 外勤特工 | MTF（槍械+近戰） | 技術專家（工程+計算機） | 戰鬥+技術 |
| 研究員 | 安保特工（近戰+偵察） | 醫療專員（治療） | 戰鬥+保護 |
| D級人員 | 外勤特工（潛行+欺騙） | 技術專家（廢品修復） | 滲透+工具 |
| 技術專家 | 安保特工（保護） | 外勤特工（偵察） | 安全+情報 |
| 醫療專員 | MTF（火力） | 研究員（分析） | 戰鬥+知識 |
| 安保特工 | 研究員（弱點發現） | 醫療專員（急救） | 知識+治療 |

### 1.4 夥伴招募與更換

回到站點後，PC 可進行一次 `d100 ≤ PRE + 領導` 檢定（標準難度 ±0）：
- 成功 → 獲得一名新夥伴（從站點現有人員中挑選）
- 失敗 → 等待下一任務後重試
- 災厄(00) → 站點主管拒絕——「你上次帶出去的人沒回來」

## 二、遭遇難度調整

### 2.1 敵人數量縮放

原劇本中敵方數量按以下公式調整：

| 原設計（4 人） | 單人模式 | 說明 |
|---------------|---------|------|
| 1 菁英敵人 | 1（屬性 −10，HP −20%） | 讓步但不弱化到無威脅 |
| 2–3 標準敵人 | 1（不變） | 夥伴可處理另一目標 |
| 4+ 雜兵 | 1–2（不變）+ 分批出現 | 不會被淹沒 |
| Boss | 屬性 −5，HP −30%，但保留全部特殊能力 | 可擊敗但仍有壓力 |

### 2.2 SCP 難度調整

- **Safe 級**：不調整。單人 + 1 夥伴應可處理
- **Euclid 級**：認知危害 SAN 傷害 −1 級（重度→中度）；物理 SCP 的 HP −20%
- **Keter 級**：收容成功點需求從 4 降至 3；GM 提供更多環境利用選項
- **不可戰勝 SCP**：不調整難度——這類型的核心是生存和收容而非戰鬥

### 2.3 獎勵調整

單人模式下所有 CR/SA/XP 報酬 ×**1.5**（因風險集中）。PC 不可分割。

## 三、規則修改

### 3.1 行動經濟

原規則（§3.1）：`1 標準 + 1 移動 + 1 快速 + 1 反應`

單人模式：PC 保留原行動配額。每個夥伴在自己的回合中獲得 `1 標準 + 1 移動`（無快速、無反應）。非戰鬥場景中夥伴無行動配額限制——他們是合理協助者。

### 3.2 小隊指令（§3.5 修改）

原規則要求「擁有指揮權者使用標準動作發布指令」。單人模式中：

- PC 可使用**快速動作**對一名夥伴下達單一指令（「射擊那個」「治療我」「啟動設備」）
- 夥伴在下一輪開始時執行
- 無需指揮權——PC 即為隊長
- 原小隊指令中僅保留「集火」和「撤退」，其餘不適用

### 3.3 協助規則（§1.4 修改）

原規則：輔助者成功投 d100 ≤ 己方 TN → 主動者 +10 TN（最多 +20）。

單人模式：
- 夥伴核心技能可提供協助（+10 TN）
- 夥伴弱項不可協助
- GM 可扮演夥伴提供情報——但 GM 不應替玩家做決定

### 3.4 士氣系統（§3.5 修改）

原規則：恐慌擴散基於小隊存在。

單人模式：
- 移除「恐慌擴散」（因無小隊可擴散）
- **士氣值 = 40 + PC 的 WIL/2**（不再使用隊長值，PC 即為參照點）
- 夥伴的士氣獨立計算（使用 NPC 士氣預設：平民 30 / 安保 45 / MTF 55）
- 夥伴恐慌時 → PC 目睹隊友崩潰（SAN −1d4）

### 3.5 SAN/SP 恢復（§1.5 修改）

原規則有多項依賴隊友的恢復方式。

單人模式修改：

| 原規則 | 單人修改 |
|--------|---------|
| 隊友「安撫」（PRE+領導）−2d4 SP | 夥伴可安撫 PC（使用自己的 PRE/2 作為 TN，成功 −1d4 SP） |
| 心理諮詢 −1d6 SAN/次 | 保留，PC 有優先預約權 |
| 完成重大收容任務 −1d8 SAN | **單人加成**：−2d6 SAN（獨自承擔全部風險的回報） |

**新增：站點內獨處恢復**
PC 在站點安全區域獨處 1 小時（閱讀、整理裝備、寫報告）→ SP −1d4。每任務限 1 次。

## 四、GM 指南補充

### 4.1 節奏控制

單人遊戲的節奏比小隊遊戲快 2–3 倍——沒有玩家間討論、意見分歧、策略會議。GM 應：

- 減少冗長描述，快速進入決策點
- 每場景準備 3–5 個直接選擇（而非開放式探索）
- 利用夥伴提供提示（「長官，我注意到走廊左側有異常讀數」）
- 每次擲骰後立即推進劇情——不要等待

### 4.2 張力管理

單人遊戲的恐怖感更集中——因為沒有隊友分擔。GM 應：

- 保持 SAN/SP 追蹤可見（讓玩家看到壓力累積）
- 在 PC 獨處時放大環境細節（腳步聲、通風管異響、燈光閃爍）
- 夥伴的存在不能削弱恐怖——他們同樣脆弱，同樣會死
- 關鍵抉擇時，夥伴不應給出「正確答案」——他們的建議可能互相矛盾

### 4.3 「獨狼」特質（可選規則）

創建角色時，PC 可選擇獲得**「獨狼」特質**：

```
獨狼：你在沒有隊友的情況下行動時獲得以下效果：
· 單人行動時，所有檢定獲得 ADV（d100 取低）
· 夥伴倒下時，你獲得「腎上腺素」狀態——下 2 輪攻擊 ADV + 傷害 +1 骰
· 代價：與部門的關係值 −2（你是個難以共事的人）
· 代價：SAN 恢復量減半（你不擅長接受幫助）
```

## 五、快速啟動

### 5.1 建立單人角色

1. 按原規則 §2.1–§2.8 創建標準 PC
2. 選擇 1–2 名夥伴（見 §1.3 推薦組合）
3. 使用夥伴簡化模板填寫（30 秒/名）
4. 選擇是否擁有「獨狼」特質

### 5.2 選擇劇本

原四套戰役劇本中，以下場景已適配單人模式（見單人劇本補充）：

- **推薦起手**：「孤狼協議」——專為單人設計的 3 場景入門模組
- B 系列「深紅檔案」最適合單人調查玩法
- A 系列「破曉協議」場景 A-1、A-2 已適配
- D 系列「代價」中 D 級 PC 路線天然適合單人
