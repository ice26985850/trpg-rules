# 第一章：核心規則

## 1.1 骰子系統

### 核心公式

本遊戲使用 **d100 Roll-Under** 系統。所有檢定遵循統一公式：

```
d100 ≤ 目標值 (TN) → 成功
成功率 = TN%
```

**目標值構成**：
```
TN = 基礎屬性值 + 技能值 + 難度修正 ± 情境調整
```

TN 範圍固定在 1–99。出目 01 = 必定成功（暴擊），出目 00 = 必定失敗（災厄）。

### 成功度體系

| 出目範圍 | 成功度 | 效果 |
|---------|--------|------|
| 01 | 傳奇成功 | 自動成功 + 額外收益（雙倍傷害/關鍵情報/完美完成） |
| 02 – TN×0.2 | 卓越成功 | 高質量完成，附帶額外效果或信息 |
| TN×0.2+1 – TN×0.5 | 堅實成功 | 標準成功，完全達成目標 |
| TN×0.5+1 – TN | 普通成功 | 勉強完成，可能附帶小代價 |
| TN+1 – 99 | 失敗 | 未達成目標 |
| 00 | 災厄失敗 | 自動失敗 + 嚴重負面後果 |

**示例**（TN = 60）：
- 出目 01 → 傳奇 / 02–12 → 卓越 / 13–30 → 堅實 / 31–60 → 普通 / 61–99 → 失敗 / 00 → 災厄

### 優勢/劣勢

| 狀態 | 規則 | 等效影響 |
|------|------|---------|
| 優勢 (ADV) | 投 2 組 d10 組成 d100，取最有利結果 | +16% 等效成功率 |
| 劣勢 (DIS) | 投 2 組 d10 組成 d100，取最不利結果 | -16% 等效成功率 |
| 雙重優勢 | 投 3 組，取最優 | +23% |
| 雙重劣勢 | 投 3 組，取最劣 | -23% |
| 優勢+劣勢 | 互相抵消，正常單骰 | — |

## 1.2 屬性體系

### 七大屬性

#### 身體維度

| 屬性 | 縮寫 | 設計意圖 |
|------|------|---------|
| **力量** (Strength) | STR | 肌肉出力、近戰傷害、負重、破門撬鎖 |

| **耐力** (Endurance) | END | 身體韌性、HP 基礎、毒素抵抗、持久行動 |

#### 心智維度

| 屬性 | 縮寫 | 設計意圖 |
|------|------|---------|
| **智力** (Intellect) | INT | 邏輯推理、知識檢索、技術操作、科研分析 |
| **感知** (Perception) | PER | 環境觀察、威脅察覺、讀人、搜索、識破僞裝 |
| **意志** (Willpower) | WIL | 心理韌性、SAN 基礎、抵抗認知危害、克服恐懼 |

#### 社交維度

| 屬性 | 縮寫 | 設計意圖 |
|------|------|---------|
| **氣場** (Presence) | PRE | 說服力、威懾力、領導力、欺騙、安撫、表演 |

### 數值體系

- **範圍**：10–65（人類基準，後期可突破至 80）
- **購點總額**：190 點（自由分配至 7 屬性，單項最低 10，最高 65）
- **標準數組**（快速創建）：STR 50 / AGI 44 / END 38 / INT 32 / PER 26 / WIL 20 / PRE 14
- **備選數組**：55, 50, 45, 40, 35, 30, 25（分配至 7 屬性）
- **隨機檔案**：7×(3d10×2+10)，範圍 16–70，均值 ~43

### 屬性等級語義

| 屬性值 | 等級 | 敘事含義 |
|--------|------|---------|
| 10–15 | 脆弱 | 明顯的弱點 |
| 16–25 | 低於平均 | 未經訓練的弱項 |
| 26–35 | 平均 | 普通成年人水平 |
| 36–45 | 高於平均 | 有訓練或天賦 |
| 46–55 | 優秀 | 基金會專業標準 |
| 56–65 | 卓越 | 領域頂尖——MTF 精銳、首席研究員 |
| 66–80 | 傳奇 | 人類極限——O5 直屬特工 |

### 派生屬性

| 派生屬性 | 公式 | 說明 |
|---------|------|------|
| **生命值 (HP)** | END + 職業HP加值 + 等級成長 | 見第二章職業表。HP = 0 進入瀕死 |
| **理智值 (SAN)** | 50 + WIL（上限 99） | 長期心智穩定度。SAN ≤ 0 = 永久瘋狂 |
| **壓力值 (SP)** | 起始 0，上限 100 | 短期心理應激累積。SP ≥ SAN 觸發崩潰 |
| **先攻 (INIT)** | AGI + PER（可選職業微調） | 決定戰鬥行動順序 |
| **速度 (MOV)** | (STR + AGI) / 2 米/移動動作 | 每移動動作的基礎移動距離 |
| **負重** | STR × 2 kg | 舒適負重上限 |

## 1.4 檢定規則

### 標準檢定流程

1. GM 確定目標屬性 + 技能（或裸屬性）
2. GM 設定難度修正（默認 ±0）
3. 玩家計算 TN = 屬性值 + 技能值 + 難度修正 ± 情境調整
4. 玩家投 d100
5. 比較骰值與 TN，判定成功度
6. GM 根據成功度描述結果

### 難度修正表

| 難度 | TN 修正 | 描述 | 示例 |
|------|---------|------|------|
| 極簡 | +60 | 幾乎不可能失敗 | 日常工作使用專業技能 |
| 簡單 | +30 | 明顯容易 | 在照明良好的房間找東西 |
| 較易 | +10 | 略有優勢 | 用撬棍撬舊木門 |
| **標準** | ±0 | 需要專業訓練 | 黑入標準安保網絡 |
| 挑戰 | -20 | 有顯著壓力 | 交火中做緊急急救 |
| 困難 | -40 | 高壓力/高複雜度 | 認知危害影響下破解異常代碼 |
| 極難 | -60 | 接近人類極限 | 單人 30 秒內穩定 Keter 收容失效 |
| 傳奇 | -80 | 幾乎不可能 | 用言語說服已啓動的異常停下 |

### 成功概率參考

假設專業特工（屬性 40 + 技能 35 = 基礎 TN 75）：

| 難度 | TN 修正 | 最終 TN | 成功率 |
|------|---------|---------|--------|
| 簡單 | +30 | 99 | 99% |
| 較易 | +10 | 85 | 85% |
| **標準** | ±0 | **75** | **75%** |
| 挑戰 | -20 | 55 | 55% |
| 困難 | -40 | 35 | 35% |
| 極難 | -60 | 15 | 15% |

### 對抗檢定

當兩角色行動直接衝突時：雙方各自投 d100 ≤ 己方 TN，比較成功度。

- 都成功 → 成功度更高者獲勝
- 一方成功一方失敗 → 成功方獲勝
- 都失敗 → 平局/無進展

### 協助與團隊

**協助**：輔助者成功投 d100 ≤ 己方 TN → 主動者 +10 TN（最多疊加 2 人，即 +20）。

**團隊技能挑戰**：至少半數成員成功 → 團隊成功。

**擴展對抗（技能挑戰）**：累積 N 次成功（通常 3–5 次），允許 M 次失敗（通常 2–3 次）。

## 1.5 理智與壓力雙軌系統

> *"SAN 是你還能撐多久。SP 是你現在有多怕。"*

### SAN（理智值）

```
SAN 最大值 = 50 + WIL
起始 SAN = 最大值（滿狀態開始）
範圍：60（WIL=10）– 99（封頂）
```

SAN 檢定形式爲 `d100 ≤ 當前 SAN`。

#### SAN 傷害來源

| 來源 | SAN 傷害 | 示例 |
|------|---------|------|
| 輕度認知危害 | 1d4 | 看到低危異常圖像 |
| 中度認知危害 | 2d6 | 首次遭遇 Euclid 級 SCP |
| 重度認知危害 | 3d8 | 目睹 Keter 級突破收容 |
| 極端認知危害 | 4d10 | 直接暴露於模因實體 |
| 目睹隊友死亡（10m 內） | 1d6 | — |
| 目睹隊友被異常轉化 | 2d6 | — |
| 被迫犧牲他人 | 1d4 | 累積效應 |
| 長期壓力 | 每週 1d4 | 持續收容失效環境 |

#### SAN 閾值與狀態

| SAN 剩餘 | 狀態 | 效果 |
|----------|------|------|
| 100%–76% | 穩定 | 正常運作 |
| 75%–51% | 不安 | 壓力檢定 DIS；細微幻覺/偏執 |
| 50%–26% | 動搖 | SP 每輪 +1；無法獲得 WIL 檢定 ADV |
| 25%–1% | 崩潰邊緣 | 所有檢定 DIS；可能對隊友產生敵意 |
| ≤ 0 | 永久瘋狂 | 角色轉爲 NPC |

#### SAN 恢復

| 方式 | 恢復量 | 條件 |
|------|--------|------|
| 安全休息（站點內） | 1d4/天 | 無威脅環境 |
| 心理諮詢 | 1d6/次 | 每週最多 1 次 |
| 記憶刪除（B 級） | 2d6 | 清除創傷記憶。投 d100 ≤ INT：成功則不丟失經驗，失敗則隨機一項技能 -1d10 |
| 完成重大收容任務 | 1d8 | GM 酌情 |
| 模因抗性藥物 | 1d4 | 每週限 1 次，過量有副作用（連續使用 → d100 ≤ END 否則永久 INT -1d3） |

#### 記憶刪除分級規則

| 等級 | SAN 恢復 | 副作用 | 檢定 | 使用場景 |
|------|---------|--------|------|---------|
| **A 級**（短期） | 無恢復（僅 SP 清零） | 丟失當次任務記憶細節；下次任務開始時相關技能 -5 | 自動生效 | 標準任務後處理 |
| **B 級**（長期） | 2d6 SAN | d100 ≤ INT 成功無損失，失敗隨機技能 -1d10；丟失整次任務記憶 | 需 CL.3+ 授權 | 創傷事件後 |
| **C 級**（人格重建） | 3d6 SAN | 所有技能 -2d10；永久丟失 1d3 項技能（降至 0）；人格可能改變 | 需倫理委員會批准 | 模因感染/終極方案 |

### SP（壓力值）

```
SP 起始 = 0，上限 = 100

SP 自動增長觸發：
· 戰鬥中每輪 +1
· 被火力壓制 +1d4
· 目睹認知危害 +1d6
· 隊友恐慌 +1d4
· 遭受重傷 +2
· 獨自處於完全黑暗中 +1d4/輪
· 得知模因/信息危害 +1d6
```

#### 崩潰檢定

當 **SP ≥ SAN** 時觸發崩潰檢定：
`d100 ≤ SAN - SP`

- 成功 → SP 減半，獲得"緊張"狀態 1 輪
- 失敗 → 從崩潰表中投 d100 確定表現

#### 崩潰表（d100）

| d100 | 表現 | 持續 |
|------|------|------|
| 01–15 | **僵直**：無法行動/言語 | 1d4 輪 |
| 16–30 | **逃跑**：全力遠離威脅 | 1d6 輪 |
| 31–45 | **戰鬥狂暴**：隨機攻擊最近目標（50%友方） | 1d4 輪 |
| 46–60 | **尖叫/暴露**：暴露位置 | 1 輪 |
| 61–70 | **幻覺**：GM 提供虛假情報 | 1d6 輪 |
| 71–80 | **失語**：無法言語/理解語言 | 1d4 小時 |
| 81–90 | **失憶**：忘記最近 1d6 小時 | 1d4 小時 |
| 91–95 | **人格片段替換**：被隨機人格覆蓋 | 1d6 天 |
| 96–99 | **暴力精神病**：無差別暴力 | 1d6 小時 |
| 00 | **心因性死亡**：心臟驟停 | 永久 |

#### SP 緩解

| 方式 | SP 減少 | 條件 |
|------|---------|------|
| 一回合不做動作 | -1d4 | 無直接威脅 |
| 隊友"安撫"（PRE+領導檢定） | -2d4 | 消耗標準動作 |
| 離開直接威脅區域 | -1d6/輪 | 至 SP = SAN/2 |
| 任務後休息（安全環境8小時） | 降至 0 | 完全重置 |

- **Lv.5 代價**：SAN 上限永久 -30
- **緊急越級（42-所羅門協議）**：臨時 +2 CL/場景；代價 SAN-1d3+事後 O5 聽證

## 2.1 角色創建流程（9 步）

1. **概念**：你的角色在基金會中的定位是什麼？爲什麼加入？
2. **選擇身份**：從七大身份中選擇（見 §2.2）

4. **選擇類人分類**（見 §2.3）
5. **分配技能點**：按職業模板獲得技能點（見 §2.4）
6. **計算派生屬性**：HP、SAN、INIT、MOV
7. **選擇子職業**（Lv.3 時生效）
8. **裝備初始配發**：按許可等級獲取裝備
9. **填寫背景與部門關係**：GM 審覈

### 經驗值表

| 10 | 23,000 | 5,000 | 巔峯能力 |

**升級速度**（參考：每任務約 1,000–2,000 XP）：
- Lv.1→5：約 4–6 場遊戲（快節奏成長）
- Lv.5→8：約 6–8 場遊戲（中期穩固）
- Lv.8→10：約 5–7 場遊戲（終局衝刺）
- 完整 1→10 戰役：約 15–21 場遊戲

### XP 來源

- **任務完成**：見任務報酬表（含 XP 基礎值）
- **額外 SCP 收容**：每額外收容一個 SCP +300–600 XP
- **角色發展**：重大個人抉擇/犧牲 +300–800 XP
- **站點貢獻**：組織管理成就 +200–500 XP
- **優秀任務報告**：+200 XP（寫報告的角色限定）

### 兼職規則

角色可在升級時選擇獲得另一身份的 1 級能力，而非當前等級的提升。需滿足：

1. **屬性要求**：滿足目標身份的核心屬性 ≥ 40
2. **敘事合理**：有合理的劇情原因（如：研究員經歷了多次外勤任務後接受戰鬥訓練）
3. **資源池獨立**：每個身份的資源池分別追蹤，不可混用
4. **HP 成長**：採用所有身份中最高每級 HP 成長值
5. **限制**：最多兼職 1 個額外身份（即最多 2 個身份）。子職業不能兼得——只能從一個身份獲得子職業

**許可等級在兼職中取最高值。**

### 許可等級晉升（獨立於經驗）

許可等級不隨角色等級自動提升。需要：
1. 角色等級達標（Lv.4→可升 CL.3 / Lv.8→可升 CL.4 / Lv.10→可升 CL.5）
2. 站點安全度 ≥ 40
3. O5 關注度 ≤ 6
4. 無嚴重部門敵對
5. 完成"許可升級評估任務"（GM 定製）

1. 根據任務報酬表發放 CR、SA、PC、XP
2. SA 自動存入角色檔案（基金會標準：《安全資產追蹤表》Form-SEC-447）
3. PC 不可交易或轉移，僅限個人使用
4. CR 可用於購買標準裝備（見價格表）、黑市交易（2× 價格）、或作爲站點預算捐獻（每 500 CR = 站點資源 +5）

- SA 代表你在基金會安保體系中的"信任額度"
- 兌換限制級裝備從 SA 池扣除（不退還）

**PC 使用規則**：

- 消耗 2 PC → 要求一次倫理委員會聽證（可推翻一項部門決策）
- 消耗 3 PC → 請求 O5 級別的信息解密（CL+2 的臨時查閱權，單次）
- 消耗 5 PC → 申請異常物品試用許可（綠色/黃色級，單任務）
- PC 永遠不會自動減少——只會因使用而消耗或因醜聞被 O5 撤銷

## 2.8 D 級人員「死裏逃生」機制

> *"D 級人員的平均預期壽命是 30 天。但有些人——極少數人——就是死不了。"*

### 觸發與檢定

| 觸發事件 | 檢定 |
|---------|------|
| HP 降至 0（瀕死） | d100 ≤ WIL + LP×5 |
| 被異常直接攻擊 | d100 ≤ AGI |
| 處於必死場景中（GM 裁定） | d100 ≤ (STR+AGI+END+WIL)/4 |

### 成功效果

| 成功度 | 效果 |
|--------|------|
| **傳奇**（出目=01） | 逃脫死亡 + 獲得優勢 |
| **卓越** | 完全規避 + 發現逃生路徑 |
| **堅實** | 規避死亡，降爲重傷（25% HP） |
| **普通** | 規避死亡，重傷 + 失去下回合 + 物品損毀 |
| **失敗** | 進入正常瀕死流程（但 D 級瀕死豁免 ADV） |

### 「九條命」追蹤

- 隱藏計數器起始 1d3（玩家不可知）
- 每次死裏逃生成功 → -1
- 歸零 → 解鎖「傳奇 D 級」標記（O5 關注 +2、月末結算自動成功 ×1）
- 歸零後計數器重置爲 1d3（GM 暗擲），繼續追蹤——傳奇可以多次觸發
- 第三次觸發傳奇標記時 → D 級 PC 獲得「O5 特別關注」狀態：可能被招募爲特殊特工，或被視爲需要研究的潛在異常（GM 根據劇情走向決定）

### 月末結算

```
d100 ≤ WIL + (存活月數×2) + (貢獻任務成功次數×3)

傳奇/卓越 → 豁免立即生效，轉爲 C 級人員
堅實 → 下月 +10 TN 累計
普通 → 無變化
災厄(00) → 轉至更高風險崗位，下月 TN -20
```

## 3.1 行動經濟

### 回合結構

每輪 ≈ 6 秒遊戲時間。

```
1. 先攻階段 → 投先攻（AGI+PER），降序排列
2. 行動階段 → 每角色按先攻順序執行行動
3. 結束階段 → 持續效果計時、士氣傳播、環境結算
```

### 行動配額

| 行動類型 | 每輪數量 | 說明 |
|---------|---------|------|
| 標準動作 | 1 | 攻擊、使用能力、急救、收容設備 |
| 移動動作 | 1 | 移動 MOV 米、起身、換彈、切換武器 |
| 快速動作 | 1 | 瞄準、標記目標、小隊通訊、注射器 |
| 反應 | 1 | 藉機攻擊、掩護射擊、緊急閃避 |

|------|------|------|
| **瞄準** | 快速 | 本回合下一次遠程 ADV |

| **火力壓制** | 標準 | 錐形區域壓制（見 §3.3） |
| **衝刺** | 標準+移動 | MOV×3，本回合不能攻擊 |
| **急救** | 標準 | 穩定瀕死/臨時止血（見 §3.5） |
| **收容操作** | 標準 | 激活斯克蘭頓錨等 |
| **評估異常** | 標準 | d100 ≤ INT+異常學，獲取弱點信息 |
| **撤退** | 標準 | 本回合移動不觸發藉機 |

## 3.2 攻擊與迴避（d100 對抗體系）

### 攻擊流程

```
攻擊者投 d100 ≤ 攻擊技能值（AGI + 武器技能值）
防禦者投 d100 ≤ AGI + 迴避技能值（總迴避值）

結果判定：
┌────────────┬─────────────────┬─────────────────┐
│            │ 防禦者成功(≤AGI+迴避) │ 防禦者失敗(>AGI+迴避) │
├────────────┼─────────────────┼─────────────────┤
│ 攻擊者成功 │ 比較成功度，      │ 攻擊命中 ✓      │
│ (≤攻擊技能)│ 更高者勝         │                 │
├────────────┼─────────────────┼─────────────────┤
│ 攻擊者失敗 │ 攻擊未命中 ✗     │ 流彈/環境破壞   │
│ (>攻擊技能)│                 │                 │
└────────────┴─────────────────┴─────────────────┘
```

### 成功度傷害加成

攻擊成功時，成功度直接影響傷害：

| 攻擊成功度 | 傷害調整 |
|-----------|---------|
| 傳奇成功（出目 01） | 傷害 ×2（取最大值） |
| 卓越成功（≤ TN/5） | 傷害 +1 骰（如 1d10 → 2d10） |
| 堅實成功（≤ TN/2） | 傷害 +2 |
| 普通成功（≤ TN） | 標準傷害 |
| 失敗 | 無傷害 |

**設計意圖**：高技能不僅提高命中率，也提高傷害輸出。專家用同樣的武器打出更高的有效傷害（命中要害、掌握時機）。這縮短了同級對抗的 TTK——專家對專家的戰鬥不再是 25 輪的消耗戰。

### 重擊

攻擊出目 ≤ 攻擊技能值的 1/10，且防禦者回避失敗 → 觸發部位特殊效果，傷害按傳奇成功計算（×2）。

### 近戰攻擊

使用 **STR + 近戰技能值** 作爲攻擊技能值。若使用敏捷型近戰武器（如匕首、細劍），可用 AGI 替代 STR（需 GM 批准）。防禦者投 d100 ≤ AGI + 迴避技能值。

## 3.3 傷害體系

### HP 閾值與狀態

| HP 剩餘 | 狀態 | 效果 |
|---------|------|------|
| 100%–76% | 完好 | 無懲罰 |
| 75%–51% | 輕傷 | 僅敘事描述 |
| 50%–26% | 中等傷 | 所有行動檢定 TN -10 |
| 25%–1% | 重傷 | TN -20；每輪只能標準或移動二選一 |
| 0 | 瀕死 | 見 §3.4 |

### 身體部位傷害（三區制）

| 部位 | 觸發條件 | 傷害倍率 | 特殊效果 |
|------|---------|---------|---------|
| 頭部 | 出目 ≤ 5 或主動瞄準 | ×1.5 | d100 ≤ END 否則暈眩 1 輪 |
| 軀幹 | 默認 | ×1.0 | 無 |
| 四肢 | 出目 ≥ 96 或主動瞄準 | ×0.75 | 腿：MOV 減半；臂：攻擊 DIS |

**主動瞄準**：消耗標準動作指定部位，攻擊 TN -20。

### 傷害類型與抗性

| 類型 | 示例 | 抗性來源 |
|------|------|---------|
| 穿刺 | 槍彈、利爪 | 防彈護甲 |
| 切割 | 刀具、骨刃 | 切割防護 |
| 鈍擊 | 棍棒、衝擊波 | 緩衝護甲 |
| 熱力 | 燃燒、急凍 | 隔熱服 |
| 化學 | 腐蝕、神經毒劑 | 防化服 |
| 輻射 | 核廢料、放射性 SCP | 鉛襯 |
| **異常** | 現實扭曲、概念侵蝕 | 斯克蘭頓錨（極少） |

護甲提供 **傷害減免（DR）**：輕 1–2 / 中 3–4 / 重 5–6。異常傷害通常無視常規 DR。

**最低傷害規則**：DR 減免後傷害最低爲 1（除非目標有免疫）。即使護甲完全吸收攻擊的數值，每次命中至少造成 1 點擦傷/衝擊傷害。

## 3.4 重傷、瀕死與死亡

### 重傷表

單次傷害超過 **END 屬性值**（即單次受傷 > END 的數值）時觸發。若角色 END=38，則單次受到 ≥39 點傷害時觸發重傷檢定（d100）：

| d100 | 效果 |
|------|------|
| 01–25 | **震盪**：下回合失去所有動作 |
| 26–50 | **骨折**：相關肢體無法使用 |
| 51–75 | **內出血**：每輪 -1d4 HP |
| 76–90 | **器官損傷**：永久屬性 -5（需高級醫療恢復） |
| 91–00 | **瀕死**：立即進入瀕死狀態 |

### 瀕死規則

每輪投瀕死豁免：`d100 ≤ END`（裸骰無修正）

- 累計 3 次成功 → 穩定，HP 回升至 1，昏迷 1d4 小時
- 累計 3 次失敗 → 死亡
- 出目 01–05 → 立即恢復 1 HP 並清醒
- 出目 96–00 → 計爲 2 次失敗

### 治療

| 方式 | 動作 | 效果 | 限制 |
|------|------|------|------|
| 急救穩定 | 標準 | 穩定瀕死+停止內出血 | 需急救包，d100 ≤ 醫學 |
| 戰場包紮 | 標準 | 恢復 1d6 + (醫學/10) HP | 每角色每戰鬥限 1 次 |
| 注射急救針 | 快速 | 恢復 2d6 HP，無視重傷懲罰 1 輪 | 24h 內重複→d100 ≤ END 否則嘔吐 |
| 醫療站治療 | 1 小時 | 恢復 等級×d8 HP | 需醫療設施 |
| 手術 | 4–8 小時 | 移除重傷永久效果，完全恢復 | 需基金會醫療翼 |

## 3.5 戰術規則

### 掩體系統

| 掩體等級 | 效果 | 示例 |
|---------|------|------|
| 部分掩體 | 攻擊者 TN -10 | 翻倒桌子、灌木叢 |
| 半身掩體 | 攻擊者 TN -20 | 矮牆、汽車門 |
| 全身掩體 | 不可直接瞄準 | 混凝土牆後 |
| 強化掩體 | 全身+不可穿透 | 防爆盾、安全門 |

掩體需主動聲明（快速動作蹲伏/貼牆）。區域攻擊效果減半。

### 火力壓制

標準動作 + 彈藥消耗，對 15m 錐形區域：

- 區域內敵方投 `d100 ≤ WIL - 壓制修正（TN = 射手射擊技能值）`
- 失敗 → **壓制狀態**：必須找掩體，向壓制源移動減半，攻擊 DIS
- 成功 → 無效果
- 快速動作維持壓制持續至下回合
- 交叉火力：敵方 TN -15（更難抵抗）

### 小隊指令

擁有指揮權者使用標準動作發佈指令：

| 指令 | 效果 | 持續 |
|------|------|------|
| 集火 | 對被標記目標攻擊 ADV | 1 輪 |
| 散開 | 下一次區域攻擊傷害減半 | 至下回合 |
| 交替掩護 | 移動不觸發藉機+保留掩體 | 1 輪 |
| 壓制推進 | 移動+火力壓制自動掩護 | 1 輪 |
| 撤退 | MOV×2，撤退不消耗標準動作 | 1 輪 |

### 士氣與恐慌

**士氣值計算**：
```
小隊士氣值 = 40 + 隊長 WIL/2（向下取整）
NPC 士氣值 = 預設值（平民 30 / 安保 45 / MTF 55 / 精英 65）
```

**士氣檢定**（d100 ≤ 士氣值 - 情境修正）：

- 成功：正常
- 失敗（差 1–20）：**緊張**——25% 概率動作變全防禦
- 失敗（差 21+）：**恐慌**

**恐慌擴散**：恐慌者 10m 內友方回合結束時需進行士氣檢定。隊長可使用標準動作**鎮定指令**（d100 ≤ PRE+領導）抑制擴散。
