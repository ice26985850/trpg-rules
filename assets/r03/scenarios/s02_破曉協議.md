# 系列 A：破曉協議 (Breaching Protocol)

## 概述

| 維度 | 說明 |
|------|------|
| **定位** | 對標 D&D 戰術地下城風格——SCP 世界觀中的火力與戰術 |
| **玩法重心** | 戰術戰鬥、火力壓制、收容突擊、小隊協同 |
| **適合身份** | MTF特遣隊員（首選）、外勤特工、安保特工、醫療專員 |
| **等級覆蓋** | Lv.1–10（起點 Lv.1，終局 Lv.9–10） |
| **場景數量** | 6 個主要場景 + 1 個可選間章 |
| **核心衝突** | 混沌分裂者大規模滲透 Site-19，同步觸發多個 SCP 突破收容——這不是事故，是計劃好的攻擊 |
| **站點** | Site-19（全球最大站點，████個收容單元） |
| **戰役時長** | 預估 12–18 場遊戲（約 40–60 小時） |

### 戰役摘要

凌晨 03:47，Site-19 的 Hume 場監測陣列同時亮起 12 個紅色警報。三個 Safe 級 SCP 收容單元幾乎在同一秒失效，緊接着三個 Euclid 級出現異常讀數。這不是系統故障——是有人從內部控制了收容協議。

一支混沌分裂者滲透小隊，僞裝成基金會安保人員，已經在 Site-19 的走廊裏活動了至少 72 小時。他們的目標不是偷走某個 SCP——他們要讓這座站點從內部崩塌，以證明基金會的"收容"理念是失敗的。

而在地下的重型收容區，一個從未被公開記錄的 Keter 級 SCP 正在甦醒——因爲混沌分裂者切斷了它的斯克蘭頓錨。

玩家將扮演一支剛完成訓練的新建 MTF 小隊（代號"錘骨"），在 Site-19 的最長一夜中——戰鬥、抉擇、生存。

#### 場景流程

**階段 1 — 醒來與武裝（15 分鐘）**

GM 引導玩家描述角色在宿舍中被警報驚醒。每個玩家可做一個簡短的 RP 動作——抓起裝備、檢查通訊器、安撫（或緊張地忽略）宿舍中的其他人。

裝備配發：每位玩家從裝備櫃領取標準配發——手槍（1d8，15 發）、戰術背心（DR 2/2/1）、通訊器和急救包 ×1。MTF 額外領取突擊步槍（1d10，30 發）。

**階段 2 — 走廊推進（45 分鐘）**

小隊從宿舍區向主控室移動。穿過 D 級收容翼走廊時，他們遇到：

- **第一道障礙**：走廊防爆門已降下。工程檢定 d100 ≤ INT+工程 TN 50 手動越控；或計算機檢定 TN 55 繞過門控系統；或 STR 檢定 TN 60（三人協助）撬開。
- **環境**：走廊燈光以不規律的間隔閃爍。每 1d6 輪，全部熄滅 1 輪（完全黑暗：視覺動作自動失敗，除非有手電筒/夜視）。

**階段 3 — 遭遇 SCP-████-A "鐵處女"（60 分鐘）**

在通往主控室的 T 字路口，一具中世紀板甲封住了通道。它正在攻擊兩名試圖逃離的安保特工——其中之一已經重傷倒地。

**戰鬥參數速查**：
- SCP-████-A HP 55 / 穿刺 DR 5 / AGI 35
- 攻擊：d100 ≤ 55，傷害 1d10+2 切割
- 兩名 NPC 安保特工：HP 各 45/15（一重傷），手槍 d100 ≤ 60

**解決路徑**：

| 路徑 | 方法 | 關鍵檢定 |
|------|------|---------|
| **戰鬥** | 正面擊倒 SCP-████-A | 槍械 TN 75（MTF Lv.1：AGI 40 + 槍械 35），需約 6–8 次命中穿透 DR |
| **知識** | 識別口令 | 語言學 d100 ≤ INT+語言學 TN 60 → 發現銘文爲古法語；基金會史 d100 ≤ INT+基金會史 TN 55 → 回憶檔案中有口令記載；或直接嘗試猜測口令（PRE 檢定，TN 40，失敗 3 次引發暴怒） |
| **弱點** | 利用熱力弱點 | 工程 TN 55 製造臨時燃燒物（滅火器+打火機→熱力錐形）；或找到消防栓/熱力設備 |
| **潛行** | 繞過而非對抗 | 潛行 TN 60（盔甲 PER 25，但它有回聲定位般的振動感知——需要脫鞋或極慢速移動） |

**階段 4 — 抵達指揮中心（30 分鐘）**

進入主控室後，玩家見到哈洛主管（通過視頻——他在深層安全室）。他簡要說明情況：
- 三個 Safe 級 SCP 突破收容
- 三個 Euclid 級出現異常活動
- 主走廊的防爆門被"內部指令"鎖死——有人在使用安保代碼
- MTF Nu-7 正在響應，但他們的部署被幹擾了

哈洛指派"錘骨"小隊處理兩個目標：(1) 清理由 D 級區到醫療翼的走廊；(2) 尋找並護送倖存者。

**關鍵檢定參考（Lv.1 基準）**：
- MTF PC：槍械 TN ~75（AGI 40+槍械 35）、迴避 TN ~55（AGI 40+迴避 15）
- 外勤 PC：潛行 TN ~65（AGI 45+潛行 20）、偵察 TN ~60（PER 35+偵察 25）
- 安保 PC：偵察 TN ~65（PER 40+偵察 25）、近戰 TN ~60（STR 35+近戰 25）
- 醫療 PC：醫學 TN ~65（INT 40+醫學 25）

#### 可能結局

1. **高效通過**：玩家用非戰鬥方式處理鐵處女（口令/弱點），節省大量彈藥和 HP。哈洛印象 +1。

3. **瀕臨失敗**：鐵處女進入暴怒模式，小隊損失慘重。GM 可安排 MTF Nu-7 的先鋒小隊介入援救——但代價是小隊信譽受損。

**層 16 — 錨控制室（120 分鐘）**

**錨 A（已完全破壞）**：
- 需要完全更換核心組件

- 同時需要有人警戒（每 5 輪，CI 增援可能到達——d100 ≤ 40）

**錨 B（部分破壞）**：
- 控制面板被鎖定，帶有 CI 的反向協議
- 密碼學 TN 60 破解協議 → 然後工程 TN 50 重啓
- 如果密碼學失敗：嘗試暴力重啓（工程 TN 70，極難——失敗觸發反向協議，Hume 場 -20）

**錨 C（運轉中但失效中）**：
- 仍在運轉但輸出功率下降（Hume -5/10 分鐘）
- 可以"超載"錨 C（工程 TN 55）使其輸出翻倍 × 1d6 輪——風險是錨可能燒燬
- 或直接維護（工程 TN 45）保持當前輸出穩定

**Hume 場追蹤**：GM 應使用一個公開或隱藏的 Hume 計數器。起始 Hume = 65。

| Hume 降至 20 → ZK 場景 |

| MTF 槍械（重裝突破） | ~80 | AGI 44+槍械 36 |

| 密碼學（反向協議） | ~62 | INT 38+密碼學 24 |
| 計算機（電梯越控） | ~65 | INT 38+計算機 27 |
| 爆破（天花板定向） | ~60 | INT 36+爆破 24 |

#### 可能結局

1. **三個錨全部修復**：Hume 場穩定回升至 85+。SCP-████-C 回到休眠狀態。通往層 18 的大門可以安全開啓。
2. **兩個錨修復**：Hume 場穩定在 50–65。足夠防止立即崩潰，但終末低語已激活——所有進入層 18 的角色需持續應對認知危害。
3. **僅一個錨修復或全部失敗**：Hume 場降至 40 以下。終末低語全功率。場景 A-5 變爲"緊急撤離"而非"正面收容"。

#### 後續銜接

- 錨修復 ≥ 2 → 場景 A-5：正面面對 SCP-████-C + 凱爾
- 錨修復 < 2 → 場景 A-5 變爲"生存模式"——在完全崩潰前撤離並啓動 42-所羅門協議

### 場景 A-5：虛空之心

> **📍 地圖引用**：請參閱 `campaign_a_maps_zh.pdf` 第 6-7 頁（80m 球形收容艙俯視圖 + 斯克蘭頓錨陣列 + 突入路線）。

| 項目 | 內容 |
|------|------|
| **等級** | Lv.7–8 |
| **位置** | Site-19 深層——虛空之心收容單元（直徑 80m 的球形艙室） |
| **時長** | 2–3 場（約 8–12 小時） |

#### GM 簡報

這是戰役的高潮。玩家進入虛空之心的收容單元——一個巨大的球形艙室，黑色晶體懸浮在中央，周圍是複雜的斯克蘭頓錨陣列。凱爾和他的精英衛隊已經在此等候。

凱爾的計劃進入了最後階段：他不是要摧毀 SCP-████-C——他是要把它變成一把槍。通過將虛空之心的現實侵蝕聚焦成一道束流，他打算在 O5 議會召開緊急會議時擊中他們的位置。

#### 真相卡

| 層 | 內容 |
|----|------|
| **表層** | 凱爾在收容單元內。他有一個"相位聚焦器"——用 CI 從 SCP-████-B 研究中提取的技術改造的設備 |
| **裏層**（科學/異常學揭示） | SCP-████-C 不是純粹的破壞力。它是在——某種程度上——"消化"現實。被它消耗的現實不是消失，而是被轉化爲一種可被導向的能量。凱爾的聚焦器在理論上可行 |
| **深淵** | 水晶中有"東西"——不是一個意識，而是碎片化的多個意識的回聲。每一個都是被虛空之心吞沒的現實的最後痕跡。如果玩家嘗試與它溝通（見談判路徑），他們聽到的聲音是多重的、破碎的——但同時充滿了一種奇怪的、非惡意的特質。它只是……在進食。它不知道（或不關心）它的進食意味着什麼 |

#### 場景流程

**舞臺設定**

收容單元是一個巨大的球形空間，直徑約 80m。SCP-████-C 懸浮在中心，被三個斯克蘭頓錨包圍（其中至少兩個應該已被玩家修復）。多條金屬走道從牆壁延伸到中心平臺。走道沒有護欄——墜落 = 20m 掉落（3d6 鈍擊傷害 + 重傷檢定）。

**環境效果**（基於場景 A-4 的 Hume 場狀態）：
- Hume ≥ 50：所有物理檢定 DIS；每 5 輪 d100 ≤ SAN-10 否則 SAN -1d6
- Hume ≥ 30：上述 + 每 3 輪虛空裂隙自動生成 1 個虛空碎片
- Hume < 30：上述 + 每輪終末低語（d100 ≤ SAN-20，SAN -3d8）

**階段 1 — 對峙（30 分鐘）**

凱爾站在中心平臺上，身旁是他的精英衛隊（4 名 CI 精銳）。他手裏拿着一個遠程引爆器——他在三個斯克蘭頓錨上安裝了備用炸藥。

**凱爾的開場白**：
> *"你們終於到了。瓦斯奎茲呢？她沒來？真遺憾。我以爲她會想親眼看看——她的選擇帶來的後果。你知道她爲什麼離開 CI 嗎？不是因爲我們是錯的。而是因爲她無法面對我們是正確的事實。"*

瓦斯奎茲（如果還活着且在小隊中）的回應：
> *"我離開是因爲你開始享受它了，凱爾。異常不是武器——它們是囚犯。我們曾經都相信這一點。"*

**階段 2 — 多層戰鬥（90–120 分鐘）**

這個遭遇有三個同時進行的層面：

**層面 A：戰鬥（對抗 CI）**
- 凱爾（指揮官數據見 NPC 檔案）+ 4 名 CI 精銳（HP 55，槍械 TN 68，戰術背心 DR 3/2/2 帶陶瓷插板）
- 凱爾的戰術：保持距離，使用走道作爲機動空間，激活炸藥分散注意力
- 若凱爾 HP < 30% → 他激活相位聚焦器原型（給自己 3 輪 ADV 於迴避，但每輪 -1d6 HP）

**層面 B：收容（穩定水晶）**
- 三個錨上的炸藥需要被拆除（爆破 TN 60 每個，或工程 TN 55 物理移除）
- 虛空碎片持續生成——需要有人專門處理它們（"清小怪"角色）
- 可選：利用哈洛的實驗數據——如果玩家獲得了這些數據，他們可以嘗試"調諧"錨的頻率（異常學 TN 65），使水晶的 Hume 消耗速率降低一半

**層面 C：溝通（意外選項）**
- 如果玩家中的研究員/高 INT 角色嘗試研究而非攻擊水晶：異常學 TN 60 或科學 TN 65 → 發現水晶在特定頻率下有"回應模式"
- 通過調整斯克蘭頓錨的 Hume 輸出頻率（工程+異常學聯合檢定 TN 55），玩家可以嘗試與水晶中的意識碎片溝通
- 溝通不是對話——更像是接收碎片化的圖像和情緒。內容由 GM 即興發揮，但核心信息是：(1) 水晶不想傷害任何人，(2) 它甚至不真正理解"傷害"是什麼意思，(3) 它很孤獨，(4) 它想回家——回到它來的地方
- 如果玩家成功傳達"你必須停止消耗 Hume 場"的意圖：PRE+說服 TN 45（非語言溝通，難度降級）→ 水晶暫時降低消耗速率（Hume 消耗降爲每 30 分鐘 -5）

**階段 3 — 終局（30 分鐘）**

當凱爾的 HP 降至 0 或大部分 CI 精銳被擊敗時，觸發終局：

凱爾啓動了他最後的籌碼——相位聚焦器對準了虛空之心。他狂笑着說：

> *"如果我不能證明 CI 是對的——那我就證明基金會是錯的。你們保護的一切——都將看到真相。"*

聚焦器開始發射脈衝——每輪對水晶造成傷害（直接攻擊 HP），同時水晶的 Hume 消耗速率飆升（每輪 -10 Hume）。

**終局選擇**：

| 選擇 | 方法 | 代價 |
|------|------|------|
| **擊殺凱爾** | 集火攻擊（他此時無法迴避——專注維持聚焦器） | 他可能在死前完成聚焦——水晶 HP 降至 50% |
| **摧毀聚焦器** | 攻擊設備（HP 30，DR 5），或爆破 TN 55 過載 | 凱爾轉而全力攻擊玩家 |
| **救贖凱爾** | PRE+說服 TN 55（需要先讓瓦斯奎茲與他對話，喚起他曾有的信念） | 凱爾放下武器，但 CI 精銳可能不會 |
| **與水晶合作** | 如果玩家已建立溝通 → 水晶主動吸收聚焦器的能量束（Hume 消耗反而下降） | 水晶變得更"活躍"——未來可能成爲一個更復雜的實體 |
| **犧牲** | 一名角色手動超載斯克蘭頓錨，以自身 Hume 場頻率共振——角色 SAN 永久 -30 且獲得"現實敏感"標記 | 水晶立即休眠，所有異常效應停止 |

#### 關鍵檢定與 TN 參考（Lv.7–8 基準）

| 檢定 | TN | 說明 |
|------|-----|------|
| MTF 槍械（凱爾戰鬥） | ~82 | AGI 46+槍械 36 |

#### 可能結局

1. **完美收容**：水晶穩定 + 凱爾被俘獲/救贖 + 全部錨修復。O5 印象深刻。小隊獲得"Site-19 捍衛者"榮譽。
2. **代價收容**：水晶穩定但代價沉重——一名 PC 或關鍵 NPC 犧牲/永久受損。
3. **悲慘勝利**：水晶被摧毀（而非收容）。基金會失去了一個潛在的無價研究資源。O5 感到失望但承認這是必要的。
4. **撤退協議**：小隊無法穩定水晶，啓動緊急疏散。Site-19 被部分廢棄，SCP-████-C 被封印在坍塌的深層區域中——但這只是將問題推遲。

### 場景 A-6：代價清算

| 項目 | 內容 |
|------|------|
| **等級** | Lv.9–10 |
| **位置** | Site-19 會議室 → O5 虛擬聽證會 → 各角色結局 |
| **時長** | 1–2 場（約 4–6 小時） |

#### GM 簡報

事件結束。Site-19 的走廊還在冒煙，但收容已經恢復。現在——清算開始了。

O5 議會召開了一次閉門聽證會，審查事件的責任歸屬。哈洛的祕密實驗、瓦斯奎茲的 CI 背景、凱爾的供詞（如果他活着）、以及玩家的所有關鍵決策——都將被擺在桌面上。

這不是一場戰鬥。這是一場敘事審判——玩家的說服、證據呈現和道德立場將決定結局。

#### 場景流程

**階段 1 — 準備證詞（45 分鐘）**

玩家有時間回顧事件，決定他們要說什麼。每個關鍵決策都被記錄在案：

- 場景 A-1：是否用非戰鬥方式處理鐵處女（展現智慧 vs 純武力）
- 場景 A-2：是否救出拉什蒂、醫療翼人質
- 場景 A-3：是否信任瓦斯奎茲、是否發現哈洛的祕密
- 場景 A-4：Hume 場狀態、修復了多少錨
- 場景 A-5：凱爾的命運、水晶的命運、是否有角色犧牲

**階段 2 — O5 聽證會（60–90 分鐘）**

GM 扮演 O5 議會（通過視頻屏幕——O5 成員從不親自出現，只有聲音和輪廓）。聽證會按以下順序進行：

1. **哈洛作證**：他承認實驗，但辯解說是"爲了更好的收容"
2. **瓦斯奎茲作證**：她的 CI 背景被正式討論。O5-7 介入並解密"銅斑蛇行動"檔案（如果玩家之前未能做到）
3. **拉什蒂作證**：如果還活着，他作爲一個"外部視角"提供證詞——他的發言出人意料地有力
4. **玩家作證**：每個玩家可做一次陳述（PRE+說服或 PRE+領導檢定，TN 60）

**階段 3 — 裁決與結局（30 分鐘）**

O5 做出裁決。結果取決於：

| 因素 | 影響 |
|------|------|
| SCP-████-C 是否被成功收容 | 最大的加分項 |
| 凱爾是否被活捉 | +提供情報價值 |
| 哈洛的實驗是否被揭露 | 減分（基金會尷尬），但玩家揭露它 → 展現誠信 |
| 瓦斯奎茲是否被支持 | 影響 MTF Nu-7 的未來 |
| D 級人員的處理 | 拉什蒂的證詞質量影響 D 級改革討論 |
| 平民/低級人員傷亡 | 越低越好 |

#### 結局分支

**結局 A："新黎明"**
- 條件：水晶成功收容 + 凱爾被活捉 + 哈洛的責任被揭露 + 瓦斯奎茲清白被證明
- O5 將哈洛調離，任命瓦斯奎茲爲 Site-19 代理主管（或推薦一名改革派主管）
- 玩家獲得"O5 嘉獎令"——CL 晉升 + 1（上限 Lv.4）
- 拉什蒂被授予 C 級人員身份
- 後日談：Site-19 開始實施收容協議改革

**結局 B："穩定即勝利"**
- 條件：水晶被收容（任何方式），但存在灰色地帶
- O5 保持現狀——哈洛留任但被更嚴格監督，瓦斯奎茲繼續作爲 MTF 指揮官
- 玩家獲得標準嘉獎——XP +500，無 CL 晉升
- 後日談：一切回到正常……但"正常"在基金會意味着什麼？

**結局 C："燃燒的教訓"**
- 條件：水晶被摧毀或逃脫，重大損失
- O5 發起全面調查。哈洛被解職並可能被記憶刪除。瓦斯奎茲被暫停職務等待審查
- 玩家小隊被解散，成員被分配到不同站點——但每個人都被標記爲"不可完全信任"
- 後日談：一架直升機將玩家送出 Site-19。沒有人說話。在他們下方，重型收容區的廢墟上，施工隊已經開始工作

**結局 D（隱藏）："銅斑蛇的孩子們"**
- 條件：凱爾被救贖 + 水晶被溝通（而非強制收容）+ 瓦斯奎茲存活
- O5-7 私下聯繫玩家——你們展示了一種不同的收容方式。也許基金會需要更多"能與非人類實體溝通"的人
- 玩家被邀請加入一個全新的項目："SCP 溝通倡議"——一個實驗性的計劃，嘗試與有意識的 SCP 進行對話而非單純收容
- 瓦斯奎茲和（贖罪的）凱爾成爲該項目的顧問
- 後日談：一架黑色直升機降落在 Site-19 的直升機坪上。O5-7 的聲音從通訊器中傳出："來 Area-██。我們需要談談——關於未來。"

### 可選場景 A-X：鼠輩之路

| 項目 | 內容 |
|------|------|
| **等級** | Lv.3–5（分支場景） |
| **位置** | Site-19 D 級收容翼深處 → 廢棄維護隧道 → CI 後勤據點 |
| **時長** | 1 場（約 4 小時） |

#### GM 簡報

這個可選場景在場景 A-3 的分支選擇中出現——如果玩家選擇"通風系統 → CI 指揮中心"路線。它以拉什蒂（或別的 D 級 NPC）爲嚮導，帶領玩家穿越 Site-19 的"底層世界"——D 級人員祕密知曉的通道、廢棄區域和非官方捷徑。

這是一次潛行滲透場景，而非正面戰鬥。

#### 場景流程

**階段 1 — "鼠輩的走廊"（45 分鐘）**

拉什蒂帶領玩家進入 D 級收容翼深處的一套廢棄維護隧道。這些隧道不在官方地圖上——它們是在 1970 年代擴建時被遺忘的。

拉什蒂解釋：
> *"D 級們管這些叫'鼠道'。每個老站點都有。主管們不知道——或者不想知道。在這裏，你學到一件事：基金會是建在它自己的錯誤上的。每一層收容協議下面，都有一層它試圖忘記的東西。"*

**環境**：隧道黑暗、狹窄（單列通行，無法展開戰鬥隊形）、潮溼。牆壁上有前任 D 級人員刻下的標記——有些是計數（存活天數），有些是名字，還有一些是被時間模糊到無法辨認的信息。

**階段 2 — "幽靈"（60 分鐘）**

在隧道中，玩家發現了一個廢棄的小型收容單元。門上的標籤已經鏽蝕，但計算機檢定 TN 50（便攜終端掃描）發現它曾收容一個 Safe 級異常——SCP-████-D，已於 1983 年被重新分類爲"無效化"並移除。

但檔案中說"無效化"……單元裏卻有新的痕跡。最近有人在這裏待過。

**發現**：這是一名 CI 滲透者的藏身點。拉什蒂認出他的物品——是他在 CI 時期認識的一個聯繫人。這個人現在應該在 CI 後勤據點中。這提供了關鍵情報：CI 在隧道系統中有一個隱藏據點。

**階段 3 — CI 後勤據點滲透（90 分鐘）**

CI 在廢棄的 1970 年代維修車間建立了一個小型據點。這裏有三名 CI 後勤人員（非戰鬥精銳——HP 35，手槍 d100 ≤ 50）和大量裝備。

**目標**：
- 獲取 CI 的通訊日誌（計算機 TN 55）
- 找到 CI 在 Site-19 的完整人員名單（包含所有僞裝身份的對照表）
- 可選：偷取 CI 的相位穩定器原型（使 SCP-████-B 在場景 A-4 中更容易處理）

**解決路徑**：

| 路徑 | 方法 |
|------|------|
| **潛行** | 全體潛行 TN 60 滲透，獲取情報後無聲撤離 |
| **僞裝** | 拉什蒂假裝是 CI 信使（欺騙 TN 55），玩家藏在暗處支援 |
| **突襲** | 快速戰鬥——利用狹窄空間的優勢（CI 無法同時展開） |
| **技術** | 遠程黑入 CI 的便攜服務器（計算機 TN 65）而不進入據點 |

#### 後續銜接

- 成功滲透 → 獲得 CI 完整人員名單 → 在場景 A-4 中，玩家可以識別並繞過某些 CI 防禦（知道他們的換崗時間）
- 獲取相位穩定器 → 場景 A-4 中 SCP-████-B 恢復正常行爲模式（更容易）
