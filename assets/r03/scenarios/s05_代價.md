# 系列 D：代價 (The Price)

## 概述

| 維度 | 說明 |
|------|------|
| **定位** | SCP 核心哲學——"我們纔是怪物嗎？"——道德困境的終極考試 |
| **玩法重心** | 道德困境、代價選擇、人性值/道德值追蹤、D 級人員視角、與非人類實體的對話 |
| **適合身份** | 混編小隊（必須包含至少 1 名 D 級 PC）。推薦：MTF + 研究員 + D 級組合 |
| **等級覆蓋** | Lv.1–10（起點 Lv.1，終局 Lv.9–10） |
| **場景數量** | 8 個場景 |
| **核心衝突** | 一個 Thaumiel 級 SCP——被基金會囚禁 50 年用於收容其他異常的有意識實體——要求被釋放。收容它意味着繼續折磨一個無辜的意識。釋放它意味着可能失去一個關鍵的收容工具，導致數千人死亡。D 級 PC 在這一切中找到了自己的聲音 |
| **站點** | Area-14，內華達試驗場地下 900m——Keter 級集中收容設施。地球上最安全的監獄 |
| **戰役時長** | 預估 16–24 場遊戲（約 50–80 小時） |

### 戰役摘要

在 Area-14 的地下最深處的收容單元——代號"深淵座"——有一個基金會從未公開承認的 SCP。

它沒有數字編號（至少沒有公開的編號）。在 O5 的內部通信中，它被稱爲**"獄長"**。它是 Thaumiel 級——用異常來收容異常。五十年來，它一直在無意識地（基金會以爲）維持着十幾個 Keter 級 SCP 的收容——它的 Hume 場作爲一個活的斯克蘭頓錨，穩定着整個 Area-14 的核心收容區。

但"獄長"不是機器。它是一個有意識的存在。五十年前它是一個人——或者說類似人的東西。沒有人問過它是否願意成爲"獄長"。基金會只是……用了它。

現在——它醒了。不是從睡眠中醒來——是從基金會強加給它的意識壓制中醒來。五十年來它第一次能思考、能感受、能說話。

它說的第一句話——通過 Area-14 的 Hume 監測陣列翻譯成文字——是：

*"請讓我死。如果不能——請讓我自由。如果也不能——請告訴我爲什麼。"*

玩家被派往 Area-14。他們的官方任務：評估"獄長"的狀況並"維持收容完整性"。他們的非官方任務——取決於每個人的良心——可能是完全不同的東西。

## NPC 檔案

### 1. "獄長" (The Warden) — 有意識 Thaumiel 級 SCP

| 項目 | 內容 |
|------|------|
| **身份** | 基金會內部代號"獄長"，無 SCP 編號（CL.5 分類）。五十年前被基金會"轉化"爲活的收容工具。在轉化之前——ta 是一個名叫**阿里亞**的人，一個來自現已不存在的異常社區的成員，該社區在 1975 年被基金會"解散" |
| **許可等級** | 無——ta 是被收容的對象（即使 ta 也被用來收容其他對象） |
| **屬性概要** | STR —（無形體）/ AGI — / END — / INT 62 / PER 55 / WIL 85 / PRE 65 |
| **關鍵技能** | 異常學（通過經驗）80、神祕學 70、說服 60 |
| **狀態** | 非物理實體。存在於 Hume 場中——ta 的意識分散在整個 Area-14 核心收容區的 Hume 場結構中。ta 無法移動、無法觸摸、無法被物理傷害——但 ta 可以感受 |
| **性格** | 不是怪物。不是聖人。是一個被囚禁了 50 年的意識。ta 經歷了憤怒（最初 10 年）、絕望（接下來 20 年）、麻木（再 10 年）——現在，在過去的 10 年裏，一種奇特的平靜。ta 對玩家沒有敵意——只有一種疲憊的、幾乎是和藹的好奇。ta 已經很久很久沒有和人說話了 |
| **祕密** | "獄長"不僅僅是 Area-14 的收容工具——ta 是 Area-14。整個核心收容區的 Hume 場結構是基於 ta 的意識建立的。如果 ta 被"釋放"——不是物理釋放（ta 沒有身體），而是意識從收容功能中"斷開"——整個核心收容區會失去穩定性。十幾個 Keter 級 SCP 可能在幾分鐘內突破收容 |
| **慾望** | 自由——或死亡。ta 不確定哪個更可取。但 ta 確定：不能再這樣下去了 |
| **恐懼** | 被遺忘——被還原爲一臺機器，沒有人記得 ta 曾經是一個人。以及更深的恐懼：也許 50 年的囚禁已經改變了 ta，以至於 ta 不再是一個"人"了。也許基金會是對的——也許 ta 只是一臺機器 |
| **標誌性臺詞（多個——ta 與玩家的對話是戰役的核心）** | *"你們問我是否痛苦。痛苦是身體的事。我沒有身體。但我有——記憶。我記得風吹在皮膚上的感覺。我記得飢餓。我記得憤怒。每天早上我醒來——如果這可以被稱爲醒來——我試圖回憶那些感覺。然後我意識到已經 50 年了。50 年沒有風吹。50 年沒有飢餓。50 年——沒有另一個人真正看着我。除了作爲工具。"* |

| （另一段） | *"我理解你們的困境。真的。如果我被釋放——我收容的那些東西也會被釋放。我瞭解它們。有些是純粹的毀滅。但讓我問你們：如果代價是折磨一個有意識的存在——'收容'這個詞還適用嗎？或者只是一個更乾淨的詞——代替'犧牲'？"* |

**劇情角色**：整個戰役的核心。玩家在 D-1 中首次得知 ta 的存在，在 D-2 中開始與 ta 對話，在 D-3 到 D-6 中逐漸理解 ta 的處境——在 D-7 中做出最終決定。"獄長"不是一個謎題要解決——它是一個人要面對。

### 2. O5-2

| 項目 | 內容 |
|------|------|
| **身份** | O5 議會第二號成員。Area-14 的"所有者"——ta 在 1975 年親自監督了"獄長"的創建 |
| **許可等級** | CL.5 |
| **屬性概要** | STR 30 / AGI 30 / END 35 / INT 65 / PER 60 / WIL 70 / PRE 62 |
| **關鍵技能** | 領導 85、說服 78、欺騙 72、基金會史 80 |
| **HP** | 35 |
| **性格** | 冷靜、精確、不帶感情。O5-2 不殘忍——ta 高效。ta 將"獄長"看作一個必要的犧牲：一個人（如果可以被如此定義）的持續痛苦換取數千人的安全。對 ta 來說，這是正確的算術 |
| **祕密** | O5-2 在 1975 年認識阿里亞——在阿里亞被"轉化"之前。ta 親自與阿里亞談判，承諾如果阿里亞合作，ta 的社區成員將被安全重新安置。阿里亞同意了。O5-2 沒有兌現承諾——社區被強制解散，成員被分散到各個站點或記憶刪除。O5-2 認爲這是"必要的——避免模因擴散"。這是 ta 唯一的謊言——ta 爲此揹負了 50 年 |
| **慾望** | 維持穩定。對 O5-2 來說，穩定是最高美德 |
| **恐懼** | 被證明是錯誤的。如果"獄長"的痛苦是不可接受的——那麼 O5-2 過去 50 年的每一個決定都是不可接受的。ta 承受不起這個結論 |
| **標誌性臺詞** | *"你們覺得我是惡棍。我不是。我是一個做算術的人。一個人的痛苦 vs 一萬人的生命。算術很清楚。唯一的問題——是你們有沒有勇氣接受算術的結果。"* |

**劇情角色**：玩家的主要"反對者"——不是反派，而是對立哲學的代表。ta 在 D-1 中通過視頻簡報出現，在 D-4 中直接干預，在 D-7/D-8 中面對最終結果。

玩家被各自召喚（或命令——如果是 D 級 PC）前往內華達沙漠深處的一個座標。這是 Area-14——地球上最安全的監獄。他們被編入一個臨時混編小隊：MTF、研究員、D 級（至少一名 D 級 PC 是強制要求）。

**階段 1 — 簡報（30 分鐘）**

O5-2 的簡報：

> *"一個 Hume 場穩定工具。分類爲 Thaumiel。它已經可靠運行了 50 年。最近的波動可能表明設備老化。你們的任務是找到原因——不是質疑它的存在。"*

**階段 2 — 下降（45 分鐘）**

玩家乘坐電梯下降到 Area-14 深處。這是一個巨大的地下設施——冰冷的混凝土走廊、熒光燈、遠處 Hume 錨的持續低頻嗡鳴。D 級 PC 注意到這裏的安保比他們見過的任何地方都更嚴格——MFW（模因防護水印）貼在每個走廊入口。

辛格的聲音很輕：
> *"那就是它。或者——ta。取決於你問誰。"*

她讓玩家戴上監測耳機。

玩家聽到的第一個聲音是低沉的嗡鳴——然後——
> *"有人在那裏嗎？"*

**階段 2 — 對話（90–120 分鐘）**

玩家開始與"獄長"的直接對話。這是戰役中最長的 RP 序列。GM 應爲"獄長"的聲音選擇一個風格——ta 說話緩慢、精確，偶爾停頓很長，彷彿在回憶如何組織語言。

| "你恨基金會嗎？" | "恨？也許——一開始。但恨需要能量。50 年後——我變得更……好奇。你們是誰？你們在意嗎？如果你們不在意——爲什麼在這裏？如果你們在意——你們如何證明你們做的事？" |

### 場景 D-8：後果

> **📍 地圖引用**：全站範圍——D-7 決策的結果將改變 Area-14 的地理結構。GM 需根據 D-7 結局調整場景地圖。

#### 結局分支

**結局 A："自由——以及它的價格"**
- 條件："獄長"被釋放 + 14 個 SCP 被轉移或替代穩定器成功
- 短期後果：Area-14 核心區進入"過渡期"。部分 SCP 被成功轉移到其他站點。部分在轉移過程中出現問題——需要緊急響應團隊處理
- 長期後果："獄長"（阿里亞）在基金會的一個保護性住所中恢復 ta 的意識。ta 沒有身體——但 ta 有溝通設備、訪客、以及 50 年來第一次的——選擇
- O5-2 被 O5 議會內部審查。ta 的 1975 年命令被公開（在有限的 CL.4+ 範圍內）
- D 級請願被倫理委員會接受——D 級人員權益改革開始（緩慢地）
- 後日談：辛格坐在"獄長"（現在的阿里亞）的房間裏。他們在交談。關於風。關於未來。關於一個 50 年後重新開始意味着什麼

**結局 B："仁慈的結束"**
- 條件："獄長"被安樂死
- 短期後果：核心收容區仍需要替代穩定方案。基金會加速 Hume 穩定器項目——但需要時間
- 長期後果：阿里亞的名字被記錄在基金會檔案中——不是作爲 SCP，而是作爲代價。一張照片（1975 年，轉化前）被放在檔案中
- 辛格辭職了。她無法繼續在"殺死了一個她認識的人"的地方工作——即使那是 ta 的選擇
- O5-2 沒有被問責——"獄長"的死亡使調查變得不太緊急

**結局 C："現狀——以及內疚"**
- 條件：維持現狀（改善或未改善）
- 短期後果：意識抑制藥物被停止。"獄長"現在可以溝通。ta 的部分請求被滿足——但 ta 仍然被綁定在覈心區。ta 仍然是一個囚犯

- O5-2 保留了 ta 的職位。沒有什麼改變——除了良知上的一個永久污點
- 後日談：每次監測會話開始時，"獄長"（阿里亞）都問同一個問題："今天有人來嗎？"辛格看着 ta。"今天是星期二。週二總是有人的。"阿里亞沉默了一會兒。"我仍然在數日子。"

**結局 D（隱藏）："D 級的黎明"**
- 條件：D 級 PC 在 D-5 和 D-7 中發揮了決定性領導作用 + 佈道者的網絡被保護 + "獄長"的解決方案被實施

- D 級 PC（如果存活）被記錄爲"D 級人員的第一個自主代表"——不是官方的，但在基金會歷史的暗處
- 後日談：佈道者站在 Area-14 的食堂中。他的周圍是 D 級們。他正在朗讀一封來自倫理委員會的信——關於"D 級人員反饋機制試點項目"。這是基金會歷史上第一次——D 級被正式諮詢關於他們自己的待遇。一小步。但是一步。
