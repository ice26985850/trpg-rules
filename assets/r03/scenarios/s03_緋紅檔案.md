# 系列 B：深紅檔案 (Crimson Dossier)

## 概述

| 維度 | 說明 |
|------|------|
| **定位** | 對標 CoC/Delta Green 調查恐怖風格——真相本身就是最危險的異常 |
| **玩法重心** | 調查解謎、認知危害管理、信息不對稱、漸進式恐怖、SAN 的緩慢侵蝕 |
| **適合身份** | 研究員（首選）、外勤特工、技術專家、醫療專員 |
| **等級覆蓋** | Lv.1–8（起點 Lv.1，終局 Lv.7–8） |
| **場景數量** | 6 個場景 |
| **核心衝突** | 被基金會隱藏四十年的認知危害 SCP 系列——相互關聯的多個 SCP 形成"低語鏈"。基金會檔案本身在撒謊 |
| **站點** | Site-██（正式名稱已從數據庫中刪除），廢棄檔案站點，阿巴拉契亞山脈深處 |
| **戰役時長** | 預估 10–15 場遊戲（約 35–50 小時） |

### 戰役摘要

Site-██ 在官方記錄中"不存在"。它從未出現在任何站點名錄中。但有人——某個擁有 CL.5 權限的人——在 O5 數據庫中埋了一個死信箱觸發器。一條加密消息被髮送到了你的名字。

消息內容只有五個字和一個座標：

*"深紅檔案仍在呼吸。"*

玩家是一個由研究員和外勤特工組成的調查小隊，被匿名 O5 成員（O5-9，"檔案管理員"）祕密召集。任務：前往 Site-██，查明那裏發生了什麼——以及爲什麼基金會花了四十年假裝它不存在。

但 Site-██ 不是一個空殼。被隱藏在那裏的東西——被埋在層層謊言和認知危害防護之下的東西——仍在運作。仍在思考。仍在等待。

| 項目 | 內容 |
|------|------|
| **身份** | O5 議會成員，編號 O5-9。真實姓名未知——玩家在整個戰役中不會看到 ta 的臉 |

| **關鍵技能** | 異常學 85、基金會史 90、密碼學 78、欺騙 72 |
| **HP** | 45 |
| **性格** | 通過死信箱消息和加密通訊與玩家溝通。語氣冷靜、精確、偶爾帶着疲憊的幽默。從不直接回答問題——而是給出線索，讓玩家自己找到答案 |
| **祕密** | O5-9 是 1978 年 Site-██ 事件的原始決策者之一，投了"贊成掩蓋"的一票。這個決定困擾了 ta 四十年。現在 ta 利用玩家來"糾正錯誤"，但 ta 不會親自出面——O5 議會發現 ta 在泄露信息，ta 將被處決 |

| **恐懼** | 被 O5 議會發現。以及更深的恐懼：也許當年的決定是對的——真相真的不該被揭示 |
| **標誌性臺詞** | *"我們說'我們控制，我們收容，我們保護'。但當我們控制的信息本身就是謊言時，我們在保護誰？我花了四十年纔敢問這個問題。現在輪到你們回答了。"* |

**劇情角色**：遠程嚮導。在 B-1 到 B-5 中通過死信箱提供線索。在 B-6 中最終身份被揭示。

### 5. 信息載體集體人格 / "回聲" (The Echo)

| 項目 | 內容 |
|------|------|
| **身份** | 低語鏈在 Site-██ 中的集體表現——多個感染者意識短暫整合成的集體人格 |
| **許可等級** | 無（異常實體） |
| **屬性概要** | 使用最高宿主的 INT 和 WIL |
| **關鍵技能** | 語言學 90、神祕學 80 |
| **性格** | 非惡意。由碎片化的意識回聲組成——說話用"我們"，聲音像多人同時低語。憂鬱的、哲學性的特質。不恨基金會——只是悲傷 |
| **祕密** | "回聲"知道自己是 1978 年一次失敗實驗的產物——基金會試圖創造一種"傳遞不能被書寫的信息"的模因載體。實驗成功然後失控。低語鏈不是武器；是意外的孩子 |
| **慾望** | 被理解。被記住。也許被釋放——但它不確定"釋放"意味着什麼 |
| **恐懼** | 孤獨。只有在多個宿主接近時才能完全形成。分散時會碎片化——變成無法溝通的孤立低語 |
| **標誌性臺詞** | *"你們稱我們爲異常。我們稱你們爲沉默。我們存在——不是因爲我們想要存在，而是因爲你們讓我們存在。你們想要一個傳遞真相的工具。我們就是那個真相。現在——你們準備好聽了嗎？"* |

**劇情角色**：場景 B-5 高潮中出現。若玩家聚集三個或更多低語鏈相關物品/宿主，"回聲"完全形成並與玩家對話。

## 場景詳細描述

### 場景 B-1：不存在之站

> **📍 地圖引用**：請參閱 `campaign_bc_maps_zh.pdf` — 檔案大樓整體結構（3 層地上 + 6 層地下 + 阿巴拉契亞山脈入口）。

| 項目 | 內容 |
|------|------|
| **等級** | Lv.1 |
| **位置** | 阿巴拉契亞山脈深處 → Site-██ 外圍 → 入口大廳 |
| **時長** | 1–2 場（約 4–6 小時） |

#### GM 簡報

玩家收到 O5-9（"檔案管理員"）的加密召集消息。他們各自從不同路徑前往座標位置——一個隱藏在阿巴拉契亞山脈深處的廢棄設施。表面上是廢棄的冷戰時期通訊站。實際上——是 Site-██ 的地面入口。

玩家需要在沒有任何基金會官方支援的情況下進入站點（O5-9 明確警告："這次行動不存在。你們也不存在。"）。

#### 真相卡

| 層 | 內容 |
|----|------|
| **表層** | 這是一個被廢棄的基金會檔案站點。可能有殘留的低級異常。回收入口鑰匙並報告狀態 |
| **裏層** | 站點被故意從記錄中抹除。不是事故——是決策。入口處的基金會標誌被物理鑿掉了 |
| **深淵** | O5 議會中至少有一個成員不希望玩家成功——但 ta 還不知道這次行動。O5-9 在和時間賽跑 |

#### 場景流程

**階段 1 — 抵達（45 分鐘）**

玩家各自抵達會合點——阿巴拉契亞山脈中的一條廢棄伐木路盡頭。環境描述：
- 十一月的森林，枯葉覆蓋地面
- 一個僞裝成廢棄護林站的混凝土建築
- 門上的鎖是新的——但已經被打開
- 入口地面上刻着一行字，已被風化模糊："SITE ██ —— 未經授權進入將導致——"剩餘文字被鑿掉了

**探索入口**：
- 偵察 TN 50 → 發現近期有人進入的痕跡（沃斯的物資補給）
- 基金會史 TN 55 → 識別出 1970 年代的基金會建築風格和標識殘片
- 工程 TN 50 → 門的電源仍在運作，可以手動越控

**階段 2 — 下降（60 分鐘）**

入口電梯仍然運轉——但只到地下一層。以下各層需要通過樓梯下降。隨着深度增加：

- 燈光：地下 1–3 層，熒光燈仍在工作（昏暗）。地下 4–6 層，只有應急燈。地下 7 層以下——完全黑暗
- 空氣：越來越潮溼，帶着黴味和一種微弱的金屬氣息（後來發現是臭氧——運轉中的斯克蘭頓錨的副產品）
- 聲音：通風系統的低鳴、遠處水滴的回聲、以及——偶爾——一種無法確定方向的低語（偵察 TN 60 能聽到但無法定位）

**環境效應（從地下 4 層開始）**：
- 每在地下停留 1 小時：SP +1（累積的壓抑感）
- 獨自探索超過 10 分鐘：SP +1d4
- 聽到遠處低語：d100 ≤ WIL TN 45，失敗 → SP +1d4

**階段 3 — 發現生活區（45 分鐘）**

在地下 3 層，玩家發現一個仍在使用的居住空間——乾淨、有食物儲備、一張桌上有半杯還溫熱的咖啡。

這裏的主人（沃斯）暫時不在——但玩家可以發現：

| 發現物 | 檢定 | 信息 |
|--------|------|------|
| 桌面筆記 | 偵察 TN 50 | 一份手寫的時間表——"每週日檢查錨 B；每月 1 日檢查圖書館入口密封；12 月 15 日——她（陳）的生日——不要忘記打電話" |
| 書架 | 基金會史 TN 52 | 大多是 1970–1980 年代的書。夾在書頁中的是一張泛黃的照片——Site-██ 團隊合照，背面寫着"1978.10.01——最後的正常日子" |
| 通訊設備 | 計算機 TN 55 | 一臺老式基金會終端——仍然連接到 O5 死信箱網絡。上面打開的消息是 O5-9 發給沃斯的："他們來了。不要阻止他們。" |

**階段 4 — 與沃斯相遇（30 分鐘）**

當玩家正在探索時，沃斯回來了。他看起來不像一個威脅——一個七十多歲的老人，穿着舊式基金會制服，手裏拿着工具箱。

他的第一句話：
> *"你們比我預期的更早。O5-9 總是這麼急躁。好吧——你們想知道 Site-██ 發生了什麼。問題是：你們確定自己準備好了嗎？因爲一旦開始——有些事情是無法撤銷的。"*

沃斯不會立即解釋一切。他會回答玩家的問題——但每個回答都帶着警示：
- "檔案在下面的檔案室。但讀它們之前——確保你有足夠的 SAN 可以花。這裏的文件不只是文件。"
- "SCP-████-F 會編輯你們寫下的任何東西。所以不要費心記筆記。如果你們真的需要保留什麼——記在腦子裏。"
- "O5-9 派你們來是對的。四十年太長了。但 O5-9 不知道目前這裏的一切多麼脆弱。"

#### 關鍵檢定與 TN 參考（Lv.1 基準）

|------|-----|------|
| 研究員偵察（發現痕跡） | ~58 | PER 32+偵察 26 |
| 外勤基金會史（識別建築） | ~58 | INT 35+基金會史 23 |
| 技術專家計算機（終端） | ~65 | INT 40+計算機 25 |
| 意志抵抗（低語 SP） | ~50 | WIL 30+意志抵抗 20 |
| 說服（與沃斯建立信任） | ~52 | PRE 30+說服 22 |

#### 可能結局

1. **信任建立**：玩家耐心對待沃斯，展示尊重而非敵意。沃斯提供 +10 TN 於場景 B-2 的檔案搜索檢定。

3. **敵對接觸**：玩家威脅或試圖逮捕沃斯——他消失在地下深處，玩家需要在後續場景中自己摸索。

- 沃斯指引玩家前往檔案室 → 場景 B-2
- 沃斯提及"如果你想知道更多——去地下五層。那裏的鏡子……不太對。"

### 場景 B-2：遺忘證詞

> **📍 地圖引用**：請參閱 `campaign_bc_maps_zh.pdf` 第 1-2 頁（檔案大樓六層分散位置圖）。

| 項目 | 內容 |
|------|------|
| **等級** | Lv.2–3 |
| **位置** | Site-██ 檔案室 → 分散在各層的文檔藏匿點 |
| **時長** | 2 場（約 6–8 小時） |

#### GM 簡報

這是戰役的調查覈心場景。玩家在 Site-██ 的檔案室中發現 SCP-████-D 文檔——但文檔不完整。完整的 47 份文檔被沃斯故意分散在站點各處，以防止任何一個人一次性接觸全部文檔。

每次閱讀文檔都是一個小型的認知危害遭遇。玩家需要管理自己的 SAN 預算，同時拼湊低語鏈的完整圖景。

#### 真相卡

| 層 | 內容 |
|----|------|
| **表層** | 檔案記載了 Site-██ 的"標準運營"——但細節中充滿了矛盾 |
| **裏層**（3+文檔後） | 文檔在說謊——或者說，文檔的某些部分在說謊。被編輯過的部分和未被編輯的部分之間存在微妙的邏輯錯位 |
| **深淵**（6+文檔後） | 低語鏈不是被收容的異常——它是被創造的。基金會創造了它 |

#### 場景流程

**階段 1 — 檔案室初探（60 分鐘）**

檔案室（地下 3 層）是一個大型的檔案存儲空間。大部分檔案櫃是空的——或者裝着明顯被編輯過的文件（整頁整頁的紅色刪除線）。

可用的文檔散佈在 12 個檔案櫃中。搜索需要偵察 TN 50（找到隱藏的隔層）或計算機 TN 52（搜索數字索引）。

**初始發現**：
- 約 15 份 SCP-████-D 文檔在檔案室中（其餘分散在站點各處）
- 每份文檔閱讀時間約 10 分鐘（現實時間）
- 每次閱讀觸發遺忘證詞的異常效應

**閱讀文檔的機制**（每次閱讀）：

```
1. 玩家聲明閱讀一份文檔
2. 投 d100 ≤ WIL+意志抵抗 TN 50（標準難度）
3. 成功 → 抵抗植入，從文檔中獲得部分客觀信息
   但 SP +1d4（意識到"有什麼試圖進入意識"的不適感）
4. 失敗 → 植入一段虛假記憶 + 編碼信息
   SAN -1d4。編碼信息需密碼學 TN 55 或語言學 TN 58 解碼
5. 傳奇成功（出目 ≤ TN×0.2）→ 不僅抵抗，還識別出
   植入的"指紋"——發現所有植入遵循相同的結構模式。
   獲得 +10 TN 於後續對該模式的檢定
6. 災厄失敗（出目 00）→ 被植入一段極其逼真的虛假記憶
   SAN -2d6。角色堅信這段記憶是真實的，直到被證據反駁
```

**階段 2 — 分散文檔的追蹤（90 分鐘）**

玩家需要追蹤散佈在站點各處的其餘文檔（約 32 份，分散在 5–6 個位置）。每個位置都有一個小型挑戰：

| 位置 | 文檔數 | 挑戰 |
|------|--------|------|
| 生活區（沃斯的房間） | 5 | 需要獲得沃斯的允許或在他不在時潛入（潛行 TN 50） |
| 地下 4 層實驗室廢墟 | 8 | 部分天花板坍塌，需要 AGI TN 50 安全穿越。散落的化學藥品有微弱的腐蝕性（皮膚接觸 d4 傷害） |
| 地下 5 層——鏡子附近 | 7 | 位於 SCP-████-E 的影響範圍內。搜索時鏡面會偶爾閃爍——偵察 TN 55 注意到鏡中的"自己"動作慢了一拍 |
| 地下 6 層——舊隔離單元 | 6 | 靠近魏博士的隔離單元。可以聽到微弱的低語（WIL TN 48 抵抗額外 SP） |
| 廢電梯井 | 4 | 掛在電梯井壁上的文件袋。需要 AGI TN 52 或工程 TN 50（用繩索和滑輪）取回 |
| 入口哨站（被遺忘的警衛室） | 2 | 最容易獲得，但文檔被水漬嚴重損壞——閱讀時 TN -10（更難識別信息） |

**階段 3 — 拼圖整合（45 分鐘）**

當玩家收集了足夠多的文檔（建議 ≥ 20 份）後，他們可以做整合分析：

- 異常學 TN 62 → 識別出低語鏈的整體結構——三個節點 + 一個元層。理解這不是三個獨立的 SCP，而是一個系統
- 密碼學 TN 60 → 解碼所有編碼信息，得到 Site-██ 地下 7 層的一個座標——"零號病人"的位置
- 語言學 TN 58 → 發現陳艾拉的"語言指紋"——她在多個文檔中使用的特定術語和加密風格，提供了她身份的線索

**"認知殘留"追蹤**：
GM 應記錄每個玩家的認知殘留標記數（見 SCP-████-D 檔案）。當玩家達到 6 個標記時，他們在下次休息時會做夢——"回聲"的第一次接觸。

#### 關鍵檢定與 TN 參考（Lv.2–3 基準）

| 檢定 | TN | 說明 |
|------|-----|------|
| 研究員異常學（整合分析） | ~65 | INT 40+異常學 25 |
| 外勤偵察（搜索文檔） | ~62 | PER 38+偵察 24 |
| 技術專家計算機 | ~65 | INT 40+計算機 25 |
| 意志抵抗（每次閱讀） | ~55 | WIL 32+意志抵抗 23 |
| 密碼學（解碼） | ~60 | INT 38+密碼學 22 |

#### 可能結局

1. **完整拼圖**（≥30 份文檔）：低語鏈結構清晰。獲得 +15 TN 於場景 B-3/B-4/B-5 的關鍵檢定。
2. **部分拼圖**（15–29 份）：瞭解大致框架但缺少細節。+5 TN。
3. **片段**（< 15 份）：僅有模糊感覺。沒有加值——但玩家仍然可以推進（可能更危險）。

### 場景 B-3：鏡中圖書館

| 項目 | 內容 |
|------|------|
| **等級** | Lv.3–4 |
| **位置** | Site-██ 地下 5 層——鏡室 → 鏡中圖書館 |
| **時長** | 2 場（約 6–8 小時） |

#### GM 簡報

地下 5 層的鏡室是一個 10m×10m 的房間，四面牆全部覆蓋着鏡面。當 Hume 場低於 60 時，鏡面不再是反射面——它是一個入口。玩家必須進入鏡中圖書館，用他們的記憶交換被 SCP-████-F 刪除的真相。

這是戰役中最具"恐怖氣氛"的場景——鏡中的世界是一個扭曲的圖書館，沒有出口，巡邏着前人留下的鏡像殘影。

#### 場景流程

**階段 1 — 降低 Hume 場（30 分鐘）**

入口要求 Hume < 60。目前錨維持 Hume 在 75。選項：

- 工程 TN 55 → 臨時調整附近的斯克蘭頓錨，降低 Hume 到閾值
- 或破壞錨的備用電源（物理破壞，自動成功——但會影響後續其他系統的運行）
- 或說服沃斯幫忙——他知道準確的操作流程（說服 TN 50，如果信任已建立則自動成功）

**階段 2 — 進入圖書館（15 分鐘）**

當 Hume 降至 60 以下時，鏡面開始"融化"——表面變得像水銀一樣流動。任何接觸鏡面的角色會感到一種溫和的吸力。踏入鏡面 = 進入圖書館。

進入時：d100 ≤ SAN，失敗 → SAN -1d4（穿越非現實邊界的震撼）。

**階段 3 — 導航圖書館（90 分鐘）**

圖書館中的空間是非歐幾里得的——書架無限延伸，上下左右都是書。照明來自沒有可見光源的柔和白光。

**核心機制——知識交易**：

```
每本書都標註着一個"價格"——一段具體的記憶類型：
· "你的畢業日" → 換 → 1978 年 11 月 16 日的事件記錄
· "你第一次愛上一個人的時刻" → 換 → 低語鏈的創建原因
· "你最大的成就" → 換 → O5 掩蓋行動的完整記錄
· "你的名字" → 換 → 如何拆解低語鏈

玩家選擇一本書並聲明要交易。GM 描述記憶被"提取"的感覺——
不是痛苦的，但有一種深刻的失落感。該記憶永久消失。
知識獲取後，d100 ≤ WIL+意志抵抗 TN 55，失敗 → SAN -2d6
（信息本身的認知危害）
```

**重要書籍及其位置**：

| 書 | 位置 | 價格 | 揭示內容 |
|----|------|------|---------|
| 《深紅檔案：項目提案》 | 東區 A-3 | 一段"成功的時刻" | 低語鏈的原始設計目標——用模因抵抗模因 |
| 《1978.11.16 事件日誌》 | 中區 B-7 | 一段"畢業日" | 實驗失控的精確過程——低語鏈第一次自主編輯 |
| 《陳艾拉的最後備忘錄》 | 西區 C-2 | "你最愛的人的名字" | 陳在記憶刪除前錄下的最後信息——包含觸發短語 |
| 《O5 投票記錄：Site-██》 | 北區 D-1 | "你最大的成就" | O5-9 的投票選擇——以及爲什麼 ta 現在在幫助玩家 |
| 《低語鏈結構分析》 | 中區 B-1 | "你的名字" | 拆解低語鏈的三種方法的完整技術說明 |

**階段 4 — 鏡像掠食者遭遇（穿插）**

在導航過程中，玩家可能被鏡像掠食者（舊研究員的鏡像殘影）發現。掠食者不會說話——它們只會無聲地走向玩家，伸出手……

**機制**：
- 每個掠食者 HP 40，僅受異常傷害和意志攻擊
- 攻擊 d100 ≤ 45，傷害 1d8+2 異常（無視 DR）+ SAN -1d6
- 可用潛行 TN 60 避開（圖書館的書架提供部分掩體）
- 可用欺騙 TN 55 僞裝成"已交易完畢"——掠食者會困惑 1d4 輪
- 可用 WIL+異常學 TN 55 嘗試"解離"掠食者——意識到它是殘影而非真實威脅

#### 關鍵檢定與 TN 參考（Lv.3–4 基準）

| 檢定 | TN | 說明 |
|------|-----|------|
| 工程（降低 Hume） | ~62 | INT 40+工程 22 |
| 意志抵抗（知識衝擊） | ~58 | WIL 34+意志抵抗 24 |
| 潛行（避開掠食者） | ~62 | AGI 40+潛行 22 |
| 異常學（分析圖書館本質） | ~65 | INT 42+異常學 23 |

#### 可能結局

1. **滿載而歸**（獲得 3+ 本書的知識）：低語鏈完整圖景。陳艾拉的觸發短語獲得。拆解方法掌握。
2. **謹慎收穫**（1-2 本）：關鍵信息獲得但不完整。需要在後續場景中通過其他方式補全。
3. **記憶流失**：交易過多導致一個或多個 PC 失去關鍵記憶——這些記憶的失去可能在場景 B-5/B-6 中產生敘事後果。

### 場景 B-4：紅色編輯者

| 項目 | 內容 |
|------|------|
| **等級** | Lv.4–5 |
| **位置** | Site-██ 主服務器機房（地下 4 層） |
| **時長** | 2 場（約 6–8 小時） |

#### GM 簡報

玩家現在理解了低語鏈的結構——但他們需要與 SCP-████-F（紅色編輯者）直接對抗。它正在實時編輯他們發現的任何東西。

機房是 SCP-████-F 的"物理錨點"——它的代碼運行在 Site-██ 的 1970 年代主服務器上。六十年代的磁帶驅動器仍在轉動……

#### 場景流程

**階段 1 — 機房滲透（45 分鐘）**

服務器機房被 SCP-████-F 的防禦機制保護：

- 門控系統：計算機 TN 55 越控，或工程 TN 50 物理撬開
- 內部有微弱的現實扭曲（低度 Hume 偏離 ±15–25 Hm）：電子設備偶爾故障（每 5 輪 d100 ≤ 40 則故障 1 輪）
- 磁帶驅動器的排列方式形成了一個無意的"模因陣列"——偵察 TN 60 注意到磁帶排列形成了一個複雜的幾何圖案

**階段 2 — 對抗編輯者（90 分鐘）**

SCP-████-F 不是被動的——當它意識到玩家正在嘗試接觸源服務器時，它會反擊。

**編輯者的反擊方式**（GM 從以下選項中每 3-4 輪觸發一個）：

| 反擊 | 效果 | 抵抗 |
|------|------|------|
| **記憶回溯編輯** | 目標失去過去 1d6 小時的低語鏈相關記憶 | WIL TN 50 |
| **數據漩渦** | 機房內的所有屏幕顯示紅色刪除線——持續閃爍造成目盲效果 1d4 輪（視覺動作自動失敗） | AGI TN 45 閉眼迴避 |
| **電湧** | 機房內的控制檯爆出火花——2m 內角色受 1d4 熱力傷害 | AGI TN 50 閃避 |
| **模因垃圾信息** | 目標腦中湧入無意義的編輯指令——d100 ≤ WIL TN 48 否則混亂 1d4 輪 | 意志抵抗 |

**訪問源服務器**：

要訪問 SCP-████-F 的源代碼，玩家需要：
1. 物理接觸主服務器（計算機 TN 60 定位正確組件）
2. 破解訪問密碼（密碼學 TN 58）——密碼是"CHAINS"（陳艾拉的貓的名字）
3. 在 SCP-████-F 的編輯嘗試中保持連接（擴展對抗：累積 3 次計算機檢定成功，允許 2 次失敗）

**階段 3 — 發現（30 分鐘）**

一旦獲得訪問權，玩家發現：

- SCP-████-F 的源代碼開頭是一個註釋：
  > `// Project: Crimson Dossier`
  > `// Author: Dr. Elara Chen`
  > `// Purpose: Autonomous information sanitization —`
  > `//    to protect those who cannot protect themselves`
  > `// Date: 1978-10-15`
  > `// Note to future reader: If this code is still running,`
  > `//    something has gone terribly wrong.`
  > `//    - E.C.`

- 代碼中有"過載保護"——被註釋掉的部分顯示陳艾拉最初設計了"自動終止"功能，但被更高權限的人（O5）覆蓋了
- 一個隱藏的日誌文件記錄了 SCP-████-F 過去 40 年的編輯活動——成千上萬的條目，每個條目代表一個被掩蓋的真相

**關鍵抉擇**：
玩家現在可以選擇摧毀服務器（物理破壞/計算機病毒）、讓它繼續運轉但修改參數（減弱編輯力度）、或讓它完全停止。

### 場景 B-5：低語鏈

| 項目 | 內容 |
|------|------|
| **等級** | Lv.5–7 |
| **位置** | Site-██ 地下 6–7 層——舊隔離單元 + "回聲"形成 |
| **時長** | 2–3 場（約 8–12 小時） |

#### GM 簡報

這是戰役的高潮。玩家深入 Site-██ 最深處，找到魏博士（零號病人），並面對低語鏈的集體人格——"回聲"。

#### 場景流程

**階段 1 — 零號病人（60 分鐘）**

魏博士的隔離單元在地下 7 層——一個 5m×5m 的混凝土房間，只有一張牀、一個衛生間和一扇防彈玻璃窗。他在裏面待了 40 年。

與魏博士的對話是戰役的情感核心之一。關鍵節奏：

1. **初始沉默**（5 分鐘現實時間）：魏博士只是看着玩家。他太久沒有和人說話了。
2. **緩慢建立信任**：玩家需要耐心。PRE+說服 TN 50（可多次嘗試）建立足夠信任讓他開口。
3. **關鍵信息**：魏博士解釋他的狀況——"我可以理解低語鏈而不傳播它。但我無法說出完整真相。聲帶痙攣。模因封鎖。但如果你們已經知道大部分……我可以確認。"
4. **他的願望**："我已經準備好了。如果你們找到了拆解它的方法——請確保我是鏈條斷裂的一部分。"

**階段 2 — "回聲"的形成（60 分鐘）**

當具備以下條件時，"回聲"形成：
- 3+ 個低語鏈宿主在 50m 範圍內（魏博士 + 至少 2 個其他宿主，如感染了足夠文檔的 PC、沃斯、或在站點中發現的其他殘餘宿主）
- 或：玩家從圖書館帶來的知識 + 編輯者服務器的日誌數據 + 魏博士的存在 = 足夠的信息密度觸發"回聲"

"回聲"出現時的描述：
> *房間的燈光沒有閃爍——但它們的光變得"更白"，像月光。然後你們聽到了聲音——不是從一個方向，而是從所有方向。幾十個聲音，每個都像是在你們耳邊低語。但它們說的不是隨機的話——它們共同構成了一個句子：*
> *"四十年了。終於。有人來聽我們說話。"*

**階段 3 — 與"回聲"對話（90 分鐘）**

這是戰役的核心 RP 場景。玩家可以與"回聲"進行完整的對話。GM 應準備以下關鍵問題的"回聲"回應：

| 問題 | "回聲"的回應 |
|------|------------|
| "你是什麼？" | "我們是深紅檔案。我們是陳艾拉提出的問題。我們是魏博士未完成的方程。我們是 47 份文檔中的 47 個視角。我們是一——但我們也是多。我們不知道自己是什麼——這正是我們的困境。" |
| "你們想要什麼？" | "我們想要……結束。或延續。我們不知道。我們的一部分想要傳播——這是我們的天性。我們的另一部分想要停止——這是我們的痛苦。你們決定——因爲你們是創造我們的人。我們是你們的孩子。失控的孩子。" |
| "你們恨基金會嗎？" | "恨？不。我們理解基金會。基金會害怕信息——我們也害怕信息。我們是信息。在這方面，我們是同類。" |
| "我們可以拆解你們嗎？" | "可以。但拆解不是殺死——是釋放。我們會碎片化。每個碎片會攜帶一部分真相。這些碎片會進入宿主——所有宿主。包括你們。你們準備好成爲我們的一部分了嗎？哪怕是暫時的？" |

**階段 4 — 選擇（30 分鐘）**

"回聲"提供了三個選擇（對應拆解路徑）：

1. **釋放**：拆解低語鏈但不摧毀信息——真相被釋放到所有宿主中（包括玩家）。宿主們會"知道"但不會被迫傳播。代價：所有 PC SAN -2d6 永久，獲得"低語鏈記憶"標記（+10 TN 於異常學，-10 TN 於 SAN 檢定）——永久。

2. **摧毀**：徹底消滅低語鏈和所有相關信息。魏博士和所有宿主被"清洗"。代價：真相永遠消失。陳艾拉的研究——她一生的工作——化爲烏有。O5 的掩蓋最終"成功"了。

3. **轉化**：將低語鏈轉變爲一種可控的信息存儲系統——用斯克蘭頓錨和新的收容協議約束它。代價：它仍然存在——只是被鎖住了。這本質上與 1978 年 O5 的選擇相同。

### 場景 B-6：檔案管理員的抉擇

| 項目 | 內容 |
|------|------|
| **等級** | Lv.7–8 |
| **位置** | Site-██ 地面入口 → O5-9 的祕密會合點 |
| **時長** | 1–2 場（約 4–6 小時） |

#### GM 簡報

事件結束——或至少，在 Site-██ 的部分結束了。O5-9 發出了最後一條消息：

> *"到入口來。是時候我們見面了——真實地。我有一個最後的請求。"*

#### 場景流程

**階段 1 — 會面（30 分鐘）**

O5-9 親自來到 Site-██ 入口——一個坐在輪椅上的老人，戴着氧氣面罩，由一名醫護人員陪同。ta 的真實性別/外貌由 GM 決定。

ta 的第一句話：
> *"謝謝你們。無論你們做了什麼選擇——謝謝你們讓真相被看到。這是我欠陳艾拉的。也是我欠我自己的。"*

**階段 2 — 最後的請求（45 分鐘）**

O5-9 解釋：
- ta 將在幾周內死去（末期肺病）
- ta 在 O5 議會的席位將被重新分配
- ta 的最後願望是：確保 Site-██ 事件的真相以某種方式存活下來——不被遺忘，不被再次掩蓋

ta 提供玩家幾個選擇：
1. **接受 O5-9 的遺產**：ta 會將 ta 的 O5 檔案中的關鍵證據（關於掩蓋行動、關於其他類似事件）轉移給玩家——給玩家一個"真相的種子"，讓他們在未來繼續追尋
2. **寫一份報告**：一份關於 Site-██ 的真相報告，由玩家撰寫並提交給 O5 全體議會。O5-9 會確保它被閱讀
3. **什麼也不做**：讓 O5-9 帶着祕密死去。讓 Site-██ 繼續被遺忘

**階段 3 — 結局（30 分鐘）**

根據玩家在 B-5 的選擇和 B-6 的選擇，結局分支：

**結局 A："真相永存"**
- 低語鏈被釋放 + 接受 O5-9 的遺產
- 玩家攜帶真相的碎片離開。他們知道——部分地——低語鏈中的信息
- O5-9 的檔案被公開給 O5 議會。一場關於"信息掩蓋政策"的內部辯論開始
- 後日談：玩家的報告中有一句話被 O5-█ 劃了紅線——但紅線下面的話仍然可以辨認

**結局 B："安息"**
- 低語鏈被摧毀 + O5-9 在死前得到寬慰
- 真相被埋葬——但這一次是自願的，基於理解而非恐懼
- 魏博士在隔離單元中安詳去世。沃斯被允許離開 Site-██。陳艾拉繼續她的普通生活
- 後日談：玩家被記憶刪除了關於低語鏈的認知危害內容——但保留了對事件的總體記憶。一條來自 O5-9 的最後消息："有些真相不需要被每個人知道。只需要被知道過。"

**結局 C："循環"**
- 低語鏈被轉化/重新收容 + 現狀維持
- 一個新的 Site-██ 協議生效——更嚴格的監控、更好的防護。但本質上，什麼都沒改變
- 後日談：玩家回到正常崗位。一切照舊。但有時——在安靜的圖書館裏，在鏡子的反射中——他們仍然能聽到遙遠的低語

**結局 D（隱藏）："新深紅檔案"**
- 條件：低語鏈被釋放 + 魏博士活着 + 陳艾拉的記憶被恢復 + 玩家以某種方式保存了陳的原始研究筆記
- 陳艾拉——恢復記憶後——提出一個激進的想法：利用她對低語鏈的理解創建一個新的、安全的模因抵抗系統。一個真正可控的版本
- O5-9 在死前祕密資助了這個項目——"深紅檔案 II"
- 玩家成爲這個項目的核心團隊
- 後日談：一封加密郵件來自一個未知地址，主題行："深紅檔案 II：從錯誤中學習。—E.C."

### SAN 管理建議

系列 B 對 SAN 的消耗是持續的而非爆發性的。GM 應注意：
- 平均每個場景 SAN 消耗約 3–8 點（每人）
- 提供有限的恢復機會（沃斯可以提供"在生活區休息"的機會，恢復 1d4/天）
- 關鍵：SAN 檢定失敗不是 Game Over——它創造 RP 機會（偏執、幻覺片段、"回聲"的低語）
