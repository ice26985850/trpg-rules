# 第二部分：全新單人劇本 —— 回聲旅館（★→★★★★★）

**設計說明：** 這是一個完全為單人設計的劇本。它不是調整現有劇本，而是從循環結構到碎片獲取全部圍繞「一個人調查」來構建。玩家扮演一名入住偏僻山區旅館的旅客，在暴風雪中被困，發現旅館每晚午夜都會重置到前一天傍晚——而旅館的每一個房間都藏著一個前客人的秘密。

難度曲線覆蓋：循環 1-3（新手探索）→ 4-6（標準調查）→ 7-9（進階拼圖）→ 10-12（專家真相）→ 13+（終極選擇）。

---

## 劇本概要

| 項目 | 內容 |
|------|------|
| **難度** | ★→★★★★★ 漸進（新手友好入口，專家級真相） |
| **循環長度** | 1 天（暴風雪之夜：傍晚 18:00 → 次日午夜 00:00） |
| **每日 行動點（AP）** | 9 + 行動（ACT）修正（6小時有效窗口） |
| **建議循環上限** | 15 |
| **基調標籤** | 孤獨中的執著 / 每一個房間都有一個故事 / 過去從未真正過去 |

## 循環設定

- **循環終點：** 午夜 00:00，旅館大廳的鐘聲響起，所有客房的門同時鎖上——然後重置。
- **起點時刻：** 傍晚 18:00，你在旅館大廳的壁爐旁醒來。暴風雪在外面呼嘯。旅館老闆正在吧檯後面擦拭杯子。
- **循環邊界：** 旅館建築 + 周圍 50 米（超過 50 米在暴風雪中無法生存——自動重置）。
- **開場敘述：** 「壁爐的火噼啪作響。你睜開眼睛，發現自己蜷縮在大廳的舊沙發上。窗外是暴風雪——白茫茫一片，看不到路。吧檯後面，一個老人正在擦拭杯子。『醒了？』他頭也不抬地說。『暴風雪還要持續一陣子。客房在二樓——隨便選一間吧。反正也沒別的客人。』他說『沒別的客人』時，你的目光無意中掃過登記簿——上面密密麻麻寫了十幾個名字。但都被劃掉了。」

## 核心真相

**錨點事件：** 這座旅館不屬於任何時代。它是一個「時間的縫隙」——每一個在暴風雪中迷路並死在這座山裡的人，死前的最後意識都會來到這個旅館。他們在這裡住一晚，然後在午夜消散。旅館老闆是唯一一個永遠在這裡的人——他不是活人，他是這個縫隙的守護者。他記不住任何客人，因為在時間的縫隙裡，「人」只是過客。

十年前，有一個客人沒有消散。她叫**林素問**，是一個考古學家，在暴風雪中為救同伴而墜崖。她的遺憾是——她沒有告訴她的女兒「媽媽愛你」。這個遺憾太重了，重到讓縫隙無法消化——形成了裂痕。從那以後，每一個來到旅館的客人都被困在了一個六小時的循環中。林素問本人住在 204 號房間，但她不記得自己是誰——她只記得「我在等一個人」。

**裂痕癒合條件：**
- 必要：玩家在 204 號房間找到林素問的遺物（一封給女兒的未寄出的信）
- 必要：玩家對林素問說出真相——「你已經不在人世了，但你的女兒還活著。她需要知道你是為了救人才死的。她需要這封信。」
- 可選：玩家探訪其他客房，理解其他客人的故事——這些故事不是必要的，但它們會讓玩家理解循環的本質（並可能提供 認知點（CP） 和線索）。

## 八個真相碎片

**碎片 1：登記簿的秘密（場景/大廳吧檯/易/循環1）**
- 登記簿上被劃掉的名字，仔細看——每個名字旁邊都有一行小字，用不同的筆跡寫著「死於 XXXX 年 X 月 X 日」。最後一條是十年前。那之後登記簿是空白的——直到你出現。你的名字沒有被劃掉。旁邊只寫了三個字：「還活著」。

**碎片 2：204 號房間的哭聲（場景/二樓走廊/中/循環2）**
- 晚上 10:00，如果你路過 204 號房間，你會聽到裡面有人在哭。門是鎖著的——但如果等到晚上 11:00，門會短暫打開 5 分鐘。房間裡有一個女人，坐在窗邊，看著暴風雪。她不會主動和你說話。但如果你問她「你在等誰」，她會回答：「我的女兒。她說會來接我。但雪太大了。她可能回不來了。」

**碎片 3：其他客人的故事（對話/各個房間/中/循環3+）**
以下 3 個小故事分佈在旅館的其他房間中。至少需要了解 2 個才能拼出循環的本質：
- **201 號房 - 老獵人（73歲）：** 五年前在暴風雪中迷路凍死。他每晚都在擦拭一把獵槍——但其實那把槍不是他的。是他死前在山洞裡找到的遺物，他至死都在想「這把槍是誰的」。
- **203 號房 - 年輕登山者（24歲）：** 三年前遇難。他每晚都在寫一封信——但每次寫到一半就忘了自己在寫什麼。信的開頭是：「親愛的媽媽，對不起，我不應該一個人來。山很美，但——」然後筆跡就斷了。
- **205 號房 - 貨車司機（41歲）：** 八年前在雪崩中遇難。他每晚都在看地圖，試圖找到一條不存在的路。如果你看了他的地圖——你會發現那條路曾經存在。但十年前就廢棄了。

**碎片 4：老闆的日記（物品/吧檯後面/中/循環4）**
- 旅館老闆的日記。第一頁寫於「時間不詳」。最後一頁是十年前：「今天來了一個女人。她不像別人——她記得自己是誰。她問了我一個問題：『你在等誰？』我回答：『我不等任何人。我只是在這裡。』她說：『我也是。』然後她走上了二樓。從那以後，這裡的時間就亂了。雪不再停。客人不再離開。我記不住他們的臉——但今天晚上，我記下了這句話：『我也是。』」

**碎片 5：林素問的考古筆記（物品/204號房床下/難/循環5）**
- 一箇舊揹包，裡面有一本考古筆記。記錄了十年前的考古項目。最後一頁是一張從報紙上撕下來的照片——一個小女孩，標題是「山區救援隊搜尋失蹤考古學家」。背面寫著：「女兒問我什麼時候回家。我說下週三。那天是週三嗎？我已經不知道了。」

**碎片 6：未寄出的信（物品/204號房枕頭下/難/循環6）**
- 林素問寫給女兒的信，從未寄出。全文：

> 「親愛的朵朵：
> 媽媽被困在一個地方了。不是山洞——是一個旅館。有壁爐，有溫暖的床，有永遠不會停的雪。但媽媽不怕——因為這裡很安全。媽媽唯一怕的是，你不知道媽媽是愛你的。那天早上出門前我們吵架了。你說『你從來不在乎我』——那是你一生中說的最錯的一句話。媽媽在乎你。在乎到在這暴風雪裡，媽媽唯一在想的事情就是下週三是你的生日。對不起媽媽回不去了。如果有一天有人把這封信帶給你——請記住：媽媽是為救人而死的。這比任何考古發現都重要。」

**碎片 7：老闆的真名（對話/吧檯/特殊/循環8+）**
- 旅館老闆不是真正的旅館老闆。他是這座山本身——或者說，是這座山對所有死者的歉疚。如果你直接問他「你到底是誰」，他會沉默。但在第 8+ 循環後，如果你已經收集了碎片 1-6 中的至少 4 個——他會回答：「我叫什麼不重要。重要的是——那個叫林素問的女人。她不應該在這裡。你應該幫她。」然後他給你 204 號房間的鑰匙（此前門只在 23:00-23:05 打開）。

**碎片 8：送信（行動/觸發式/循環9+）**
- 這個循環結束時，你做了一個選擇：是否「錨定」那封信。錨定那封信需要花費**3 個錨點**（完整重現級別的錨定）。如果你錨定了——你下個循環醒來時，手裡攥著那封信。紙是暖的。墨跡未乾。然後你會意識到：這封信不是給你看的。你必須離開這座旅館。你必須找到林素問的女兒。而當循環結束時——你發現旅館的門，第一次，向外打開了。

## 五個關鍵 NPC

**林素問「等待的母親」（42歲）：** 情緒基線 3/10（悲傷中的平靜），敏感度「極高」——她是錨點人物。她每晚在 204 號房看著窗外。如果你不和她說話，她不會主動開口。如果你說了，她會問你：「你見過一個叫朵朵的女孩嗎？」

**旅館老闆「山」（外表 60 歲，實際 ∞）：** 情緒基線 5/10（永恆的平靜），敏感度 N/A（他不是人類——他不會劣化偏移）。他在每個循環開始時都會說同樣的話：「醒了？暴風雪還要持續一陣子。客房在二樓。」他在整個劇本中不會偏移、不會有既視感——他是唯一不變的錨。

**老獵人（201 號房）：** 情緒基線 4/10（平靜的悲傷）。他不會說話——他的喉嚨在凍死時受損。他只會點頭、搖頭、或指向某物。他的獵槍指向一張地圖——標誌著林素問墜崖的位置。如果玩家能理解他在指什麼：獲得額外 1 認知點（CP）。

**年輕登山者（203 號房）：** 情緒基線 2/10（懊悔）。他每晚在寫信。如果你在他忘記之前幫他寫好結尾，他會在消失前微笑——並且第二天循環開始時，他的房間門上會多一把鑰匙，可以打開 204 號房（替代碎片 7 的鑰匙獲取方式）。這是「為他人完成未竟之事」的獎勵。

**貨車司機（205 號房）：** 情緒基線 6/10（固執的樂觀）。他相信他能找到出路。每次循環他都會拿著地圖衝出旅館——然後在門口被暴風雪嚇回來。如果你告訴他「這條路十年前就廢棄了」，他會沉默，然後遞給你一張紙條：「林素問。那是十年前的乘客。我送過她。她要去的地方在那個懸崖。座標是——」

## 推薦 NPC 夥伴

**候選夥伴：年輕登山者（203 號房）——** 屬性：體能 3 / 警覺 2 / 意志 2 / 親和 1。他在第 3+ 循環後可以成為夥伴（幫助他寫完信之後）。他年輕、行動力強，體能 3 在夥伴中屬於高值——適合戰鬥和行動輔助。代價：他對「離家」有深深的恐懼，如果玩家提到「回家」，他會陷入沮喪——本循環內所有檢定劣勢。

## 劣化路線圖（單人專用）

| 循環 | 劣化階段 | 關鍵事件 |
|:--:|:--:|------|
| 1-2 | 鏡像 | 正常旅館。玩家探索大廳、客房、熟悉 NPC。碎片 1+2 可取得。 |
| 3-4 | 鏡像→漣漪 | 203 號房的門開始自己打開（登山者的信寫到一半）。碎片 3 中的故事開始循環「播放」——NPC 的重複行為變得明顯。 |
| 5-6 | 漣漪 | 壁爐的火不再噼啪響——變成了無聲的火焰。204 號房的哭聲比之前更清晰——然後突然停止（林素問在那一刻幾乎記起了什麼）。碎片 4+5+6 可取得。 |
| 7-8 | 裂紋 | 暴風雪中出現人臉——在窗口一閃而過。是十年前在這座山裡死去的所有面孔。老闆第一次說了一句不一樣的話：「今天？今天星期幾？」碎片 7 可取得。 |
| 9-10 | 斷裂 | 204 號房的門不再自動鎖上。林素問開始說完整句子——但她說的不是現在的事。她在說話——但內容是十年前她墜崖那一刻對女兒說的話。碎片 8 觸發條件達成。 |
| 11-12 | 斷裂→崩壞 | 旅館的牆壁開始變得透明——你可以在走廊看到外面暴風雪中的山。但山不是現在的山。是十年前的山——沒有廢棄的路，沒有倒塌的橋。 |
| 13-15 | 崩壞 | 最後的循環。旅館的所有房間門同時打開。所有「客人」站在門口——不是在等你，而是在等林素問。他們知道她是誰。他們在等她做出選擇。 |

## 三種結局

**A - 信送達了（完美·錨定結局）**
觸發條件：碎片 1-7 全部獲得 + 錨定了碎片 8（花費 3 錨點錨定信）+ 說服林素問接受真相。
結局敘事：下個循環醒來時，信在手裡——暖的。旅館的門開了。門外不是暴風雪——是一條山路，陽光明媚。你知道你要去哪裡：山下的小鎮，找一個叫「朵朵」的人。旅館在你身後消失了——但它沒有被抹去。它只是不再需要循環了。那個叫林素問的女人，終於等到了她等的人。雖然那個人不是她的女兒——但足夠了。

**B - 告訴了她（一般·非錨定結局）**
觸發條件：碎片 1-6 獲得 + 對林素問說出真相但未錨定信。
結局敘事：林素問在聽到真相後，沉默了很久。然後笑了。「告訴他——或者她。那封信我不需要寄了。我知道它寫的是什麼。」她走向窗邊。暴風雪停了。她推開窗戶——窗外不是山。是她女兒的房間。她走了進去。窗關上了。循環停止了。

**C - 留在暴風雪中（壞結局）**
觸發條件：循環耗盡（15次）而未讓林素問面對真相。
結局敘事：旅館不再重置。暴風雪停了——但所有客房都空了。林素問的房間裡只剩下一封信，壓在枕頭下面。信已經泛黃——像放了十年。你拿起信。走出旅館。山路上沒有腳印——只有你一個人的。你必須走到山下。你必須找到那個叫朵朵的人。但你不知道她已經多大了。你甚至不知道她是否還在等。
