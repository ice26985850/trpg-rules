# 劇本三：最後的學園祭（進階 · 7天）

## 劇本概要

| 項目 | 內容 |
|------|------|
| **難度** | ★★★★☆ 進階 |
| **循環長度** | 7 天 |
| **建議玩家數** | 3-5 |
| **建議循環上限** | 15 |
| **每日行動點（AP）** | 8 + 行動（ACT）修正（7天×行動點（AP），共約 56-77 行動點（AP）） |
| **基調標籤** | 青春的終結 / 未竟之言 / 即使知道結局也要做的事 |

## 循環設定

- **循環終點：** 第七天（學園祭當天）下午 3:00，學校發生毒氣事件，全校死亡
- **起點時刻：** 學園祭前七天（星期一）早晨 7:00，玩家在教室醒來
- **循環邊界：** 整個學校校區（含宿舍、體育館、後山）
- **開場敘述：** 「你在課桌上醒來。臉頰貼著冰涼的桌面，嘴角還有口水的痕跡。黑板上寫著『距離學園祭還有 7 天』。窗外的櫻花開了——你記得櫻花應該下週才開。但你想不起來昨天發生了什麼。或者前天。或者你為什麼會趴在課桌上。」

## 核心真相

**錨點事件：** 毒氣事件的真正原因不是意外，而是化學老師為了掩飾一起實驗意外致死而引發的連鎖反應。但形成裂痕的瞬間不是毒氣——而是一個學生在死前最後一秒的遺憾：她/他從來沒有向暗戀的人告白。

**表面故事：** 學園祭當天實驗室氣體洩漏，意外事件，全校遇難。

**真實故事：** 化學老師江雪在學園祭前三天的一次秘密實驗中，因操作失誤導致一名留校學生（她的助教）吸入了有毒氣體。她隱瞞了事故，但洩露持續擴散。學園祭當天，實驗室積累了足夠濃度的毒氣，通過通風系統擴散到全校。

但裂痕不是化學老師造成的。裂痕是一個叫「蘇眠」的學生——她在毒氣中倒下的瞬間，唯一的念頭是：「我還沒有告訴林同學我喜歡他。」這個遺憾撕裂了現實。

**裂痕癒合條件：**
- 必要：蘇眠（或在玩家的幫助下）向林同學告白
- 必要：揭露化學老師的事故真相
- 可選：在學園祭當天阻止毒氣擴散

## 八個真相碎片

1. **蘇眠的日記（物品/蘇眠的課桌/易/循環1）：** 一本被寫了又撕、撕了又寫的日記。每一頁都只有一句話：「今天也沒有說出口。」
2. **實驗室的鎖（場景/化學實驗室/中/循環3）：** 化學實驗室在學園祭前三天開始反鎖——正常應該是開放的。門縫有淡淡的苦杏仁味。
3. **缺席的助教（對話/學生/易/循環2）：** 高三的學長「周洋」在學園祭前四天突然請假——從此再也沒人見過他。老師們說他「轉學了」。
4. **江雪老師的加班記錄（文件/教職員辦公室/難/循環4）：** 化學老師江雪在學園祭前三天到前一天的深夜都在實驗室。出勤記錄上有她的簽名——但簽名越來越潦草。
5. **通風系統圖（物品/校務處/中/循環5）：** 學校的通風系統圖紙。標註顯示化學實驗室的通風管連接到了全校——包括體育館（學園祭主場地）。
6. **林同學的筆記（物品/圖書館/易/循環1）：** 林同學在學園祭前五天借了一本詩集。書裡夾著一張紙條：「想在學園祭那天，在櫻花樹下讀這首詩給一個人聽。如果我有勇氣的話。」
7. **蘇眠的最後一刻（記憶/體育館/特殊/循環7+）：** 在毒氣擴散的瞬間，如果玩家在蘇眠附近，GM 觸發閃回：蘇眠的視角——她倒下時看著體育館另一邊的林同學，嘴唇在動，但發不出聲音。那個口型是：「我喜歡你。」
8. **江雪的供詞（對話/觸發/難/循環8+）：** 如果你帶著碎片 2+3+4+5 的證據去質問江雪，她會在第七天崩潰：「我只是不想讓一個事故毀了一切。周洋是個好學生。他只是在幫我。他不應該死。我也不應該讓他白死。」——但她的隱瞞殺了全校。

## 五個關鍵 NPC

**蘇眠「未告白的少女」（17歲）：** 情緒基線 5/10（內向、緊張），敏感度「極高」——她就是錨點人物。在每次循環中，她都會在第 7 天下午 2:55 走向林同學——但永遠走不到。如果你在第 7 天下午 2:50 之前告訴她「你應該去告白」，她會去——這直接觸發裂痕癒合。

**林同學「被暗戀的人」（17歲）：** 情緒基線 7/10（開朗），敏感度「高」。他其實也喜歡蘇眠——但他的紙條從來沒有被蘇眠看到。關鍵偏移：循環 6+ 可能無意識在課桌上畫蘇眠的名字。

**江雪「化學老師」（34歲）：** 情緒基線 3/10（極度焦慮），敏感度「高」。她不是壞人——她只是一個犯了錯然後試圖掩蓋的普通人。關鍵偏移：循環 8+ 可能主動去校長室自首。

**周洋「消失的助教」（18歲）：** 情緒基線 N/A（他已不在了）。敏感度 N/A。他的「殘影」在實驗室附近偶爾出現。他是唯一一個在循環開始前就死亡的人——他是裂痕的「預兆」。

**校長「知情人」（58歲）：** 情緒基線 6/10（表面鎮定），敏感度「中」。他知道江雪在隱瞞什麼，但他選擇相信她。他的秘密：他女兒也在學園祭那一天在學校。

## 劣化路線圖

- **1-3（鏡像）：** 正常學校生活。建立與蘇眠和林同學的熟悉度。讓玩家體驗「日常的青春」。
- **4-6（漣漪）：** 櫻花提前凋謝。江雪開始出錯——課堂上講錯公式。蘇眠的日記頁數每天不同。
- **7-9（裂紋）：** 學校廣播偶爾播放不屬於這個時代的歌曲。走廊的長度在變化。蘇眠可能短暫「意識」到循環。
- **10-12（斷裂）：** 化學實驗室的門消失了——但裡面的毒氣還在擴散。周洋的殘影開始與其他 NPC 互動。
- **13-15（崩壞）：** 學園祭的裝飾自行變化。體育館的時鍾倒著走。蘇眠在第 7 天會自動走向林同學——但時間流速在減慢。

## 四種結局

**A - 告白（完美）：** 揭露江雪真相 + 促使蘇眠在毒氣擴散前告白 + 阻止毒氣擴散。學園祭正常舉行。蘇眠在櫻花樹下讀完那首詩。全校得救。裂痕癒合。

**B - 遺憾但完整（進階好）：** 揭露真相但未能阻止毒氣。蘇眠在最後一刻告白了。全校死亡——但循環停止了。蘇眠的遺憾被填滿。裂痕癒合——以所有人消散為代價。

**C - 蘇眠的選擇（隱藏）：** 如果蘇眠在後期循環「半覺醒」——她會意識到自己是循環的原因。她可以選擇：繼續循環（她可以反覆見到林同學）或告白（循環結束，但她會死）。她把這個選擇交給玩家。

**D - 最後的學園祭（壞）：** 循環耗盡。學校從地圖上消失。唯一留下的，是櫻花樹上刻著的兩個字：「蘇眠」。
