Yonghe Martial Codex TRPG rules / maps/ Resource Index
============================================================

This ruleset adopts an "ambiguous geography" design (the source explicitly states there is no precise map), and the setting deliberately provides no navigable, precise geographic map. But for the convenience of the GM and players, this directory now supplements three kinds of map resources:

  1) World Map (schematic)        -- Five Regions + Eight Great Powers + key landmarks, no precise coordinates
  2) Exploration Map (schematic)  -- routes / key points / threats, no precise distances
  3) Combat Map (precise distance data) -- grid + distance bands + positions + terrain + friendly/enemy placement

Design basis: Player Rulebook Sec.4.7 Distance/Position/Terrain, and Sec. Jianghu World faction chart / geography and customs; built by reviewing scene-by-scene the exploration and combat sequences of the two scenarios (s01_OneDragonScenario, s02_SoloScenario).

  Combat_TianjianRooftop.svg              Ch.5 Tianjian Alliance rooftop (Boss Ye Xiuluo)
  Combat_BloodMoonMainAltar.svg           Ch.5 Variant D / Solo Ch.5 Blood Moon Cult Main Altar corridor battle
  Combat_NorthernFrontierAltar.svg        Ch.6 Barbarian ancient altar (Great Shaman)
  Combat_YanmenPass.svg                    Ch.6 Yanmen Pass decisive battle (Boss Jin Ridi)

  Each combat map contains:
    - Grid (A- column / 1- row coordinate axes), friendly/enemy positions marked by colored circles at precise cells
    - Distance-band scale: adjacent=melee | 1 cell=one step | <=3 cells=three-step | >3 cells=far
    - Terrain overlay: high ground (+2 hit) / narrow (long weapon -3) / water (half movement) / half cover (DC+2) /
      full cover / destructible object / objective / threat zone
    - Tactical hints (based on scenario encounter data: HP, weakness, recommended tactics, positioning advice)

  Distance and movement reference (Sec.4.7):
    Normal move   = change 1 distance band (1 cell)
    Dash          = change 2 distance bands (2 cells)
    Lightfoot lunge = change 2 distance bands (2 cells), +1 hit on target next round
    Disengage     = change 1 distance band (1 cell) + lightfoot contest to avoid pursuit
  Positioning: front (default) / flank (+2 hit, requires Agility contest) / rear (+4 hit, cannot block)
  Ganging up: 2 attackers +1 / 3 attackers +2 (max 5 attackers)

IV. Coverage Check (two scenarios vs maps)
------------------------------------------------------------
  s01_OneDragonScenario (6 chapters):
    Exploration -> Explore_BlackWindStrongholdPath / LuoyangCity / EmeiBackMountainAndWanxiang /
                   QianjiPavilionHQ / WanxiangGrottoInterior / NorthernFrontierFrontline
    Combat      -> Combat_BlackWindStronghold / CamelAlley / EmeiBackMountainCave / QianjiPavilionNangongHui /
                   WanxiangGrottoMainHall / TianjianFrontCourtyard / TianjianRooftop /
                   BloodMoonMainAltar / NorthernFrontierAltar / YanmenPass
  s02_SoloScenario (6 chapters):
    Exploration -> shares the above 6 exploration maps with s01 (same locations)
    Combat      -> besides reuse, solo-version adjustments are noted in Combat_BlackWindStronghold / BloodMoonMainAltar
                   (e.g. solo version 2 Elites + 1 Minor Chief, Han Tieyi's ranged cover, etc.,
                   with solo / original differences annotated in each map's notes)
  Notes on scenes not separately mapped:
    - Ch.3 "three-way melee", Ch.4 "Duan Tianya's challenge (non-lethal)", Ch.6 "barbarian cavalry"
      etc. are folded into adjacent combat maps by tactical layout (QianjiPavilionNangongHui / TianjianRooftop /
      NorthernFrontierFrontline path); the GM may apply the distance bands directly per the notes.
    - Pure social / decision scenes (Tianjian Alliance choice, Plan B duel, etc.) need no map.
