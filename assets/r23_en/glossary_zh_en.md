# 永和武典 (Yonghe Martial Codex) — Chinese → English Glossary

> **Purpose.** This is the single source of truth for the Chinese→English translation of SET #25 "永和武典" (Yonghe Martial Codex TRPG). Read this FIRST before translating any other file. Every canonical term below must be used consistently across all translated documents.
>
> **Convention used in this glossary.** Game terms are given as **English Full Name (ABBR)** where an abbreviation exists. Proper nouns (people, sects, places) are given as **Pinyin (English gloss)** because wuxia proper nouns should keep their pinyin spelling (consistent with the `角色圖/` filename convention).
>
> **Pinyin / character-name rule (MANDATORY).** Character names MUST follow the spelling shown in the `sheets/角色圖/` filenames: surname + given name, each syllable capitalized, **no space in code/filename form** (e.g. `LiuRufeng`) but **spaced when written in prose** (e.g. "Liu Rufeng"). Translators MUST match these spellings. For any minor/enemy/unnamed card not listed here, apply the same pinyin convention by reading the characters (e.g. 山賊嘍囉 → "Shan Zei Loulou" / file "ShanZeiLoulou"; 血月教教徒 → "Xue Yue Jiao Jiaotu"). When a character also appears as a portrait file, prefer that file's exact spelling.
