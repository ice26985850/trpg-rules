## Reading Notes

### Data Format

Each martial technique includes the following fields:

| Field | Description |
|------|-------------|
| **Type** | External art (sword/staff-palm/saber/staff-bludgeon/hidden-weapon/finger/bare-hand/claw), Inner art (mental-method/hardening), Lightfoot, Special (medical-combat/poison-hidden/hidden-weapon) |
| **Tier** | Initiate / Advanced / Superior / Peerless |
| **Force** | Swift / Heavy / Firm / Gentle / Long-range / Subtle — determines move counter relationships (see Combat System §4.4.3) |
| **Qi Cost** | Qi consumed per use. Inner-art manuals note upkeep cost or passive bonus |
| **Hit Bonus** | Extra bonus to the hit check (inner-art manuals note "—") |
| **Damage** | Base damage + attribute-bonus method (inner/lightfoot note "—" or a bonus effect) |
| **Damage Type** | External Injury / Internal Injury / Poison / Mixed / Sealed Meridian |
| **Special Effect** | The move's unique tactical effect |
| **Attribute Requirement** | Minimum attributes needed to learn and use the move |
| **Affiliated Sect** | Sword Sect / Qi Sect / Vajra Sect / Poison Sect / Shadow Sect / Skill Sect / Medicine Sect / Independent |
| **Proficiency Requirement** | Required Martial Proficiency realm (First Glimpse / Minor Accomplishment / Complete Mastery / Perfecting the Craft / Transcendent) |

### Balance Reference

| Tier | Qi Cost | Hit Bonus | Damage Range | Note |
|------|---------|-----------|--------------|------|
| Initiate | 0–2 | +1 ~ +3 | 1d6 ~ 2d6 + attribute | Simple and practical, low cost |
| Advanced | 3–4 | +3 ~ +5 | 2d6 ~ 3d6 + attribute | Begins to have special effects |
| Superior | 5–7 | +4 ~ +7 | 3d6 ~ 4d6 + modifier×2 | Powerful effects, crit synergy |
| Peerless | 8–10 | +6 ~ +9 | 4d6 ~ 6d6 + special effect | Can change the battle |

### Technique Coverage Overview

| Dimension | Coverage |
|-----------|----------|
| Technique type | External 18, Inner 5, Lightfoot 4, Special 3 |
| Technique tier | Initiate 8, Advanced 10, Superior 8, Peerless 4 |
| Force type | Swift ×7, Heavy ×5, Firm ×6, Gentle ×4, Long-range ×3, Subtle ×6 (all ≥3) |
| Sect coverage | Sword Sect ×4, Qi Sect ×3, Vajra Sect ×4, Poison Sect ×3, Shadow Sect ×4, Skill Sect ×3, Medicine Sect ×2, Independent ×7 |
