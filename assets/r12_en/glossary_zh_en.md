# 《市井倖存者》英譯術語表 / Urban Survivors — Chinese→English Glossary

> **用法（重要）：** 所有翻譯 agent 必須先讀本表，鎖定以下官方英文譯名。
> 全文統一使用「英文全名（縮寫）」格式（例：`難度等級（DC）` → `Difficulty Class (DC)`、`精神狀態` → `Mental State`）。
> 未列出但出現的中文字詞，按字面與本表風格直譯，並在首次出現時附中文括註。
> 地名、人名、組織名按本表專名翻譯，**不要**音譯成拼音（Ostwin / Kolvannia / River Velta 等為已定英文名）。

---

## 一、遊戲名稱 / Game Title
- 市井倖存者 → **Urban Survivors** (TRPG 標題，全大寫視場合使用 *Urban Survivors*)
- 你不是英雄，你只是在圍城中努力活到明天的人 → "You are not a hero—you are just someone trying to survive to tomorrow in a city under siege."
- 跑團規則工作室 → Tabletop Rule Studio (設計工作室署名)

## 二、核心骰種 / Core Dice
- 3d6（三顆六面骰，貝爾曲線系統） → 3d6 (three six-sided dice, bell-curve system)
- 3d6 + 屬性值 → 3d6 + attribute value
- 4d6 取最高三顆 / 4d6k3 → 4d6 keep highest three
- 4d6 取最低三顆 → 4d6 keep lowest three
- 自然骰 → natural roll (the dice sum before modifiers)
- 總值 → total (dice + modifiers)

## 三、五大屬性 / The Five Attributes (範圍 0–5，20 點分配)
- 體魄（身體） → **Physique (PHY)**
- 機敏（敏捷） → **Agility (AGI)**
- 意志（意志） → **Willpower (WIL)**
- 社交（社交） → **Social (SOC)**
- 手藝（手藝） → **Craft (CRA)**

## 四、衍生屬性 / Derived Attributes
- 體力 → **Stamina** (體魄×2+5，每日行動點上限)
- 飽足度 → **Satiety** (0–10，初始 7)
- 溫暖度 → **Warmth** (0–10)
- 精神狀態 → **Mental State** (意志×2；歸零→崩潰狀態)
- 隱蔽值 → **Stealth** (機敏 + 環境掩體；敵方察覺的 DC)
- 察覺值 → **Awareness** (敵軍發現玩家的偵測值)

## 五、檢定結果分級 / Check Result Tiers
- 大失敗 → **Critical Failure**
- 失敗 → **Failure**
- 代價成功 → **Costly Success** (做到了但有代價)
- 成功 → **Success**
- 大成功 → **Critical Success**
- 難度等級（DC） → **Difficulty Class (DC)**
- 標準檢定（屬性檢定） → Standard Check (Attribute Check)
- 對抗檢定 → Contest Check
- 團隊檢定 → Group Check

## 六、優劣勢 / Advantage & Disadvantage
- 優勢 → **Advantage** (4d6 取最高三顆)
- 劣勢 → **Disadvantage** (4d6 取最低三顆)
- 正常 → Normal (3d6)

## 七、傷勢系統（取代 HP） / Wound System (replaces HP)
- 傷勢 → **Wound** (取代生命值；分級如下)
- 輕傷 → **Minor Wound**
- 重傷 → **Serious Wound**
- 致命傷 → **Fatal Wound**
- 防禦值 → **Defense Value**
- 傷害 → **Damage**
- 命中 → **Hit**

## 八、創傷與成長 / Trauma & Growth
- 創傷 → **Trauma**
- 創傷累積 → **Trauma Accumulation**
- 創傷烙印 → **Trauma Brand** (退伍軍人起始獲得)
- 適應性專長 → **Adaptive Talent**
- 崩潰狀態 → **Breakdown State** (精神狀態歸零)
- 脆弱點 → **Vulnerability** (學生職業起始額外獲得)

## 九、休息 / 力竭 / 士氣 / Rest, Exhaustion, Morale
- 短休息 → **Short Rest**
- 長休息（睡眠） → **Long Rest (Sleep)**
- 完整休息日 → **Full Rest Day**
- 力竭 → **Exhaustion** (等級 1–3)
- 士氣 → **Morale**: 鼓舞 **Inspired** / 正常 **Normal** / 低落 **Low**
- 安全環境 → safe environment
- 結構（避難所結構完整度） → structure (see 避難所)

## 十、命運點 / Fate Points
- 命運點 → **Fate Point (FP)** (初始 3，最多 5)
- 重擲 → reroll
- 規避代價 → avoid the cost

## 十一、時間時段 / Time of Day
- 黎明 → **Dawn**
- 白晝 → **Daytime** (狙擊手的時間)
- 黑夜 → **Night** (玩家的機會)

## 十二、避難所 / Shelter
- 避難所 → **Shelter**
- 結構完整度 → **Structural Integrity** (0–5)
- 密封度 → **Sealing** (0–5)
- 舒適度 → **Comfort** (0–5)
- 避難所改善行動 → Shelter Improvement Action

## 十三、角色創建 / Character Creation
- 創角九步驟 → Nine-Step Character Creation
- 戰前職業 → **Pre-war Profession** (12 種，非 Class)
- 自由技能選擇 → Free Skill Selection
- 保護對象 → **Protected One** (物品 or 人)
- 羈絆記憶 → **Bond Memory** (失去之人相關；每場遊戲限一次重擲意志)
- 隨身物品 → Personal Belongings
- 負重 → **Carrying Capacity** (體魄×2，最低 2 槽)
- 性格特質 → Personality Traits
- 口頭禪或習慣 → Catchphrase or Habit
- 秘密 → Secret
