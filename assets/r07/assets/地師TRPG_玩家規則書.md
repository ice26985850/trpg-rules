# 第一章：核心規則

## 1-1 核心判定系統

地師 TRPG 使用 **2d10 + 屬性值 + 技能等級** 對抗 **難度等級（DC）** 的判定系統。

### 檢定公式

```
檢定結果 = 2d10 + 屬性值 + 技能等級 + 裝備修正
成功條件：檢定結果 ≥ 難度等級（DC）
```

### 為何是 2d10？

兩顆十面骰的結果形成鐘形曲線——極端值（2 或 20）出現的機率僅 1%，而中間值（11）出現的機率高達 10%。這意味著：

- **技藝壓倒運氣**：熟練的地師不會有 5% 的機率犯低級錯誤
- **每一點修正都有意義**：在鐘形曲線的中段，每 +1 修正大約提升 5-10% 的成功率
- **大成功與大失敗稀有而珍貴**：雙 10 大成功（1%）、雙 1 大失敗（1%）

### 大成功與大失敗

| 擲骰結果 | 名稱 | 效果 |
|:---:|------|------|
| **雙 10（20）** | **大成功** | 自動成功，且獲得額外正面效果（GM 裁定） |
| **雙 1（2）** | **大失敗** | 自動失敗，且發生意外負面效果（GM 裁定） |

### 優勢與劣勢

某些情況下，檢定會獲得**優勢**或**劣勢**：

| 狀態 | 機制 | 等效修正 |
|------|------|:---:|
| **優勢** | 擲 3d10，取較高的兩個 | 約 +3.8 |
| **劣勢** | 擲 3d10，取較低的兩個 | 約 −3.8 |
| **雙重劣勢** | 擲 4d10，取較低的兩個 | 約 −5.5 |

> **恐懼劣勢**：當你的恐懼值超過恐懼閾值時，所有行動獲得劣勢。這是地師在墓中最常面對的狀態。

## 1-2 五大屬性

| 屬性 | 縮寫 | 含義 | 在盜墓中的角色 |
|------|:---:|------|------|
| **身手** | 身 | 敏捷、身法、體能——身體的執行力 | 閃避陷阱、攀爬墓道、近身格鬥 |
| **真氣** | 氣 | 內功修為、氣息運轉——內在能量的儲備與運用 | 施展武功招式、對抗屍毒、運氣護體 |
| **堪輿** | 輿 | 風水知識、墓葬格局、機關原理 | 分金定穴、識破機關、判斷墓室結構 |
| **通靈** | 靈 | 感知超自然、符咒效力、靈體溝通 | 開陰陽眼、畫符、與墓中的「東西」交涉 |
| **膽魄** | 膽 | 意志力、心理承受 | 抵抗恐懼、壓制屍氣威壓、在窒息中保持冷靜 |

### 屬性值含義

| 屬性值 | 敘事描述 |
|:---:|------|
| 1 | 極弱——幾乎不存在此能力 |
| 2–3 | 弱——低於常人 |
| 4–5 | 普通——常人水準 |
| 6–7 | 優良——經過訓練或天賦異稟 |
| 8–9 | 卓越——宗師級 |
| 10 | 傳奇——人類極限（僅可通過升級達到） |

## 1-3 衍生屬性

| 衍生屬性 | 縮寫 | 計算公式 | 用途 |
|------|:---:|------|------|
| **生命值** | HP | 身手 × 3 + 10 | 物理傷害承受上限 |
| **真氣池** | QP | 真氣 × 2 + 5 | 武功招式與法術的能量儲備 |
| **恐懼值** | 恐懼值 | 0（起始），動態累積 | 當前恐懼程度 |
| **恐懼閾值** | FT | 膽魄 × 2 + 5 | 恐懼耐受上限 |
| **陰陽感知** | YY | 10 + 通靈 | 被動感知超自然存在 |
| **屍毒抗性** | PR | 真氣 + 向下取整（膽魄 ÷ 2） | 對抗屍毒感染的檢定加值 |
| **防禦值** | DEF | 身手 + 裝備防禦修正 + 硬功修正 | 被攻擊時的命中門檻 |
| **先攻值** | INIT | 身手 + 向下取整（膽魄 ÷ 2） | 決定遭遇開始時的行動順序（固定值） |

### 生命值（HP）狀態

| HP 狀態 | 效果 |
|------|------|
| HP ≥ 50% | 正常狀態 |
| HP ＜ 50% | 輕傷——無額外懲罰，但 GM 應描述身體狀況 |
| HP ＜ 25% | 重傷——所有行動劣勢 |
| HP ≤ 0 | 昏迷倒地。每回合失去 1 HP（失血）。需同伴救治 |
| HP ≤ −身手 | 死亡 |

## 1-4 難度等級（DC）階梯

| DC | 難度 | 說明 | 範例 |
|:---:|------|------|------|
| **6** | 極易 | 幾乎不會失敗 | 在平地上行走、辨識常見物品 |
| **10** | 簡單 | 常人有一半以上機率成功 | 攀爬有落腳點的牆面、發現明顯的陷阱 |
| **14** | 中等 | 需要一定訓練 | 判斷墓室朝代、畫一道驅邪符 |
| **18** | 困難 | 需要專業水準 | 分金定穴找到隱藏古墓、畫鎮屍符 |
| **22** | 極難 | 宗師級挑戰 | 看穿疑塚、畫五雷符 |
| **26** | 傳奇 | 當世頂尖才能做到 | 與不化骨對話取得信任 |
| **30** | 近乎不可能 | 傳說中的事蹟 | 單人封印養屍地 |

# 第二章：角色創建

## 2-1 創角流程總覽（10 步驟）

```
出身背景 → 屬性配點 → 技能配點 → 主要傳承 → 法術傳承 → 所屬門派 → 招牌武功 → 第一張符 → 最糟的棺 → 團隊角色
```

# 第四章：戰鬥基礎（玩家視角）

## 4-1 行動經濟

每回合你可以執行以下動作組合：

| 動作類型 | 每回合次數 | 內容 |
|------|:---:|------|
| **主要動作** | 1 次 | 攻擊、使用道具、施展武功、畫符（戰鬥中）、開棺 |
| **移動動作** | 1 次 | 移動最多 30 尺（可放棄主要動作換第二次移動） |
| **反應動作** | 1 次（非自己回合） | 閃避（狸貓翻身）、護體功（運氣護體）、格擋 |
| **自由動作** | 不限 | 說話、丟下物品、切換手持裝備 |

### 移動與距離

本遊戲預設使用**劇院式心智（Theater of the Mind）**——GM 和玩家透過敘事理解戰場位置，不使用方格地圖。距離以「尺」標示供參考（1 尺 ≈ 30 公分）：

- **近戰範圍：** 5 尺以內。在此範圍內可進行近戰攻擊
- **一般移動：** 每回合 30 尺（約 9 公尺）。墓道中約可從隊尾走到隊頭
- **雙移動：** 放棄主要動作換第二次移動——總共 60 尺
- **困難地形：** 碎石、水淹、狹窄墓道——移動速度減半

### 閃避動作

若你沒有硬功或護體功，可使用**主要動作**執行閃避：本回合內你的 DEF +4（對抗近戰和遠程攻擊均有效），直到你下回合開始。此動作不需消耗真氣，但會消耗你的主要動作（即本回合無法攻擊）。

### 團隊合作檢定

當多位角色合作完成同一任務時：
- **協助者**進行相關檢定（DC 10）
- 若成功，**主要執行者**獲得**優勢**（擲 3d10 取較高的兩個）
- 最多 2 人協助同一檢定（即最多 3 人合作一項任務）
- 某些任務必須多人協作（如 S5 的鎮煞大陣需 3 位地師），無法單人完成

### 機會攻擊

當敵人在你的近戰範圍（5 尺）內，且未使用「撤退」動作就離開你的範圍時，你可以消耗**反應動作**進行一次近戰攻擊（通用攻擊公式：2d10 + 身手 + 械鬥）。此攻擊為正常命中判定，命中後造成武器基礎傷害（無真氣附加）。

## 4-2 攻擊判定

```
攻擊檢定 = 2d10 + 身手 + 相關技能 vs 目標防禦值（DEF）
```

- **命中**：攻擊檢定 ≥ 目標 DEF
- **未命中**：攻擊被閃避或擋下
- **大成功（雙 10）**：自動命中，傷害取最大值
- **大失敗（雙 1）**：自動失手，可能發生意外

### 武功攻擊 vs 通用攻擊

| 攻擊方式 | 公式 |
|------|------|
| **武功攻擊**（掌法、劍法等） | 2d10 + 身手 + 武功等級 |
| **通用攻擊**（無武功時應急） | 2d10 + 身手 + 械鬥技能等級 |

## 4-3 傷害計算

| 傷害類型 | 說明 | 來源範例 |

| **物理傷害** | 普通武器和徒手攻擊 | 拳腳、刀劍、陷阱 |
| **真氣傷害** | 真氣強化的攻擊 | 鐵砂掌、崩拳、摧心掌 |
| **符咒傷害** | 符咒產生的灼傷 | 驅邪符、五雷符 |
| **法器傷害** | 特殊法器對超自然的剋制 | 桃木劍、銅錢劍、百年桃木劍 |
| **精神傷害** | 直接影響心智的攻擊 | 怨靈的精神衝擊 |
| **環境傷害** | 墓中環境造成的傷害 | 毒氣、水銀、坍塌 |

## 6-3 休息與恢復

### 短休（10 分鐘）

在安全環境中短暫休息 10 分鐘。你可以：

- 消耗**生命骰**恢復 HP：每角色等級有一顆 d6 生命骰。消耗任意數量的生命骰，每顆恢復 `1d6 + floor(角色等級/2)` HP
- 進行打坐調息：每回合恢復 2 真氣（道門真傳 +3、玄空派心法持有者再 +1）
- 使用急救包（恢復 1d6 HP，每次冒險限一次）
- 恐懼值減半

生命骰在長休後全部恢復。

### 長休（8 小時，通常是過夜）

在安全的環境中完整休息 8 小時。效果：

- HP 恢復至最大值
- 真氣池恢復至最大值
- 恢復全部已消耗的生命骰
- 恐懼值歸零
- 消除一級「疲勞」狀態
- 陽氣損耗效果消除

> **冒險日建議：** GM 應設計讓玩家每 2-3 場戰鬥遭遇後有機會進行一次短休，每次冒險結束後進行長休。若玩家在墓中找不到安全休息點（如耳室、水銀河中島等），GM 應在敘事中提供替代方案（如符籙派的休息結界）。

### 睡眠不足

若玩家無法進行長休超過 24 小時，獲得一級「疲勞」（所有檢定 −1）。每額外 24 小時不休息，疲勞等級 +1。疲勞在進行一次完整的長休後全部消除。
