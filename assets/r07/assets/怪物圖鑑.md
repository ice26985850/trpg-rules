# 地師 TRPG —— 怪物圖鑑

> 所有怪物數據使用以下格式：
> 挑戰等級（CR） | 生命值（HP） | 防禦值（DEF） | 先攻值（INIT）

---

## 一、殭屍類

### 新屍（CR 0.5）

```
生命值（HP）：15
防禦值（DEF）：5–8（身手 1–3 + 無護甲 + 硬功 0）
先攻值（INIT）：+1–3
移動：10 尺（僵硬）

攻擊：
  爪擊——2d10+2 vs 防禦值（DEF），命中：1d6 物理傷害

特殊能力：
  - 無

弱點：
  - 陽光：陽光下每回合 1d6 傷害
  - 驅邪符：即死（無需傷害擲骰）
  - 鎮屍符：完全定身

戰術：本能攻擊最近目標。無戰術意識。
出現場合：S1 初試啼聲、剛屍變的新墓
```

### 白僵（CR 2–3）

```
生命值（HP）：30
防禦值（DEF）：12–13（身手 2–3 + 天生硬皮 ~9–10 + 硬功 0）
先攻值（INIT）：+2–4
移動：20 尺（雙臂前伸跳躍，無法轉彎或彎腰）

攻擊：
  雙爪揮擊——2d10+3 vs 防禦值（DEF），命中：1d6+2 物理 + 屍毒感染（DC 12）
  擒抱——2d10+3 vs 防禦值（DEF），命中：壓制（對抗身手 DC 14 掙脫）

特殊能力：
  - 跳躍撲擊：移動＋攻擊合併為一個動作，命中 +1
  - 屍氣威壓：10 尺內活人恐懼值 +1／回合

弱點：
  - 驅邪符：1d8 灼傷＋削弱（下回合攻擊劣勢＋移動減半）
  - 鎮屍符：完全定身（無需真氣注入）
  - 銅錢劍：額外 +1d4 灼傷傷害
  - 糯米：踩到 1d4 灼傷
  - 墨斗結界：無法穿越
  - 陽光：每回合 1d6 傷害

戰術：跳躍撲擊最近目標。優先攻擊移動最快者。無戰術意識。
出現場合：S1（變體）、S2、小型古墓
```

### 黑僵（CR 4–5）

```
生命值（HP）：50
防禦值（DEF）：14–16（身手 3–4 + 硬質皮膚 ~11–12 + 硬功 0）
先攻值（INIT）：+3–5
移動：25 尺（可自由走動但關節僵硬，像鎖死的木偶）

攻擊：
  爪擊撕裂——2d10+4 vs 防禦值（DEF），命中：2d6+3 物理 + 屍毒感染（DC 16）
  衝撞——2d10+4 vs 防禦值（DEF），命中：2d4+2 物理，目標擊退 10 尺＋倒地（DC 14）

特殊能力：
  - 生前記憶碎片：保留部分語言能力（可進行簡單對話）
  - 屍氣擴散：20 尺內活人恐懼值 +1／回合，真氣恢復 −1／回合
  - 硬質皮膚：物理傷害減免 −3
  - 狩獵本能：優先攻擊已受傷目標

弱點：
  - 驅邪符：效果減半（1d6 灼傷，削弱效果僅持續半回合）
  - 鎮屍符：需注入真氣（DC 18 畫符檢定）方可定住
  - 墨斗結界：無法穿越（金絲墨斗有效 3 小時）
  - 銅錢劍：正常傷害

戰術：有簡單戰術意識。會試圖孤立單一目標。若受傷會退後等待時機。
     可能願意對話——若玩家展示尊重或提及墓主生前關心之事。
出現場合：S2 將軍塚、中型古墓、被破壞封印的墓
```

### 跳屍（CR 6–7）

```
生命值（HP）：80
防禦值（DEF）：17–18（身手 5–6 + 銅皮鐵骨 ~12 + 硬功 0）
先攻值（INIT）：+5–7
移動：30 尺（行動自如，外表與活人無異，可奔跑跳躍）

攻擊：
  鋼爪斬——2d10+6 vs 防禦值（DEF），命中：3d6+4 物理 + 屍毒感染（DC 20）
  撕裂擒抱——2d10+6 vs 防禦值（DEF），命中後每回合自動 2d6（對抗身手 DC 18 掙脫）
  投擲——2d10+5 vs 防禦值（DEF），命中：2d8 物理，目標倒地

特殊能力：
  - 銅皮鐵骨：普通兵器傷害 0。物理傷害減免 −5
  - 高階屍氣：30 尺內恐懼值 +2／回合。膽魄 DC 16 否則恐慌
  - 跳躍突襲：可從 40 尺外跳躍攻擊，先攻檢定優勢
  - 殘留意識：保留部分生前記憶和戰鬥技巧
  - 完全偽裝：外表與活人無異（CR 7 時）

弱點：
  - 驅邪符：僅能逼退數步（1d4 傷害）
  - 鎮屍符：僅能定住數分鐘（而非數小時）
  - 五雷掌／五雷符：3d8 法器傷害（可劈開體表）
  - 法器（桃木劍／銅錢劍／百年桃木劍）：正常傷害
  - 硬功大成（LV12 武師）：徒手攻擊視為法器

戰術：聰明且致命。優先攻擊符法師（威脅最大）。懂得利用環境。會佯攻。
     若保留較多生前記憶，可能願意對話——但比黑僵更難說服。
出現場合：S5 養屍地、高階古墓、帝王陵護衛
```

### 跳屍·飛屍（CR 8–9，跳屍變體）

```
生命值（HP）：65
防禦值（DEF）：19–20（身手 6–7 + 銅皮鐵骨 ~13 + 硬功 0）
先攻值（INIT）：+7–8
移動：30 尺（地面）+ 飛行 40 尺

攻擊（繼承跳屍全部攻擊，並增加）：
  俯衝抓取——飛行中攻擊，2d10+7 vs 防禦值（DEF），命中後抓取目標飛至高空
  高空拋摔——被抓起後下一回合拋下，4d6 墜落傷害

特殊能力（繼承跳屍全部能力，並增加）：
  - 飛行：40 尺飛行速度
  - 高空優勢：對地面目標攻擊優勢
  - 掠奪俯衝：俯衝攻擊後可立即飛行離開（不觸發藉機攻擊）

弱點：同跳屍。額外弱點——狹窄空間限制飛行（室高小於 10 尺時無法飛行）
出現場合：S4 鬼市交易（玉棺中的怨靈）、S7 帝陵、高階封印物內容
```

### 不化骨（CR 10–12）

```
生命值（HP）：120
防禦值（DEF）：22–24（身手 7–8 + 千年屍身 ~15–16 + 硬功 0）
先攻值（INIT）：+7–9
移動：30 尺（完全自如，可偽裝成人類混入人群）

攻擊：
  碎骨擊——2d10+8 vs 防禦值（DEF），命中：4d6+5 物理 + 屍毒感染（DC 24）
  橫掃——2d10+7 vs 防禦值（DEF），命中：2d8+3 物理，15 尺錐形範圍
  精神震懾——膽魄 DC 20，失敗：震懾 1 回合＋恐懼值 +4

特殊能力：
  - 刀槍不入：普通兵器傷害 0。物理傷害減免 −8
  - 水火不侵：火焰／環境傷害無效
  - 偽裝成人：外表與活人完全無異。可完美模仿人類行為
  - 千年屍氣：50 尺內恐懼值 +3／回合。膽魄 DC 18 否則恐慌
  - 不死意志：HP 降至 0 時，膽魄 DC 22，成功則以 1 HP 繼續戰鬥（每戰一次）
  - 完全智能：可制定複雜策略、操控他人、進行長期計劃
  - 語言之主：可完美使用人類語言（甚至多種方言）

弱點：
  - 普通符咒：完全無效
  - 鎮屍符：貼上即自燃
  - 僅法器（百年桃木劍／斬龍劍／天師符）或五雷掌能造成有效傷害
  - 生前執念：可能是唯一的非戰鬥解決途徑

戰術：極度危險。先精神震懾全隊，再優先擊殺符法師。會撤退、設伏、利用人質。
     遇到強力抵抗時會撤退並重新計劃。最危險的不是力量——是智慧。
出現場合：S6 不化骨、S7 帝陵、隱藏的最終威脅
```

## 二、靈體類

### 滯留靈（一般）

```
挑戰等級（CR）：1–2
生命值（HP）：20（虛體——僅法器／符咒可命中）
防禦值（DEF）：10（虛體——普通物理攻擊自動失手）
先攻值（INIT）：+3
移動：20 尺（飄浮）

攻擊：
  精神干擾——膽魄 DC 12，失敗：1d4 精神傷害＋恐懼值 +1

弱點：法器、符咒、完成執念
出現場合：S1 三姨太、各墓中的次要靈體
```

### 怨靈／厲鬼

```
挑戰等級（CR）：3–6
生命值（HP）：30–50（虛體——僅法器／符咒可命中）
防禦值（DEF）：14（虛體——普通物理攻擊自動失手）
先攻值（INIT）：+4–6
移動：30 尺（飄浮，可穿牆）

攻擊：
  精神衝擊——膽魄對抗 DC 14–18，失敗：2d6 精神傷害＋恐懼值 +2
  控物攻擊——2d10+4 vs 防禦值（DEF），命中：2d4 物理（控制無主物品擲物）
  附身——意志堅守 DC 16–20，失敗：身體被控制 1d4 回合

特殊能力：
  - 虛體：普通物理攻擊自動失手
  - 穿牆：可穿過任何非附魔實體障礙
  - 靈體顯現：可選擇性讓特定人看到
  - 執念鎖定：若玩家與執念有關，攻擊優勢

弱點：
  - 法器／符咒正常傷害
  - 驅邪符：1d8 灼傷
  - 破穢符：強制退散
  - 完成執念：和平解決的唯一方式

出現場合：S3 水銀迷宮（工匠怨靈）、S4 玉棺中的怨靈、各墓中的冤魂
```

## 三、精怪類

### 狐仙／精怪

```
挑戰等級（CR）：3–8（取決於年齡和修為）
態度：友善中立——有自己的利益和底線
交涉難度等級（DC）：14–18

特性：
  - 可交流談判，有完整智能
  - 不會無故傷人也不會無故助人
  - 喜歡以物易物的公平交易
  - 對人類世界有一定了解但不完全
  - 可能擁有獨特的情報或能力

出現場合：S4 鬼市交易、野外遭遇、古墓附近的靈地
```

## 四、環境威脅

### 鬼打牆

```
觸發條件：陰氣濃度 ≥ 4 的區域，或特定怨靈刻意製造
效果：玩家無論怎麼走都回到原點
持續：直到被破解

破解方式：
  1. 陰陽眼看穿——DC 14
  2. 羅盤導航——DC 16
  3. 開光八卦鏡——消耗 2 真氣，自動成功
  4. 引路符——自動成功（消耗 1 張符）
  5. 閉眼倒走——膽魄 DC 14（民間偏方）
```

### 養屍地

```
效果（區域）：
  - 區域內所有不死生物獲得優勢檢定
  - 區域內所有活人真氣恢復 −1／回合
  - 區域內屍變概率 ×3
  - 區域邊界墨斗結界持續時間減半

破解：鎮煞大陣（需 3 位地師協作，DC 14）或修復鎮物（DC 16）
```
