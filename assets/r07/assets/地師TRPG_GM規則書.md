## 第一章：核心判定系統

### 1-1 檢定公式

```
檢定結果 = 2d10 + 屬性值 + 技能等級 + 裝備修正
成功條件：檢定結果 ≥ 難度等級（DC）
```

### 1-2 大成功與大失敗

| 擲骰結果 | 效果 |
|:---:|------|
| 雙 10（20） | 大成功——自動成功，額外正面效果 |
| 雙 1（2） | 大失敗——自動失敗，意外負面效果 |

## 第三章：戰鬥完整規則

### 3-1 戰鬥流程

#### 回合順序

```
1. 先攻確定（INIT 固定值，最高者先行）
2. 每回合循環：
   a. 玩家／敵人依先攻順序行動
   b. 每個角色：主要動作 + 移動動作 + 自由動作（不限）
   c. 反應動作可在非自己回合使用
3. 回合結束——狀態效果結算
```

#### 先攻平手處理

```
INIT 平手 → 身手高者先行
身手平手 → 膽魄高者先行
膽魄平手 → 同時行動（傷害同時結算）
```

### 3-2 行動經濟

| 動作類型 | 次數 | 內容 |
|------|:---:|------|
| **主要動作** | 1 | 攻擊、使用道具、畫符（戰鬥）、施展武功、開棺、驅邪儀式 |
| **移動動作** | 1 | 移動 30 尺。可放棄主要動作換第二次移動（雙移動） |
| **反應動作** | 1/輪 | 閃避（狸貓翻身）、運氣護體、藉機攻擊 |
| **自由動作** | 不限 | 說話、丟物品、切換武器 |

### 3-3 攻擊與防禦系統

#### 攻擊判定

```
攻擊檢定 = 2d10 + 身手 + 武功等級（或械鬥技能）
目標 DEF = 身手 + 裝備防禦修正 + 硬功修正
命中條件：攻擊檢定 ≥ 目標 DEF
```

#### 怪物防禦值參考

| 怪物 | DEF | 說明 |
|------|:---:|------|
| 新屍 | 5–8 | 剛屍變，肢體僵硬 |
| 白僵 | 12–13 | 體生白毛，身手 2–3 + 天生硬皮 |
| 黑僵 | 14–16 | 體色轉黑，身手 3–4 + 硬質皮膚 |
| 跳屍 | 17–18 | 銅皮鐵骨，身手 5–6 |
| 跳屍·飛屍（變體） | 19–20 | 可飛行，身手 6–7 |

| 怨靈（虛體） | 14（僅法器可命中） | 無實體，普通攻擊自動失手 |

### 3-4 傷害系統

#### 傷害公式

**物理傷害：**
```
最終傷害 = 武器基礎傷害 + 真氣附加傷害 − 目標傷害減免
```

**符咒傷害（對超自然）：**
```
最終傷害 = 符咒基礎傷害（無視物理減免）
```

#### 傷害類型

| 類型 | 說明 | 可傷目標 |
|------|------|------|
| 物理 | 普通武器、徒手 | 活人、生物（對殭屍減免或無效） |
| 真氣 | 掌法、武功附加 | 所有目標（對不化骨減免） |
| 符咒 | 驅邪符、五雷符等 | 殭屍、靈體（對活人無效） |
| 法器 | 桃木劍、銅錢劍 | 殭屍、靈體 |
| 精神 | 怨靈攻擊 | 活人、有意識的殭屍 |
| 環境 | 毒氣、火焰、坍塌 | 所有目標 |

### 3-8 屍毒感染規則（完整流程）

#### 感染觸發

當角色被殭屍爪擊命中且造成傷害時，觸發屍毒感染檢定：

```
屍毒對抗檢定 = 2d10 + 屍毒抗性（PR） vs 屍毒 DC

屍毒 DC：
  白僵抓傷：DC 12
  黑僵抓傷：DC 16
  跳屍抓傷：DC 20
  不化骨抓傷：DC 24
```

#### 感染階段

| 階段 | 效果 | 進展條件 |
|------|------|------|
| **潛伏期** | 無明顯症狀（持續 1 小時） | — |
| **輕度感染** | 每小時 −1 HP | 每小時 PR 檢定 DC 12，失敗則惡化 |
| **中度感染** | 每回合 −1 HP，所有行動劣勢 | 10 分鐘內 PR 檢定 DC 16，失敗則惡化 |
| **重度感染** | 每回合 −2 HP，無法行動 | 每分鐘 PR 檢定 DC 20，失敗則死亡後屍變為新屍 |

| 方式 | 效果 | 條件 |
|------|------|------|

#### GM 控制恐懼值的技巧

- **不要讓恐懼值長期為 0**——墓中應該一直有輕微的壓迫感
- **在安全點（耳室休息）時讓恐懼值緩慢消退**——給玩家喘息的空間
- **恐懼值接近閾值時是戲劇張力最強的時刻**——放慢節奏，加強環境描述
- **超過閾值不等於遊戲結束**——劣勢機制讓玩家仍然可以行動，只是更困難
- **崩潰狀態應極少出現**——這通常是玩家連續決策失誤的結果，而非 GM 的懲罰

### 4-6 遭遇難度設計

#### TTV（總威脅值）公式

```
TTV = Σ（每個怪物的 CR × 數量） × 環境係數

環境係數：
  開闊空間 = 0.8
  標準墓室 = 1.0
  狹窄墓道 = 1.2（殭屍優勢——無法閃避）
  煞氣濃郁區 = 1.5
```

#### 難度對照表（以 4 人隊為基準）

| 玩家平均等級 | 簡單 TTV | 中等 TTV | 困難 TTV | 極難 TTV |
|:---:|:---:|:---:|:---:|:---:|
| 1–3 | 2–6 | 6–10 | 10–14 | 14–18 |
| 4–6 | 6–12 | 12–16 | 16–20 | 20–24 |
| 7–9 | 12–18 | 18–24 | 24–28 | 28–34 |
| 10–12 | 18–24 | 24–30 | 30–36 | 36–42 |
| 13–15 | 24–30 | 30–38 | 38–44 | 44–52 |

#### 人數調整

```
TTV 調整後 = TTV 基準 × (玩家數 ÷ 4)

1 人：× 0.6（且必須提供 NPC 同伴）
2 人：× 0.75
3 人：× 0.9
4 人：× 1.0（基準）
5 人：× 1.15
```

#### 遭遇構築六原則

1. **恐怖遞進**：先讓玩家感受不對勁 → 再看到威脅 → 最後才正面對抗
2. **環境即武器**：墓室結構本身就是威脅——狹窄通道、坍塌風險、毒氣區域
3. **非戰鬥選項**：每次遭遇都應至少有一種非戰鬥的解決途徑（對話、繞路、談判）
4. **三波節奏**：遭遇應分波次出現（探索→輕度威脅→核心威脅），不要一次全部投入
5. **資源壓力**：每次遭遇應消耗資源（HP/QP/符紙/丹藥），讓玩家在兩次遭遇間感到緊張
6. **撤退是選項**：不是每次遭遇都必須打贏。逃跑是合理的策略，設計時應預留退路

## 第六章：GM 敘事指南

### 6-1 恐怖氛圍營造——五感描述法

| 感官 | 描述方向 | 範例 |
|------|------|------|
| **視覺** | 光線不足、顏色異常、影子移動 | 「火把的光只能照到前方三步——三步之外，黑暗好像有實體，在慢慢向你擠壓。」 |
| **聽覺** | 寂靜中的細微聲音、不該有的聲音 | 「你聽到身後有水滴滴落的聲音——但在這個深度，不可能有水。滴答。滴答。它越來越近了。」 |
| **嗅覺** | 腐敗、潮濕、異常的甜味 | 「空氣中有一股甜膩的腐味——不是屍體的腐臭，更像是陳年的蜜糖和腐爛的花混合在一起。」 |
| **觸覺** | 溫度驟降、不正常的濕度 | 「你的手摸到墓牆——它不應該是溫熱的。石頭在這個深度應該是冰冷的。但它不是。」 |
| **直覺** | 被注視感、難以言說的不安 | 「你沒有看到任何東西。你的羅盤也沒有異常。但你就是知道——有什麼東西在看著你。」 |

### 6-2 三層線索法

| 層級 | 獲取方式 | 揭露內容 |
|------|------|------|
| **表層線索** | 無需檢定，觀察即可 | 環境描述、明顯的物品、可見的痕跡 |
| **中層線索** | DC 10–14 檢定 | 墓的年代、風水格局、墓主大致身分 |
| **深層線索** | DC 16–20 或特定條件 | 墓主的祕密、執念的真相、隱藏區域入口 |

- 每個新墓室至少給一條表層線索 + 一條可獲得的中層線索
- 深層線索應與劇情核心掛鉤
- 錯過線索時準備替代路徑

### 6-3 節奏控制循環

```
探索 → 緊張 → 釋放 → 再緊張
  │       │       │       │
 線索    遭遇    安全點   循環
 環境    威脅    喘息
```

- 不要連續觸發兩個高強度遭遇
- 「安靜」本身可以是恐怖——讓玩家在無威脅環境中感到不安
- 每次遭遇都應消耗資源

### 6-4 「是的，而且……」原則

- 玩家說「我用羅盤感應陰氣流動」→ 不要說「檢定失敗了什麼也感覺不到」
- 而是說：「羅盤的指針劇烈顫動，但方向混亂——說明陰氣被某種東西刻意擾亂。你能感覺到來源在更深處，但具體位置需要更接近才能確定。」
- **失敗創造新的敘事分支，而不是敘事的終點。**

### 6-5 單人遊戲調整

單人地師下墓極度危險——陽氣不足。

| 調整項目 | 規則 |
|------|------|
| 威脅數量 | 降至正常的 60%（TTV × 0.6） |
| NPC 同伴 | 必須提供至少一個（師兄弟、幫手、被救者） |
| 環境解謎 | DC 不變（智力挑戰與人數無關） |
| 陽氣不足 | 陰氣相關檢定 DC +2 |
| 額外資源 | 起始攜帶雙倍符紙和醫療用品 |

### 6-6 羅盤使用的敘事層次

| 檢定結果 | 敘事範例 |
|------|------|
| **大失敗** | 「羅盤指針瘋狂旋轉——要嘛附近有極強煞氣源，要嘛你的羅盤壞了。你無法確定。」 |
| **失敗** | 「指針微微偏移，但讀數不穩定。能感覺到有東西，無法精確定位。」 |
| **成功** | 「羅盤穩定指向西北——磁針沉降三度，煞氣來源在下方，約二十丈。」 |
| **大成功** | 「磁針的震動模式告訴你這不是一般的屍變。震動頻率對應黑僵級別以上，而且……不止一隻。」 |

## 第八章：陪葬品與詛咒系統

### 8-1 陪葬品靈性狀態鑑定

| 狀態 | DC | 市場價值 | 風險 |
|------|:---:|:---:|------|
| 乾淨 | 6 | 正常市價 | 無 |

| 被詛咒 | 18 | 無法正常出售 | 見詛咒表 |
| 鎮物 | 22 | 不出售 | 取出釋放被封印之物 |

### 8-2 詛咒效果表（d10）

| d10 | 詛咒 | 解除 |
|:---:|------|------|
| 1 | 噩夢纏身：長休 DC 12 意志檢定，失敗無法恢復真氣 | 符籙派淨化 DC 14 |
| 2 | 陰煞吸引：遭遇超自然概率翻倍 | 送回原墓 |
| 3 | 運勢衰敗：自然骰 1–2 均為大失敗 | 完成墓主遺願 |
| 4 | 體溫流失：體質相關檢定劣勢 | 正午陽光曝曬七天 |
| 5 | 幻覺：GM 每回合暗投 d6，6 = 幻覺 | 高級符法淨化 DC 18 |
| 6 | 墓主呼喚：每週意志 DC 14，失敗強制返回 | 返回並完成要求 |
| 7 | 生命汲取：每日 −1 暫時 HP | 破壞物品或地脈淨化 |
| 8 | 語言詛咒：無法說出特定詞語 | 公開真相 |
| 9 | 血脈詛咒：傳承給下一代 | 三代贖罪 |
| 10 | 墓主佔據：被墓主意志取代 | 意志對抗 DC 18 或驅邪 DC 22 |

### 8-3 特殊陪葬品類型

| 類型 | 說明 | GM 使用建議 |
|------|------|------|
| **鎮物** | 放在棺中鎮壓某物的法器。取出它 = 釋放那個東西 | 終極道德困境——拿還是不拿？ |
| **墓主遺物** | 帶有墓主強烈執念的物品。持有者會看到墓主記憶片段 | 既是線索也是陷阱。可用於推進劇情 |
| **封印容器** | 表面是普通陪葬品，實則是封印物。打開 = 釋放 | 經典恐怖橋段——好奇心害死貓 |
| **贗品** | 精緻仿品。可能誤導玩家對墓主身分的判斷 | 疑塚的第二層防護 |
| **詛咒陷阱** | 看起來最有價值的物品——實際上被下了最強的咒 | 考驗玩家的古物鑑定能力 |

## 第九章：隨機遭遇表

當玩家偏離劇本探索、或 GM 需要即興填充墓中內容時，擲 d20：

| d20 | 遭遇類型 | 內容 |
|:---:|------|------|
| 1–5 | **寂靜** | 什麼都沒有——但寂靜本身就是墓中最可怕的東西。GM 進行環境描述，可讓玩家進行感知檢定 |
| 6–7 | **環境威脅** | 塌方（DC 12 閃避，失敗 1d6）、毒氣（體質 DC 12）、濕滑地面（身手 DC 10 避免摔倒） |
| 8–9 | **次要發現** | 壁畫／銘文（DC 12 墓室解讀獲得墓主線索）、前人遺留物（破損工具、乾涸的血跡） |
| 10–11 | **痕跡** | 殭屍拖行痕跡（追蹤 DC 14）、糯米殘留（前一批盜墓者留下的）、燒過的符紙灰燼 |
| 12–13 | **次要靈體** | 無害滯留靈（可對話獲得情報 DC 14）、徘徊的動物靈 |
| 14–15 | **陷阱** | 弩箭（DC 12 閃避，2d4）、翻板（DC 14 察覺）、落石（DC 14 閃避，2d6） |
| 16 | **物資** | 前人遺留的補給（1d4：1=急救包 2=乾糧 3=繩索 4=火摺子） |
| 17 | **新屍 ×1** | CR 0.5，HP 15。可能剛從棺材中爬出 |
| 18 | **白僵 ×1** | CR 2，HP 25。正在巡邏或進食 |
| 19 | **黑僵 ×1 + 線索** | CR 4，HP 45。擊敗後可找到墓主相關線索 |
| 20 | **特殊發現** | GM 決定：隱藏耳室（含額外陪葬品）、封印物、或一個友善的精怪 |

> **使用建議：** 同一區域不要連續觸發兩次戰鬥遭遇。兩次 d20 結果之間至少間隔一個墓室／一段探索。
