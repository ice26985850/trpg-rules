# 神之影（S11）
> 季：第 3 季「遠征之章」
**基本資訊**
- **建議等級**：Lv.50-57
- **難度**：困難
- **預期長度**：2-3 次跑團
- **遊玩模式**：預設多人模式（1 名 GM + 多名玩家）；亦支援單人模式（1 名 GM + 1 名玩家），見文末「單人模式調整」
## 核心衝突

科塔爾（狼神）的分身投影首次出現在裂縫中——不是完整的主神，但已足夠強大。玩家必須擊退這個投影。
