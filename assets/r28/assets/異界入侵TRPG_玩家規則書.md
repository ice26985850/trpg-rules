# 第一章：核心規則

## 1.1 骰子系統

本遊戲使用 **d100 百分位骰**。

| 模式 | 公式 | 場景 |
|------|------|------|
| 擲低即成功 | d100 ≤ 目標百分比 | 攻擊命中 |
| 擲高即成功 | d100 + 調整值 ≥ 難度等級（DC） | 技能檢定、屬性檢定 |

## 1.2 六維屬性

| 屬性 | 縮寫 | 主要影響 |
|------|------|---------|
| 力量（STR） | 物理攻擊力、負重 |
| 敏捷（DEX） | 先攻、閃避率、暴擊率 |
| 體質（CON） | 生命值（HP） 上限、物理減傷 |
| 智力（INT） | 魔法攻擊力、破解 |
| 感知（WIS） | 命中率、偵查 |
| 精神（SPI） | 魔力值（MP） 上限、精神抗性 |

**階梯花費**：10 以下 = 1點, 11-20 = 1點, 21-40 = 2點, 41-60 = 3點, 61-80 = 4點, 81-100 = 5點, 101+ = 6點。

> 屬性基礎值為 10。創角時 30 屬性點自由分配。屬性點不足時允許多級跳躍（例如從 10 直接升到 40 需 10×1 + 10×2 = 30 點）。

## 1.3 衍生屬性

| 屬性 | 縮寫 | 公式 |
|------|------|------|
| 生命值（HP） | 體質（CON） × 10 + 角色等級 × 5 |
| 魔力值（MP） | 精神（SPI） × 5 + 角色等級 × 3 |
| 物理攻擊力（PATK） | 力量（STR） × 2 + 武器加值 |
| 魔法攻擊力（MATK） | 智力（INT） × 2 + 武器加值 |
| 物理防禦力（PDEF） | 體質（CON） × 1.5 + 防具加值 |
| 魔法防禦力（MDEF） | 精神（SPI） × 1.5 + 防具加值 |
| 命中率（HIT%） | 50% + 感知（WIS） × 3%（上限 95%） |
| 閃避率（DGE%） | 10% + 敏捷（DEX） × 2%（上限 60%） |
| 暴擊率（CRT%） | 5% + 敏捷（DEX） × 1% |

> **技能傷害**：技能的最終傷害取決於角色攻擊力與職業等級的疊加：
> **技能最終傷害 =（攻擊力 + 技能基礎威力）×（1 + 職業等級 ÷ 20）**
> 物理技能使用 物理攻擊力（PATK），魔法技能使用 魔法攻擊力（MATK）。

## 1.4 攻擊判定

1. 計算 **有效命中率（EHit%）** = 命中率（HIT%） − 目標 閃避率（DGE%）（min 5%, max 95%）
2. 擲 d100
3. 判定：1-5 = 大成功（必中+暴擊+額外效果）、96-100 = 大失敗（必失+負面後果）、6-95 = d100 ≤ 有效命中率（EHit%） → 命中（若 ≤ 暴擊率（CRT%） → 暴擊）
4. 傷害 = max（攻擊力 − 防禦力, 1），暴擊 ×1.5（大成功 ×2.0）
5. 若為技能攻擊：最終傷害 = max（（攻擊力 + 技能基礎威力） × (1 + 職業等級 ÷ 20) − 目標對應防禦力, 1）

## 1.5 技能檢定

> d100 + (屬性 + 被動加值) ≥ 難度等級（DC）

| 難度等級（DC） | 難度等級（DC） | 難度 |
|----|------|----|------|
| 20 | 簡單 | 80 | 困難 |
| 40 | 普通 | 100 | 極難 |
| 60 | 中等 | 120+ | 史詩 |

## 1.6 優勢／劣勢

擲 2d100，攻擊取低、檢定取高（優勢）；反之（劣勢）。多個不疊加。

# 第二章：角色創建

## 2.1 創角步驟

| 步驟 | 內容 |
|------|------|
| 1. 背景 | 選擇現代背景（見 §2.2）→ 獲得屬性加成和背景特性 |
| 2. 覺醒場景 | 擲骰或自選（見 §2.3） |
| 3. 屬性配點 | 基礎 10，30 屬性點自由分配（階梯花費） |
| 4. 衍生屬性 | 計算 生命值（HP） / 魔力值（MP） / 物理攻擊力（PATK） / 魔法攻擊力（MATK） / 物理防禦力（PDEF） / 魔法防禦力（MDEF） / 命中率（HIT%） / 閃避率（DGE%） / 暴擊率（CRT%） |

| 8. 初始裝備 | 公會配給 E 級套裝 + 50 金幣（G） 補助金 |
| 9. 動力 | 為什麼戰鬥？ |

# 第三章：主職業（戰鬥職業）

## 3.1 通用規則

- 技能不再有 Lv.1-10。**你會就是會、不會就是不會。**
- 技能傷害 = **（攻擊力 + 技能基礎威力） × (1 + 該職業等級 ÷ 20)**，物理技能用 物理攻擊力（PATK），魔法技能用 魔法攻擊力（MATK）。
- 技能解鎖節點：Lv.1（2技能+特性）、Lv.3、Lv.6、Lv.10（特性進化）、Lv.15（分支選擇）、Lv.20、Lv.30（特性進化）、Lv.40（大師技）、Lv.50（終極特性）
- 不同職業的技能獨立——前鋒不能用術士的技能（除非你也練了術士）

# 第七章：戰鬥規則（玩家視角）

## 7.1 戰鬥框架

- **回合制**：每回合約 6 秒。先攻 = 敏捷（DEX） + d20，高者先行，順序固定。
- **行動經濟**：每回合可執行：
  - 1 個標準動作（攻擊、使用技能、投擲炸彈、使用物品）
  - 1 個移動動作（移動至相鄰區域）
  - 1 個迅捷動作（切換武器、簡單互動、戰場急救等）
  - 1 個反應動作（藉機攻擊等，在他人回合觸發）
- 動作可向下互換：標準→移動→迅捷。

## 7.2 區域制地圖

| 距離級別 | 區域差距 | 說明 |
|---------|:--:|------|
| 同區域 | 0 | 同一房間，近戰可攻擊 |
| 近距 | 1 | 相鄰房間，需移動 1 動作 |
| 中距 | 2-3 | 需衝刺（標準+移動） |
| 遠距 | 4-5 | 需多回合移動或遠程武器 |
| 超遠距 | 6+ | 視線盡頭，只有狙擊手可攻擊 |

**移動選項**：普通移動 1 區（1 移動動作）／衝刺 2 區（標準+移動）／謹慎移動 1 區（不觸發藉機攻擊）。

## 7.3 攻擊判定

1. 計算 有效命中率（EHit%） = 命中率（HIT%） − 目標 閃避率（DGE%）（min 5%, max 95%）
2. 擲 d100
3. 判定：1-5 = 大成功（必中+暴擊）、96-100 = 大失敗（必失）、6-95 與 有效命中率（EHit%） 比較
4. 命中時：若 d100 ≤ 暴擊率（CRT%） → 暴擊（傷害 ×1.5，大成功 ×2.0）
5. 結算：傷害 = max（攻擊力（ATK） − 目標 防禦力（DEF）, 1）。技能傷害 = max（（攻擊力 + 基礎威力）× (1+職業等級÷20) − 目標對應防禦, 1）

## 7.4 狀態效果（玩家常見）

| 狀態 | 效果 | 典型來源 |
|------|------|------|
| 暈眩 | 跳過下一回合 | 猛擊、盾擊 |
| 流血 | 每回合 物理攻擊力（PATK） × 0.2 × 層數 生命值（HP） 損失 | 旋風斬、血怒 |
| 燃燒 | 每回合 5 × 層數 魔力值（MP） 損失 | 爆破彈、元素爆發（火焰） |
| 冰凍 | 不能移動、物理防禦力（PDEF） +30% | 元素爆發（冰霜） |
| 麻痺 | 25% 動作失敗 | 元素爆發（雷電）、影縛 |
| 中毒 | 每回合 3 × 層數 生命值（HP） 損失 | 毒霧、毒屬性攻擊 |
| 強化 | 攻擊力 +30% | 戰吼、強化藥劑 |
| 護盾 | 獲得臨時 生命值（HP） = 精神（SPI） × 3 | 魔力護盾 |

## 7.5 生命值歸零

生命值（HP） ≤ 0 時進入**瀕死狀態**：
1. 無法行動
2. 每回合結束進行 體質（CON） 檢定（d100 + 體質（CON） ≥ 難度等級（DC） 60）：成功 3 次 → 穩定（生命值（HP）=1，無法繼續戰鬥）；失敗 3 次 → 死亡
3. 大成功（1-5）：立刻穩定。大失敗（96-100）：算兩次失敗
4. 被攻擊時每次算一次失敗
5. 隊友使用急救（難度等級（DC） 60）可立即穩定

### 死亡

角色死亡後，可透過以下方式復活：
- 莉莉絲的犧牲復活（神授技能，需生命織者神祇職業）
- 傳說級復活道具（GM 裁決，極稀有）
- 部分劇本特殊條件下的劇情復活

死亡懲罰（由 GM 選擇）：失去一件裝備／永久失去 5 屬性點／角色等級 −1。

## 7.6 休整

- **短休整**（10 分鐘）：使用藥水回復，快速恢復被動生效。
- **長休整**（8 小時）：生命值（HP）/魔力值（MP） 完全回復，每日次數重置。
