# 異界入侵 TRPG —— 鍛造·煉金·烹飪 完整規則

# 一、共通規則

## 1.1 製作流程（三職業通用）

| 步驟 | 說明 |
|:--:|------|
| 1 | **準備材料**——收集所需素材（見各配方表） |
| 2 | **進行檢定**——擲 d100 + 對應屬性 ≥ 難度等級（DC） |
| 3 | **結算結果**——成功／大成功／失敗／大失敗 |
| 4 | **產出物品**——獲得成品或損失材料 |

## 1.2 檢定公式

```
製作檢定 = d100 + 對應屬性 + 職業等級 × 2
```

| 職業 | 對應屬性 |
|------|---------|
| 鍛造師 | 力量（STR） |
| 煉金師 | 智力（INT） |
| 廚師 | 感知（WIS） |

## 1.3 檢定結果

| d100 擲出 | 結果 | 效果 |
|:--:|------|------|
| 1-5 | 大成功 | 品質提升一級（加值 +2 或特效數 +1）、不消耗材料 |
| 6-95 | 依 難度等級（DC） 判定 | d100 + 屬性 + 職業Lv×2 ≥ 難度等級（DC） → 成功；否則失敗 |
| 96-100 | 大失敗 | 材料損毀 50%（每種材料獨立擲骰決定保留或損毀），已消耗的異界結晶無法回收 |

## 1.4 製作時間

| 稀有度 | 所需時間 | 可否在戰鬥中 |
|:--:|------|:--:|
| 白·普通 | 10 分鐘 | 否（需安全環境） |
| 綠·優良 | 30 分鐘 | 否 |
| 藍·稀有 | 1 小時 | 否 |
| 紫·獨特 | 3 小時 | 否 |
| B 級炸彈／傳說料理 | 1 小時 | 否 |
| 橙·傳說 | 8 小時（一天） | 否 |
| 紅·神話 | 24 小時（三天，需休息） | 否 |

# 二、鍛造規則（鍛造師）

## 2.1 鍛造配方

### 一般裝備鍛造

| 難度等級（DC） | 所需材料 | 鍛造師等級需求 |
|:--:|:--:|------|:--:|
| 白·普通 | 30 | 基礎金屬 ×2 | 0（任何人都可嘗試） |
| 綠·優良 | 50 | 基礎金屬 ×2 + 異界合金 ×1 | Lv.1 |
| 藍·稀有 | 70 | 基礎金屬 ×2 + 異界結晶 ×1 | Lv.1 |
| 紫·獨特 | 90 | 異界結晶 ×2 + 對應魔物材料 ×1 | Lv.5 |
| 橙·傳說 | 110 | 異界結晶 ×3 + Boss 材料 ×1 | Lv.10 |
| 紅·神話 | 140 | 異界結晶 ×5 + 龍鱗或神造材料 ×1 | Lv.15 |

### 裝備升級（將現有裝備提升一個稀有度）

| 難度等級（DC） | 所需材料 | 成功率加成 |
|------|:--:|------|------|
| 白→綠 | 40 | 異界合金 ×1 | — |
| 綠→藍 | 60 | 異界結晶 ×1 | — |
| 藍→紫 | 80 | 異界結晶 ×2 + 魔物材料 ×1 | 若已附加符文則 難度等級（DC） −10 |
| 紫→橙 | 100 | 異界結晶 ×3 + Boss 材料 ×1 | 若為匠簽裝備則 難度等級（DC） −10 |
| 橙→紅 | 130 | 異界結晶 ×5 + 神造材料 ×1 | 需鍛造師 Lv.15 |

> 升級失敗：材料消耗，但原裝備保留（不會降級）。

### 符文鍛造（鍛造師 Lv.10 專家特性）

為一件現有裝備附加隨機屬性。

| 項目 | 內容 |
|------|------|
| 難度等級（DC） | 70 |
| 材料 | 異界結晶 ×1 |
| 限制 | 每件裝備僅限 1 次 |
| 屬性池 | 力量（STR）/敏捷（DEX）/體質（CON）/智力（INT）/感知（WIS）/精神（SPI） +3 或 命中率（HIT%）/閃避率（DGE%）/暴擊率（CRT%） +5%（擲 1d9 決定） |
| 大成功 | 玩家自選屬性，加值翻倍（+6 或 +10%） |

### 匠簽裝備（鍛造師 Lv.15 大師技能）

| 項目 | 內容 |
|------|------|
| 難度等級（DC） | 100 |
| 材料 | 異界結晶 ×3 |
| 限制 | 每 10 級角色等級可打造 1 件 |
| 效果 | 裝備加值 ×1.5（向下取整），且必定附帶一個特效（GM 與玩家協商決定） |
| 大成功 | 加值 ×2.0，附帶兩個特效 |

## 2.2 鍛造師等級加成

| 鍛造師等級 | 加成 |
|:--:|------|
| Lv.1 | 匠造：製作裝備時基礎加值 +1（無條件） |
| Lv.5 | 材質鑑定：檢定成功後，該材料製作 難度等級（DC） −10 |
| Lv.10 | 符文鍛造解鎖 |
| Lv.15 | 名匠之作解鎖 |

# 四、烹飪規則（廚師）

## 4.1 食材採集（廚師 Lv.5 專業技能）

擊殺魔物後，廚師**無需檢定**即可採集食材：

| 魔物等級 | 獲得份數 |
|:--:|:--:|
| E/D 級 | 1 份 |
| C/B 級 | 2 份 |
| A/S 級 | 3 份 |

> 食材份數決定可製作的料理數量。每份食材可製作 1 份料理。

## 4.2 一般魔物料理（廚師 Lv.1 學徒特性）

| 項目 | 內容 |
|------|------|
| 難度等級（DC） | 40 |
| 材料 | 任意魔物食材 ×1 |
| 時間 | 10 分鐘（需安全環境和烹飪工具） |
| 效果 | 食用後獲得 **單一屬性 +15%** 的 增益（Buff），持續至下次休整（約 8 小時或長休整） |
| 增益（Buff） 屬性 | 由魔物種類決定（GM 裁決——力量型的魔物傾向 力量（STR） 增益（Buff），魔法型的傾向 智力（INT） 增益（Buff） 等） |
| 限制 | 每種魔物只能研發一種 增益（Buff）（首次烹飪該魔物時決定屬性） |
| 大成功 | 增益（Buff） 效果 +20%、雙倍份量 |
| 大失敗 | 料理失敗——食材浪費。不會中毒。 |

> **增益（Buff） 屬性池**（GM 根據魔物類型選擇）：力量（STR）、敏捷（DEX）、體質（CON）、智力（INT）、感知（WIS）、精神（SPI）、物理攻擊力（PATK）、魔法攻擊力（MATK）、物理防禦力（PDEF）、魔法防禦力（MDEF）、命中率（HIT%）、閃避率（DGE%）、暴擊率（CRT%）。

## 4.3 雙重 增益（Buff）（廚師 Lv.10 專家特性）

| 項目 | 內容 |
|------|------|
| 條件 | 已食用兩種不同屬性的魔物料理 |
| 效果 | 兩種 增益（Buff） **同時生效**（疊加）。兩種 增益（Buff） 必須對應不同屬性。 |
| 限制 | 仍受限於每種魔物一種 增益（Buff） 的上限 |

## 4.4 傳說食譜（廚師 Lv.15 大師技能）

| 項目 | 內容 |
|------|------|
| 難度等級（DC） | 100 |
| 材料 | Boss 級魔物的稀有食材 ×1（採集時自動獲得） |
| 時間 | 1 小時 |
| 效果 | 二選一： |
| | **A. 全能盛宴**：全屬性 +10%（力量（STR）/敏捷（DEX）/體質（CON）/智力（INT）/感知（WIS）/精神（SPI）），持續至下次休整 |
| | **B. 極致專注**：單一屬性 +30%（自選），持續至下次休整 |
| 限制 | 每種 Boss 只能研發一次傳說食譜。研發後可重複製作（每次仍需 Boss 食材）。 |
| 大成功 | 全能盛宴全屬性 +15%、或極致專注 +40% |

## 4.5 廚師等級加成

| 廚師等級 | 加成 |
|:--:|------|
| Lv.1 | 魔物料理解鎖 |
| Lv.5 | 食材採集：必定獲得食材（無需檢定） |
| Lv.10 | 雙重 增益（Buff） 解鎖 |
| Lv.15 | 傳說食譜解鎖 |

# 六、快速參考卡

## 鍛造師
```
製作 難度等級（DC） = 目標稀有度對應 難度等級（DC）（白30/綠50/藍70/紫90/橙110/紅140）
檢定 = d100 + 力量（STR） + 鍛造Lv × 2
匠造：所有製作 +1 加值
符文鍛造（Lv.10）：難度等級（DC） 70，異界結晶×1，隨機屬性
名匠之作（Lv.15）：難度等級（DC） 100，異界結晶×3，加值×1.5+特效
```

## 煉金師
```
藥水 難度等級（DC） = 藥水等級對應 難度等級（DC）（初30/中50/高70/特90）
檢定 = d100 + 智力（INT） + 煉金Lv × 2
雙倍調合（Lv.1）：30% 雙倍產出
炸彈（Lv.5）：難度等級（DC） 60，異界材料×1，產2個，基礎威力30
萬能藥（Lv.10）：每場1次反轉藥水效果
賢者之石（Lv.15）：難度等級（DC） 120，異界結晶×5+500 金幣（G），7天冷卻
```

## 廚師
```
一般料理 難度等級（DC） = 40 | 傳說料理 難度等級（DC） = 100
檢定 = d100 + 感知（WIS） + 廚師Lv × 2
Lv.5 食材採集自動成功
Lv.1 一般料理：單屬性+15%
Lv.10 雙重增益（Buff）：兩種料理效果疊加
Lv.15 傳說食譜：全屬性+10% 或 單屬性+30%
```
