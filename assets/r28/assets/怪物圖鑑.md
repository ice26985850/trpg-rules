# 異界入侵 TRPG —— 怪物圖鑑

## 低階魔物（Lv.1-15）

### 虛空鼠
- **等級：** Lv.1-5
- **挑戰等級（CR）：** 1-4
- **分類：** 低階獸型
- **生命值（HP）：** 30-80
- **魔力值（MP）：** 0
- **物理攻擊力（PATK）：** 8-20
- **魔法攻擊力（MATK）：** 0
- **物理防禦力（PDEF）：** 3-10
- **魔法防禦力（MDEF）：** 2-5
- **命中率（HIT%）：** 55-65
- **閃避率（DGE%）：** 15-25
- **暴擊率（CRT%）：** 5
- **傷害類型：** 穿刺（咬嚙）
- **抗性：** 無
- **弱點：** 火焰 ×1.5
- **特殊能力：** 群體戰術（周圍有同類時命中率（HIT%）+5%）
- **AI 模板：** 野獸本能（生命值（HP）<30%逃跑）
- **掉落：** 5-15 經驗值（EXP），1-3 金幣（G），虛空鼠皮（白·普通材料）
- **出沒：** E 級裂縫、侵蝕區邊緣

- **分類：** 中階獸型
