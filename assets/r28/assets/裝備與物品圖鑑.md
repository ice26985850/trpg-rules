# 異界入侵 TRPG —— 裝備與物品完整圖鑑

> 收錄所有裝備、消耗品、材料的完整數據與稀有度變體規則

---

# 一、稀有度系統（核心規則）

## 1.1 一件裝備 = 一個基底類型 + 一個稀有度等級

同一種裝備在不同稀有度下有不同的數值和特效。**稀有度不等於獨特名稱**——一把「長劍」可以是白·普通，也可以被重鑄成橙·傳說。

```
長劍（白·普通）  ──鍛造升級──→  長劍（綠·優良）
                                   ──鍛造升級──→  長劍（藍·稀有）
                                                   ──異界淬煉──→  長劍（紫·獨特）
```

| 概念 | 說明 |
|------|------|
| 基底類型 | 裝備的「種類」——長劍、手弩、防護背心、戰術靴等 |
| 稀有度等級 | 決定數值範圍和特效數量——白/綠/藍/紫/橙/紅六級 |
| 最終裝備 | 基底類型 + 稀有度 = 一件具體的裝備 |

|:--:|------|:--:|:--:|:--:|:--:|------|
| E | 白·普通 | +1~+3 | +1~+4 | +1 | 0 | 公會配給、E 級裂縫掉落 | 10~50 金幣（G） |

| C | 藍·稀有 | +6~+15 | +6~+15 | +3~+6 | 1 | C 級裂縫掉落、需異界結晶 | 200~800 金幣（G） |
| B | 紫·獨特 | +12~+25 | +10~+22 | +5~+10 | 1-2 | B 級 Boss 掉落、魔物專屬 | 800~3,000 金幣（G） |

## 1.3 稀有度命名規則

```
[顏色]·[稀有度名稱] [基底類型]

範例：
  白·普通長劍（+2 物理攻擊力（PATK））
  綠·優良長劍（+5 物理攻擊力（PATK））
  藍·稀有長劍（+10 物理攻擊力（PATK）, 命中率（HIT%） +5%）
  紫·獨特長劍 — 「獵犬的獠牙」（+10 物理攻擊力（PATK）, 對獸型魔物傷害 +20%）
  橙·傳說長劍 — 「君臨者之刃」（+28 物理攻擊力（PATK）, 暴擊率（CRT%） +10%, 擊殺回復 5% 生命值（HP））
  紅·神話長劍 — 「奧賽庫斯之正午」（+50 物理攻擊力（PATK）, 神聖傷害, 對獸人 ×2.0, 每場 1 次黎明制裁）
```

> 紫級以上裝備通常會獲得獨特名稱——但底層仍然是「長劍」基底。

## 1.4 裝備部位

| 部位 | 主要影響 | 副影響 |
|------|---------|--------|
| 武器 | 物理攻擊力（PATK）或魔法攻擊力（MATK） | 命中率（HIT%）、暴擊率（CRT%）、特效 |
| 身體 | 物理防禦力（PDEF）、魔法防禦力（MDEF） | 生命值（HP） 加成、特效 |
| 腳部 | 移動速度 | 敏捷（DEX）、閃避率（DGE%）、特效 |
| 飾品 | 微量屬性加成 | 特殊效果 |

# 七、裝備箱（掉落形式）

裝備不直接掉落成品——掉落「裝備箱」，開啟後隨機獲得對應稀有度的裝備。

| 箱子名稱 | 稀有度 | 內容 |
|------|:--:|------|
| 白·普通裝備箱 | E | 白·普通武器/防具/飾品（隨機部位） |
| 綠·優良裝備箱 | D | 綠·優良裝備（隨機部位） |
| 藍·稀有裝備箱 | C | 藍·稀有裝備（隨機部位） |
| 紫·獨特裝備箱 | B | 紫·獨特裝備（指定部位，GM 可讓玩家骰） |
| 橙·傳說裝備箱 | A | 橙·傳說裝備（指定部位 + 一個隨機特效） |
| 紅·神話裝備箱 | S | 紅·神話裝備（唯一，通常與擊敗的 Boss 相關） |

> GM 建議：讓玩家擲 1d4 決定部位（1=武器, 2=身體, 3=腳部, 4=飾品），再擲 1d6 從該部位的同稀有度池中選取一件。
