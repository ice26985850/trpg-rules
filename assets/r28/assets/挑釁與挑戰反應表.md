# 異界入侵 TRPG —— 挑釁與挑戰反應表

> 收錄 16 位神祇及 17 位半神對玩家挑釁／挑戰的反應。GM 可在玩家做出驚人之舉時參考此表，確保角色反應與設定一致。

---

# 第一層：原始存在

## 尤格德拉（世界樹之靈）

| 情境 | 反應 |
|------|------|
| 玩家在世界樹下大聲叫囂 | 無視。一片樹葉飄到玩家頭上。五分鐘後，另一片樹葉。再過五分鐘，再一片。玩家通常會因為太無聊而自己離開。 |
| 玩家試圖攀爬世界樹 | 不阻止——但越往上爬，樹枝會越滑。爬到第三層時，玩家會聽到一個極其古老的聲音在腦中響起：「你確定要繼續嗎。」沒有問號——是陳述句。繼續爬→第四層開始，每一步都會老一歲。目前沒有人去過第五層以上。 |
| 玩家在世界樹根處冥想並誠心提問 | 回答。不是用聲音——是讓一片樹葉落在玩家手中，樹葉上的脈絡會形成一個字的答案。每次只能問一個問題。每年只能問一次。 |
| 踩底線 | 在世界樹根部小便、焚燒樹皮、或在樹根處進行黑暗儀式 | 你會聽到一聲沉悶的轟鳴——方圓一百公里內的所有樹木同時轉向你。沒有攻擊——但你從此被世界樹記住了。你的影子永遠不會落在樹蔭下。任何德魯伊、精靈、樹人或自然領域的生物見到你時，都會本能地感到厭惡（交涉永久劣勢）。你不會死——但你永遠失去了自然世界的接納。 |
| **GM 建議** | 尤格德拉不會傷害凡人。祂的反應範圍是「無視」到「給你一次機會」。玩家不可能靠暴力與祂互動。 |

## 伊格納羅斯（沉睡的龍祖）

| 情境 | 反應 |
|------|------|
| 玩家在龍島火山口大喊 | 火山輕微震動——那是伊格納羅斯在睡夢中翻了個身。安格爾威德在五秒內出現在玩家面前，表情像是一個發現小孩在玩打火機的父親。 |
| 玩家試圖進入火山深處 | 安格爾威德會用龍翼物理阻擋。如果玩家堅持——「你知道你在做什麼嗎。你真的知道嗎。好。」祂會讓開。走進去的人沒有一個回來過。不是伊格納羅斯殺了他們——是火山本身就足夠致命。 |
| 玩家對安格爾威德說「我要挑戰你媽」 | 安格爾威德沉默五秒。然後說：「這是我兩千年來聽過最愚蠢的一句話。」轉身離開。不是生氣——是太荒謬了以至於不想浪費時間。 |
| **GM 建議** | 伊格納羅斯是不可挑戰的。接近她的任何嘗試都是一個「你確定嗎」的恐怖故事橋段。如果玩家真的走到她面前——你應該問：「你確定你要讓這個故事在這裡結束嗎？」 |

# 第二層：人類方

## 奧賽庫斯（光明之神）

| 情境 | 反應 |
|------|------|
| 玩家質疑祂為什麼不直接出手 | 認真回答。奧賽庫斯會詳細解釋法則衝突如何限制了祂的能力、為什麼直接降臨只會讓更多人類傷亡、以及——「我已經做了我能做的一切。剩下的，是你們的戰鬥。」語氣誠懇，不帶憤怒。 |
| 玩家挑戰祂 | 微微搖頭。拔出身邊的劍——不是要戰鬥，是插在地上。「拔出這把劍，你就可以與我一戰。」那把劍——沒有人能移動它一絲一毫。只有當玩家承認自己還不夠強時，劍會自己回到鞘中。 |
| 玩家對祂不敬（辱罵、褻瀆） | 沉默。你腳下的影子消失了——神殿永遠是正午，你不可能有影子，但奧賽庫斯能讓光繞過你。你變成了世界上唯一一個沒有影子的人類。持續 24 小時。不是懲罰——是讓你思考。 |
| 踩底線 | 在他的神殿中進行褻瀆儀式（例如用獸人血液塗抹祭壇） | 神殿內的所有光線瞬間收縮至一點然後炸開。在場的所有人都看到了你一生中做過的所有錯事，以全景影像的形式呈現在空中。奧賽庫斯的聲音在你腦中響起：「你現在所做的——是這些事的延續。停下來。這是我最後一次勸你。」如果你繼續——正午的陽光會繞過你。你永遠活在正午的陰影中——所有人都能看見你，但太陽永遠不會照在你身上。 |
| **GM 建議** | 奧賽庫斯像一個失望但從不放棄的父親。祂永遠不會對凡人下殺手。祂的「懲罰」本質上是給你時間反省。 |

# 第三層：特殊

## Collector（玩樂之神）

| 情境 | 反應 |
|------|------|
| 玩家挑釁祂 | 極度興奮。立刻憑空變出一個計分板和彩色紙屑。「太好了！我一直在等你這麼說！來吧，挑釁我——說得越有創意分數越高！」然後認真打分。最高紀錄是 47 分（來自三百年前一個醉酒的矮人）。 |
| 玩家挑戰祂 | 「哦？你想怎麼玩？」根據玩家的回答決定遊戲規則：比腕力→祂把手臂變成軟糖；比速度→祂把時間暫停然後悠哉地走到終點。不會殺玩家——但會讓玩家深刻體會到「和神玩遊戲」的荒謬。結束後送一個紀念品：「下次再來玩！」 |
| 玩家對祂說「這一切不好玩」 | 祂的笑容瞬間消失。那是祂最認真的一瞬間。沉默片刻後：「那你為什麼還在這裡？」如果玩家能給出一個好的答案，祂會真的聽。這是非常非常罕見的時刻。 |
| 踩底線 | 破壞他收集的收藏品——例如砸爛雪糕星球的一角、或撕掉他正在寫的「劇本」 | 笑容第一次消失。不說話。不笑。瞳孔中的星辰停止旋轉。他把手杖輕輕敲在地上——世界暫停了三秒。在這三秒內，他讓你看到了無限種可能性的你在無限種宇宙中的死法。三秒後恢復正常。笑容回來。「剛剛那個，不是懲罰——是預覽。別有下次。」 |
| **GM 建議** | Collector 幾乎不可能被真正激怒。唯一能讓祂認真的是質疑「這一切是否有趣」。注意：祂可能假裝生氣來測試玩家的反應——然後大笑：「騙到你了！」 |

# 第四層：獸人方

## 科塔爾（狼神）

| 情境 | 反應 |
|------|------|
| 玩家挑釁祂 | 四隻眼睛同時睜開。微微前傾。嘴角揚起——那是獵食者的微笑。「我等這句話等了很久。」 |
| 玩家挑戰祂 | 接受。但會先給玩家一個機會：「你確定嗎？你可以收回。我只給一次機會。」如果玩家堅持——進入狩獵模式。科塔爾會讓玩家先跑十分鐘，然後開始狩獵。不會殺死玩家——當祂追上時，會把玩家按在地上：「下一次我會認真。等你準備好。」 |
| 被科塔爾「狩獵」過的玩家 | 從此被科塔爾記住了。每次玩家出現在獸人之森附近，科塔爾都會傳送一個訊息——不是威脅，是：「隨時歡迎再來狩獵。」這是一種榮譽。 |
| 踩底線 | 在他的面前殺死一隻幼狼（或狼形態的人狼幼崽） | 四隻眼睛全部睜開——從未有人見過科塔爾的四隻眼睛同時完全睜開。他不再說話。不再微笑。你聽到的是純粹的、來自遠古狩獵者的低吼。「你不再是我的獵物——你是我的仇敵。」他會狩獵你——不是一次，是持續進行。他不會馬上殺你。他會讓你體驗被世界上最強的獵食者持續追蹤的恐懼。你永遠不能在月光下入睡。 |
| **GM 建議** | 科塔爾珍惜有膽量的對手。挑戰祂是獲得祂尊重的最快方式。但第一次狩獵祂不會用全力——祂希望你有第二次。 |

## 古拉姆（山嶽之王）

| 情境 | 反應 |
|------|------|
| 玩家挑釁祂 | 低頭看了看玩家，像是在看一隻對著山吼叫的螞蟻。「你想要什麼？」語氣平淡。 |
| 玩家挑戰祂 | 「打造一件我認可的作品。」如果玩家說「我不是來打鐵的」，古拉姆會說：「那你就不是來挑戰的。你是來浪費我的時間。」然後回到鍛造中。 |
| 玩家在祂面前批評祂的作品 | 這比挑戰更有效。古拉姆會停下來。「你覺得哪裡不好。」如果玩家能說出一個合理的批評——「有點意思。」然後祂會真的修改。這可能是所有神祇中最離譜的獲取好感方式——但你最好真的有料。 |
| 踩底線 | 毀掉他正在鍛造的未完成作品 | 完全停下。他的手——那雙能打造神器的手——第一次握成了拳頭。鍛造廠的地面裂開。「你知道一件作品需要多少年嗎。你知道這件已經做了三百年了嗎。」一拳捶在鐵砧上——鐵砧碎成兩半。他不會打你——但你會被他逐出鍛造廠，並且所有的矮人工匠從今以後都不會為你打造任何東西。沒有武器、沒有防具、沒有任何金屬製品。 |
| **GM 建議** | 古拉姆對戰鬥沒有興趣。祂唯一在乎的是工藝。想獲得祂的關注？帶一件你親手做的東西來。 |

## 希爾薇婭（暗影之母）

| 情境 | 反應 |
|------|------|
| 玩家挑釁祂 | 消失了。你聽到身後傳來輕微的貓叫。轉身——什麼都沒有。再轉身——祂在你正前方，蹲著，和你視線平齊，歪著頭看著你。「繼續說。我喜歡聽。」 |
| 玩家挑戰祂 | 不正面戰鬥。先消失。接下來的二十四小時內，你的影子會背叛你——你往右走，影子往左。你的倒影會對你做鬼臉。你每一次試圖睡覺，都會有一隻黑貓跳到你臉上。不是傷害——是讓你抓狂。二十四小時後，希爾薇婭會再次出現：「還要挑戰嗎？」 |
| 玩家表現出真正的勇氣和尊重 | 「你很有趣。」她可能會給你一個機會——通過暗影森林的考驗。不是戰鬥——是忍耐。 |
| 踩底線 | 傷害她的貓（任何一隻）、或對米拉造成嚴重的精神傷害 | 她不再微笑。不再消失。她站在原地——但你感覺到她身邊的暗影正在變濃、變重。她的聲音變成了低語：「你知道撫養一個孤兒需要多少耐心嗎。」下一瞬間，你的影子站了起來。你的影子從你身上剝離，變成了另一個你——和你有一樣的數據、一樣的技能，但它永遠站在你的對立面。你需要殺死自己的影子才能把它收回來。如果你下不了手——你的影子永遠在外面遊蕩。 |
| **GM 建議** | 希爾薇婭不會對凡人下殺手——不是出於仁慈，是因為「死掉的玩具不好玩」。米拉（她的養女）非常保護她，挑戰希爾薇婭之前先想想米拉會不會在附近。 |

## 墨爾基斯（毒智之主）

| 情境 | 反應 |
|------|------|
| 玩家挑釁或挑戰祂 | 微笑。極其緩慢的微笑——從嘴角開始，花了將近十秒才到達眼睛。「你知道挑釁我的人通常會發生什麼事嗎。」不等回答：「他們會成為我研究的一部分。」 |
| 玩家堅持挑戰 | 「我可以殺了你。但那太浪費了。」提出交易：你為我做一件事，我告訴你一個你想知道的祕密。如果拒絕——祂會放你走。「下次。你不會有選擇。」接受交易請見墨爾基斯的契約條款（S10）。 |
| 玩家已經中毒（墨爾基斯暗中下毒） | 「這是蛇涎。三天內不會致命。三天後——我們再看看。」這是一個計時器。祂用這種方式確保你會回來。 |
| 踩底線 | 接受了他的交易之後違約 | 「你知道為什麼沒有凡人敢違約嗎。」他沒有生氣——他看起來幾乎是悲傷的。「因為每一個違約的人——現在都在我的蛇殿裡。不是死了——是還在。活著。在學習他們當初為什麼不該違約。」你不會死。但你會消失。其他玩家可以在蛇殿深處找到你——你的身體被保存在琥珀色的毒液中，你的意識是清醒的。你需要完成墨爾基斯的三個新任務才能贖回你的自由。 |
| **GM 建議** | 挑戰墨爾基斯是最危險的選擇之一——不是因為祂會立即殺你，是因為祂會讓你欠祂一次。永遠不要欠墨爾基斯任何東西。維諾（半神）會執行墨爾基斯不方便親自做的事。 |

## 澤菲羅斯（蒼穹之王）

| 情境 | 反應 |
|------|------|
| 玩家挑釁祂 | 盤旋在上方，白色的眼睛注視著你。不說話。風開始變強。你感覺自己像是一隻被鷹盯上的田鼠。「你有十秒的時間解釋你為什麼站在這裡對我吼叫。」 |
| 玩家挑戰祂 | 輕嘆一口氣，像一個被小孩纏住的長輩。祂不會親自動手——會召來一陣持續一小時的風暴。如果你能在風暴中站穩，祂會說：「我沒時間跟你玩。但你至少比我想像的有毅力。」然後飛走。 |
| 玩家說「我看過你的預言——你是錯的」 | 這是澤菲羅斯少數會認真對待的挑釁。祂會停下來。盤旋降低。「你看到什麼。」如果玩家說的是實話——澤菲羅斯會聽。如果不是——風暴從一小時延長至破曉，期間還伴隨冰雹。「浪費我的時間是有代價的。」 |
| 踩底線 | 殺死一隻鷹（鷹人氏族的象徵聖鳥） | 風停了。完全停了——不只是你周圍的風，是整個區域的風。澤菲羅斯第一次降落到地面。他的翼展遮住了半個天空。「你殺了一隻鷹。在我面前。」他沒有召喚風暴。他伸手碰觸你的額頭——你的聽力從此被取走了一半。你永遠只能從左耳聽到風的聲音。右耳——只有一個輕微的風哨聲。那是那隻死去的鷹留給你的遺言。 |
| **GM 建議** | 澤菲羅斯太忙了——處理預言和管理氏族內部矛盾已經消耗了祂大部分精力。挑釁祂的玩家多半會被無視，除非提到「預言」或「未來」。 |

## 伊露娜（幻惑之姬）

| 情境 | 反應 |
|------|------|
| 玩家挑釁祂 | 她會笑。不是嘲笑——是真正的開心。「終於有人不是來跪著說話的。我喜歡你。」 |
| 玩家挑戰祂 | 不正面回應。先問三個問題。如果答錯——「你還沒準備好。」玩家發現自己已經被傳送到了千面之城的入口，之前的一切都是幻象。如果三個都答對——「有意思。」她會認真考慮挑戰——但不是現在。「等你通過了我的城市再說。」（指向 S18 千面之城） |
| 玩家看穿了她的幻象 | 「你是第三個做到的人。」沒有生氣。她會在你面前露出真正的樣子——不是那個微笑的狐神，而是一個看起來確實活了三百年以上的存在。「現在你看到真正的我了。你覺得怎麼樣。」這是一個考驗。誠實是唯一的答案。 |
| 踩底線 | 看穿了她的真面目，並把這個祕密當眾揭穿來羞辱她 | 她的微笑沒有消失。這是更可怕的部分——她還在微笑，眼眶裡卻開始流出黑色的淚水。「你以為看穿我是贏了。你不知道——我這張臉戴了三百年。你以為你是第一個看穿的人嗎。」她不會傷害你。她會在你面前一隻一隻地收回她的九條尾巴——每收回一條，她就年輕一歲。收回九條之後，站在你面前的是一個你不認識的少女狐人。「現在你不認識我了。現在沒有人認識我了。你滿意了嗎。」她轉身離開。千面之城從此關閉——對你和對所有覺醒者。 |
| **GM 建議** | 伊露娜是十六神中最難預測的。她對待挑戰者的態度取決於當下的心情和挑戰者的「故事」。一個有故事的挑戰者比一個強大的挑戰者更能引起她的興趣。 |

# 第五層：中立方神祇

## 安格爾威德（龍神）

| 情境 | 反應 |
|------|------|
| 玩家挑釁祂 | 緩緩轉過頭。祂的眼睛——兩個微型星系——緩慢旋轉。「你身上的魔力波動告訴我，你的等級大約是 X。我的等級是 18。不是人物等級。是神格。」祂沒有在炫耀——祂在陳述事實。 |
| 玩家挑戰祂 | 「你知道我每天在做什麼嗎。我在壓制一座火山，防止我的母親醒來把這片大陸燒成灰燼。你覺得你比一座火山更值得我分心嗎？」如果玩家堅持——「通過五元素考驗。然後我們再談。」（指向 S14） |
