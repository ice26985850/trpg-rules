# 異界入侵 TRPG —— 雙 經驗值（EXP） 與職業系統規格

## 一、經驗值系統

角色擁有**兩個獨立的 經驗值（EXP） 槽**：

| 經驗值（EXP） 類型 | 來源 | 用途 |
|---------|------|------|
| 角色 經驗值（EXP） | 擊殺魔物、完成任務、關閉裂縫 | **提升角色等級**，獲得屬性點 |
| 職業 經驗值（EXP） | 以該職業身份戰鬥／使用該職業技能／以該副職業進行生產活動 | **提升職業等級**，解鎖技能與特性 |

|------|-----|

## 二、技能二元制

技能不再有等級（Lv.1-10）。**你要麼會、要麼不會。**

### 技能威力公式

```
技能傷害 = 技能基礎威力 × (1 + 該技能所屬職業的等級 ÷ 20)
```

| 職業等級 | 傷害倍率 |
|---------|:----:|
| 1 | ×1.05 |
| 10 | ×1.50 |
| 20 | ×2.00 |
| 30 | ×2.50 |
| 40 | ×3.00 |
| 50 | ×3.50 |

> 基礎威力為技能本身的固定數值（見各職業技能表）。

### 技能獲取

- 創角時：從第一個職業的 Lv.1 解鎖列表中選擇 **2 個技能**
- 提升職業等級：自動解鎖對應技能
- 跨職業：不同職業的技能互相獨立。前鋒不能用術士的技能——除非你也練了術士

### 魔力值（MP） 消耗

所有技能有固定魔力值（MP）消耗和冷卻（見各技能描述），不再隨等級變化。

## 四、通用解鎖節點

### 戰鬥職業（Lv.1-50）

| 等級 | 解鎖 |
|------|------|
| Lv.1 | 基礎主動技能 ×2 + 職業特性 Lv.1 |
| Lv.3 | 新主動技能 ×1 |
| Lv.6 | 新技能 ×1（主動或被動） |
| Lv.10 | 職業特性 → Lv.2 |
| Lv.15 | **分支選擇**（二選一）+ 分支技能 ×1 |
| Lv.20 | 新技能 ×1 |
| Lv.30 | 職業特性 → Lv.3（分支強化） |
| Lv.40 | **大師技能** ×1 |
| Lv.50 | 終極特性 |

### 生活職業（Lv.1-15）

| 等級 | 解鎖 |
|------|------|
| Lv.1 | 學徒特性 |
| Lv.5 | 第一專業技能 |
| Lv.10 | 專家特性（取代學徒特性） |
| Lv.15 | 大師技能 |

### 神祇特殊職業

| 獲取時 | 解鎖 |
|--------|------|
| 獲得神祇眷顧 | 神授特性（取代或強化覺醒技能）+ 神授技能（每場 1 次） |
