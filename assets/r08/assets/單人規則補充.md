# 天機·修真心 — 單人遊玩規則補充

> **適用場景**: 1 GM + 1 玩家（Duet Play）
> **依賴規則**: 本文件為《天機·修真心》規則書的補充。所有未修改的規則沿用主規則書（`規則書.md`）原文。
> **引用格式**: `→ §章節` 表示引用主規則書對應章節。

---

## 一、核心改動總覽

| 主規則 | 單人調整 |
|--------|----------|
| 合擊規則（→ §6.2） | **禁用**。改為「連擊系統」（見§1.2） |
| 聯合施法（→ §6.3） | **禁用**。改為「蓄力施法」（見§1.3） |
| 陣型戰術（→ §6.4） | **禁用**。改為 NPC 夥伴戰術（見§2.3） |
| 協助動作（→ §6.1） | **改為 NPC 夥伴執行動作**（見§2.1） |
| 遭遇規模 | 敵人數量 −50%，單體 Boss 保留但調整數值（見§3） |

---

## 一.1 回合結構（沿用 → §3.1）

不變。玩家仍然每回合擁有 **3 個動作點**（主要/移動/輔助各一）。

---

## 一.2 連擊系統（替代合擊 → §6.2）

單人無法合擊，改為「連擊」——玩家在特定條件下可連續發動多次攻擊：

| 連擊觸發條件 | 效果 |
|-------------|------|
| 上一回合未受到任何傷害 | 本回合第一次攻擊傷害 +1d6 |
| 敵人處於異常狀態（冰凍/麻痹/灼燒/定身） | 對該敵人的第一次攻擊額外造成 1 個輔助動作的傷害（僅限武技，不消耗輔助動作） |
| 連續 3 回合對同一目標造成傷害 | 第 4 回合對該目標的傷害自動暴擊（傷害×1.5） |

---

## 一.3 蓄力施法（替代聯合施法 → §6.3）

玩家可消耗 1 回合進行「蓄力」：本回合不做任何攻擊，下一回合的神通或地級以上武技傷害 ×1.5。蓄力期間受到攻擊則蓄力中斷（傷害加成取消但不反噬）。

---

## 二、NPC 夥伴系統

單人遊玩中，玩家可攜帶 **1 名 NPC 夥伴**同行。夥伴有簡化數據卡，由玩家在戰鬥中下達指令。

> **引用**: NPC 夥伴的詳細角色卡見 `角色卡Excel/NPC夥伴卡.xlsx`。
> **設計原則**: 夥伴補足玩家不具備的能力（如玩家是劍修，夥伴可以是丹修提供治療）。

### 二.1 夥伴動作規則

每回合夥伴擁有 **2 個動作點**（1 主要 + 1 移動），由玩家指揮。夥伴不能使用神通（簡化NPC無神通槽）。

| 夥伴可執行的主要動作 | 說明 |
|---------------------|------|
| 攻擊 | 使用夥伴的武技攻擊（傷害見夥伴卡） |
| 協助 | 為玩家提供本回合命中 +10 或防禦 +5（→ §6.1 簡化版） |
| 治療 | 使用丹藥或治療類武技 |
| 防禦 | 本回合 防禦值（AC）+10，但無法攻擊 |

### 二.2 夥伴成長

夥伴不獨立獲取修為。每當玩家突破一個**大境界**，夥伴自動提升至同一境界的**初期**。

| 玩家突破 | 夥伴提升 |
|----------|----------|
| 煉氣 → 築基 | 夥伴升至築基初期；生命值（HP）+20；傷害骰+1d |
| 築基 → 金丹 | 夥伴升至金丹初期；解鎖第二武技槽 |
| 金丹 → 元嬰 | 夥伴升至元嬰初期；生命值（HP）+40；可執行 3 個動作/回合 |

### 二.3 夥伴戰術（替代陣型 → §6.4）

| 戰術 | 條件 | 效果 |
|------|------|------|
| **前後夾擊** | 玩家與夥伴在不同區域（近+中距） | 雙方對中間區域敵人的攻擊命中 +10 |
| **掩護撤退** | 夥伴在近身區，玩家在中/遠距區 | 玩家本回合閃避 +15；夥伴承受下次攻擊 |
| **集火** | 雙方攻擊同一目標 | 第二次攻擊無視目標 5 點防禦 |

## 三、遭遇規模調整

主規則中的怪物/NPC（→ §3.9）數據以 3-4 人團隊為基準。單人遊玩時按以下比例調整：

### 三.1 敵人數量調整

| 主規則遭遇 | 單人調整 |
|-----------|----------|
| 1 Boss | 不變（Boss 生命值（HP） −20%，傷害 −1d） |
| 2-3 雜兵 | 減為 1-2 |
| 4+ 雜兵 | 減半（向下取整） |
| 大規模戰場 | 改為敘事處理，僅擲關鍵檢定 |

### 三.2 單人遭遇設計原則

| 遭遇類型 | 建議 |
|----------|------|
| 雜兵戰 | 1-2 隻，用於消耗資源，一般不致命 |
| 精英戰 | 1 隻，生命值（HP） = 玩家 生命值（HP）×0.8~1.2，需策略應對 |
| Boss 戰 | 1 隻，生命值（HP） = 玩家 生命值（HP）×1.2~1.8，多階段或多機制 |
| 追逐/逃生 | 身法檢定為主，不強制戰鬥 |

## 四、其他規則變更

### 四.1 休息（→ §一 / 主規則補遺）

不變。NPC 夥伴與玩家同步休息。

### 四.2 社交（→ §二 / 主規則補遺）

不變。NPC 夥伴可參與社交但不做獨立檢定（夥伴的態度修正可由 GM 裁定）。

### 四.3 製作與採集（→ §三 / 主規則補遺）

不變。可使用夥伴協助（煉丹/煉器檢定 +5）。

### 四.4 拜師系統（→ §十四 / 主規則補遺）

不變。NPC 夥伴不獨立拜師，但可通過玩家的師父獲得間接指導。

### 四.5 聲望與關係（→ §四 / 主規則補遺）

不變。NPC 夥伴的聲望不獨立追蹤。

### 四.6 死亡與復活

玩家死亡時，若 NPC 夥伴存活且持有「護身玉符」或類似道具，夥伴可消耗該道具為玩家抵擋致命一擊（夥伴在場時，護身玉符的效果由玩家觸發）。夥伴本身不會真正死亡——生命值（HP） 歸零時陷入「重傷」狀態，需長休恢復。
