## 5.6 遭遇表使用指南



### 擲骰規則



```

隨機遭遇頻率: 每旅行1天擲1次 d100（或在GM認爲合適時觸發）

遭遇概率:  - 安全區域(宗門附近/大道): 擲d100, ≤30觸發遭遇 - 普通區域(野外/山路): 擲d100, ≤50觸發遭遇 - 危險區域(妖獸領地/古戰場): 擲d100, ≤70觸發遭遇 - 極危區域(魔域/祕境深處): 擲d100, ≤90觸發遭遇



遭遇難度調整: GM可根據隊伍實際實力調整遭遇的數量/強度 輕鬆遭遇: 可增加50%數量 極難遭遇: 可減少敵人數量或降低挑戰等級（CR）1-2級

```



### 遭遇類型說明

| 類型 | 說明 | GM處理建議 |
|------|------|-----------|
| **戰鬥** | 直接進入戰鬥 | 按標準戰鬥規則處理 |
| **社交** | 涉及NPC互動 | 可能發展爲交易/委託/情報獲取/結盟/敵對 |
| **探索** | 涉及場景探索 | 使用探索技能檢定(神識感知/悟性解謎/身法穿越等) |
| **奇遇** | 特殊事件 | 通常需要檢定(機緣爲主)，結果可能是獎勵/戰鬥/任務 |
| **災難** | 環境危險 | 需團隊協作應對，通常沒有"敵人"但有環境檢定 |



### 交叉遭遇



GM可混合不同區域的遭遇表或同時觸發多個遭遇:

- 例1: 中州遭遇"天材地寶出世"+東土遭遇"各方修士趕來"=一場爭奪戰

- 例2: 南荒遭遇"蠻族部落"+西域遭遇"血煞教"=血煞教在蠱惑蠻族

- 例3: 戰鬥遭遇+災難遭遇=在暴風雪/沙暴中戰鬥(環境減值疊加)
