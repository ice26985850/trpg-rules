## 1.1 陣法規則總覽



### 通用陣法機制



```

佈陣流程: 1. 消耗指定動作佈置陣眼（放置核心陣器/陣旗） 2. 擲 d100 ≤ 陣法技能值，成功則陣法激活 3. 陣法持續生效：每回合消耗陣法師真氣（或陣法自帶靈石供能） 4. 大失敗 → 陣法反噬（陣法師承受 2d10 傷害，材料損毀）



破陣方式: - 摧毀陣眼（陣眼有獨立 生命值（HP） 和防禦值） - 陣法師被打斷/擊殺 - 以陣法技能對抗破陣（雙方各擲 d100，比較成功度） - 使用破陣符



（自動破除同品級及以下陣法）



通用公式: 陣眼生命值（HP） = 佈陣者陣法技能值 × 陣法品級係數 陣法品級係數: 黃=0.5, 玄=1.0, 地=2.0, 天=3.5 破陣難度（DC） = 80 + 佈陣者陣法技能值/2 + 品級加值(黃0/玄+10/地+20/天+30) 維持消耗(真氣/回合) = 基礎消耗 × (1 - 境界層級/10)（最低爲基礎消耗的30%）

```

## 2.1 符籙規則總覽



```

符籙通用規則: - 使用動作: 輔助動作（捏碎/激活符籙）——無需真氣 - 符籙效果: 製作時已"灌注"檢定結果，使用時自動生效 - 一次性: 使用後符籙自毀 - 攜帶上限: 同品級符籙最多攜帶 悟性/10 張（避免符籙海戰術）



制符規則: 制符難度（DC） = 基礎難度（DC） + 品級調整 制符時間: 黃1時辰/玄2時辰/地4時辰/天8時辰 制符檢定: d100 ≤ 符道技能值 大成功(差值≥40): 符籙效果×1.5 大失敗(d100≥96): 材料損毀，符籙爆炸(制符者承受1d6/品級傷害)



符籙效果強度 = 製作時的檢定成功度 - 購買/拾取的符籙: GM預先確定（通常取標準值） - 自制的符籙: 記錄製作時的成功度等級

```
