# 七、玩家建卡教學



歡迎來到《天機·修真心》的世界！創建角色是你修仙之路的第一步，也是最令人興奮的一步。以下是爲你一步步拆解的建卡指南。



## 第1步：想一個角色概念——你是誰？爲什麼修仙？



在擲骰子之前，先用幾分鐘想象一下你的角色。



**三個核心問題**：

1. **你是誰？** —— 你的名字、年齡、出身？是宗門弟子還是散修？是富商之子還是山野獵戶？

2. **你爲什麼修仙？** —— 爲了長生？爲了力量？爲了復仇？爲了守護？還是單純覺得飛劍很酷？

3. **你的性格是什麼？** —— 冷傲孤僻還是熱情開朗？謹慎小心還是魯莽衝動？



**舉個栗子**：

> "我叫雲千影，18歲，從小被太虛劍宗收入外門。我修仙是因爲那年師父在洗劍池邊揮出的那一劍——那是我見過最美的東西。我沉默寡言，劍就是我的語言。"



有了概念後，我們就可以開始擲骰子啦！

## 常見問題 FAQ



**Q: 靈根品質太差怎麼辦？**

A: 下品靈根雖然修煉慢，但修仙之路不是百米衝刺而是馬拉松。很多傳奇修士起步時資質平平，憑藉機緣和努力照樣登頂。而且……GM通常會同情下品靈根玩家，給更多奇遇機會哦。



**Q: 什麼是"靈根加成"？**

A: 每條靈根根據類型提供對應的屬性加值（如金靈根=根骨+5）。如果你有金靈根，就在根骨上+5。如果你有兩條靈根，兩個加值都有效。



**Q: 初始屬性總和高了怎麼辦？**

A: 標準數組方案下，8屬性初始合計應該是 160（基礎各20）+ 60（自由點）= 220，靈根/出身加成另算。如果超了請重新調整。



**Q: 我可以不選宗門嗎？**

A: 當然！散修出身就沒有宗門約束。但散修意味着沒有俸祿、沒有師承、沒有庇護——一切靠自己。適合有經驗的玩家。



**Q: 修習了屬性不兼容的功法會怎樣？**

A: 參悟難度+20，功法效果-30%。不值得。老老實實選兼容的功法吧。



**Q: 靈力值和生命值（HP）怎麼算？**

A: 煉氣期：生命值（HP） = 肉身 × 1.5（向下取整），靈力 = 靈力 × 1.0 + 心法加成。境界越高，係數越大。詳見 戰鬥系統設計.md。



**Q: 心魔值是什麼？**

A: 心魔值代表你內心的魔障累積。修煉魔功、走火入魔、殺戮過多都會增加。心魔值≥道心值時觸發「心魔纏身」——全檢定-10。平時多修煉道心，保持內心純淨很重要。

# 八、叛門/多門派混修規則



## 8.1 叛門概述



在修仙界，叛門（背叛師門、改投他派）是極其嚴重的行爲。修仙宗門視傳承道統爲生命，叛門者輕則被逐出師門、重則被追殺至天涯海角。但修仙界廣闊，總有人因各種原因走上叛門之路——或許是宗門腐朽、或許是道不同不相爲謀、或許是被驅逐後不得不另尋出路。



## 8.2 叛門條件與流程



### 主動叛門（弟子主動脫離）

| 步驟 | 內容 | 檢定/條件 |
|------|------|----------|
| 1. 動機確認 | 玩家需向GM陳述叛門理由 | 需合理劇情動機（GM裁決） |
| 2. 叛門宣告 | 角色正式脫離宗門（告知宗門或直接逃走） | — |
| 3. 宗門反應 | GM根據宗門類型決定反應 | d100+修爲差距+地位修正 |
| 4. 後果結算 | 裝備/功法/聲望等影響 | 見下方表 |



### 被逐出師門（宗門驅逐弟子）

| 觸發條件 | 例子 |
|---------|------|
| 嚴重違反門規 | 私傳功法、殘害同門、勾結魔修 |
| 修煉禁術 | 被宗門禁止的魔功/禁術 |
| 任務重大失敗 | 導致宗門重大損失 |
| 拒絕宗門調令 | 多次拒絕宗門指派的重要任務 |



### 叛門檢定（GM暗投）



```

宗門追緝力度 = 基礎值 + 弟子重要性修正 + 功法泄露風險修正 + 宗門實力修正



基礎值: 40（大多數宗門對叛門者都有追緝意願）

弟子重要性: 外門+0 / 內門+10 / 真傳+20 / 長老+30

功法泄露: 未學核心功法+0 / 學了核心功法+20 / 學了鎮宗功法+40

宗門實力: 小門派+0 / 中等宗門+10 / 上宗+20 / 聖地+30



擲 d100: ≤ 追緝力度 → 宗門發起正式追緝 > 追緝力度 → 宗門僅發佈懸賞通告，不主動追緝 大成功(d100 ≤ 範圍) → 宗門派出最強戰力追殺 大失敗(96-00) → 宗門內部意見分歧，未採取有效行動

```



## 8.3 叛門後果



### 即時後果

| 後果類型 | 嚴重程度 | 說明 |
|---------|---------|------|
| **聲望扣減** | -20~-100 | 在原宗門勢力範圍內聲望大幅降低；與該宗門交好的勢力也會受影響 |
| **裝備回收** | 部分~全部 | 宗門配發的法器/法袍/丹藥一律收回（除非叛門前偷偷帶走） |
| **俸祿取消** | 永久 | 失去所有宗門俸祿和月供 |
| **洞府收回** | 永久 | 宗門分配的修煉洞府被收回 |



### 功法相關後果

| 情況 | 後果 | 檢定 |
|------|------|------|
| 宗門基礎功法 | 可保留（已學會的不會"遺忘"） | — |
| 宗門核心功法 | 30%概率被宗門以祕法封印（功法失效） | d100 ≤ 30 |
| 鎮宗功法 | 60%概率被封印；若被封印，每使用一次觸發1次道心檢定 | d100 ≤ 60 |
| 師承獨門功法 | 50%概率被封印 | d100 ≤ 50 |
| 被長老親傳的功法 | 該長老可遠程感應（500裏內）功法被使用時 | — |



### 追殺系統

| 追殺等級 | 持續時間 | 追殺者境界 | 懸賞金額 |
|---------|---------|-----------|---------|
| 輕度 | 1-6個月 | 同境界1-2人 | 100-500靈石 |
| 中度 | 6-24個月 | 高於1小境界1-2人 | 500-5,000靈石 |
| 重度 | 2-10年 | 高於1大境界1人+同境界多人 | 5,000-50,000靈石 |
| 死仇 | 百年以上 | 宗門最強戰力親自出手 | 50,000-500,000靈石 |



> **每經過一次追殺週期**：GM擲 d100，≤30降低一級追殺等級，≥70則追殺升級（宗門發現新線索/增派人手）。



### 叛門者標記



叛門者在原宗門勢力範圍內獲得特殊標記：

- **懸賞令**：在宗門任務大廳掛牌，所有修士可接取

- **神識印記**：部分宗門會在弟子身上種下「追蹤印」（叛門時需神識檢定破解）

- **畫像通緝**：在宗門勢力範圍內的城鎮/坊市張貼



## 8.4 多門派混修規則



### 核心原則：不可同時爲兩個宗門的內門及以上弟子



修仙界有一條不成文的規矩：**一人不可拜兩個師父**（指正式師承關係）。但以下灰色地帶是允許的：



### 合法多門派身份

| 身份類型 | 條件 | 限制 | 實例 |
|---------|------|------|------|
| **客卿** | 受宗門邀請；境界≥金丹 | 不觸及宗門核心功法；有固定任期 | 散修高手受邀成爲某宗門客卿長老 |
| **記名弟子** | 交靈石或完成入宗任務 | 僅學入門功法；無師承關係；無俸祿 | 散修花靈石在某宗門掛名學藝 |
| **掛名長老** | 境界≥元嬰；原宗門同意 | 需原宗門書面許可；不可學新宗門功法 | 某宗門長老受邀擔任另一宗門「客座講法」 |
| **外門旁聽** | 繳納旁聽費 | 只能旁聽公開課程；不可學內門功法 | 散修花靈石旁聽太虛劍宗的公開劍術課 |
| **聯盟成員** | 加入宗門聯盟 | 受聯盟章程約束但保留原宗門身份 | 「正道聯盟」成員同時也是太虛劍宗弟子 |



### 灰色地帶（GM裁決）

| 情況 | 判定 |
|------|------|
| 同時是兩個宗門的外門弟子 | 理論上不允許但難以追查；若被發現，兩個宗門都可能驅逐 |
| 一方外門一方客卿 | 通常可接受；客卿身份本身就不是正式弟子 |
| 原宗門解散後加入新宗門 | 完全合法；宗門都沒了還有什麼叛門一說 |
| 記名弟子轉正（同一宗門） | 標準晉升流程，完全合法 |



### 混修功法規則



若角色通過合法途徑獲取了多個宗門的功法：

| 規則 | 說明 |
|------|------|
| 功法數量不受限制 | 只要功法槽位有空，可以裝備不同宗門的功法 |
| 同類型功法可能衝突 | 兩門心法如果屬性相剋（如冰與火），裝備時需道心檢定（d100 ≤ 道心）否則兩者都失效 |
| 不同宗門的同屬性功法疊加 | 威力疊加但存在邊際遞減：第二門同屬性功法效果-30% |
| 鎮宗功法不可外傳 | 若被發現持有他宗鎮宗功法且非合法途徑獲得，視爲盜竊——兩宗都會追緝 |



## 8.5 客卿/記名弟子/掛名長老體系



### 客卿制度



客卿是修仙界最常見的灰色身份——你不是宗門弟子，但爲宗門做事並獲取報酬。

| 客卿等級 | 最低境界 | 年俸(靈石) | 可接觸功法 | 義務 |
|---------|---------|-----------|----------|------|
| 三等客卿 | 金丹初 | 2,000 | 玄級公開功法 | 每年完成1次宗門任務 |
| 二等客卿 | 元嬰初 | 20,000 | 地級公開功法+1門獨門功法 | 每年完成3次宗門任務 |
| 一等客卿 | 化神初 | 100,000 | 地級核心功法 | 宗門危機時必須出戰 |
| 供奉 | 煉虛+ | 500,000+ | 天級公開功法 | 宗門存亡之際出手 |



### 記名弟子



記名弟子是"花錢買學籍"——交靈石成爲掛名弟子，享受部分宗門資源但不涉及師承。

| 項目 | 內容 |
|------|------|
| 入門費 | 500-5,000靈石（視宗門品級） |
| 年費 | 100-1,000靈石/年 |
| 可學功法 | 僅入門功法和公開武技（品級不超過玄級） |
| 可使用設施 | 公開修煉區、坊市交易權 |
| 不可接觸 | 核心功法、內門丹方、長老授課 |
| 師承 | 無——記名弟子不列入宗門傳承譜系 |



### 掛名長老



掛名長老本質是一種榮譽職位，通常是某領域的專家被邀請來"撐門面"。

| 條件 | 說明 |
|------|------|
| 境界要求 | 元嬰期以上 |
| 原宗門許可 | 必須取得，否則視爲叛門 |
| 義務 | 每年講法1-2次；參與宗門大典 |
| 權利 | 年俸靈石+獨立洞府（非永久）+ 宗門功法庫限定閱覽 |
| 限制 | 不可學習新宗門的核心功法；不可擔任新宗門的實權職位 |

### 貢獻度與叛門的關係



叛門時，未使用的貢獻度清零。部分宗門允許"贖身"——支付相當於貢獻度×10的靈石，換取體面脫宗（不視爲叛門，聲望不扣減）。
