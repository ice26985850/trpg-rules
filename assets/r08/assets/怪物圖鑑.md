## 第三章：靈獸譜



## 3.1 靈獸規則總覽



```

靈獸通用規則: - 行動順序: 在主人先攻之後立即行動 - 每回合行動: 1主要動作 + 1移動動作 - 指揮: 主人可用輔助動作指揮靈獸（否則按本能行動/GM控制） - 忠誠度: 0-100，影響是否服從危險命令 - 死亡: 靈獸生命值（HP）歸零則死亡（特殊靈獸可涅槃/重生）



本能行動表（主人不指揮時）: 勇猛型: 攻擊最近/威脅最大的敵人 護衛型: 守在主人近身區域，替主人擋刀 狡詐型: 優先攻擊生命值（HP）最低/最弱的敵人 膽怯型: 遠離戰鬥，僅在安全距離攻擊 獨立型: 自主判斷最優目標（需靈獸神識≥40）



馴服規則: 馴服難度（DC） = 基礎難度（DC） + 靈獸品級調整 + 靈獸當前狀態調整 馴服檢定: d100 ≤ 馴獸技能值（或神識+馴獸熟練度） 失敗後果: 靈獸攻擊馴服者（視靈獸性格而定）

  

進化規則: - 吞噬同品級或更高品級靈獸內丹 - 主人突破大境界時可隨同進化 - 特殊天材地寶餵養（如龍血草、鳳凰果等）

```

### 靈獸與主人的協同機制



```

協同攻擊（主人使用主要動作指揮）: - 主人與靈獸同時攻擊同一目標 - 目標對該次攻擊的閃避-20（顧此失彼） - 若雙方都命中，傷害各+1d6



靈獸合體（需化神以上，特殊神通）: - 主人與靈獸短暫合體 - 所有屬性 + 靈獸品級×3 - 獲得靈獸的特殊能力 - 持續3回合，結束後靈獸虛弱2回合



靈魂契約（本命靈獸，僅1只）: - 主人與靈獸共享生命感知 - 靈獸生命值（HP）歸零時主人可用自身生命值（HP）替代（1:1） - 主人死亡時靈獸自由（解除契約） - 解除契約：雙方各承受3d10神魂傷害

```
