# 第一章：核心規則

## 1.1 d100 百分比檢定

### 核心公式

```
檢定成功條件: d100 ≤ 目標值（TN）
目標值（TN） = 屬性值 + 熟練度加成 + 功法加值 + 情境修正 − 難度修正（DC）
```

### 成功度等級（MoS = 目標值（TN） − d100 結果）

| 等級 | 成功度（MoS） 範圍 | 效果描述 |
|------|---------|---------|
| 小成 | 1-20 | 勉強成功，效果打折扣 |
| 大成 | 21-40 | 標準成功，穩定發揮 |
| 圓滿 | 41-60 | 出色成功，額外收益 |
| 超凡 | 61-80 | 驚豔表現，顯著加成 |
| 天人 | 81+ | 技近乎道，傳奇效果 |

### 大成功·機緣

範圍隨境界成長而擴大：

```
大成功範圍 = 3 + floor((等級−1) / 3)
```

| 境界 | 大成功範圍 | 概率 |
|------|-----------|------|
| 煉氣初期(1級) | 01-03 | 3% |
| 築基初期(5級) | 01-04 | 4% |
| 金丹初期(9級) | 01-05 | 5% |
| 元嬰初期(13級) | 01-07 | 7% |
| 化神初期(17級) | 01-08 | 8% |
| 煉虛初期(21級) | 01-09 | 9% |
| 合體初期(25級) | 01-11 | 11% |
| 大乘初期(29級) | 01-12 | 12% |
| 渡劫初期(33級) | 01-13 | 13% |
| 渡劫圓滿(36級) | 01-14 | **14%** |

### 大失敗·走火入魔

- **範圍**：固定 96-00（5%），後果隨境界加重
- **觸發**：檢定大失敗 / 功法反噬 / 丹藥過量 / 心魔攻擊

### 對抗檢定

| 情況 | 結果判定 |
|------|---------|
| 雙方成功 | 比 成功度（MoS），高者勝 |
| 一成一敗 | 成者勝 |
| 雙方失敗 | 比 失敗度（MoF），低者（失敗較輕者）勝 |
| 雙方大成功 | 比 成功度（MoS）；平手則機緣碰撞（雙方增益） |
| 雙方大失敗 | 災難性結果 |

### 境界突破公式

```
突破成功率 = 60% + 根骨/5 + 悟性/10 + 道心/10 + 丹藥 + 護法 + 靈脈（上限 95%）
```

| 天劫類型 | 輪數 | 觸發 | 主屬性檢定 | 通過條件 |
|----------|------|------|-----------|---------|

## 1.6 走火入魔

### 觸發條件
1. 任意檢定出 96-00
2. 強行修煉超階功法
3. 丹藥過量累積藥毒
4. 心魔攻擊

### 抵抗與後果

抵抗檢定：`d100 ≤ 道心 − 心魔值`

| 等級 | 名稱 | 道心檢定 | 後果 |
|------|------|---------|------|
| 1 | 真氣逆行 | +0 | 真氣池−20%，持續 1 輪 |
| 2 | 經脈受損 | −5 | 全屬性−5，持續 1 天 |
| 3 | 氣血翻湧 | −10 | 生命值（HP）−30%，隨機屬性−1d5（永久） |
| 4 | 道基動搖 | −15 | 境界倒退一小階段，道心−1d10 |
| 5 | 元神受創 | −20 | 神識/靈力減半，持續 1 月 |
| 6 | 心魔纏身 | −25 | 心魔值+20，大失敗擴至 94-00 |
| 7 | 身死道消 | −30 | 角色死亡（GM 可引入復活線） |

### 心魔值系統
- **累積**：走火入魔 / 心魔劫 / 修煉魔功 / 殺戮業力
- **閾值**：心魔值 ≥ 道心值時「心魔纏身」（全檢定−10，大失敗 94-00）
- **消除**：閉關靜修（每月−1d5）、清心丹、特殊機緣

## 3.1 回合結構

每回合 = **1 主要動作 + 1 移動動作 + 1 輔助動作 + 不限自由動作 + 每輪 1 次反應**

| 動作類型 | 次數 | 典型用途 |
|----------|------|---------|
| 主要動作 | 1 | 武技攻擊、釋放神通、激活法寶、全力防禦、佈陣 |
| 移動動作 | 1 | 跨 1 個距離等級、起跳、從倒地起身 |
| 輔助動作 | 1 | 切換武器/法寶、服用丹藥、捏碎符籙、神識掃描 |
| 自由動作 | 不限 | 簡短說話、激活持續型心法、真氣流轉 |

# 一、休息與恢復系統

## 1.1 休息類型

| 類型 | 耗時 | 生命值（HP） 回復 | 真氣回復 | 藥毒降低 | 心魔降低 | 限制 |
|------|------|---------|---------|---------|---------|------|
| **短休**（調息） | 1 時辰 | 回復 `肉身×1` | 回復 `靈力×1` | — | — | 每日最多 2 次 |
| **長休**（入定） | 8 時辰 | 回復 `肉身×境界生命係數` | 回復 `靈力×境界真氣係數` | -5 | -3（若道心檢定成功） | 需安全環境 |
| **閉關** | 7 日以上 | 完全回復 | 完全回復 | -20 | -10 | 需閉關場所；每月最多 1 次 |

## 1.2 短休·調息（1 時辰）

```
條件：非戰鬥狀態，可被打斷（被打斷則僅回復 50%）
效果：生命值（HP） 回復 肉身×1；真氣回復 靈力×1
消耗：每短休消耗 1 枚下品靈石（提供靈氣）
每日上限：2 次
```

## 1.3 長休·入定（8 時辰）

```
條件：安全環境（無敵方威脅）、不可被打斷
效果：
  - 生命值（HP） 回復 肉身 × 境界生命係數
  - 真氣回復 靈力 × 境界真氣係數
  - 藥毒值 -5
  - 心魔值：道心檢定 d100 ≤ 道心，成功則 -3，失敗無變化
  - 所有「每日 1 次」技能重置
限制：每 12 時辰僅可進行 1 次長休
```

## 1.4 閉關（7 日以上）

```
條件：閉關場所（洞府/靜室/祕境）
耗費：每日消耗靈石（下品×3 或中品×1）
效果：
  - 生命值（HP）/真氣完全回復
  - 藥毒值 -20
  - 心魔值 -10
  - 可進行 1 次功法修煉檢定
  - 可進行 1 次境界突破嘗試
限制：每月最多閉關 1 次；閉關期間無法參與外部事件
```

## 1.5 特殊情況回復

| 情況 | 效果 |
|------|------|
| 丹藥輔助短休 | 短休回復量 ×1.5（需消耗 1 顆回靈丹或療傷丹） |
| 靈脈之地短休 | 短休無需消耗靈石（靈氣充足） |

## 2.1 社交檢定公式

## 2.2 NPC 態度等級

| 態度 | 難度（DC） 修正 | 典型 NPC | 交涉效果 |
|------|---------|---------|----------|

## 2.3 態度變化

# 十四、拜師與師徒系統

修仙界中，師徒關係是傳承道法的核心紐帶。一個好師父能讓弟子少走百年彎路；一個逆徒也能讓師父晚節不保。

---

## 14.1 拜師條件

### 基本條件

| 條件 | 說明 |
|------|------|
| **境界差距** | 師父境界必須 ≥ 弟子當前境界 + 2 階（如煉氣拜築基不行，需金丹以上） |
| **靈根契合** | 師父與弟子至少有一條相同或相生的靈根（否則無法傳功） |
| **道心相合** | 師徒道心值差距不超過 30（差距過大則理念不合） |
| **宗門許可** | 若師父為宗門成員，需該宗門允許收徒（通常金丹以上有收徒權） |

### 拜師儀式

進行一次正式的「拜師禮」，需滿足以下之一：
- 在宗門祖師殿舉行（DC 自動通過）
- 散修則需一名金丹以上見證人

儀式後進行 **師徒緣分檢定**：`d100 ≤ 50 + 機緣/5 + 師父好感度修正`

| 檢定結果 | 效果 |
|----------|------|
| 大成功（d100 ≤ 大成功值） | 師徒親密度初始 +20；師父贈送一件入門禮（地級物品） |
| 成功 | 正式確立師徒關係；親密度初始值 = 10 + 機緣/10 |
| 失敗 | 師父暫時不收，但給一個試煉任務（完成後可重試） |
| 大失敗 | 師父認為緣分未到，短期內（1年）不得再拜 |

## 14.3 師徒親密度

### 親密度等級

| 等級 | 數值範圍 | 稱呼 | 效果 |
|:----:|----------|------|------|
| 1 | 0-20 | **初識** | 基礎收益（無加成） |
| 2 | 21-40 | **信任** | 功法傳授 難度（DC） −5；每月靈石補貼 ×1.5 |
| 3 | 41-60 | **親近** | 師父可消耗自身修為為弟子護法（突破 +10）；可學習師父獨門武技 |
| 4 | 61-80 | **如子** | 師父願為弟子擋致命一擊（1次/年）；可繼承師父部分人脈 |
| 5 | 81-100 | **衣缽** | 師父傾囊相授；獲得師父的獨門神通傳承；師父隕落後弟子繼承其遺產 |

### 親密度變化

| 行為 | 親密度變化 |
|------|:----------:|
| 完成師父指派的任務 | +1d10 |
| 在宗門大比中獲得好名次 | +2d10（前3名額外 +5） |
| 突破境界並向師父報喜 | +1d10（大境界 +2d10） |
| 向師父進獻稀有物品（地級以上） | +物品品級 × 5 |
| 拒絕師父的任務 | −1d10 |

| 師父給弟子擋致命一擊 | +20（一次性） |

### 親密度晉升條件

親密度達到每個等級的上限後，不會自動晉升——需完成一次**晉升試煉**。以下為通用規則，各 NPC 可能有個別要求（見第十五節）。

| 晉升 | 所需親密度 | 晉升試煉 | 失敗後果 |
|:----:|:----------:|----------|----------|
| **初識 → 信任** | 20 | 完成師父指派的 1 次任務（無需檢定） | 無（可重複嘗試） |
| **信任 → 親近** | 40 | 通過師父的「道心考驗」（d100 ≤ 道心+20）或完成 3 次任務 | 親密度 −1d10；1 月後可重試 |
| **親近 → 如子** | 60 | 完成師父的「真傳試煉」（GM 設計一個專屬任務，通常涉及戰鬥、道德抉擇或重大犧牲） | 親密度 −2d10；3 月後可重試 |
| **如子 → 衣缽** | 80 | 師父提出「衣缽之問」——一個關於修道理念的終極問題。弟子 RP 回答，GM 裁定是否通過（輔以 d100 ≤ 道心+30 的檢定） | 親密度 −3d10；1 年後可重試 |

> **GM 提示**: 晉升試煉是劇情高光點。如子試煉建議作為一次獨立 session 的核心內容；衣缽之問建議安排在重大劇情轉折處，讓弟子的回答影響後續劇情走向。

| 鎮北真君 | 「北疆若破，中州必亡。若需你以壽命封魔淵——願嗎？」 | d100 ≤ 道心+20 | **合格**: 在10秒內平靜地回答「願」。**優秀**: 回答「願」並說出你想保護的具體之人/之物。**失敗**: 猶豫超過10秒、反問「封魔淵要多少年壽命？」——鎮北真君要的是義無反顧 |
| 天涯子 | 「徒弟會超越你、取代你、遺忘你——你還教嗎？」 | d100 ≤ 道心+20 | **合格**: 三次追問都不動搖。**優秀**: 第三次反問天涯子：「那你當年為什麼教我？」——天涯子會大笑。**失敗**: 任何一次回答出現猶豫或矛盾。天涯子追問：①「若他超越你後看不起你？」②「若他取代你成為天機府主？」③「若他飛升後千年不來看你一眼？」 |

> **GM 裁定準則**: 衣缽之問無「正確答案」。通過標準是弟子的回答是否真誠、是否符合其修道之路、是否能讓師父看到自己的影子。擲骰為輔助，RP 為核心。若 RP 極度出色，GM 可跳過檢定直接通過；若 RP 明顯敷衍，即使擲骰成功也可裁定失敗。

## 14.7 成為師父（高階玩法）

當玩家達到 **金丹中期** 且宗門許可（或散修聲望 ≥ 30），即可收徒。

### 收徒流程

1. 發現有潛質的 NPC/其他玩家（NPC 資質由 GM 暗投）
2. 進行拜師儀式
3. 師徒緣分檢定

### 收徒收益

| 徒弟成就 | 師父收益 |
|----------|----------|
| 徒弟每次突破 | 師父獲得修為 = 徒弟境界經驗 × 10%（天道回饋） |
| 徒弟名揚天下（聲望 ≥ 60） | 師父聲望 +1d10 |
| 徒弟開創流派 | 師父獲得「祖師」稱號；聲望 +20 |
| 徒弟飛升 | 師父壽命 +100 年；可窺見天道一角（道心 +1d10） |

---

> **設計說明**: 師徒系統是修仙世界最核心的社交關係之一。本系統同時兼顧了：儀式感（拜師禮）、數值平衡（親密度與收益掛鉤）、風險回報（師父品級越高義務越重）以及長期玩法（成為師父後有新目標）。


## 14.8 特殊師徒傳承

以下為部分隱世高人持有的獨特傳承，無法通過普通功法傳授獲得，僅在特定師徒關係達到**衣缽**級親密度時方可觸發。

### 劍道種子（獨孤無極專屬）

| 項目 | 內容 |
|------|------|
| **傳承者** | 獨孤無極（太虛劍宗宗主） |
| **觸發條件** | 親密度 ≥ 衣缽；弟子為劍修 |
| **傳承方式** | 獨孤無極將畢生劍道感悟凝為一枚「劍道種子」，植入弟子識海 |
| **持續時間** | 永久 |

**效果**：弟子選擇一門已修習的劍類功法，將其威力等級直接提升至上限（Lv.Max），無需消耗修為和時間。此後該功法施展時附帶獨孤無極的「無極劍意」——傷害額外 +2d6（無視防禦）。

**限制**：每名弟子僅能獲得一次劍道種子。

---

### 壓制修為之祕（南宮老人專屬）

| 項目 | 內容 |
|------|------|
| **傳承者** | 南宮老人（南宮鶴） |
| **觸發條件** | 親密度 ≥ 如子 |
| **傳承方式** | 南宮老人親授——他已在金丹圓滿壓制修為 50 年不突破 |

**效果**：弟子習得後可隨時選擇「壓制境界」，效果如下：

| 壓制層數 | 效果 |
|:--------:|------|
| 1 層 | 突破 難度（DC） +5；當前境界屬性上限 +5；遭遇天劫時傷害 −10% |
| 2 層 | 突破 難度（DC） +10（累計）；屬性上限 +10；天劫傷害 −20%；同境界對戰時先攻 +10 |
| 3 層 | 突破 難度（DC） +20（累計）；屬性上限 +15；天劫傷害 −30%；可越 1 階戰鬥無懲罰 |

每壓制 10 年自動獲得 1 層（上限 3 層）。一旦選擇突破，所有層數清零。

> **設計意圖**: 適合不追求快速突破、想在當前境界深耕的玩家。南宮老人就是靠這招在金丹圓滿就有了接近元嬰的戰力。

---

### 血煞灌頂（血煞魔君專屬·魔道）

| 項目 | 內容 |
|------|------|
| **傳承者** | 血煞魔君 |
| **觸發條件** | 親密度 ≥ 衣缽；弟子境界 ≥ 金丹；非正義陣營 |
| **傳承方式** | 師父消耗 3 級修為，以自身精血為引強行灌頂 |
| **⚠️ 風險** | 此為魔道祕法，正道玩家使用後陣營永久轉為魔道 |

**效果**：
- 弟子當前境界即刻突破（跳過天劫檢定）
- 突破後獲得臨時 buff「血煞沸騰」（7 天內全屬性 +10，但每天 生命值（HP） −5%）
- 永久獲得被動「嗜血」：擊殺敵人後回復 生命值（HP） × 擊殺目標境界係數 × 5%

**代價**：
- 心魔檢定 難度（DC） +20（灌頂時觸發——若失敗則走火入魔）
- 永久失去 1 條非暗系靈根（被血煞吞噬）
- 師父消耗 3 級修為（至少需要 1 年恢復）

### 逆天改命（天涯子專屬）

| 項目 | 內容 |
|------|------|
| **傳承者** | 天涯子（天機府前任府主） |
| **觸發條件** | 親密度 ≥ 衣缽 |
| **使用次數** | 終生 1 次 |

**效果**：弟子遭遇必死檢定時（d100 擲出 00 或 生命值（HP） 歸零的致命一擊），天涯子以自身壽命為代價強行幹預因果——該次檢定改為成功，或該次致命傷害改為 生命值（HP） 剩餘 1。

**代價**（由天涯子承受）：
- 天涯子壽命 −50 年（永久）
- 天涯子 1 年內無法使用任何推演類神通（天機反噬）
- 使用後天涯子會陷入短期虛弱（全屬性 −20，持續 30 天）

**GM 注意**：此為劇情級能力，不建議讓玩家輕易使用。天涯子會在弟子真正值得拯救時纔出手——他可以選擇「不出手」，由 GM 根據劇情判斷。

---

> **設計說明**: 特殊傳承的存在使拜師不僅是數值收益，更成為角色塑造的核心——每個隱世高人都有一個「為什麼只有我能教你這個」的獨特理由。
