# 星艦突擊登艦隊 — 中英術語表（Glossary: Starship Boarding Assault TRPG）

> 格式慣例：中文全稱（縮寫）→ English Full Name (ABBR)。

## 一、五大屬性（Five Attributes）
- 戰術（TAC）→ Tactics (TAC)
- 工程（ENG）→ Engineering (ENG)
- 機動（MOB）→ Mobility (MOB)
- 感知（PER）→ Perception (PER)
- 韌性（RES）→ Resilience (RES)
- 屬性修飾值 → Attribute Modifier
- 熟練加值 → Proficiency Bonus
- 環境修飾值 → Circumstance Modifier

## 二、核心機制（Core Mechanics）
- d20 擲骰系統 → d20 Roll System
- 檢定 → Check；檢定結果 = 1d20 + 屬性修飾值 + 熟練加值 + 環境修飾值
- 難度等級（DC）→ Difficulty Class (DC)
- 成功 / 失敗 → Success / Failure
- 優勢（擲 2d20 取高）→ Advantage (roll 2d20, take higher)
- 劣勢（擲 2d20 取低）→ Disadvantage (roll 2d20, take lower)
- 重投 → Reroll；暴擊 → Critical (Crit)
- 行動點（AP）→ Action Points (AP)
- 回合 → Round；階段 → Phase
- 先攻（INIT）→ Initiative (INIT)
- 五階段任務流程 → Five-Phase Mission Flow：切入（Breach）→ 突入（Enter）→ 推進（Advance）→ 目標（Objective）→ 撤離（Extract）
- 自毀倒數 → Self-Destruct Countdown
