# The Hero's Proof— Skill Catalog

> Source: system finalization (Chapter 6 Class, spec locked) , Traditional Chinese, terms use"Chinese full name (abbreviation)"format。
> General rules: 
> - Each class **4 Active(incl. Utility) +  2 Passive  =  6 Base Skill** (ClassLv 1–10) 。
> - SkillDamage/Healing/Shield  =  `Base Value (B)  × f(Skill Level) × (1 + relevant attribute modifier M / 6)`。
> - Skill Level (SkillLv)multiplier `f(n) = 1 + n(n−1)/8` → **Lv1–5 = 1.00 / 1.25 / 1.75 / 2.50 / 3.50**。
> - SPcost `C(n) = 4 + n(n−1)/2` → **Lv1–5 cumulative 4 / 5 / 7 / 10 / 14, max levelcumulative 14 SP** (see §VIII note) 。
> - Utility Skill: fixed 1 level, cost 2 SP, prohibitedcarryingnumeric bonus。
> - attribute multiplier divisor is **6** (STR skills use STR, DEX skills use DEX, MAG skills use MAG; Healing/Aegis use MAG) 。
> - **Four-stage Three-path System**: Base Class (ClassLv 1–10) → at ClassLv 10 from"3 entrySecond StagePath"choose one (**choose one of three, irreversible**, unlock CL11, Lv11–20) → **Third-stage Mastery** (unlock CL21, Lv21–30) → **Fourth-stage Ultimate** (unlock CL31, Lv31–40, max level 40) 。throughoutsingle class, skills and passives accumulate, no multiclass。
> - **Attack Skill Cooldown**: marked in table"—"(no cooldown)'sAttack Skilltreated as"once per short rest" (samePlayer Book §7.3) ; sameAttack Skilllimited to 1 use per round。

> Path naming uses **Ke Jiaoling"07_Races_and_Classes_Architecture_Rebuild"§2 table as the sole standard** (this versionaligned, voiding old draft and system finalization's"four-direction"naming) 。
