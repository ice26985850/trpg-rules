# The Hero's Proof — Spell Catalog

> Data source: system final draft (Chapter 6 Class Skills + Chapter 7 Spellcasting (7.9)), Traditional Chinese, terms use the "Chinese full name (abbreviation)" format.
> General rules:
> - Casting = one "Active Skill" action, consuming **Action Point (AP) 1–3 + Mana Point (MP)**.
> - Attack spell damage = `Base (B) × f(SkillLv) × (1 + Magic Modifier (M_MAG) / 6)`; healing / ward = `B × f(SkillLv) × (1 + M_MAG / 6)`.
> - Skill Level (SkillLv) multiplier `f(n) = 1 + n(n−1)/8` → **Lv1–5 = 1.00 / 1.25 / 1.75 / 2.50 / 3.50**.
> - Damage type Resistance / Weakness / Immunity: ×0.5 / ×1.5 / ×0 (applied after damage reduction). Physical (Pierce / Slash / Bludgeon) / Elemental (Fire / Frost / Lightning / Acid) / Mystic (Holy / Shadow / Psychic).
> - Range: Melee 1 tile / Short 2–4 tiles / Medium 5–10 tiles / Long 11+ tiles. Area Effect (AOE) = center tile + radius R tiles.

---

## 0. Spell Acquisition Rules (Learning / Unlocking)

Spells are not all mastered at birth; they must be learned through one of the following paths, and are constrained by "level unlocking" and "medium":

1. **Class Spell**: The "magic-type" Active Skills of the seven classes (such as Fireball, Frost Nova, Lightning Chain, Healing Light, etc.) are obtained together with the class at character creation, and correspond to the entries in Chapters 1–7 of the *Skill Catalog* as the **same spell** (see the "Overlap Note" below), and do not additionally occupy a Skill Point (SP).
2. **Spell Slot Unlocking**: Non-magic classes (Warrior / Monk / Thief / Hunter / Dancer) can each unlock 1 "General Spell Slot" when Class Level (ClassLv) reaches 5 / 10 / 15, to learn spells from "VII. General Spells" in the *Spell Catalog* (such as Magic Missile, Detect Magic).
3. **Scroll / Medium**: Spell scrolls obtained as loot or exchanged at temples are permanently learned after being transcribed at the cost of Influence Points (IP) or Gold (G) (usable across classes; costs and restrictions see Chapter 14, 14.4 of the GM Book); one-time scrolls are consumed for a single encounter.
4. **Level Unlock Threshold**: High-tier spells (Mana Point (MP) cost ≥10, or three-stage mastered same-name spell) require Class Level (ClassLv) ≥ corresponding stage (Stage 2 = 11 / Stage 3 = 21) to cast; those below the threshold cannot chant even if learned.

**Overlap Note with the *Skill Catalog***: Chapters 1–7 of the *Skill Catalog* list class skills by "class" (including the magic classes' attack / healing spells), and the school entries "I–VI" of this catalog have **completely identical values, being two perspectives of the same spell** — the former is for character creation and class balance reference, the latter for spell mechanics / school / cross-class learning reference; please cite one or the other, do not double-count. The "VII. General Spells" of this catalog is cross-class exclusive, not found in the class skill tables, and any class can learn it via paths 2 / 3 above.
