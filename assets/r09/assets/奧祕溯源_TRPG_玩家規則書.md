# 第一章：核心規則

## 1.1 骰子系統

### 核心引擎：2d10 + 屬性值

```
檢定結果 = 2d10 + 屬性值 + 專精加值 + 設施加值 + 其他修正
```

### 大成功 / 大失敗

| 結果 | 條件 | 頻率 | 效果 |
|------|------|------|------|
| **大成功** | 雙10 | 1% | 效果最大化 + 額外敘事收益 |
| **大失敗** | 雙1 | 1% | 自動失敗 + 可能觸發負面後果 |

### 優勢 / 劣勢

| 狀態 | 規則 | 期望值變化 |
|------|------|-----------|
| **優勢** | 擲 4d10，取最高的兩個 | 約 +3.3 |
| **劣勢** | 擲 4d10，取最低的兩個 | 約 –3.3 |

> 優勢和劣勢互相抵消（不論各自數量）。大成功/大失敗仍以原始兩骰為準（若原始骰為雙10，即使優勢也只取一組雙10判斷）。

## 1.2 屬性體系

### 五大屬性

| 屬性 | 含義 | 在研究迴圈中的角色 |
|------|------|-------------------|
| **感知** | 觀察力、對魔法現象的敏感度 | 觀察階段 |
| **理論** | 邏輯推理、因果分析、學術素養 | 假設和分析階段 |
| **技藝** | 精密操作、儀式執行、材料處理 | 實驗階段 |
| **意志** | 精神韌性、抵抗魔法反噬 | 實驗失敗時「你還撐得住嗎」 |
| **博學** | 既有知識儲備、文獻查閱 | 文獻研究 |

### 屬性值含義

| 屬性值 | 含義 |
|--------|------|
| 1 | 災難級——這方面是公認的災難 |
| 2–3 | 薄弱——明顯低於同行平均 |
| 4–5 | 合格——獨立法師的基礎水準 |
| 6–7 | 優秀——同行中的佼佼者 |
| 8 | 卓越——已觸及凡人天賦的極限 |
| 9–10 | 傳奇——僅能透過特殊事件或設施突破達成 |

> **屬性直接作為修正值。** 屬性 5 就是 +5，屬性 8 就是 +8。

## 1.4 生命值與傷害

### HP 計算

```
最大HP = 15 + 意志
```

意志直接貢獻HP——精神強韌的法師更能承受傷害。

### HP 成長

| 途徑 | HP 增加 |
|------|---------|
| 意志屬性提升（每+1） | 最大HP +1 |
| 任一屬性達到8 | 最大HP +5（一次性） |
| 實驗室達到Lv5 | 最大HP +5（一次性） |

HP 理論最大值：15 + 10（意志10）+ 5（屬性8）+ 5（實驗室Lv5）= 35。

### 受傷與死亡

**HP降至0**：陷入**瀕死**狀態——失去意識，無法行動，每回合開始時進行**死亡豁免**。

**死亡豁免**：擲 2d10（無屬性修正）：
- 結果 ≥ 10：一次成功
- 結果 < 10：一次失敗
- 雙1：兩次失敗
- 雙10：恢復至 1 HP，甦醒

累計 **3 次成功**：穩定——不再需要死亡豁免，1d4 小時後恢復至 1 HP。  
累計 **3 次失敗**：死亡。

**受到傷害時（瀕死中）**：自動計為一次失敗。若為重擊（雙10攻擊），計為兩次失敗。

### HP 恢復

| 方式 | 恢復量 |
|------|--------|
| 短休 | 恢復 意志值 點HP（至少1） |
| 長休 | 恢復全部HP |
| 「生命」元素法術 | 見法術效果 |
| 塔樓維護行動 | 不恢復HP（僅恢復塔樓HP） |

## 1.5 休息規則

### 短休
- **時間**：1 小時的輕度活動（閱讀、整理筆記、冥想）
- **地點**：塔樓內，或野外安全地點（GM判定）
- **效果**：恢復一半最大靈性（向下取整）+ 恢復 意志值 點HP
- **限制**：每次長休之間最多進行 2 次短休

### 長休
- **時間**：8 小時（至少 6 小時睡眠 + 2 小時輕度活動）
- **地點**：必須在安全地點——塔樓、有防禦的營地、旅館等
- **效果**：恢復全部靈性 + 恢復全部HP + 移除一級疲勞
- **限制**：每 24 小時只能進行一次長休
- **中斷**：若長休被戰鬥或緊急事件中斷超過 1 小時，需重新開始

### 野外宿營
- 在野外進行長休需要成功建立營地：**感知或技藝 DC10**
- 失敗：仍可長休，但恢復效果減半（靈性和HP各恢復一半）
- 大失敗：夜間遭遇野外威脅（GM擲遭遇表）

### 疲勞
- 每 24 小時未進行長休，獲得一級疲勞
- 疲勞等級：1=全檢定–1；2=速度減半；3=全檢定劣勢；4=HP減半；5=無法行動；6=死亡
- 每次長休移除一級疲勞

## 1.7 研究迴圈

```
確定目標 → 觀察(感知) → 假設(理論) → 準備(消耗材料) → 實驗(技藝) → 分析(理論)
```

### 事故觸發規則

實驗失敗時：
- **事故差額（DC – 檢定結果）≤ 安全閾值**：材料消耗，未得碎片，可重試
- **事故差額 > 安全閾值**：觸發 d20 實驗事故表（GM參照）

---

## 1.8 靈性透支

當法術的靈性消耗超過當前靈性池時，可「透支」施法：
- 每透支 1 點靈性，受到 1d4 力場傷害（不可減免）
- 透支的靈性在下次長休時優先歸還
- 若透支導致 HP 降至 0，施法者失去意識且法術失敗（靈性已消耗不退還）

## 2.4 第3步：研究風格

> **一旦選擇，不可更改。**

### 實證派
**優勢**：實驗技藝檢定優勢；事故表擲兩次取低  
**代價**：材料×1.3；執行實驗+1AP（失敗時回收30%材料）
**學派進階**：10+標準化流程(DC–2) → 30+實驗室自動化(免費快速實驗) → 60+方法論奠基

### 直觀派
**優勢**：假設零消耗；實驗DC–2  
**代價**：事故表d12+8(9–20)；筆記不可復現(DC+2)  
**學派進階**：10+靈光一閃 → 30+直覺洞察 → 60+正規化突破

### 文獻派
**優勢**：圖書館罕見起跳(50%/35%/15%)；圖書館理論優勢；零事故  
**代價**：30%隱藏錯誤；實驗技藝劣勢  
**學派進階**：10+交叉引用 → 30+文獻鑑定 → 60+百科全書

### 禁忌派
**優勢**：實驗DC–4；傳說碎片×2  
**代價**：意志DC15/實驗(失敗腐化+2)；學術聲望上限30；腐化20→NPC化  
**學派進階**：10+暗影通道 → 30+(上限)禁忌加速(×3, DC升至18)

### 協作派
**優勢**：合作雙方獲益；每協助者DC–2(最多–6)  
**代價**：獨立DC+3；發表即公開碎片  
**學派進階**：10+研究網路 → 30+聯合發表(不公開) → 60+學派召集

**DC修正疊加順序**：先計算基礎DC → 加風格修正（+3或–2/人） → 減設施/材料修正 → 最後應用優勢/劣勢。

## 2.10 成長與進階

## 2.16 法術書與記憶

### 法術書容量

```
可記憶法術數量 = 理論 + 博學
```

- 起始法師（理論3–5, 博學3–5）可記憶 6–10 個法術
- 超過容量的法術仍記錄在筆記中，但無法在冒險中快速施放
- 在塔樓中可花 1AP 交換記憶中的法術

### 施放已創法術

- 已創造並記錄的法術可重複施放，每次支付靈性消耗
- 不需要重新進行法術組合檢定
- 法術所有引數（傷害骰、DC、持續時間）在**創造時鎖定**——基於創造時的理論值和品質等級
- 若理論值提升，已創造的法術不會自動變強——需重新創造一個新版本

### 施法失敗的靈性處理

| 情況 | 靈性 |
|------|------|
| 法術攻擊未命中 | 全額消耗 |
| 目標豁免成功（半傷） | 全額消耗 |
| 專注被中斷 | 已消耗，不退還 |
| 被反制 | 已消耗，不退還 |
| 施放過程被中斷（如儀式被打斷） | 退還一半（向下取整） |

> **核心原則**：靈性在法術完成施放瞬間全額支付。只要法術「離手」，靈性即消耗。

### 持續法術的鎖定

- 施放時鎖定所有引數（持續回合數、DC、效果）
- 施放後即使理論值變化，已啟動的持續法術不受影響
- 專注中斷：法術立即結束，靈性不退還

## 3.1 法術創造原理

### 核心公式

```
法術 = 元素(1–3) + 形式(1–2) + [介質(0–2)] + [約束(0–2)]
```

最小2碎片，建議最大7碎片。

1. 選元素（1–3）→ 傷害型別與主效果
2. 選形式（1–2）→ 射程/範圍/持續
3. 可選介質（0–2）→ 條件換增益
4. 可選約束（0–2）→ 代價換收益
5. 計算品質（最高稀有度）
6. 計算靈性消耗
7. 命名 → GM審核

## 3.11 禁忌碎片的獲取路徑

禁忌元素（血液、靈魂、混沌）DC30——這是純屬性不可達的天花板。達成路徑：

```
DC30 = 2d10 + 8(意志/理論) + 5(專精大師) + 5(設施Lv5) = 2d10 + 18
```

加上：元素室(–5) + 稀有材料(–3) + 文獻(–2) = 淨DC20  
2d10+18 vs DC20 = 64%成功率。

**投入頂級資源**（禁忌派DC–4）：淨DC16  
2d10+18 vs DC16 = 85%成功率。

**禁忌派的傳說加速**（獲得率×2或×3）進一步提升效率。這意味著傳說禁忌碎片的研究是一生的追求——不可能輕易達成，但並非不可能。
