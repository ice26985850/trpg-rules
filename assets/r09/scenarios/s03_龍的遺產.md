# 劇本三：「龍的遺產」

| 屬性 | 內容 |
|------|------|
| **建議品質** | ★★★–★★★★ 專家級至大師級 |
| **玩家人數** | 2–4 名法師 |
| **預計團次** | 3–4 次 |
| **核心產出** | 傳說級火焰碎片（◈） |
| **主要威脅** | 龍、龍族長老議會、競爭法師團隊 |
| **前置** | 至少一名玩家學術聲望 ≥30；或禁忌派傳說加速 |

## 背景

在北方的永冬冰原深處，一條名為**伊格納瑞斯**的古代火龍正在老去。龍族長老議會的一位使者——**瓦拉斯特拉**——發出了罕見的邀請：允許人類法師參與龍的「臨終儀式」。

龍的死亡不是終結——牠們會將畢生的魔法精華凝聚成一個傳說碎片，然後身體化為元素，回歸星辰之織。伊格納瑞斯願意將這個碎片交給「能證明自己值得的人類」。

但消息已經走漏。至少三個法師團隊正在趕往永冬冰原——包括玩家的競爭對手。

## 第一幕：瓦拉斯特拉的試煉

### 場景：龍族長老議會的冰殿

瓦拉斯特拉是一條三千年歷史的銀龍，以人類形態（一位白髮老嫗）接見了玩家。

> 「伊格納瑞斯的碎片可能是有史以來最純淨的火焰碎片。但龍的遺產不屬於貪婪之人。為了證明你們的價值——你們必須先證明你們的知識。」

**試煉內容**（每個玩家必須完成至少一項）：

1. **知識試煉**（博學或理論 難度等級（DC）18）：回答瓦拉斯特拉關於龍族歷史和魔法理論的三個問題
2. **技藝試煉**（技藝 難度等級（DC）18）：在不使用魔法工具的情況下，徒手穩定一個不穩定的元素樣本
3. **意志試煉**（意志 難度等級（DC）18）：直視龍族幻象——伊格納瑞斯的千年記憶——而不失去自我

**成功獎勵**：通過試煉的玩家獲得瓦拉斯特拉的認可和「龍語者印記」——使用火焰碎片時，法術攻擊 +1。

**失敗後果**：未通過試煉的玩家仍可參與，但在接下來的挑戰中所有檢定劣勢（「龍族在觀察你」）。

## 第二幕：穿越冰原

### 區域 1：冰風峽谷

**威脅**：極寒天氣和冰元素生物。

**環境效果**：每在冰原中行進 4 小時，體質 難度等級（DC）12 否則獲得一級疲勞。

**可發現物**（感知 難度等級（DC）15）：
- 冰元素結晶（罕見冰霜碎片的前體材料）
- 古代龍族符文石（記錄了龍的歷史——博學 難度等級（DC）14 解讀，價值 150 金幣（GP） 或可用於學術論文 +1d6 聲望）

#### 敵人：冰元素 ×2
| 屬性 | 數值 |
|------|------|
| 生命值（HP） | 30 |
| 護甲等級（AC） | 15 |
| 攻擊 | 2d10+3 冰霜（法術攻擊，射程 40 尺，命中後速度 –15 尺） |
| 特殊能力 | 冰霜光環——10 尺內每回合開始 1d4 冰霜傷害；寒冷免疫；火焰弱點 ×1.5 |
| 戰術 | 兩隻冰元素會前後夾擊，一隻吸引注意，另一隻從後方攻擊 |

### 區域 2：伊格納瑞斯的巢穴入口

**敘事**：一個巨大的洞穴入口。洞壁上刻滿了龍族符文，散發著微弱的紅光。洞穴深處傳來深沉的呼吸聲——像是地殼在移動。

**第二道試煉**：洞穴入口前站著龍族守衛——一條年輕的火龍**澤菲羅斯**。

> 「伊格納瑞斯只願意見那些能證明自己對火焰有理解的人。向我展示——你們的法術。」

**試煉**：每個玩家必須展示一個含有火焰元素的法術。澤菲羅斯會根據法術的特性和創造力來評判：

| 評判標準 | 通過門檻 |
|----------|----------|
| 學徒級火焰法術 | 勉強及格——澤菲羅斯不以為然但放行 |
| 含有火焰元素交叉的法術 | 澤菲羅斯讚賞——未來火焰 難度等級（DC） –1 |
| 用傳說級火焰碎片創造的法術 | 澤菲羅斯震驚——直接帶你去見伊格納瑞斯 |

## 第三幕：龍的臨終儀式

### 場景：伊格納瑞斯

伊格納瑞斯是一條體長超過兩百尺的古代火龍。牠的鱗片已經從鮮紅褪為灰白，牠的每一次呼吸都伴隨著巖漿的湧動。但牠的眼神仍然銳利。

> 「我見過一千個冬天，一千個夏天。我看過人類從洞穴中走出，學會了火——然後學會了馴服火。現在，你們中只有一個人能帶走我的火焰。」

### 競爭——其他法師團隊

伊格納瑞斯允許所有到達的法師團隊參與。玩家將面對：

**團隊 A：阿爾伯特·奧雷利安的學院代表團**
- 阿卡迪亞皇家魔法學院的精英研究員
- 領隊：**莉迪亞·炎心**（實證派，理論 8，技藝 7，專精火焰）
- 優勢：頂級研究設備和學術資源
- 弱點：過度依賴標準化流程，缺乏創造力

**團隊 B：禁忌研究者的精英**
- 地下網絡派出的兩人組
- 領隊：**「灰燼」**（禁忌派，意志 8，理論 7，腐化 12）
- 優勢：不擇手段——他們的實驗 難度等級（DC） –4 且使用禁忌加速
- 弱點：高腐化值可能隨時觸發災難性後果

**團隊 C：玩家的競爭對手**（從角色卡導入）

### 核心挑戰——穩定伊格納瑞斯的臨終碎片

伊格納瑞斯開始儀式後，牠的魔法精華會以不穩定的形態釋放。誰能在規定時間內穩定並捕獲它？

**挑戰機制**（時間限制：5 回合）：

每個回合，所有團隊同時進行一次技藝檢定（各自的風格修正）。累計成功次數最多的團隊獲得碎片。但──

**第 3 回合事件**：伊格納瑞斯的魔法釋放失控——全場火焰傷害 3d6（敏捷 難度等級（DC）15 減半）。此時「灰燼」會嘗試使用禁忌方法強行穩定碎片——這可能導致儀式崩潰。

**玩家抉擇**：
1. **競爭到底**：繼續自己的穩定嘗試（檢定 難度等級（DC）20）
2. **阻止灰燼**：使用法術對抗阻止禁忌操作（法術碰撞或意志對抗 難度等級（DC）18）
3. **協助伊格納瑞斯**：使用生命或光耀法術幫助龍穩定自身（理論 難度等級（DC）16）

**大成功分支**：玩家使用含有光耀+火焰雙元素的法術——完美地平衡了龍的混沌火焰。伊格納瑞斯認可玩家的技藝和智慧。傳說碎片自動歸玩家所有，其他團隊心服口服。

**「灰燼」腐化爆發分支**（如果灰燼在第 3 回合未被阻止）：腐化值觸及 15 點閾值——灰燼的碎片被替換為腐化版本，儀式崩潰，全場受到 6d6 火焰+2d8 虛空傷害。伊格納瑞斯強行中斷儀式——碎片不完整（降為稀有級）。
