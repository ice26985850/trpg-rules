# 劇本二：「深淵之門」

| 屬性 | 內容 |
|------|------|
| **建議品質** | ★★–★★★ 正式級至專家級 |
| **玩家人數** | 2–4 名法師 |
| **預計團次** | 2–3 次 |
| **核心產出** | 虛空碎片（稀有）+ 空間碎片（罕見） |
| **主要威脅** | 守望者議會的審查、禁忌研究殘留物、異界生物 |
| **前置** | 至少一名玩家學術聲望 ≥10 或禁忌派 |

## 背景

阿什維爾廢墟——紀元 1102 年大爆炸的地點——最近出現了新的魔法波動。守望者議會正在祕密組織一支考察隊，名義上是「學術考察」，實際上是調查是否有禁忌研究者正在廢墟中進行非法實驗。

但在此之前，一條匿名消息通過禁忌研究網絡傳出：廢墟深處的虛空裂隙仍然活躍。裂隙中偶爾會「吐出」極其稀有的虛空碎片——如果能在守望者之前拿到它們。

## 第一幕：兩個邀請

玩家同時收到兩個消息：

**消息 A**（守望者議會）：一封正式的信函，邀請「學術聲望良好的法師」參加阿什維爾廢墟的學術考察隊。參加者可獲得 200 金幣（GP） 的研究補助和優先獲取考察發現的權利。

**消息 B**（禁忌網絡）：一張沒有署名的羊皮紙出現在玩家的實驗室桌上。上面只有一行字：「廢墟第三層。新月之夜。帶一個空的碎片容器。」

**玩家選擇**：
- 接受守望者邀請 → 正規路線，低風險低迴報
- 跟隨禁忌線索 → 高風險高回報，但可能被守望者發現
- 兩邊都參加 → 雙面間諜——風險最高，回報也最高（但一旦被發現後果嚴重）

## 第二幕：深入廢墟

### 區域 1：廢墟表面——守望者營地

如果玩家選擇正規路線：

**守望者考察隊 NPC**：
- **隊長奧莉薇亞·鐵壁**：資深守望者，意志 8，對禁忌研究零容忍
- **研究員提比略**：年輕的學院法師，理論 7，好奇心過剩
- **傭兵隊長加雷特**：負責保護考察隊，技藝 7

營地中，玩家被分配任務：使用感知和理論檢定繪製廢墟的魔法殘留地圖。

**隱藏情報**（感知 難度等級（DC）15 或博學 難度等級（DC）14）：
> 你在繪製地圖時注意到一個異常：廢墟第三層的魔法殘留圖案和標準的爆炸殘留不符。爆炸是從中心向外擴散的——但第三層的魔法痕跡是**從外向內匯聚**的。這不是爆炸的痕跡——這是某種**召喚儀式**的殘留。

如果玩家將此發現報告給奧莉薇亞，她會變得異常緊張，並禁止任何人靠近第三層。如果玩家保密，這會成為一個有價值的情報。

### 區域 2：第一層——魔法殘留區

**威脅**：殘留的魔法能量形成了不穩定的元素陷阱。

**前進檢定**（每次前進一個區域需要一次檢定）：
- 感知 難度等級（DC）13 察覺陷阱
- 技藝 難度等級（DC）13 解除或繞過
- 失敗：隨機元素傷害 1d6（擲 d6：1–2=火焰，3–4=冰霜，5=雷電，6=力場）

**可發現物**（感知 難度等級（DC）14）：
- 阿什維爾的實驗日誌碎片（普通級文獻碎片）——內含關於虛無碎片穩定化的失敗嘗試記錄
- 一個被時間侵蝕但仍可使用的稀有材料（鳳凰灰——價值 100 金幣（GP））

### 區域 3：第二層——地下實驗室

**敘事**：這是阿什維爾爆炸前的主實驗室。牆壁上仍然嵌著燒焦的符文。實驗臺的抽屜裡有一些密封的樣本瓶。

**核心挑戰**：一個因殘留魔法而活化的**魔法守衛**守護著實驗室的核心區域。

#### 敵人：活化魔法守衛
| 屬性 | 數值 |
|------|------|
| 生命值（HP） | 40 |
| 護甲等級（AC） | 14 |
| 攻擊 | 2d10+4 力場，射程 30 尺（法術攻擊） |
| 特殊能力 | 魔力吸收——每當受到法術傷害，恢復等同於施法者理論值一半的 生命值（HP） |
| 弱點 | 物理攻擊（非魔法武器正常傷害）；可被技藝 難度等級（DC）15 解除（拆除核心符文） |

**戰術提示**：活化守衛是對法師的考驗——純粹的法術攻擊會餵養它。玩家需要合作：一人吸引守衛注意，另一人尋找並解除核心符文。

**擊敗獎勵**：
- 核心符文（罕見約束碎片——可作為「冷卻」約束使用）
- 實驗室日誌（罕見文獻碎片——內含關於虛空碎片萃取的正確方法、難度等級（DC）–2）

### 區域 4：第三層——虛空裂隙

**敘事**：地下實驗室最深處。天花板塌陷了一半，月光從裂縫中灑下來。在地面上，有一道大約三尺長的黑色裂縫——虛空裂隙。它看起來像是空間本身被撕裂了。裂隙邊緣的物質在緩慢地「流淌」——方向是從外向內，正如玩家在營地發現的異常。

**核心挑戰**——獲取虛空碎片：

**方法 A：萃取（實證派/直觀派推薦）**
- 技藝檢定 難度等級（DC）16 + 稀有材料（鳳凰灰或龍鱗片）
- 成功：獲得虛空碎片（稀有級） + 空間碎片（罕見級）
- 失敗（安全閾值內）：材料消耗，虛空裂隙變得不穩定（難度等級（DC） +2 下次嘗試）
- 大失敗（超過安全閾值）：裂隙擴大，釋放異界生物（見下文敵人）

**方法 B：直接抓取（禁忌派推薦）**
- 意志檢定 難度等級（DC）15 + 技藝檢定 難度等級（DC）12（禁忌派 難度等級（DC）–4 = 難度等級（DC）8）
- 成功：獲得虛空碎片（稀有級） + 禁忌派傳說獲得率觸發 → 可能獲得 2 個
- 失敗（安全閾值內）：受到 2d10 虛空傷害，腐化 +1
- 大失敗（超過安全閾值）：腐化 +3 + 異界生物釋放

#### 敵人：虛空裂縫行者
| 屬性 | 數值 |
|------|------|
| 生命值（HP） | 60 |
| 護甲等級（AC） | 16 |
| 速度 | 40尺（可短距傳送） |
| 攻擊 | 2d10+5 虛空（法術攻擊，觸及） |
| 特殊能力 | 虛空吞噬——被擊中的目標意志 難度等級（DC）14 否則失去下一個附贈動作；虛空之步——每回合一次附贈動作傳送 20 尺 |
| 弱點 | 力場傷害×1.5；光耀傷害阻止其傳送一回合 |

**戰術提示**：這是第一個真正危險的敵人。裂縫行者會優先攻擊施法者中理論值最高的（「聞到強魔法」）。玩家需要使用光耀傷害限制其機動性，並用力場法術造成實際傷害。

## 第三幕：後果

### 守望者路線
- 奧莉薇亞對玩家的發現表示「感謝」——但要求玩家將虛空碎片交給守望者「安全保管」
- 玩家可以：服從（失去碎片但獲得守望者的信任和 300 金幣（GP））或拒絕（獲得碎片但與守望者關係惡化）
- 如果玩家的禁忌派身分被發現：奧莉薇亞發出正式警告（學術聲望 –2d6，被列入觀察名單）

### 禁忌路線
- 禁忌網絡派人聯絡，表示「你通過了考驗」
- 獲得進入黑市網絡的資格——未來可以用八折價格購買禁忌材料
- 但守望者開始對你產生懷疑（每月有 10% 概率遭遇守望者檢查）

### 雙面間諜路線
- 如果成功兩邊都拿到碎片且未被發現：獲得雙倍碎片 + 禁忌網絡信任 + 守望者津貼
- 如果被守望者發現：最壞情況——被正式起訴「危害公共安全」，塔樓可能被查封
- 如果被禁忌網絡發現：被列入「不可信任名單」——永久失去禁忌網絡的管道

## 結局分支

| 結局 | 條件 | 獎勵 |
|------|------|------|
| **學術英雄** | 正規路線 + 發現祕密 + 服從守望者 | 守望者津貼 300 金幣（GP），學術+2d6，守望者好感 |
| **禁忌學者** | 禁忌路線 + 成功獲取碎片 | 虛空碎片(稀有)+空間碎片(罕見)，黑市資格，禁忌網絡信任 |
| **雙面大師** | 兩邊都成功且未被發現 | 雙倍碎片 + 雙倍信任 + 學術+2d6，實用+1d6 |
| **裂隙釋放者** | 實驗大失敗觸發異界生物 | 可能損失碎片，但擊敗裂縫行者獲得「虛空核心」（傳說材料的前體） |
| **守望者通緝** | 雙面間諜被發現 | 失去所有碎片，塔樓可能被封，需要逃亡荒野 |
