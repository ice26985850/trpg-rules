# Backrooms Walker TRPG — Entity Bestiary

> Entities are not monsters. They are part of the environment. Most should not be fought — you should run, hide, or use environmental rules to counter them.

---

## Smilers

| Item | Details |
|------|---------|
| **Threat Level (TL)** | ★★★ (in darkness) / ☆ (in light) |
| **Appears On** | All dark Levels |
| **Behavior Pattern** | Attacks in darkness — manifests an oversized grin, attacks after staring |
| **Core Weakness** | Light — any effective light source immediately dispels it |
| **Hit Points (HP)** | 15 (when embodied) |
| **Defense (DEF)** | 14 (ethereal in darkness — disadvantage on physical attacks) |
| **Attack Bonus** | +5 (darkness only) |
| **Damage** | 1D4 Physical + SP -1D4 |
| **Key Mechanic** | Lighting system — fully lit (safe) / dim (present but ethereal) / flickering (50% embodied) / dark (fully embodied) |
| **Expulsion Method** | Fully lit source: vanishes instantly. Thrown Almond Water: dispels for 1D3+1 turns. Fire: keep your distance. |

## Shadows

| Item | Details |
|------|---------|
| **Threat Level (TL)** | ★★★ (on contact) / ☆ (no contact) |
| **Appears On** | Level 6 (Blackout) |

| **Core Weakness** | Any light source (emergency light) dispels it; moves slowly |
| **Hit Points (HP)** | 12 (ethereal — disadvantage on physical attacks) |
| **Defense (DEF)** | 12 |
| **Attack Bonus** | +3 (on contact) |
| **Damage** | Shadow vanishes — Agility/Evasion-related checks -1 (permanent; Willpower DC 15 halves it to -0) |
| **Group Size** | 2-4 |

|------|-------------|
| ★☆☆☆☆ | No direct threat — safe to observe |
| ★★☆☆☆ | Minor threat — requires caution but is manageable |
| ★★★☆☆ | Moderate threat — requires a clear response strategy |

| ★★★★★ | Extreme threat — an encounter may be fatal |
