# 宇宙船團經營 TRPG —— 單人模式規則補充 v1.0

> **適用對象：** 1 名玩家 + 1 名主持人
> **前置閱讀：** 玩家手冊 + 主持人（GM） 手冊（核心規則不變，本補充僅修改多人依賴部分）
> **引用標記：** `[玩家§X.X]` = 玩家手冊對應章節 / `[主持人（GM）§X.X]` = 主持人（GM） 手冊對應章節

---

# 第一章：單人模式設計原理

## 1.1 為什麼需要這個補充？

原始規則的核心設計圍繞「船團」——多艘船、多位船長、投票決策。當只有一名玩家時，以下系統無法直接運作：

| 原始系統 | 多人依賴 | 單人替代方案 |
|---------|---------|------------|
| 船團投票 `[玩家§2.6]` `[主持人（GM）§4.7]` | 需多位船長投票 | **船員議會**——玩家與 非玩家角色（NPC） 橋梁船員討論，玩家做最終決定 |
| 船團協同作戰 `[主持人（GM）§1.11]` | 需多艘玩家船 | **僚機系統**——玩家指揮自己的船 + 最多 2 艘 非玩家角色（NPC） 僚機 |
| 船團關係值 `[玩家§2.6]` | 玩家之間互相評分 | **盟友聲望**——與 非玩家角色（NPC） 船長/勢力的友好度 |
| 船員挖角 `[玩家§2.5]` | 其他玩家船長挖你的船員 | **忠誠危機事件**——非玩家角色（NPC） 勢力/敵對船長嘗試挖角 |
| 船團資源共享 `[主持人（GM）§5.2]` | 多船分配資源 | **單船資源管理**——簡化追蹤，由船員議會討論優先級 |

## 1.2 核心設計目標

- 保留「危機管理 × 船員日常」的公路片調性
- 讓 非玩家角色（NPC） 船員從「數據」升級為「角色」——他們是你的船員議會
- 確保戰鬥深度不因單人而減損
- 提供完整 Lv1-10 的成長曲線

# 第二章：船員議會（替代船團投票）

## 2.1 什麼是船員議會？

每當原始規則要求船團投票 `[主持人（GM）§4.7]` 時，改為**船員議會**：

> 你的橋梁船員（大副、工程師、導航官、通訊官）各自根據性格和資訊提出意見。你聆聽後做出**最終決定**——但這個決定會影響船員的忠誠度和士氣。

## 2.2 議會流程

1. **主持人（GM） 描述情境**——需要決策的問題（航線選擇、資源分配、是否接危險委託）
2. **每位橋梁船員發表意見**（主持人（GM） 根據該 非玩家角色（NPC） 的性格和隱藏目標扮演）
3. **玩家可以提問、反駁、或說服特定船員**（交涉（DIP） 對抗檢定）
4. **玩家做出最終決定**
5. **根據決定與各船員立場的吻合度，調整忠誠度**

## 2.3 意見分歧與忠誠影響

| 船員立場 vs 你的決定 | 忠誠變化 |
|-------------------|:------:|
| 船員強烈贊同你的決定 | +1（每章最多 2 次） |
| 船員意見與你不同但你成功說服了 ta | 不變 |
| 船員意見與你不同且你直接否決 | -1 |
| 你連續三次無視同一船員的意見 | -2 |
| 船員的隱藏目標與你的決定衝突 `[主持人（GM）§3.3]` | -1 ~ -4（取決於衝突程度） |

> **設計筆記：** 這保留了原始規則中「投票輸掉的戲劇張力」——只是形式從「被其他船長投票壓過」變成「做出一個你的大副極力反對的決定」。

## 2.4 緊急決策（戰鬥中）

戰鬥中的快速決策保持原規則 `[主持人（GM）§4.7]`，但改為：

- 玩家直接決定（你是船長）
- 但如果玩家猶豫超過 30 秒 → 主持人（GM） 可以讓大副「插話」提出建議
- 大副的建議可能幫助也可能誤導（基於 ta 的 指揮（CMD） 屬性）

# 第三章：僚機系統（替代船團協同）

## 3.1 概述

在單人模式中，你主要指揮自己的船。但在特定情況下，你可以獲得 非玩家角色（NPC） 僚機的支援。僚機不是完整的 PC——它們是簡化版的友方船艦。

## 3.2 僚機類型

| 類型 | 來源 | 可用性 | 控制方式 |
|------|------|:---:|------|
| **盟友船長** | 劇情中結盟的 非玩家角色（NPC） 船長 | 特定任務 / 章節 | 玩家給簡單指令，主持人（GM） 執行 |
| **僱傭護衛** | 花錢僱用 | 付費期間常駐 | 跟隨玩家，自主戰鬥（主持人（GM） 控） |
| **劇情僚機** | 主線劇情特定段落 | 劇情限定 | 主持人（GM） 控制 |

## 3.3 僚機指令

每回合玩家可以給每艘僚機一個簡單指令（不消耗動作）：

| 指令 | 效果 |
|------|------|
| **集中火力** | 僚機攻擊玩家當前目標 |
| **掩護我** | 僚機對攻擊玩家的敵方使用反應攔截（如有點防禦） |
| **保持距離** | 僚機移至遠距，使用遠程武器 |
| **自由行動** | 主持人（GM） 根據僚機船長的性格決定最佳行動 |

## 3.4 僚機簡化規則

僚機不追蹤完整資源（燃料、彈藥等）——主持人（GM） 只需追蹤：
- 船體生命值（HP） 與受損階段
- 能量（簡化：每回合固定回復 2）
- 武器（使用預設配置）

**僚機不會被「挖角」或「忠誠度變化」影響**——它們是劇情工具，不是長期管理對象。

## 3.5 沒有僚機時的戰鬥平衡

當玩家單獨作戰時，主持人（GM） 應：
- 將敵方數量減少 30-50%（相對於多人船團的遭遇）
- 避免使用需要船團協同才能擊敗的 TL3+ 敵人（除非這是有意的高難度挑戰）
- 增加「可選擇是否戰鬥」的遭遇（交涉、繞道、潛行）
- 參考以下單人難度調整表：

| 原始遭遇（多人） | 單人調整 |
|---------------|---------|
| 1d3+1 輕型掠奪艇 | 1d2 輕型掠奪艇 |
| 1 中型 + 1d2 輕型 | 1 中型劫掠艦（無護航） |
| 1 重型旗艦 + 2d3 輕型 | 改為非戰鬥遭遇或給予劇情僚機 |

# 第四章：非玩家角色（NPC） 船員深度系統

## 4.1 橋梁船員的角色升級

在單人模式中，你的 非玩家角色（NPC） 船員**不僅是加值提供者**——他們是你的主要互動對象。建議 主持人（GM） 為每位橋梁船員準備：

| 要素 | 說明 |
|------|------|
| **性格關鍵詞**（3 個） | 快速 RP 參考（如「忠誠、保守、迷信」） |
| **口頭禪** | 一句標誌性台詞 |
| **對船長的看法**（初始） | 崇拜 / 尊敬 / 懷疑 / 畏懼 |
| **個人目標** | 除了隱藏目標外，一個公開的、長期的小目標 |

## 4.2 船員個人故事線

替代原始規則中的「船團內部事件」`[主持人（GM）§4.15]`，改為使用船員個人故事線：

| d12 | 事件 |
|:---:|------|
| 1 | 大副私下請求一次單獨談話——關於船長的某個近期決定 |
| 2 | 工程師在引擎室發現了一個隱藏隔間——可能是前船主的 |
| 3 | 導航官做了一個關於前方星系的噩夢——細節驚人地具體 |
| 4 | 通訊官攔截到一段關於船長的加密訊息——發送者不明 |
| 5 | 醫官請求在下一站停靠處理「個人事務」——不願多說 |
| 6 | 兩名船員在餐廳爭吵——需要船長調解 |
| 7 | 一名船員的生日——其他人偷偷準備了驚喜 |
| 8 | 某船員收到家鄉殖民地的最後通訊——殖民地正面臨危機 |
| 9 | 船員發現船上有東西在「移動」——可能是偷渡者，也可能是幻覺 |
| 10 | 大副提出了一個大膽的改進建議——但實施有風險 |
| 11 | 通訊官在監聽頻道時聽到了自己的名字 |
| 12 | 船員在業餘時間完成了一件驚人的事——畫作、歌曲、或發明 |

## 4.3 忠誠危機（替代挖角）

原始規則的挖角主要來自其他玩家船長。單人模式改用以下觸發：

| 觸發 | 效果 |
|------|------|
| 港口中遇到一個提供「更好條件」的 非玩家角色（NPC） 船長 | 交涉（DIP） 對抗：你的 指揮（CMD） vs 非玩家角色（NPC） 的 交涉（DIP） |
| 船員收到家人/舊船長的訊息 | 如果不處理，忠誠 -1 |
| 某勢力直接向船員提出招募 | 你必須在下次靠港前處理（談判/說服/讓船員自己選擇） |
| 船員的隱藏目標被敵對勢力利用 | 可能導致背叛或洩密 |
| 連續三個月未發獎金 | 忠誠 -1（同原規則 `[玩家§2.5]`） |

# 第五章：單人模式專用規則調整

## 5.1 起始設定

單人模式玩家從 Lv1 開始，使用標準角色創建 `[玩家§2.1-2.8]`，但以下調整：

- **起始船員：** 4 名（多一名——你獨自飛行，需要更完整的橋梁團隊）
- **起始資金：** 背景起始金 + 2,000 信用點（Cr）（補償沒有船團資源共享）
- **船體配點：** 可使用自由配點或預設船型（建議選擇**遊牧民級**或**星巡者級**——多用途船更適合單人生存）

## 5.2 經驗值調整

單人玩家面對更多挑戰，經驗值（XP） 獲取速率調整：

| 來源 | 原 經驗值（XP） | 單人 經驗值（XP） |
|------|:---:|:-----:|
| 完成目標章節 | 500 | 600 |
| 個人背景支線 | 300 | 400 |
| 船員個人故事完成 | 100 | 150 |
| 發現新星系 | 50 | 50（不變） |
| 每場戰鬥 | 50-100 | 75-150 |

## 5.3 資源管理簡化

沒有船團共用資源，追蹤簡化為：

- 只追蹤你自己的船的資源（燃料、食物、零件、彈藥、藥物）
- 港口服務費用見 `[主持人（GM）§5.1]`
- 可選擇是否追蹤 非玩家角色（NPC） 僚機的資源（預設：不追蹤，主持人（GM） 根據劇情決定僚機何時需要補給）

## 5.4 聲望系統

單人模式的聲望系統同 `[玩家§2.6b]`，但增加：

| 事件 | 聲望進度 |
|------|:------:|
| 獨自擊敗 TL2+ 敵人 | +1 |
| 拯救一個 非玩家角色（NPC） 船長 / 殖民地 | +2 |
| 非玩家角色（NPC） 盟友公開讚揚你 | +1 |
| 被多個勢力同時通緝 | -2 |

# 第六章：非玩家角色（NPC） 盟友系統（替代船團關係）

## 6.1 盟友聲望等級

取代原始規則的船團關係值 `[玩家§2.6]`，使用**盟友聲望**追蹤你與重要 非玩家角色（NPC） 的關係：

| 值 | 等級 | 效果 |
|:--:|------|------|
| -3 ~ -1 | 敵對 / 冷淡 | 非玩家角色（NPC） 拒絕合作，可能主動阻撓 |
| 0 | 中立 | 正常互動 |
| 1-2 | 友好 | 願意提供情報、小額幫助 |
| 3-4 | 信賴 | 可作為僚機出戰、願意借出資源 |
| 5-6 | 盟友 | 願意長期結盟、在危難中冒險救你 |
| 7+ | 生死之交 | 願為你犧牲、可解鎖特殊劇情 |

## 6.2 如何提升盟友聲望

| 行動 | 變化 |
|------|:---:|
| 完成 非玩家角色（NPC） 的個人任務 | +2 |
| 在戰鬥中救了 非玩家角色（NPC） 的船 | +3 |
| 在 非玩家角色（NPC） 需要時提供資源 / 情報 | +1 |
| 公開支持 非玩家角色（NPC） 的立場 | +1 |
| 背叛 非玩家角色（NPC） 的信任 | -4 |
| 在 非玩家角色（NPC） 面對危險時袖手旁觀 | -2 |

## 6.3 起始盟友

單人模式開始時，玩家自動獲得一個**起始盟友**（由背景決定）：

| 背景 | 起始盟友 |
|------|---------|
| 破產商人 | 老客戶「艾可」——一位獨立貿易商，欠你人情（聲望 3） |
| 叛逃軍官 | 前副官「凱恩」——跟你一起叛逃，但選擇了不同的路（聲望 4） |
| 學術流亡者 | 導師「歐瑞恩博士」——仍在大學，暗中幫助你（聲望 3） |
| 星際走私犯 | 黑市聯絡人「影」——你救過 ta 的命（聲望 4） |
| 殖民者倖存者 | 同鄉「莉亞」——一起逃出來的童年玩伴（聲望 5） |
| 傭兵隊長 | 前隊員「鐵拳」——退休了但欠你一條命（聲望 4） |
| 宗教朝聖者 | 同修「兄弟以西結」——仍在聖殿，為你祈禱（聲望 3） |
| 探險家 | 競爭對手轉朋友「卡莎」——曾經一起發現過重大遺跡（聲望 3） |

> 起始盟友不一定在船上——他們可能是港口聯絡人、偶遇的友艦、或遠方的筆友。主持人（GM） 在第一章結束前安排一次與起始盟友的實質互動。
