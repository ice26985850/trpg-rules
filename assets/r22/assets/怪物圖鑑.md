### 毒蛇夫人（CR 9）——首領

| 屬性 | 數值 |
|------|------|
| 洞察（洞） | 7 |
| 記憶（憶） | 5 |
| 執行（執） | 6 |
| 社交（社） | 8 |
| 意志（志） | 6 |
| 生命值（生） | 20（含首領加成+5） |
| 耐受值（耐） | 5（含絲質護甲+2） |
| 護甲值（甲） | 2 |
| 先攻 | 洞7+1d10 |
| 攻擊 | 毒針（穿刺+毒）1d6 / 淬毒匕首（銳器+毒）1d8 |

**三階段戰鬥**：

**第一階段（生命值20→14）：「魅惑凝視」**
- 每回合次要行動：社交8 vs 玩家意志對抗，失敗則玩家失去2時
- 遠程毒針攻擊為主，保持距離

**第二階段（生命值13→7）：「蛇群召喚」**
- 花費3時召喚1d3條毒蛇（雜兵級，生命值4，攻擊1d4+毒）
- 自身隱入蛇群（閃避優勢）
- 改為近戰淬毒匕首

**第三階段（生命值6→0）：「毒霧爆發」**
- 一次性能力：所有區域變為毒霧（每回合玩家1輕傷毒素）
- 自身免疫毒素

**弱點**：
- **火焰恐懼**（心理創傷）：火焰傷害+1級，意志檢定劣勢
- **自戀**：社交分散注意力（社8對抗，成功則失去1時）

**AI**：精明級——保持距離、利用社交能力離間、優先消滅受傷目標、生命值<3嘗試談判

### 時噬者雛形（CR 12）——首領

| 屬性 | 數值 |
|------|------|
| 洞察（洞） | 8 |
| 記憶（憶） | 10 |
| 執行（執） | 5 |
| 社交（社） | 1 |
| 意志（志） | 4 |
| 生命值（生） | 18 |
| 耐受值（耐） | 2 |
| 護甲值（甲） | 0（虛體） |
| 先攻 | 洞8+1d10+5（時間感知） |
| 攻擊 | 時間侵蝕（精神）2d6 / 記憶汲取（特殊） |

**特殊能力**：
- **時間吞噬**：被命中者失去1d4條記憶碎片（該輪有效）
- **時間迴廊**：創造一個時間循環區域——區域內角色每回合重複相同行動（意志DC 18抵抗）
- **預知閃避**：每回合第一次被攻擊時自動閃避（知道攻擊何時到來）
- **記憶回聲**：使用玩家過去循環中死亡場景的記憶進行精神攻擊（裂痕+1d3）

**弱點**：
- **時間錨點**：在永恆之井或存檔點附近失去預知閃避能力
- **記憶過載**：同一輪中受到3次以上不同來源的傷害，時間感知混亂
- **尚未完全成形**：本質上是一個崩潰的回歸者，仍保留碎片化的人性——可被情感觸動

**背景**：時噬者雛形是一個裂痕超過40後完全失控的回歸者。他們的精神已經崩潰，身體被時間能量扭曲。他們無法區分過去、現在和未來——對他們來說，一切都同時發生。

### 不死的審判官（CR 14）——傳奇

| 屬性 | 數值 |
|------|------|
| 洞察（洞） | 9 |
| 記憶（憶） | 8 |
| 執行（執） | 8 |
| 社交（社） | 4 |
| 意志（志） | 10 |
| 生命值（生） | 26（含傳奇加成+5） |
| 耐受值（耐） | 9（含儀式板甲+6，達軟上限） |
| 護甲值（甲） | 6 |
| 先攻 | 洞9+1d10+2 |
| 攻擊 | 巨劍（銳器）2d6+3 / 附加火焰1d4 |

**傳奇特性**：
- 每回合2次反應（非1次）
- 免疫恐懼效果
- 死亡後1d6回合復活一次（生命值恢復至10）
- 不受記憶碎片弱點發現影響（需自行觀察）

**四階段戰鬥**：

**第一階段（生命值26→20）：「審判宣告」**
- 宣告玩家一項「罪行」→玩家意志DC16，失敗則對審判官所有攻擊劣勢

**第二階段（生命值19→13）：「罪孽清算」**
- 每回合攻擊兩次（6時）
- 每次命中回復1生命值

**第三階段（生命值12→6）：「真理之眼」**
- 每回合預判玩家一個行動，若執行則自動反制
- 可使用「信仰之盾」無效一次攻擊

**第四階段（生命值5→0）：「最後審判」**
- 所有攻擊變為範圍攻擊（2區內）
- 自身生命值每回合-2（自我燃燒）

**跨輪次記憶**（天才級AI專屬）：
- 「記得」之前輪次戰鬥中的玩家戰術
- 重複使用相同戰術→自動反制
- 玩家展現過多未來知識→審判官開始提問：「你究竟是什麼？」
- 多次遭遇後可能成為劇情關鍵角色

**弱點**（需自行發現，記憶碎片無效）：
- **聖徽**：胸前聖徽是力量來源→破壞後失去傳奇特性
- **教義矛盾**：引用教義矛盾（社交DC18）→失去1回合
- **火焰餘燼**：第四階段自燃可用水/冰中斷
