# Chapter 1: Basic Rules

## 1.1 Core Formula

```
Check Result = 3d6 + Attribute Value + Skill Level
Success Condition: Check Result ≥ Difficulty (DC)
```

This game uses the **3d6 Bell Curve** — results cluster in the 9–12 range, and extreme values are rare. This means a skilled crafter will not inexplicably botch simple work, while a Legendary masterpiece always needs a touch of fate's favor.

### 3d6 Probability Quick Reference

| Target | No Modifier | +2 | +3 | +4 | +5 |
|--------|--------|----|----|----|-----|
| 6+ | 95% | 99% | ~100% | ~100% | ~100% |
| 9+ | 74% | 91% | 95% | 98% | 99% |
| 12+ | 38% | 63% | 74% | 84% | 91% |
| 15+ | 9% | 26% | 38% | 50% | 63% |
| 18+ | 0.5% | 5% | 9% | 16% | 26% |

## 1.5 Check Rules

### Difficulty Ladder

| Difficulty | Difficulty (DC) | Typical Situation |
|------|-----|----------|
| Trivial | 6 | Chopping vegetables, cleaning the shop |
| Easy | 9 | Mixing a basic potion, mending clothes |
| Normal | 12 | Crafting a standard weapon, baking bread |
| Hard | 15 | Smithing Fine enchanted gear, developing a new dessert |
| Very Hard | 18 | Casting a Superior-quality artifact, deciphering an ancient recipe |
| Legendary | 21 | Creating a Legendary masterpiece |

### Critical Success / Critical Failure

| Event | Condition | Probability |
|------|------|------|
| **Critical Success** | Natural roll 16–18 | 4.63% |
| **Critical Failure / Fumble** | Natural roll 3–5 | 4.63% |

> Only the natural die face counts, modifiers ignored. This is fate intervening.

- **Critical Success**: When a Check succeeds, quality automatically rises one tier. Superior + Critical Success → Legendary.
- **Critical Failure**: If it should have succeeded → quality −1 + minor accident; if already failed → tool breakage / total material loss.

### Contest Check

Both sides roll `3d6 + Attribute + Skill`; the higher wins. The active side gets +1. On a tie, both gain a partial advantage.

### Cooperative Crafting

Designate a **Lead** to perform the main Check. Each **Support** first makes an assist Check (3d6 + relevant attribute, Difficulty (DC) 10):

| Result | Effect |
|------|------|
| Success | Lead +2 |
| Critical Success (nat 16–18) | Lead +4, final quality +1 tier |
| Failure | No effect |
| Critical Failure (nat 3–5) | Lead −2 |

At most 2 Supports may assist at once.

## 1.6 Quality System

When crafting, **declare the target quality**, using the recipe's base Difficulty (DC) as the baseline:

| Quality | Difficulty (DC) Offset | Price | Note |
|------|---------|------|------|
| ★ Crude | Difficulty (DC) − 5 | ×0.5 | Barely usable |
| ★★ Standard | Difficulty (DC) | ×1.0 | Commercial standard |
| ★★★ Fine | Difficulty (DC) + 5 | ×1.5 | Excellent craftsmanship |
| ★★★★ Superior | Difficulty (DC) + 10 | ×2.5 | Breathtaking |
| ★★★★★ Legendary | Difficulty (DC) + 15 + Critical Success | ×5.0 | Legendary-grade work |

> If the result exceeds the declared threshold, use the actual result. Below the declaration → failure, materials consumed.

# Chapter 2: Character Creation

## 2.1 Creation Process (8 Steps)

### Step 1: Concept

Answer three questions: What kind of adventurer were you before retirement? Why did you retire? Why open a shop in this profession?

### Step 2: Choose Race

| Race | Attribute | Racial Trait |
|------|------|----------|
| **Human** | +1 to any | **Mortal Resilience**: Once per week, reroll one failed non-combat Check |
| **Dwarf** | Craft (CFT) +1 | **Stonesolid Focus**: Ignore one environmental-disruption penalty while crafting |
| **Elf** | Inspiration (INS) +1 | **Elder's Eye**: Once per day, advantage on Appraisal/Inspiration (4d6 take highest 3d6) |
| **Halfling** | Social (SOC) +1 | **Lucky Routine**: Once per day, downgrade a Critical Failure to a normal failure |
| **Half-Orc** | Stamina (STA) +1 | **Unyielding Body**: On a failed Stamina Check, may spend Stamina value to offset damage |

### Step 3: Choose Class

| Class | Main Attributes | Signature Skill | Shop Role |
|------|--------|----------|----------|
| **Cook** | Craft (CFT)+Inspiration (INS) | Secret Recipe | Product core |

| **Gatherer** | Stamina (STA)+Appraisal (APP) | Nature's Guidance | Supply chain |
| **Researcher** | Inspiration (INS)+Appraisal (APP) | Reverse Engineering | Innovation engine |

### Step 4: Distribute Attributes

| Parameter | Value |
|------|-----|
| Attribute Pool | **15 points** |
| Starting Value | All = 1 |
| Cost per level | 1 point |
| Creation Cap | 4 (bonuses excluded) |

# Chapter 3: Crafting & Signature Skills

## 3.1 Crafting Process

```
Choose recipe → Prepare materials → Perform crafting → Quality appraisal → Store finished product
```

### Crafting Check Formula

```
3d6 + Craft value + Skill Level + Tool bonus + Material quality bonus − Fatigue penalty
```

### Recipe Difficulty

| Difficulty | Difficulty (DC) | Example |
|------|-----|------|
| Basic | 9 | Healing potion, iron sword, home stew |
| Advanced | 12 | Mana potion, steel weapon, court cuisine |
| Rare | 15 | Dragon-breath potion, enchanted gear |
| Legendary | 18 | Elixir of life, mythic weapon |

### Material Bonus

| Rarity | Bonus | Acquisition Difficulty (DC) | Price Multiplier |
|--------|------|---------|----------|
| Common | +0 | Automatic | ×1 |
| Uncommon | +1 | Difficulty (DC) 12 | ×3 |
| Rare | +2 | Difficulty (DC) 16 | ×8 |
| Legendary | +3 | Difficulty (DC) 20 | ×20 |

## 3.2 Per-Class Crafting Traits

### Cook — Flavor Value

```
Flavor Value = Inspiration value + Freshness bonus + special ingredient bonus
```

| Flavor Value | Effect |
|--------|------|
| 1–2 | No bonus |
| 3–4 | Satisfaction +0.5 |
| 5–6 | Satisfaction +1.0, effect +1 scene |
| 7+ | Satisfaction +1.5, effect +2 scenes, may be named |

- Finished-product Freshness = average of materials (rounded down)
- −1 per scene; reaching 0 → effect halved; going negative → spoilage and poisoning

### Smith — Durability & Enchantment

```
Base Durability = 10 + Stamina value × 2
Quality bonus: Crude −3 / Standard +0 / Fine +3 / Superior +6 / Legendary +10
```

| Quality | Enchantment Slots |
|------|----------|
| Fine | 1 |
| Superior | 2 |
| Legendary | 3 |

Material examples: volcanic ore → fire enchantment +1 / deep-sea steel → durability +5 / dragonbone → damage +2

### Alchemist — Potency & Side Effects

```
Potency = Appraisal value + Craft value + rare-material bonus
Side-effect chance = 15% − (Appraisal value × 3%), minimum 5%
```

| Potency | Multiplier |
|--------|------|
| 0–2 | ×0.5 |
| 3–4 | ×1.0 |
| 5–6 | ×1.5 |
| 7+ | ×2.0 |

Shelf life: Crude 1 week / Standard 1 month / Fine 3 months / Superior 6 months / Legendary permanent

### Researcher — Integrity

```
Integrity = Natural roll + Inspiration value + Appraisal value − recipe Difficulty (DC)
```

| Integrity | Teaching Success Rate |
|--------|-----------|
| <0 | 30% |
| 0–4 | 50% |
| 5–9 | 70% |
| 10–14 | 85% |
| ≥15 | 95% |

## 3.3 Signature Skills

### Cook — "Secret Recipe"
- **Cost**: 2 Inspiration Points (IP), once per 2 turns
- **Check**: 3d6 + Inspiration, Difficulty (DC) 13
- **Effect**: Develop an exclusive dish, Flavor Value +3
- **Upgrade**: Lv.2 → once per turn / 1 Inspiration Point (IP); Lv.3 → Flavor +5, starts at Fine

### Smith — "Smith's Soul"
- **Cost**: 2 Stamina (temporary Fatigue), once per turn
- **Effect**: Quality floor +1 level (minimum Standard)
- **Upgrade**: Lv.2 → floor +2 (minimum Fine); Lv.3 → affects whole turn

### Alchemist — "Tasting Constitution"
- **Type**: Permanent passive
- **Effect**: Self-drinking potion effect ×2 (side effects also ×2)
- **Upgrade**: Lv.2 → side effects no longer doubled; Lv.3 → once per turn immune to side effects

### Merchant — "Sense the Opportunity"
- **Cost**: 1 Inspiration Point (IP), once per turn
- **Check**: 3d6 + Social, Difficulty (DC) 12
- **Effect**: Foreknow next turn's Market Fluctuation
- **Upgrade**: Lv.2 → 2-turn prediction + speculation; Lv.3 → actively influence market

### Gatherer — "Nature's Guidance"
- **Cost**: 1 Stamina, once per turn
- **Effect**: Rare material discovery rate ×2
- **Upgrade**: Lv.2 → ×3 + extra materials; Lv.3 → designated rare material auto-discovered

### Researcher — "Reverse Engineering"
- **Cost**: 1 Inspiration Point (IP) + 1 crafting-phase turn
- **Check**: 3d6 + Inspiration + ⌊Appraisal/2⌋, Difficulty (DC) = 9 + target quality × 2
- **Effect**: Analyze product to gain recipe draft (Integrity −5), consume item
- **Upgrade**: Lv.2 → no consumption (DC +2); Lv.3 → Integrity +0, may improve

# Chapter 4: Equipment & Shop

## 4.1 Currency

Gold standard. 10 Silver (S) = 1G, 100 Copper (C) = 1G.

## 4.2 Starting Funds

GM decides, suggested **300–500G**.

## 4.3 Income Formula

```
Weekly Income = Base Revenue + Product Value × Foot Traffic × Satisfaction − Material Cost − Maintenance − Wages
Foot Traffic = 1d6 + Reputation modifier + Location modifier + Shop Level modifier
Base Revenue = 5G (neighbors dropping by, small scattered transactions — this safety-net income exists even at 0 Foot Traffic)
```

> **Safety-net mechanic**: Base Revenue ensures a new shop will not instantly go bankrupt from terrible luck. Even if the first week's Foot Traffic roll is 1, Base Revenue still covers Maintenance.

## 4.8 Tool Durability

Your tools wear down. Each tool type has a base durability:

| Tool | Durability | Per-use Consumption | Critical Failure |
|------|------|---------|--------|
| Chef's Knife Set | 20 | −1 | −2 |
| Smithing Tool Set | 30 | −1 | −2 |
| Alchemy Tool Set | 25 | −1 | −2 |
| Foraging Tool Set | 15 | −1 (foraging) | −2 |
| Research Tool Set | 30 | −1 (research) | −2 |

**Durability effect**: 10+ normal → 5–9 worn (Check −1) → 1–4 severely worn (Check −2, Critical Failure range +3) → 0 broken (needs repair: 1 material + Craft Difficulty (DC) per table above). Durability −5 = unrepairable.

**Repair**: Success restores 1d3 + Craft value. Smith repair Difficulty (DC) −3, recovery +2.

| **Spring** | Herbs +10% discovery rate, but Freshness decays faster |
| **Summer** | More adventurer customers, but heat spoils food quicker |
| **Autumn** | Harvest season — foraging Difficulty (DC) −1, material price −20% |
| **Winter** | Heavy snow blocks mountains — foraging Difficulty (DC) +2, but ice-type special materials appear |

About 12–15 turns per season. GM announces changes at season transitions. See the GM Guide for details.

# Chapter 5: Side-Class Rules

The advantage of a retired adventurer lies in rich experience — your past had more than one identity. The Side-Class system lets a character learn the basic abilities of a second class beyond their main class.

## 5.1 Side-Class Conditions

| Condition | Note |
|------|------|
| **Attribute Threshold** | Any main attribute of the target class ≥ 3 |
| **Mentor** | Requires an NPC mentor or a player character already of that class to instruct |
| **Time** | 4-week study period (normal business allowed, but 1 Action Point (AP) per week spent studying) |
| **Cost** | 200G tuition (or equivalent material/service trade, GM discretion) |
| **Prerequisite** | Must have completed at least 5 successful trades (proof you have found your footing) |

## 5.2 Learning Process

| Week | Content | Check |
|------|------|------|
| **Week 1** | Basic theory study | Inspiration Check Difficulty (DC) 12, success shortens total study by 1 week |
| **Week 2** | Basic tool operation | Craft (CFT) (or Appraisal) Check Difficulty (DC) 9, success unlocks starting recipe |
| **Week 3** | Internship crafting (I) | Use target class to complete 1 basic recipe (mentor assistance required) |
| **Week 4** | Internship crafting (II) + graduation | Independently complete 1 basic recipe (DC 9), success graduates |

> If any week's Check fails, that week must repeat (total time +1 week). GM may adjust pacing by plot — e.g., an early epiphany during a special event.

## 5.3 Side-Class Gains

| Gain | Note |
|------|------|
| **Signature Skill** | Gain the target class's Signature Skill, but **uses halved** (minimum 1 use), Inspiration Point (IP) cost **+1** |
| **Starting Recipes** | Gain 2 basic recipes of that class |
| **Skill Tree T1** | May **choose 1** from the target class's T1 (not choose 1 of 2) |
| **Crafting Trait** | Gain that class's crafting trait dimension (Cook gains Flavor Value, Smith gains Durability/Enchantment, etc.) |

## 5.4 Non-Gains

| Not Gained | Reason |
|--------|------|
| Attribute bonus | Starting +1 is class talent, cannot be gained later |
| Starting tools/gear | Must be purchased yourself |
| Starting Funds | None |
| Starting skill level | Related skills start from 0 |
| Skill Tree T2/T3 | Unlock conditions stricter than main class (see below) |

## 5.5 Restrictions

| Restriction | Rule |
|------|------|
| **Side-Class Cap** | At most 1 Side Class (2 classes total) |
| **Signature Skill IP** | Side-Class Signature Skill costs +1 extra Inspiration Point (IP) |
| **Skill Tree XP** | Side-Class Skill Tree unlock XP × 1.5 (T2 needs 23 XP, T3 needs 53 XP) |
| **Quality Penalty** | When crafting with a Side Class, **Quality Cap −1** (specialization matters) |
| **Irreversible** | Once a Side Class is chosen, it cannot be changed (may retrain for 500G + 8 weeks, GM permission) |

## 5.6 Synergies

Certain class combinations produce Synergy bonuses in specific situations — a natural expression of the adventurer's diverse experience.

| Main + Side | Synergy Bonus |
|------------|----------|
| **Cook + Gatherer** | Appraisal +1 when gathering ingredients (you know what is freshest) |
| **Cook + Merchant** | Restaurant Foot Traffic +1 (your eloquence makes dishes more tempting) |
| **Smith + Merchant** | Social +1 when selling smithed goods (you know how to show the value of craft) |
| **Smith + Gatherer** | Appraisal +1 when mining ore (veins cannot escape your eye) |
| **Alchemist + Researcher** | Potion recipe research Difficulty (DC) −1 (theory meets practice) |
| **Alchemist + Gatherer** | Appraisal +1 when gathering herbs (you know each plant's property) |
| **Merchant + Researcher** | Improved market prediction accuracy (you know how to analyze data) |
| **Merchant + Cook** | Restaurant Foot Traffic +1 (eloquence + cuisine = word of mouth) |
| **Gatherer + Smith** | Stamina +1 when hunting large prey (your weapon knowledge helps aim at weak points) |
| **Gatherer + Cook** | +1 unit yield when gathering ingredients (you know which parts taste best) |
| **Researcher + Alchemist** | Reverse Engineering potion products Difficulty (DC) −1 (you are extra sensitive to ingredients) |
| **Researcher + Smith** | Difficulty (DC) −1 when analyzing smithed goods (you understand the language of metal) |

> Synergy bonuses do not stack — if a character meets multiple conditions (e.g. Cook+Merchant+Halfling Social bonus), take the highest value.

## 5.7 Side-Class Example

### Example: Cook with Gatherer Side Class

```
Tetsuka — a retired warrior, now head chef of the small restaurant "Tetsuka Pavilion."

Week 1: Inspiration 4 → Check 3d6+4=16 ≥ Difficulty (DC) 12, success! Study shortened to 3 weeks.
Week 2: Craft (CFT) 5 + Cooking 2 → Check 3d6+7=19 ≥ Difficulty (DC) 9, smoothly masters foraging tool operation.
Week 3: Under a Gatherer companion's guidance, completes first wilderness forage (DC 9), success.
  → Side Class complete!

Gains:
• Signature Skill "Nature's Guidance" — but only 1 use per 2 turns, costs 1 extra Inspiration Point (IP)
• 2 Gatherer basic recipes
• T1 Skill Tree: chose "Flora Codex"
• Synergy bonus: Appraisal +1 when gathering ingredients

From then on, Tetsuka not only cooks, but can personally go into the mountains for the best ingredients —
but when cooking as a Gatherer, Quality Cap −1. After all, the kitchen is his true battlefield.
```
