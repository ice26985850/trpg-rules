# Hearthside Tales — 爐邊譚 Bilingual Glossary (zh → en) — Set #27/33

> **Official English Display Name:** `Hearthside Tales` (full subtitle: *Hearthside Tales: A Shopkeeping TRPG*).
> **Justification:** The CN title 爐邊譚 literally means "Hearthside Tales / Tales by the Hearth" (爐邊 = by the fireplace/hearth, 譚 = tales/discourses). The game's own CN rulebooks already embed the English line *"Hearthside Tales: A Shopkeeping TRPG"* in their headers, so this is the canonical, author-sanctioned English name. Use `Hearthside Tales` as the display name everywhere; `爐邊譚` remains the Chinese key for file/path references.
>
> This glossary LOCKS official English terms for the bilingual project. Later translation agents MUST read this file FIRST and use these terms consistently. Chinese entries are expected here (this is a zh→en reference, NOT a leak).

## (d) Character Name Romanization Rule

NPC/character names in this system are **mixed**: some are Chinese-transliterated invented names, some are already Western.

- **Mandatory rule:** For Chinese-transliterated names, provide a faithful, pronounceable romanization and keep it stable across all files (e.g. 貝蒂 → Betty, 哈洛 → Harlo, 小炭 → Soot, 老鐵 → Old Iron, 瑪莎 → Martha).
- Already-Western names are kept **as-is** (艾琳 → Eileen, 馬爾科 → Marco). Do NOT "re-translate" them.
- Nicknamed/code names keep quotes: 「狐狸」 → "Fox", 「甜牙」瑪莎 → "Sweet Tooth" Martha, 「無名」 → "Nameless".
- When a name's romanization is uncertain, preserve the Chinese name in parentheses on first appearance, e.g. `Harlo (哈洛)`.

## (e) Hard Rules for Translators

1. **Filename/path references are NEVER translated.** Any string ending in `.md` / `.yaml` / `.svg` / `.xlsx` / `.pdf` is kept in its ORIGINAL Chinese form. Examples to keep verbatim: `介紹.txt`, `爐邊譚_玩家規則書.md`, `s01_這個月的房租.yaml`, `尹瑟嘉德區域地圖.svg`, `NPC角色卡合集.xlsx`, `爐邊譚.pdf`. Reference them inside English prose exactly as written.
2. **"English Full Name (ABBR)" format:** On first mention of any stat/resource, write the full English name followed by its abbreviation in parentheses, e.g. `Action Points (AP)`, `Inspiration (INS)`, `Difficulty (DC)`, `Experience (XP)`. Subsequent mentions may use the ABBR alone.
3. Use the locked terms in sections (a)–(c) verbatim; do not invent synonyms (e.g. always "Shop" not "store", always "Reputation" not "fame", always "Check" not "roll/test" for 檢定).
4. Currency: `G` = Gold (金幣); `S` = Silver (銀幣); `C` = Copper (銅幣). Keep the letter symbols.
