# Nation Building TRPG — Monster Bestiary

---

## How to Use

This bestiary contains monsters and hostile creatures that may be encountered in *Nation Building TRPG*. Each entry includes complete game data, which the GM can use directly for encounter design.

| Field | Description |
|------|------|
| Challenge Rating (CR) | Monster strength indicator; affects encounter difficulty |
| Hit Points (HP) | The monster's hit points |
| Attack (ATK) | Base damage per attack |
| Defense (DEF) | Reduces damage taken |
| Movement (MOV) | Distance (in tiles) the monster can move each turn |
| Morale | When morale drops to 0, the monster flees or breaks |

## Encounter Difficulty Design Guide

| Player Army Total Attack | Suggested Challenge Rating (CR) Range | Difficulty |
|----------------|---------------------|------|
| 10-30 | 1-3 | Easy |
| 31-60 | 3-6 | Normal |
| 61-100 | 5-8 | Hard |
| 101-150 | 7-12 | Very Hard |
| 151-200 | 10-16 | Epic |
| 200+ | 14-20 | Legendary |

The GM may adjust based on whether Hero Units are present and the player's tactics.
