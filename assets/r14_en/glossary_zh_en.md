# 《建國模擬》英譯術語表 / Nation Building TRPG — Chinese→English Glossary

> **用法（重要）：** 所有翻譯 agent 必須先讀本表，鎖定以下官方英文譯名。
> 全文統一使用「英文全名（縮寫）」格式（例：`難度等級（DC）` → `Difficulty Class (DC)`、`生命值（HP）` → `Hit Points (HP)`、`人口（POP）` → `Population (POP)`）。
> 未列出但出現的中文字詞，按字面與本表風格直譯，並在首次出現時附中文括註。
> 專名（地名/種族/神明）已鎖定英文，**不要**音譯成拼音（Elden、The Sundering、Ley Lines 等）。

## 一、遊戲名稱 / Game Title
- 建國模擬 TRPG → **Nation Building TRPG**（副標「你不是冒險者，你是國王」→ *"You are no adventurer — you are the King."*）
- 玩家規則書 → Player's Handbook；GM 規則書 → GM Guide
- 遊戲主持人（GM） → **Game Master (GM)**（簡稱 GM）
- 跑團規則工作室 → Tabletop Rule Studio

## 二、世界觀專名 / Setting Proper Nouns
- 新大陸「埃爾登」 → the new continent of **Elden**
- 大崩解（The Sundering） → **The Sundering**
- 魔力流（Ley Lines） → **Ley Lines**
- 五族 → the Five Races：人類 **Human** / 矮人 **Dwarf** / 精靈 **Elf** / 獸人 **Orc** / 龍裔 **Dragonborn**
- 混種 → **Mixed-blood** (Half-breed)；融合科技 → **Fusion Tech**
- 種族滿意度 → **Racial Satisfaction**
- 飛行城市 → **Sky City**；與神明對話 → **converse with the gods**

## 三、核心規則術語 / Core Rules
- 國家六維 → **National Six Dimensions**：人口（POP）Population (POP) / 資源（RES）Resources (RES) / 經濟（ECO）Economy (ECO) / 軍事（MIL）Military (MIL) / 科技（TEC）Technology (TEC) / 民心（MOR）Morale (MOR)
- 國力（NP） → **National Power (NP)**（衍生）
- 難度等級（DC） → **Difficulty Class (DC)**
- 調整值（MOD） → **Modifier (MOD)**
- d20 系統 → **d20 System**；屬性調整值公式 MOD = ⌊(屬性值−10)÷5⌋
- 優勢（ADV） → **Advantage (ADV)**（擲 2d20 取較高）；劣勢（DIS） → **Disadvantage (DIS)**（取較低）
- 大成功（爆擊） → **Critical Success (Crit)**；大失敗（災難） → **Critical Failure (Fumble)**
- 自然擲出 20 / 自然擲出 1 → natural 20 / natural 1
- 標準檢定 → **Standard Check**；對抗檢定 → **Opposed Check**；集體檢定 → **Group Check**；協助檢定（Aid） → **Aid Check**
- 四季調整 → **Seasonal Modifiers**：春 Spring / 夏 Summer / 秋 Autumn / 冬 Winter（一年四回合）
- 時代演進 → **Era Progression**：部落時代 **Tribal Age** / 城邦時代 **City-State Age** / 王國時代 **Kingdom Age** / 帝國時代 **Empire Age** / 傳奇時代 **Legendary Age**
- 危機牌組（Crisis Deck） → **Crisis Deck**；危機事件 → **Crisis Event**
- 種族與文化融合 → **Race & Culture Fusion**

## 四、英雄單位 / Hero Units
- 英雄單位（Hero） → **Hero Unit (Hero)**
- 英雄九項屬性（nine hero attributes）：力量 **Strength (STR)** / 敏捷 **Dexterity (DEX)** / 體質 **Constitution (CON)** / 智力 **Intelligence (INT)** / 感知 **Wisdom (WIS)** / 魅力 **Charisma (CHA)** / 學識 **Knowledge (KNW)** / 手藝 **Craft (CRF)** / 其餘英雄屬性依原文括註縮寫照譯（如 幸運 Luck、意志 Will 等）。
- 英雄攜帶上限 → **Hero Carrying Cap**

## 五、魔法 / Magic
- 法力值（MP） → **Mana (MP)**；冷卻（CD） → **Cooldown (CD)**；法術 → **Spell**
- 施法檢定 → **Casting Check**；施法屬性 → **Casting Attribute**；效果 → **Effect**；大成功/大失敗 → Critical Success/Failure
- 六大魔法類型：奧術 **Arcane** / 神聖 **Divine** / 自然 **Nature** / 符文 **Rune** / 煉金 **Alchemy** / 時空 **Chrono**
- 法術名：奧術飛彈 Arcane Missile / 魔法護盾 Arcane Shield / 隕星術 Meteor Strike / 治療術 Heal / 驅邪 Turn Undead / 草木纏繞 Entangle / 動物溝通 Speak with Beasts / 附魔 Enchant / 守護符文 Warding Rune / 炸藥 Explosive / 治療藥劑 Healing Draught / 時間停止 Time Stop
- 束縛（BIND） → **Bind**；不死／邪異 → **Undead / Aberrant**；元素精華 → **Elemental Essence**（火焰 Flame / 冰霜 Frost / 雷電 Thunder）；虛空精華 → **Void Essence**；龍血 → **Dragon Blood**；神明碎片 → **Divine Shard**
