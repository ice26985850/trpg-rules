# Chapter 1: Gap Creatures

## §3.3 Gap Creatures — Cannot Be Killed, Only Helped to Transition

> Core design principle: Gap Creatures are not monsters. They are **beings trapped in a state of transition**. No Hit Points (HP), no Armor Class (AC), no weapon die — only Negotiation Difficulty Class (DC) and liberation conditions.

### 3.3.1 Five Kinds of Gap Creatures

#### A. Threshold Lingerer

| Item | Content |
|---|---|
| **Origin** | People who hesitated too long at the moment of making a major life decision. Now they can never cross that Threshold |
| **Behavior** | Repeatedly walks toward the same door, touches the handle, but never opens it |
| **Attributes** | Anchor 2 (×2 = 4), Negotiation Difficulty Class (DC) **10** |
| **Liberation Condition** | Help them "take that step" — you need to know what they are hesitating about. Gain clues from their memory fragments (Retrieval Difficulty Class (DC) 12) or from Surface investigation (Awareness Difficulty Class (DC) 10) |
| **Liberation Reward** | Gain 1 Return Mark; the Threshold henceforth becomes your Memory Threshold (entering it automatically reduces Difficulty Class (DC) by 3) |

#### B. Lost Item Collector

| Item | Content |
|---|---|
| **Origin** | Was once a Gap Walker — but stayed too long and forgot they belonged to the Surface |
| **Behavior** | Hoards Lost Items, categorizing them by logic they themselves no longer remember |
| **Attributes** | Retrieval 4 (×2 = 8), Negotiation Difficulty Class (DC) **14** |
| **Weakness** | An irresistible craving for "new Lost Items" |
| **Negotiation Method** | Exchange with a Lost Item they've never seen — one you just found in the Gap, or one you brought in from the Surface |
| **May Grant** | Information (location of a Sealed Space Crack), a rare Lost Item from their collection, a Gap Shortcut |

#### C. the Mirror

| Item | Content |
|---|---|
| **Origin** | Not trapped — a product of the Gap itself. They are "reflections in reflected space" |
| **Behavior** | Mimics your movements. You walk, it walks. You stop, it stops. But sometimes — it doesn't stop with you |
| **Attributes** | Equal to the encountering character's full Attribute Values |
| **Negotiation Difficulty Class (DC)** | **16** (Contest Check: your Negotiation vs the Mirror's Negotiation; the Mirror uses the same Negotiation value as you) |
| **Core Rule** | **Never turn your back on the Mirror.** Exit the Gap while looking at it — otherwise next time you enter, it may be waiting at the spot where you last stood |
| **Special Interaction** | If the character has formed a special bond with the Mirror (see Ch2 Mirror Sacrifice rules), a special interaction may trigger. Sacrificing the Mirror can reverse one Gap Sickness stage, at the cost of permanently losing the Mirror |

#### D. Path Guardian

| Item | Content |
|---|---|
| **Origin** | A large creature trapped by the Gap — a horse that can never cross the bridge, a dog hesitating at the doorway |
| **Behavior** | Blocks an important Gap path. Not hostile — it doesn't know whether it should let you pass |
| **Attributes** | Traverse 3 (×2 = 6), Negotiation Difficulty Class (DC) **12** |
| **Liberation Condition** | Give it a "reason" to cross — a carrot, a name, or helping it find the master it's waiting for |
| **If Liberated** | Gain 1 Return Mark; that path is henceforth permanently open to you, and Gap Endurance cost in that area –1 |

#### E. Seal Watcher

| Item | Content |
|---|---|
| **Origin** | An existence standing guard beside a Sealed Space Crack. Not hostile — it doesn't know whether it should let you pass |
| **Behavior** | Blocks the Crack, staring at you. Says nothing |
| **Attributes** | Anchor 5 (×2 = 10), Negotiation Difficulty Class (DC) **18** |
| **Pass Condition** | Prove you "need to pass" — show it a Lost Item that must be related to the Sealed Space (gain clues from Surface investigation or Memory Crystals) |
| **Force Passage** | Traverse Check at Difficulty Class (DC) 22. Failure: rejected — the Crack is permanently closed to you, and a Gap Sickness immediate-worsening Check triggers |

### 3.3.2 Negotiation Exchange Table

With Gap Creatures, no language is used — only **"exchange."** Every Negotiation is a transaction.

#### What You Can Give:

| Give | Value Tier | Description |
|---|---|---|
| A memory (obtained from a Memory Crystal) | High | Gap Creatures feed on memory. This is your most precious chip |
| A Lost Item | Mid–High | Depends on the item's emotional weight. Lost Item Collectors especially value "unseen ones" |
| A span of time | Mid | Stay X extra turns in the Gap to keep it company. What you spend is your Gap Endurance |
| A name | Highest | Call its True Name — must be obtained elsewhere. Once used, it is free |
| A promise | Mid | "I will return" — if you break it, that creature's liberation Difficulty Class (DC) rises by 5 for you from then on |
| A story of yours | Low–Mid | Tell a true story about yourself. Beings in the Gap have a natural curiosity about "Surface stories" |

#### What You Can Obtain:

| Obtain | Value Tier | Description |
|---|---|---|
| Passage through the path it guards | Mid | A Gap Shortcut — shortens the distance between two points |
| Information | Mid–High | Location of a Sealed Space Crack, whereabouts of another Lost Item, someone's True Name |
| Its assistance | Mid | Helps you search for Lost Items (Retrieval Difficulty Class (DC) –5 in that area) or guides you to a specific location |
| A service | High | Obtainable only by exchanging with a "name." Afterward it is free — you'll see it cross that Threshold |
| Return Mark | — | Not obtained by exchange — automatically gained when you liberate it |

#### Negotiation Difficulty Baseline

| Negotiation Difficulty Class (DC) | Description |
|---|---|
| 8 | Exchange clearly favors it — it will almost certainly accept |
| 12 | Fair exchange — requires a successful Check |
| 16 | Exchange is unfavorable to it — it will hesitate |
| 20 | You ask it to do something against its nature — may refuse, may demand extra cost |

**Negotiation Modifiers**:
- Each Return Mark tier (First Mark / Familiar Mark / Deep Mark / Inscribed Mark / Legendary Mark): +1 to Negotiation Checks (see Ch2 §2.9.3)
- Holding a Lost Item related to that creature: +5
- Having broken a promise to that creature: –5
- Knowing that creature's True Name: +5 and enables "Name Exchange"
