# 間隙行者TRPG — 中英術語表 (Glossary)

> Display name: **Rift Walker TRPG**
> 本表中文為刻意對照（非漏譯），後續翻譯 agent 一律照此表鎖定英文。
> 命名公約：凡「間隙-」派生詞統一用 **Gap** 前綴（Gap Layer / Gap Creature / Gap Endurance / Gap Sickness / Gap Shortcut）；**Rift** 僅用於遊戲標題（Rift Walker TRPG）；**Crack** 用於「裂縫」。
