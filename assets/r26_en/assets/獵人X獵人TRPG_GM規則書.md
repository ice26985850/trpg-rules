| Difficulty Class (DC) | Difficulty | Example |
|:---:|------|------|

# Chapter 2: Monster & NPC Design

> ▶ For complete stats and weakness / drop data of enemy characters, see the *Monster Codex*; for Legendary and special items, see the *Item Codex*.

## 2-1 Challenge Rating (CR) and Encounter Points (EP)

> **Encounter Points (EP)** is an internal value the GM uses to build encounter budgets, **not** Experience Points (XP) given to players. For character XP, see Player Handbook §2-9.

| Challenge Rating (CR) | Corresponding Growth Stage | Encounter Points (EP) Value | Threat Level |
|:---:|------|:---:|------|
| 1/4 | Rookie mook | 25 EP | Solvable easily by one person |
| 1/2 | Rookie boss (BOSS) | 50 EP | Stepping-stone threat for rookie party |
| 1 | Apprentice Hunter level | 100 EP | Even match for Apprentice Hunters |
| 2-3 | Apprentice → Licensed level | 150-300 EP | Requires teamwork |
| 4-5 | Licensed Hunter level | 400-500 EP | Tough fight for Licensed Hunters |
| 6-8 | Professional Hunter level | 600-900 EP | True threat faced by Professional Hunters |
| 9-12 | Star Hunter level | 1200-1800 EP | Formidable foe at Star Hunter level |
| 13-15+ | Legendary | 2000+ EP | Chairman-level / King-level threat |

## 2-2 Three-Tier NPC Templates

### Mook Tier (CR 1/4 ~ 1)

| Attribute | Range |
|------|:---:|
| Hit Points (HP) | 15-40 |
| Armor Class (AC) | 10-12 |
| Main Attack | 1d6 ~ 2d6 |
| Spirit Points (SP) | 10-25 |
| Nen ability | 0-1 (basic) |

**Typical characters:** ordinary Mafia member, amateur fighter, beast larva

**Tactical AI:** directly attack nearest target, flee when Hit Points (HP) <50%

### Elite Tier (CR 2 ~ 5)

| Attribute | Range |
|------|:---:|
| Hit Points (HP) | 40-90 |
| Armor Class (AC) | 12-15 |
| Main Attack | 2d6 ~ 3d6+ |
| Spirit Points (SP) | 25-60 |
| Nen ability | 1-2 |

**Typical characters:** professional Hunter, phantom beast, Mafia officer, Heavens Arena floor master

**Tactical AI:** prioritize casters / ranged, use cover, employ Nen abilities

### Boss (BOSS) Tier (CR 6 ~ 14+)

| Attribute | Range |
|------|:---:|
| Hit Points (HP) | 90-250+ |
| Armor Class (AC) | 15-20 |
| Main Attack | 3d6+ ~ 6d6+ |
| Spirit Points (SP) | 60-150+ |
| Nen ability | 2-4 (including restrictions and pledges) |

**Typical characters:** Phantom Troupe member, high-tier Nen user, Legendary beast

**Tactical AI:** target PC weaknesses, use environment, exploit restrictions and pledges

## 2-3 NPC Quick Generation in Five Steps

1. **Determine Challenge Rating (CR)** → get value framework from the table above
2. **Allocate attributes** → main attribute 14-16, secondary attribute 10-12
3. **Design Nen ability** → 1-2 Nen abilities matching the CR level (use Binding Pledge points (BP) system to assist design)
4. **Set tactical AI** → choose from the 5 AIs below
5. **Add features** → unique appearance, catchphrase, weakness / ecological weakness

### Five Tactical AIs

| AI Type | Behavior Pattern | Suited For |
|------|------|------|
| **Berserker** | Attack weakest target, ignore defense | Beasts, barbarians |
| **Cautious** | Probe first, keep distance, retreat at HP <50% | Smart generals, assassins |
| **Defensive** | Prioritize protecting self / important target, counterattack-focused | Guards, guardian beasts |
| **Tactical** | Analyze PC weaknesses, use environment, team coordination | Hunters, soldiers |
| **Chaotic** | Random target, unpredictable, may self-destruct | Controlled ones, runaway Nen beasts |

## 2-4 Boss (BOSS) Three-Phase Mechanism

| Phase | Trigger Condition | Behavior Change |
|------|------|------|
| **Probing** | Default | Use basic abilities, test PC tactics, hold back Nen abilities |
| **Serious** | Hit Points (HP) 70% or round 3 | Begin using Nen abilities, upgrade attack patterns, may reveal some restriction info |
| **Limit** | Hit Points (HP) 30% or pledge triggered | Go all out, restriction effect doubled, may have self-destruct tendency, reveal boss's true purpose |

### Trigger Method Suggestions

| Method | Description |
|------|------|
| Hit Points (HP) threshold | Fixed HP percentage (most common) |
| Time trigger | Auto-trigger after round N |
| Environment trigger | PC destroys specific item / protected target dies |
| Pledge trigger | PC satisfies the boss's restriction condition |

## 2-5 Phantom Beast / Magical Beast Design Guide

### Four-Level Classification

| Level | Challenge Rating (CR) | Trait | Example |
|------|:---:|------|------|
| Common | 1/4-1 | No Nen ability, tameable | Large wild beast |
| Dangerous | 2-5 | Innate Nen ability | Nen beast, phantom beast |
| Calamity | 6-10 | High intelligence + multiple Nen abilities | Chimera Ant soldier captain |
| Legendary | 11+ | Can alter ecosystem | Chimera Ant King, Dark Continent creature |

### Magical Beast Design Formula

```
Beast CR = base physique + innate Nen ability + special ecological trait
```

### Eight Special Ability Examples

| Ability | Effect | Suited CR |
|------|------|:---:|
| Hard Shell | Physical damage −1d4 | 2+ |
| Venom Secretion | Melee triggers Poisoned Lv.1 | 1+ |
| Mimicry | Advantage on Stealth check | 1+ |
| Aura Sense | Sense all Nen users within range | 3+ |
| Regeneration | Restore 1d4 Hit Points (HP) per round | 4+ |
| Nen Drain | Using Nen ability on it costs ×2 SP | 5+ |
| Divination | Create 1d4 low-HP clones | 6+ |
| Domain Expansion | All Nen users in range at disadvantage on checks | 8+ |

### Part Destruction and Ecological Weakness

- Large beasts may have destructible parts (horn, tail, shell), each with independent Hit Points (HP)
- Each beast should have 1-2 ecological weaknesses (specific frequency, light, smell, etc.)
- Discovering an ecological weakness requires a "Nen Knowledge" or "Survival" check (DC 15-22)

### Capture Rules

- Target Hit Points (HP) reduced below 25%
- Make a "Survival" or corresponding knowledge check (DC = 15 + Challenge Rating (CR))
- On failure the target escapes or enters a berserk state

# Chapter 3: Encounter Design Guide

## 3-1 Encounter Points (EP) Budget System

> **Encounter Points (EP)** are used only by the GM to build encounters, **not given to players**. Player XP is in Player Handbook §2-9.

### Daily EP Budget (4-person party)

| Player Growth Stage | Daily Encounter Points (EP) Budget (4-person party) |
|------|:---:|
| Rookie | 100 EP |
| Apprentice Hunter | 300 EP |
| Licensed Hunter | 800 EP |
| Professional Hunter | 1,600 EP |
| Star Hunter | 2,800 EP |
| Legendary | 4,000+ EP |

### Encounter Difficulty Multiplier

| Difficulty | EP Budget Usage Rate |
|------|:---:|
| Easy | 25% |
| Medium | 50% |
| Hard | 75% |
| Lethal | 100% |

**Example:** A 4-person Apprentice Hunter party, medium-difficulty encounter EP budget = 300 × 50% = 150 EP. Can arrange 1 CR1 (100 EP) + 2 CR 1/4 (25 EP × 2 = 50 EP).

**Actual XP the players gain:** see Player Handbook §2-9; not converted from EP.

## 3-2 Five Principles of Nen Ability Combat

This is the core doctrine for running Hunter × Hunter TRPG combat:

| Principle | Description | GM Operation |
|------|------|------|
| **Information asymmetry** | Players don't know the opponent's full Nen ability | Reveal boss ability in stages; first describe only visual effects |
| **SP Contest** | SP is a finite resource; allocation decides victory | Hint to PCs "the opponent's aura still looks plentiful / is starting to tire" |
| **Restriction use** | Every Nen ability has a weakness | Give PCs a chance to perceive the restriction (Nen Knowledge DC 15-22) |
| **Environment as weapon** | Hunter combat makes good use of terrain | Prepare 3 interactive objects in each combat scene |
| **Non-combat resolution** | Even the strongest Nen ability can't solve everything | Design fights avoidable through Persuasion / Stealth / schemes |

## 3-3 Balance of Four Encounter Types

| Type | Suggested Share | Resources Consumed | Check Focus |
|------|:---:|------|------|
| Social encounter | 25% | Info, favors, SP (Charm/Intimidate) | Persuasion, Insight, Deception |
| Exploration encounter | 30% | HP (traps), SP (puzzles), time | Perception, Investigation, Survival |
| Combat encounter | 30% | HP, SP, consumables | Combat system |
| Rest / interlude | 15% | Recovery, character interaction | Free roleplay |

### Social Encounter Depth Mechanics

Social interaction in the Hunter world is more than dice checks — a clash of convictions, a game of information asymmetry, a collision of moral stances. The GM may use the following mechanics to deepen social encounters:

#### Social Stance

The NPC's initial stance toward the PC is divided into five levels, affecting the social check Difficulty Class (DC):

| Stance | Difficulty Class (DC) Adjustment | Condition to Shift |
|------|:---:|------|
| Hostile | DC +5 | PC displays overwhelming force or sincerity |
| Suspicious | DC +2 | PC provides credible evidence or shared interest |
| Neutral | DC 0 | Default; PC makes a reasonable proposal |
| Friendly | DC −2 | PC once helped this NPC or shares a goal |
| Trusted | DC −5 | Long-term ally; will not betray |

#### Three Elements of Social Conflict

When a PC tries to persuade an important NPC, the GM judges whether the following three elements are satisfied:

| Element | Meaning | If Unsatisfied |
|------|------|------|
| **Interest** | What benefit does the PC's proposal offer the NPC? | DC +3 |
| **Trust** | Why should the NPC believe the PC is telling the truth? | DC +3 |
| **Feasible** | Can the PC's proposal actually be executed? | DC +3 |

> **Usage:** Base DC = 15. NPC stance adjusts ±DC (as above). For each element the PC satisfies, DC −3. Final DC minimum 5.

**Example — PC persuades Edmund Lei to retreat:**
- Base DC 15; stance "Suspicious" → DC 17
- Interest: PC proposes alternative (exchange controllable Dark Continent resources) → DC −3 = 14
- Trust: PC shows evidence of the Five Calamities' true nature → DC −3 = 11
- Feasible: PC has the Gatekeeper's backing, proving the custodial plan works → DC −3 = 8
- Final DC 8 → a normal Persuasion check succeeds

## 4-4 GM Running Guide

### Character Creation Facilitation Points (30-60 minutes)

1. **Guide the backstory** — let players voice their character's motivation and bonds
2. **Assist allocation** — recommend allocation plans to beginners (Balanced type)
3. **Water Divination ritual feel** — after rolling, describe the Water Divination change, prepare a unique visual description for each type
4. **Nen ability design guidance** — ask "what do you want to do" first, not "what numbers do you want". For example:
   - "I want to freeze the enemy in place" → Manipulation / Conjuration
   - "I want to shatter anything with one punch" → Enhancement
   - "I want to read others' memories" → Specialization / Manipulation
5. **Restriction reward** — encourage players to limit themselves, "the more interesting your restriction, the stronger your ability"

### Five-Dimension Nen Ability Review Standard

| Dimension | Evaluation Question | Red-line Hint |
|------|------|------|
| **Type reasonableness** | Is the ability within that type's scope? | Cross-type abilities must pay an efficiency cost |
| **Restriction balance** | Is the Binding Pledge points (BP) income/expense balanced? Is the cost truly limiting? | "Once per day" has little real limit for a long campaign |
| **Combat fairness** | Will it make other PCs feel useless? | Watch for "one-man show" designs |
| **Narrative potential** | Can this ability create interesting plot? | Pure-number abilities lack narrative depth |
| **Weakness exists** | Is there a clear weakness or limit left? | Perfect ability = reject |

### Review Dialogue Template

When needing to reject or adjust a player's Nen ability design:

```
"This ability's concept is very interesting, [praise specifically].
But I notice [specific problem]. We could try [alternative],
which keeps the feel you wanted while leaving room for other players.

What do you think?"
```

### Togashi-style Narrative Style

- **Information asymmetry**: the world the PCs see ≠ the real world. Prepare two notes per encounter: "what the PCs know" and "what the PCs don't know"
- **Three layers of truth**: surface story → internal intel → ultimate truth. Prepare at least two reversals per commission
- **Defeat ≠ end**: what is lost this round may become a comeback next round. Design non-lethal failure consequences (arrest, lost key item, forced cooperation)
- **Strategic space**: give PCs enough information to make meaningful tactical choices
- **Moral gray**: no pure evil; every villain has an understandable reason

### Gray Zone Design (6 moral dilemma templates)

| Dilemma | Situation | Player Choice |
|------|------|------|
| Necessary evil | Client is a criminal, but the task itself is just | Refuse / accept / negotiate terms |
| Hard choice | Must choose between saving people vs completing the task | Tests character values |
| Cost of consequence | Task success will harm the innocent | Seek a third path |
| Info control | Telling the NPC the truth may get them killed | Conceal / reveal / compromise |
| Friend or foe | The opponent is actually a coerced pawn | Defeat / understand / convert |
| Order vs freedom | Association rules clash with sense of justice | Follow the system / break the rules |

# Chapter 5: Module Framework

## 5-1 Module 1: Hunter Exam (intro, 4-6 hours)

**Suited for:** beginner guidance, teaching party after character creation
**Suggested PC level:** Rookie (0-3 XP)
**Core experience:** system teaching, character building, team cohesion

| Scene | Content | Check Focus | Duration |
|:---:|------|------|:---:|
| 1 | Physical test — cross dangerous terrain | Athletics, Survival, Endurance | 45min |
| 2 | Intelligence stage — puzzles and intel gathering | Investigation, Tactics | 45min |
| 3 | Teamwork — a trial passable only by cooperating | Social skills | 60min |
| 4 | Live elimination — battle other examinees | Combat system teaching | 90min |
| 5 | Final interview — the Chairman's persuasion / trial | Free player expression | 30min |

**Key NPCs:**
- Examiner (Elite tier, adjusts difficulty by examinee level)
- 3-5 rival examinees (Mook to Elite tier)
- Final interviewer

**Loot:** Hunter License, basic equipment set, 1,000J, 3-5 XP

## 5-2 Module 2: Heavens Arena (combat, repeatable)

**Suited for:** repeatable combat module
**Suggested PC stage:** Rookie ~ Professional Hunter
**Core experience:** tower climb challenge, rival story line

### Five-Tier System

| Floor | Challenge Rating (CR) Range | Prize/round | XP/round | Nen Restriction |
|------|:---:|:---:|:---:|------|
| 10-50 floor | 1/4 ~ 1/2 | 500-2,000J | 1 XP | Nen ability unusable |
| 50-100 floor | 1 ~ 2 | 3,000-10,000J | 2 XP | Nen ability unusable |
| 100-150 floor | 3 ~ 5 | 15,000-50,000J | 2-3 XP | Nen ability allowed |
| 150-200 floor | 6 ~ 8 | 60,000-200,000J | 3-4 XP | Nen ability required |
| 200+ floor | 9+ | 250,000J+ | 4-5 XP | Match of first-rate masters |

### Rival System

The GM designs 3-5 rival opponents:
1. **Classmate**: starts climbing with the PCs, competes with them
2. **Avenger**: once defeated by the PCs, returns strengthened
3. **Genius**: overwhelmingly talented opponent the PCs must fail multiple times to find a weakness
4. **Mentor**: technically above the PCs, but gives hints

### Opponent Rotation Table (ensure different play each time)

| Play Count | Opponent Type |
|:---:|------|
| 1st | Classmate + local fighter |
| 2nd | Avenger + Nen ability prodigy |
| 3rd | Genius + foreign challenger |
| 4th | Mentor + former champion |

## 5-4 Module 4: Dangerous Beast Subjugation (high difficulty, 8-12 hours)

**Suited for:** advanced party, Chimera Ant arc style
**Suggested PC stage:** Licensed Hunter and above
**Core experience:** survival pressure, team dependence, strategic depth

### Four-Phase Structure

| Phase | Content | Duration |
|:---:|------|:---:|
| **Prep** | Intel gathering, equipment purchase, team plan | 2hr |
| **Advance** | Traverse the target's territory | 2hr |
| **Subjugation loop** | Encounter → combat → retreat → re-prep | 4-6hr |
| **Final battle** | Boss (BOSS) three-phase combat | 2hr |

### Event Table in Subjugation Loop (d6)

| d6 | Event |
|:---:|------|
| 1 | Encounter target's guard creatures (Mook tier × 3-5) |
| 2 | Discover traces left by target (Tracking DC 15) |
| 3 | Environmental hazard (collapse, poison fog, Nen field) |
| 4 | Encounter rival (another Hunter team) |
| 5 | Discover target's nest (gain ecological weakness intel) |
| 6 | Target suddenly attacks (probing phase, retreats after fight) |

### Boss (BOSS) Design Checklist

- [ ] Three-phase behavior change set (probing / serious / limit)
- [ ] Each phase has a unique visual description
- [ ] At least 1 restriction/pledge perceptible by PCs
- [ ] Ecological weakness exists and can be discovered (Investigation/Nen Knowledge DC 15-22)
- [ ] Combat field has 3 interactive environment objects
- [ ] Non-combat solution exists (e.g., satisfy the boss's true need)
- [ ] Plot consequence after successful subjugation (not just a reward)

# Chapter 6: Original Expansions

## 6-1 Three Original Dark Continent Regions

### Crystallized Wasteland

| Item | Content |
|------|------|
| **Terrain** | Endless crystallized plain, glowing memory-crystal fragments drifting in the air |
| **Core threat** | Crystallization syndrome — spreads within 1d6 hours after contact with tissue; infected lose 1 Dexterity per day, fully crystallize on day 7 |
| **Native creature** | Crystal beast (immune to crystallization syndrome, feeds on memory crystals) |
| **Unique treasure** | Memory crystal (peek into past Nen records), eternal ice crystal (material for Legendary Nen equipment) |
| **Suggested CR** | 8-14 |
| **Treatment** | Fortitude DC 20 / Nen ability (Emission specialized healing) |

### Tear Sea

| Item | Content |
|------|------|
| **Terrain** | A liquid ocean that reflects emotion — becomes heavy water (cannot float) when sad, boils when angry |
| **Core threat** | Emotion made physical — all of a PC's emotions in the area produce physical effects; ancient ruin guardian (CR 10-12) |
| **Native creature** | Emotion sprite (attracted by specific emotions), deep-sea leviathan (appears only when negative emotions concentrate) |
| **Unique treasure** | Emotion crystal (for making mental-type Nen equipment), hyper-ancient tech relic |
| **Suggested CR** | 10-16 |
| **Special rule** | Characters entering the Tear Sea must make a Willpower DC 15 check each hour; failure randomly triggers an emotion-made-physical effect |

### Inverted Forest

| Item | Content |
|------|------|
| **Terrain** | Giant forest where gravity direction flips by region; trees grow downward, the zenith is another ecosystem |
| **Core threat** | Gravity-flip zone — careless and you "fall toward the sky"; zenith predator (CR 9-13) |
| **Native creature** | Down-growing plant (fruit temporarily grants gravity control), mirror-wing bird (flies between two gravity planes) |
| **Unique treasure** | Anti-gravity ore (flying Nen equipment material), floating wood (lightest weapon material) |
| **Suggested CR** | 9-15 |
| **Special rule** | Within the region, an "Acrobatics" or "Athletics" check (DC 12-18) is needed to adapt to gravity changes; a character may spend 1 hour on a "gravity adaptation" check to gain movement advantage in that region |

|------|:---:|------|:---:|------|------|

### Per-Domain Story-Advancement Rules

- **Network Hunter:** advantage on Investigation when researching electronic intel; can perform "Investigation" remotely (no need to be on site)
- **Psychology Hunter:** after probing a target's psychological weakness, advantage on social checks against that target; can perform a "psychological profiling" special check (Intelligence + Insight, DC = target's Willpower value) to gain background intel
- **Frontier Hunter:** advantage on Survival in the Dark Continent and surrounding regions; can perform an "ecology record" check (Intelligence + Survival), on success gaining permanent knowledge bonus against creatures of that ecology region

## 6-3 Nen Beast System Rules Framework

### Four Nen Beast Types

| Type | Base Attributes | Maintenance SP | Summon Action | Special |
|------|:---:|:---:|:---:|------|
| **Scout** | HP 10, AC 12 | 1/round | Standard | Shares senses with summoner (range = Four Major Techniques × 10m) |
| **Combat** | HP 30, AC 14 | 3/round | Standard | Independent attack (1d6 + manipulator's Willpower Modifier) |
| **Support** | HP 20, AC 12 | 2/round | Minor | Provides summoner a specific skill advantage |
| **Composite** | Multi-unit | 5/round | Standard+ | Combines offense, defense, scouting, but high BP cost |

### Nen Beast Creation Steps

1. **Choose type** → get base attribute framework
2. **Allocate attribute points** → 5 points (Scout) / 8 points (Combat) / 6 points (Support) / 12 points (Composite)
3. **Design special ability** → use Binding Pledge points (BP) system (Nen beast's independent BP cap = half the summoner's BP cap)
4. **Calculate maintenance SP** → base SP + enhancement modifier − restriction discount

### Nen Beast Design Notes (GM)

- The Nen beast is an extension of the player's ability, not a "second character"
- After a Nen beast dies, it takes 24 hours to resummon
- Nen beast SP is drawn from the summoner's SP pool
- Each character can maintain at most 1 Nen beast at a time (unless buying the "multi-Nen-beast" enhancement with BP)
