# 戰役總覽

## 使用此戰役的方法

本劇本是 **完整戰役路徑**。GM 可按卷依序進行，也可從中抽取特定段落作為短期劇本。

| 卷 | 建議等級 | 樓層範圍 | 預估聚會次數 | 主題 |
|----|---------|----------|------------|------|
| 卷壹 | Lv.1-10 | 第1-10層 | 6-10次 | 死亡遊戲的覺醒、學習生存 |
| 卷貳 | Lv.10-25 | 第11-25層 | 8-14次 | 公會政治、前線壓力、PK威脅 |
| 卷參 | Lv.25-50 | 第26-50層 | 12-20次 | 攻略組的榮耀與犧牲、公會興衰 |
| 卷肆 | Lv.50-75 | 第51-75層 | 10-16次 | 死亡迷宮、最終Boss前夕 |
| 卷伍 | Lv.75-100 | 第76-100層 | 8-12次 | 紅玉宮、最終對決 |
| **合計** | **Lv.1-100** | **全100層** | **約44-72次** | |

### 場景：2022年11月6日，SAO正式營運第一天

| 3. 第一次戰鬥 | 在鎮外草原遭遇 **狂暴山豬**（參見怪物圖鑑） |

## 第壹章：死亡遊戲的開始

### 場景觸發：下午5點30分

> *「一道強制傳送的光芒包圍了你。當你睜開眼，發現自己回到了起始之鎮的中央廣場——和所有其他玩家一起。」*
>
> *「天空變成了血紅色。一個巨大的、無面的紅色斗篷人影出現在廣場上方。」*
>
> *「歡迎來到我的世界。我是茅場晶彥。」*

**茅場晶彥的宣告**（GM儘可能營造壓迫感）：

1. 無法登出——NerveGear 會阻斷登出指令
2. 遊戲內死亡 = 現實中死亡（NerveGear 的高功率微波會破壞大腦）
3. 唯一的逃脫方法——通關全部 100 層
4. 所有玩家獲得 「手持鏡」——自動使用，顯示真實外貌

### 導入衝突：玩家的反應

GM 描述周圍 NPC 玩家的各種反應：

| NPC反應 | 代表 |
|---------|------|
| 恐慌與哭泣 | 大多數玩家 |
| 沉默接受 | 少數冷靜者 |
| 立即行動 | 克萊因、桐人（NPC）、為數不多的積極者 |
| 失控暴怒 | 極少數（攻擊NPC、破壞物品等） |

**給玩家的抉擇**：
1. 冷靜下來，聽取資訊
2. 嘗試幫助恐慌的玩家
3. 尋找同樣積極行動的人
4. 獨自離開人群

### 導入 NPC 互動

**克萊因** —— 在混亂中主動搭話的紅色頭巾武士：
- 性格：熱情、粗獷、有領導力但不想承擔責任
- 首次互動：如果他注意到玩家保持冷靜，會主動提出組隊
- 提供資訊：基本戰鬥技巧、SAO封測經驗

**阿爾戈** —— 在人群中出售基本情報：
- 販賣「攻略指南手冊」
- 包含：第1層地圖、基本怪物弱點、安全區域標記
- 價格：免費（在混亂中，她選擇免費發放）

## 第貳章：生存的第一週

### 新手訓練（1-2次聚會）

引導玩家學會以下內容——GM應以教程形式進行：

#### 城鎮任務線

| 任務 | 來源 | 報酬 | 內容 |
|------|------|------|------|
| 初心者的試煉 | 起始之鎮訓練場NPC | 100 Col + EXP 50 | 使用初級劍技擊敗訓練用魔像 |
| 藥草收集 | 道具店NPC | 中型生命藥水×2 | 在城外收集藥草×5 |
| 情報收集 | 阿爾戈 | 地圖擴展 | 找到鎮中三個隱藏NPC |

#### 第一次組隊戰鬥

引導玩家組成 2-4 人小隊，前往「起始之草原 - 深處」：

```
遭遇設計（分波進行）：

第一波：狂暴山豬 ×2
第二波：巨型狼 ×2（Lv.3）
休息機會：返回城鎮補給
第三波：森林毒蛇 ×1 + 巨型狼 ×2
```

### 月夜黑貓團（支線）

> *「我們是月夜黑貓團。公會不大，但大家都很好相處。」*

玩家在起始之鎮遇到 **啟太**（Keita）和他的小型公會「月夜黑貓團」（約5-6人）。

| 互動選項 | 結果 |
|----------|------|
| 加入月夜黑貓團 | 獲得公會支援、共享倉庫，但公會成員等級較低 |
| 保持獨立 | 後續仍可與他們合作 |
| 指導他們 | 與啟太建立好感，日後可影響命運 |

> **GM注意**：原作中月夜黑貓團在迷宮陷阱中全滅。這是整個戰役中最早的重大死亡事件——GM可選擇：1) 維持原作悲劇 2) 讓玩家有機會拯救他們。

**參與NPC**：約40名玩家（包括後來的KoB和DDA前身成員）  
**主要發言人**：艾基爾（Agil）——高大的光頭斧使，自願主持會議

**會議內容**（GM演出）：
1. Boss房位置與路線確認
2. Boss情報分享（狗頭人領主·伊爾凡）
3. 隊伍編成（坦克/輸出/支援的分配）
4. 切換戰術的首次公開教學

### 時代背景

第10層攻略後，玩家群體開始明顯分化：
- **攻略組**：積極攻略樓層的頂尖玩家（約300-500人）
- **中間層**：有一定實力但不參與前線的玩家（約3,000-4,000人）
- **起始層**：留在第1層、幾乎不戰鬥的玩家（約2,000-3,000人）

**劇情導向**：玩家現在被視為「攻略組候補」——NPC開始期待他們加入前線。

### 亞絲娜的初登場

**獎勵**：西莉卡的友誼、馴獸知識（如隊伍中有馴獸技能的玩家，可獲馴獸經驗+2）

## 第拾壹章：犧牲的意義（第36-45層）

### 死亡逐漸逼近

在這些樓層，攻略組開始付出真正的犧牲。GM應在此階段：

- 描寫黑鐵宮紀念碑上越來越多的橫線

### 月夜黑貓團的命運（若仍存在）

> **此為原作關鍵節點。根據卷壹玩家的選擇，有多種發展：**

**路線A：玩家未加入/未干涉**
→ 月夜黑貓團在第38層迷宮觸發陷阱，全滅。啟太死亡。
→ 玩家可能在黑鐵宮看到他們的名字被劃線。
→ 這是戰役中最悲傷的場景之一。

**路線B：玩家曾指導他們**
→ 月夜黑貓團成員等級提高，但在第40層Boss戰中仍有傷亡。
→ 啟太存活，對玩家表達感謝。
→ 他決定留在中層不再參與前線攻略。

**路線C：玩家加入過月夜黑貓團**
→ 啟太和部分成員在玩家的帶領下加入了攻略組。
→ 全員的命運與玩家公會綁定。

3. 有玩家看到希茲克利夫在深夜獨自進入迷宮

**給玩家的提示**：這是不信任的種子。玩家現在有理由懷疑希茲克利夫——但沒有證據。

## 第拾肆章：真相的線索（第61-70層）

### 希茲克利夫露出破綻

在第65層Boss戰中，設計一個關鍵場景：

> *Boss的攻擊擊中了希茲克利夫。他的HP條變成了黃色——但只有一瞬間。下一秒，HP條又回到了綠色。*
>
> *而且——HP條變黃的那一瞬間——希茲克利夫腳下出現了一個黃色的系統標記。那是只有GM權限才會看到的「不可破壞物件」標記。*

**察覺判定**：
- 在場的所有玩家進行 INT 判定（難度-15）
- 成功者注意到這個瞬間
- 大成功者（01-05）還注意到更多：希茲克利夫的攻擊動畫有極輕微的延遲——那是系統輔助校準的痕跡

**後續發展**：
- 若有玩家察覺並質問希茲克利夫 → 他會冷靜地否認，「是你太緊張了」
- 亞絲娜會為希茲克利夫辯護——她未察覺異常
- 但懷疑的種子已經種下

# GM 使用指南

## 調整難度

若隊伍實力高於預設，增加以下調整：
- 怪物數量 +50%
- Boss HP +20%
- 增加 1 個菁英怪物於遭遇戰中

若隊伍實力低於預設：
- 額外提供 1-2 名NPC戰友
- Boss HP -20%
- 增加安全房間的數量

## 重要提醒

1. **死亡是真實的**——不要讓玩家覺得GM在保護他們
2. **日常很重要**——每次聚會至少保留 15-20 分鐘給非戰鬥場景
3. **音樂**——建議使用 SAO 原聲帶作為背景音樂
4. **角色發展**——追蹤玩家角色的情感弧線，在後期給予回報
