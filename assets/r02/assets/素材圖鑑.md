# SAO TRPG — 素材圖鑑

> *「在 SAO 中，幾乎所有東西都可以從怪物、採集或任務中獲得。沒有什麼是買不到的——只要你有足夠的珂爾和情報。」*

---

## 使用說明

本圖鑑收錄 SAO 中所有可獲取的素材（材料），按類別編排。每種素材標明：

- **稀有度**：★普通 / ★★少見 / ★★★稀有 / ★★★★傳說
- **獲取方法**：怪物掉落 / 採集 / 釣魚 / 任務 / 商店購買
- **出現位置**：樓層及區域
- **用途**：鍛造 / 料理 / 藥水 / 裁縫 / 飾品 等

## 七、素材獲取判定表

### 7.1 採礦判定

```
擲 D100 ≤ (STR + 採礦技能×3 + LUK÷2)
成功：獲得該區域的採掘表隨機1-3個礦石
大成功(01-05)：獲得稀有礦石概率翻倍 + 數量+1
大失敗(96-00)：礦脈崩塌，該採掘點失效1週遊戲時間
```

### 7.2 採集判定

```
擲 D100 ≤ (INT + 採集技能×3 + LUK)
成功：獲得該區域的採集表隨機1-3個素材
大成功(01-05)：發現稀有藥材
大失敗(96-00)：採到毒草（需VIT判定否則中毒）
```

### 7.3 釣魚判定

```
擲 D100 ≤ (DEX + 釣魚技能×3 + LUK÷2)
成功：釣到魚（依水域和技能等級決定品種）
大成功(01-05)：釣到稀有魚或寶箱（可能含道具）
大失敗(96-00)：魚線斷裂，損失魚餌
```

### 7.4 狩獵判定

```
擲 D100 ≤ (AGI + DEX + 狩獵技能×2)
成功：從動物型怪物屍體獲得額外剝取素材 1D3 個
大成功(01-05)：獲得稀有剝取素材
大失敗(96-00)：破壞素材，無獲得
```
