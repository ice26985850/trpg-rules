# SAO TRPG GM 規則書

> SAO TRPG（刀劍神域改編）— 本文件由規則書各章整合而成，內容與原章節一致。

## 第六章　GM 指南

> *「GM，你就是這個世界的茅場晶彥。你創造規則，你設計挑戰，你掌控生死。但你也要記住——你不是要殺死玩家，而是要讓他們體驗真正的冒險。」*

## 6.1 GM的核心原則

### 6.1.1 死亡張力 vs 公平性

SAO TRPG 的核心張力來自**永久死亡**。但 GM 必須學會平衡：

| 你應該做的 | 你不應該做的 |
|-----------|-------------|
| 讓玩家感受到危險是真實的 | 設計無法迴避的必死陷阱 |
| 在Boss戰前給予充分的情報機會 | 隱瞞Boss的致命技能直到發動 |
| 提供逃生手段（傳送水晶）的使用窗口 | 在玩家剛使用完劍技硬直時發動秒殺攻擊 |
| 讓死亡成為有意義的劇情轉折 | 用意外的隨機遭遇殺死角色 |
| 為新玩家提供新手保護期（Lv.1-5） | 在教程階段就展現遊戲的殘酷性 |

### 6.1.2 SAO氛圍塑造

SAO 的獨特氛圍來自以下要素：

1. **這確實是個遊戲** — 有UI提示、技能特效、掉落畫面、等級顯示
2. **但這又不是遊戲** — 會痛、會累、會恐懼、會饑餓、會死
3. **日常與非日常的交錯** — 前線攻略與湖畔釣魚同等重要
4. **玩家社群** — 城鎮中有數千名真實的「玩家」，每個都有自己的故事
5. **時間的流逝** — 被困兩年不是一次地城探險，而是另一種人生

建議 GM 在每個章節之間穿插「生活場景」：
- 在旅館休息時的角色對話
- 在玩家市集淘寶
- 嘗試新發現的料理
- 收到其他玩家的求救信

## 6.3 Boss設計深入

### 6.3.1 守層Boss設計原則

1. **主題性** — Boss的外觀和技能應與樓層主題一致
2. **階段感** — 至少2個階段，讓戰鬥有起伏
3. **可攻略性** — 必須有弱點或模式可供玩家利用
4. **史詩感** — 描述應磅礡，HP降低應有視覺變化
5. **生存壓力** — 但不是不可戰勝的

### 6.3.2 守層Boss設計範例

```
═══════════════════════════════
  Boss：鋼鐵守護者·伏爾剛
  (Iron Guardian - Volgon)
═══════════════════════════════

第15層守層Boss | Lv.18 | 類型：機械巨人
攻略推薦：Lv.15-18，8-12人

【基礎屬性】
HP：2400 / 2400     SP：200 / 200
ATK：35    DEF：40
HIT：45    EVA：20
SPD：30

【階段1：100%-61%】
描述：伏爾剛緩步移動，雙臂的巨大齒輪緩慢旋轉

技能：
  1. 碾壓打擊：ATK×1.5，單體，HIT-5
  2. 齒輪飛刃：ATK×1.3，前方3目標，HIT+0
  3. 震地波：ATK×1.0，全體，附帶AGI判定否則倒地

【階段2：60%-31%】
描述：伏爾剛的裝甲展開，露出內部高溫核心

技能：
  1. 過載打擊：ATK×2.0，單體，HIT+5
  2. 火焰噴射：ATK×1.5，前方扇形，附加燃燒
  3. 超震地波：ATK×1.3，全體，必定倒地
  4. 自我修復：恢復200HP（使用2次）

【階段3：30%-0%】
描述：伏爾剛進入暴走模式，全身高溫發紅，移動速度暴增

技能：
  1. 暴走連擊：ATK×2.5，4連擊，隨機目標
  2. 熔毀光束：ATK×3.0，直線貫穿，HIT+15
  3. 自我毀滅倒數：3回合後爆炸，ATK×10全體

【弱點】
- 冰屬性武器傷害×1.5
- 背後攻擊HIT+15（核心暴露）
- 腿部破壞後SPD-20（需要累積100傷害到腿部）

【掉落物】
LA獎勵：伏爾剛之心（稀有強化石，可將武器強化至+7）
固定掉落：鋼鐵齒輪 × 5（稀有鍛造素材）
隨機掉落：守護者之盾（DEF+18，格擋成功率+15%），50%機率
```

## 6.4 冒險結構設計

### 6.4.1 典型冒險框架

```
═══════════════════════════════
  冒險：[標題]
═══════════════════════════════

【序幕】 在城鎮中接到任務/聽到傳聞

【第一章：情報收集】
- 向NPC打聽情報
- 收集地圖、得知怪物弱點
- 準備補給品

【第二章：野外探索】
- 前往迷宮入口的旅途
- 1-3次野外遭遇

【第三章：迷宮攻略】
- 探索迷宮尋找Boss房間
- 陷阱/機關
- 3-5次迷宮遭遇
- 可能找到安全房間（休息點）

【第四章：Boss戰役】
- Boss戰
- 勝利 → 第五章
- 撤退 → 需要重新攻略迷宮

【第五章：歸途與結算】
- 回到城鎮
- 販賣戰利品
- 角色扮演場景
- 解鎖新樓層傳送門
- 分配EXP和Col

【幕間】
- 生活場景
- 公會活動
- 個人劇情
```

### 6.4.2 節奏控制

| 聚會次數 | 內容規劃 |
|----------|---------|
| 第1次 | 情報收集 + 出發 + 1-2場野外戰鬥 |
| 第2次 | 迷宮探索 + 2-3場戰鬥 + 發現Boss房間 |
| 第3次 | Boss攻略會議 + Boss戰 + 結算 |

## 6.5 特殊場景處理

### 6.5.1 橙名玩家（犯罪玩家）

在 SAO 中，攻擊其他玩家會變為橙色標記（橙名玩家 Orange Player）。

**TRPG處理**：
- 橙名玩家無法進入城鎮的安全區域
- NPC商店拒絕交易
- 其他玩家可以攻擊橙名玩家而不會變橙
- 橙名狀態持續72小時（遊戲時間）後可通過任務恢復

**綠名玩家（Green Player）**：
- 擊敗橙名玩家的玩家有時會變為綠色標記
- 社會地位提升，部分商店提供折扣

### 6.5.2 紅名玩家（PK公會）

例如「微笑棺木」（Laughing Coffin）——SAO中最惡名昭彰的PK公會。

**TRPG處理**：
- 紅名玩家是敵對NPC
- 遭遇紅名玩家的難度遠高於同級怪物（因為有智慧）
- 紅名玩家可能使用骯髒戰術（偷襲、陷阱、人質）
- 擊敗紅名組織是戰役中的重要劇情節點

### 6.5.3 精神崩潰/退出攻略

被困在死亡遊戲中的壓力是巨大的。部分玩家會精神崩潰，拒絕離開城鎮。

**TRPG中的處理**：
- 玩家角色不會強制崩潰（除非玩家選擇RP）
- NPC的精神狀態是重要的劇情元素
- 可以設計安撫NPC玩家、重建信心的支線任務

## 6.7 戰役管理

### 6.7.1 戰役軌跡記錄

GM 應記錄以下內容以便長期追蹤：

| 記錄項 | 說明 |
|--------|------|
| 當前遊戲日期 | SAO內部時間 |
| 攻略進度 | 當前已解鎖的最高樓層 |
| 死亡角色名單 | 記錄在黑鐵宮 |
| 重要NPC狀態 | 生死、關係變化 |
| 經濟狀態 | 團隊總資產 |
| 未完成任務 | 支線任務追蹤 |
| 公會動態 | 各公會的權力變化 |

### 6.7.2 長期進度建議

| 實際遊玩時間 | 遊戲內時間 | 建議進度 |
|------------|-----------|---------|
| 1個月（4次聚會） | ~2個月 | Lv.1→10，攻略至第5層 |
| 3個月（12次聚會） | ~6個月 | Lv.10→25，攻略至第25層 |
| 6個月（24次聚會） | ~1年 | Lv.25→50，攻略至第50層 |
| 1年（48次聚會） | ~2年 | Lv.50→75，攻略至第75層 |

## 6.8 變體規則

### 6.8.1 平行世界模式

如果玩家不希望永久死亡，可以使用以下變體：
- 角色死亡後失去所有該次冒險中獲得的EXP和物品
- 在城鎮中復活，獲得「死亡標記」減益（所有判定-10，直到下次升級）
- 此模式適合較休閒的遊戲風格（但不推薦——死亡恐懼是SAO的核心）

### 6.8.2 ALfheim Online 模式

將設定切換至妖精之舞篇：
- 取消永久死亡（ALO無死亡遊戲）
- 加入飛行系統和魔法系統
- 種族系統（9大妖精種族）
- 適合想要更輕鬆奇幻風格的團隊

### 6.8.3 Gun Gale Online 模式

將設定切換至幽靈子彈篇：
- 取消永久死亡
- 科幻槍械武器取代劍技
- 加入 BoB（Bullet of Bullets）大賽系統
- 適合想要現代戰鬥風格的團隊

## 6.10 怪物類型系統

將所有怪物歸入以下類型，每種類型有固定特性。GM 設計怪物時直接套用類型模板：

| 類型 | 特性 | 弱點 | 代表怪物 |
|------|------|------|---------|
| **獸型** (Beast) | SPD+5, ATK+5 | 無特別弱點 | 狂暴山豬、巨狼 |
| **不死型** (Undead) | 毒/出血免疫 | 神聖×2.0 | 骸骨戰士 |
| **蟲型** (Insect) | EVA+5, 中毒攻擊常見 | 火×1.5 | 巨蛛 |
| **武裝型** (Armored) | DEF+10, SPD-5 | 雷×1.5 | 狗頭人守衛、廢墟守護者 |
| **龍型** (Dragon) | 全屬性+10 | 依亞種而異 | 暴風龍 |
| **半獸型** (Demi-human) | 智慧行為、可使用武器 | 無特別弱點 | 狗頭人、哥布林系 |
| **植物型** (Plant) | 毒/麻痺攻擊常見 | 火×1.5 | 樹精 |
| **魔法生物** (Magical) | 遠程攻擊, 浮遊 | 物理×1.2 | 惡魔之瞳、妖精 |
| **機械型** (Mechanical) | DEF+15, 毒免疫 | 雷×1.5 | 機械巨人 |

使用方式：為怪物選擇類型後，直接疊加類型特性到基礎數值上。

## 6.11 唯一技能（Unique Skills）

SAO 中除了二刀流，還存在其他唯一技能。全 SAO 只有 10 種唯一技能，每種僅一人能持有。

### 6.11.1 已知唯一技能

| 技能名 | 持有者 | 效果 | 解鎖條件 |
|--------|--------|------|----------|
| **二刀流** (Dual Blades) | 桐人 | 雙持單手武器 | 反應速度最快者 |
| **神聖劍** (Holy Sword) | 希茲克利夫/茅場晶彥 | 攻防一體，HP再生 | GM權限 |
| **無限槍** (Infinite Spear) | —（原設） | 長槍終極進化 | 特定條件 |
| **暗黑劍** (Darkness Blade) | —（原設） | 暗屬性最強 | 特定條件 |

### 6.11.2 GM使用指南

- **二刀流**：唯一可由玩家解鎖的唯一技能
- **神聖劍**：作為最終Boss（希茲克利夫）的專屬能力
- **其他唯一技能**：可在戰役後期作為 NPC 的能力出現，或由 GM 原創
- 每個唯一技能只能由 **一位玩家或NPC** 持有——這是不可違反的系統規則
