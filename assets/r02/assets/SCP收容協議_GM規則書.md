## 3.7 異常對戰規則

### 認知危害 (Cognitohazards)

通過感知觸發，攻擊 SAN 而非 HP。

| 強度 | CH 豁免 | SAN 傷害 |
|------|---------|---------|
| 輕度 | d100 ≤ SAN | 1d4 |
| 中度 | d100 ≤ SAN -10 | 2d6 |
| 重度 | d100 ≤ SAN -20 | 3d8 |
| 極端 | d100 ≤ SAN -30 | 4d10 |

**認知過濾**：SCRAMBLE 護目鏡等可將強度降低一級。

### 現實扭曲 (Reality Bending)

| 等級 | Hume 偏離 | 範圍 | 對策 |
|------|----------|------|------|
| 低度 | ±10–30 Hm | 5m | 現實穩定劑 |
| 中度 | ±31–60 Hm | 20m | 斯克蘭頓錨減半 |
| 高度 | ±61–90 Hm | 100m | 多錨疊加 |
| 極端 | ±91+ Hm | 無上限 | 撤退+最大穩定 |

區域內所有物理檢定 DIS。攻擊扭曲源需先通過 `d100 ≤ WIL（TN = 50 + Hume/5）`。

### 模因危害 (Memetic Hazards)

| 等級 | 傳播方式 | 清除方式 |
|------|---------|---------|
| A 級 | 直接接觸信息載體 | B 級記憶刪除 |
| B 級 | 間接得知概要 | A 級記憶刪除 + SAN -1d6 |
| C 級 | 知道"存在"即感染 | 完全信息封鎖 + SAN -3d6 |
| D 級 | 信息具有自我意識 | 僅 O5 授權可接觸 |

**元認知陷阱**：玩家知道模因內容 ≠ 角色免疫——這是 SCP 的核心恐怖。

## 3.8 不可戰勝的 SCP：收容框架

某些 SCP 無法被擊敗。使用四階段遭遇流程：

```
階段 1：識別 → 科研/感知檢定確定特性和弱點
階段 2：反應 → 建立收容周界、疏散、激活協議
階段 3：執行 → 累積收容成功點（通常 3–8 個）
階段 4：代價 → "最小代價"決策——誰來犧牲？
```

### 收容進度系統

- 每有效收容行動投 `d100 ≤ 相關技能` → 成功 = 1 點，卓越 = 2 點
- SCP 威脅同步推進——若先達臨界值 → 收容失敗
- D 級人員消耗：犧牲 = 自動 1 點；失敗重試 = D 級先行試探

## 3.10 遭遇設計指南

### 難度預算

| 難度 | 小隊消耗 | 典型場景 |
|------|---------|---------|
| 常規 | 10–20% | 日常巡邏 |
| 挑戰 | 30–50% | Safe 級突破收容 |
| 困難 | 50–70% | Euclid 級突破 |
| 極端 | 70–90% | Keter 級、站點被滲透 |
| 末日 | 90–100%+永久代價 | XK 級場景 |

### 四大設計原則

1. **每場遭遇都有非戰鬥出口**：撤退 ≠ Game Over
2. **信息不對稱設計**：玩家起始處於信息劣勢
3. **代價選擇 > 數值博弈**：讓玩家在兩種代價間選擇
4. **SAN 與 HP 雙重消耗**：HP 可恢復，SAN 恢復緩慢——長期累積纔是真正威脅

# 第四章：世界與敘事

## 4.1 基金會世界觀

### 核心設定

這是一個"我們的世界，但多了一層陰影"的設定。故事時間線默認錨定近未來（2025–2035），基金會、GOC、各異常組織在公衆視野之外運作，維持"常態共識"。

**核心悖論**：基金會保護人類免受異常威脅，但基金會自身也是人類——這意味着它同樣會犯錯、腐敗、分裂。玩家角色正站在這個悖論的中心。

### 組織架構

```
O5 議會（13 名成員，最高決策層）
  ├── 倫理委員會（獨立監督）
  ├── 科學部 → 異常研究、實驗設計
  ├── 安保部 → 站點安全、MTF 調度
  ├── 收容部 → SCP 儲存與維護
  ├── 外勤部 → 情報、回收、掩蓋
  ├── 信息安保部 → 文檔密級、記憶刪除
  └── 後勤部 → 供應、人事、D 級管理
```

### 站點網絡

| 站點類型 | 功能 | 示例 |
|---------|------|------|
| Site | 地表/半地下設施 | Site-19（全球最大站點） |
| Area | 完全地下/隔離 | Area-14（Keter 集中收容） |
| 前哨站 | 偏遠地區監控 | 多個 |
| 機動站點 | 可移動/臨時 | MTF 專用 |

### 歷史年線（六階段）

1. **史前時期**（？–1800）：異常被視爲神蹟或魔法
2. **工廠時期**（1800–1900）：早期工業化收容嘗試
3. **基金會成立**（1900–1945）：從 13 人祕密會議開始
4. **冷戰時期**（1945–1991）：與 GOC 的意識形態對抗
5. **全球網絡化**（1991–2020）：SCiPNet 建立
6. **近未來**（2020–2035）：AI 輔助收容、倫理危機加劇

## 4.3 GM 運行指南

### 冰山原則

玩家只該知道冰山一角。使用**真相卡系統**：

- **表層真相**（玩家起始已知）：任務簡報內容
- **裏層真相**（調查後可知）：SCP 真實性質、基金會隱藏數據
- **深淵真相**（可能永遠不知）：O5 的祕密、基金會的真正起源

### 文檔驅動敘事

以"簡報→現場→報告"結構推進

### 首次開團指南

**給新 GM 的 5 步啓動**：

1. **閱讀玩家手冊**（第 1–2 章）：理解核心判定、屬性技能、角色創建
2. **讓玩家創建角色**：參考 §2.1 九步流程。首次建議使用標準數組或範例角色（見 SCP_Pregen_Characters.xlsx）節省時間
3. **選擇起始模組**：
   - 偏好戰鬥 → 系列 A 場景 A-1「鐵處女突襲」（約 2 小時）
   - 偏好調查 → 系列 B 場景 B-1「遺忘的檔案」（約 1.5 小時） 
4. **控場要點**：
   - 每場景準備 2 個檢定（如：偵察 + 異常學）
   - 不要在每個動作都要求檢定——只檢定有風險、有壓力的行動
   - SAN/SP 系統是氛圍工具：不必每輪計算，只在緊張時刻觸發
5. **節奏**：第一場控制在 2–3 小時內結束，以一個完整的「簡報→遭遇→收容」小循環收尾

**第一場建議配置**：
- 3–4 名玩家，Lv.1
- 1 個 Safe 級 SCP
- 1–2 場戰鬥或潛行遭遇
- 1 次 SAN 檢定
- 結尾：寫任務報告（每種難度首次收容成功 +200 XP 獎勵）

：

1. **簡報階段**：GM 分發任務文檔（截斷版 SCP 檔案）
2. **現場階段**：玩家發現文檔中的遺漏、錯誤、刻意隱瞞
3. **報告階段**：玩家撰寫任務報告，GM 比較"官方版本"與"實際經歷"

### 五幕結構

```
第一幕：調查 → 蒐集線索，建立懸疑
第二幕：發現 → 真相揭露，異常展現
第三幕：危機 → 局勢失控，收容壓力
第四幕：抉擇 → 兩難選擇，代價談判
第五幕：收容/犧牲 → 代價兌現，倖存者清點
```

### 漸凍式恐怖（三階段階梯跳躍）

- **階段一：正常**（2–3 場）——日常任務，建立安全感
- **階段二：異常**（3–4 場）——異常出現但可控
- **階段三：深淵**（終場）——不可控恐怖、永久代價

### 氛圍營造三層法

| 層 | 技巧 | 示例 |
|----|------|------|
| 物理層 | 環境描述 | "走廊燈光以每秒一次的頻率閃爍，每次熄滅時你能聽到通風管裏有東西在爬" |
| 語言層 | 文檔語體 | 用臨牀術語描述最恐怖的事物 |
| 情感層 | 道德壓力 | 讓玩家自己做出犧牲決策 |
