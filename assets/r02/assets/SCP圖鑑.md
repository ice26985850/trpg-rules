# SCP 圖鑑（異常實體數據庫）

> 本檔案由《SCP: CONTAINMENT PROTOCOL》主持人指南 §3.9 抽出，作為獨立圖鑑供 GM 與玩家快速查閱。
> 遊戲中的「怪物／敵人」即為各類 SCP 異常實體；其完整角色卡另見 `sheets/敵人角色卡合集.xlsx`。

## SCP 數據模板

建立一張 SCP 時，請依下列欄位填寫數據卡：

```
┌──────────────────────────────────────────────┐
│ SCP 數據卡                                    │
├──────────────────────────────────────────────┤
│ 項目編號：SCP-XXXX    │ 分級：[Safe/Euclid/Keter]│
├──────────────────────────────────────────────┤
│ 戰鬥參數                                      │
│ HP/耐久：[值]    迴避：[AGI]    速度：[m]      │
│ 物理抗性：[穿刺/切割/鈍擊] DR                 │
│ 元素抗性：[熱力/化學/輻射] DR                  │
│ 異常抗性：[免疫/抗性/無/弱點]                  │
│ 理智傷害光環：[強度]                           │
├──────────────────────────────────────────────┤
│ 屬性：STR/END/AGI/PER/INT/WIL/PRE             │
├──────────────────────────────────────────────┤
│ 特殊能力 ×N                                   │
│ · 名稱 · 觸發 · 動作 · 頻率 · 範圍 · 效果     │
├──────────────────────────────────────────────┤
│ 收容協議 + 戰術筆記（GM 專用）                 │
└──────────────────────────────────────────────┘
```

## 預設 SCP 示例（摘要）

- **SCP-███-A "發條士兵"**（Safe，可戰鬥）：機械構造，穿刺 DR 5，熱力弱點，背部發條鎖孔爲致命弱點
- **SCP-████ "鏡中居民"**（Euclid，需智取）：僅存在於反射面，免疫物理傷害，需覆蓋鏡面引導至無光收容艙
- **SCP-████ "虛空之歌"**（Keter，只能生存）：非物理實體，聽覺半徑內每輪 SAN 傷害，4 收容成功點臨時壓制
