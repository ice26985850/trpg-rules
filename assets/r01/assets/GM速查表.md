## A面：核心規則速查

### 判定流程
```
1. 宣告行動 → 2. 對應屬性 → 3. 難度補正
4. 判定值 = 屬性 + 補正 → 5. 擲D100
   ≤判定值 = 成功 | 01-05 = 大成功
   >判定值 = 失敗 | 96-00 = 大失敗
```

### 難度補正
| 極易 +40 | 簡單 +20 | 普通 +0 | 困難 -20 | 極難 -40 |

### 戰鬥公式
```
命中：D100 ≤ HIT - 敵EVA
傷害：(ATK × 倍率 - DEF) × 暴擊 × 屬性
暴擊：D100 ≤ CRT率 → 傷害×2
屬性：有利×1.5 / 不利×0.5
```

### 戰鬥回合
```
每回合：1主要 + 1移動 + 1即時
順序：SPD高→低 (每回合重新確認)
移動距離 = AGI ÷ 2 公尺（疾走每級 + AGI÷10）
```

### 劍技硬直表
| 初級 5-10SP | 0回合硬直 | 可連攜（每連續3次後HIT-10） |
| 中級 11-20SP | 1回合硬直 | |
| 上級 21-35SP | 2回合硬直 | |
| 奧義 36+SP | 3回合硬直 | |

### 切換連攜加成
| 1st: HIT+5 | 2nd: HIT+10, ×1.1 |
| 3rd: HIT+15, ×1.2 | 4th: HIT+20, ×1.3 |
| 5th+: HIT+25, ×1.5 | 失誤 → 重置！ |

### 技能槽（Skill Slot）
```
Lv.1: 2槽 | Lv.10: 3 | Lv.20: 4
Lv.30: 5 | Lv.50: 6 | Lv.70: 7
Lv.90: 8 | Lv.100: 10

武器技能: 1槽 | 被動: 1槽/個
戰鬥通用: 1槽/個 | 生活技能: 獨立2槽
```

### 狀態異常
| 中毒: -VIT÷2 HP/回合 (1D6r) |
| 麻痺: 無法行動+EVA=0 (1D4r) |
| 暈眩: 無法行動+DEF半 (1D3r) |
| 睡眠: 無法行動至被攻擊 (1D6r) |
| 詛咒: 判定-20 (至解除) |
| 出血: -STR÷2 HP/回合 (1D4r) |
| 燃燒: -5HP/回合+DEF-5 (1D4r) |
| 恐懼: 1回合無法行動 |

## B面：GM 工具

### 怪物快速生成
```
普通: HP=Lv×15 ATK=Lv×1.2+5 DEF=Lv×0.9+4
菁英: HP=Lv×30 ATK=Lv×1.5+10 DEF=Lv×1.2+8
Boss: HP=Lv×100+ ATK=Lv×2.0+15 DEF=Lv×1.5+10

HIT=25+Lv×0.5 | EVA=15+Lv×0.35 | SPD=20+Lv×0.4
EXP=Lv×15(普)/40(菁)/120(Boss)
Col=Lv×8(普)/20(菁)/120(Boss)(團隊平分)
```

### 怪物類型速查
| 獸型: SPD+5, ATK+5 | 不死型: 毒/出血免疫, 神聖×2 |
| 蟲型: EVA+5, 火弱點×1.5 | 武裝型: DEF+10, SPD-5, 雷弱點 |
| 龍型: 全屬性+10 | 半獸型: 智慧, 可使用武器 |
| 植物型: 毒/麻痺常見, 火弱點 | 魔法生物: 浮遊, 物理×1.2 |
| 機械型: DEF+15, 毒免疫, 雷弱點 |

### 屬性傷害倍率
| 有利屬性 | ×1.5 | 不利屬性 | ×0.5 | 神聖對不死 | ×2.0 |

### Boss設計檢查表
```
□ 主題與樓層一致
□ 至少2個階段
□ 每個階段2-4個技能
□ 有明確弱點
□ 有範圍攻擊
□ 階段轉換有視覺描述
□ LA獎勵已設定
□ Boss房為水晶無效化區域
□ 攻略會議有情報可收集
```

### 水晶無效化區域規則
```
觸發區域：Boss房間、迷宮陷阱區、高層深層
效果：傳送水晶/迴廊水晶/記錄水晶全部失效
Boss房門：進入後自動鎖閉，Boss死亡才開啟
唯一例外：Boss房外預設的迴廊水晶（需戰術準備）

GM提示：Boss戰前務必告知玩家「此區域為水晶無效化區域」
```

### 決鬥系統速查
| 先手必勝: 先命中者勝, 3回合限 | 訓練/娛樂 |
| 半減決鬥: HP降至50%以下 | 爭端解決 |
| 全損決鬥: HP歸零 → 死亡 | 生死之爭 |

```
決鬥規則：旁觀者不可干涉 | 不可使用回復道具
全損決鬥應為劇情關鍵時刻，勿輕易由NPC發起
```

## D面：冒險架構速查

### 冒險結構模板
```
序幕 → 情報收集 → 野外探索(1-3戰) →
迷宮攻略(3-5戰+陷阱) → Boss戰 →
歸途結算 → 幕間(生活場景)
```

### 獎勵平衡（4人團隊/1次聚會）
- EXP: 每人100-300
- Col: 每人200-500
- 掉落: 0-1件裝備

### 升級需求 (近似)
| Lv.1→5 | 每級 ~150-700 |
| Lv.5→10 | 每級 ~700-1500 |
| Lv.10→20 | 每級 ~2k-5k |
| Lv.20→40 | 每級 ~5k-15k |
| Lv.40→75 | 每級 ~15k-40k |

### 掉落率基準
| 普通: 素材30%, 裝備5% | 菁英: 素材60%, 裝備20% |
| Boss: 素材100%, 裝備100%+LA獎勵 |

### 稀有度倍率
| ★普通 (×1) | ★★精良 (×0.3) | ★★★稀有 (×0.1) |
| ★★★★傳說 (×0.02) | ★★★★★神話 (Boss限定) |

### 消耗品價格速查
| 小藥水 100 | 中藥水 300 | 大藥水 800 | 超高級 2000 |
| 小SP 250 | 中SP 600 | 解毒 150 | 萬能 1000 |
| 傳送水晶 500 | 迴廊水晶 5000 | 記錄水晶 2000 | 炸彈 200 |

### 任務等級
| E: 100-300Col, Lv1-5 | D: 300-800, Lv5-15 |
| C: 800-2k, Lv15-30 | B: 2k-5k, Lv30-50 |
| A: 5k-15k, Lv50-70 | S: 15k+, Lv70+ |

### Downtime 每日活動 (2次/日)
| 打工: 50-200Col | 鍛造/料理練習: 經驗+1 |
| 情報收集: 1D3條情報 | 釣魚: 食材 |
| 社交: 提升NPC好感 | 訓練: Lv×5 EXP |
| 購物/探索/休息 |

### 武器耐久
| ★100耐久 | ★★150 | ★★★250 | ★★★★400 | ★★★★★600 |
| 每戰鬥-1 | 受暴擊-2 | 歸零=ATK剩10% |
| 修理費 = 缺失耐久×稀有度倍率 |

### 樓層解鎖
```
Boss死亡 → 傳送門出現 → 抵達新層主城鎮
→ 啟動傳送門 → 系統全服公告
首次啟動：EXP+100, 稱號「拓荒者」
```
