# SAO TRPG — 艾恩葛朗特攻略地圖資料

> *「浮遊城的每一層都是一個獨立的世界。理解它的結構，是攻略的第一步。」*

---

## 地圖總則

艾恩葛朗特是一座垂直結構的浮遊城堡，從第1層（最底部）到第100層（最頂端）。每一層都是封閉的獨立環境，擁有自己的地形、城鎮、迷宮和守層Boss。

### 地圖基本結構

每一層由三個核心區域組成：

```
┌─────────────────────────────────────────────┐
│            第 [X] 層 地圖結構                 │
├─────────────────────────────────────────────┤
│                                             │
│  ┌─────────────┐                             │
│  │ 主城鎮       │  ← 安全區域（Safe Zone）     │
│  │ (Town)       │     所有設施集中              │
│  └──────┬──────┘                             │
│         │ 電梯塔（Teleport Gate）              │
│    ┌────┴────┐                               │
│    │ 電梯塔   │ ← 連接上下樓層的垂直通道         │
│    │         │     步行需1-3天遊戲時間          │
│    └────┬────┘                               │
│         │                                    │
│  ┌──────┴──────────────────────────────┐     │
│  │  野外區域（Wilderness）               │     │
│  │  草原/森林/沙漠/沼澤/火山…            │     │
│  │  普通/菁英怪物分佈                    │     │
│  └──────────────┬──────────────────────┘     │
│                 │                            │
│  ┌──────────────┴──────────────────────┐     │
│  │  迷宮區（Dungeon）                   │     │
│  │  多層地下迷宮，含陷阱                 │     │
│  │  Boss房間位於迷宮最深處               │     │
│  └─────────────────────────────────────┘     │
│                                             │
└─────────────────────────────────────────────┘
```

### 地圖資訊追蹤

GM 在遊戲過程中需要持續追蹤以下地圖資訊：

| 追蹤項目 | 說明 | 更新時機 |
|---------|------|---------|
| **已攻略樓層** | 哪些樓層已被通關 | 每擊殺1次守層Boss |
| **已探索區域** | 哪些迷宮通道已走過 | 每次探索迷宮 |
| **傳送門狀態** | 各層傳送門是否已啟動 | 每層首次啟動時 |
| **Boss 存活狀態** | Boss 是否已被擊敗 | Boss 戰結束時 |
| **水晶無效化區域** | 哪些區域水晶失效 | Boss房鎖定時 / GM設計 |
| **NPC 位置** | 重要NPC當前在哪層 | 劇情推進時 |
| **樓層主題變化** | 各層環境特徵 | 每層首次抵達時 |


|------|------|
| 玩家首次抵達新樓層 | 標記該樓層為「已探索」，顯示該層地圖資訊 |
| 攻略Boss房 | 標記Boss為「已 defeated」，更新掉落物 |
| 使用傳送水晶 | 確認玩家當前位於哪層 |
| 死亡遊戲宣告後 | 全層範圍開啟迷宮區探索 |
| 通關樓層 | 啟動下一層傳送門，更新全局進度 |
| 進入Boss房 | 標記水晶無效化區域 |

### MAP_UPDATE 範例

```

REGION 基礎難度區 color="rgba(16,185,129,0.1)" nodes=town-beginnings,urbus
[/MAP_UPDATE]
```
