# 第二章：支線劇情線（12 條）

## 2.1 老柯的過去
**觸發：** 完成 3 次拾荒者同盟委託
**進程：**
1. 老柯開始透露自己曾是艾希拉設施保全主管
2. 委託玩家尋找他遺留在靜默社區鐘樓的個人物品
3. 找到老柯女兒的照片——她在崩塌時在設施內工作
4. 老柯給你深層實驗室的備用安全碼（劇本十的關鍵道具）
5. 如果你活著回來告訴他真相，老柯將所有積蓄留給你後離開封鎖區

## 2.2 鐵匠的秘密配方
**觸發：** 鐵匠好感度 等級（Lv.）3+
**進程：**
1. 鐵匠透露他以前是軍方武器研發部門的工程師
2. 委託從鏽蝕工廠取回他當年被沒收的設計圖
3. 設計圖揭示了原型震盪錘的完整製造流程
4. 鐵匠可以為你打造金色武器（材料自備）
5. 如果他得知設計圖被兄弟會複製，委託你銷毀兄弟會的版本

## 2.3 醫生的真實身份
**觸發：** 醫生好感度 等級（Lv.）3 + 完成 2 次醫療委託
**進程：**
1. 醫生在治療你時不經意提到「帷幕實驗的副作用」
2. 你可以追問——醫生曾是艾希拉設施的醫療主任
3. 他隨身帶著一樣東西：一份未經篡改的崩塌日醫療記錄
4. 記錄中提到「實驗體零號」——一個在崩塌前就被裂隙能量感染的人
5. 醫生在尋找這個人。線索指向核心區。

## 2.4 貓頭鷹的棋局
**觸發：** 貓頭鷹好感度 等級（Lv.）4 + 完成 5 次情報委託
**進程：**
1. 貓頭鷹透露自己並非單獨行動——他是一個外界組織的代理人
2. 該組織的目標是確保「帷幕技術」不被任何勢力壟斷
3. 他需要你從五個勢力中各偷一份關鍵情報
4. 完成後揭露：外界有一場針對封鎖區的秘密軍事行動在醞釀
5. 結局分歧：協助貓頭鷹阻止行動 / 出賣情報給 QZAC（封鎖區管理局） / 坐等漁翁之利

## 2.5 欠債者的救贖
**觸發：** 角色出身為「欠債者」
**進程：**
1. 債主派人來催債——一個賞金獵人出現在藏身處門口
2. 可選擇：付清欠款 / 接下債主的危險委託抵債 / 嘗試解決掉債主
3. 如果選擇抵債委託：深入工業區取一件金色物品
4. 債主背後的勢力是走私者網絡的高層
5. 完成後可獲得一個永久被動：談判本能升級（買價-10%賣價+10%）

## 2.6 邊境居民的隱藏路線
**觸發：** 出身為邊境居民 + 等級（Lv.）3+
**進程：**
1. 手繪地圖上的一個標記突然有意義了——那是你祖父留下的記號
2. 實地考察標記位置：核心區邊緣的一個廢棄氣象站
3. 氣象站地下有一個崩塌前建造的祕密避難所
4. 內有：你祖父的遺物 + 一條從未被人發現的進出核心區路線
5. 這條路線可永久使用，且完全避開所有已知勢力

## 2.7 變異體適應者的突變
**觸發：** 出身為變異體適應者 + 等級（Lv.）5+

# 第八章：GM 快速查用指南

## 8.1 快速生成隨機戰利品

**一般容器：** 擲d100，對照戰利品等級分布：
- 邊緣地帶：01-50=灰，51-85=白，86-97=藍，98-100=紫
- 舊城區：01-35=灰，36-75=白，76-92=藍，93-99=紫，100=金
- 工業區：01-20=灰，21-55=白，56-80=藍，81-95=紫，96-100=金
- 核心區：01-10=灰，11-30=白，31-55=藍，56-85=紫，86-100=金

**搜刮屍體：** 根據NPC類型：
- 殘留體：灰×1-2
- 變異生物：白×1+特異材料
- 新手團隊：灰×2-3+白×1-2
- 拾荒幫派：灰×1-3+白×1-2+藍×1(50%)
- 獨狼老手：白×1-3+藍×1-2
- 賞金獵人：白×2+藍×1-2
- 軍閥士兵：白×1-2+藍×1+紫×1(30%)
- 精英/軍官/Boss：藍×2-3+紫×1-2+金×1

## 8.2 快速遭遇生成

1. 擲d10判定是否遭遇：邊緣5+、舊城4+、工業3+、核心區任意
2. 遭遇觸發時擲d100查對應區域的隨機遭遇表
3. 每場出勤遭遇間隔不低於5分鐘遊戲時間（轉角遭遇除外）
4. 每場出勤強制遭遇（含Boss）上限依區域：邊緣2次、舊城3次、工業4次
