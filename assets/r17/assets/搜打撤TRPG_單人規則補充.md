# 搜打撤 TRPG —— 單人規則補充 v1.0

> **適用：** 1 名 GM + 1 名玩家
> **核心變更：** 引入 NPC 伴侶系統、行動點（AP） 調整、威脅重校準、死亡保護、潛行強化

---

# 第一章：為何不適合單人——與如何修正

## 1.1 原系統的單人瓶頸

| 問題 | 原設計 | 單人影響 |
|---|---|---|
| **行動經濟** | 2-4 玩家 = 4-8 行動點（AP）/回合 | 單人僅 2 行動點（AP） → 被包圍即死 |
| **角色分工** | 隊伍可分工（坦克/射手/技師/醫療） | 單人無法兼任 → 遭遇設計受限 |
| **死亡後果** | 隊友可帶走你的裝備 | 單人死亡 = 全損，無緩衝 |
| **被壓制/倒地** | 隊友可掩護或拖走 | 單人倒地 = 幾乎必死 |
| **部位受傷** | 隊友可急救 | 單人右手受傷後連急救自己都難 |
| **遭遇預算** | 依 4 人計算威脅值 | 等級（Lv.）1 最低遭遇 = 殘留體×3 (威脅值9)，對單人過量 |

## 1.2 核心修正

| 修正 | 做法 |
|---|---|
| **NPC 伴侶系統** | 玩家可攜帶 1-2 名 NPC 伴侶出勤（§第二章） |
| **行動點（AP） 調整** | 單人玩家 + 伴侶合計 ≥ 4 行動點（AP）/回合（§1.3） |
| **威脅值重校準** | 所有遭遇威脅值 ×0.5（§第三章） |
| **死亡保護** | 倒地後伴侶可拖拽撤離；死亡可觸發伴侶繼承（§1.4） |
| **潛行強化** | 單人更容易避戰，潛行獎勵 +2（§第四章） |

## 1.3 行動點（AP） 調整

單人模式下，玩家與伴侶共享回合：

| 配置 | 行動點（AP）/回合 |
|---|---|
| 玩家 + 1 伴侶 | 玩家 2 行動點（AP） + 伴侶 2 行動點（AP） = **4 行動點（AP）** |
| 玩家 + 2 伴侶 | 玩家 2 行動點（AP） + 伴侶A 2 行動點（AP） + 伴侶B 2 行動點（AP） = **6 行動點（AP）**（但威脅值不變，GM 可調高） |

玩家操控所有伴侶的行動。伴侶使用簡化數據卡（見 §2.4）。

## 1.4 死亡保護

| 情境 | 原規則 | 單人修正 |
|---|---|---|
| 玩家生命值（HP）=0（胸部） | 瀕死，每回合膽魄目標難度（TN）14 | **伴侶可花 2 行動點（AP） 拖拽撤離**（移動減半，無藉機攻擊） |
| 玩家死亡 | 裝備全失、新角色繼承 | **伴侶可繼承玩家裝備**（伴侶成為新主角）；或伴侶帶裝備返回藏身處再招募新角 |
| 伴侶死亡 | — | 伴侶永久失去。可在藏身處招募新伴侶（§2.5） |

> **引用：** 玩家規則書 §2.12（死亡與繼承）的繼承規則在單人模式下同樣適用。伴侶返回藏身處視為「成功撤離但失去玩家角色」，裝備保留率 100%（取代原 80% 資金繼承）。

# 第二章：NPC 伴侶系統

## 2.1 伴侶取得

| 方式 | 條件 | 獲得 |
|---|---|---|
| **初始伴侶** | 角色創建時 | 選擇 1 名伴侶（從 5 種預設中選擇） |
| **招募** | 藏身處休整階段，花費 1 行動 | 社交應酬成功（TN14）後可從酒館/安全屋招募 |
| **劇情獲得** | 特定支線完成 | 支線 NPC 加入（如救助的新手團隊成員） |
| **僱用** | 交易站 等級（Lv.）2+ | 支付 2,000-5,000 ₽ 僱用專業傭兵（1 次出勤） |

## 2.2 伴侶成長

伴侶不獨立獲取 XP，而是隨玩家等級成長：

| 玩家等級 | 伴侶屬性加成 | 伴侶獲得專長 |
|---|---|---|
| 等級（Lv.）1-2 | 基準值 | 0 |
| 等級（Lv.）3-4 | 基準值 +1 | 1 項 |
| 等級（Lv.）5-6 | 基準值 +2 | 1 項 |
| 等級（Lv.）7-8 | 基準值 +3 | 2 項 |
| 等級（Lv.）9-10 | 基準值 +4 | 2 項 |

## 2.4 伴侶操控規則

- 伴侶使用**簡化版 NPC 數據卡**（見 Excel「伴侶卡」頁）
- 伴侶生命值（HP）使用七部位系統（與玩家相同），但簡化為：**胸生命值（HP）歸零 = 失去意識，頭生命值（HP）歸零 = 死亡**
- 伴侶不承受恐懼/貪婪檢定（由玩家代為承受）
- 伴侶不會主動做重大決定——GM 可提示「鬼影看起來很擔心這條路」，但最終由玩家決定
- 伴侶有 2 行動點（AP）/回合，由玩家指揮

## 2.5 伴侶失去與替換

| 情境 | 結果 |
|---|---|
| 伴侶在出勤中死亡 | 永久失去。裝備可回收（除非來不及）。藏身處可招募新伴侶 |
| 伴侶重傷（胸生命值（HP）=0） | 返回藏身處後需 1d3 次出勤恢復 |
| 玩家死亡但伴侶存活 | 伴侶可成為新主角（使用伴侶數據 + 繼承規則），或招募全新角色 |

# 第三章：威脅值重校準

## 3.1 單人威脅預算

| 玩家等級（+1伴侶） | 建議總威脅值 | 典型遭遇 |
|---|---|---|
| 等級（Lv.）1 | 3-6 | 殘留體×1-2，或變異鼠×2-4 |
| 等級（Lv.）2 | 4-8 | 殘留體×2-3，或 獨狼老手×1 |
| 等級（Lv.）3 | 6-10 | 殘留體×3-4，或 教團成員×2 |
| 等級（Lv.）4 | 8-14 | 軍閥士兵×1-2，或 變異體×1 |
| 等級（Lv.）5 | 10-16 | 軍閥士兵×2-3，或 巡邏隊長×1 |
| 等級（Lv.）6-7 | 12-20 | 精英衛兵×2，或 賞金獵人×1+士兵×2 |
| 等級（Lv.）8-9 | 16-28 | 鐵腕維克托（HP減半），或 教團守護者×1+成員×2 |
| 等級（Lv.）10 | 20-35 | 鐵壁科薩克（生命值（HP）-30%），或 維度守護者（弱化版） |

> **引用：** GM 規則書 §3.8（遭遇難度預算）原表為 4 人設計，本節為單人重校準版本。

## 3.2 Boss 弱化規則

單人模式下，所有 Boss 自動套用以下弱化（擇一）：

| 弱化選項 | 效果 |
|---|---|
| **生命削減** | Boss 所有部位生命值（HP）×0.7（四捨五入） |
| **護甲弱化** | Boss 所有部位 傷害減免（DR） −1 |
| **階段簡化** | 三階段 Boss 縮減為二階段（跳過中間階段） |
| **增援取消** | Boss 不會呼叫增援 |

# 第四章：單人戰術強化

## 4.1 潛行優勢

單人模式下潛行檢定獲得 **+2 永久加值**（更容易避戰）。

> **引用：** 玩家規則書 §3.7 及 GM 規則書 §2.10（潛行/視野規則）。原目標難度（TN） 值不變，本節提供額外加值。

## 4.2 先發制人

單人模式下，若玩家在敵方未察覺時發動攻擊：
- 第一回合玩家 + 伴侶獲得 **+3 先攻**
- 敵方第一回合**措手不及**（不可使用反應）
- 第一擊自動視為**瞄準射擊**（可指定部位，無需花費額外 行動點（AP））

> **引用：** 玩家規則書 §3.2 射擊修正（瞄準射擊規則）。

## 4.3 急救強化

單人模式下，玩家對自己進行急救的目標難度（TN） 從 14 降至 **11**。伴侶急救玩家目標難度（TN） 仍為 11。

> **引用：** GM 規則書 §2.5 特殊動作（急救 DC）。

## 4.4 撤退選項

單人模式下新增撤退選項：

| 行動 | 行動點（AP） | 效果 |
|---|---|---|
| **煙幕撤退** | 2 | 投擲煙霧彈 + 向安全方向移動，不觸發藉機攻擊 |
| **緊急撤離呼叫** | 1 | 若在撤離點 50m 內且持有信號槍，可提前 1d3 回合呼叫撤離載具 |
| **犧牲掩護** | 1 | 命令伴侶壓制射擊（伴侶留在原地），玩家趁機移動。伴侶下回合可能被集火 |

# 第五章：角色創建建議

## 5.1 推薦出身（單人）

| 優先級 | 出身 | 理由 |
|---|---|---|
| ★★★ | 退伍軍人 | 體魄+精準雙高，搭配醫療伴侶可獨立作戰 |
| ★★★ | 拾荒者 | 感知高→先發現威脅，搭配突擊伴侶補火力 |
| ★★☆ | 前公司雇員 | 技術高→開鎖/電子自理，搭配萬能助手 |
| ★★☆ | 醫療人員 | 自帶急救能力，讓伴侶專注戰鬥 |
| ★☆☆ | 欠債者 | 單人負債 = 壓力更大，但談判優勢可獲更好委託 |
| ★☆☆ | 邊境居民 | 感知+膽魄高，隱藏入口單人更安全 |
| ★☆☆ | 變異體適應者 | 抗性強但技術低→需搭配技師伴侶 |

## 5.2 推薦技能

| 必備 | 建議 |
|---|---|
| 槍械 等級（Lv.）3+ | 單人火力是生存基礎 |
| 急救 等級（Lv.）2+ | 備用自療（即使有醫療伴侶） |
| 潛行 等級（Lv.）2+ | 單人避戰優先 |
| 察覺 等級（Lv.）2+ | 先發現威脅 = 先選擇戰鬥或撤退 |

> **引用：** 玩家規則書 §2.2（出身列表）、§1.5（二十技能體系）、§2.1 快速創角（單人玩家建議使用快速創角的「均衡型」或「偵察兵」配置）。
