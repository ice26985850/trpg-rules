# 第四章：世界觀與 GM 運行指南

> **設計者備忘錄**
> 這一章的目的是給 GM 一個「活的沙盒」——每個區域都有歷史，每個 NPC 都有動機，每一件廢墟中的垃圾都曾經屬於某個人。GM 應該能翻開任何一節，找到即興運行所需的素材。同時，我們刻意留下空白：沒有完整的世界地圖，沒有全知敘事，因為封鎖區的本質就是不確定性。

---

## 4.1 世界觀核心設定

### 4.1.1 封鎖區的由來——「帷幕崩塌」

三年前，北聯邦的「艾希拉研究設施」（Aeshir Research Complex）在進行代號「帷幕」的高能物理實驗時發生災難性失控。實驗本意是開發一種新型能源傳輸協議——利用量子糾纏在宏觀尺度上進行即時能量傳遞。但實驗觸及了一個不該被打開的維度裂隙。

**事件經過（官方說法）**：
- **Day 0**：「帷幕」實驗進入第三階段，能量輸出超出預期 4700%
- **Day 0 + 6小時**：艾希拉設施半徑 3 公里內的所有電子設備同時失效
- **Day 0 + 18小時**：第一波「異常脈衝」以艾希拉為中心向外擴散，半徑擴至 15 公里
- **Day 1**：聯邦宣布「汙染管制區」，緊急疏散 50 萬居民
- **Day 3**：軍方封鎖週邊，建立「環區圍牆」——從此無人能合法進出

**實際情況（GM 可依據調節揭露程度）**：
- 「帷幕」實驗打開的不是能量通道，而是一個不穩定的維度介面
- 異常脈衝本質上是一種「現實改寫波」——它改寫了區域內的物理常數、生物結構、甚至時間流速
- 設施核心區域（深層實驗室）至今無人進入並返回
- 聯邦並非無能為力——他們選擇了「封鎖觀察」，並秘密派遣研究隊進入收集數據

### 4.1.2 時間線

| 時間 | 事件 |
|---|---|
| **崩塌日（Day 0）** | 艾希拉設施失控，維度裂隙開啟 |
| **崩塌後 1 週** | 軍隊封鎖，「環區圍牆」開始建造 |
| **崩塌後 1 個月** | 第一批「搜刮者」出現——絕望的難民、前僱員、逃兵 |
| **崩塌後 3 個月** | 第一次「脈衝潮」——異常脈衝週期性增強，區域內生物開始變異 |
| **崩塌後 6 個月** | 封鎖區穩定為四個主要區域（核心區、工業區、舊城區、邊緣地帶） |
| **崩塌後 1 年** | 交易商網絡形成，藏身處經濟建立 |
| **崩塌後 1.5 年** | 聯邦成立「封鎖區管理局」（QZAC），開始有組織地管理外部接觸 |
| **崩塌後 2 年** | 勢力劃分大致穩定，「撤離協議」成為區內通用規則 |
| **現在（崩塌後 3 年）** | 封鎖區處於脆弱的動態平衡中——玩家角色就是在此刻進場 |

### 4.1.3 封鎖區的生態現狀

**異常現象**：
- **脈衝潮**：每 4-6 天出現一次，期間電子設備可能失效（具體擲骰規則參見核心規則第二章【擲骰系統】），高價值區域會在脈衝潮後「刷新」——新的裂隙可能打開，新的物資可能出現
- **重力異常區**：局部重力波動，從輕微減重到瞬間超重不等，是經驗豐富的搜刮者的捷徑或陷阱
- **時間泡**：小範圍內時間流速異常——外面的五分鐘可能是裡面的五小時。傳說有些失蹤的搜刮者還困在某個時間泡裡
- **殘留體**：原設施工作人員和疏散不及的居民，被異常脈衝扭曲後的非人存在。不是殭屍——他們保留部分記憶和行為模式，但動機變得不可預測

**變異生物**：
- 大多數來自封鎖區原有的動物（犬、鼠、鳥類）被脈衝能量改造
- 越接近核心區，變異程度越高
- 部分變異生物具有「異常能力」——短距傳送、局部重力操控、能量吸收

**氣候與環境**：
- 封鎖區上空常年籠罩灰黃色「霾層」，白天光線昏暗，夜晚可見度極低
- 降雨帶有微弱的異常能量，長期暴露有風險但短期可忍受
- 部分建築物處於「半坍塌但結構穩定」的奇異狀態——物理常數偏移的直接證據

### 4.1.4 「外面的世界」

封鎖區外的世界並未崩潰。北聯邦維持著正常運轉，只是多了一個永久的軍事管制區。對普通人來說，「封鎖區」既是新聞中的恐怖故事，也是傳奇致富夢的舞台。

- **官方立場**：封鎖區是「國家安全事件」，任何未經授權進入者視為犯罪
- **灰色地帶**：QZAC（封鎖區管理局）默許部分「持證拾荒者」活動——他們從搜刮者手中收購有價值的研究數據和異常樣本
- **經濟生態**：封鎖區產出的「異常物資」（帶有非常規特性的物品）在外界黑市價格極高，催生了持續的搜刮者經濟
- **媒體管制**：外界對封鎖區的報導受到嚴格審查，大多數人只知道「危險的汙染區」

> **GM 敘事提示**：外面的世界是模糊的、遙遠的。GM 不需要詳細描述外部政治——玩家角色和他們一樣，對外面只有碎片化的認知。重點放在「為什麼還要進去」的個人動機上。

## 4.2 勢力系統

### 4.2.1 五大勢力

#### 勢力一：封鎖區管理局（QZAC）——「圍牆」

| 項目 | 內容 |
|---|---|
| **定位** | 官方機構，負責封鎖區的軍事管制和外部接觸管理 |
| **領地** | 環區圍牆及周邊軍事基地、官方撤離站、檢查站 |
| **目標** | 維持封鎖、控制資訊外流、秘密研究異常現象 |
| **資源** | 正規軍裝備、直升機、無人機監控、衛星通訊 |
| **對搜刮者的態度** | 睜一隻眼閉一隻眼——只要不碰核心區，不帶出「敏感物品」 |

**對玩家的影響**：
- QZAC（封鎖區管理局） 檢查站是邊緣地區可能的撤離點——但使用意味著接受審查和繳稅
- 如果玩家持有「敏感物品」（GM 決定），QZAC（封鎖區管理局） 會在入場時成為潛在威脅
- 偶爾 QZAC（封鎖區管理局） 會發布「官方委託」——報酬豐厚但條件苛刻

#### 勢力二：拾荒者同盟（Scavengers' Compact）——「地下的秩序」

| 項目 | 內容 |
|---|---|
| **定位** | 封鎖區內搜刮者的非正式聯盟，由幾個老手搜刮者創立 |
| **領地** | 舊城區的大部分安全屋網絡、地下交易市場「洞窟」 |
| **目標** | 保障搜刮者的基本權益、維持區內最低限度的規則、對抗軍閥 |
| **資源** | 資訊網絡、安全屋、武器藏匿點、老手搜刮者的人脈 |
| **對搜刮者的態度** | 歡迎所有遵守「不主動對同類開槍」基本規則的搜刮者 |

**關鍵人物**：
- **「老柯」**：前艾希拉設施保全主管，崩塌後第一批進入封鎖區的人之一。從不談論自己在核心區看到了什麼。
- **「醫生」**：代號，真名不詳。在舊城區經營一家地下診所，收費合理，對所有人開放——包括敵對勢力成員。

**與玩家的互動**：
- 加入同盟需要推薦人或完成信任考驗
- 提供安全屋鑰匙、情報、二手裝備
- 違反同盟規則（背叛同類）會被標記為不受歡迎

#### 勢力三：鋼鐵兄弟會（Iron Brotherhood）——「軍閥」

| 項目 | 內容 |
|---|---|
| **定位** | 由叛變的前軍官「鋼鐵上校」領導的軍事化組織 |
| **領地** | 工業區的大部分、原軍方補給站 |
| **目標** | 壟斷封鎖區內的軍用級裝備和異常物資，建立區內政權 |
| **資源** | 重武器、裝甲車、前正規軍士兵、嚴格的指揮鏈 |
| **對搜刮者的態度** | 領地意識極強——未經許可進入工業區等於宣戰 |

**巡邏模式**：
- 固定路線、固定時間的武裝巡邏
- 發現即開火，極少警告
- 工業區核心地帶由兄弟會完全控制

**與玩家的互動**：
- 原則上不談判——但 GM 可以設計「繳過路費」的例外
- 如果玩家持有兄弟會正在尋找的特定物品，可能引發懸賞
- 極少數情況下，兄弟會可能僱用外部搜刮者執行危險任務

#### 勢力四：觀察者教團（Order of the Watchers）——「狂信者」

| 項目 | 內容 |
|---|---|
| **定位** | 將異常現象視為「神聖顯現」的秘密宗教組織 |
| **領地** | 核心區邊緣地帶、廢棄的宗教建築、地下殿堂 |
| **目標** | 研究並崇拜維度裂隙，相信這是人類進化的契機 |
| **資源** | 對異常現象的特殊知識、精神抗性訓練、狂熱追隨者 |
| **對搜刮者的態度** | 不主動敵對，但會阻止任何人進入「聖地」（核心區特定位置） |

**信仰體系**：
- 「帷幕」是神聖的邊界，裂隙是神明與人類之間的橋樑
- 異常脈衝是神明的低語——教團成員通過長期暴露來「聆聽真理」
- 殘留體是被選中的「先行者」，變異生物是神聖的守護者

**與玩家的互動**：
- 可以提供異常現象相關的情報和導航
- 可能會僱用搜刮者獲取「神聖遺物」（異常物品）
- 如果玩家攻擊教團視為神聖的生物或場所，將成為永久敵人

#### 勢力五：走私者網絡（Smuggler's Ring）——「影子商人」

| 項目 | 內容 |
|---|---|
| **定位** | 連接封鎖區與外界的非法貿易網絡 |
| **領地** | 邊緣地帶的秘密通道、地下交易站、外界的黑市據點 |
| **目標** | 利潤最大化——運出異常物資，運入武器和奢侈品 |
| **資源** | 秘密進出通道、偽造文件、外界的聯絡人和買家 |
| **對搜刮者的態度** | 純粹的交易關係——有貨就歡迎，沒貨就無視 |

**運作方式**：
- 走私者掌握若干不為 QZAC（封鎖區管理局） 所知的進出通道（「老鼠洞」）
- 他們是裝備和資訊流入封鎖區的主要管道
- 價格高昂但信譽良好——只要付得起，他們什麼都能搞到

**與玩家的互動**：
- 玩家可以通過走私者購買稀有裝備
- 偶爾走私者會發布「快遞」委託——運送特定物品進出封鎖區
- 使用走私者的退出通道比官方撤離點更貴但更安全（免審查）

### 4.2.3 聲望系統

| 聲望等級 | 數值範圍 | 效果 |
|---|---|---|
| **仇敵** | -50 以下 | 該勢力主動追殺你 |
| **敵對** | -20 ~ -49 | 見面即開火，拒絕一切互動 |
| **冷淡** | -19 ~ -1 | 不信任，交易價格上浮 20% |
| **中立** | 0 | 默認狀態，基本交易可能 |
| **友好** | 1 ~ 20 | 交易價格優惠 10%，可能獲得情報 |
| **尊敬** | 21 ~ 50 | 交易價格優惠 20%，解鎖特殊委託和稀有物品 |
| **崇拜** | 51 以上 | 該勢力將你視為自己人，提供獨特支援 |

**聲望增減範例**：

| 行為 | 影響 |
|---|---|
| 完成勢力委託 | +5 ~ +15（依難度和勢力） |
| 擊殺該勢力成員 | -10 ~ -20 |
| 救助該勢力成員 | +5 ~ +10 |
| 交出該勢力需要的物品（不收費） | +3 ~ +8 |
| 背叛約定 | -15 ~ -25 |
| 在該勢力領地內幫助其敵人 | 雙重影響 |
| 向該勢力提供有價值情報 | +2 ~ +10 |

> **GM 提示**：聲望是隱藏的。玩家不應該知道確切的數值——他們通過 NPC 的態度和可用選項來感受自己的地位變化。

## 4.3 地理設定

### 4.3.1 封鎖區整體佈局

封鎖區大致呈不規則的圓形，總面積約 200 平方公里，以艾希拉研究設施為圓心向外分為四個環形區域：

```
        北
        │
    邊緣地帶（最外環）
    ┌──────────────┐
    │  舊城區       │
    │  ┌────────┐  │
    │  │ 工     │  │
    │  │ 業  ◆ │  │   ◆ 核心區（艾希拉設施）
    │  │ 區     │  │
    │  └────────┘  │
    │      工業區    │
    └──────────────┘
```

| 區域 | 距核心 | 危險等級 | 主要勢力 | 物資品質 |
|---|---|---|---|---|
| **邊緣地帶** | 15-20 km | ★☆☆☆☆ | QZAC（封鎖區管理局） 巡邏、新手搜刮者 | 垃圾~普通 |
| **舊城區** | 8-15 km | ★★★☆☆ | 拾荒者同盟、走私者 | 普通~稀有 |
| **工業區** | 3-8 km | ★★★★☆ | 鋼鐵兄弟會、教團 | 稀有~軍規 |
| **核心區** | 0-3 km | ★★★★★ | 未知（極端異常） | 軍規~傳奇 |

### 4.3.2 樣本地圖一：「灰燼商場」——邊緣地帶

**概述**：曾經的郊區購物中心，疏散時留下大量混亂。現在是新手搜刮者的訓練場和低風險搜刮區。

| 項目 | 內容 |
|---|---|
| **區域大小** | 約 500m × 400m（含停車場和附屬建築） |
| **主要建築** | 三層商場主體、地下停車場、周邊加油站和倉庫 |
| **可見度** | 日間：中等（霾層下），夜間：低（部分區域有應急燈） |
| **異常強度** | 弱——偶發的輕微重力波動（無實質影響） |

**主要地標**：

| 地標 | 描述 | 潛在物資 |
|---|---|---|
| **美食廣場** | 二樓中央開放區域，桌椅翻倒，食物早已腐爛 | 基礎醫療品、生存工具 |
| **電子商品店** | 大部分已掠奪但仍有遺漏，後方倉庫門關閉 | 電子零件（稀有）、工具 |
| **地下停車場** | 昏暗、潮濕、多轉角——完美的伏擊點 | 車輛零件、燃油罐 |
| **管理辦公室** | 三樓鎖著的門後，可能存有地圖和鑰匙 | 區域鑰匙、情報文件 |
| **加油站** | 獨立建築，儲油槽仍有燃油 | 燃油、車輛維修工具 |

**物資分布**：

| 物資品質 | 分布位置 |
|---|---|
| 垃圾（灰） | 各層走廊、公共區域——數量充足但價值低 |
| 普通（白） | 商店貨架、後方倉庫——需要搜索檢定 |
| 稀有（藍） | 管理辦公室、電子店倉庫、停車場隱藏點 |

**危險等級**：★☆☆☆☆
- AI 殘留體數量：2-5（主要是巡邏型，非攻擊性除非被驚擾）
- 變異生物：0-1（小型變異鼠群，易於驅散）
- NPC 搜刮者遭遇機率：每 30 分鐘遊戲時間擲骰，5+（d10）即遭遇

**入場點**：

| 入場點 | 位置 | 風險 | 優勢 |
|---|---|---|---|
| **東側服務入口** | 商場後方卸貨區 | 低——開放視野，少遮蔽 | 直接進入地下停車場 |
| **北側公交站** | 商場北側公車站廢墟 | 中低——半開放，部分遮蔽 | 靠近美食廣場入口，視野好 |
| **西側通風管道** | 商場西側的外部通風口 | 中——狹窄，進入時無法觀察室內 | 直接進入二樓，避開一樓 AI |

**撤離點**：

| 撤離點 | 類型 | 條件 | 風險 |
|---|---|---|---|
| **東停車場撤離點** | 固定 | 信號槍發射（需消耗信號彈） | 信號會引來附近 AI 和 NPC |
| **加油站後方** | 固定 | 需等待撤離載具（d6 回合） | 等待期間暴露 |
| **屋頂直升機坪** | 隱藏 | 需要找到管理辦公室的鑰匙，且信號槍 | 最安全但需要前置條件 |

**NPC 巡邏路線提示**：
- 新手團隊常在一樓大廳和美食廣場之間來回——他們怕去停車場

## 4.4 出勤循環敘事框架

### 4.4.1 藏身處：快速處理還是詳細角色扮演？

藏身處是玩家的安全空間——也是推動劇情的地方。GM 應根據團的風格調整節奏：

**快速模式**（適合 3-4 小時單次團）：
- 藏身處場景控制在 10-15 分鐘
- 重點：選擇委託 → 整備裝備 → 確認入場點 → 進場
- 使用摘要式的選單互動：「你可以從交易商那裡買到以下物品……」「你收到了三份委託……」

**深度模式**（適合長期戰役）：
- 藏身處是角色發展和勢力互動的核心舞台
- 每個交易商都有個性和支線故事
- 藏身處升級伴隨敘事事件（安裝新設備時發現前任主人的遺物、牆內找到隱藏訊息）
- 其他搜刮者可能來訪——合作邀約、警告、或威脅

**敘事節奏範例（快速模式）**：

> **GM**：「回到藏身處。你把背包甩在角落，傷口還在隱隱作痛。現金增加了 2,400，還帶回來一個紫色的軍用無線電模組。老柯留了訊息在桌上——他說有份工作要談。你的醫務室告訴你需要三天恢復傷勢……但三天沒有收入。要聽聽老柯的委託，還是先去交易站看看？」

### 4.4.2 入場階段的敘事引導

入場是從安全到危險的過渡——GM 應該讓玩家感受到這種轉變。

**入場引導範本**：

> **GM**：「你們選擇從鏽蝕工廠的南側圍牆缺口進入。載具在距離圍牆五百米外停下——不能再靠近了。最後檢查裝備。你們背上的背包重量、手裡的武器——這些就是你們能帶進去的全部了。圍牆那頭，黃色的霾層靜靜地懸浮在空中。聽不到任何聲音。缺口就在前方二十米。誰走第一個？」

**關鍵敘事元素**：
- 強調「最後檢查」的儀式感——讓玩家意識到裝備選擇的分量
- 描繪邊界的物理存在（圍牆、霾層、廢墟）
- 使用沉默和環境音——入場時不要立刻投放遭遇
- 給玩家短暫的「安全幻覺」——入場後的前幾分鐘應該相對平靜

### 4.4.3 區內探索的節奏控制

這是搜打撤 TRPG 最核心的敘事挑戰。推薦使用「緊張→喘息→緊張」的三拍節奏：

**節奏模板（以 60 分鐘區內時間為例）**：

```
[0-10 分鐘] 入場期 → 緊張度：低
  - 環境描寫為主
  - 給玩家熟悉地形和制定計畫的空間
  - 至多一個低威脅遭遇（小型變異生物或遠處的聲響）

[10-25 分鐘] 第一搜刮期 → 緊張度：中
  - 第一個物資點
  - 巡邏型 AI 的可能遭遇
  - 遠方槍聲——提示其他搜刮者的存在

[25-35 分鐘] 轉折點 → 緊張度：高
  - 發現高價值物資（但位置暴露或有守衛）
  - 遭遇 NPC 搜刮者小隊
  - 環境變化（脈衝潮開始、天氣惡化）

[35-45 分鐘] 決策期 → 緊張度：最高
  - 玩家背包快滿了——繼續搜刮還是撤離？
  - 撤離路線上出現新威脅
  - 多個NPC小隊可能在撤離點附近聚集

[45-60 分鐘] 撤離期 → 緊張度：極高
  - 撤離倒數計時
  - 撤離點衝突
  - 最終逃脫或失敗
```

**緊張度的 GM 工具**：

| 工具 | 效果 |
|---|---|
| **時間壓力** | 「脈衝潮將在 30 分鐘後到達——屆時所有電子設備可能失效（參見核心規則第二章【擲骰系統】）」 |
| **聽覺線索** | 遠方的槍聲、腳步聲、非人的嘶吼——讓玩家感知到威脅的存在但不定位 |
| **物資誘惑** | 「透過倉庫裂縫，你看到一個藍色標記的箱子——但它在大廳的另一端，完全暴露」 |
| **地形壓力** | 唯一的退路被堵、門在身後鎖上、地板開始塌陷 |
| **NPC 壓力** | 聽到其他小隊的無線電通訊、看到手電筒光柱在走廊遠處晃動 |

> **最重要的 GM 原則**：永遠給玩家選擇。不要強制遭遇。最好的緊張來自「我選擇繼續找，但我知道這很危險」——而非「GM 又扔了一波怪」。

## 4.5 委託系統

### 4.5.1 委託類型

| 類型 | 描述 | 範例 | 報酬類型 |
|---|---|---|---|
| **搜刮委託** | 找到並帶回特定物品 | 「工廠需要 3 個軍用級電子零件」 | 現金 + 聲望 |
| **消滅委託** | 消滅特定目標 | 「清理灰燼商場地下停車場的變異體」 | 現金 + 聲望 + 特定戰利品 |
| **偵察委託** | 前往特定地點並回報 | 「確認鏽蝕工廠行政大樓的兄弟會兵力」 | 現金 + 情報獎勵 |
| **救援委託** | 找到並護送某人撤離 | 「新手團隊在靜默社區失聯——找到他們並帶出來」 | 高額現金 + 聲望 + 特殊關係 |
| **快遞委託** | 將物品從 A 運到 B | 「把這個密封箱送到走私者的安全屋」 | 現金（不問內容） |
| **標記委託** | 在特定地點放置信標/裝置 | 「在核心區邊緣放置三個監測信標」 | 現金 + 稀有裝備 |

### 4.5.2 委託難度與報酬

| 難度 | 推薦區域 | 敵對遭遇數 | 時間（遊戲內） | 基礎報酬 | 風險 |
|---|---|---|---|---|---|
| **簡單** | 邊緣地帶 | 0-2 | 1-2 小時 | 500-1,000 | 低——可能失去少量裝備 |
| **普通** | 邊緣/舊城 | 1-3 | 2-4 小時 | 1,000-3,000 | 中——可能遭遇NPC小隊 |
| **困難** | 舊城/工業 | 3-5 | 3-6 小時 | 3,000-8,000 | 高——很可能遭遇敵對勢力 |
| **極限** | 工業/核心 | 5+ | 4-8 小時 | 8,000-20,000+ | 極高——高機率遭遇Boss級威脅 |

### 4.5.3 限時委託 vs 常規委託

**常規委託**：
- 隨時可接，沒有時間限制
- 多個常規委託可以同時進行
- 報酬穩定但較低

**限時委託**：
- 有明確的完成期限（下一個脈衝潮之前、24小時內）
- 報酬顯著高於常規（1.5倍至3倍）
- 失敗可能有聲望懲罰
- 通常來自特殊勢力或有時間敏感性的需求

**Boss 委託**（特殊限時）：
- 每數次出勤才出現一次的特殊委託
- 目標是區域 Boss（強大的變異體或敵對 NPC 領袖）
- 可能有多個勢力同時發布同一目標的委託
- 最高報酬但最高風險

## 4.6 NPC 搜刮者完整行為模板

### 4.6.1 獨狼老手

**基本資料**：
| 項目 | 內容 |
|---|---|
| **小隊規模** | 1人 |
| **裝備等級** | 軍規為主（紫色），可能持有傳奇物品 |
| **活動區域** | 所有區域，偏好高價值低人流地點 |
| **出場機率** | 10%（不限區域） |

**AI 行為腳本**：

| 階段 | 行為 |
|---|---|
| **巡邏模式** | 沿區域邊緣移動，利用掩體，每回合進行一次感知檢定（聽/看） |
| **發現目標** | 優先觀察（1-2回合），評估對方裝備和意圖後決定行動 |
| **遭遇反應** | 若對方強勢 → 隱蔽並等待對方經過；若對方弱勢 → 保持距離繼續觀察；若對方持有高價值物品 → 可能跟蹤 |
| **戰鬥戰術** | 極少主動開戰。若被迫交戰，使用狙擊/遠程、打帶跑、利用地形優勢。精準射擊要害。 |
| **撤退條件** | HP 低於 50% 即撤退；若對方人數超過 2 人，HP 低於 70% 即撤退 |
| **特殊行為** | 可能留下小型物資作為誘餌；在撤離點附近伏擊是最危險的局面 |

**互動觸發條件**：
- 玩家未先開火 + 雙方距離 20m 以上 → 可能喊話
- 玩家主動展示非敵對姿態（放下武器、舉手）→ 可能短暫交流

**範例台詞**：
- 「別靠近。我不找你麻煩，你也別找我麻煩。」
- （看到玩家持有高價值物品）「那個無線電模組……你在哪找到的？」
- 「建議你別走東邊。兄弟會剛過去。」
- （談判時）「我要你背包裡的那個藍色的東西。一個換一個情報。」

### 4.6.2 新手團隊

**基本資料**：
| 項目 | 內容 |
|---|---|
| **小隊規模** | 2-4人 |
| **裝備等級** | 垃圾~普通為主（灰/白），可能有一件稀有物品 |
| **活動區域** | 邊緣地帶為主，偶爾進入舊城區 |
| **出場機率** | 20%（邊緣地帶） / 10%（舊城區） |

**AI 行為腳本**：

| 階段 | 行為 |
|---|---|
| **巡邏模式** | 雜亂無章，邊走邊低聲交談（感知檢定容易發現他們），在建築物間猶豫 |
| **發現目標** | 可能驚慌——擲膽魄檢定決定是否保持冷靜。若失敗可能驚叫或開槍 |
| **遭遇反應** | 極其多變：可能試圖逃跑（40%）、可能試圖談判（35%）、可能因恐懼先開火（25%） |
| **戰鬥戰術** | 協調差，容易中埋伏。傾向集火一個目標但命中率低。彈藥有限（3-5回合後可能耗盡）。 |
| **撤退條件** | 任一成員HP低於50% → 全隊撤退（可能丟下倒地隊友）。彈藥耗盡 → 立即撤退。看到變異生物 → 50%機率直接逃跑。 |
| **特殊行為** | 受傷倒地後可能求饒；可能願意用情報或物品換取安全通行 |

**互動觸發條件**：
- 幾乎總是願意談判（除非因恐懼先開火）
- 看到全副武裝的玩家時容易接受威嚇

**範例台詞**：
- 「等等——等等！我們只是來找醫療用品的！不要開槍！」
- 「你們是老手嗎？拜託……我們的隊友受傷了……」
- （被威嚇時）「好、好的，我們把東西放下，別殺我們……」
- （看到變異生物）「那是什麼——跑！快跑！」

### 4.6.3 賞金獵人

**基本資料**：
| 項目 | 內容 |
|---|---|
| **小隊規模** | 1-3人 |
| **裝備等級** | 稀有~軍規（藍/紫），針對目標特化裝備 |
| **活動區域** | 依照目標位置而定，常在 Boss 區域附近 |
| **出場機率** | 5%（常規）/ 15%（有 Boss 委託時） |

**AI 行為腳本**：

| 階段 | 行為 |
|---|---|
| **巡邏模式** | 目的性極強，直線前往目標區域，沿途對非目標單位保持警戒但不糾纏 |
| **發現目標** | 快速判定是否為目標。若非目標 → 評估是否構成威脅。若為目標 → 進入狩獵模式。 |
| **遭遇反應** | 先試探——觀察裝備、詢問意圖。若玩家非目標且不干擾 → 無視。若玩家干擾狩獵 → 警告後開火。若玩家是目標 → 立即開火或設伏。 |
| **戰鬥戰術** | 專業水準——協調攻擊、使用戰術裝備（閃光彈、煙霧）、優先擊倒威脅最大的目標 |
| **撤退條件** | 目標已消滅 → 立即撤離。HP 低於 40% 且目標未消滅 → 評估後決定（50%撤退/50%繼續）。 |
| **特殊行為** | 可能提出「合作狩獵」——「目標的戰利品歸我，路上的物資歸你」 |

**互動觸發條件**：
- 玩家非目標 + 保持距離 → 可能簡短對話
- 玩家詢問目標 → 可能分享情報（收費）
- 玩家試圖幫助 → 謹慎接受

**範例台詞**：
- 「我在找一個人。你們不會想擋路的。」
- （評估玩家後）「你們裝備不錯。但不是我要找的。」
- 「那個變異體是我標的。你們可以幫忙，但戰利品是我的。」
- 「你們看到一個獨自行動的、揹長槍的傢伙嗎？」

### 4.6.4 拾荒幫派

**基本資料**：
| 項目 | 內容 |
|---|---|
| **小隊規模** | 3-6人 |
| **裝備等級** | 垃圾~普通（灰/白），1-2人可能持稀有武器 |
| **活動區域** | 舊城區（主要）、邊緣地帶（次要）、工業區（少見） |
| **出場機率** | 25%（舊城區） / 15%（邊緣地帶） |

**AI 行為腳本**：

| 階段 | 行為 |
|---|---|
| **巡邏模式** | 人數優勢——大聲喧嘩、佔據主要通道、逐個建築搜刮。不在乎暴露。 |
| **發現目標** | 先評估人數和裝備。若己方人數優勢明顯 → 貪婪模式。若對方看起來強 → 收保護費模式。 |
| **遭遇反應** | 首選 → 要求「過路費」或「留下背包走人」。若對方示弱 → 得寸進尺。若對方強硬反擊 → 可能退縮。 |
| **戰鬥戰術** | 人海戰術但協調差。傾向包圍威脅然後一起開火。容易被各個擊破。若領頭的倒下 → 士氣大降（全員膽魄檢定）。 |
| **撤退條件** | 成員減員超過50% → 潰散。領頭的倒下 → 全員蛻變檢定，失敗則逃散。遇到軍閥巡邏隊 → 立即逃跑。 |
| **特殊行為** | 收錢後可能「加價」——不可信任。可能跟蹤玩家到高價值物資點然後搶劫。 |

**互動觸發條件**：
- 幾乎一定會嘗試互動（通常是負面——勒索或威脅）
- 賄賂非常有效——但只買到暫時安全

**範例台詞**：
- 「嘿！新來的？這條街是我們的。想過去？留下點東西。」
- 「你們背包看起來挺沉的。需要幫忙……減輕負擔嗎？」
- （頭目被擊倒後）「老大倒了——撤撤撤！」
- （收錢後）「好，今天算你們運氣好。快滾。」

**AI 行為腳本**：

| 階段 | 行為 |
|---|---|
| **巡邏模式** | 兩人並排前進、固定路線、定時無線電回報。間距固定（戰術隊形）。配有手電筒和夜視設備。 |

- **無**。在工業區遭遇兄弟會巡邏隊 = 戰鬥（或極度幸運的躲藏）。

**範例台詞**：

- （無線電通報）「指揮部，B隊在貨場發現未授權人員。請求交戰許可。」
- 「射擊！不要讓他們靠近管線入口！」

## 4.7 撤離系統設計

### 4.7.1 撤離點類型

| 類型 | 描述 | 優點 | 缺點 |
|---|---|---|---|
| **固定撤離點** | 每張地圖 1-2 個已知位置，永遠可用 | 可預測、可規劃路線 | 最擁擠、最可能被伏擊、最可能被 NPC 佔用 |
| **隨機撤離點** | 每次出勤隨機啟動 1-2 個 | 意外性、可能更安全 | 需要找到並確認，可能離主要路線很遠 |
| **隱藏撤離點** | 需要特定條件才能使用（鑰匙、情報、信號槍） | 最安全、可能靠近高價值區域 | 需要前置準備和資源消耗 |
| **條件撤離點** | 滿足條件後開啟（清空區域、擊敗守衛、啟動設備） | 獨特的敘事體驗、可能獲得額外獎勵 | 高風險、不可預測 |

### 4.7.2 撤離點衝突場景

**場景一：被佔用**
> 「你接近撤離點，聽到前方傳來聲音。透過掩體觀察——一隊拾荒幫派正在撤離點等待載具，他們的背包都滿了。倒數計時還有 8 分鐘。」

處理選項：
- 等待他們離開（但倒數計時可能不夠）
- 談判共享撤離（可信度存疑）
- 武力奪取（他們人多）
- 找另一個撤離點（時間壓力）

**場景二：被伏擊**
> 「撤離點看起來很安靜。但你的直覺在尖叫——太安靜了。做一個感知檢定。成功？好的——你注意到左側廢墟的陰影角度不太自然，有人在掩體後等待。」

處理選項：
- 反向伏擊（需要戰術優勢）
- 繞路從另一側接近
- 等待伏擊者不耐煩（但倒數計時在走）
- 放棄此點尋找其他撤離點

**場景三：限時壓力**
> 「無線電傳來警告——脈衝潮預計 12 分鐘後抵達。所有電子設備將在脈衝潮中失效。最近的可用撤離點在 10 分鐘路程外——如果你全速前進。」

處理選項：
- 全速前往（放棄沿途物資，可能遭遇伏擊）
- 冒險多拿一件（背包空間 vs 時間）
- 使用隱藏撤離點（如果玩家已解鎖）

**場景四：撤離點關閉**
> 「你到達撤離點，但發現信標已被破壞——有人在你之前經過這裡，故意毀掉了撤離設備。倒數計時還有 15 分鐘，但你需要找到另一個撤離點。」

處理選項：
- 尋找隨機撤離點（需要感知和導航檢定）
- 使用條件撤離點（如果有備用計畫）
- 冒險穿越危險區域到另一個固定撤離點

### 4.7.3 撤離失敗的敘事處理

撤離失敗（未能及時到達撤離點）不必然等於角色死亡。GM 有以下敘事選項：

**選項 A：脈衝潮吞噬**（不死亡但失去裝備）
> 「脈衝潮在你們還差三百米時就來了。世界變成一片白——不是光，而是一種……空白的轟鳴。當你們恢復意識時，背包和武器都不見了，身上的電子設備全部報廢。但你們還活著。四小時後，你們跌跌撞撞地走回了藏身處。」

**選項 B：被迫躲藏**（延長出勤變成生存場景）
> 「撤離載具離開了。你們被困在封鎖區內。接下來的 24 小時變成了一場截然不同的遊戲——不是搜刮，是生存。你們躲在下水道裡，聽著地面上軍閥的腳步聲和遠處變異體的嚎叫。明天，會有新的撤離窗口。」

**選項 C：被俘**（開啟新敘事線）
> 「當你們衝向撤離點時，兄弟會已經在那裡等待。『放下武器——你們的撤離許可已被撤銷。』你們被押往工業區深處。裝備被剝奪，但至少……你們還活著。接下來的故事，關於逃脫。」

**選項 D：死亡**（全損）
> 「槍聲在最後一秒響起。狙擊手。你們甚至沒看到是誰。角色死亡。裝備全部遺失。」

> **GM 指南**：選項 D 應該是真實威脅但非默認結果。每次使用選項 A-C 時，確保玩家付出實質代價（裝備損失、時間損失、新困境），否則死亡威懾系統將失效。推薦比例：約 40% 的撤離失敗導致死亡，60% 導致其他後果。

## 4.8 遭遇設計指南

### 4.8.1 遭遇難度平衡

搜打撤 TRPG 不追求「公平戰鬥」——不對稱是核心魅力。平衡的目標是確保玩家有足夠的資訊做出選擇。

**遭遇設計三要素**：

| 要素 | 說明 |
|---|---|
| **預警** | 玩家能否在遭遇前獲得資訊？（聲音、光線、NPC行為提示、環境線索） |
| **選擇** | 玩家是否有除了「開打」以外的選項？（繞過、談判、等待、設伏） |
| **後果** | 戰鬥的結果是否有趣？（資源消耗、聲望變化、新情報、撤退路線改變） |

**遭遇分類**：

| 類型 | 預警 | 選擇 | 後果 | 範例 |
|---|---|---|---|---|
| **環境告知** | 高 | 多 | 低 | 遠方槍聲、廢墟中的血跡 |
| **可選遭遇** | 中 | 多 | 中 | 前方有巡邏隊——繞路還是交戰？ |
| **轉角遭遇** | 低 | 少 | 高 | 開門——房間裡全是殘留體 |
| **Boss 遭遇** | 高 | 中 | 極高 | 區域 Boss，有前置情報 |

**轉角遭遇的使用限制**：
- 每次出勤最多 1-2 次轉角遭遇
- 永遠不要在玩家背包已滿且正要撤離時使用
- 永遠在轉角遭遇後提供高品質的喘息場景

### 4.8.2 物資點與危險的比例

| 區域 | 物資豐富度 | 危險密度 | 物資/危險比 | 設計意圖 |
|---|---|---|---|---|
| **邊緣地帶** | 低（主要灰/白） | 低 | 平衡 | 讓新手學習基本循環 |
| **舊城區** | 中（白/藍） | 中 | 物資略多 | 讓玩家體驗貪婪抉擇 |
| **工業區** | 高（藍/紫） | 高 | 危險略多 | 高風險高回報——老手樂園 |
| **核心區** | 極高（紫/金） | 極高 | 危險顯著多於物資 | 終極挑戰——需要團隊和計畫 |

### 4.8.3 各區域遭遇密度建議

| 區域 | 推薦遭遇數（3小時出勤） | 其中戰鬥遭遇 | 其中NPC遭遇 | 其中環境事件 |
|---|---|---|---|---|
| **邊緣地帶** | 3-5 | 1-2 | 1-2 | 0-1 |
| **舊城區** | 4-7 | 1-3 | 2-3 | 1-2 |
| **工業區** | 5-8 | 2-4 | 2-3 | 1-2 |
| **核心區** | 6-10 | 3-5 | 1-2 | 2-3 |

## 4.9 GM 運行指南

### 4.9.1 第一次帶團的流程建議

**準備清單**：

- [ ] 選擇樣本地圖（推薦：灰燼商場——邊緣地帶）
- [ ] 準備 3 個委託（至少 1 個簡單、1 個普通）
- [ ] 預先擲好遭遇表的前 3 個結果（讓開場流暢）
- [ ] 準備 5-8 個物資點的位置和內容
- [ ] 決定撤離點配置（至少 2 個可用撤離點）
- [ ] 準備 1-2 個 NPC 小隊的完整資料（推薦：1 個新手團隊 + 1 個拾荒幫派）
- [ ] 熟悉基本規則擲骰（屬性檢定、戰鬥流程）
- [ ] 準備一張簡易地圖（手繪即可）

**開場流程**（60 分鐘入門版本）：

| 時間 | 環節 | 內容 |
|---|---|---|
| 0-5 分鐘 | 規則簡介 | 快速說明屬性、3d6擲骰系統、六部位HP（頭/胸/腹/左臂/右臂/左腿/右腿）、負重 |
| 5-10 分鐘 | 藏身處 | 選擇委託 + 確認裝備（預設裝備卡發放） |
| 10-15 分鐘 | 入場 | 環境描寫 + 入場點選擇 |
| 15-45 分鐘 | 區內行動 | 2-3 個物資點 + 1 次 NPC 遭遇 + 1 次戰鬥 |
| 45-55 分鐘 | 撤離選擇 | 倒數計時 + 撤離點衝突 |
| 55-60 分鐘 | 結算 | 戰利品 + 經驗 + 聲望變化 |

### 4.9.2 如何營造緊張氛圍

**具體技巧**：

1. **用沉默而不是噪音**：最恐怖的時刻不是槍響之後，而是槍響之前的寂靜。在遭遇前留 3-5 秒的沉默。

2. **用玩家的想像力**：「你聽到走廊那頭傳來金屬碰撞的聲音——然後停了。完全的沉默。你的手電筒光束在牆上晃動。」——不要立刻告訴他們那是什麼。

3. **資源計數的儀式感**：當玩家說「我用最後一個彈匣」時，停頓一秒。讓所有人意識到這個事實。

4. **身體反應描寫**：不是「你很害怕」，而是「你發現自己的手在微微顫抖——握把上的汗水讓準星變得模糊」。

5. **不完整資訊**：永遠不要在第一次描述時給出完整畫面。「角落裡有什麼東西在動——你沒看清，但你的身體已經在後退了。」

6. **時間視覺化**：在桌上放一個倒數計時器（手機即可），讓玩家看到時間在流逝。

7. **物資誘惑的具體化**：「箱子打開——裡面是一把完整保養的軍用狙擊步槍。配件齊全。在黑市能賣至少 8,000。但它重 7 公斤，你的背包已經 80% 滿了。」

### 4.9.3 裝備全失時的 GM 應對

這是搜打撤系統最敏感的部分。以下是經驗法則：

**預防措施**（在死亡發生前）：

- **保險教育**：在第一次出勤前，確保玩家知道保險系統的存在和運作方式
- **委託多樣化**：始終提供玩家能力範圍內的委託，不要讓「只能進工業區」成為唯一選項
- **預警文化**：建立「GM 會給線索」的信任——玩家應該知道，如果他們注意環境細節，就能發現危險
- **撤退窗口**：在極度危險的遭遇開始時，明確告知「你們意識到這可能超出你們的能力——撤退仍然是一個選項」

**當死亡發生時**：

1. **承認失去**：「馬克死了。在鏽蝕工廠的鐵路貨場，被兄弟會的狙擊手一槍命中頭部。他的裝備——那把改裝過的 M4、三級防彈衣、還有背包裡的無線電模組——全都留在那裡了。」

2. **不立即提供補償**：給失去一些沉澱的空間。不要立刻說「但你找到一個更好的槍」。

3. **提供敘事閉環**：描述隊友帶著馬克的遺物（保險箱內容）回到藏身處的場景。如果可能，讓 NPC 對死去的角色有所反應（「老柯沉默了很久。『他是個好搜刮者。』」）

4. **新角色繼承**：
   - 新角色繼承藏身處的設施和保險庫內容
   - 起始資金為原角色的 50%（保險金扣除）
   - 基礎裝備（手槍+簡易裝備）
   - 可選：新角色是原角色的聯繫人/朋友——這提供了進入的合理動機

5. **傳承機制**（可選規則）：
   - 已解鎖的藏身處設施保留
   - 與勢力的聲望繼承一半
   - 情報中心保留已發現的撤離點資訊
   - 前一角色的「遺物」（保險箱內容）可傳承

**防止玩家棄坑的關鍵**：
- 死亡不是結束，是敘事的轉折——讓新角色帶著「復仇」或「完成未竟之事」的動機入場
- 藏身處的持續存在意味著玩家的投資沒有完全歸零
- 建立「東山再起」的敘事滿足感——從零開始但這次知道自己在做什麼

### 4.9.4 節奏控制：搜刮與戰鬥的穿插

**黃金比例**（以 3 小時為例）：
- 探索/搜刮：40-50%
- NPC 互動（非戰鬥）：15-20%
- 戰鬥：20-25%
- 撤離：10-15%

**節奏信號**：

| 當玩家…… | GM 應該…… |
|---|---|
| 連續搜刮 3 個以上物資點沒有遭遇 | 插入一個環境事件或遠方威脅信號 |
| 連續 2 場戰鬥 | 提供安全區域喘息，讓玩家處理戰利品和補給 |
| 討論時間過長（超過 5 分鐘沒有行動） | 推進環境——「你們聽到走廊那頭有什麼東西靠近了」 |
| 開始感到沮喪/疲勞 | 縮短剩餘流程，加速撤離階段 |
| 明顯興奮/投入 | 多提供一個物資點或可選遭遇（不要強制） |

### 4.9.5 單次團 vs 長期戰役

| 面向 | 單次團（3-4 小時） | 長期戰役 |
|---|---|---|
| **藏身處** | 快速處理，預設設施 | 深度經營，設施升級是核心推進力 |
| **委託** | 1-2 個，線性關聯 | 3-5 個並行，勢力網絡交織 |
| **地圖** | 一張地圖，不更換 | 多張地圖，區域解鎖 |
| **裝備** | 預設起始裝備 + 場內拾取 | 長期積累，改裝，保險管理 |
| **死亡** | 角色死亡 = 玩家旁觀至結束 | 死亡 = 新角色繼承（見 4.9.3） |
| **NPC** | 單次遭遇，不追蹤 | 重複出現，建立關係/仇恨 |
| **勢力聲望** | 簡化（友好/中立/敵對） | 完整聲望系統 |
| **敘事弧** | 一個完整的「進→搜→出」 | 跨出勤的連續敘事（復仇、探索真相、勢力戰爭） |
| **每次出勤** | 整場團就是一次出勤 | 每次團等於一次出勤 |

**長期戰役專用建議**：
- **前情提要**：每次開團前用 2 分鐘回顧上次出勤的重點
- **勢力時鐘**：在幕後追蹤勢力之間的動態（兄弟會正在向舊城區擴張等），讓世界在玩家不出勤時也在變化
- **NPC 記憶**：記錄關鍵 NPC 的名字和對玩家的態度——下次見面時 NPC 記得玩家
- **藏身處發展**：每 3-5 次出勤解鎖一個設施升級
- **主線伏筆**：在數次出勤中逐漸揭露封鎖區的真相（帷幕實驗的本質、核心區的秘密）

## 4.10 樣本模組框架：「新手的第一個合約」

### 模組概述

| 項目 | 內容 |
|---|---|
| **模組名稱** | 新手的第一個合約 |
| **適合等級** | 1 級角色 × 2-4 人 |
| **預計時間** | 3-4 小時 |
| **使用地圖** | 灰燼商場（邊緣地帶） |
| **難度** | 入門 ★☆☆☆☆ |
| **核心玩法** | 搜刮 → NPC 遭遇 → 撤離決策 |
| **GM 準備時間** | 20-30 分鐘 |

### 冒險結構

```
第一幕：藏身處（15 分鐘）
  └─ 老柯的委託 → 裝備確認 → 入場

第二幕：商場探索（90-120 分鐘）
  ├─ 場景 1：北側公車站入場 → 環境感知
  ├─ 場景 2：美食廣場搜刮 → 發現新手團隊
  ├─ 場景 3：電子商店倉庫 → 可選高價值目標
  ├─ 場景 4：地下停車場 → 變異體戰鬥
  └─ 場景 5：管理辦公室 → 發現隱藏撤離點情報

第三幕：撤離（30-45 分鐘）
  ├─ 倒數計時開始
  ├─ 撤離點衝突（拾荒幫派佔用固定撤離點）
  └─ 最終選擇：強攻 / 談判 / 使用隱藏撤離點

結算（10 分鐘）
  └─ 戰利品 → 委託完成 → 經驗 → 藏身處升級提示
```

### 關鍵場景

#### 場景 0：藏身處——老柯的委託

**敘事**：
> 「你的藏身處還是一間空蕩的房間。一張床、一個工作台、一把椅子。牆上貼著從舊報紙上撕下來的封鎖區地圖。門上有人塞了一張紙條——筆跡是老柯的。上面只有一句話：『來交易站一趟。有工作。』」

**委託詳情**：
- **「基礎補給」**（簡單，常規）：帶回 3 份醫療用品（普通品質即可）——報酬 600
- **「尋人啟事」**（普通，可選）：新手團隊「綠葉」在灰燼商場失聯——找到他們的蹤跡——報酬 1,200（+ 額外 500 如果護送他們撤離）

**老柯的額外情報**：
- 「灰燼商場最近脈衝潮剛過，物資應該刷新了。」
- 「地下停車場裡面有東西。我們不確定是什麼。避開那裡。」
- 「東側停車場的撤離點是最穩定的。但我聽說屋頂的直升機坪偶爾可用——如果你能找到管理辦公室的鑰匙。」

#### 場景 1：北側公車站入場

**環境描述**：
> 「公車站的候車亭頂棚已經塌了一半。一輛報廢的公車側翻在路邊，車身上滿是彈孔和鏽跡。商場的主入口就在前方五十米——玻璃門早已碎裂，裡面一片漆黑。你唯一能聽到的聲音是風穿過破碎的窗戶發出的低鳴。」

**可選感知檢定**（難度：中等——GM可依核心規則第二章TN表設定具體目標值）：
- 成功 → 「商場一樓的走廊深處有斷續的閃爍燈光——可能是應急燈，也可能是別的什麼。」
- 大成功 → 「你注意到地下停車場入口旁邊有一串新鮮的腳印——大約四到五個人，是往裡面走的。大小不一，步伐混亂——不是兄弟會。」

#### 場景 2：美食廣場——遭遇新手團隊

**環境描述**：
> 「美食廣場的開闊空間被上方破損的天窗投下幾道昏暗的光柱。翻倒的桌椅散落一地。空氣中有腐敗食物的酸味，以及……人聲。壓低的人聲。從角落的咖啡店櫃檯後傳來。」

**遭遇**：新手團隊「綠葉」（3人）
- 狀態：一人腿部受傷（HP 50%），繃帶用完了。另兩人精神緊張。
- 裝備：基礎手槍 ×2，霰彈槍 ×1（彈藥短缺），簡易背包
- 態度：絕望中看到希望——懇求幫助

**對話觸發**（玩家靠近 10m 內）：
> 「別開槍！我們不是威脅——我們的隊友受傷了。我們被困在這裡三個小時了，撤離點被一幫拾荒者佔著……拜託，你們有繃帶嗎？」

**可能的發展**：
- 玩家提供醫療協助 → 新手團隊感激，可能分享情報（地下停車場有好東西但裡面有怪物）
- 玩家威嚇 → 新手團隊交出少量物資（2 個普通品質物品）
- 玩家無視 → 新手團隊在後續場景可能再次出現，狀態更差
- 玩家攻擊 → 輕鬆勝利但無有價值戰利品，且聲望懲罰（拾荒者同盟 -5）

#### 場景 3：電子商店倉庫（可選）

**環境描述**：
> 「店鋪前面已被掠奪一空，空殼的展示架東倒西歪。但後方的倉庫門是關著的——一把生鏽的鐵鎖掛在上面。」

**所需檢定**：技術檢定（開鎖，具體TN見核心規則第二章）或體魄檢定（強行破門）。

**物資**（開鎖成功）：
- 電子零件 ×2（稀有/藍色）
- 基礎工具組 ×1（普通/白色）
- 老舊無線電 ×1（稀有/藍色——可修復）

**風險**：
- 破門時噪音可能引來 AI 殘留體（d6：4+ 引來 2 個）
- 倉庫內有小型重力異常——物品輕微漂浮，需要技術檢定（TN見核心規則第二章）穩定抓取

#### 場景 4：地下停車場——變異體戰鬥

**環境描述**：
> 「斜坡向下，光線在前方十米處就被黑暗完全吞沒。手電筒的光束在水泥柱之間搖曳。地上有黑色的痕跡——不是油漬。你聞到一種金屬般的腥味。然後你聽到了——一種濕潤的、多足的爬行聲。從四面八方傳來。」

**遭遇**：變異犬 ×2

> ※ 以下為佔位數據，完整變異體戰鬥數據（含部位HP、攻擊擲骰、特殊能力）見第三章【戰鬥規則】。

- HP：各 15（體型中型）
- 攻擊：撕咬（近戰，傷害中）+ 可能擊倒
- 特殊：對光敏感——手電筒可以暫時致盲（便利檢定）
- 戰術：從暗處突襲，優先攻擊落單目標

**戰利品**（擊敗後）：
- 其中一隻的項圈上掛著一串鑰匙——管理辦公室鑰匙
- 附近一輛廢棄車輛的後車廂內有：軍用級急救包 ×1（稀有/藍色）

**難度調節**（給新手 GM）：
- 如果玩家看起來吃力 → 變異犬之一撤退到更深處
- 如果太簡單 → 第三隻變異犬從入口處出現（玩家退路被堵）

#### 場景 5：管理辦公室

**環境描述**：
> 「辦公室鎖著。但鑰匙在你們手中。門後是一間整齊得令人不安的房間——彷彿崩塌那天沒人到過這裡。桌上的咖啡杯仍在原處，裡面的液體早已蒸發，留下深色的痕跡。牆上的監控螢幕全部黑屏。文件櫃半開著。」

**物資**：
- 商場地圖（完整版，包含隱藏撤離點標記）
- 信號槍 ×1（3 發信號彈——用於屋頂撤離點）
- 現金 200（零散紙幣）
- GM 可選：管理者日記——記錄了崩塌當天的混亂，提供世界觀深度

**發現**：
> 「在桌上的一疊文件中，你發現了一張手寫的撤離程序——『屋頂直升機坪在緊急情況下可使用。信號槍存放在管理辦公室。密碼：商場名稱倒序。』」

### 撤離階段

**倒數計時啟動**：
> 「你的無線電發出雜音——『警告：下一次脈衝潮預計將在 30 分鐘內抵達。所有區域內的搜刮者請立即前往撤離點。』」

**衝突：拾荒幫派佔用固定撤離點**
- 東停車場撤離點被拾荒幫派（4人）佔用
- 他們正在等待載具，背包滿載
- 選項 A：談判——他們要 500 現金或 2 件稀有物品作為「共乘費」
- 選項 B：等待（但倒數計時在走，且脈衝潮逼近）
- 選項 C：使用屋頂撤離點（需要管理辦公室鑰匙 + 信號槍——如果玩家已獲得）
- 選項 D：強攻（4v4，但對手裝備雜且士氣不穩）

**屋頂撤離點**（如果玩家解鎖）：
> 「爬上了三樓，穿過破損的天花板維修梯，你們到達了屋頂。黃色的霾層在頭頂翻滾。直升機坪的標記已經褪色但仍在。你掏出了信號槍。一發紅色的信號彈衝天而起。五分鐘後，引擎聲從遠處傳來——撤離載具正在接近。從屋頂看下去，你能看到拾荒幫派還在停車場吵鬧。你在他們發現之前就安全升空了。」

### 結算

**完成委託**：
- 「基礎補給」：+600 現金
- 「尋人啟事」（如果救助/找到「綠葉」）：+1,200 現金（+ 500 護送獎勵）
- 額外帶回戰利品：依實際獲得結算

**經驗獎勵**：
- 存活撤離：+100 XP
- 完成每個委託：+50 XP
- 發現隱藏撤離點：+30 XP
- 幫助其他搜刮者：+20 XP

**藏身處提示**：
> 「回到藏身處。你有了第一筆像樣的收入。老柯派人送來了一張新的紙條：『幹得不錯。下次來找我，我們談談升級你裝備的事。還有——醫生說如果你找到軍用級抗生素，她會出好價錢。』牆上的地圖現在有了一些新的標記——灰燼商場不再是未知的領域了。」

### GM 備忘——模組調節

| 如果…… | 則…… |
|---|---|
| 玩家太順利（沒有危機感） | 在撤離階段加入第二波遭遇——另一個拾荒幫派也到了同一個撤離點 |
| 玩家太艱難（HP 低，彈藥少） | 減少撤離點衝突的敵人人數，或讓撤離載具提前到達 |
| 時間不夠（接近 4 小時但還在探索） | 跳過場景 3 和 4，直接觸發撤離倒數計時 |
| 時間有餘（2.5 小時就完成主線） | 插入一個額外遭遇——獨狼老手出現在管理辦公室附近，提供情報交換 |
| 玩家錯過了管理辦公室鑰匙 | 在停車場擊敗變異體後自動獲得，或讓新手團隊告知「我們看到一串鑰匙在狗身上」 |

## 附錄 A：世界觀敘事鉤子——即興素材庫

以下提供 GM 可以在探索中即興投放的敘事元素：

### A.1 廢墟中的故事

### A.3 可選規則：恐懼與貪婪

> **核心機制參見**：第二章【擲骰系統】——膽魄（GUT）的雙重機制（恐懼抵抗 + 貪婪抑制）由核心規則定義具體DC與擲骰流程。以下為敘事層面的應用指南，與核心機制互為補充。

**恐懼擲骰**（敘事應用）：
- 當角色遭遇極端恐怖情境（突然出現的殘留體、隊友死亡、進入深層異常區），GM可以要求進行膽魄檢定
- 具體DC參見核心規則第二章——依威脅等級設定
- 失敗 → 獲得 1 點「恐懼點」。累積 3 點恐懼點 → 所有檢定 -1，直到回到藏身處
- 大失敗 → 角色短暫失去控制（GM 決定——僵住、驚叫暴露位置、或無差別開火）

**貪婪擲骰**（敘事應用）：
- 當角色發現高價值物資但背包已滿，且明知繼續逗留危險——GM可以要求進行膽魄檢定
- 具體DC參見核心規則第二章——依物品誘惑等級設定
- 失敗 → 角色無法抵抗誘惑，必須嘗試帶走（丟棄現有物品或超重）
- 此規則是模擬「明知該走了但就是不甘心」——可由玩家自願觸發，也可由 GM 根據角色特質要求
