# 第二章：完整戰鬥規則（GM 版）

## 2.1 回合制框架

每個戰鬥回合約 6 秒：

```
階段一：宣告階段
  • GM 宣告 NPC 可見意圖
  • 玩家口頭宣告本回合意圖

階段二：執行階段
  • 依先攻順序行動（先攻 = 感知 + 精準）
  • 每角色 2 行動點（AP）
  • 可保留 1 行動點（AP） 用於反應

階段三：結算階段
  • 持續效果（流血、火焰等）
  • 士氣檢定
  • 效果持續時間 −1
```

## 2.3 傷害減免（DR）結算鏈

```
武器傷害 → 掩體 傷害減免（DR） → 護甲 傷害減免（DR） → 最終傷害（最低 1）
```

| 掩體類型 | 掩體 傷害減免（DR） | 命中效果 |
|---|---|---|
| 無掩體 | 0 | 正常 |
| 輕掩體 | 0（僅遮蔽） | 攻擊方劣勢 |
| 半掩體 | 2 | 攻擊方劣勢 |
| 全掩體 | 4 | 攻擊方雙劣勢 |

護甲 傷害減免（DR）。頭盔=頭部，防彈衣+背心=胸腹，手套=雙臂，軍靴=雙腿。傷害減免（DR） 不可疊加超過 5。

# 第四章：世界觀

## 4.1 帷幕崩塌

三年前，北聯邦「艾希拉研究設施」的代號「帷幕」高能物理實驗失控，打開不穩定維度裂隙。異常脈衝以設施為中心向外擴散，改寫了半徑20公里內的物理常數、生物結構、甚至時間流速。

這片區域被稱為**封鎖區**。QZAC（封鎖區管理局） 環區圍牆環繞著它。但圍牆擋不住人性——搜刮者們在廢墟中尋找發財或贖罪的機會。

# 第六章：出勤循環管理

## 6.1 藏身處處理（兩種模式）

**快速模式（單次團）：** 10-15分鐘。摘要式選單——「你收到三份委託……交易商有以下物品……準備好就出發。」

**深度模式（長期戰役）：** 詳細角色扮演。交易商有個性與支線故事。藏身處升級伴隨敘事事件。其他搜刮者可能來訪。

## 6.2 入場引導

入場是從安全到危險的過渡。GM 應讓玩家感受到這種轉變。

關鍵敘事元素：
- 「最後檢查」的儀式感——裝備選擇的分量
- 邊界的物理存在（圍牆、霾層、廢墟）
- 沉默和環境音——入場時不要立刻投放遭遇
- 短暫的「安全幻覺」——入場後前幾分鐘相對平靜

## 6.3 區內節奏模板（60分鐘）

| 時段 | 階段 | 緊張度 | 內容 |
|---|---|---|---|
| 0-10 min | 入場期 | 低 | 環境描寫、熟悉地形 |
| 10-25 min | 第一搜刮期 | 中 | 物資點、巡邏AI、遠方槍聲 |
| 25-35 min | 轉折點 | 高 | 高價值物資、NPC遭遇、環境變化 |
| 35-45 min | 決策期 | 最高 | 背包快滿——繼續還是撤離？ |
| 45-60 min | 撤離期 | 極高 | 倒數計時、撤離點衝突 |

## 6.4 緊張度 GM 工具

| 工具 | 方法 |
|---|---|
| 時間壓力 | 「脈衝潮將在30分鐘後到達」 |
| 聽覺線索 | 遠方槍聲、腳步回音——不定位威脅 |
| 物資誘惑 | 「透過裂縫看到藍色標記的箱子——但在大廳另一端，完全暴露」 |
| 地形壓力 | 唯一退路被堵、門在身後鎖上 |
| NPC 壓力 | 聽到無線電通訊、手電筒光柱在遠處晃動 |
| 資源儀式感 | 要求玩家實際畫掉彈藥、標記負重 |

> **最重要原則：** 永遠給玩家選擇。最好的緊張來自「我選擇繼續找，但我知道這很危險」——而非「GM 又扔了一波怪」。

# 第十章：GM 運行技巧

## 10.1 緊張氛圍營造

| 技巧 | 具體做法 |
|---|---|
| 沉默 | 讓玩家在寂靜中行動——不主動插話 |
| 聽覺線索 | 遠方槍聲、腳步回音、非人嘶吼——不定位威脅 |
| 資源儀式感 | 要求玩家實際畫掉彈藥、標記負重 |
| 不完整資訊 | 「你聽到三聲腳步——但無法判斷方向」 |
| 時間視覺化 | 放一個倒數計時器在桌上 |
| 身體描寫 | 「你的手在抖。腎上腺素的餘味。」 |

## 10.2 死亡應對

1. **承認**——給死亡一個莊重的描寫
2. **沉澱**——給其他玩家 1-2 分鐘反應
3. **閉環**——結算繼承，讓玩家看到留下的東西
4. **繼承**——創建新角色，展示繼承的藏身處
5. **傳承**——將舊角色變為世界的一部分

## 10.3 遭遇設計三要素

1. **預警**——給玩家感知威脅的機會（聲音、腳印、無線電干擾）
2. **選擇**——提供多種應對方式（避開、談判、伏擊、硬衝）
3. **後果**——每次遭遇都有物資消耗或取得

## 10.4 遭遇類型

| 類型 | 頻率 | 說明 |
|---|---|---|
| 環境告知 | 多次 | 遠方聲響、血跡、廢棄營地——製造氛圍但不強制戰鬥 |
| 可選遭遇 | 2-3次/出勤 | 玩家可選擇接近或繞開 |
| 轉角遭遇 | ≤2次/出勤 | 不可避免的遭遇，不可在滿包撤離時使用 |
| Boss遭遇 | 特殊委託 | 需前置條件，高風險高回報 |
