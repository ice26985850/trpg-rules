# 第一部分：基礎規則

## 一、系統概述

### 1-1 什麼是吞噬基因：進化編年史？

「吞噬基因：進化編年史」是一款以「進化吸收」為核心機制的桌上角色扮演遊戲（TRPG）。在這個世界中，生命體擁有吸收擊敗的敵人並獲取其特質的能力。玩家不是透過等級提升——而是透過不斷進化來變強，但每一次進化都可能使他們偏離初始形態。

### 1-2 核心特色

| 特色 | 說明 |
|---|---|
| **無職業系統** | 能力來自進化選擇，而非職業標籤 |
| **無等級系統** | 強度取決於累積的進化節點數量和質量 |
| **無固定技能樹** | 每棵進化樹都是獨一無二的 |
| **吸收成長** | 擊敗敵人後可吸收特質，解鎖全新進化方向 |
| **身份認同** | 進化有代價——人性值會逐漸流失 |

### 1-3 遊玩人數

本系統預設支援 **1 位玩家 + 1 位 GM** 的單人模式，同時完全兼容 2-5 位玩家的多人模式。

### 1-4 GM 需要準備什麼？

| 物品 | 說明 |
|---|---|
| 本規則書 | 你正在閱讀的這份文件 |
| 劇本文件 | scenarios/ 目錄中的 .md 或 .yaml 檔案 |
| 怪物/NPC 數據 | sheets/ 中的角色卡合集 |
| 一套標準 TRPG 骰子 | d4、d6、d8、d10、d12、d20 |
| 記事本 | 記錄玩家的進化樹、人性值變化、劇情線索 |

## 二、核心擲骰系統

### 2-1 基本判定

**擲骰公式：** d20 + 屬性值 ≥ 難度等級（DC） → 成功

屬性值直接作為加值使用（無需計算衍生調整值）。

### 2-2 難度等級表

| 難度 | DC 範圍 | 說明 | 範例 |
|---|---|---|---|
| **極易** | 5-9 | 幾乎不可能失敗 | 在平地奔跑、舉起輕物、記住熟悉的路 |
| **普通** | 10-14 | 一般人有一半機會成功 | 攀爬繩索、說服中立 NPC、追蹤明顯足跡 |
| **困難** | 15-19 | 需要一定專業或天賦 | 破解機關、在暴雨中追蹤、談判重大交易 |
| **極難** | 20-24 | 即使是專家也感到棘手 | 在峭壁上攀爬、破解魔法封印、說服死敵 |
| **史詩** | 25-29 | 超越常人的境界 | 單手接住飛箭、在熔岩上行走、說服國王退位 |
| **傳奇** | 30+ | 近乎神話的成就 | 徒手撕裂城牆、與神靈對話、改變自然法則 |

### 2-3 大成功與大失敗

| 擲骰結果 | 名稱 | 效果 |
|---|---|---|
| **自然 20** | 大成功 | 自動成功，且獲得額外好處 |
| **自然 1** | 大失敗 | 自動失敗，且可能伴隨負面後果 |

### 2-4 優勢與劣勢

| 狀態 | 規則 |
|---|---|
| 優勢 | 擲 2d20，取較高者 |
| 劣勢 | 擲 2d20，取較低者 |

優勢和劣勢同時存在時互相抵消（恢復為 1d20）。

### 2-5 對抗檢定

雙方各自擲 d20 + 對應屬性值，結果較高者獲勝。平手時維持現狀。

### 2-6 團隊檢定

指定一名主要執行者檢定，每個提供協助的隊友相關屬性 ≥ 4 則 +2（最多 +6）。

## 九、戰鬥規則

### 行動點（每回合 3）

| 行動 | 消耗 |
|---|---|
| 普通攻擊 | 1 |
| 進化技能 | 1-3 |
| 移動 | 1 |
| 防禦（傷害減半） | 1 |
| 觀察/辨識弱點 | 1 |
| 吸收嘗試 | 2 |
| 強制進化 | 3 |
| 使用道具 | 1 |

### 能量系統

- 能量上限 = 體質（TZ）+ 意志（YZ）
- 每回合恢復 2 能量
- 低級技能 1-2 能量、中級 3、高級 5、終極全部

### 攻擊與傷害

- 近戰攻擊：d20 + 力量（LIL） vs 防禦值
- 遠程攻擊：d20 + 敏捷（MJ） vs 防禦值
- 玩家防禦值 = 10 + 敏捷（MJ）
- 怪物防禦值 = 依所屬劇本檔次設定（見下方「檔次防禦與攻擊表」），使不同階段命中率都維持合理
- 近戰傷害：1d6 + 力量（LIL）
- 遠程傷害：1d4 + 敏捷（MJ）

#### 檔次防禦與攻擊表（怪物用，v1.1 平衡修正）

怪物不套用玩家的固定防禦公式。依其所屬劇本的「建議檔次」設定防禦與攻擊加值，確保各階段玩家命中約 60-75%、怪物對同檔次玩家命中約 45-55%。若在更高檔次的場景使用，每高 1 檔次，防禦 +2、攻擊加值 +2。

| 檔次（劇本） | 嘍囉防禦 / 攻擊加值 | 精英防禦 / 攻擊加值 | 首領防禦 / 攻擊加值 | 終極首領防禦 / 攻擊加值 |
|---|---|---|---|---|
| S1（0-5 節點） | 14-15 / +4~+5 | 16-17 / +5~+6 | 19-20 / +6~+7 | — |
| S2（3-8 節點） | 15-16 / +5~+6 | 18-19 / +6~+7 | 20-21 / +7~+8 | — |
| S3（6-12 節點） | 17-18 / +6~+7 | 21-22 / +8~+9 | 23-24 / +9~+10 | — |
| S4（10-15 節點） | 19-20 / +8~+9 | 23-24 / +10~+11 | 25-26 / +11~+12 | 28-30 / +14~+16 |
| S5（13-20 節點） | 21-22 / +9~+10 | 23-24 / +11~+12 | 25-27 / +12~+14 | 30-32 / +16~+18 |

> 怪物攻擊加值即其攻擊骰後的「+X」（如「噬咬 1d4+X」）。GM 可在此基礎上依實際玩家數值 ±2 微調（見 15-4 動態調整）。

### 空間戰鬥與範圍規則

GM 使用方格地圖定位怪物。規則與玩家規則書 9-7 完全相同：

- **距離**：近戰 1 格 / 中距 2-3 格 / 遠距 4-6 格 / 極遠 7-10 格
- **範圍模板**：錐形 N 格（面向扇形）、圓形 / 半徑 N 格（以中心點為圓心）、直線（寬 1 格長條）、爆發（半徑 1 格瞬擴）
- **機會攻擊**：敵人從你的近戰範圍主動離開時，可免費進行一次近戰攻擊（每回合 1 次）；你處於「防禦」時不會被借機攻擊
- **困難地形**：每移動 1 格消耗 2 格移動力
- **穿越格**：可穿友方格（不可停留）；穿越敵方格需敏捷（MJ）DC 14，失敗則停在原地受 1d4 傷害；巨型體型不可被穿過

## 十二、世界觀設定

### 12-1 創世神話——「最初的吞噬者」

在人類文明誕生之前的久遠時代，世界被一種名為「**虛淵蠕蟲**」的存在統治。這種生物只有一個本能：吞噬。它吞噬岩石、吞噬海水、吞噬天空——並從每次吞噬中獲得新的形態。

虛淵蠕蟲最終吞噬了自身，它的每一塊碎片都變成了一種新的生命。這些生命繼承了它的核心能力——吸收與進化。這就是為什麼這個世界上的每一個生命體都擁有進化的潛力。

但大多數生物的進化極為緩慢，需要千百年。直到人類出現——人類擁有最純淨的「虛淵碎片」，使得他們的進化速度遠超任何其他物種。換句話說，進化能力不是恩賜，而是遠古怪物的遺產。

### 12-2 世界現狀——「裂變時代」

當前世界處於被稱為「裂變時代」的動盪時期。關鍵特徵：

| 要素 | 現狀 |
|---|---|
| **文明程度** | 中世紀至文藝復興過渡期。存在少數高度發達的古代遺跡科技（進化實驗室、基因熔爐），但現代社會無法複製 |
| **人口比例** | 約 5% 的人口是「覺醒進化者」（能主動控制進化的人）。其餘 95% 是普通人，他們也有進化潛力但從未覺醒 |
| **普通人態度** | 恐懼多於崇拜。進化者被視為不穩定因素。偏遠村莊會驅逐進化者，大城市則設有「進化者聚居區」 |
| **主要矛盾** | ①進化者 vs 普通人（存在焦慮）②快速進化派 vs 控制進化派（路線之爭）③人類勢力 vs 異變獸潮（外部威脅） |

### 12-3 三大勢力

#### 陣營一：終極進化教團（The Cult of Ultimate Evolution）

| 項目 | 內容 |
|---|---|
| **理念** | 「進化是唯一的真理。終極形態就是神。」教團認為虛淵蠕蟲的碎片是通往神性的鑰匙，進化的終點是成為新的創世神 |
| **根據地** | 深淵聖殿——一座建在巨型虛淵蠕蟲化石內部的城市 |
| **行事風格** | 激進。鼓勵無限制進化，進行大量人體實驗。不在乎人性值——他們認為「人性」是進化的枷鎖 |
| **對玩家的態度** | 試圖招募。如果玩家拒絕，視為「浪費天賦的弱者」，可能成為敵人 |
| **關鍵人物** | 「千面主教」——據說已進化超過 100 次，沒有人知道他的原始形態是什麼 |

#### 陣營二：人性守護者（Guardians of Humanity）

| 項目 | 內容 |
|---|---|
| **理念** | 「進化是工具，不是目的。我們是人——不能變成怪物。」守護者認為進化應當被嚴格控制，任何人性值低於 40% 的進化者都應被隔離或「淨化」 |

## 十三、GM 檢定與 DC 完整指南

### 13-1 DC 設定框架

當玩家嘗試一個行動時，GM 需要設定 DC。以下是決策框架：

```
這個行動是...
├─ 極易 (DC 5-9)：不需要訓練，任何人都有八成以上成功率
├─ 普通 (DC 10-14)：普通人有一半機會做到
├─ 困難 (DC 15-19)：需要相關經驗或天賦
├─ 極難 (DC 20-24)：專家級挑戰
├─ 史詩 (DC 25-29)：超越人類極限
└─ 傳奇 (DC 30+)：近乎不可能
```

### 13-3 隱藏 DC 原則

GM 不需要每次都告訴玩家 DC。以下原則供參考：

- **感知類檢定**：永遠隱藏 DC。玩家不知道陷阱有多難發現——只知道自己發現了什麼（或沒發現什麼）
- **社交類檢定**：通常隱藏 DC。玩家不知道 NPC 的真實態度
- **物理類檢定**（力量/敏捷）：可以告知 DC。玩家通常可以判斷行動的難度
- **吸收檢定**：告知 DC。玩家知道吸收一個死去的敵人比吸收瀕死的更難

### 13-4 漸進式成功

並非所有檢定都是「成功/失敗」二元對立。GM 可以採用漸進式結果：

| 擲骰結果 vs DC | 效果 |
|---|---|
| 低於 DC 10+ | 災難性失敗——不僅失敗，還造成負面後果 |
| 低於 DC 5-9 | 普通失敗——未能達成目標，但沒有額外損失 |
| 低於 DC 1-4 | 接近成功——未能完全達成，但取得部分進展。GM 可以提供補救機會 |
| 等於或超過 DC | 成功 |
| 超過 DC 5+ | 優秀成功——效果超出預期 |
| 超過 DC 10+ | 完美成功——達成最大可能的結果 + 額外好處 |

### 14-2 怪物行為 AI

以下是 GM 控制怪物時的決策指導，讓怪物行為保持真實且有趣：

#### 嘍囉行為邏輯

```
嘍囉的回合開始：
├─ 附近有瀕死隊友？ → 50% 概率逃跑（意志 DC 12）
├─ 被孤立（無隊友在 3 格內）？ → 優先移動靠近隊友
├─ 能攻擊到最弱的目標？ → 攻擊該目標（嘍囉傾向攻擊看起來易於擊敗的）
├─ 被多個敵人包圍？ → 嘗試逃跑
└─ 否則 → 攻擊最近的目標
```

#### 精英行為邏輯

```
精英的回合開始：
├─ HP < 30% 且無隊友？ → 考慮逃跑（意志 DC 14）
├─ 自身有可用技能且能量充足？ → 優先使用技能
├─ 能攻擊到使用遠程/治療的角色？ → 優先攻擊後排
├─ 有隊友瀕死？ → 50% 概率保護隊友（移到隊友前方）
├─ 玩家使用防禦時？ → 轉移目標（精英能判斷誰在防禦）
└─ 否則 → 使用最有效的攻擊
```

#### 首領行為邏輯

```
首領的回合開始：
├─ HP 降至 50% 門檻？ → 觸發第二階段
│   ├─ 啟動新的被動能力
│   ├─ 獲得 1-2 個新技能
│   └─ 恢復 2d10 HP（象徵「第二形態」的強化）
├─ 能量 ≥ 5？ → 使用高級技能（BOSS 不會節省能量）
├─ 能攻擊到多個目標？ → 優先使用範圍技能
├─ 當前生命最低的玩家在射程內？ → 優先攻擊（BOSS 會針對弱者）
├─ 上回合被同一玩家造成大量傷害？ → 轉向攻擊該玩家（復仇行為）
└─ 判定玩家使用特定模式（如總是防禦後攻擊）？ → 改變策略以反制
```

### 14-3 創建自訂怪物

#### 快速創建公式

1. **決定等級**：嘍囉 / 精英 / 首領
2. **設定主題**：這個敵人的進化主題是什麼？（毒、火、冰、精神、物理…）
3. **分配屬性**：使用模板範圍內的值
4. **派生數值**：HP = TZ×5（嘍囉可降低）、防禦 = 依場景檔次查第九節檔次防禦與攻擊表（嘍囉 14-22 / 精英 16-24 / 首領 19-27 / 終極首領 28-32）、能量 = TZ+YZ
5. **設計技能**：1（嘍囉）/ 2-3（精英）/ 4-5（首領）個攻擊方式，其中至少 1 個是進化技能
6. **設計特質樣本**：如果玩家吸收這個敵人，他們可以獲得哪些進化方向？（3 個選項）

#### 平衡檢查表

| 檢查項 | 嘍囉 | 精英 | 首領 |
|---|---|---|---|
| 單一攻擊的平均傷害 | ≤ 玩家 HP 的 10% | ≤ 玩家 HP 的 20% | ≤ 玩家 HP 的 30% |
| 單回合總輸出 | ≤ 玩家 HP 的 20% | ≤ 玩家 HP 的 35% | ≤ 玩家 HP 的 50% |
| HP 總量 | 可在 2 回合內擊敗 | 可在 4 回合內擊敗 | 可在 7 回合內擊敗 |
| 特殊能力數量 | 0-1 | 2-3 | 4-6 |

## 十五、遭遇設計與難度平衡

### 15-1 遭遇組成公式

以 1 位玩家為基準，每增加 1 位玩家調整如下：

| 遭遇難度 | 1 玩家（單人） | 2-3 玩家 | 4-5 玩家 |
|---|---|---|---|
| **簡單** | 2 嘍囉 | 4 嘍囉 | 6 嘍囉 |
| **普通** | 3 嘍囉 或 1 精英 | 5 嘍囉 或 1 精英+2 嘍囉 | 7 嘍囉 或 2 精英 |
| **困難** | 1 精英+1 嘍囉 | 2 精英 | 1 精英+5 嘍囉 或 3 精英 |
| **致命** | 1 首領 | 1 首領+2 嘍囉 | 1 首領+1 精英+3 嘍囉 |

### 15-2 遭遇節奏

一個標準劇本（約 3-4 小時）建議的遭遇配置：

```
序章探索（無戰鬥或 1 場簡單遭遇）
  ↓
第一場戰鬥（普通難度，2-3 嘍囉）——玩家熱身
  ↓
探索/解謎/社交（約 30-45 分鐘）——節奏變化
  ↓
第二場戰鬥（困難難度，精英+嘍囉）——考驗
  ↓
劇情轉折/重要發現
  ↓
第三場戰鬥（致命難度，首領戰）——高潮
  ↓
結局與獎勵
```

### 15-3 單人遊戲平衡

單人模式下最重要的三條調整：

1. **減少敵人數量**：所有遭遇的敵人數量 ×0.6（向下取整，最少 1 個）
2. **提供恢復資源**：每場戰鬥前確保玩家至少有 1 瓶治療藥劑
3. **NPC 夥伴系統**：GM 可以提供一個不參與進化的 NPC 夥伴協助戰鬥。夥伴使用簡化數據——HP 20、防禦 12、近戰攻擊 1d6+2。夥伴每回合只有 2 行動點，不能使用進化技能

### 15-4 難度動態調整

遊戲中即時調整難度不需要宣告。以下技巧：

| 情況 | 調整方式 |
|---|---|
| 玩家太強（2 回合秒殺精英） | 下一波敵人 +2 HP、或在第二回合增援 1-2 個嘍囉 |
| 玩家太弱（每回合都在瀕死） | 敵人的傷害 -1d4、「恰巧」有環境物體可以當掩體 |
| 單一 BOSS 戰太簡單 | 在 50% HP 時觸發第二階段、或召喚 2 個嘍囉 |
| 單一 BOSS 戰太難 | 讓 BOSS「輕視對手」，選擇炫耀性攻擊而非致命攻擊（如使用較弱技能而非最強技能） |

### 15-5 獎勵分配指南

| 遭遇類型 | 進化點數 | 生物質 | 遺骸幣（幣） | 其他 |
|---|---|---|---|---|
| 簡單遭遇 | 1 | 1-2 | 5-10 | 小型消耗品 |
| 普通遭遇 | 2 | 2-4 | 10-30 | 標準消耗品 |
| 困難遭遇 | 3 | 4-7 | 30-60 | 稀有消耗品 |
| 致命遭遇（BOSS） | 5 | 8-15 | 50-100（含吸收結晶 +50%） | 極稀有消耗品 + 特質樣本（5 選 2） |
| 完成劇本 | 3-5 | - | 20-50 | 特殊劇情獎勵（如免費進化節點） |

> **遺骸幣經濟（v1.1 平衡修正）：** 怪物不再「無掉落」。擊敗敵人固定掉落遺骸幣（嘍囉 5-10 / 精英 15-30 / 首領 50-100，見玩家規則書 7-1），另可販賣多餘生物質（3 幣/單位）與裝備（售價 50%）換幣。一個標準劇本約可累積 80-200 幣，足以在城鎮補給 1-2 件罕見裝備或一批消耗品。吸收敵人屍體無法販賣，但提煉的「進化結晶」可兌換額外 50% 遺骸幣。

## 十六、劇本運行指引

### 16-1 五個劇本概覽

#### S1：巢穴覺醒（建議節點 0-5）

| 項目 | 內容 |
|---|---|
| **開場** | 玩家在地底巢穴中醒來，周圍是死去同類的屍體。記憶一片空白。唯一的本能：向上爬 |
| **場景結構** | ①覺醒（醒來、感受進化衝動、選擇根節點）→ ②第一餐（遭遇變異鼠，第一次吸收或擊殺的選擇）→ ③黑暗中的聲音（遇到另一個倖存的進化體——NPC 夥伴或對手）→ ④出口（擊敗守門精英，逃出巢穴）→ ⑤地面（第一次看到外面的世界，加入或遭遇某個勢力） |
| **核心衝突** | 生存本能 vs 身份疑問（我是誰？） |
| **關鍵 NPC** | 另一個倖存進化體（可成為夥伴或對手）、地面上的勢力代表 |
| **可能結局** | ①獨自逃出後踏上尋找記憶之旅；②與另一個進化體結盟；③擊敗守門者後吸收它——付出人性值代價換取力量 |

#### S2：實驗室逃亡（建議節點 3-8）

| 項目 | 內容 |
|---|---|
| **開場** | 玩家發現自己是實驗體。實驗室是一個巨大的地下基因研究設施，由前文明的殘餘 AI 管理。AI 的目標：收集所有進化路線的數據 |
| **場景結構** | ①牢籠（發現牢籠和實驗記錄，了解自己的起源）→ ②回收區（其他實驗體——有的想合作逃出、有的已經失控變成怪物）→ ③核心實驗室（面對 AI，選擇是破壞它還是利用它的知識）→ ④突破（與精英守衛戰鬥，逃出實驗室） |
| **核心衝突** | 自由 vs 知識（AI 可以提供進化路線的完整資訊——但代價是永遠留在實驗室） |
| **關鍵 NPC** | AI「守護者」（非敵非友，純粹理性）、變異實驗體（可能成為盟友或敵人） |
| **可能結局** | ①破壞 AI 逃出（獲得大量進化點數但失去知識）；②與 AI 交易後離開（獲得進化圖鑑資訊但幫助 AI 進行最後一次實驗）；③吸收 AI 的核心——獲得「機械融合」特殊進化方向 |

#### S3：進化戰爭（建議節點 6-12）

| 項目 | 內容 |
|---|---|
| **開場** | 終極進化教團和人性守護者在基因熔爐遺跡前展開對峙。雙方都想控制這個能加速進化的古代設施。玩家必須選擇陣營——或成為攪局者 |
| **場景結構** | ①陣營接觸（雙方代表接觸玩家，各給出誘人的條件）→ ②前置任務（所選陣營的考驗任務）→ ③熔爐爭奪戰（三方混戰——玩家陣營、敵對陣營、以及熔爐的自動防禦系統）→ ④熔爐核心（控制熔爐——獲得強大的進化機會） |
| **核心衝突** | 選擇與後果——每個陣營的路線都合理但都有代價 |
| **關鍵 NPC** | 教團使者（提供力量但要求降低人性值）、守護者指揮官（提供裝備和資源但限制進化）、協議觀察員（提供第三條路但不介入戰鬥） |
| **可能結局** | ①幫助教團控制熔爐（獲得 5 進化點數 + 免費形態節點但人性值 -10）；②幫助守護者控制熔爐（獲得稀有裝備 + 人性值 +5）；③關閉熔爐讓雙方都得不到（獲得協議好感 + 特殊被動節點「平衡之心」） |

#### S4：食物鏈頂端（建議節點 10-15）

| 項目 | 內容 |
|---|---|
| **開場** | 玩家踏入「競技場」——一片被遠古力量封鎖的大陸。規則只有一條：只有最強的進化者才能活著離開。所有被困在競技場中的進化者都在互相獵殺、互相吸收 |
| **場景結構** | ①入場（進入競技場，發現規則——無法離開直到成為「頂端」）→ ②獵人與獵物（遭遇其他進化者——你可能成為獵人，也可能成為獵物）→ ③結盟與背叛（臨時聯盟在競技場中很常見——但背叛更常見）→ ④半決賽（擊敗競技場的區域霸主）→ ⑤決賽（只剩下你和另一個最強進化者——最後的對決） |
| **核心衝突** | 競爭 vs 同理心（不是所有競技場中的進化者都是惡人——有些人跟你一樣是被困在這裡的） |
| **關鍵 NPC** | 「冠軍」——上屆競技場的勝者，已進化超過 20 個節點。他自願留在競技場中等待值得一戰的對手 |
| **可能結局** | ①擊敗冠軍後離開（獲得最多進化點數）；②與冠軍聯手打破競技場的封印（需共同進行意志檢定 DC 22，成功後解放全場所有進化者）；③吸收冠軍——獲得終極形態節點但人性值降至 10% 以下 |

| **場景結構** | ①裂谷下降（沿途遭遇裂谷最深處的異變生物——最危險的進化體）→ ②碎片殿堂（虛淵蠕蟲的意識碎片以回聲形式存在於此。與碎片的對話揭示一切真相）→ ③最終選擇（三個選項：吸收碎片的全部力量成為新的虛淵蠕蟲？摧毀碎片終結進化詛咒？還是將碎片與自己融合但用人性控制它？） |
| **核心衝突** | 終極進化 vs 自我犧牲 |
| **關鍵 NPC** | 虛淵殘響（不是敵人——是遠古蠕蟲的記憶回聲，可能以已故親人或導師的形象出現） |
| **可能結局** | ①吸收碎片——成為新的「吞噬者」（力量達到頂峰、無限進化容量，但人性值歸零，角色變為 NPC/反派）；②摧毀碎片——世界上所有生物的進化能力消失（包括你），但裂谷停止擴張；③融合與控制——成功將碎片的力量融入自身同時保持人性（需意志 YZ 檢定 DC 30，成功後獲得「究極形態」——可以自由切換所有已解鎖的形態且人性值不再下降） |

詳細劇本內容見 `scenarios/` 目錄。

### 16-2 進化節奏控制

GM 需要控制玩家的進化速度。太快→遊戲失去挑戰性；太慢→玩家無法享受進化的樂趣。

**建議節奏：**

| 遊戲階段 | 每次遭遇後的進化 | 每個劇本的總成長 |
|---|---|---|
| 序章（前 3 場遭遇） | 每場 1-2 進化點數 | 累積 3-5 點，解鎖 2-3 個新節點 |
| 中段 | 困難遭遇 2-3 點、BOSS 3-5 點 | 解鎖 4-6 個節點 |
| 終章 | BOSS 戰 5+ 點、劇情獎勵 5+ | 解鎖 5-8 個節點 |

**防止過強的策略：**
- 不要讓玩家在同一劇本中解鎖超過 8 個新節點
- 器官節點和形態節點應有「冷卻期」——解鎖一個形態節點後，至少 2 場遭遇後才能解鎖下一個
- 細胞容量是內置的軟上限——當玩家進化節點數接近容量時，他們會自然放緩速度

**防止過弱的策略：**
- 如果玩家連續 3 場遭遇都沒有成功吸收，讓下一場遭遇的敵人提供更容易吸收的條件（自願或已被麻痺）
- 環境適應獎勵可以在戰鬥困難時作為「保底」提供

### 16-3 NPC 扮演要點

以人性值為核心的 NPC 反應系統：

| NPC 類型 | 對高人性值（>40%）的反應 | 對低人性值（<40%）的反應 |
|---|---|---|
| 普通村民 | 好奇、謹慎、可交易 | 恐懼、逃跑、可能召喚守衛 |
| 商人 | 正常交易 | 拒絕交易或價格 ×3 |
| 守護者士兵 | 登記後放行 | 立即攻擊或驅逐 |
| 教團成員 | 試圖招募（「你還不夠強」） | 尊重（「你已經走在正確的路上了」） |
| 協議學者 | 友善、提供幫助 | 提供人性值恢復服務（收費） |
| 異變獸 | 正常敵意 | 可能將你視為同類（50% 概率不主動攻擊） |

### 16-4 即興創作工具

當玩家做出出乎意料的行動時：

1. **確定意圖**：「你想達成什麼？」
2. **判斷可行性**：是否可能？（是 → 設定 DC；否 → 解釋原因 + 提供替代方案）
3. **設定後果**：成功會發生什麼？失敗會發生什麼？
4. **擲骰**：讓玩家擲骰
5. **敘述結果**：描述發生的事情——記住，你不是在宣布數字，而是在講故事

|---|---|---|---|
| **沙漠/高溫** | 每小時體質（TZ）DC 12，失敗則受到 1d4 高溫傷害 | 存活 3 回合（約 3 小時） | ①耐高溫 ②水分儲存（被動：飲水需求減半）③熱感視覺 |
| **極寒/凍原** | 每小時體質（TZ）DC 12，失敗則移動速度 -2 格 | 存活 3 回合 | ①耐低溫 ②冬眠（被動：可進入休眠狀態降低消耗）③冰霜皮膚（被動：冰霜傷害 -1） |
| **深海/高壓** | 每回合體質（TZ）DC 14，失敗則受到 1d6 壓力傷害 | 存活 3 回合 | ①水棲適應 ②深潛器官（器官：深海視覺+壓力抗性）③生物發光（被動） |
| **火山/極熱** | 每回合受到 1d6 火焰傷害（無豁免） | 存活 3 回合 | ①火焰免疫 ②熔岩形態（形態節點提示）③火焰吐息 |
| **劇毒沼澤** | 每回合體質（TZ）DC 14，失敗則中毒 | 存活 3 回合且未中毒（或成功抵抗 3 次） | ①毒免疫 ②酸液腺（器官）③沼澤偽裝（被動） |
| **高輻射區** | 每回合人性值 -1（無法抵抗） | 存活 5 回合 | ①輻射吸收（被動：可將輻射轉化為能量，每回合 +1 能量）②基因穩定化（被動：人性值減少 -1）③輻射吐息（高級主動） |
| **虛空/邊境** | 每回合意志（YZ）DC 15，失敗則人性值 -1d4 | 存活 5 回合且意志檢定成功 3 次以上 | ①虛空適應（形態節點提示）②維度感知（被動：可感知附近空間異常）③虛空之刃 |

### 17-2 進化衝突與撤銷

**主動捨棄節點：**
玩家可以選擇永久捨棄一個已解鎖的進化節點。效果：
- 該節點效果消失
- 進化點數不退還
- 生物質不退還
- 人性值恢復 +3
- 釋出 1 進化容量

**形態切換：**
部分玩家可能解鎖多個形態節點。規則：同一時間只能激活一個形態節點（昆蟲除外——可同時激活兩個器官節點但形態仍只能一個）。切換形態需要 1 回合的「變身」過程——期間不能行動。

### 17-3 多人協同進化

在多人遊戲中，進化者之間可以產生獨特的互動：

| 互動 | 規則 |
|---|---|
| **共同吸收** | 兩個玩家可以同時吸收一個大型敵人（如 BOSS），各自獲得一個特質樣本（每個人的選項可能不同） |
| **進化共鳴** | 擁有共同吸收經歷的玩家，在戰鬥中距離 3 格內時，各自的能量恢復 +1/回合 |
| **人類羈絆** | 如果一個玩家的人性值降至 20% 以下，隊友可以通過消耗 1 行動點進行「人性呼喚」（意志 YZ 檢定 DC 15），成功則該玩家暫時恢復 1d4 人性值（僅持續至戰鬥結束） |

### 17-4 進化失控

當玩家累積太多節點或一次性進行過於劇烈的進化時，可能發生進化失控：

**觸發條件：** 單次獲得超過 8 進化點數並全部用於進化，或在人性值低於 20% 時再解鎖一個形態節點。

**失控效果（擲 1d6）：**

| d6 | 失控表現 |
|---|---|
| 1 | 肉體暴走——隨機觸發一個已解鎖的主動節點（由 GM 選擇最糟糕的時機） |
| 2 | 形態隨機切換——如果你有多個形態節點，隨機激活一個（可能不適合當前環境） |
| 3 | 能量過載——失去所有剩餘能量並受到等同於失去量的傷害 |
| 4 | 意識碎片化——1d4 回合內無法控制角色行動（GM 描述你的進化本能接管了你的身體） |
| 5 | 反向進化——隨機失去一個進化節點（GM 秘密選擇，不退還點數） |
| 6 | 良性失控——幸運地，這次失控沒有負面效果（但不代表下次也這麼幸運） |

## 十八、進化節點完整圖鑑

本節收錄所有進化節點的完整數據，作為 GM 參考。（完整節點列表同玩家規則書第六節，此處不重複。）

GM 可使用 `catalogs/進化節點圖鑑.md` 作為快速查閱工具。

### 18-1 GM 自訂節點指南

創建新進化節點時，遵循以下平衡原則：

| 節點類型 | 效果強度參考 | 進化點數成本 |
|---|---|---|
| 屬性節點 | 總屬性增加 1-3 點 | 每 +1 屬性 ≈ 1.5 進化點數 |
| 被動節點 | 數值效果約等於 +1 至 +3 屬性等效 | 等效屬性值 ×1.5 |
| 低級主動 | 等效傷害約 1d8+屬性、或等效控制 1 回合 | 2 |
| 中級主動 | 等效傷害約 2d8+屬性、或範圍效果 | 3-4 |
| 高級主動 | 等效傷害約 3d10+屬性、或強力控制 | 5 |
| 終極主動 | 戰鬥決定性效果 | 5 + 特殊條件 |

> 終極主動節點（形態變身、領域展開、終極進化、自爆重生、基因崩潰、萬象吞噬）的完整數據與解鎖條件，見 `catalogs/進化節點圖鑑.md` 的「終極主動節點」章節。玩家需累積相當的進化深度（通常 15+ 節點）才能解鎖。
| 器官節點 | 提供 2-3 個獨立效果 | 3-5 + 生物質 |
| 形態節點 | 屬性變化 4-7 點 + 多個新能力 + 重大副作用 | 5 + 大量生物質 |

## 十九、可選規則與變體

### 19-1 快速進化模式

適合短版遊戲（1-2 個劇本）。變更：
- 所有進化成本 -1（最低 1）
- 每場遭遇的進化點數獎勵 +1
- 進化容量上限 +3（因為遊戲時長不足以提升體質和意志）
- 人性值減少減半（因為遊戲中不會有足夠的時間處理人性值恢復）

### 19-2 永久死亡模式

適合高風險硬核體驗。變更：
- 瀕死時不進行體質檢定——HP 降至 -（體質 ×5）即永久死亡
- 但是——如果在瀕死時成功吸收附近的敵人，可以「竊取」其生命精華恢復 1d10 HP
- 每劇本可使用此緊急吸收 1 次

### 19-3 合作進化模式

適合多人團隊遊戲。變更：
- 玩家可以捐贈進化點數給隊友（每劇本每人最多捐贈 2 點）
- 捐贈雙方獲得「進化羈絆」——之後雙方在 5 格內時，能量恢復各 +1
- 代價：捐贈者永久失去 1 人性值（因為你的進化能量離開了你的身體）

### 19-4 隨機進化模式

適合混亂有趣的體驗。變更：
- 吸收敵人後不提供選擇——改為隨機獲得該敵人的一個進化方向
- 玩家獲得「拒絕進化」能力——如果隨機到的方向是禁忌進化，可以消耗 1 進化點數重新隨機
- 此模式下人類的「適應力」天賦改為：可以重擲 1 次隨機結果

### 19-5 無人性值模式

適合只想要純粹進化戰鬥的玩家群體。變更：
- 人性值系統完全移除——進化不再有任何社交或身份代價
- 所有與人性值相關的天賦和裝備調整：人類天賦改為「進化容量 +2」；幼龍的成本懲罰取消
- 此模式適合單次戰鬥向遊戲，不適合長期戰役
