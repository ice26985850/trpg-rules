## 3.7 Anomaly Combat Rules

### Cognitohazards

Triggered through Perception; attacks SAN rather than HP.

| Intensity | CH Save | SAN Damage |
|----------|---------|------------|
| Light | d100 ≤ SAN | 1d4 |
| Moderate | d100 ≤ SAN -10 | 2d6 |
| Severe | d100 ≤ SAN -20 | 3d8 |
| Extreme | d100 ≤ SAN -30 | 4d10 |

**Cognitive Filter**: SCRAMBLE goggles, etc. can reduce intensity by one tier.

### Reality Bending

| Level | Hume Deviation | Range | Countermeasure |
|-------|---------------|-------|----------------|
| Low | ±10–30 Hm | 5m | Reality Stabilizer |
| Moderate | ±31–60 Hm | 20m | Scranton Anchor (halved) |
| High | ±61–90 Hm | 100m | Multiple Anchors Stacked |
| Extreme | ±91+ Hm | No Upper Limit | Retreat + Maximum Stabilization |

All Physical checks within the area suffer DIS. Attacking the bending source requires first passing `d100 ≤ WIL (TN = 50 + Hume/5)`.

### Memetic Hazards

| Level | Transmission | Removal Method |
|-------|--------------|----------------|
| Class A | Direct contact with information carrier | Class B Amnestics |
| Class B | Indirect knowledge of summary | Class A Amnestics + SAN -1d6 |
| Class C | Knowing of its "existence" causes infection | Complete information blackout + SAN -3d6 |
| Class D | Information possesses self-awareness | Only O5-authorized contact permitted |

**Metacognitive Trap**: A player knowing the memetic content ≠ character immunity — this is the core horror of SCP.

## 3.8 Unbeatable SCP: Containment Framework

Some SCPs cannot be defeated. Use the four-phase encounter flow:

```
Phase 1: Identify → Research/Perception check to determine traits and weaknesses
Phase 2: Respond → Establish containment perimeter, evacuate, activate protocol
Phase 3: Execute → Accumulate Containment Success Points (typically 3–8)
Phase 4: Cost → "Minimum Cost" decision — who sacrifices?
```

### Containment Progress System

- Each effective Containment action rolls `d100 ≤ relevant skill` → Success = 1 point, Exceptional = 2 points
- The SCP's threat advances in parallel — if it reaches the critical threshold first → Containment Failure
- D-Class expenditure: Sacrifice = automatic 1 point; failure retry = D-Class probe first

## 3.10 Encounter Design Guide

### Difficulty Budget

| Difficulty | Squad Expenditure | Typical Scenario |
|-----------|-------------------|------------------|
| Routine | 10–20% | Daily patrol |
| Challenging | 30–50% | Safe-Class Containment Breach |
| Hard | 50–70% | Euclid-Class Breach |
| Extreme | 70–90% | Keter-Class, Site infiltration |
| Apocalyptic | 90–100%+permanent cost | XK-Class Scenario |

### Four Core Design Principles

1. **Every encounter has a non-combat exit**: Retreat ≠ Game Over
2. **Asymmetric information design**: Players start at an informational disadvantage
3. **Cost choice over number-crunching**: Let players choose between two costs
4. **SAN & HP dual depletion**: HP is recoverable, SAN recovers slowly — long-term accumulation is the real threat

# Chapter 4: World & Narrative

## 4.1 Foundation Worldview

### Core Setting

This is a "our world, but with one extra layer of shadow" setting. The story timeline defaults to anchoring in the near future (2025–2035); the Foundation, GOC, and various anomalous organizations operate beyond public view, maintaining the "Veil of Normalcy."

**Core Paradox**: The Foundation protects humanity from anomalous threats, yet the Foundation itself is human — which means it too makes mistakes, corrupts, and fractures. The player characters stand at the center of this paradox.

### Organizational Structure

```
O5 Council (13 members, highest decision-making body)
  ├── Ethics Committee (independent oversight)
  ├── Department of Science → Anomalous research, experiment design
  ├── Department of Security → Site security, MTF deployment
  ├── Department of Containment → SCP storage & maintenance
  ├── Department of Field Operations → Intelligence, recovery, cover-up
  ├── Department of Information Security → Document classification, Amnestics
  └── Department of Logistics → Supply, personnel, D-Class management
```

### Site Network

| Site Type | Function | Example |
|-----------|----------|---------|
| Site | Surface/semi-underground facility | Site-19 (largest Site globally) |
| Area | Fully underground/isolated | Area-14 (centralized Keter containment) |
| Outpost | Remote-area monitoring | Multiple |
| Mobile Site | Mobile/temporary | MTF-exclusive |

### Historical Timeline (Six Phases)

1. **Prehistoric Period** (?–1800): Anomalies viewed as miracles or magic
2. **Industrial Period** (1800–1900): Early industrialization containment attempts
3. **Foundation Founding** (1900–1945): Began from a 13-person secret council
4. **Cold War Period** (1945–1991): Ideological confrontation with the GOC
5. **Global Networking** (1991–2020): SCiPNet established
6. **Near Future** (2020–2035): AI-assisted Containment, ethics crisis intensifies

## 4.3 GM Running Guide

### Iceberg Principle

Players should only know the tip of the iceberg. Use the **Truth Card system**:

- **Surface Truth** (known to players at start): Mission briefing content
- **Inner Truth** (discoverable after investigation): SCP's true nature, Foundation's hidden data
- **Abyssal Truth** (possibly never known): O5's secrets, the Foundation's true origin

### Document-Driven Narrative

Advance using the "Briefing → Scene → Report" structure.

### First Session Guide

**5-Step Startup for New GMs**:

1. **Read the Player's Handbook** (Chapters 1–2): Understand core checks, attributes & skills, character creation
2. **Have players create characters**: Refer to §2.1 nine-step process. For the first session, it is recommended to use a standard array or pregenerated characters (see SCP_Pregen_Characters.xlsx) to save time
3. **Choose a starting module**:
   - Prefer combat → Series A Scenario A-1 "Iron Maiden Raid" (~2 hours)
   - Prefer investigation → Series B Scenario B-1 "Forgotten Archive" (~1.5 hours)
4. **Session control key points**:
   - Prepare 2 checks per scene (e.g.: Observation + Anomalistics)
   - Do not require a check for every action — only check actions with risk and pressure
   - The SAN/SP system is an atmosphere tool: no need to calculate every round; trigger it only at tense moments
5. **Pacing**: Keep the first session within 2–3 hours, ending with a complete "Briefing → Encounter → Containment" mini-loop

**Recommended First-Session Configuration**:

- 3–4 players, Lv.1
- 1 Safe-Class SCP
- 1–2 combat or stealth encounters
- 1 SAN Check
- Ending: Write a mission report (first successful Containment of each difficulty +200 XP bonus)

:

1. **Briefing Phase**: The GM distributes the mission document (redacted SCP file)
2. **Scene Phase**: Players discover omissions, errors, and deliberate concealment in the document
3. **Report Phase**: Players write the mission report; the GM compares the "official version" with the "actual experience"

### Five-Act Structure

```
Act I: Investigation → Gather clues, build suspense
Act II: Discovery → Truth revealed, anomaly manifests
Act III: Crisis → Situation spirals out of control, containment pressure
Act IV: Choice → Dilemma, cost negotiation
Act V: Containment/Sacrifice → Cost paid, survivors accounted for
```

### Creeping Dread (Three-Phase Stepped Progression)

- **Phase One: Normal** (2–3 sessions) — Daily tasks, build a sense of security
- **Phase Two: Anomaly** (3–4 sessions) — Anomalies appear but are controllable
- **Phase Three: Abyss** (finale) — Uncontrollable terror, permanent cost

### Three-Layer Atmosphere Building Method

| Layer | Technique | Example |
|-------|-----------|---------|
| Physical Layer | Environmental description | "The corridor lights flicker once per second; each time they go out, you can hear something crawling in the vents" |
| Linguistic Layer | Document register | Describe the most terrifying things using clinical terminology |
| Emotional Layer | Moral pressure | Let players make the sacrifice decision themselves |

## 4.4 Organization Management Subsystem

### Site Status Panel

| Metric | Range | Description |
|--------|-------|-------------|
| Security | 0–100 | Site containment stability |
| Personnel | 0–100 | Deployable manpower |
| Resources | 0–100 | Supplies & budget |
| Morale | 0–100 | Personnel psychological state |
| Research Progress | 0–100 | Completion of current major project |

### Resource Allocation

| Action | Cost | Effect | Risk |
|--------|------|-------|------|
| Request D-Class quota | Resources -5 | Personnel +10 | O5 Attention +1 |
| Emergency supply allocation | Resources -10 | Security +10 (temporary) | Morale -5 |
| Overtime crunch | Morale -10 | Research Progress +15 | Personnel -5 (fatigue accidents) |
| Department coordination meeting | None | Morale +5 | Political capital -2 |

### O5 Attention (Hidden Tracking)

| Attention | Effect |
|-----------|-------|
| 0–3 | Normal operation |
| 4–5 | Additional reporting, increased scrutiny |
| 6–7 | Observer dispatched, autonomy restricted |
| 8–9 | Direct O5 intervention, possible reorganization |
| 10 | Site placed under "Special Observation" — equivalent to trusteeship |

### Departmental Politics

The seven departments each have a relationship value (-10 to +10), affecting equipment acquisition, mission assignment, and ethics review outcomes. Department conflict events are triggered by the GM from the Event Table.

## 4.5 Moral Dilemma Narrative Framework

### Seven SCP Signature Dilemmas

| Dilemma Type | Core Question | Example |
|--------------|---------------|---------|
| Sacrifice the few | Use D-Class to secure civilian safety? | D-Class expenditure in containment operations |
| Knowledge is risk | Telling teammates the truth equals harming them? | Information isolation for memetic hazards |
| Containment is imprisonment | Should a sentient SCP be imprisoned indefinitely? | Humanoid SCP |
| Anomaly exploitation | Use SCP-500 to save civilians or researchers? | Resource allocation |
| Amnestics | Erase traumatic memories or preserve growth? | SAN recovery choice |
| Veil of Normalcy | Is lying to civilians the real protection? | Cover-up operations |
| We are the monsters | When do the Foundation's methods become scarier than the anomaly? | Revealed over long campaigns |

### Cost Tracking (Dual-Axis System)

| Axis | Range | Reduction Trigger | Consequence at Zero |
|------|-------|-------------------|---------------------|
| **Humanity** | 0–10 | Sacrificing others, apathetic decisions | Character loses empathy, unable to make social checks |
| **Morality** | 0–10 | Abusing power, violating ethics | Ethics Committee hearing, possible forced Amnestics |

After each moral dilemma decision, the GM secretly adjusts the two axes. Dropping below 4 → corresponding consequence takes effect.

## 4.6 Module Framework

### Standard Mission Types

| Type | Code | Core Mechanic | Typical Duration |
|------|------|---------------|------------------|
| Containment Breach Response | BREACH | Containment Progress System | 1–2 sessions |
| New Anomaly Investigation | ANOMALY | Investigation check chain | 2–3 sessions |
| Site Crisis | SITE | Organization Management + Combat | 3–4 sessions |
| Field Recovery | RECOVERY | Infiltration + Negotiation | 2–3 sessions |
| Internal Incident | INTERNAL | Political gameplay + Moral dilemma | 1–2 sessions |

### Module Structure Template

```
1. Briefing (1 page) — Mission objectives, known intel, resource distribution
2. GM Truth Cards (1 page) — 5 progressively revealed hidden pieces of information
3. Scene List (half page per scene) — Location, NPC, checks, possible outcomes
4. Ending Branches (half page) — 3–5 ending conditions
5. Sequel Seeds (half page) — The story does not stop after the module ends
```

### Example Module Outline: "Mirror Cicada" (3 sessions)

*Synopsis: A mirror at a research Site begins to show reflections that do not belong to this reality. The players must investigate the anomaly's source while dealing with the factional struggle inside the Site — some want to exploit the mirror, some want to destroy it, and the thing inside the mirror is approaching.*

Five acts, 16 scenes | 5 key NPCs | 5 ending branches

## Appendix B: Quick Reference

### TN Calculation Quick Reference

```
Standard check: d100 ≤ (Attribute + Skill + Difficulty Modifier)
Attack check: d100 ≤ (AGI + Weapon Skill - Cover Modifier)
SAN check: d100 ≤ (SAN - CH Modifier)
Overclearance operation: d100 ≤ (Attribute + Skill - Overclearance Modifier)
Near-death save: d100 ≤ END (naked roll)
```

### Difficulty Modifier Quick Reference

| +60 Trivial | +30 Easy | +10 Slightly Easy | ±0 Standard |
| -20 Challenging | -40 Hard | -60 Very Hard | -80 Legendary |

### Cognitohazard Quick Reference

| Light: d100 ≤ SAN, 1d4 SAN | Moderate: d100 ≤ SAN-10, 2d6 |
| Severe: d100 ≤ SAN-20, 3d8 | Extreme: d100 ≤ SAN-30, 4d10 |

### Combat Quick Reference

| Action quota: 1 Standard + 1 Move + 1 Quick + 1 Reaction |
| Cover: Partial TN-10 / Half TN-20 / Full cannot be targeted |
| Armor DR: Light 1-2 / Medium 3-4 / Heavy 5-6 |
| Called shot: Head TN-20 / Limbs TN-10 |
