# SCP Compendium (Anomalous Entity Database)

> This file is excerpted from §3.9 of the SCP: CONTAINMENT PROTOCOL Game Master Guide, serving as a standalone compendium for quick reference by the GM and players.
> The "monsters/enemies" in the game are various SCP anomalous entities; their complete character sheets can be found separately in `sheets/敵人角色卡合集.xlsx`.

## SCP Data Template

When creating an SCP, fill in the data card according to the following fields:

```
┌────────────────────────────────────────────────────────┐
│ SCP Data Card                                            │
├────────────────────────────────────────────────────────┤
│ Item Number: SCP-XXXX    │ Class: [Safe/Euclid/Keter]    │
├────────────────────────────────────────────────────────┤
│ Combat Parameters                                        │
│ HP/Endurance: [value]    Evasion: [AGI]    Speed: [m]    │
│ Physical Resistance: [Piercing/Slashing/Bludgeoning] DR  │
│ Elemental Resistance: [Thermal/Chemical/Radiation] DR    │
│ Anomalous Resistance: [Immune/Resistance/None/Weak]      │
│ SAN Damage Aura: [intensity]                             │
├────────────────────────────────────────────────────────┤
│ Attributes: STR/END/AGI/PER/INT/WIL/PRE                 │
├────────────────────────────────────────────────────────┤
│ Special Abilities ×N                                     │
│ · Name · Trigger · Action · Frequency · Range · Effect   │
├────────────────────────────────────────────────────────┤
│ Containment Protocol + Tactical Notes (GM Only)          │
└────────────────────────────────────────────────────────┘
```

## Preset SCP Examples (Summary)

- **SCP-███-A "Clockwork Soldier"** (Safe, combat-engagable): Mechanical construct, Piercing DR 5, Thermal weakness, with the winding keyhole on its back as its Fatal Weakness
- **SCP-████ "Mirror Dweller"** (Euclid, requires outwitting): Exists only in reflective surfaces, immune to physical damage, must be covered with a mirror surface and guided into a lightless containment pod
- **SCP-████ "Song of the Void"** (Keter, survival-only): Non-physical entity, deals SAN Damage each round within auditory radius, temporarily suppressed with 4 Containment Success Points
