# 後室管理局 TRPG —— GM 規則書

> **版本：** v1.0
> **給 GM 的話：** 你手中的不僅是一本規則書——你是上級、情報官、命運本身。你的任務不是打敗玩家，而是讓每一個決策都有重量，讓每一個傷亡都有名字。

## 第一章：核心規則系統（完整版）

### 1.1 骰子系統：d100 調整值對抗難度等級

**核心公式**：
```
最終檢定值 = d100 + 調整值總和
成功條件：最終檢定值 ≥ 難度等級（DC）
```

**調整值組成**：
| 來源 | 計算 | 範圍 |
|------|------|:---:|
| 團隊經驗加值 | Σ 每位探險員經驗值 | +5 ～ +125（5 × 25） |
| 裝備加值 | 裝備（EQP）× 2 | +4 ～ +24（初始 EQP2～12）/ +30（上限 EQP15） |
| 方針加值 | 謹慎 −5 / 標準 ±0 / 激進 +5 | −5 ～ +5 |
| 專長匹配加值 | 每位匹配專長 +5（主）/+3（次） | +5 ～ +25 |

### 1.2 難度等級（DC）完整階梯

| 難度 | DC | 敘事描述 | 典型任務 |
|------|:--:|----------|----------|
| **極易** | 40 | 幾乎沒有風險。例行公事 | 熟悉安全樓層的巡邏、已開通路線的物資運送 |
| **簡單** | 55 | 輕微風險。不該出錯的任務 | 輕度威脅偵察、低價值資源回收 |
| **中等** | 70 | 合理挑戰。準備充足即可應對 | 標準偵察、外交接觸、常規搜救 |
| **困難** | 85 | 顯著威脅。需要經驗和裝備 | 危險樓層資源回收、已知實體區域探索 |
| **極難** | 100 | 極度危險。菁英團隊才有把握 | 未知深層探索、實體狩獵、高價值回收 |
| **自殺級** | 115 | 送死任務。傳奇探險員才可能生還 | Boss 級實體、樓層崩潰撤離、深層首探 |

### 1.3 GM 如何使用 DC（對玩家隱藏的資訊）

**步驟 1**：根據任務的真實難度，設定**真實 DC**。

**步驟 2**：根據玩家購買的情報等級，擲**偏差骰（d100）**——此骰對玩家隱藏：

| 情報等級 | 偏差骰結果對應的 DC 偏移 |
|----------|------------------------|
| 無情報 | 01–20：−40% / 21–50：−20% / 51–80：+20% / 81–100：+40% |
| 基礎情報 | 01–33：−25% / 34–66：0% / 67–100：+25% |
| 詳細情報 | 01–50：−15% / 51–100：+15% |
| 精確情報 | 01–50：−5% / 51–100：+5% |
| 完美情報 | 無偏差 |

**步驟 3**：告知玩家**預估 DC 範圍**（即原始 DC ± 情報等級對應的偏差範圍），但不告知實際偏移。

```
範例：真實 DC = 70（中等難度）
玩家購買詳細情報（偏差 ±15%）→ GM 告知：「根據情報分析，此任務難度約在 60–81 之間」
GM 實際擲偏差骰：85 → 偏移 +15% → 實際 DC = 70 × 1.15 = 81（偏難的那端）
玩家最終檢定擲出 85 → 85 ≥ 81 → 成功！
玩家不知道的是：他們以「剛好及格」完成了這個任務。
```

**步驟 4**：玩家擲任務檢定骰後，以**實際 DC** 判定結果。

### 1.4 結果判定規則

**優先級檢查順序**：

| 優先級 | 條件 | 結果 |
|:----:|------|------|
| 1 | d100 自然值 01–05 | **災難**（無視調整值） |
| 2 | d100 自然值 96–100 | **大成功**（無視 DC） |
| 3 | 邊際 ≥ +20（檢定值 − 實際 DC ≥ 20） | **大成功** |
| 4 | 邊際 ≥ 0（檢定值 − 實際 DC ≥ 0） | **成功** |
| 5 | 邊際 ≥ −15（檢定值 − 實際 DC ≥ −15） | **勉強成功** |
| 6 | 邊際 ≥ −35（檢定值 − 實際 DC ≥ −35） | **失敗** |
| 7 | 邊際 < −35（檢定值 − 實際 DC < −35） | **災難** |

### 1.5 方針偏移（雙軸系統）

方針同時影響兩個獨立維度：

| 方針 | 檢定加值 | 安全軸偏移 | 收穫軸偏移 |
|------|:------:|:------:|:------:|
| **謹慎** | −5 | +1 級（更安全） | −1 級（收益降低） |
| **標準** | ±0 | 不變 | 不變 |
| **激進** | +5 | −1 級（更危險） | +1 級（收益提升） |

**安全軸**影響傷亡率計算（以偏移後的結果等級查傷亡表）。
**收穫軸**影響任務獎勵倍率（以偏移後的結果等級查收穫表）。

```
範例：基礎結果為「成功」、激進方針
→ 安全按「勉強成功」（基礎 35% 傷亡率）
→ 收穫按「大成功」（×1.5 倍率）
→ 主任拿到了更多戰利品——但代價是更高的傷亡風險。
```

### 1.6 概率參考（GM 平衡用）

> **公式**：`成功率（成功以上） = 101 − (DC − 加值)`，下限 1%、上限 100%。`含勉強成功 = min(100, 成功率 + 10)`（勉強成功門檻為 DC−10）。

| 配置 | 總加值 | 對中等 DC 70（成功以上／含勉強） | 對困難 DC 85（成功以上／含勉強） |
|------|:----:|:----------------------------:|:----------------------------:|
| 新手隊（1正式、1見習、裝備 3、標準） | +24 | 55% / 65% | 40% / 50% |
| 標準隊（2正式、裝備 5、標準） | +35 | 66% / 76% | 51% / 61% |
| 精銳隊（2資深、裝備 6、標準） | +48 | 79% / 89% | 64% / 74% |
| 菁英隊（2菁英、裝備 8、激進） | +69 | 100% / 100% | 85% / 95% |
| 傳奇隊（2傳奇、裝備 10、標準） | +80 | 100% / 100% | 96% / 100% |

> **設計原則**：標準配置對中等難度成功率（成功以上）約 66%、含勉強約 76%，符合「合理挑戰」。自殺級（DC 115）對傳奇隊成功率 = 101 − (115 − 80) = **66%**（含勉強 76%），仍屬高風險但非必死；GM 應避免讓低加值隊伍挑戰自殺級任務（成功率可能跌至 1%）。

## 第二章：傷亡系統（GM 完整版）

### 2.1 傷亡檢定流程

```
Step 1: 確定安全軸結果等級 → 查基礎傷亡率
Step 2: 套用傷亡率調整項 → 計算最終傷亡率
Step 3: 對每位派遣探險員擲 d100 傷亡檢定
Step 4: 觸發傷亡者擲傷勢嚴重度（d100）
```

### 2.2 基礎傷亡率（依安全軸）

| 安全軸結果 | 基礎傷亡率（每位探險員） |
|------------|:--------------------:|
| 大成功 | 0%（無傷亡檢定） |
| 成功 | 15% |
| 勉強成功 | 35% |
| 失敗 | 60% |
| 災難 | 90% |

### 2.3 傷亡率調整項（累加，下限 5%）

| 調整來源 | 效果 |
|----------|:---:|
| 每點裝備（EQP） | −2% |
| 謹慎方針 | −10% |
| 激進方針 | +10% |
| 配備醫療包（裝備） | −5% |
| 配備杏仁水（每人 1 單位） | −5% |
| 醫護專長探險員在隊中 | −5% |
| 遭遇威脅等級 3+ 實體 | +10% |
| 任務為「搜救」且超過時間窗口 | +15% |

```
例：安全軸「勉強成功」（基礎 35%）、裝備 5（−10%）、標準方針、配備醫療包（−5%）
→ 最終傷亡率 = 35% − 10% − 5% = 20%
每位探險員擲 d100，≤ 15 即觸發傷亡。
```

### 2.5 失蹤系統

任務災難時，死亡結果中的 20% 轉為「失蹤（MIA）」而非確認死亡。

**失蹤處理選擇**：
| 行動 | 效果 | 代價 |
|------|------|------|
| **派遣搜救** | 生成新搜救任務 | 人力、預算、時間壓力（參見 2.6） |
| **放棄搜救** | — | 聲望 −3、全隊壓力 +1、影響未來招募 |
| **等待（不派遣）** | 每月月初擲 d100，≤ 5 則自行歸隊（攜帶基本情報） | 時間消耗 |

### 2.6 搜救任務規則

| 失蹤天數 | DC 修正 | 存活率 |
|:------:|:-----:|:---:|
| 1–3 天 | 正常 DC | 90% |
| 4–7 天 | DC +10 | 60% |
| 8–14 天 | DC +20 | 30% |
| 15 天以上 | DC +30 | 5% |

**線索系統**：根據情報等級，初始線索數 = 情報（INT）÷ 2（向下取整，最多 3 條）。每條線索可降低搜救 DC 10。

**放棄搜救的連鎖效應**：聲望 −3、全隊心理檢定（d100 ≥ 50 則壓力 +1）、額外撫恤金、該失蹤者所屬團隊的士氣長期低迷。

### 2.7 全隊覆沒規則

觸發條件（滿足任一）：
- 任務「災難」+ ≥ 50% 隊員死亡或失蹤
- 任務「災難」+ 隊伍中無菁英以上探險員
- Boss 級實體遭遇且任務失敗

後果：
- 聲望 −5（可疊加）
- 觸發「調查委員會」事件（消耗 1 個月行動，強制進行內部審查）
- 所有在編探險員心理狀態降低一級
- 任務中所攜帶的裝備全損

### 2.9 實體攻擊與即時傷勢判定

本遊戲不使用傳統生命值（HP）。實體造成的「傷害」以傷亡檢定表現。當探險隊在任務中遭遇實體攻擊時，依下列規則處理：

**實體攻擊傷亡檢定**：遭遇實體並受到攻擊時，根據實體威脅等級決定基礎攻擊傷亡率，由裝備與醫療調整後，每位受攻擊探險員獨立擲 d100：

| 實體威脅等級（TL） | 攻擊基礎傷亡率 |
|:--:|:--:|
| TL1 | 10% |
| TL2 | 20% |
| TL3 | 35% |
| TL4 | 40% |
| TL5 | 60% |

調整項同 2.3（每點裝備（EQP）−2%、謹慎 −10%、醫療包 −5%、杏仁水 −5%、醫護專長 −5%；遭遇 TL3+ 實體 +10%）。

**即時傷勢（當場重傷）**：擲中傷勢表 71–90（重傷）或 91–100（死亡）者，當場失去戰鬥能力——無法繼續本任務的行動，由剩餘隊員決定撤離或繼續。重傷者按 2.4 恢復 6 回合，並有 d100 ≤ 30 永久降一級的風險。

**團隊行動選項**：當場重傷發生後，主任可（透過通訊）下達：①撤離（全隊撤離檢定）或 ②留下繼續（剩餘隊員承受下次攻擊 +10% 傷亡率）。此選擇是經典的「是否拋下隊友」困境。

### 2.11 存在感規則（GM 版）

**存在感（EXI）** 是每位探險員的隱藏數值，初始 10，記錄於探險員角色卡。

- **侵蝕**：遭遇「空洞」時，每 10 分鐘隨機 1 名探險員存在感 −1
- **歸零處理**：存在感歸零者從所有人的記憶中消失。GM 應私下從名冊移除該探險員，並在後續遊戲中安排「空床鋪」「無人認領的裝備」等細節，讓玩家逐漸意識到有人消失了——但其他探險員不記得他
- **液態寂靜**：每次飲用永久存在感 −1（累積使用 3 次以上風險顯現）
- **情感錨定**：攜帶摯愛信物（SPC-05）者獲一次性 +20 對抗加值（使用後信物碎裂）

## 第四章：世界觀與樓層目錄

### 4.1 後室是什麼？

**後室（The Backrooms）** 是「現實的背面」——一個由無限重複的室內空間構成的異次元。它存在於現實的裂縫中，當人們在錯誤的地方「切出」現實時，就會「切入」後室。

### 4.2 後室五大法則

1. **非歐幾里德空間**：空間不遵守線性幾何。同一條走廊走兩次可能通往完全不同的地方
2. **時空異常**：時間流速不穩定。一天可能感覺像一週，反之亦然
3. **無訊號法則**：無線電、Wi-Fi、衛星訊號在後室中不可靠或不存在。跨樓層通訊是極罕見的科技
4. **孤立生成**：後室會根據進入者的心理狀態和記憶生成景觀。這解釋了為何不同人可能看到不同的後室
5. **資源稀缺**：食物、水、光源在後室中不會自然生成（杏仁水是少數例外）。所有資源必須從外部帶入

## 第七章：GM 操作指南

### 7.1 GM 的核心角色

你是三個身分的合一：
1. **上級**：給出任務、設定期限、施壓——但不無理
2. **情報官**：管理資訊不對稱。你知道的永遠比玩家多，但選擇性披露
3. **命運**：當骰子落下，你負責將數字轉化為有重量的敘事

### 7.2 核心主持原則

**原則一：「是的，而且……但代價是」**
玩家想做什麼，盡量說「可以」。然後加上「但這意味著……」。每次選擇都有漣漪效應。

```
玩家：「我想派兩隊同時進行兩個困難任務。」
GM：「可以。但這意味著你的所有菁英探險員都在前線——如果同時出事，你沒有後備。」
```

**原則二：你不是怪物，你是命運**
GM 不站在實體那邊。你站在「後果」那邊。當探險員死亡時，不要得意——描述死訊時要有分量。每個死亡都是故事的一部分。

**原則三：資訊不對稱是設計特徵**
玩家永遠不應該知道所有事。情報偏差不是 bug，是本遊戲的核心樂趣。不要因為玩家買了「完美情報」就覺得無聊——完美情報的代價（500 預算）正是策略的一部分。

**原則四：後果優先於劇情**
玩家選擇 > 骰子結果 > 你預設的劇情。如果玩家做出驚人的決定讓你計劃的劇情無法實現——擁抱它。最好的故事來自意料之外。

### 7.3 任務池管理

每個月提供玩家 3–5 個可選任務。推薦比例：

| 任務類型 | 比例 | 說明 |
|----------|:--:|------|
| 偵察 | 20% | 維持情報流入 |
| 補給/資源 | 30% | 維持資源循環 |
| 搜救/外交 | 25% | 推動劇情 |
| 戰鬥/危機 | 25% | 製造張力 |

**「過期」機制**：任務不會永遠存在。GM 定期宣布某些任務因時間耗盡而失效（搜救窗口關閉、委託方撤回等），迫使玩家在「做什麼」和「不做什麼」之間取捨。

### 7.4 節奏控制：每月四週循環

把每個遊戲月分為四個「節拍」：

| 週 | 節拍 | GM 要做的事 |
|:--:|------|------------|
| 第一週 | **簡報** | 呈現任務清單和情報。讓玩家感受到壓力——資源有限、選擇必須做出 |
| 第二週 | **執行** | 任務檢定、結果揭曉。這是擲骰和敘事的高潮 |
| 第三週 | **回應** | 玩家處理後果——傷員、失蹤、裝備損耗。情感沉澱的時間 |
| 第四週 | **清算** | 預算結算、月度事件觸發、劇情推展。為下個月鋪墊 |

**三級戲劇事件節奏**：
- **每月**：至少 1 個小事件（一張任務中的隨機事件卡、一段 NPC 對話）
- **每季（3 回合）**：至少 1 個中事件（派系關係變化、意外發現）
- **每戰役（10–15 回合）**：1 個大事件（主要劇情轉折）

### 7.5 情感基調控制

安全感與焦慮感是一條光譜。在不同階段移動光譜：

| 階段 | 光譜位置 | 做法 |
|------|:------:|------|
| 任務簡報階段 | 中等安全感 | 讓資訊清晰但有缺口。「你知道的夠多——但你知道你知道的不夠多」 |
| 派遣階段 | 中等焦慮 | 限制選項、突出代價。「你可以派三個人——但只有兩套好裝備」 |
| 執行階段 | 高焦慮 | 擲骰前的停頓、資訊偏差的懸念 |
| 結果階段 | 釋放 | 揭露結果，讓情感落地。不要急著跳到下一個任務 |
| 休整階段 | 短暫寧靜 | 基地生活的小片段、探險員之間的對話。為下一次的焦慮蓄力 |

### 7.6 單人模式特別建議

- **讓「孤獨」成為主題**：單人玩家沒有其他玩家可以討論、分擔責任。利用這點——讓辦公室場景有孤獨感
- **NPC 探險員要有個性**：單人玩家唯一的社交對象是你扮演的 NPC。給每個探險員鮮明的聲音和個性
- **「主任的個人時間」**：每 3–5 回合，插入一個短場景——主任在辦公室整理文件時發現的舊照片、前任主任留下的筆記、深夜獨自喝著杏仁水看著窗外無盡的黃色走廊
- **別讓數字淹沒故事**：單人玩家需要處理所有管理細節，容易陷入試算表心態。定期用敘事將他們拉回來

### 7.7 緊急狀況處理

**情境一：玩家決策癱瘓**
- 症狀：面對任務選擇時長時間猶豫不決
- 處理：引入時間壓力。「指揮官來電——他需要你的決定在五分鐘內。」用遊戲內壓力反映玩家的癱瘓

**情境二：探險員全滅後的恢復**
- 提供「安全網」機制——M.E.G. 可借調 2 名正式探險員（代價：未來 6 個月的任務優先權歸 M.E.G.）
- 觸發「志願者」事件——獨立據點可能有探險員願意加入（代價：對該據點的義務）
- 不要讓遊戲結束——讓重建成為一個故事

**情境三：派系關係崩潰**
- 如果與所有派系關係都降至 −50 以下：觸發「孤立」劇情線
- 玩家必須靠自己——沒有外部支援、沒有貿易、沒有情報共享
- 這不是懲罰，是另一種遊戲體驗。可以設計「孤狼管理局」的專屬事件

### 7.8 隱藏資訊管理

**永遠不該直接告訴玩家的**：
1. 實際 DC（只給出範圍）
2. 偏差骰的結果
3. 實體的準確位置和數量（除非完美情報）
4. 未來事件的具體劇本

**三層資訊揭露法**：
1. **第一層**：所有人都知道的事（常識——「L2 管道迷宮中可能有肢團」）
2. **第二層**：情報可獲知的事（「根據最近偵察，L2 北區的肢團活動增加 30%」）
3. **第三層**：只有經歷才會知道的事（「那隻肢團的迴聲頻率與普通不同——牠可能已經吸收了某個東西」）

### 7.9 主任個人數值（上司關係值與愧疚值）

玩家規則書 3.6、3.7 定義了兩個主任個人數值，GM 需據以下規則運作：

**上司關係值（SUP）**（初始 0，−20～+20）：
- 每月結算時，若玩家達成其上司的「好感條件」→ SUP +3；否則 −2
- SUP ≥ +10：每月月初給予玩家 +50 預算，或 1 次免費基礎情報（二選一）
- SUP ≤ −10：每月額外指派 1 個強制任務（未完成則聲望 −2）

**愧疚值（GLT）**（初始 0）：
- 每次任務「災難」或探險員「死亡（KIA）」→ GLT +1；「未發出的撤離命令」相關失誤額外 +1
- GLT ≥ 5 是結局 C「親自走入後室」的觸發條件之一
- GLT 越高，「主任的噩夢」事件（9.1 d100=60）的敘事強度越大

## 附錄 A：GM 速查表

### A.1 任務結算流程卡

```
1. 主任宣告方針（謹慎/標準/激進）
2. 計算總加值（TEB + EQB + DOC + SPC）
3. GM 宣告預估 DC 範圍（含偏差）
4. 擲 d100 + 加值 → 任務檢定值
5. 以實際 DC 判定五級結果
6. 結算收穫（任務類型 × 收穫軸等級）
7. 每位探險員獨立擲傷亡骰（d100 ≤ 最終傷亡率）
8. 結算裝備損耗（擲 d100 ≤ 損耗 DC → 裝備損壞）
9. 結算壓力變化、情報更新
10. GM 敘述最終結果
```

### A.2 DC 快速對照

### A.3 傷亡率快速計算

```
最終傷亡率 = 基礎傷亡率 − EQP×2% − 方針調整 − 裝備調整 + 懲罰
```
- 基礎傷亡率：大成功 0% / 成功 15% / 勉強成功 35% / 失敗 60% / 災難 90%
- 方針：謹慎 −10% / 激進 +10%
- 下限：5%（即使所有加值都完美，後室的最低風險永存）
