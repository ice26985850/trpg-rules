## 威脅等級（TL）對照

| TL | 描述 | DC 加值 | Boss 規則 |
|:--:|------|:------:|:------:|
| 1 | 輕微——可輕易避開或無威脅 | +0 | 否 |
| 2 | 普通——謹慎應對可安全通過 | +5 | 否 |
| 3 | 危險——需要專業裝備和經驗 | +10 | 否 |
| 4 | 致命——菁英團隊才能對抗 | +20 | 可選 |
| 5 | 災厄——使用 Boss 三階段規則 | +30 | 是 |

## 實體攻擊傷亡率（遭遇戰參考）

本遊戲不使用傳統生命值（HP）。實體「攻擊」造成的後果以傷亡檢定表現。當探險隊遭遇實體攻擊時，依實體威脅等級決定基礎攻擊傷亡率（由裝備、醫療、方針調整後，每位受攻擊探險員獨立擲 d100）：

| 實體威脅等級（TL） | 攻擊基礎傷亡率 |
|:--:|:--:|
| TL1 | 10% |
| TL2 | 20% |
| TL3 | 35% |
| TL4 | 40% |
| TL5 | 60% |

> 完整規則（即時傷勢、團隊行動選項、狀態效果）見 GM 規則書第二章 2.9–2.11。

## 實體 #1：微笑者（Smilers）

| 屬性 | 內容 |
|------|------|
| **威脅等級** | TL2（無照明時 TL3） |
| **出現區域** | Level 0–3 的黑暗區域 |
| **DC 加值** | +5（照明不足 +10） |
| **基礎遭遇率** | 25% |
| **特性** | 黑暗中浮現的發光笑面。無實體形態——是光和黑暗之間的某種存在 |

**特殊規則**：
- **光與暗**：任何光源故障時 TL 立即提升至 3，持續至光源恢復
- **微笑蔓延**：團隊中有「創傷」或「崩潰」狀態的探險員時 DC +5
- **多數面對**：微笑者通常以 1d3+1 的數量出現

**應對方式**：充足照明即可安全通過。高功率手電筒（BE-02）提供對抗加值

**GM 敘事建議**：不要描述「微笑者突然出現」——描述燈光開始不穩定地閃爍，在明暗交替的瞬間，玩家瞥見走廊盡頭有東西在笑

## 實體 #2：派對客（Partygoers / =)）

| 屬性 | 內容 |
|------|------|
| **威脅等級** | TL4 |
| **出現區域** | 僅 Level Fun |
| **DC 加值** | +20 |
| **基礎遭遇率** | 90%（Level Fun 內幾乎必然遭遇） |
| **特性** | 黃色皮膚、卡通笑臉的人形生物。以「邀請」方式轉化人類 |

**特殊規則**：
- **友好面孔**：首次遭遇可進行意志對抗（d100 ≥ 50），失敗則被誘惑跟隨
- **派對規則**：在 Level Fun 內，撤退規則不適用——必須完成「派對遊戲」才能離開
- **轉化不可逆**：被轉化的探險員永久從名冊移除
- **團隊壓力效應**：團隊中每有 1 名「緊張」或「創傷」探險員，DC +3

**GM 警告**：不要讓派對客成為常規遭遇。它們應該是「你可能永遠失去一個人」的代名詞。一旦有探險員被轉化——就結束了。沒有拯救任務。

## 實體 #3：死亡飛蛾（Death Moths）

| 屬性 | 內容 |
|------|------|
| **威脅等級** | TL5（Boss） |
| **出現區域** | Level 5、大型封閉空間 |
| **DC 加值** | +30 |
| **基礎遭遇率** | 15% |
| **特性** | 翼展 3 米的巨型飛蛾。無聲飛行、強酸性體液 |

**特殊規則**：
- **產卵**：重傷探險員有 30% 機率被產卵。被產卵者需在 d6 天內接受 DC 80 的醫療檢定，失敗則死亡
- **巢穴**：通常以 d3+1 隻的群體出現。巢穴女王使用 Boss 三階段規則
- **無聲獵手**：遭遇觸發時無視方針（謹慎也無法降低遭遇率）

**應對方式**：高頻聲波發射器（EE-03）提供傷亡率 +3 對抗

**Boss 三階段**：
- 第一階段（100%）——空中攻擊，3 次 DC 85 對抗
- 第二階段（50%）——落地近戰，酸性噴射，2 次 DC 90 對抗
- 第三階段（25%）——瀕死產卵狂暴，1 次 DC 95 對抗。失敗 → 在場所有人強制產卵檢定

## 實體 #4：無面靈（Facelings）

| 屬性 | 內容 |
|------|------|
| **威脅等級** | TL1（攻擊型 TL3） |
| **出現區域** | Level 1–4 |
| **DC 加值** | +0（攻擊型 +10） |
| **基礎遭遇率** | 40% |
| **特性** | 無面部特徵的人形生物。多數中立甚至友善 |

**特殊規則**：
- **攻擊型判定**：遭遇時擲 d6，5–6 為攻擊型
- **鏡子詭計**：攜帶小鏡子的團隊對無面靈傷亡率 −5%（牠們對自己的反射感到困惑）
- **兒童無面靈**：20% 機率遇到孩童版（無攻擊性），可嘗試帶回據點——情報永久 +1，但需照顧

**GM 敘事建議**：無面靈是後室中最「不恐怖」的實體——這正是使它們可怕的地方。牠們太像人了。在昏暗的走廊中，你可能無法從背後分辨一個無面靈和一個戴著面具的同事。

## 實體 #5：獵犬（Hounds）

| 屬性 | 內容 |
|------|------|
| **威脅等級** | TL3 |
| **出現區域** | Level 0–3 |
| **DC 加值** | +10（群體 +15） |
| **基礎遭遇率** | 30% |
| **特性** | 大型四足掠食者。群體狩獵、高速移動 |

**特殊規則**：
- **群獵本能**：團隊中有負傷者時 TL 提升至 4
- **叫聲震懾**：非菁英以上探險員聽到叫聲需意志對抗（d100 ≥ 60），失敗則個人加值 −5
- **追蹤氣味**：一旦被鎖定，需使用 1 單位杏仁水抹除氣味才能脫離。否則後續遭遇率 ×2

**應對方式**：杏仁水抹除氣味、攀爬至高處、大量噪音可暫時驅散

## 實體 #6：剝皮者（Skin-Stealers）

| 屬性 | 內容 |
|------|------|
| **威脅等級** | TL4 |
| **出現區域** | Level 1–3 |
| **DC 加值** | +20 |
| **基礎遭遇率** | 10% |
| **特性** | 能完美模仿人類外觀。剝取受害者皮膚進行偽裝 |

**特殊規則**：
- **滲透者（GM 使用）**：出發前暗擲 d100，≥ 90 則隊伍中已有 1 名探險員被替換
- **皮膚記憶**：可應付基本身份查驗。被替換者會表現得像本人——但對「情感」問題給出模糊答案
- **揭露僵直**：被識破時，剝皮者會僵直 1 回合——團隊獲得 1 次自由攻擊/逃脫機會

**GM 警告**：這是本遊戲最強的心理恐怖元素。被替換的 NPC 應該在一個關鍵時刻背叛——不是隨機的，而是在最能造成傷害的時刻。給玩家線索但不要太明顯。

## 實體 #7：哀嚎者（Wretches）

| 屬性 | 內容 |
|------|------|
| **威脅等級** | TL2 |
| **出現區域** | Level 1–2 |
| **DC 加值** | +5 |
| **基礎遭遇率** | 35% |
| **特性** | 曾經是人類。在後室中完全精神崩潰。不斷哀嚎 |

**特殊規則**：
- **靈魂回聲**：在哀嚎者附近超過 30 分鐘，全隊自動觸發心理檢定（d100 ≥ 50），失敗 → 壓力 +1
- **認識的人**：10% 機率哀嚎者是團隊中某人認識的前探險員（GM 從已陣亡名冊中選擇）
- **拯救可能**：可嘗試帶回據點進行治療。3 個月後有 30% 機率恢復為見習探險員

**GM 敘事建議**：哀嚎者的恐怖不在於威脅——在於牠提醒了你：這就是後室對人類的結局。每一個哀嚎者都曾經有名字、有合約、有主任簽名。也許有一天，你的一個探險員也會成為牠們中的一員。

## 實體 #8：肢團（Clumps）

| 屬性 | 內容 |
|------|------|
| **威脅等級** | TL3 |
| **出現區域** | Level 2 管道迷宮 |
| **DC 加值** | +10（狹窄管道中 +20） |
| **基礎遭遇率** | 20% |
| **特性** | 由多個人類肢體融合而成的巨大肉塊。在管道中蠕動吸收一切 |

**特殊規則**：

- **管道迴聲**：可在 3 個房間外感知其接近——給予團隊反應時間

**應對方式**：牠不能快速轉彎——利用管道的曲折結構脫逃

## 實體 #10：空洞（The Hollow）

| 屬性 | 內容 |
|------|------|
| **威脅等級** | TL5（不可戰勝） |
| **出現區域** | 任意樓層（極罕見，遭遇率 2%） |
| **DC 加值** | +30 |
| **特性** | 不可見、不可觸的存在性威脅。吞噬「存在感」 |

**特殊規則**：
- **存在侵蝕**：每 10 分鐘，隨機 1 名探險員「存在感」−1（從 10 開始）。歸零者從所有人的記憶中消失——不曾存在過（詳細規則與「歸零」的 GM 處理方式見 GM 規則書 2.11 存在感規則）
- **情感錨定**：攜帶摯愛信物（SPC-05）的探險員可獲得一次性 +20 對抗加值。使用後信物碎裂
- **紀錄的力量**：持續書寫或錄音（每 5 分鐘進行一次描述）可使對抗 DC −10
- **不可戰勝**：空洞不能被「擊敗」。任務目標永遠是生存和撤離

**GM 終極警告**：空洞不是怪物——牠是概念性威脅。永遠不要描述空洞的「外觀」。描述的是探險員的感知：記憶開始模糊、記不起同事的名字、不確定那個人是否一直都在隊伍中。如果你要讓一個探險員「歸零」——讓它成為整個戰役中最令人難忘的時刻。被遺忘者不只是在遊戲中消失——其他探險員應該真的不再記得牠。玩家應該在後續遊戲中偶然發現一個空床鋪、一個沒人認領的裝備——然後疑惑那是誰的。
