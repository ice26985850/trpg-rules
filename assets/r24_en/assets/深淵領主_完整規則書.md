# Chapter One: Core Rules

## 1.1 Dice System

This ruleset uses the **d6 Dice Pool** system.

| Die Face | Result |
|------|------|
| **6** | Success + **Explosion (Critical)**: counts as 1 success, grants +1 extra die (can chain) |
| **5** | Success: counts as 1 success |
| 1-4 | No effect |

Expected successes per die = 0.40 (5–6 success rule, 1/3 probability + explosion recursion).

### Dice Pool Composition

```
Dice Pool = Attribute Dice + Skill Dice + Modifier Dice
```

| Source | Description | Cap |
|------|------|------|
| Attribute Dice | Attribute value = base dice count (1–5) | 5d6 |
| Skill Dice | Skill level provides extra dice (0–5) | +5d6 |
| Modifier Bonus | Temporary bonus dice from gear/terrain/aid | +3d6 |
| Modifier Penalty | Adverse condition removes dice | -3d6 |
| Advantage | Fixed dice added before roll | +2d6 |
| Disadvantage | Highest N dice removed from pool before roll | -2d6 |

**Dice Pool Cap**: A single check does not exceed **10d6**.

### Margin of Success Levels

| Net Successes | Result Level | Description |
|----------|---------|------|
| 0 | **Failure** | Action did not meet goal, may have minor negative consequence |
| 1 | **Partial Success** | Goal met but with a cost, delay, or reduced effect |
| 2 | **Full Success** | Goal achieved cleanly |
| 3 | **Critical Success** | Exceeds expectations, with extra benefit |
| 4+ | **Legendary Success** | Effect doubled or hidden benefit unlocked |

### Difficulty Levels

| Difficulty | Successes Required | Typical Scene |
|------|-----------|---------|
| Easy | 1 | Command loyal minions, basic construction |
| Standard | 2 | Build rooms, interrogate T2 captive, recruit monsters |
| Hard | 3 | Interrogate high-Will captive, magic trap, deep dig |
| Extreme | 4 | Convert legendary captive, ultimate ritual |
| Epic | 5+ | Magic that reshapes the world order |

### Key Probability Quick Reference

| Dice Pool | P(≥1 Success) | P(≥2 Success) | P(≥3 Success) | Expected Successes |
|------|-----------|-----------|-----------|-----------|
| 1d6 | 33.3% | — | — | 0.40 |
| 2d6 | 55.6% | 11.1% | — | 0.80 |
| 3d6 | 70.4% | 33.3% | 11.1% | 1.20 |
| 4d6 | 80.2% | 48.1% | 21.0% | 1.60 |
| 5d6 | 86.8% | 60.5% | 32.2% | 2.00 |
| 6d6 | 91.2% | 70.8% | 43.7% | 2.40 |
| 7d6 | 94.1% | 78.9% | 54.4% | 2.80 |
| 8d6 | 96.1% | 85.1% | 64.1% | 3.20 |

> Sweet spot is 3–5d6. At 3d6 the Standard difficulty success rate is about 33%, at 5d6 about 60%.

## 1.3 Check Types

### Standard Check

1. GM announces the difficulty level
2. Player builds the dice pool
3. Roll and count successes
4. Net Successes ≥ Difficulty = success

### Opposed Check

Both sides build their dice pools and roll simultaneously. **Net Successes = active side's successes − opposed side's successes**.

### Critical Success & Critical Failure

- **Critical Success**: Net Successes ≥ 3 or 3+ sixes rolled → extra benefit
- **Critical Failure**: Successes = 0 and 3+ ones appear in the pool → unexpected negative event

## 1.5 Game Example

> The following is a typical turn-flow example to help newcomers understand the game's rhythm.

**Management Phase**:
*GM*: "Another Abyssal week. In your Throne Hall, a gargoyle crouches in the corner polishing its wings, cultists pore over ancient tomes in the research chamber. A rhythmic tapping comes from the mine — skeleton soldiers don't need rest."

*Player (Ancient Wyrm, Lv2)*: "Good. First I assign monster posts — gargoyle to the combat post guarding the outer layer, cultists back to the research chamber, skeleton soldiers sent to the mine. Then I want to use Building Materials to dig a second small space."

*GM*: "Roll IND + Engineering check."

*Player rolls*: "Industry (IND)=4, Engineering=1… I roll 5d6. Got 6, 5, 3, 2, 1 — 2 successes! Follow-up die… 3. Total successes = 2."

*GM*: "Full Success! You dug out a medium cave — and shimmering Mana Crystal light glows on the rock wall. You discovered a Mana Node; that space's mana-room efficiency permanently +1 die."

*Player*: "Great! I spend ◇ to build a Trap Workshop here. Then end of turn — roll invasion check?"

**Invasion Phase**:
*GM*: "Roll Infamy (INF)(2)+1d6… got 5. 2+5=7, below 8 — safe this week. But your Scout Outpost noticed firelight in the distance. Next turn, someone may come."

**Second Turn**:
*GM*: "Invasion check: Infamy (INF)(2)+1d6=7… wait, this time a 6. 2+6=8 — invasion! Two adventurers approaching."

*Player*: "I deploy the gargoyle to the outer layer, pull the cultists back to the combat post to help. The Trap Workshop's rockslide trap is already in place."

*GM*: "Adventurers enter the outer layer. Warrior Allen steps on the rockslide trap — 2d6=7 damage! But he still has 3 HP, keeps advancing. Thief Mira spotted the gargoyle. Combat begins!"

> This is the rhythm loop of Abyss Lord: expand → build → assign → (possibly) invade → post-battle settlement → loop again.

### Two-Step Build Flow

```
Step 1: Dig to unlock space (spend Building Materials + time, roll IND check)
Step 2: Choose a room type to build within the unlocked space
```

Must **dig before building**. Cannot build directly in an undug space. Rooms a space can hold are determined by its level.

### Dig Check

**Dice Pool**: Industry (IND) + Engineering skill
**Difficulty**: see Space Level table
**Net Success Results**:

| Net Success | Result |
|--------|------|
| 0 | Dig fails, Building Materials doubled, that location cannot be dug again |
| 1 | Unlock space, attached discovery canceled |
| 2+ | Full success, unlock space + roll d6 for discovery |

## 2.4.2 Enchanting System ⭐⭐⭐

Enchanting is the infusion of Abyssal energy from Mana Crystals into equipment or creatures, granting them supernatural properties.

### Enchanting Process

1. **Prepare**: Own a Forge Lv2 + Research Chamber (satisfying the "Arcane Workshop" synergy)
2. **Choose Target**: one forged piece of equipment or one monster
3. **Choose Enchant Type**: select from the enchant table below
4. **Enchant Check**: roll `Arcana (ARC) + Enchanting skill`, difficulty per enchant table
5. **Spend Resources**: pay ◇ and ●
6. **Check Result**:
   - Failure (0 successes): resources spent, enchant not applied. May retry
   - Partial Success (1 success): enchant applies but at half strength (lasts 3 turns then expires, needs re-enchant)
   - Full Success (2 successes): enchant stably applied
   - Critical Success (3+ successes): enchant strength doubled or random extra effect added

### Enchant Types

#### Elemental Enchant (weapon/armor)

| Enchant | ◇ Cost | Difficulty | Effect |
|------|:---:|:---:|------|
| **Flame Enchant** | 3 | 2 | Equipped monster attack +1 fire damage; target burns 1/turn ×2 turns |
| **Frost Enchant** | 3 | 2 | Equipped monster attack adds slow: target movement -1 room (1 turn) |
| **Lightning Enchant** | 4 | 3 | Equipped monster attack may jump to adjacent enemy (second target CP -2 dice) |
| **Dark Erosion Enchant** | 5+●1 | 3 | Equipped monster attack recovers HP = damage ×0.5 (rounded up) |
| **Holy Light Resistance** | 3 | 3 | Equipped monster takes 50% less Holy Light/divine damage (specialized vs Order of Light) |

#### Enhancement Enchant (weapon/armor)

| Enchant | ◇ Cost | Difficulty | Effect |
|------|:---:|:---:|------|
| **Sharp** | 2 | 1 | CP extra +1 (stacks on equipment base CP) |
| **Tough** | 2 | 1 | Defense die extra +1 die (stacks on equipment base defense) |
| **Vampiric** | 5+●2 | 4 | Recover 1 HP per 3 damage dealt |
| **Indestructible** | 4 | 3 | Equipment cannot be seized/destroyed. Monster's equipment always recovered on death |
| **Light** | 2 | 1 | Removes equipment weight penalty (equipment that originally had -1 movement also unaffected) |

#### Creature Enchant (applied directly to monster, no equipment slot used)

| Enchant | ◇ Cost | Difficulty | Effect |
|------|:---:|:---:|------|
| **Enchanted Skin** | 3 | 2 | Monster gains magic defense dice pool = Arcana (ARC)/2 (rounded up) |
| **Elemental Bloodline** | 4+●1 | 3 | Monster gains chosen element attack (fire/ice/elec/acid); +50% damage vs opposite element |
| **Regeneration** | 5+●2 | 4 | Monster auto-recovers 1 HP per turn |
| **Shadow Affinity** | 3 | 2 | Monster gains Stealth ability (Cunning (CUN)+1 die); +1 die attacking in darkness |
| **Loyalty Mark** | 2+●1 | 1 | Monster LOY permanent +1 (not stackable, 1 time per monster) |

### Enchant Stacking Rules

- Each equipment slot holds at most **2 enchants** (Lord's armament holds 3)
- Same-name enchants don't stack — when enchant names are identical, take the highest-level effect
- Different-name enchants can stack
- Enchant effects persist when equipment is removed/transferred

### Enchant Trade

Enchanted equipment's trade value rises substantially: base equipment price × (1 + enchant ◇ cost's 50%).
Example: Iron Claw (◆8) + Flame Enchant (◇3) → trade price = 8 + 3×0.5 = ◆9.5 → ◆10.

Enchanted equipment is a popular trade good among NPC dungeons — especially Holy Light Resistance gear (all dungeons in Order of Light threat zones demand +50% premium).

## 2.6 Monster Assignment System ⭐

> Each monster has two usage dimensions — management vs. combat. Assignment is the core strategy.

### Monster Dual-Dimension Attributes

| Attribute | Meaning | Use |
|------|------|------|
| **Management (MV)** (Management Value) | Contribution when deployed to production/management | Management dice pool |
| **Combat (CP)** (Combat Value) | Contribution when deployed to defense/combat | Combat dice pool |

### Assignment Rules

- At the start of each turn, each monster must be assigned to the **Management Group** or the **Combat Group**
- A monster cannot contribute to both management and combat in the same turn
- Assignment is a free action (costs no action points)
- Emergency Conscription: when an invasion occurs, a monster in management may be urgently moved to combat, costing 1 action → first-turn dice pool -1 → monsters with Loyalty (LOY) ≤2 need a loyalty shock check

### Management Dispatch Dice Pool

> Total management dice pool = Industry (IND) + relevant skill + floor(Σ Management (MV) ÷ 2)

### Production Output Formula

> After a production check succeeds, resources are produced per the following rules:

| Dice Pool Source | Allocation |
|---------|------|
| IND dice + skill dice successes | Allocated to **output rooms** (each success = that room's Lv output ×1). Prioritize Mine (■), Research Chamber (◇), Vault (◆). Successes with no room to absorb → ◆×1 |
| Monster MV bonus dice successes | Allocated to **the room the monster belongs to** (e.g., skeleton in mine → Building Materials, cultist in research chamber → Mana Crystals). No designated room → corresponding monster's upkeep resource ×1 |

> **Example**: Ancient Wyrm (Industry (IND)=4, Engineering=1) rolls 5d6 → 3 successes. 2 gargoyles (ΣMV=4, bonus 2d6) → 1 success. Mine Lv1 present, Lv1 Research Chamber present. Allocation: IND's 3 successes → mine outputs 3■ (Mine Lv1 = ■×1/success). Monster MV's 1 success → gargoyle in mine → extra 1■. This turn's total output: 4■.

### Combat Defense Dice Pool

> Total combat dice pool = Warfare (WAR) + monster command/tactical deployment + floor(Σ Combat (CP) ÷ 2)

### Efficiency Guide

| Monster Group | Σ Management (MV)/Combat (CP) | Bonus Dice | Efficiency (dice/monster) |
|--------|--------|------|-------------|
| 4 skeleton soldiers (Combat (CP) 1×4) | 4 | 2 | 0.50 |
| 2 hellhounds (Combat (CP) 3×2) | 6 | 3 | 1.50 |
| 1 elemental construct (Combat (CP) 4) | 4 | 2 | 2.00 |

> The floor(Σ/2) formula makes high-quality monsters more efficient than low-quality swarms, encouraging pursuit of elites over quantity.

## 2.8 Captive Management System ⭐

### Captive Flow (six stages)

```
Defeat adventurer (HP to 0 = unconscious) → Imprison → Interrogate/Torture/Charm → WIL lowered → Collapse or Convert
```

### Captive Attributes

| Attribute | Meaning | Range |
|------|------|------|
| Will (WIL) | Willpower: mental strength resisting interrogation/brainwashing | 1-5 |
| PL | Profession Level: captive's profession skill level | 1-5 |
| STA | Stamina: physical condition, determines labor dice pool | 1-5 |

### Will Contest (Will (WIL) Resistance)

> Dungeon Lord rolls **Dominion (DOM) + Interrogation skill** vs captive rolls **Will (WIL)**

| Net Successes | WIL Change | Side Effect |
|----------|---------|---------|
| ≤0 | No change | Captive resists, GM secretly rolls vague intel |
| 1 | Will (WIL) -1 | Captive begins to waver |
| 2 | Will (WIL) -1 | Next interrogation captive WIL dice pool -1 die |
| 3+ | Will (WIL) -2 | Will greatly weakened, certain intel gained |

### Five WIL-Lowering Methods

| Method | Attribute Used | Effect | Risk |
|------|---------|------|------|
| Interrogation | Dominion (DOM) | Will (WIL)-1 (stable) | None |
| Torture | Warfare (WAR) | Will (WIL)-2 (efficient) | STA-2, captive may be crippled |
| Charm | Dominion (DOM) | Slow but accelerates conversion | Spends Dark Coins |
| Isolation | — | Passive: WIL -1 per turn (first time only) | Requires single-cell prison |
| Brainwashing | Arcana (ARC) | Will (WIL)-3 (strongest) | May collapse (WIL immediately to 0) |

### WIL-Zero Outcomes (roll 2d6)

| 2d6 | Outcome | Effect |
|-----|------|------|
| 2-3 | **Mental Collapse** | Captive becomes a worthless wreck, worth only 1 Soul Essence |
| 4-6 | **Numb Obedience** | Labor efficiency 50%, won't escape, but no special value |
| 7-9 | **Conversion Success** | Becomes a loyal minion, retains 50% profession skills, can serve as room supervisor |
| 10-11 | **Awakening Resonance** | Full conversion! Retains all profession skills, Loyalty (LOY)=4, gains 1 random management ability |
| 12 | **Dark Awakening** | Converts and bursts potential — all attributes +1, Loyalty (LOY)=5, may develop into a plot NPC |

**Method Modifiers**: Charm +1 outcome die, Torture -1 outcome die, Brainwashing -2 outcome die.

### Five Labor Types

| Labor | Dice Pool Formula | Output |
|------|---------|------|
| Dig & expand | STA + PL (warrior +1 die) | Building Materials × successes |
| Trap making | STA + PL (thief +1 die) | Trap components × successes |
| Magic research | STA + PL (mage +1 die) | Mana Crystals × successes |
| Resource production | STA + PL | Corresponding resource × successes |
| Combat cannon fodder | PL dice pool (Combat Value = PL) | STA -1 per battle |

### Escape Check

At end of each turn, captives with Will (WIL) ≥2 attempt escape:
- Captive rolls WIL dice pool vs dungeon rolls DEF dice pool + prison level
- Captive success > dungeon → escape triggered, enters pursuit phase
- Pursuit: captive rolls PL dice pool vs dungeon rolls Warfare (WAR) + deterrence tactics (hellhound +2 dice)
- Captive escapes → remove captive, may expose dungeon intel

### Moral Paths

| Path | Method Preference | Advantage | Disadvantage |
|------|---------|------|------|
| **Tyrant** | Torture + Brainwashing | Fast conversion | Low conversion quality (Numb Obedience), high captive death rate |
| **Benevolent Lord** | Charm + Interrogation | High conversion quality (Awakening Resonance) | Slow conversion |
| **Pragmatist** | Mixed | Highest flexibility | No specialization bonus |

### Core Resource Details

**Dark Coins (◆)**: The dark currency circulating in the Abyss. Not ordinary gold — each Dark Coin is forged from Abyssal mana, emitting a dark-red glow in darkness. Surface gold cannot be used in the underworld; gold carried by adventurers must be "converted" into Dark Coins in the vault (1 surface gold = 1d2 Dark Coins, determined by roll). Dark Coins are the foundation of the dungeon economy, usable for trade, recruitment, bribery, magic-material purchase. The Ancient Wyrm archetype has natural affinity for them (vault interest).

**Mana Crystals (◇)**: Solidified condensation of Abyssal mana. Naturally forms near mana nodes, appearing as purple-black translucent crystals. Touching them gives a faint pulse — that is Nexis's heartbeat. Mana Crystals are the energy source driving magic rituals, releasing combat arts, activating magic traps. Mana-dense dungeons (Magic (MAG) ≥8) can slowly generate their own. Mad Sorcerers and Necromancer Lords consume large amounts of Mana Crystals.

**Building Materials (■)**: Standard unit measuring stone, wood (underground fungal wood), and metal ore dug from the underground. 1 unit of Building Material builds 1 wall segment, 1 door, or 3 square meters of floor. Building Material quality has three grades: rough stone (basic), obsidian (defense +1), Abyss Alloy (defense +2 and magic-conductive). Mines produce basic Building Materials; high-quality materials require trade or special digging.

**Soul Essence (●)**: Abyssal energy extracted from a defeated adventurer's life force. Appears as a floating blue-white orb containing the defeated one's last wisp of consciousness — a trained Abyss Lord can read faint memories from it. Soul Essence is the core fuel of necromancy, the price of sacrifice rituals, and the currency for recruiting undead/demon-type monsters. The Order of Light views Soul Essence as the deepest blasphemy — being found holding large amounts triggers religious judgment.

#### Forging Material Details

**Iron Ingot**: A dark-gray metal ingot refined from Abyss iron ore. Denser than surface iron — forms naturally under underground high pressure, found everywhere in mines. The entry material for forging basic equipment, also circulates as "small change" in trade (public exchange rate 2 Dark Coins = 1 Iron Ingot).

**Obsidian Steel**: Reinforced metal formed when iron ingots are long steeped near mana nodes. Surface has a purple-black glassy luster, rings crystal-clear when struck. Requires the Forge Lv2 furnace temperature to shape. Core material of fine equipment — tight supply and demand, Goblin Tinkerer dungeons demand it most.

**Abyss Alloy**: Rarest deep-layer ore, forms only where Breath of Nexis permeates deepest. Dark green, faintly self-glowing. Needs no fuel to forge — Abyss Alloy auto-heats to forging temperature on contact with Mana Crystals. The sole material for epic and legendary equipment. Extremely low yield — a full Lv15 Abyss equipment set requires long accumulation or heavy trade.

> **Storage**: The three forging materials don't count against the core resource storage cap, but each has a max storage = Wealth (WLH) ×5 units.

### Resource Storage Cap

| Dungeon WLH | ◆ Cap | ◇ Cap | ■ Cap | ● Cap |
|:---:|:---:|:---:|:---:|:---:|
| 1-3 | 30 | 15 | 20 | 10 |

## 2.11 Character Creation Flow (Quick Guide)

Creating a Dungeon Lord character takes only seven steps:

### Step 1: Choose Archetype
Pick one of the six archetypes. Each determines your attribute bonuses, core abilities, and playstyle.
> Newbie recommendation: **Abyssal Overlord** (frontal crush, intuitive) or **Ancient Wyrm** (economy build, high fault tolerance).
> Advanced challenge: **Mad Sorcerer** (high-risk high-reward) or **Shadow Council** (intel build, requires foresight).

### Step 2: Allocate Lord Attributes
You have **12 attribute points** to allocate. All five attributes start at 1, raising by 1 costs 1 point.
Archetype bonus stacks after allocation (e.g., Mad Sorcerer Arcana (ARC)+2 → allocate ARC=3+2=5).
- Recommend prioritizing your archetype's main attribute to 4 (reaches 5 after archetype bonus)
- Allocate at least 2 points to DOM (Dominion) — needed for interrogating captives and diplomacy

### Step 3: Allocate Skill Points
You have **6 initial skill points**. Lv0→Lv1 costs 1 point, Lv1→Lv2 costs 1 point.
- Prioritize upgrading archetype-related skills (Necromancer Lord → Ritual Master, Demon → Tactical Command…)
- Allocate at least 1 point to an engineering/construction skill — digging expansion requires it

### Step 5: Configure Starting Dungeon
### Step 4: Record Archetype Abilities
Write down your archetype's passive and active abilities. These are your core combat/management advantages.

### Step 5: Configure Starting Dungeon
All archetypes share a unified starting config:
- Throne Hall Lv1 (free)
- 2 small spaces (undeveloped, need digging)
- Starting monsters per archetype table (3-5)
- Starting resources per archetype table

### Step 6: Record Monsters & Roll Management Abilities
For each starting monster roll d66 to get a random management ability (see §2.7). Mark monster positions on the dungeon layout sketch.

### Step 7: Name & Fill Sheet
Name the dungeon and lord, fill the character sheet. Done!

### Quick Start Suggestions
| What to do on Turn 1 | Suggestion |
|------|------|
| Assign monster posts | At least 1 combat post (defense), rest management posts (produce resources) |
| First dig | Spend 1 action + Building Materials ×2, roll IND + Engineering check, dig first small space |
| First build | Recommend: Trap Workshop (auto-defense) or Mine (steady output) |
| Await invasion | After management phase, roll invasion check (Infamy (INF)+1d6≥8) |

> **Newbie GM Tip**: Lv1 First Incursion uses 2 T1 adventurers (Warrior + Thief), letting players experience the full combat loop without being too hard.

## 2.12 Co-Management Mode (1 GM + 2~4 players)

When multiple players play together, all players **jointly manage the same dungeon**. Each plays a "Abyss Lieutenant" — the Dungeon Lord's right-hand.

### Role Division

| Player Role | Domain | Main Attribute | Per-Turn Exclusive Action |
|------|------|------|------|
| **Chief Lord** | Final decisions, diplomacy, expedition | Dominion (DOM)/Warfare (WAR) | 1 diplomacy/expedition action |
| **Defense Commander** | Combat deployment, monster allocation, trap planning | Warfare (WAR)/Cunning (CUN) | 1 free monster redeploy |
| **Management Steward** | Construction, resource output, captive management | Industry (IND) | Build/upgrade check +1 die |
| **Magic Advisor** | Magic research, rituals, spell prep | Arcana (ARC) | Casting ◇ cost -1 (min 1) |

**Roles optional**: 1~4 players; unchosen role functions are GM-managed or player-covered.

### Decision Mechanism

- **Lord Council**: Before each turn starts, players discuss and decide this turn's strategy (5-min limit)
- **Veto**: Chief Lord has 1 veto per turn, can override any single person's decision
- **Expert Respect**: For checks in a specific domain, the domain owner rolls main, others may assist (+1 die)
- **Tie**: Roll 1d6, odd = maintain status quo, even = Chief Lord decides

### Conflict & Fun

| Mechanic | Effect |
|------|------|
| **Lieutenant Ambition** | Every 3 turns, each lieutenant secretly rolls 1d6. A 6 = that lieutenant proposes a "personal goal" (e.g., "I'll run the interrogation this turn", "I'll deploy the traps myself"). Completing it → +1 EXP reward |
| **Loyalty Test** | If Chief Lord ignores the same lieutenant's advice two turns running, that lieutenant's assist-check dice pool -1 (morale hit) |
| **Joint Ritual** | Ritual checks with multiple participants, +1 die per extra player (cap +3 dice) |

### Multiplayer Combat Operation

- Each lieutenant may personally command 1-2 monsters (directly control their actions)
- Chief Lord controls overall tactics
- Different defense layers may be commanded by different lieutenants

> **Design Intent**: The core of co-management mode is "cooperative decision + role division", avoiding each player going their own way. The Lieutenant Ambition mechanic injects moderate competitive fun into long-term cooperation.

# Chapter Three: Combat & Conflict

## 3.1 Combat Framework

### Turn Structure (six-phase)

```
Phase 0: Preparation Phase — CUN recon check, emergency conscription, pre-battle ritual
Phase 1: Initiative Phase — invader 1d6+Tier mod vs defender 1d6+lord CUN
Phase 2: Action Phase — both sides take unit actions in turns
Phase 3: Environment Phase — trap triggers, ongoing-effect settlement, room effects
Phase 4: Morale Phase — check rout/waiver, monster loyalty check
Phase 5: Advance Phase — invader decides whether to advance to next layer, battle-loss tally
```

### Initiative Rules

- Invader: 1d6 + Tier (T1=+0, T2=+1, T3=+2, T4=+3, T5=+4)
- Defender: 1d6 + [Lord CUN value]
- Initiative side decides to go first or second

### Action Economy

| Action | Per Round | Description |
|------|---------|------|
| Move | 1 | Move to adjacent room |
| Standard Action | 1 | Attack, cast spell, use ability |
| Bonus Action | 1 | Quick ability, switch weapon, command order |
| Reaction | 1 | Opportunity attack, guard, trigger-type ability |

## 3.2 Defense Layer System

Adventurers must break through the dungeon defenses layer by layer. Four escalating layers:

| Layer | Name | Defense Value (DV) | Trap Slots | Monster Slots | Special Slots |
|------|------|-----------|--------|--------|--------|
| Outer | Outer Defense | Defense (DEF)÷2 | 2 | 2 | Scout Outpost |
| Middle | Core Combat Zone | Defense (DEF) | 3 | 3 | Monster Lair / Training Ground |
| Inner | Lord's Domain | Defense (DEF)×1.5 | 1 | 4 | Altar / Research Chamber |
| Core | Throne Chamber | Defense (DEF)×2 | 0 | Unlimited | Throne Hall |

### Breakthrough Mechanic

Adventurers must accumulate damage ≥ current layer's DV to advance to the next layer. After each layer is broken, that layer suffers **permanent damage** — loses traps and some monster lives.

## 3.6 Invasion Generation

### Invasion Trigger Check

> Each turn end roll: Infamy (INF) + 1d6 ≥ 8 triggers invasion

After Infamy (INF) ≥7, invasion every turn (target of all).

### Invasion Construction (GM five-step flow)

1. **Determine trigger**: roll invasion check
2. **Determine source**: roll 1d6 1-2=Adventurers' Guild, 3-4=Order of Light, 5=Royal Investigation Corps, 6=Freelance Hunters
3. **Determine scale & Tier**: dice pool vs INF table
4. **Generate class composition**: roll d6 to determine team mix
5. **Add narrative hook**: roll d6 to determine adventurer motivation

### Adventurer AI Behavior Table (2d6)

| 2d6 | Tactical Behavior |
|-----|---------|
| 2 | Reckless charge — whole team rushes next layer, regardless of cost |
| 3-4 | Scatter search — split to scout multiple rooms |
| 5-6 | Cautious advance — thief scouts traps first |
| 7 | Steady — cleric in middle, warrior guards front and back |
| 8-9 | Fire suppression — mage casts ranged magic to weaken defense |
| 10-11 | Tactical retreat — retreat to last safe layer on disadvantage |

## 3.7 Special Tactical Rules

### Ambush/Sneak Attack

The defender may conduct an ambush in their own dungeon (Cunning (CUN)+Stealth vs adventurer recon). Success grants first-round surprise — enemy whole-team defense dice pool -2, own attack dice pool +2.

### Dungeon Lord Fights in Person

The Lord may personally join any defense-layer battle. See §5.1 "Lord Combat System" (Lord HP, dice pool, action economy, defeat penalty) for details.

### Captive Cannon Fodder

Captives may be driven to the front line as cannon fodder. Captive Combat Value = PL. Each battle captive STA -1. If a captive is knocked down, 1/3 chance of permanent death. Captive escape risk doubled.

### Active Retreat/Scorched Earth Tactics

The defender may choose to abandon a defense layer. On retreat all monsters pull back to the next layer, but adventurers advance to the latter half of that layer. May spend 1 action on scorched earth — destroy all traps in that layer (deal at most 1 trap damage instance to pursuing adventurers).

## 3.8 Magic System

Magic is the Dungeon Lord's second combat-ability system besides combat arts. Combat arts are the "martial way" (physical/hybrid skills costing Bonus Action or ◇), magic is the "arcane way" (pure ARC casting costing ◇ + action). The two may be freely combined.

### 3.8.1 Magic Learning

The Lord does not innately master all spells. Learning new spells requires time, resources, and research.

**Three ways to learn new spells**:

| Way | Condition | Cost | Time |
|------|------|------|:---:|
| **Self-Research** | Research Chamber Lv1+, ARC check vs spell level difficulty | ◇×(spell level ×2) | 1-3 turns |
| **Learn from Captive** | Captive mage (PL≥2), DOM interrogation success reveals known spells | No extra resource | Captive loses that spell's memory |
| **Exchange from Ally** | Relationship with NPC dungeon ≥5, other lord masters the spell | ◆×(spell level ×5) or equivalent trade | Learn immediately |

**Self-Research Check**:

| Spell ◇ Cost | Research Difficulty | Research Time |
|:---:|:---:|:---:|
| 1◇ spell | Standard (2 successes) | 1 turn |
| 2-3◇ spell | Hard (3 successes) | 2 turns |
| 4-5◇ spell | Extreme (4 successes) | 3 turns |
| 6◇ spell | Epic (5 successes) | 3 turns + special condition |

**Spell Slot Cap** (max number of spells learnable):
| Condition | Spell Slots |
|------|:---:|
| Arcana (ARC)≥2 | 2 |
| ARC each +1 | +1 (Arcana (ARC)=5 → total 5) |
| Skill "Ritual Master" Lv1/2/3/4 | each +1 |
| Skill "Cursecraft" Lv3+ | +1 |
| Research Chamber Lv2/3 | each +1 |
| Abyss Lord assistance | +1 legendary spell slot |

**Max Spell Slots**: about 10-12 spells (Lord may selectively learn, not forced to fill).

> The Lord may, before battle, choose up to "Arcana (ARC)+2" spells from learned spells as "prepared spells" for that invasion. Unprepared spells can't be cast in battle. Preparing spells is free in the Preparation Phase.

### 3.8.2 Spell Casting

> Casting dice pool = ARC dice pool + Arcane Knowledge skill dice + Research Chamber bonus

Casting a spell costs 1 Standard Action + ◇ Mana Crystals (varies per spell). Cast range: any room on same layer.

> ▶ Full spell list has been separately compiled in `魔法圖鑑.md`; please refer to it.

### 3.8.4 Archetype Spell Affinity

| Archetype | Affinity School | Bonus | Banned School |
|------|---------|------|---------|
| Necromancer Lord | Summoning/Necro, Curse | Summon spell CP+1 | Defense-school spell effect halved |
| Abyssal Overlord | Destruction, Defense | Destruction damage +1 | Summoning/Necro unusable |
| Mad Sorcerer | All schools (incl. transformation) | Casting check +1 die, but spell has 1/12 chance of random extra effect | None |
| Ancient Wyrm | Destruction (dragon-breath related), Utility | Destruction may choose one of fire/ice/acid/electric four elements | Summoning/Necro unusable |
| Shadow Council | Curse, Utility (illusion/whisper), Transformation | Curse duration +1 turn | Destruction damage -1 |
| Goblin Tinkerer | Utility (identify/portal/repair) | Utility ◇ cost -1 (min 1) | Destruction/Summon/Necro/Transformation unusable (use combat arts instead) |

### 3.8.5 Enchantment Spells (Seventh School)

Enchantment spells are the magic school of permanently infusing Abyssal mana into equipment or creatures — unlike combat spells, enchantment effects are **permanent or long-lasting**, cast in the management phase rather than combat rounds.

| Spell | ◇ | Level | Effect |
|------|:---:|:---:|------|
| **Basic Enchant** | 2 | Arcana (ARC)≥2 | Apply 1 basic enchant to 1 equipment (Sharp/Tough/Light). Requires Forge Lv1. Permanent |
| **Elemental Infusion** | 4+●1 | Arcana (ARC)≥3 | Apply 1 elemental enchant to 1 equipment (Flame/Frost/Lightning/Dark Erosion/Holy Light Resistance). Requires Arcane Workshop synergy. Permanent |
| **Creature Enhancement** | 3 | Arcana (ARC)≥3 | Apply 1 creature enchant to 1 monster (Enchanted Skin/Shadow Affinity/Loyalty Mark). No equipment slot used. Permanent |
| **Advanced Enchant** | 5+●2 | Arcana (ARC)≥4 | Apply 1 enhancement enchant to 1 equipment (Vampiric/Indestructible/Regeneration). Requires Forge Lv2+. Permanent |
| **Mass Elemental Infusion** | 8+●3 | Arcana (ARC)≥5 | Apply Elemental Bloodline enchant to up to 3 monsters on same layer simultaneously. Requires Forge Lv3 + Research Chamber Lv3. Permanent |
| **Legendary Enchant** | 10+●5 | Arcana (ARC)=5+ Legendary | Apply 2 enchants to 1 Lord's Armament simultaneously (chosen combo). Requires Arcane Workshop + Altar Lv3. Once per campaign |

**Enchantment Spell Special Rules**:
- Enchantment spell cast time = 1 full management turn (not a combat round)
- Enchantment spells can't be used in combat — combat has dedicated enhancement spells (see Transformation/Enhancement school)
- Enchant scrolls can be bought at the Abyss Black Market (price = ◇ cost ×3 in Dark Coins)
- Mad Sorcerer's enchant check has 1/12 chance of "unexpected enchant" — randomly gains 1 GM-secret-rolled hidden effect (blessing or curse)

## 3.10 Ritual System

Rituals are grander, more time-consuming magic acts than spells. Spells are cast in combat rounds (seconds), rituals are executed in the management phase (hours to turns).

### Ritual Types

| Ritual | Requirement | Duration | Cost | Effect |
|------|------|:---:|------|------|
| **Sacrifice Ritual** | Altar Lv1 | 1 turn | ●×3 + 1 captive (WIL zeroed) | ARC check, each success = dungeon MAG temporary +1 (lasts 3 turns) |
| **Enhancement Ritual** | Altar Lv1 | 1 turn | ◇×5 | Choose 1 monster, its CP or MV permanent +1 (cap 3 times each) |
| **Curse Ritual** | Altar Lv2 | 2 turns | ◇×8+●×5 | Apply army-wide curse to next invasion's adventurers — all checks -1 die (lasts whole invasion) |
| **Great Summoning Ritual** | Altar Lv2 | 3 turns | ◇×10+●×8 | ARC check, each success summons 1 random elite monster (Loyalty (LOY)=3). Kept after battle |
| **Dungeon Blessing** | Altar Lv3 | 3 turns | ◇×15+●×10 | All-dungeon check +1 die, monster LOY+1, captive escape -2 dice. Lasts 5 turns |
| **Ultimate Ritual** | Altar Lv3 | 5 turns | ◇×25+●×20 | See archetype-specific ultimate ritual table (below). Once per campaign |

### Ritual Check

Rituals use the `Arcana (ARC) + Ritual Master skill` dice pool. Some rituals allow multiple assistants (each +1 die, cap +3 dice).

A ritual's "Net Successes" determines effect strength, not success/failure — rituals don't fail (resources already spent), but low successes = reduced effect.

| Net Successes | Ritual Effect |
|:---:|------|
| 0 | Minimum effect — only 50% efficacy |
| 1-2 | Standard effect — per table |
| 3+ | Enhanced effect — effect ×1.5 or extra benefit |

### Archetype-Specific Ultimate Rituals

| Archetype | Ultimate Ritual | Effect |
|------|---------|------|
| Necromancer Lord | **Undead Legion** | Summon CP1 skeleton ×ARC value (permanently kept, free upkeep) |
| Abyssal Overlord | **Abyssal Rift** | Dungeon gains permanent demon gate — each battle can additionally summon 1 demon minion |
| Mad Sorcerer | **Reality Warp** | Own ARC permanent +1 (can break cap to 6); but gains a permanent random negative mutation |
| Ancient Wyrm | **Dragon Nest Awakening** | All vault Dark Coins doubled; vault interest permanent +0.5× |
| Shadow Council | **Shadow Network** | Permanently know intel of all neighboring dungeons; Assassination Order usable on any target |
| Goblin Tinkerer | **Doomsday Device** | Spend ■×20+◇×10, build one-time Doomsday Device — can destroy entire invasion wave (after use device fails, needs rebuild) |

> The Ultimate Ritual is a campaign-level investment — recommended at Lv12+, facing the Light Crusade.

# Chapter Four: World & Narrative

## 4.1 Worldview Setting

### Core Flip

In this world, **dungeons are not monster lairs, but the kingdoms of Dungeon Lords**; **adventurers are not heroes, but invaders and plunderers**. This ruleset redefines classic fantasy from the dungeon's perspective.

### Creation Myth

The world was born from the conflict of two primordial deities — **Aoth** (God of Light) and **Nexis** (Mother of the Abyss). Aoth created the surface's Realms of Light; Nexis was banished to the deep underground. Nexis's blood seeped into the rock, becoming the first source of mana; her bones became the underground mountain ranges; her thought-fragments became the first Abyssal consciousness.

The first dungeon was Nexis's tomb, and the gateway to the Abyss. After her banishment, the world's rifts gradually widened, and more lords rose from the Abyss.

### World Geography: Two-Layer Structure

**Surface World**:
- **Kingdom of Dawn**: The strongest surface kingdom, headquarters of the Order of Light
- **Silver Federation**: Commercial federation, financier of the Adventurers' Guild
- **The Holy See**: Religious nation, fanatical crusade organization

**Underworld**:
- **Sea of Shadows**: A labyrinth of tangled tunnels, traditional territory of Shadow Council and Necromancer Lords
- **Magma Plains**: The scorching kingdom of the Abyssal Overlord
- **Gloom Forest**: An eerie subsurface ecological zone, the Mad Sorcerer's laboratory
- **Scrap Canyon**: Ancient dwarven ruins, paradise of the Goblin Tinkerer
- **Abyssal Core**: The deepest primordial mana sea, said to be where Nexis sleeps

### Historical Timeline

| Era | Event |
|------|------|
| Genesis Era | War of Aoth and Nexis, Nexis banished |
| 500 years before Rift Era | Archmage Modiras invents the "Conversion Method" — can convert defeated adventurers into Abyssal minions |
| 200 years before Rift Era | Edwin — leader of the Radiant Paladin Order — falls into an Abyss Lord, shocking the light world |
| 50 years before Rift Era | Lord Wars — large-scale civil war between dungeons |
| **Year 700 of Rift Era (now)** | The era the players inhabit — light forces grow ever stronger, adventurer invasions ever more frequent |

## 4.4 GM Running Guide

### The GM's Five Roles

1. **Adventurer Commander**: Control invading adventurer squads
2. **World Engine**: Drive seasons, weather, world events
3. **NPC Voice**: Play captives, dark merchants, neighboring dungeon lords
4. **Rule Judge**: Determine difficulty, arbitrate disputes
5. **Narrative Pacing Master**: Balance management and combat rhythm

### Invasion Construction Six-Step Flow

1. **Invasion Check**: Infamy (INF) + 1d6 ≥ 8 triggers
2. **Invasion Source**: 1d6 determines which faction it comes from
3. **Scale & Tier**: vs INF→Tier mapping table, roll d6 for squad size
4. **Class Composition**: roll d6: 1-2=mixed, 3=physical-leaning, 4=magic-leaning, 5=scout-leaning, 6=all cleric (Order)
5. **Narrative Hook**: 1d6: 1=revenge, 2=rescue, 3=treasure hunt, 4=ordered, 5=trial, 6=lost
6. **Special Event Check**: 1/6 chance of extra special event (weather effect, extra reinforcements, temporary ally)

### Pacing Control

**Management Phase** (dungeon calm period):
- Opening: "Another peaceful Abyssal week…" depict dungeon daily life
- Duration: 10-20 min, let players fully discuss and decide
- End signal: when players start hesitating repeatedly, roll invasion check to push pace

**Invasion Phase** (combat tension period):
- Opening: "The Scout Outpost reports movement — someone's come down from the surface again"
- Duration: 15-30 min, layer-by-layer advance builds escalating tension
- End signal: after last layer broken or adventurers retreat, enter settlement

### Real-Time Difficulty Adjustment

| Method | Direction | Applicable |
|------|------|---------|
| Adjust squad size | ±1-2 people | Fine-tune |
| Leak intel early | Lower difficulty | When player intel insufficient |
| Hide intel | Raise difficulty | When player too comfortable |
| Weather/environment mod | ±dice | Add variables |
| Insert Boss mid-way | Raise difficulty | Need climax |

### Captive Narrative Toolbox

**3d6 Captive Background Quick Table**:

| Origin (1d6) | Motivation (1d6) | Secret (1d6) |
|-----------|----------|-----------|
| 1=farmkid | 1=saving for sister's medicine | 1=actually noble bastard |
| 2=city poor | 2=prove oneself | 2=carries old lover's letter |
| 3=fallen noble | 3=repay debt | 3=afraid of darkness (claustrophobia) |
| 4=orphanage raised | 4=follow idol | 4=first mission |
| 5=merchant family | 5=escape past | 5=knows Guild high-level secret |
| 6=adventurer family | 6=find missing kin | 6=actually Abyssal bloodline |

**Conversion Narrative Four Stages**:
1. **Resistance**: "I'd rather die than work for you!"
2. **Wavering**: "At least… it's more honest here than up there. Nobody pretends to be good."
3. **Adapting**: "Yesterday I fixed the third-corridor trap, more efficient than that Guild bunch."
4. **Converted**: "My lord, there's a familiar face among the new adventurers — shall I 'renew acquaintance'?"

## 4.6 Starter Module: "First Incursion"

### Scene 1: Establishing the Initial Dungeon

GM narration:
> "You are a newly ascended Dungeon Lord. The mana torches of your Throne Hall are already lit — this is your first dungeon. For now there are only three chambers: your Throne Hall, and the ends of two undeveloped, pitch-black tunnels. A few freshly recruited monsters prowl restlessly at your feet. From afar comes the faint sound of surface humans — are they coming?"

Players need: Familiarize with attributes, assign starting monsters, plan which side to dig first.

### Scene 2: First Dig & Expansion

The player spends 1 action + Building Materials ×2, rolls IND + Engineering check for the first dig. GM guides the exploration-discovery narration — may stumble onto a vein, or find a broken diary inside an ancient ruin.

### Scene 3: First Wave of Invasion

Warning: Scout skill check reveals "2 T1 adventurers approaching".

Preset adventurers:
- **Allen ** (Warrior T1): CP=1d6, HP=5, shield, "Loyal and simple, saving for sister's medicine"
- **Mira ** (Thief T1): Combat Value (CP)=2d6, HP=3, can scout traps, "Impatient and reckless, wants to prove herself"

Invasion route: Outer Layer → Middle Layer. Player commands defense.

### Scene 4: First Captive & Interrogation

If adventurers defeated (HP to 0 = unconscious): may capture. GM introduces interrogation-mechanic tutorial — let player choose method (Interrogation? Torture? Charm?). Allen's weakness: "Eyes flicker when his sister is mentioned".

### Scene 5: Post-Battle Settlement & Second Expansion

Distribute loot, use gained resources for second dig. First experience of the full "Dig → Build → Assign → Defend" loop.

## 4.7 Campaign Framework: From Cavern to Abyss Empire (Lv1-15)

### Act One: Establishment (Lv1-3) — 2~4 sessions

**Theme**: Survive. A newly enthroned Dungeon Lord starts from the Throne Hall + 2 pitch-black tunnels. The outside is unknown — every sound of digging may draw the first adventurers.

| Dungeon Lv | Key Event | GM Focus |
|:---:|------|------|
| 1 | **First Incursion** (see §4.6). Repel 2 T1 adventurers, first taste of defense combat | Teaching battle. Let players familiarize with combat phases, trap triggers, monster deployment |
| 2 | First dig expansion succeeds. Discover the first natural resource (Vein / Mana Node). Neighboring NPC dungeon appears for the first time — a letter arrives at your Throne Hall | Introduce expansion system. Introduce diplomacy concept (reply to the letter or not?) |
| 3 | **"The Adventurers' Guild has noticed you"**. Two consecutive turns of invasion — the second wave is a revenge squad (led by the adventurer who escaped last time). Must decide: strengthen defense or accelerate expansion? | Introduce continuous invasion pressure. Player must make strategic trade-offs |

**Act One Climax**: "Adventurers' Guild Wanted" — after INF reaches 3, the Guild officially places your dungeon on the "Wanted List". GM introduces a physical wanted poster (printable prop).

---

### Act Two: Growth (Lv4-7) — 3~6 sessions

**Theme**: Expansion and choice. The dungeon takes shape. The Abyss Embassy is built — you must choose one of the Four Alliances to join. The choice will affect all later diplomacy.

| Dungeon Lv | Key Event | GM Focus |
|:---:|------|------|
| 4 | Can build the Abyss Embassy. Two known NPC dungeons each invite you to join their alliance. **Balzec, "Earth-Render"**'s flame missive vs **Marquis Malthus**'s bone dove. Must choose — or stay neutral | Alliance choice. This affects all subsequent diplomacy |
| 5 | Unlock elite monster recruitment. First elite invasion (T3, includes Boss captain). If allied before — allied dungeon may proactively send reinforcements | Boss battle mechanic introduced (Phase 2 trigger). First allied-coordination experience |
| 6 | Archetype Lv6 advancement unlocked. After the dungeon reaches a certain size — first discovery that conflicts exist between other dungeons. **Moris, "Thousand-Faces"** asks you to mediate his territorial dispute with Balzec | Inter-dungeon politics. Player's choice affects the tripartite relationship |

**Act Two Climax**: "Abyss Black Market" — **Grix, "Goldtooth"** (Ancient Wyrm) hosts the annual black market auction in the Scrap Canyon. All known NPC dungeon lords attend. Player may: socialize face-to-face with multiple lords / bid on 1 legendary item (starting bid at least ◆50) / experience an assassination event after the auction — Shadow Network intel trade.

---

### Act Three: Threat (Lv8-11) — 4~8 sessions

**Theme**: War and betrayal. The dungeon becomes a regional power. The Order of Light begins organizing large-scale expeditions — no longer adventurer squads, but company-level offensives.

| Dungeon Lv | Key Event | GM Focus |
|:---:|------|------|
| 8 | **"The Order's Expedition"** — the Order of Light dispatches 3-4 T3 squads invading simultaneously from different entrances! Must call on allied reinforcements. Dungeon diplomacy check determines how many NPC dungeons are willing to send troops | First large-scale multi-front defense. Tests the player's resource allocation and diplomatic results |
| 9 | Archetype Lv9 ultimate advancement unlocked. Around this time — cracks appear within your alliance. Bone Mound Council: is Malthus being challenged? Abyssal Legion: does Balzec demand you join the flame trial? Free Artificers: tech-piracy dispute? Shadow Network: traitor leaking intel? | Intra-alliance politics. Player's reaction determines the alliance's direction |
| 10 | Unlock the first legendary monster. **Moris, "Thousand-Faces"**'s forbidden experiment suffers a serious accident — his dungeon is spiraling out of control. If you were friendly with him — he sends you a desperate distress signal | Time-sensitive side quest. Rescue / exploit / ignore — three choices affecting the whole picture |

**Act Three Climax**: "Breath of Nexis" — abnormal fluctuations in the Abyssal mana tide. **Ethlin** (Void-Weaver) warns: the mana tide may be a premonition of "something" awakening. GM here introduces the first anomaly of the **Primordial Rift (D-16)** — it made a sound. The ancient dungeon begins to awaken.

---

### Act Four: Overlord (Lv12-15) — 6+ sessions

**Theme**: Fateful choice. Your dungeon has become a top-tier Abyssal power. The Order of Light prepares a "Crusade" — a full-scale assault on the Abyss. And the sleeping entity in the **Primordial Rift** is about to wake.

| Dungeon Lv | Key Event | GM Focus |
|:---:|------|------|
| 12 | **"The Dungeon Covenant"** — you convene (or are invited to) the Abyssal Council. All Lv8+ dungeon lords gather. Topic: unite against the Order of Light, or each fight alone? Your diplomacy check determines the strength of the united front | Multi-NPC diplomatic negotiation. This is a complete social encounter scene |
| 13 | **"The Light Crusade"** begins. T4–T5 adventurer legions attack all allied dungeons simultaneously. The forces assigned to your dungeon are determined by INF — high Infamy attracts the strongest enemies | Ultimate defense battle. Use all accumulated resources, monsters, allies, captive cannon fodder |
| 14 | Crusade continues. If defense succeeded last turn — adventurers suffer heavy losses but the Order's reinforcements keep coming. ## 5.1 Lord Combat System

The Dungeon Lord is no weakling hiding in the Throne Hall issuing orders. The Lord can fight in person, leave the dungeon on expedition, and clash with other dungeons.

### 5.1.1 Lord Combat Attributes

**Lord HP**: `(Dominion (DOM) + Warfare (WAR) × 2 + Dungeon Level)`

| Stage | Typical Attributes | HP Example | Description |
|------|---------|--------|------|
| Lv1 New Lord | Dominion (DOM)2+Warfare (WAR)2 | 9 | Can take 2-3 medium hits |
| Lv5 Growing Lord | Dominion (DOM)3+Warfare (WAR)3 | 17 | Can frontally engage T3 adventurers |
| Lv9 Abyss Lord | Dominion (DOM)4+Warfare (WAR)4 | 25 | Holds the inner layer alone |
| Lv15 Legendary Overlord | Dominion (DOM)5+Warfare (WAR)5 | 35 | Can trade blows with legendary adventurer Boss |

**Lord Defense Dice Pool** (three stances selectable, + Dungeon Level÷3 growth bonus):

| Defense Stance | Dice Pool Composition | Applicable Scene |
|---------|---------|---------|
| Will Shield (default) | DOM dice pool + Dungeon Level÷3 | Spell-type lord, forms invisible barrier with Abyssal majesty |
| Evade/Block | WAR dice pool + Dungeon Level÷3 | Warfare-type lord, combat-experience dodge |
| Magic Barrier | ARC dice pool + Dungeon Level÷3 | Mana-type lord, arcane energy shield |

**Lord Attack Dice Pool**:

| Attack Type | Dice Pool | Applicable Archetype |
|---------|------|---------|
| Physical attack | WAR dice pool | Abyssal Overlord, Ancient Wyrm (melee) |
| Magic attack | ARC dice pool | Necromancer Lord, Mad Sorcerer, Ancient Wyrm (dragon breath) |
| Engineering attack | IND dice pool | Goblin Tinkerer |
| Cunning attack | CUN dice pool | Shadow Council |

**HP Recovery**: Resting in Throne Hall recovers `Dominion (DOM) + Dungeon Level` HP/turn.

### 5.1.2 Lord Deployment Rules

The Lord may, in Phase 0 (Preparation Phase), spend 1 action to deploy to any defense layer:

| Deployed Layer | Lord Bonus | Throne Hall Penalty |
|--------|---------|-----------|
| Core Layer | All-attribute check +2 dice (ultimate home field) | None |
| Inner Layer | Arcana (ARC)/DOM check +1 die (home-field advantage) | — |
| Middle Layer | Monster Lair / Training Ground synergy bonus | Throne Hall DEF to zero |
| Outer Layer | Scout Outpost warning info real-time synced | Throne Hall DEF to zero, all-dungeon check -1 die |

**"Lord Present" Bonus**: Same-layer monster LOY+1, same-layer monster morale won't rout in combat, enemy adventurer morale -1, may use Reaction guard on adjacent monsters.

### 5.1.3 Lord Combat Actions

The Lord uses the same action economy as monsters in combat (Move + Standard + Bonus + Reaction):

| Action Type | Lord-Specific Options |
|---------|------------|
| **Standard Action** | Normal attack, cast combat art, use archetype active ability, command monster (forgo attack to give same-layer monster +1 die and act immediately) |
| **Bonus Action** | Switch attack dice pool, brief command (monster move +1 room), quick combat art, mana charge (1●→1◇/ once per battle) |
| **Reaction** | Guard adjacent monster, interrupt adventurer casting (ARC contest), opportunity attack, dark counter (after being hit spend 1◇ magic counter) |
| **Move** | Any room on same layer |

### 5.1.4 Lord Defeated — Banishment

When Lord HP hits zero they are **not killed** (Abyss Lords are undying), but banished back to the Throne Hall:

| Stage | Effect |
|------|------|
| Banishment Blast | All adjacent units take DOM dice pool damage (friendly halved) |
| Soul Repatriation | Teleport back to Throne Hall, 1d3 turns to reform flesh (cannot act/use abilities) |
| All-Dungeon Penalty | All checks Disadvantage -3 (remove highest 3 dice) ×2 turns, all monster LOY -1, all archetype abilities disabled |
| Resource Loss | Lose current Dark Coins 20%, that wave of adventurers gains extra +3 Experience Point (EXP) |

Consecutive banishment (defeated again in same invasion): Disadvantage escalates to -5 ×3 turns, LOY another -1, recovery speed halved.

## 5.3 Duel Mechanic

When an adventurer Boss (Phase 2+) and the Lord are on the same layer, the Boss challenges the Lord to a duel.

### Duel Three Stages

```
A. Standoff → DOM contest (Lord vs Boss Will dice pool), winner's next-turn attack +1 die
B. Clash → both roll attack vs defense, damage = Net Successes (pure skill, no weapon bonus)
C. Settlement → HP≤0 ends, or choose continue/retreat
```

### Victory/Defeat Effects

| Lord Defeats Boss | Boss Defeats Lord |
|-------------|------------|
| All enemy morale -2, immediate rout check | Lord banished to Throne Hall (see §5.1.4) |
| Boss capture chance +30%, Will (WIL)-1 | All-dungeon penalty + monster LOY-2 |
| Infamy (INF)+1 | Dungeon intel leaked, next invasion AI upgraded |
| Lord recovers 1d6 HP | Boss morale +2 |
