## (d) Character Name Convention
Character / NPC names are **already given in romanized Western form inside the CN source** (e.g., 馬爾薩斯 → Malthus, 艾德溫 → Edwin, 瑟拉希爾 → Selathil). Use EXACTLY the romanization present in the CN text. Do NOT invent new English names. Where only Chinese appears, romanize per standard pinyin (surname-first) and keep the Chinese alongside on first mention. Chinese designer/world-architect names (e.g., 景世雯) likewise keep pinyin romanization.

---

## (e) Path & Format Conventions (MANDATORY)
- **Filename/path references** (any string ending in `.md` / `.yaml` / `.svg` / `.xlsx` / `.pdf`) are kept in their ORIGINAL CHINESE — do NOT translate them. Example: reference `assets/深淵領主_玩家規則書.md` stays exactly as-is; only the human-readable link text or description around it may be English.
- **"English Full Name (ABBR)" format rule**: On first mention of any stat/term, write the English full name followed by its abbreviation in parentheses, e.g., Health Points (HP), Combat Value (CV), Management Value (MV), Difficulty Class (DC), Margin of Success (MoS), Willpower (WIL), Stamina (STA), Profession Level (PL). After first mention, the abbreviation alone may be used.
- Attribute dice notation: write as `詭計(CUN)`, `威儀(DOM)`, `魔力(ARC)`, `匠造(IND)`, `戰策(WAR)`; dungeon attributes as `深度(DEP)`, `惡名(INF)`, `防禦(DEF)`, `財富(WLH)`, `魔力(MAG)`. Keep the Chinese character + (ABBR) pairing where the source uses it.
