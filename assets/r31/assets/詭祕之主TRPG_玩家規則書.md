# 第一章：核心規則

## 1.1 骰子基礎

本系統使用 **d100 百分骰（roll-under）**。投擲 1d100，若出目 ≤ 目標值（TN），則檢定成功。

| 術語 | 縮寫 | 定義 |
|------|------|------|
| 目標值 | TN | 檢定需 ≤ 的數值，通常爲屬性值或屬性+技能值 |
| 難度修正 | DC | 對 TN 的加減修正，如困難(−20)、極難(−40) |
| 優勢 | Adv | 雙骰取低，概率大幅提升 |
| 劣勢 | Dis | 雙骰取高，概率大幅壓低 |
| 大成功 | Crit | 出目 ≤ 5，必定成功且效果增強 |
| 大失敗 | Fumble | 出目 ≥ 96，必定失敗且附帶負面後果 |
| 靈性池 | SP | 使用非凡能力的能量資源 |
| 失控值 | LoC | 累積的非凡污染度量 |
| 失控閾值 | LoCT | 心智×2+10 |

## 1.2 五大屬性

| 屬性 | 含義 | 影響範圍 |
|------|------|----------|
| **靈性 (SPI)** | 非凡能力的燃料、靈感 | 靈性池大小、占卜/靈視/儀式檢定 |
| **心智 (MND)** | 理性、邏輯、記憶 | 失控閾值、知識檢定、抵抗精神影響 |
| **體魄 (BOD)** | 身體強度、耐力 | HP、抵抗毒素/疾病 |
| **身手 (AGI)** | 敏捷、協調、戰鬥 | 近戰/射擊、潛行、先攻、閃避 |
| **風度 (CHA)** | 魅力、社交、表演 | 交涉/欺騙、僞裝、維持「表層生活」 |

### 起始屬性分配

- 每項屬性基礎值 **30**，獲得 **50 點自由分配**
- 單屬性上限 80，下限 30
- 總和：30×5 + 50 = 200

## 1.4 難度階梯

| 難度 | 修正 | 說明 | 屬性50的成功率 |
|------|------|------|---------------|
| 常規 | ±0 | 日常行動 | 50% |
| 困難 | −20 | 專業技巧、時間壓力 | 30% |
| 極難 | −40 | 極端環境 | 10% |
| 傳奇 | −60 | 超越人類極限 | 0%（需技能加成） |

- 修正直接加減到目標值。下限 1，上限 95。
- 多個修正疊加（如困難−20+黑暗中−20 = 極難等效−40）

## 1.5 大成功與大失敗

- **大成功**：出目 ≤ 5，必定成功且效果增強（傷害翻倍、額外信息等）
- **大失敗**：出目 ≥ 96，必定失敗且附帶負面後果（武器卡殼、失控值+1d3等）

---

## 1.6 優勢與劣勢

**優勢**：投 2d100 取低 | **劣勢**：投 2d100 取高

### 優勢觸發條件
1. 靈性充沛（靈性池 ≥ 75%）
2. 充分準備（花至少 10 分鐘）
3. 隊友協助（關聯技能 TN ≥ 40）
4. 目標暴露弱點
5. 正確的神祕學環境

### 劣勢觸發條件
1. **耳語階段**：失控值達閾值 50-75%，所有心智檢定劣勢
2. 倉促行動
3. 恐懼/魅惑狀態
4. 靈性枯竭（靈性池 < 25%）
5. 環境干擾

同時擁有優劣勢則抵消，投正常 1d100。

| TN | 正常 | 優勢 | 劣勢 |
|----|------|------|------|
| 30 | 30% | 51% | 9% |
| 50 | 50% | 75% | 25% |
| 70 | 70% | 91% | 49% |

## 1.7 對抗檢定

雙方各投 1d100，比較成功等級：

1. 大成功（≤5） > 普通成功（≤TN） > 失敗 > 大失敗（≥96）
2. 同等級比成功度（TN−出目），大者勝
3. 完全相同則防禦方/被動方獲勝

## 1.8 靈性池

**最大值 = 靈性 × 3 + 5**

### 消耗基準

| 能力層級 | 屬途徑消耗 | 不屬途徑消耗 | 適用範圍 |
|----------|-----------|------------|----------|
| 戲法/低階 | 1-3點 | 3-5點 | 序列9-8 |
| 初階 | 5-8點 | 7-10點 | 序列7-6 |
| 中階 | 10-15點 | 15-20點 | 序列5-4 |
| 高階 | 18-25點 | 25-35點 | 序列3-2 |

> "屬途徑"：使用自身途徑能力，消耗降低約 30%。

### 靈性恢復

| 方式 | 恢復量 | 限制 |
|------|--------|------|
| 完整休息（8小時） | 靈性×2 | 每晚一次 |
| 短暫冥想（1小時） | 靈性×0.5 | 每天最多兩次 |
| 序列晉昇 | 立即回滿 | 一次性 |

**靈性枯竭**：靈性池歸零後，靈性關聯檢定劣勢，無法使用非凡能力。

## 1.9 失控系統

### 失控值累積

| 觸發事件 | 失控值 |
|----------|--------|
| 使用不屬途徑非凡能力 | +1d3 |
| 使用屬途徑非凡能力 | +1 |
| 靈性池完全枯竭 | +2d5 |
| 大失敗（任意檢定） | +1d3 |
| 目睹神話生物形態 | +1d10+5 |

### 失控四階段

| 階段 | 範圍 | 效果 |
|------|------|------|
| **穩定** | < 50% 閾值 | 正常，安全可控 |
| **耳語** | 50%-75% 閾值 | 腦中低語，**所有心智檢定劣勢** |
| **異變** | 75%-100% 閾值 | 耳語 + **風度檢定劣勢** + 身體出現異變特徵 |
| **失控邊緣** | ≥ 100% 閾值 | 每次使用非凡能力前須擲**失控檢定** |

### 失控檢定

當 LoC ≥ LoCT 時，每次使用非凡能力前：**擲 d100 ≤ 心智**（純屬性，無技能加成）

- **成功**：能力正常，失控值+2
- **失敗**：完全失控——GM 接管 1d6 回合，靈性池歸零，永久損失 1 點心智

### 失控值消退

| 方式 | 消退 |
|------|------|
| 完整休息（不用能力） | −5 |
| 完成扮演核心行爲 | −3 |
| 接受心理治療 | −5 |
| 序列晉昇 | 減半 |

# 第三章：戰鬥規則

## 3.1 回合結構

```
┌──────────────────────────────────┐
│         战 斗 回 合               │
├──────────────────────────────────┤
│ 1. 宣言阶段：GM描述局势，宣告意图    │
├──────────────────────────────────┤
│ 2. 行动阶段：按先攻顺序，每角色3AP   │
├──────────────────────────────────┤
│ 3. 结算阶段：持续伤害、失控检定、环境  │
└──────────────────────────────────┘
```

### 先攻

**先攻 = 身手 + d10**（戰鬥開始時擲一次），從高到低行動。突襲者第一回合先攻+5。

### 3AP 動作經濟

**標準行動（1AP）：**
- 攻擊：使用武器攻擊
- 使用非凡能力：施展消耗1AP的非凡能力
- 換彈：左輪6發/1AP；步槍1發/2AP
- 使用物品：喝藥水、投擲物品
- 急救：d100 ≤ 體魄，恢復1d6 HP（每場每目標1次）
- 準備動作：設定觸發條件，本回合觸發時執行

**移動行動（1AP）：**
- 標準移動：至多10m
- 衝刺：至多20m，但對你攻擊+10命中
- 匍匐/起身

**快速行動（0AP，每回合限1次）：**
- 拔/收武器
- 簡短指令（10字以內）
- 觀察：快速掃描戰場

**反應行動（消耗下回合AP，每回合最多2AP）：**
- 閃避：被命中時 d100 ≤ 身手，完全避開
- 格擋：被近戰命中時 d100 ≤ 身手+武器技能，傷害減半
- 藉機攻擊：敵人從近戰範圍移開時
- 掩護：替相鄰隊友承受傷害

## 3.2 攻擊與傷害

### 攻擊檢定

**d100 ≤ (身手 + 武器技能加成 − 護甲防禦 − 掩體修正)**

武器技能：未受訓+0 / 基礎+10 / 熟練+20 / 精通+30 / 大師+40

防禦來源：護甲防禦(+1~+10)、盾牌(+1~+5)、掩體(半掩−15/全掩−25)、倒地(遠程−10)、近距離火器(<3m)+10

> 反應閃避（消耗AP）：被命中時擲 d100 ≤ 身手，成功則完全避開。格擋僅限近戰。閃避和格擋每回合各限1次。

### 傷害公式

- **近戰**：武器基礎骰 + 體魄修正（體魄/5，向下取整）
- **遠程**：武器基礎骰

| 近戰類型 | 基礎傷害 | 示例 |
|----------|----------|------|
| 輕型 | 1d8 + 體魄修正 | 匕首、短棍 |
| 中型 | 2d6 + 體魄修正 | 長劍、軍刀 |
| 重型 | 2d8 + 體魄修正 | 雙手劍、戰錘 |
| 徒手 | 1d4 + 體魄修正 | 拳腳 |

### 傷害類型

| 類型 | 特效 |
|------|------|
| 斬擊 | 可造成流血 |
| 穿刺 | 對無甲+2 |
| 鈍擊 | 對重甲不減半 |
| 光 | 對黑暗×2 |
| 暗 | 附加詛咒 |
| 火 | 附加燃燒 |
| 雷 | 對金屬甲+1d6 |
| 精神 | 無視物理護甲 |

**抗性**：免疫（完全不受）/ 高抗（減半）/ 低抗（-2）/ 弱點（×1.5）

### 瀕死與治療

**HP ≤ 0 → 瀕死**：每回合 d100 ≤ 體魄 穩定；失敗 HP 繼續−1d6；大失敗立即死亡。HP 降至 −(體魄×2) 時死亡。

**治療**：急救（1AP/恢復1d6/每場1次）、包紮（戰後/體魄修正×2）、完整休息（1天/體魄×2）。

# 第四章：調查與線索

## 4.1 線索等級

| 等級 | 能否錯過 | 獲取方式 |
|------|---------|---------|
| **核心線索** | ❌ 不可錯過 | 自動發現（只要你調查了正確位置） |
| **關鍵線索** | ⚠️ 可能不完整 | 檢定成功→完整；失敗→部分信息 |
| **輔助線索** | ✅ 可錯過 | 檢定成功+特定條件 |
| **誤導線索** | ❌ 不可錯過 | 自動發現（但可被識破） |

## 4.2 調查流程

1. GM 描述現場（只包含表面信息）
2. 玩家宣告調查方式（"我用觀察檢查書桌"）
3. 核心/誤導線索自動獲得；關鍵/輔助線索擲檢定
4. 每個場景每人最多 3 次獨立調查檢定

## 4.3 推理檢定

收集 3+ 條線索後可嘗試：**d100 ≤ 心智+調查 − 線索數量×5**

- 大成功：GM 必須揭示所有線索之間的真實聯繫
- 成功：GM 指出正確方向 + 一個仍缺失的信息
- 失敗：正確方向摻入一條誤導
- 大失敗：玩家確信一個錯誤結論

## 4.4 不同途徑的調查加成

# 快速入門（5分鐘版）

- **擲骰子**：d100，比目標值小就成功。≤5=大成功。≥96=大失敗。
- **5個屬性**：靈性(魔法值)、心智(理智)、體魄(血量)、身手(戰鬥)、風度(社交)

- **戰鬥**：每回合 3AP。攻擊/能力/移動/閃避（反應）
- **最重要的**：扮演你的角色。做符合角色的決定——不是"最優解"。
