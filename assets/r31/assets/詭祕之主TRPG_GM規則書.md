### 遭遇預算（4-5名序列9玩家）

| 難度 | 總CR | 資源消耗 |
|------|------|---------|
| 簡單 | 3-4 | 10-20%靈性 |
| 普通 | 5-7 | 30-40%靈性 |
| 困難 | 8-10 | 50-70%靈性 |
| 致命 | 11-14 | 接近耗盡，高死亡風險 |

> CR疊加：多個低CR敵人總CR = 單個CR × 數量 × 0.7

### 構築原則

1. **多樣性**：每場至少2-3種敵人（前排/後排/控制）
2. **環境敘事**：煤氣燈（可打破引發火焰）、廢棄工廠（定時機械傷害）、教堂/墓園（途徑加成/削弱）、靈界裂隙（失控加速）
3. **失控變量**：不穩定封印物、敵方可能先失控、環境低語
4. **非戰鬥目標**：回收封印物、保護凡人、突破封鎖、阻止災難
5. **彈性調節**：援軍(d6回合)、敵人內訌、環境突變(濃霧/爆炸)、第三方介入

## 1.2 戰鬥中失控管理

### 失控值觸發（戰鬥中）

| 觸發 | 失控值 | 頻率 |
|------|--------|------|
| 單場景靈性消耗超50% | +1 | 每場景1次 |
| 靈性池耗盡後強行用能力 | +3 | 每次 |
| 非凡能力大失敗 | +1 | 每次 |
| 目睹序列4+高位格顯現 | +1d3 | — |
| 被高位格注視/接觸 | +2d3 | — |
| 隊友完全失控 | +1 | 每場景1次 |
| 單回合受>50%HP傷害 | +1 | 每場景1次 |
| 使用不相容封印物 | +2 | 每次 |
| 靈界/污染場地中戰鬥 | +1/5回合 | 持續 |

### 失控邊緣每回合檢定

觸發條件：失控值 ≥ 閾值。每回合結算階段 **d100 ≤ 心智**。

| 結果 | 效果 |
|------|------|
| 大成功（≤心智/5） | 壓制瘋狂，下回合+10 |
| 成功 | 勉強壓制，所有檢定-10 |
| 失敗 | 部分失控，擲失控行爲表 |
| 大失敗 | 完全失控，GM接管 |

### 失控行爲表（d10）

| d10 | 行爲 |
|-----|------|
| 1-2 | 本能爆發：無差別攻擊最近目標1回合 |
| 3-4 | 瘋狂逃竄：全力隨機方向移動1回合 |
| 5-6 | 僵直：喃喃自語，失去所有行動1回合 |
| 7-8 | 能力暴走：隨機非凡能力對隨機目標1回合 |
| 9 | 自殘：攻擊自身 |
| 10 | 異變釋放：自身5m半徑 2d10 途徑屬性傷害 |

### 完全失控處理

1. GM完全接管角色，成爲NPC/怪物
2. 無差別攻擊最近目標，優先靈性最強的
3. 每回合+2失控值（加速惡化）
4. 失控值>閾值2倍 → 永久轉化 → 下一團Boss素材

### 喚回失控者

**喚回行動（2AP，需接觸或≤5m）：d100 ≤ 風度**

| 結果 | 效果 |
|------|------|
| 大成功 | 立即恢復，失控值-3，本場餘下失控檢定+10 |
| 成功 | 本回合恢復自主，失控值-1 |
| 失敗 | 無效，被視作威脅 |
| 大失敗 | 喚回者自身失控值+1 |

修正：深厚羈絆+15 / 真名+10 / 私人物品+5 / 同一途徑+5 / 異變-10 / 24h內失控過-15

> **每場戰鬥只能被喚回一次。第二次失控直接完全失控。**

# 第二章：世界設定

## 2.1 時代背景

這是一個類似維多利亞時代中期（1850-1880年代風格）的世界。

- **科技水平**：蒸汽機、差分機（早期計算機）、左輪手槍、步槍、電報、火車、飛艇
- **社會結構**：皇室→貴族→中產→工人→貧民，階層分明
- **表面世界**：工業文明繁榮，帝國殖民擴張，科學理性至上
- **裏世界**：22條非凡途徑暗中角逐，教會掩蓋超自然真相，隱祕組織操控幕後

---

## 2.2 灰霧城（Mistgrave）

帝國第三大城市，120萬人口，北方工業心臟。終年籠罩薄霧，煤煙與靈性交織。

### 七大城區

| **王冠區** | 貴族宅邸、皇家劇院 | 貴族非凡者的藏身處 |
| **齒輪區** | 工廠林立、蒸汽轟鳴 | 差分機異常掩蓋失控事件 |

4. **灰霧大學地下書庫**——禁忌知識藏於迷宮般的書架深處
5. **聖瑪利亞瘋人院**——失控者的祕密收容所

# 第三章：GM 運行指南

## 3.1 扮演進度判定

### 三級扮演體系

| 等級 | 進度 | 判斷標準 | 示例（占卜家途徑） |
|------|------|---------|-------------------|
| **敷衍** | +0 | 只說了能力名就擲骰 | "我用靈擺占卜"然後擲骰 |
| **被動** | +1 | 有扮演但沒推動劇情 | 用占卜幫鄰居找走失的貓 |
| **主動** | +3 | 用非凡方式解決問題 | 放棄調查直接靈擺定位線索 |
| **核心** | +5 | 情感投入且承擔後果 | 做出準確預言卻眼看它發生而無能爲力 |

### 每場遊戲建議發放量

- 新手團（首次遊戲）：5-8 點
- 常規團：8-12 點
- 高潮團（劇情關鍵節點）：12-15 點
- 每場至少 1 次核心扮演機會

---

## 3.2 失控節奏控制

### 四階段敘事框架

**穩定階段（< 50% 閾值）**
- GM做什麼：埋環境伏筆。奇怪聲響、角落閃過的影子、似曾相識的既視感
- 給玩家的感覺：安全可控

**耳語階段（50%-75%）**
- 機制：所有心智檢定劣勢
- GM做什麼：給玩傢俬密紙條。例如"你聽到有人在叫你的名字——但是用你已經遺忘的乳名。沒有人應該知道這個名字。"
- 給玩家的感覺：有人在你腦子裏說話——而且你知道它說的是真的

**異變階段（75%-100%）**
- 機制：耳語效果 + 風度檢定劣勢 + 身體異變
- GM可選規則「扭曲之力」：使用非凡能力時傷害+1d4，但失控值額外+1d3
- GM做什麼：描述身體變化。"你發現手指在無意識顫抖——不是因爲恐懼，而是它們在試圖比劃某個你不認識的符號。"
- 給玩家的感覺：你的身體不再完全屬於你

**失控邊緣（≥ 100%）**
- 機制：每次使用能力須擲失控檢定
- GM做什麼：終極誘惑。"力量從未如此純粹。你感到自己可以一瞥世界的真相——只要放手。"檢定前給一句敘事引導。
- 給玩家的感覺：每一次使用能力都是一場與命運的賭博

### 完全失控轉化

1. **終局時刻**：在失控檢定失敗後描述——"你感覺體內有什麼東西終於掙脫了。它一直在等這一刻。"
2. **轉化爲NPC/Boss**：下一場戰鬥直接用失控形態數據。建議保持原角色能力但傷害+50%，增加隨機行爲表。
3. **敘事迴響**：原角色的表層生活暴露、隊友記得他、可能以靈體形式短暫出現。

## 3.3 敘事節奏

### 三幕結構

| 幕 | 佔比 | 內容 | GM要點 |
|----|------|------|--------|
| **調查** | 40% | 收集線索、走訪NPC、靈性感知 | 每場景至少1條非凡可探知的信息 |
| **衝突** | 35% | 戰鬥/社交對抗/儀式競爭 | CR控制在預算內的普通-困難 |
| **真相** | 25% | 揭示黑幕、道德抉擇 | 至少2種可行選擇，無"正確"答案 |

### 信息揭示四層結構

1. **表面線索**（凡人也看得到）：報紙報道、目擊證詞、現場痕跡
2. **靈性線索**（占卜/靈視發現）：能量殘留、靈體存在、預兆
3. **專業知識**（神祕學/途徑知識）：識別途徑、封印物等級、儀式目的
4. **深層真相**（改變世界觀）：幕後的真正力量、反派的人性面

### 佔比建議

調查30% + 社交扮演20% + 神祕學探索10% + 戰鬥行動25% + 劇情揭示15%

## 3.4 氣氛營造

### 維多利亞哥特五要素

1. **霧**——不僅遮蔽視線，也遮蔽非凡痕跡
2. **煤氣燈**——昏黃燈光在水汽中暈開
3. **煙囪工業**——晝夜不停的黑煙，足以掩蓋非凡戰鬥的聲響
4. **階級體面**——每個人都戴着面具。非凡者戴着兩張
5. **古老隱祕**——地下廢墟比城市更老

### 不可名狀的描述技巧

- **描述感官而非類別**："你看到的不是一張臉——是你祖母的臉和你上司的臉和鏡子裏自己的臉同時疊在一起的圖案"
- **描述觀察者的影響**："你看了一眼就忘了它長什麼樣，但你知道自己忘了——你忘了你不想忘的東西"
- **對比與悖論**："它在動，但它沒有移動。它在變大，但距離沒有變近"

# 第四章：起始模組 ——《白房間的血色舞會》

## 4.1 基本信息

- **推薦玩家**：3-5人，序列9，接受所有途徑
- **時長**：2-3次遊戲（每次3-4小時）
- **核心主題**：美與恐怖一體兩面，執念如何毀滅人
- **反派**：白夫人——觀衆途徑序列6「催眠師」，以舞蹈爲情緒操控媒介

## 4.2 背景

三個月來，灰霧城的藝術家圈子裏流傳着一個傳聞：收到一張印有紅玫瑰的白色請柬，你將在"白房間"參加一場終生難忘的舞會。去過的人回來後作品突然充滿驚人的生命力。但最近一次舞會後，一名畫家失蹤了——他的畫室裏留下一幅未完成的畫：六個人在跳舞，第六個人的面容模糊不清。

## 4.3 鉤子（3選1）

1. **委託**：失蹤畫家的家屬僱玩家調查
2. **傳聞**：玩家在溺者酒館聽到了舞會的傳聞，靈性直覺觸發
3. **偶然**：一名玩家收到了白色請柬

## 4.4 第一幕：調查

**線索點1——失蹤者之家**：表面線索：畫作上第六個舞者面容似乎在變化。靈性線索：靈視可感知觀衆途徑殘留。

**線索點2——莫蘭街13號**：表面線索：鄰居說每週五晚上黑色馬車來接人。靈性線索：占卜顯示馬車來自鐵橋區方向。

**線索點3——溺者酒館**：社交挑戰：需成功交涉/賄賂才能從情報販子口中套出白夫人曾是位天才舞者，因演出意外失去一切。

**線索點4——灰霧大學**：學術挑戰：查閱舊報紙可發現五年前皇家劇院火災中一名舞者奇蹟生還——但後續報道全部消失。

## 4.5 第二幕：衝突

**場景1——舞會滲透**：玩家潛入白房間（鐵橋區廢棄劇院地下室）。超過20名賓客在跳舞。調查可發現六名舞者中已有一人死去，但白夫人拒絕承認。社交路徑：與白夫人交談；潛行：潛入後臺；戰鬥：被發現則觸發。

**場景2——交鋒**：白夫人發動能力——所有賓客變爲她情緒操控下的"舞者"。可選擇：正面擊倒、喚回被控賓客、破壞封印物「永恆節拍器」。

**封印物——「永恆節拍器」（2級）**
- 形態：小型節拍器，擺錘刻有音符
- 正面：用節奏操控周圍人情緒（觀衆途徑序列6能力）
- 副作用：使用者沉迷於"完美節奏"，以8拍思考一切
- 隱藏：午夜整點時自行擺動，召喚上次舞會的"舞者"

## 4.6 第三幕：抉擇

揭示真相：白夫人五年前在火災中並非"奇蹟生還"——她失控了，能力暴走將劇院觀衆束縛在無盡舞蹈幻覺中。她一直在"重辦"那場舞會，堅信跳得足夠完美一切就能重來。那個死去的舞者——是她在幻覺中看到的自己。

### 結局分支

# 第七章：大範圍戰鬥與指揮

## 7.1 抽象規則

當戰鬥超過 12 人蔘與時，改用單位和波次概念：

**一個單位 = 5-10名同類戰鬥者的聚合。**
- 單位HP = 個體HP × 人數 / 5
- 單位攻擊 = 個體攻擊 + 每5人+5
- 單位傷害 = 個體傷害 × √人數（取整）

## 7.2 指揮檢定

**d100 ≤ 風度 + 領導技能加成**

| 結果 | 效果 |
|------|------|
| 大成功 | 己方單位本回合攻擊+20，士氣+3 |
| 成功 | 己方單位本回合攻擊+10 |
| 大失敗 | 一單位本回合攻擊隨機目標 |

獵人途徑指揮自動優勢。戰士途徑指揮部隊傷害+20%。
