# 狀態效果圖鑑（黎明殺機TRPG）

> **來源檔**：`31_狀態效果條目.md`（戰止戈 設計）
> **用途**：玩家與主持人（GM）可快速查閱的圖鑑。本檔由 30 條條目重組為「一頁式總表（前）＋ 完整條目（後）」兩段。
> **命名鐵律**：所有狀態一律「中文全稱（英文原名）」格式；所有效果一律明確數值修正，禁止模糊描述。
> **時間單位**：全系統唯一時間單位為「輪（Round）」，約 10–15 秒。

---

## 一、使用說明

- **陣營標示**：倖存者減益／倖存者增益／殺手增益／雙方減益／倖存者中性／回聲同伴專屬。
- **類別標示**：感知類／移動類／生命類／行動類／實體類。
- **數值修正鐵律**：所有效果必須是可直套的數字（檢定加減值、格數、輪數、進度點（PP）），禁用百分比。
- **交互裁定速查**：見本檔末「五、狀態效果交互裁定速查」。

## 三、完整條目（ST-01 ～ ST-30）

### ST-01 失明（Blindness）

| 欄位 | 內容 |
|---|---|
| **陣營** | 雙方減益 |
| **類別** | 感知類 |
| **來源** | 手電筒照射殺手面部（4 格內）；蠟燭修女（造物 RC-06）；殺手天賦「黑霧壟斷」；詛咒圖騰 |
| **數值修正** | ① 無法讀取任何光環（Aura）——所有揭示位置的天賦、道具、力量（Power）效果對持有者全部失效。② 所有感知（PER）檢定 −4（殺手方）／所有專注（FOC）判讀檢定 −4（倖存者方）。③ 殺手持有時：無法讀取抓痕（Scratch Marks）與血跡（Blood Pools），追蹤檢定自動失敗。④ 倖存者持有時：無法用地圖（Map）道具，無法判讀紅漬（Red Stain）。 |
| **持續** | 手電筒致盲：2 輪；天賦／造物來源：2 輪；詛咒圖騰：圖騰存在期間持續 |
| **疊加規則** | 不可疊加，刷新持續輪數（取較長者） |
| **解除條件** | 持續輪數結束；淨化對應詛咒圖騰 |
| **原著對照** | Blindness：無法讀取任何光環 |

### ST-02 血怒（Bloodlust）

| 欄位 | 內容 |
|---|---|
| **陣營** | 殺手增益 |
| **類別** | 移動類 |
| **來源** | 同一次追逐持續累積輪數（自動） |
| **數值修正** | 第一層（第 3 輪起）：追逐對抗檢定 +1，移動等級 +1 格／輪。第二層（第 5 輪起）：追逐對抗 +2，移動 +1 格／輪，倖存者繞圈值（Loop Value）加成 −1。第三層（第 7 輪起）：追逐對抗 +3，移動 +2 格／輪，且每輪追逐間距（CG）自動 −1（倖存者對抗大成功可抵銷）。 |
| **持續** | 追逐持續期間；脫離追逐後每輪 −2 層 |
| **疊加規則** | 分層累積，上限第三層 |
| **解除條件** | 立即歸零：殺手破壞任何板子／成功命中任何倖存者／發動任何力量（Power） |
| **原著對照** | 血怒 I：15 秒 +0.2 公尺／秒；II：25 秒 +0.4；III：35 秒 +0.6。破板、命中、用力量即失去 |

### ST-03 破碎（Broken）

| 欄位 | 內容 |
|---|---|
| **陣營** | 倖存者減益 |
| **類別** | 生命類 |
| **來源** | 孤身掙脫（Solitary Break）成功後；疫染（Infected）第三階；殺手天賦；部分道具加裝的代價 |
| **數值修正** | ① 完全不可治療：治療進度軌無法累積任何進度（他人治療、自我治療、醫療包皆無效）。② 已累積的治療進度歸零。③ 從瀕死（Dying）被扶起仍可（扶起不算治療），但只能回到受傷（Injured）狀態。 |
| **持續** | 依來源；孤身掙脫來源為 2 輪；天賦來源通常為 4 輪或整場 |
| **疊加規則** | 不可疊加，刷新持續輪數 |
| **解除條件** | 持續輪數結束 |
| **原著對照** | Broken：無法被治療超過受傷狀態 |

### ST-04 深度創傷（Deep Wound）

| 欄位 | 內容 |
|---|---|
| **陣營** | 倖存者減益 |
| **類別** | 生命類 |
| **來源** | 堅韌（Endurance）狀態下受擊；軍團的狂亂（Feral Frenzy）命中；腐骨獵犬（造物 RC-05）撕咬 |
| **數值修正** | ① 施加深度創傷倒數 4 輪。② 倒數在奔跑中或進行縫合（Mend）行動時暫停；其餘任何時候每輪 −1。③ 倒數歸零→立即進入瀕死（Dying）狀態並發出噪音通知。④ 縫合（Mend）行動：1 行動點（AP）＋意志（WIL）檢定；自我縫合需 2 次成功，他人協助縫合需 1 次成功。 |
| **持續** | 直到縫合完成或倒數歸零 |
| **疊加規則** | 不可疊加；再次觸發則倒數刷新為 4 輪 |
| **解除條件** | 完成縫合（Mend）；或進入瀕死狀態（狀態自然消失） |
| **原著對照** | Deep Wound：非奔跑／非縫合時流失，歸零自動瀕死。自我縫合 10 秒、他人協助 6 秒 |

|---|---|
| **陣營** | 倖存者減益 |
| **類別** | 行動類 |
| **來源** | 使用任何標註「耗竭類」的天賦（Perk）後自動施加 |

| **解除條件** | 持續輪數結束；被救下鉤時立即解除 |
| **原著對照** | Exhausted：無法使用耗竭類天賦，隨時間恢復；解鉤時立即恢復 |

### ST-06 暴露（Exposed）

| 欄位 | 內容 |
|---|---|
| **陣營** | 倖存者減益 |
| **類別** | 生命類 |
| **來源** | 殺手天賦「無人生還」類；女巫的幻影泥印觸發；獻祭執事（造物 RC-09）；部分力量（Power）超載（Overload） |
| **數值修正** | ① 受到任何基本攻擊（Basic Attack）或撲擊（Lunge）命中時，傷勢格直接 +2——健康（Healthy）狀態一擊進入瀕死（Dying）。② 已在受傷（Injured）狀態時，效果與一般命中相同（進入瀕死）。③ 不揭示光環——暴露狀態本身不會讓殺手看到你在哪。④ 堅韌（Endurance）可抵擋：受擊時改為施加深度創傷（Deep Wound）。 |
| **持續** | 依來源；標準值 3 輪 |
| **疊加規則** | 不可疊加，刷新持續輪數 |
| **解除條件** | 持續輪數結束；來源天賦或圖騰失效 |
| **原著對照** | Exposed：受擊直接瀕死（雙倍傷害），不揭示光環 |

### ST-07 出血（Haemorrhage）

| 欄位 | 內容 |
|---|---|
| **陣營** | 倖存者減益 |
| **類別** | 生命類 |
| **來源** | 殺手天賦；女獵人戰斧命中；撕裂（Mangled）來源多半同時施加 |

| **解除條件** | 完成一次完整治療（治療進度軌滿 4 格）；持續輪數結束 |
| **原著對照** | Haemorrhage：血跡更多、未痊癒治療進度以 −7%／秒流失 |

| **持續** | 直到掙脫或被解救 |
| **疊加規則** | 不可疊加 |
| **解除條件** | 自行掙脫：每輪 1 行動點（AP）＋敏捷（AGI）檢定難度等級（DC）14，成功即脫困（每次失敗後下次檢定 +2 累積加值，保證最終能出來）。隊友解救：同區域隊友花 1 行動點（AP）自動成功。殺手釋放：殺手可花 1 行動點（AP）解開獸夾。 |
| **原著對照** | 延伸自陷阱者的 Bear Trap 與女巫的 Phantasm Trap |

| 欄位 | 內容 |

## 五、狀態效果交互裁定速查

| 交互情境 | 裁定 |
|---|---|
| 暴露（Exposed）＋ 堅韌（Endurance）同時存在，受擊 | 堅韌優先：傷勢格不變，改施加深度創傷（Deep Wound），堅韌消耗 |
| 破碎（Broken）＋ 深度創傷（Deep Wound） | 縫合（Mend）不算治療，仍可進行；破碎不阻止縫合 |
| 加速（Haste）＋ 阻礙（Hindered）同時存在 | 兩者相加（+2 與 −2 抵銷為 0），不互相取消狀態本身 |
| 渾噩（Oblivious）＋ 顫慄（Trembling） | 渾噩優先：心跳籌碼為 0 → 不觸發顫慄 |
| 不可探測（Undetectable）＋ 顫慄（Trembling） | 心跳籌碼為 0 → 不觸發顫慄。不可探測是殺手最強的心理武器 |
| 失明（Blindness）＋ 殺手直覺（Killer Instinct） | 殺手直覺不受失明影響，仍正常揭示 |
| 束縛（Snared）＋ 被追逐 | 追逐間距（CG）每輪自動 −1，直到追逐間距（CG）＝ 0 |
| 窒息（Suffocating）＋ 亢奮（Adrenal） | 亢奮的生命狀態恢復仍生效（瞬間效果不受窒息的治療歸零影響） |
| 疫染（Infected）第三階 ＋ 破碎（Broken） | 不重複施加，破碎持續至疫染降階 |
| 瘋狂（Madness）第二層 ＋ 渾噩（Oblivious）來自其他來源 | 不疊加，取最長持續輪數 |
| 迴聲（Echoing）＋ 任何狀態 | 回聲同伴可承受所有狀態效果，但不擲檢定的行動用不受檢定減值影響 |
| 多個阻礙（Hindered） | 最多疊 2 層（−4 格），第 3 層以上無效 |
| 多個詛咒（Cursed） | 各自生效並相加，無上限 |
