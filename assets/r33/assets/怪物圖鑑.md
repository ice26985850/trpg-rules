# 怪物圖鑑（黎明殺機TRPG）

> **來源檔**：`32_殺手力量與造物條目.md`（戰止戈 設計）
> **用途**：玩家與主持人（GM）可快速查閱的圖鑑。本檔由條目資料庫重組而成，系統規則見 `30_追逐戰鬥.md`、`10_核心機制.md`。
> **命名鐵律**：所有遊戲術術語採「中文全稱（縮寫）」格式；公式中的英文變數名為鐵律例外（供 Excel 實作）。
> **格線與時間**：1 格 ＝ 2 公尺方格；全系統唯一時間單位為「輪（Round）」，約 10–15 秒。

---

## 一、使用說明

1. **本圖鑑分兩部**：
   - **第一部　九名化身**——既是玩家可選的殺手陣營，也是主持人可投放的怪物圖鑑條目。
   - **第二部　十二條領域造物**——實體（The Entity）析出的次級存在，不可掛鉤、不可獻祭、有生命值（HP）。
2. **化身作為怪物時的挑戰等級（CR）**：`挑戰等級（CR） ＝ 聲望等級（PRS） ＋ 化身危險係數（AVM）`。本圖鑑附「聲望等級 1／10／20」三基準，主持人可直接取用。
3. **造物鐵律**：造物**不得造成死亡**（最多打到瀕死（Dying）），正解為**驅散弱點（Banish Weakness）**或迴避，不是打倒它。徒手傷害僅 1d4，對高挑戰等級（CR）造物在數學上不可行。

**一句話戰術提示**：蹲行通過陌生區域並記住已知陷阱位置——用陷阱格逼殺手繞路，優先解救受困隊友（2 行動點（AP）自動成功）。

## 五、遭遇預算（EB）速查

```
遭遇預算（EB） ＝ ROUND( N × (2 ＋ 聲望等級（PRS）) × 難度係數（DM), 0 )

N   ＝ 玩家倖存者人數（回聲同伴不計入）
DM  ＝ 難度係數：輕微 0.5／標準 1.0／艱難 1.5／致命 2.0

Excel：=ROUND(N*(2+PRS)*DM, 0)

造物預算（CB） ＝ ROUND( N × (2 ＋ 聲望等級（PRS）) × 難度係數（DM） × 2 / 5, 0 )
（殺手固定預留 60% 為預留位、不另計；造物以 CB 為準，單一公式末端取整一次）
Excel：=ROUND(N*(2+PRS)*DM*2/5, 0)
```

> 取整無歧義保證：CB 永遠不會落在 .5（四種難度係數（DM）下 CB_raw ＝ M/5、2M/5、3M/5、4M/5，M ＝ N×(2+聲望等級（PRS）) 為整數），故 Excel ROUND、Python round、主持人（GM）心算三者結果永遠一致。

### 5-1　投放規則

| 規則 | 說明 |
|---|---|
| **殺手在場時** | 造物預算（CB）＝ ROUND(N×(2+PRS)×DM×2/5, 0)，直接以此為上限投放造物。殺手佔用的 60% 為預留位，不另計。 |
| **殺手不在場時** | 造物預算（CB）＝ 遭遇預算（EB）＝ ROUND(N×(2+PRS)×DM, 0)，全額可用於造物。 |
| **首領級造物** | 單場試煉最多 **1 個**；若已投放，殺手的三階段升壓（見 `32` §1-6）不得進入第三階段。 |
| **同型造物** | 同一編號單場最多 `MAX(1, INT(N))` 個（鏽鴉群 RC-01 例外，不受限）。 |
| **情報型造物** | RC-02 井裡的合唱不佔預算，可自由投放。 |

**造物預算（CB）下限規則（新手引導）：** 當 造物預算（CB）＜ 最便宜造物成本（RC-01 鏽鴉群 ＝ 2 點預算成本（EBC））時，該場**不投放任何造物**，為純殺手試煉。觸發此情形的全是「聲望 1–5 的獨行試煉」與「輕微難度」——共 7 組參數（N1/聲望1 輕微或標準、N1/聲望2–5 輕微、N2/聲望1 輕微），即新手頭幾場（第一次跑團＝「你與殺手，霧裡只有你們兩個」，無鏽鴉、無泥手）。這是刻意的新手引導設計、非瑕疵，絕不臨場判斷「要不要湊整放行」。

### 5-3　高難度範例（聲望等級 15、艱難 DM 1.5、N = 4、殺手在場）

```
EB ＝ ROUND(4 × (2＋15) × 1.5, 0) ＝ ROUND(102, 0) ＝ 102
CB ＝ ROUND(4 × (2＋15) × 1.5 × 2/5, 0) ＝ 41
```
