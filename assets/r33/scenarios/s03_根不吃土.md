# S3 · 根不吃土

> 本劇本是玩法質變的第一站：玩家從「逃生」進入「逃生 ＋ 潛入」。第二幕是標準試煉，但第三幕是**在試煉進行中偏離主線、潛入一個不該存在的地方**——霧窖（Fog Cellar）。玩家在此取回第一張記憶卡（Memory Card），並理解餘燼可作為「開鎖的東西」。

## 2. GM 摘要

**故事線**：玩家帶著 S2 刻痕 #5「火會記得」的線索。植物學背景的倖存者莎莉·恩科西（§8-A）說：寒風農場中央那棵獻祭之樹「根是向上長的……它吃別的東西」。第二幕試煉中，玩家必須在開闊農場邊逃邊完成「開啟樹根通道」三步驟——其中第二步要求產生一次利他之望（Altruistic Hope）作為鑰匙，使「救人」從道德選擇變成通關必要條件。第三幕玩家下降進入霧窖，在倒著長的根系中摘取記憶囊。

**真相（GM 專屬）**：霧窖是實體（The Entity）的記憶檔案庫——記憶沒有被銷毀，只是被「歸檔」。摘囊前必須「認出」它是自己的，GM 不告訴對錯。摘到別人的囊（含某位殺手的）是 S6 伏筆。餘燼時刻（Ember Moment）揭露：樹只認得一種東西——實體自己吐不出來的利他之望。

**如何運行**：開闊地是「鏈鋸屠夫（HBY）」的主場，這是全戰役到目前最痛的一場——只有 1 面板子（Pallet），玩家必須用玉米田遮蔽玩心理戰而非繞圈。霧窖無殺手、無目標，壓力來自收縮倒數與「認出自己」的認知挑戰。GM 應至少安排一名玩家摘錯囊（摘到殺手記憶）。

## 3. 開場文本（可直接朗讀）

> 火光裡，莎莉把一根手指按在泥地上，畫了一道假想的弧線。
>
> 「寒風農場中間那棵樹，」她說，「它的根是向上長的。我看過，在它被土蓋住之前。」
>

>
> 「根不吃土。它吃別的東西。」
>
> 艾洛薇把那句刻痕「火會記得」唸了一遍，像在嚼一個字。
>
> 「如果記憶被拿走了，」她說，「那它一定被放在某個地方。而這地方……不會在試煉外面。」
>
> 「所以在裡面。」你說。
>
> 「在裡面。」她點頭。「但要在試煉還沒結束的時候，鑽進去。」
>
> 她把火撥亮了一點。
>
> 「這一次，別只想著逃。」

## 7. 抉擇點與分支結果

**抉擇一：是否產生利他之望開鎖（核心）**
- 玩家若全程獨善其身，無法產生鑰匙，進不去霧窖——只能純逃脫完成試煉，但拿不到記憶卡。
- 分支：產生利他之望 → 樹根鬆開 → 進入霧窖（取記憶卡＋觸發餘燼時刻）。

**抉擇二：霧窖摘囊**
- 摘到自己的囊 → 1 張記憶卡（用 S1 隨身物連結）。
- 摘到別人的囊 → 1 張他人記憶卡（＋1 希望點（HOP）上限，無法歸還，原主人後續會察覺）。**GM 應安排至少一名玩家摘錯**（摘到某位殺手的記憶＝ S6 伏筆）。
- 收縮倒數內未離開 → 失去 3 點希望點（HOP），被實體「歸檔」強制回營火。

## 9. 結局分支與獎勵

**結局分支**：是否進入霧窖（取決於抉擇一）；霧窖中摘對／摘錯囊（抉擇二）。摘錯不是失敗，是 S6 伏筆。

**獎勵**

| 項目 | 內容 |
|---|---|
| 血點（BP） | 標準 ×（依人數表） |
| 聲望等級（PRS） | 完成後升至 7 級 |
| 希望點（HOP） | +3 |
| 營火餘燼 | 過程累積（預估 5–9） |
| **記憶卡** | **1–2 張**（依人數表） |
| 物品 | 每人 1 件罕見物品 |
| 敘事 | 記憶被歸檔而非銷毀；餘燼可作為鑰匙 |
| 新能力 | 玩家可花 1 點希望點（HOP）「向記憶卡求助」，重擲一次與該記憶主題相關的檢定 |

**餘燼時刻（Ember Moment）觸發文本**：
> 你把手按上樹皮的時候，樹沒有反應。你又試了一次。還是沒有。
> 然後你想起剛才——你在鉤子底下把那個人接下來的時候，胸口掉出去的那個溫的東西。
> 你伸手到口袋裡。它在。你不記得自己撿了它。
> 你把它按在樹皮上。樹根像手指一樣鬆開了。
> **這棵樹不吃土，也不吃血。它只認得一種東西——那種它自己也吐不出來的東西。**

## 10. 與前後劇本的銜接

- **向前（S2）**：刻痕 #5「火會記得」→ 艾洛薇推論「記憶被放在某處」→ 本劇本霧窖。
- **向後（S4）**：莎莉若摘錯囊 → S4 她會「認得十七號的臉」卻說不出為什麼；本劇本取回的記憶卡是 S4 拼湊「十七號病歷」的素材。
- **伏筆回收點**：① 擦手的人替摘囊 → S5 虛空認出玩家；② 摘到殺手記憶 → S6 莎莉說出重鑄問答；③ 霧窖「認出自己」機制 → S7 淨罪神殿的錯誤比例。
