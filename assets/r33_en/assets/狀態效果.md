# Status Effects Catalogue (Dead by Daylight TRPG)

> **Source File**: `31_狀態效果條目.md` (designed by Zhan Zhige)
> **Purpose**: A quick-reference catalogue for both Players and the Game Master (GM). This file reorganizes 30 entries into two sections: a one-page summary table (front) plus full entries (back).
> **Naming Iron Rule**: Every status uses the `Chinese Full Name (English Original)` format; every effect must state an explicit numeric modifier — vague descriptions are forbidden.
> **Time Unit**: The only time unit in the entire system is the "Round (Round)", roughly 10–15 seconds.

---

## I. How to Use

- **Faction Tag**: Survivor Debuff / Survivor Buff / Killer Buff / Both-Sided Debuff / Survivor Neutral / Echo Companion Exclusive.
- **Category Tag**: Perception / Movement / Vitality / Action / Entity.
- **Numeric Modifier Iron Rule**: Every effect must be a directly-applicable number (check modifiers, cells, rounds, Progress Point (PP)) — percentages are prohibited.
- **Interaction Ruling Quick Reference**: See "V. Status Effect Interaction Rulings Quick Reference" at the end of this file.

## V. Status Effect Interaction Rulings Quick Reference

| Interaction | Ruling |
|---|---|
| Exposed + Endurance present, taking a hit | Endurance takes priority: wound cell unchanged, Deep Wound applied instead, Endurance consumed |
| Broken + Deep Wound | Mend is not healing, still allowed; Broken does not block Mend |
| Haste + Hindered present together | The two add (+2 and −2 cancel to 0); the statuses themselves are not mutually cancelled |
| Oblivious + Trembling | Oblivious takes priority: Heartbeat Tokens are 0 → Trembling does not trigger |
| Undetectable + Trembling | Heartbeat Tokens are 0 → Trembling does not trigger. Undetectable is the Killer's strongest psychological weapon |
| Blindness + Killer Instinct | Killer Instinct is unaffected by Blindness, still reveals normally |
| Snared + being chased | Chase Gap (CG) automatically −1 each round, until Chase Gap (CG) = 0 |
| Suffocating + Adrenal | Adrenal's Health State recovery still applies (instant effect unaffected by Suffocating's healing reset) |
| Infected tier 3 + Broken | Not applied again; Broken persists until Infected drops a tier |
| Madness tier 2 + Oblivious from another source | Does not stack; take the longest duration |
| Echoing + any status | The Echo Companion can bear all status effects, but check-independent actions are unaffected by check penalties |
| Multiple Hindered | Stack at most 2 tiers (−4 cells); tier 3 and above have no effect |
| Multiple Cursed | Each takes effect and adds up, no cap |
