# Item Catalogue (Dead by Daylight TRPG)

> **Purpose**: A table-side reference for players and the Game Master (GM). This catalogue holds **58 entries** in total — 18 base items, 26 Add-ons (Add-on), and 14 Offerings (Offering).
> **Numeric Iron Rule**: All effects are integer add/subtract or fixed counts — no percentages. The sole exception is the Chest drop-weight table (that is a system probability, not an effect modifier).
> **Time & Distance**: The only time unit in the system is the "Round", roughly 10–15 seconds; 1 square = a 2-meter grid cell.
> **Solo-Runnable**: This system defaults to 1 player + 1 Game Master (GM) to start. Every item includes a "Solo Trial note" describing its boost or restriction under Setup 1 (Solo Trial).

**Chest Scavenging Check** — Trigger: you and the Chest are in the same Contact (CON) Distance Band. Cost: 3 Action Point (AP). Check: 2d10 + Technique (TEC) bonus + Search (SRC) Skill Level vs. Difficulty Class (DC) 9. Result: Critical Success — obtain the item and raise the rarity roll by 1 tier; Success — obtain the item, roll d100 against the cumulative weights above to determine rarity; Failure — obtain nothing this time, the Chest remains unopened; Critical Failure — obtain nothing, emit a noise cue, and the Game Master (GM) reveals that Chest's location to the Killer.

### 1-3 Durability (Charge Point)

- Durability is expressed in **Charge (CHG) points**: how many Action Point (AP) of use the item can still support.
- **Iron Rule: Using an item, every 1 Action Point (AP) spent consumes 1 Charge (CHG) point.**
- When Charge (CHG) hits zero the item is spent but still counts toward Load (LOAD); spending 0 Action Point (AP) lets you actively discard it.
- After the Trial ends: if you escape, the item is kept and Charge (CHG) refills; if you are Sacrificed the item and Add-ons are lost together (unless you burned IT-54 White Ward). **Add-ons are always consumed**, regardless of outcome.

### 1-4 Add-on General Rules

- Each item can equip at most **2 Add-ons**, and they must match the item's category.
- Equipped before the Trial starts, cannot be swapped mid-Trial, always consumed after the Trial ends.
- Total available Add-ons depends on Prestige (PRS): opens 1 slot at level 4, 2 slots at level 10.
- Add-ons and Offerings **do not count toward Load (LOAD)**.
- A Killer's Add-ons go on their Power; the rules are the same. Each avatar's exclusive power components are in the Monster Catalogue; this catalogue collects only the 6 universal components any avatar can equip.

### 1-5 Offering General Rules

- Offerings are burned at the Campfire, take effect before the Trial starts, and are permanently consumed.
- Each character may burn at most **1 per Trial**. The Offering slot opens at Prestige (PRS) **level 8**.
- **Conflict Ruling**: the higher rarity takes effect and the rest are returned; at equal rarity all are returned (for Realm-choice offerings of equal rarity, one is chosen at random).

Wherever an entry says "other Survivors," in a Solo Trial it means Echo Companions. Echo Companions have a fixed total modifier of +2 on skill checks, and their Progress Point (PP) contribution is halved (rounded down).

## III. Category I — Medical (IT-01 ~ IT-04)

> **Common Check Baseline** — Heal others: 3 Action Point (AP), Difficulty Class (DC) 10. Self-heal: 4 Action Point (AP), Difficulty Class (DC) 14, and you must hold a Med-Kit (or have equipped the Perk "Self-Care Technique", see Perk Catalogue SP-07).
> **Common Progress Baseline** — Critical Success +6 Progress Point (PP), Success +4, Failure −1, Critical Failure −3. Accumulating **12 Progress Point (PP)** restores one Health State (HS) tier of the target (Dying → Injured, or Injured → Healthy).
> **Common Check Formula** — 2d10 + Focus (FOC) bonus + First Aid (MED) Skill Level + item modifier.

### 9-3 Charge (CHG) Formula

The following is a formula block; variables use English abbreviations. Chinese gloss: Remaining Charge equals the item's base Charge plus the Add-on Charge modifier, minus Charge already used; an item is usable while Remaining Charge is greater than 0; usable count equals Remaining Charge divided by the single-action AP, truncated.

```
Remaining Charge = Base Item Charge + Add-on Charge Modifier − Charge Already Used
Item Usable? = IF(Remaining Charge > 0, "Usable", "Spent")
Usable Count = INT(Remaining Charge / Single-Action AP)
```

The AP above is Action Point; CHG is Charge.

## X. Load (LOAD) Cap Formula

The following is a formula block; variables use English abbreviations. Chinese gloss: Load Cap equals 3 plus Technique divided by 2, truncated, plus 1 if the archetype is Artificer.

```
Load Cap = 3 + INT(TEC / 2) + IF(Archetype = "Artificer", 1, 0)
Current Load = SUM(Load values of carried items)
Carry Allowed? = IF(Current Load <= Load Cap, "Legal", "Overweight")
```

The TEC above is the Technique attribute; LOAD is Load.

### 10-2 Load (LOAD) Rules

1. Each item's Load (LOAD) value is in its entry, generally 1 — only IT-04 Ranger Med-Kit and IT-08 Commodious Toolbox are 2.

4. An item with exhausted Charge **still counts toward Load (LOAD)** — remember to drop it.
