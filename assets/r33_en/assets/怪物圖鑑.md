# Monster Catalogue (Dead by Daylight TRPG)

> **Source File**: `32_殺手力量與造物條目.md` (designed by Zhan Zhige)
> **Purpose**: A quick-reference catalogue for both Players and the Game Master (GM). This file reorganizes the entry database; system rules are in `30_追逐戰鬥.md` and `10_核心機制.md`.
> **Naming Iron Rule**: All game terms use the `Chinese Full Name (Abbreviation)` format; English variable names in formulas are an iron-rule exception (for Excel implementation).
> **Grid & Time**: 1 cell = a 2-meter square; the only time unit in the entire system is the "Round (Round)", roughly 10–15 seconds.

---

## I. How to Use

1. **This catalogue has two parts**:
   - **Part One — Nine Avatars**: both a Killer faction the players can select and a monster-catalogue entry the GM can deploy.
   - **Part Two — Twelve Realm Creations**: subordinate existences shed by The Entity; cannot be hooked, cannot be Sacrificed, have Hit Points (HP).
2. **Challenge Rating (CR) when an Avatar is used as a monster**: `Challenge Rating (CR) = Prestige (PRS) + Avatar Danger Coefficient (AVM)`. This catalogue attaches three baselines "Prestige 1 / 10 / 20" for the GM to use directly.
3. **Creation Iron Rule**: Creations **must not cause death** (at most down to Dying), the correct solution is **Banish Weakness** or avoidance, not defeating them. Bare-handed damage is only 1d4, mathematically infeasible against high Challenge Rating (CR) Creations.

## V. Encounter Budget (EB) Quick Reference

```
Encounter Budget (EB) = ROUND( N × (2 + Prestige (PRS)) × Difficulty Modifier (DM), 0 )

N   = number of player Survivors (Echo Companions not counted)
DM  = Difficulty Modifier: Minor 0.5 / Standard 1.0 / Hard 1.5 / Lethal 2.0

Excel: =ROUND(N*(2+PRS)*DM, 0)

Creation Budget (CB) = ROUND( N × (2 + Prestige (PRS)) × Difficulty Modifier (DM) × 2 / 5, 0 )
(The Killer's fixed 60% reservation is a reserved slot, not counted separately; Creations use CB as the standard, rounded once at the end of the single formula)
Excel: =ROUND(N*(2+PRS)*DM*2/5, 0)
```

> Rounding-ambiguity guarantee: CB never lands on .5 (under the four Difficulty Modifiers (DM), CB_raw = M/5, 2M/5, 3M/5, 4M/5, where M = N×(2+Prestige (PRS)) is an integer), so Excel ROUND, Python round, and the GM's mental math always agree.

### 5-1 Deployment Rules

| Rule | Description |
|---|---|
| **Killer present** | Creation Budget (CB) = ROUND(N×(2+PRS)×DM×2/5, 0), deploy Creations directly up to this cap. The Killer's 60% reservation is a reserved slot, not counted separately. |
| **Killer absent** | Creation Budget (CB) = Encounter Budget (EB) = ROUND(N×(2+PRS)×DM, 0), fully available for Creations. |
| **Boss-tier Creation** | At most **1** per Trial; if deployed, the Killer's three-phase pressure ramp (see `32` §1-6) may not enter phase three. |
| **Same-type Creation** | At most `MAX(1, INT(N))` of one ID per Trial (Rust Crows RC-01 is exempt, unlimited). |
| **Intel-type Creation** | RC-02 Well Chorus costs no budget, freely deployable. |

**Creation Budget (CB) floor rule (new-player onboarding):** When Creation Budget (CB) < the cheapest Creation cost (RC-01 Rust Crows = 2 Encounter Budget Cost (EBC)), that match **deploys no Creations** — a pure-Killer Trial. The triggering cases are all "Prestige 1–5 Solo Trials" and "Minor difficulty" — 7 parameter groups total (N1/Prestige1 Minor or Standard, N1/Prestige2–5 Minor, N2/Prestige1 Minor), i.e., a new player's first few sessions (the first session = "you and the Killer, only the two of you in the Fog", no Rust Crows, no Mud Hands). This is deliberate new-player onboarding, not a flaw — never ad-lib "should we round up and allow it" on the spot.

### 5-2 Example Quick Reference (Standard difficulty DM 1.0, Killer present)

| N | Prestige (PRS) | Encounter Budget (EB) | Creation Budget (CB) | Suggested Combo | Result |
|---|---|---|---|---|---|
| 1 | 5 | ROUND(1×7×1.0)=7 | ROUND(1×7×1.0×2/5)=**3** | RC-01 Rust Crows ×1 (2) | 1 left |
| 2 | 5 | ROUND(2×7×1.0)=14 | ROUND(2×7×1.0×2/5)=**6** | RC-04 Straw Afterimage (4) + RC-01 (2) = 6 | Exact |
| 3 | 5 | ROUND(3×7×1.0)=21 | ROUND(3×7×1.0×2/5)=**8** | RC-06 Mud Hands (6) + RC-01 (2) = 8 | Exact |
| 4 | 5 | ROUND(4×7×1.0)=28 | ROUND(4×7×1.0×2/5)=**11** | RC-07 Observation Eye (10) | 1 left |

### 5-3 High-Difficulty Example (Prestige 15, Hard DM 1.5, N = 4, Killer present)

```
EB  = ROUND(4 × (2+15) × 1.5, 0)  = ROUND(102, 0)  = 102
CB  = ROUND(4 × (2+15) × 1.5 × 2/5, 0)  = 41
→ RC-10 The Fogcellar Warden (24) + RC-08 Blood Leaf Swarm (8) + RC-01 Rust Crows ×4 (8) = 40, 1 left
```

### 5-4 Creation Encounter Cadence (25-round standard Trial)

| Round | Suggestion | Purpose |
|---|---|---|
| Rounds 1–5 | Deploy only CR 1–2 intel types (Rust Crows, Well Chorus) | Build cognition, apply no real pressure |
| Rounds 6–12 | 1 main Creation of CR 3–5 | Interleave with the chase, two-front tension in the midgame |
| Rounds 13–20 | Main Creation persists + add Rust Crows as needed | Resources spent, pressure most effective |
| Rounds 21–25 (endgame) | Boss-tier Creation (RC-10 / RC-12) appears | Overlaps with Endgame Collapse (14−2N rounds), creates the climax |
