# 異界入侵 TRPG — 中英術語鎖定表 (Bilingual Glossary)

> **Project:** 異界入侵 TRPG (Chinese→English TRPG rulebook translation)
> **Glossary version:** v1.0 (term-locking draft)
> **Scope:** Reference glossary only. Chinese on the left column is intentional — do NOT treat it as an untranslated string.
> **Convention:** Stat / ability names use the **English Full Name (ABBR)** format.

---

## 0. Rule Set Display Name

| 中文 (源) | English Display Name | Notes |
|-----------|----------------------|-------|
| 異界入侵 TRPG | **Otherworld Invasion TRPG** | Primary proposed display name. 異界 = "otherworld / other dimension"; 入侵 = "invasion". Faithful to the literal meaning while reading cleanly in English. Alternatives considered: *Otherworldly Invasion TRPG* (slightly less punchy), *Rift Invasion TRPG* (drifts from 異界, which means "other world", not strictly "rift"). Use **Otherworld Invasion TRPG** everywhere as the canonical title. |

## 1. Core Dice System (核心骰種)

| 中文 | English (ABBR) | Notes |
|------|----------------|-------|
| 百分位骰 / d100 | Percentile Dice (d100) | Core dice system. |
| 擲低即成功 | Roll-Low-to-Succeed | Attack hit check: d100 ≤ target %. |
| 擲高即成功 | Roll-High-to-Succeed | Skill / attribute check: d100 + mod ≥ DC. |
| 難度等級 | Difficulty Class (DC) | Thresholds: 20 Easy → 40 Simple → 60 Normal → 70 Moderate → 80 Hard → 100 Very Hard → 120 Epic → 140 Legendary → 160+ Mythic. |
| 大成功 | Critical Success | d100 = 1–5 (forced hit + crit + bonus). |
| 大失敗 | Critical Failure | d100 = 96–100 (forced miss + negative consequence). |
| 優勢 | Advantage (ADV) | Roll 2d100, take favorable (low on attack / high on check). |
| 劣勢 | Disadvantage (DIS) | Roll 2d100, take unfavorable. ADV/DIS do not stack. |

## 3. Derived Stats (衍生屬性)

| 中文 | English Full Name (ABBR) | Formula |
|------|--------------------------|---------|
| 生命值 | Hit Points (HP) | CON×10 + Level×5 |
| 魔力值 | Mana Points (MP) | SPI×5 + Level×3 |
| 物理攻擊力 | Physical Attack (PATK) | STR×2 + weapon bonus |
| 魔法攻擊力 | Magic Attack (MATK) | INT×2 + weapon bonus |
| 物理防禦力 | Physical Defense (PDEF) | CON×1.5 + armor bonus |
| 魔法防禦力 | Magic Defense (MDEF) | SPI×1.5 + armor bonus |
| 命中率 | Hit Rate (HIT%) | 50% + WIS×3% (cap 95%) |
| 閃避率 | Dodge Rate (DGE%) | 10% + DEX×2% (cap 60%) |
| 暴擊率 | Critical Rate (CRT%) | 5% + DEX×1% |
| 有效命中率 | Effective Hit Rate (EHit%) | HIT% − DGE% (min 5%, max 95%) |

*Plain ATK / DEF may appear generically (e.g. "攻擊力"→Attack, "防禦力"→Defense). PATK/MATK/PDEF/MDEF are the locked specific forms.*

| 中文 | English | Notes |
|------|---------|-------|

| 職業等級 | Class Level | Drives skill unlocks (cap: main 50, sub 15). |

| 移動動作 | Move Action | Move to adjacent zone. |

| 反應動作 | Reaction Action | Opportunity attack etc. |

| 衝刺 | Dash | Move 2 zones (Standard+Move). |
| 短休整 | Short Rest | 10 min; potions, passives reset. |
| 長休整 | Long Rest | 8 hrs; full HP/MP recovery, daily resets. |

| 單人模式 | Solo Mode | Built-in adjustment for 1 player. |
