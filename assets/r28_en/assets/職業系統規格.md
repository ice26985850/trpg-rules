# Otherworld Invasion TRPG — Dual EXP and Class System Specification

## I. Experience Point (EXP) System

A character possesses **two independent Experience Point (EXP) pools**:

| Experience Point (EXP) Type | Source | Use |
|---------|------|------|
| Character Experience Points (EXP) | Slaying monsters, completing quests, closing rifts | **Raise Character Level**, gain Attribute Points |
| Class Experience Points (EXP) | Fighting / using class skills in that class's role / conducting production activities as that sub-class | **Raise Class Level**, unlock skills and traits |

### Character Experience Points (EXP) Gain

| Source | Experience Points (EXP) |
|------|-----|
| Slay a same-tier monster | 10 - 20 |
| Slay a higher-tier monster | 30 - 100 |
| Slay a lower-tier monster | 1 - 5 |
| Complete a quest | Depends on quest level |
| Close a rift (participation) | 100 - 500 |
| Slay a Boss-tier monster | 500 - 2000 |

### Character-Level-Up Reward

Each character level-up grants: **5 Attribute Points** (freely allocated, following the tiered cost).

### Class Experience Points (EXP) Gain

| Source | Class Experience Points (EXP) |
|------|---------|
| Participate in combat in that class's role (per battle) | Sum of monster Experience Points (EXP) in the battle × 0.8 |
| Use a skill unlocked by that class (per battle) | Sum of monster Experience Points (EXP) in the battle × 0.3 (stacks additionally) |
| Conduct production activities as a Life Class (per activity) | Fixed value (see each Life Class description) |

### Sum Cap Rule

```
Sum of all Class Levels ≤ Character Level
Deity Special Classes do not count toward the sum
```

| Character Level | Configurable Cap | Example |
|---------|----------|------|
| Lv.10 | 10 | Vanguard (MC1) 10 |

| Lv.100 | 100 | Vanguard (MC1) 50 + Shadowrunner (MC6) 50 |

## II. Binary Skill System

Skills no longer have levels (Lv.1-10). **You either know it or you don't.**

### Skill Power Formula

```
Skill Damage = Skill Base Power × (1 + Owning Class Level ÷ 20)
```

| Class Level | Damage Multiplier |
|---------|:----:|
| 1 | ×1.05 |
| 10 | ×1.50 |
| 20 | ×2.00 |
| 30 | ×2.50 |
| 40 | ×3.00 |
| 50 | ×3.50 |

> Base Power is a fixed value intrinsic to the skill (see each class's skill table).

### Skill Acquisition

- At character creation: choose **2 skills** from the Lv.1 unlock list of your first class
- Raise class level: automatically unlock the corresponding skill
- Cross-class: skills from different classes are independent. A Vanguard (MC1) cannot use a Warlock's (MC4) skills — unless you also leveled Warlock (MC4)

### Mana Points (MP) Cost

All skills have a fixed Mana Points (MP) cost and cooldown (see each skill description); these no longer change with level.

## IV. Universal Unlock Nodes

### Combat Classes (Lv.1-50)

| Level | Unlock |
|------|------|
| Lv.1 | Basic Active Skill ×2 + Class Trait Lv.1 |
| Lv.3 | New Active Skill ×1 |
| Lv.6 | New Skill ×1 (active or passive) |
| Lv.10 | Class Trait → Lv.2 |
| Lv.15 | **Branch Choice** (choose one of two) + Branch Skill ×1 |
| Lv.20 | New Skill ×1 |
| Lv.30 | Class Trait → Lv.3 (branch enhancement) |
| Lv.40 | **Master Skill** ×1 |
| Lv.50 | Ultimate Trait |

### Life Classes (Lv.1-15)

| Level | Unlock |
|------|------|
| Lv.1 | Apprentice Trait |
| Lv.5 | First Specialized Skill |
| Lv.10 | Expert Trait (replaces Apprentice Trait) |
| Lv.15 | Master Skill |

### Deity Special Class

| On Acquisition | Unlock |
|--------|------|
| Gain a Deity's Favor | Divine-Bestowed Trait (replaces or enhances the Awakening Skill) + Divine-Bestowed Skill (once per battle) |
