# I. Common Rules

## 1.1 Crafting Process (shared by all three classes)

| Step | Description |
|:--:|------|
| 1 | **Prepare Materials** — gather required materials (see each recipe table) |
| 2 | **Make a Check** — roll d100 + relevant attribute ≥ Difficulty Class (DC) |
| 3 | **Resolve Result** — success / critical success / failure / critical failure |
| 4 | **Produce Item** — obtain the finished product or lose materials |

## 1.2 Check Formula

```
Crafting Check = d100 + Relevant Attribute + Class Level × 2
```

| Class | Relevant Attribute |
|------|---------|
| Blacksmith (SC1) | Strength (STR) |
| Alchemist (SC2) | Intelligence (INT) |
| Cook (SC6) | Wisdom (WIS) |

## 1.3 Check Results

| d100 Roll | Result | Effect |
|:--:|------|------|
| 1-5 | Critical Success | Quality improves by one tier (bonus +2 or +1 special effect), no material consumed |
| 6-95 | Resolved by Difficulty Class (DC) | d100 + attribute + Class Lv×2 ≥ Difficulty Class (DC) → success; otherwise failure |
| 96-100 | Critical Failure | 50% of materials destroyed (each material independently rolled to keep or destroy), consumed Otherworld Crystals cannot be recovered |

## 1.4 Crafting Time

| Rarity | Time Required | Usable in Combat |
|:--:|------|:--:|
| White·Common (E) | 10 minutes | No (safe environment required) |
| Green·Uncommon (D) | 30 minutes | No |
| Blue·Rare (C) | 1 hour | No |
| Purple·Unique (B) | 3 hours | No |
| B-Rank Bomb / Legendary Dish | 1 hour | No |
| Orange·Legendary (A) | 8 hours (one day) | No |
| Red·Mythic (S) | 24 hours (three days, requires rest) | No |

| Upgrade | Difficulty Class (DC) | Required Materials | Success Rate Bonus |

| White→Green | 40 | Otherworld Alloy ×1 | — |

# IV. Cooking Rules (Cook)

## 4.1 Ingredient Gathering (Cook Lv.5 Specialized Skill)

After slaying a monster, the Cook may gather ingredients **without a check**:

| Monster Tier | Portions Gained |
|:--:|:--:|
| E/D-Rank | 1 portion |
| C/B-Rank | 2 portions |
| A/S-Rank | 3 portions |

> Number of ingredient portions determines how many dishes can be cooked. Each portion makes 1 dish.

## 4.2 Standard Monster Dish (Cook Lv.1 Apprentice Trait)

| Item | Content |
|------|------|
| Difficulty Class (DC) | 40 |
| Materials | Any Monster Ingredient ×1 |
| Time | 10 minutes (requires safe environment and cooking tools) |
| Effect | On consumption, gain a Buff of **single attribute +15%**, lasting until the next rest (about 8 hours or a long rest) |
| Buff Attribute | Determined by monster type (GM adjudicates — Strength-type monsters tend toward Strength (STR) Buff, magic-type toward Intelligence (INT) Buff, etc.) |
| Limit | Each monster type may only develop one Buff (attribute decided on first cooking of that monster) |
| Critical Success | Buff effect +20%, double portions |
| Critical Failure | Dish fails — ingredient wasted. No poisoning. |

> **Buff Attribute Pool** (GM chooses by monster type): Strength (STR), Dexterity (DEX), Constitution (CON), Intelligence (INT), Wisdom (WIS), Spirit (SPI), Physical Attack (PATK), Magic Attack (MATK), Physical Defense (PDEF), Magic Defense (MDEF), Hit Rate (HIT%), Evasion Rate (DGE%), Critical Rate (CRT%).

## 4.3 Dual Buff (Cook Lv.10 Expert Trait)

| Item | Content |
|------|------|
| Condition | Already consumed two different-attribute monster dishes |
| Effect | The two Buffs **take effect simultaneously** (stack). The two Buffs must correspond to different attributes. |
| Limit | Still bound by the one-Buff-per-monster-type cap |

## 4.4 Legendary Recipe (Cook Lv.15 Master Skill)

| Item | Content |
|------|------|
| Difficulty Class (DC) | 100 |
| Materials | Rare ingredient from a Boss-tier monster ×1 (auto-gained on gathering) |
| Time | 1 hour |
| Effect | Choose one of two: |
| | **A. Grand Feast**: all attributes +10% (Strength (STR) / Dexterity (DEX) / Constitution (CON) / Intelligence (INT) / Wisdom (WIS) / Spirit (SPI)), lasting until next rest |
| | **B. Extreme Focus**: single attribute +30% (chosen), lasting until next rest |
| Limit | Each Boss may only develop one Legendary Recipe. After development it can be remade (each time still requires the Boss ingredient). |
| Critical Success | Grand Feast all attributes +15%, or Extreme Focus +40% |

## 4.5 Cook Level Bonuses

| Cook Level | Bonus |
|:--:|------|
| Lv.1 | Monster Dish unlocked |
| Lv.5 | Ingredient Gathering: always obtain ingredients (no check needed) |
| Lv.10 | Dual Buff unlocked |

|------|:--:|------|
| Basic Metal | White | Buy from Guild Shop (5 Gold (G)/portion), gather at Abandoned Factory, recycle Rift Debris |

| Divine-Crafted Material | Red | Supreme Deity Projection drops, S-Rank World-Class Quest reward |

# VI. Quick Reference Cards

## Blacksmith

```
Crafting Difficulty Class (DC) = target rarity's DC (White 30 / Green 50 / Blue 70 / Purple 90 / Orange 110 / Red 140)
Check = d100 + Strength (STR) + Forging Lv × 2
Artisan's Touch: +1 bonus to all crafting
Rune Forging (Lv.10): DC 70, Otherworld Crystal×1, random attribute
Masterwork (Lv.15): DC 100, Otherworld Crystal×3, bonus×1.5 + special effect
```

## Alchemist

```
Potion Difficulty Class (DC) = potion tier's DC (Minor 30 / Intermediate 50 / Major 70 / Superior 90)
Check = d100 + Intelligence (INT) + Alchemy Lv × 2
Double Brewing (Lv.1): 30% double yield
Bomb (Lv.5): DC 60, Otherworld Material×1, yield 2, base power 30
Panacea (Lv.10): invert potion effect once per battle
Philosopher's Stone (Lv.15): DC 120, Otherworld Crystal×5 + 500 Gold (G), 7-day cooldown
```

## Cook

```
Standard Dish Difficulty Class (DC) = 40 | Legendary Dish Difficulty Class (DC) = 100
Check = d100 + Wisdom (WIS) + Cook Lv × 2
Lv.5 Ingredient Gathering auto-success
Lv.1 Standard Dish: single attribute +15%
Lv.10 Dual Buff: two dish effects stack
Lv.15 Legendary Recipe: all attributes +10% or single attribute +30%
```
