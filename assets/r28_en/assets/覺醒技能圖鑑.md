## Awakening Skill Acquisition Rules

| Rule | Description |
|------|------|
| Acquired at creation | Roll 1d20, randomly obtain **1** Awakening Skill from the table above |
| Artist background | May reroll once (choose one of the two) |
| Special cases | Some deity special classes "replace" the Awakening Skill (converted to a divine-granted trait) |
| Evolution trigger | The GM announces evolution when conditions are met. Evolution is irreversible |
| Deity class conflict | If a deity special class is obtained, the original Awakening Skill is replaced by a divine-granted trait. If divine favor is later lost — the Awakening Skill returns to the evolution stage it had before being lost |

---

## GM Usage Suggestions

- Awakening Skill evolution conditions should naturally blend into the gameplay process; no need to arrange them deliberately.
- If players go long without triggering evolution conditions, the GM may offer "accelerated trigger" opportunities at appropriate plot nodes (e.g. a specially designed trial).
- W11 Lone Wolf and W16 Healing Aura are powerful skills in Solo Mode; the GM may let solo players draw one extra Awakening Skill at creation.
- W20 Die of Fate becomes very strong after Evolution II — ensure the Evolution II trigger condition (reversing pivotal situations twice in a row in a Boss battle) is a truly epic moment.
