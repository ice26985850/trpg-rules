# 《市井倖存者》怪物／敵軍圖鑑

> 6 種敵軍單位完整數據，使用 v1.1 3d6 系統。
> 所有數值已與核心骰子機制對齊。

---

## 威脅等級體系

| 威脅等級 | 含義 | 平民單獨面對的生存率 |
|---------|------|-------------------|
| **威脅 1** | 輕微威脅——可透過潛行輕鬆避開 | ~95% |
| **威脅 2** | 中等威脅——需要謹慎應對 | ~70% |
| **威脅 3** | 高度威脅——被發現後極難逃脫 | ~30% |
| **威脅 4** | 致命威脅——一旦遭遇幾乎必死 | ~10% |
| **威脅 5** | 毀滅性威脅——個人無法抗衡 | ~1% |

## 敵軍單位

### 巡邏兵（Patrol Soldier）——威脅 2

```
【巡邏兵（巡邏）】
威脅等級：2
屬性：體魄 4 / 機敏 3 / 意志 2
察覺值：+2（常規巡邏時 +0）
移動速度：1 距離帶／回合（步行巡邏）
攻擊方式：
  • 突擊步槍（+3 射擊，射程 100 公尺，傷害：至少重傷）
  • 槍托毆打（+2 近戰，傷害：輕傷）
  • 刺刀（+3 近戰，傷害：重傷）
特殊能力：
  • 無線電呼叫：1 回合後，2d4 回合內 1–2 名增援到達
  • 手電筒：黑夜中可照亮 30 公尺範圍
弱點：
  • 固定巡邏路線——可預測
  • 疲憊——長時間執勤後察覺值 −2
  • 對平民可能猶豫——若角色求饒（社交 DC 14），有 30% 機率放水
行為模式：
  按路線巡邏，每 3 回合（約 18 秒）停頓觀察。
  發現異常先報告再調查。除非被攻擊，否則不一定立即開火——可能先喊「站住！」
生存提示：觀察路線，在停頓時移動。若被發現——跑。不要試圖戰鬥。
```

### 狙擊手（Sniper）——威脅 4

```
【狙擊手（狙擊）】
威脅等級：4
屬性：體魄 3 / 機敏 5 / 意志 4
察覺值：+5（視覺）／+1（聽覺）
移動速度：0（固定在狙擊位置）
攻擊方式：
  • 狙擊步槍（+5 射擊，射程 500 公尺，傷害：至少致命傷，超過防禦值 → 直接死亡）
  • 手槍（+2 射擊，射程 30 公尺，傷害：重傷）
特殊能力：
  • 瞄準射擊：若花費 1 回合瞄準，下回合射擊 +3
  • 光學瞄準鏡：白晝忽視 100 公尺內的掩體加成
  • 偽裝位置：被動察覺 DC 18 才能發現狙擊手的位置
弱點：
  • 視野狹窄——僅覆蓋特定區域（通常是一條街道或廣場）
  • 白天最活躍——黑夜時效率大幅降低（無夜視鏡則視野降至 50 公尺，無瞄準加成）
  • 開槍後暴露位置（槍聲 + 火光）——雖然通常已經太遲
行為模式：
  白天佔據高點，掃視負責區域。優先射擊武裝目標。
  對單個平民不一定開槍——取決於命令（GM 決定）。
  一旦開槍，會在 2d4 回合後轉移位置。
生存提示：永遠不要在白晝穿越已知的狙擊區域。等到黑夜。使用鏡子或反光物確認位置。
```

### 軍官（Officer）——威脅 3

```
【軍官（軍官）】
威脅等級：3
屬性：體魄 3 / 機敏 3 / 意志 5
察覺值：+4
移動速度：1 距離帶／回合
攻擊方式：
  • 手槍（+3 射擊，射程 30 公尺，傷害：重傷）
  • 軍刀（+3 近戰，傷害：重傷）
特殊能力：
  • 指揮：附近巡邏兵察覺值 +2，不會猶豫開火
  • 審問：社交對抗 DC 16——可能從俘虜口中獲得情報
  • 戰術思維：不會被聲東擊西輕易迷惑
弱點：
  • 傲慢——可能低估平民的威脅
  • 保護自身——受傷後優先撤退
  • 有無線電——但可能不願呼叫支援（怕被視為無能）
行為模式：
  帶領 2–4 名巡邏兵。下命令而非親自搜查。
  遇到平民時先審問（「你是誰？為什麼在這裡？還有誰和你一起？」）。
  若角色能提供有用情報（社交 DC 16），可能換取安全通行。
生存提示：軍官是可以談判的對象——如果你有他需要的東西。但不要低估他的警覺性。
```

### 逃兵（Deserter）——威脅 2

```
【逃兵（逃兵）】
威脅等級：2
屬性：體魄 4 / 機敏 4 / 意志 2
察覺值：+3（對威脅特別敏感）
移動速度：1 距離帶／回合（謹慎移動）
攻擊方式：
  • 突擊步槍（+2 射擊，射程 100 公尺，傷害：重傷——但彈藥有限，只有 d6 發）
  • 匕首（+3 近戰，傷害：重傷）
特殊能力：
  • 絕望：在被包圍或走投無路時攻擊獲得優勢
  • 野外生存：搜刮物資檢定 +3
  • 知道巡邏路線：可幫助角色避開敵軍（若願意合作）
弱點：
  • 彈藥有限——開槍是最後手段
  • 多疑——難以信任任何人（社交 DC 16 建立初步信任）
  • 正在被自己的軍隊追捕——若被發現和逃兵在一起，角色也會被視為敵人
行為模式：
  躲藏、搜刮、避開所有人。遇到平民時先判斷對方是否構成威脅。
  可能交易——逃兵有軍事知識和武器，但需要食物和庇護。
  若角色願意提供避難所，逃兵可能成為強力同伴——但也可能出賣角色以求自保。
生存提示：逃兵是潛在的強力盟友，但也是定時炸彈。信任需要時間建立。
```

### 暴徒（Looter/Raider）——威脅 2–3

```
【暴徒（暴徒）】
威脅等級：2（單獨）／3（結夥 3 人以上）
屬性：體魄 3 / 機敏 3 / 意志 2
察覺值：+2
移動速度：1 距離帶／回合
攻擊方式：
  • 棍棒／鐵管（+2 近戰，傷害：輕傷 → 重傷）
  • 小刀（+3 近戰，傷害：重傷）
  • 手槍（+1 射擊，射程 20 公尺，傷害：重傷——僅 30% 機率有槍）
特殊能力：
  • 人多勢眾：3 人以上時，攻擊檢定 +1（夾擊）
  • 掠奪：知道哪些地點可能還有物資
弱點：
  • 無組織——可能內鬨
  • 欺軟怕硬——若遇到堅決抵抗（角色反擊造成任何傷勢），意志 DC 12 否則撤退
  • 噪音大——暴徒自己也會引來敵軍
行為模式：
  搜刮空屋、搶劫其他倖存者。遇到單獨平民時可能要求「交出所有物資」。
  不一定立即暴力——先恐嚇。若角色順從，可能只拿走一部分物資。
  若角色抵抗或逃跑，追擊 2d4 回合後放棄（怕引來軍隊）。
生存提示：暴徒是欺軟怕硬的機會主義者。有時交出部分物資比戰鬥更安全。
```

### 野狗（Feral Dog）——威脅 1–2

```
【野狗（野狗）】
威脅等級：1（單隻）／2（群 3 隻以上）
屬性：體魄 2 / 機敏 4 / 意志 1
察覺值：+4（嗅覺）／+2（聽覺）
移動速度：2 距離帶／回合
攻擊方式：
  • 撕咬（+3 近戰，傷害：輕傷 + 感染風險——體魄 DC 10）
  • 群體圍攻：3 隻以上同時攻擊同一目標 → 攻擊獲得優勢
特殊能力：
  • 追蹤氣味：可追蹤 24 小時內的氣味軌跡
  • 夜視：黑暗中視野不受影響
弱點：
  • 怕火——火焰或大聲響可驅散（意志 DC 8 否則逃跑）
  • 飢餓——可用食物引開（投擲食物，自動成功轉移注意）
  • 受傷後撤退——單隻野狗受到任何傷勢即逃跑
行為模式：
  飢餓驅動，尋找任何可吃的東西。可能攻擊受傷／虛弱的倖存者。
  群體會包圍獵物。先吠叫警告，若目標不撤退則攻擊。
  不會追擊進入建築物的目標（除非極度飢餓）。
生存提示：野狗怕火，可用食物引開。但被咬傷後務必處理傷口——感染風險是真實的。
```

## GM 遭遇設計建議

### 威脅組合參考

| 遭遇 | 威脅總和 | 適合劇本 |
|------|---------|---------|
| 1 隊巡邏兵（2 名） | 4 | S1 初期 |
| 野狗群（3 隻） | 6（群體） | S1–S2 |
| 巡邏兵（2 名）+ 軍官（1 名） | 7 | S2 |
| 暴徒（3 名） | 9（結夥） | S2 |
| 狙擊手（1 名）+ 巡邏兵（2 名） | 8 | S2–S3 |
| 軍官（1 名）+ 巡邏兵（4 名） | 11 | S3 |

### 單人玩家提示

- 永遠提供潛行繞過的選項
- 遭遇不應是「必須解決的障礙」，而是「需要評估的風險」
- 讓玩家看到巡邏路線、聽到腳步聲——給他們準備的時間
- 即使被發現，逃跑永遠是有效選項
