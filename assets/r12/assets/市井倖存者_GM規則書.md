# 第一部份：核心規則（玩家與 GM 通用）

> 本部份內容與《玩家規則書》一致。無論你是玩家還是 GM，這些是遊戲的基礎機制。

## 第一章：骰子系統——3d6 貝爾曲線

《市井倖存者》使用 **3d6 + 屬性值** 的檢定系統。擲三顆六面骰，取總和，加上屬性值，與難度等級（DC）比較。

**設計理念：** 三顆骰子形成貝爾曲線——結果向中央集中，極端值（3 或 18）各僅 0.46%。這模擬普通人的穩定能力，而非英雄式的隨機起伏。

## 第二章：五大屬性與衍生屬性

### 五大屬性（範圍 0–5，20 點分配）

| 屬性 | 全稱 | 含義 |
|------|------|------|
| **體魄** | 體魄（身體） | 身體健康和體力 |
| **機敏** | 機敏（敏捷） | 警覺性、速度和靈巧 |
| **意志** | 意志（意志） | 精神韌性和心理承受力 |
| **社交** | 社交（社交） | 溝通和建立信任的能力 |
| **手藝** | 手藝（手藝） | 實用技能和應變能力 |

屬性值即調整值（無需轉換）。體魄 4 就擲 3d6+4。

### 衍生屬性

| 衍生屬性 | 計算公式 | 說明 |
|---------|---------|------|
| **體力** | 體魄 × 2 + 5 | 每日行動點上限。歸零 → 無法行動 |
| **飽足度** | 0–10（初始 7） | <3 → 體魄檢定劣勢 |
| **溫暖度** | 0–10（初始依季節） | <3 → 每日體魄 −1 |
| **精神狀態** | 意志 × 2 | 歸零 → 崩潰狀態 |
| **隱蔽值** | 機敏 + 環境掩體 | 敵方察覺的 DC |

## 第三章：檢定規則

### 難度等級（DC）階梯

| DC | 難度 | 典型情境 | 屬性 +2 成功率 |
|----|------|---------|---------------|
| 6 | 輕而易舉 | 找到顯眼的罐頭 | ~99% |
| 8 | 簡單 | 封住小窗 | ~95% |
| 10 | 普通 | 說服友善鄰居 | ~84% |
| 12 | 有難度 | 巡邏時保持安靜 | ~62% |
| 14 | 困難 | 穿過狙擊手視野 | ~37% |
| 16 | 嚴峻 | 砲擊中領導撤離 | ~16% |
| 18 | 極端 | 搬開混凝土梁 | ~5% |
| 20 | 近乎不可能 | 餓三天後背人走五公里 | ~0.5% |

### 檢定結果分級

| 結果 | 條件 | 敘事含義 |
|------|------|---------|
| **大失敗** | 自然骰 ≤ 4 | 局勢明顯惡化 |
| **失敗** | 總值 ≤ DC−3 | 正常後果 |
| **代價成功** | 總值 = DC−2 或 DC−1 | 做到了但有代價 |
| **成功** | 總值 ≥ DC | 如預期完成 |
| **大成功** | 自然骰 ≥ 17 | 卓越成功 |

> **GM 提示：代價成功是本遊戲的核心張力來源。** 不要讓代價變成純粹的懲罰——讓它成為推動故事的轉折點。門開了但發出聲音（引來注意）、說服了對方但他要求回報（未來的債務）、找到罐頭但割傷手指（感染風險）。

### 對抗檢定

雙方各擲 `3d6 + 屬性值`，較高者勝出。平手時主動方以代價成功達成。

### 團隊檢定

半數以上成功 → 整體成功。僅一人失敗 → 由成功者之一補救（額外檢定，消耗體力）。

## 第四章：優劣勢系統

| 狀態 | 擲骰方式 |
|------|---------|
| **優勢** | 4d6 取最高三顆 |
| **正常** | 3d6 |
| **劣勢** | 4d6 取最低三顆 |

**優勢觸發：** 職業專長、充分準備（消耗 2 體力）、同伴協助（協助者消耗 1 體力）、高品質工具、命運點。

**劣勢觸發：** 飢餓（飽足度 <3）、寒冷（溫暖度 <3）、受傷、恐懼狀態、黑暗中行動。

不疊加。同時存在 → 互相抵消。

### 優劣勢數學影響（屬性 +2，DC 12）

| 模式 | 成功率 |
|------|--------|
| 劣勢 | ~22% |
| 正常 | ~62% |
| 優勢 | ~89% |

## 第五章：休息與恢復

### 休息類型

| 休息類型 | 體力恢復 | 其他效果 |
|---------|---------|---------|
| **短休息**（1–2h） | +（體魄 + 2） | 消除 1 級力竭 |
| **長休息/睡眠**（6–8h，需安全環境） | 全部 | 精神 +意志值（DC 10）；創傷 −1（密封 ≥ 3） |
| **完整休息日**（不外出） | 全部 | 精神 +2；消除全力竭；傷勢推進 1 天 |

### 力竭狀態

| 等級 | 效果 | 消除 |
|------|------|------|
| 1 級 | 體魄 −1 | 短休息 |
| 2 級 | 體魄、機敏 −2 | 長休息 |
| 3 級 | 所有 −3，移速減半 | 完整休息日 |

### 士氣

| 狀態 | 觸發 | 效果 |
|------|------|------|
| 鼓舞 | 藝術表演、好消息 | 意志 +1 至下次休息 |
| 正常 | 日常 | — |
| 低落 | 連續失敗、死亡 | 社交 −1 |

> **GM 提示：** 士氣是靈活的敘事工具——不需要玩家追蹤數值。當劇情走向黑暗時，自然讓士氣低落。當玩家做出英勇或感人的行為時，給予鼓舞。

## 第六章：命運點系統

每位玩家初始 **3 點**（上限 5 點）。可用於：重擲（擲後）、獲得優勢（擲前）、消除代價。每完成劇本章節恢復 1 點；重大道德犧牲時恢復 1 點。

# 第二部份：角色創建（GM 指導）

## 第七章：戰前職業系統

你的玩家不是英雄——他們是普通人。12 種戰前職業定義了他們圍城前的身分。

### 職業列表與 GM 提示

| # | 職業 | 核心優勢 | GM 提示 |
|---|------|---------|---------|
| 1 | 教師 | 安撫、教導 | 給他們需要安撫的 NPC；他們的說服對象不一定是敵人 |
| 2 | 醫護人員 | 醫療 | 圍城中最珍貴的角色——給他們道德困境（只有一份藥，兩個傷者） |
| 3 | 麵包師傅/廚師 | 食物處理 | 物資轉化的關鍵角色；食物不足時他們的技能決定生死 |
| 4 | 水電工/技工 | 修理 | 給他們可以修理的東西——收音機、發電機、破損的窗戶 |
| 5 | 小販/商販 | 議價 | 黑市場景是他們的舞台；讓他們發揮交易直覺 |
| 6 | 記者/撰稿人 | 觀察、記錄 | 他們的記錄可以成為遊戲中的關鍵道具 |
| 7 | 學生 | 快速學習 | 潛力型——給他們成長的機會和需要保護的理由 |
| 8 | 退伍軍人 ⚠️ | 戰術 | 限制使用——每團最多 1 位；他們的 PTSD 是劇情引擎 |
| 9 | 社工/輔導員/神職 | 心靈支柱 | 給他們需要安慰的 NPC；他們是團隊的精神支柱 |
| 10 | 司機/送貨員 | 導航 | 城市移動場景中不可或缺 |
| 11 | 藝術家/音樂家 | 士氣 | 在黑暗時刻給他們發光的機會——一首歌可能拯救一個人的理智 |
| 12 | 會計師/公務員 | 物資管理 | 資源追蹤是他們的超能力 |

### 職業機制：熟練 +2 + 優勢

戰前職業賦予的技能：起始熟練度為 +2，且使用該技能時獲得**優勢**（4d6k3）。這使職業技能在可靠性上顯著優於普通技能。

## 第八章：20 項技能與屬性映射

### 體魄技能
- **耐力**：長時間勞動、強行軍、扛重物
- **力氣**：舉起重物、撬開門窗、近身力量對抗
- **承受**：抵抗疾病毒素、忍受傷痛

### 機敏技能
- **潛行**：無聲移動、躲避視線
- **攀爬**：爬牆、穿越廢墟
- **駕駛**：駕駛車輛、躲避追擊
- **搜索**：搜刮物資、發現隱藏物品
- **巧手**：精細操作、偷竊、解鎖

### 意志技能
- **鎮定**：保持冷靜、抵抗恐懼
- **警覺**：感知危險、注意到不對勁
- **忍耐**：在極端環境中堅持
- **記憶**：記住路線、人臉、密碼

### 社交技能
- **說服**：改變態度、獲取信任
- **欺瞞**：說謊、偽裝身分
- **安撫**：緩解恐懼、化解衝突
- **議價**：以物易物、判斷價值
- **察言觀色**：判斷意圖、感知謊言

### 手藝技能
- **修理**：修理物品、應急補救
- **急救**：處理傷口、止血、骨折固定
- **烹飪**：準備食物、最大化營養
- **藥理**：辨別藥物、配製藥劑
- **電工**：處理電力系統、接線

### 熟練度階梯

| 等級 | 加值 | 效果 |
|------|------|------|
| 未受訓 (0) | +0 | 可嘗試 |
| 初通 (1) | +1 | 基本了解 |
| 熟練 (2) | +2 | 可靠水準 |
| 老手 (3) | +3 | 經驗豐富 |
| 專家 (4) | +3 + 優勢 | 領域權威 |
| 大師 (5) | +3 + 優勢 + DC−1 | 傳奇 |

技能檢定公式：`3d6 + 屬性值 + 熟練度加值`（有職業覆蓋時 4d6k3）

### GM 提示：技能交叉適用

允許玩家用非預設屬性使用技能：
- 攀爬（體魄）——長時間攀爬考驗耐力
- 急救（意志）——砲火下急救考驗冷靜
- 說服（意志）——以堅定信念說服他人

這確保單人角色的技能組合能靈活應對多樣情境。

## 第九章：角色創建九步驟（GM 引導）

作為 GM，引導玩家完成這九個步驟。每一步都是**敘事 + 機制**的結合——不要讓創角變成填表練習。

1. **你是誰？** → 名字、年齡、戰前職業
2. **被困在哪裡？** → 圍城開始時的位置和身邊的人
3. **屬性配點** → 20 點分配（0–5），每個 ≥3 的屬性給一個初通技能
4. **自由技能** → 選 2 項初通技能
5. **避難所** → 3 點分配結構/密封/舒適度
6. **失去的人** → 具體的人、具體的失去方式、最後一面
7. **保護對象** → 物品或人——這將是遊戲中的核心動力
8. **隨身物品** → 不超過負重槽位
9. **最後潤色** → 性格特質、習慣、秘密

### GM 特別注意

- **步驟 6 和 7 是最重要的**——它們定義了角色的情感核心
- 讓玩家詳細描述「失去」——不要讓它變成一個簡單的「死了」
- 「保護對象」將是你作為 GM 最重要的劇情工具——保護它、威脅它、讓玩家為它做出艱難的選擇

# 第三部份：生存與衝突系統（完整規則）

## 第十章：隱蔽與潛行（GM 視角）

### 隱蔽值計算

```
玩家隱蔽值 = 機敏 + 環境掩體加成 + 動態調整
```

| 環境 | 掩體加成 |
|------|---------|
| 開闊地帶 | −3 |
| 稀疏遮蔽 | +0 |
| 中等掩體（廢墟、車輛後） | +3 |
| 良好掩體（地下室、暗巷） | +5 |
| 完全隱蔽（地道、偽裝後方） | +8 |

| 動態因素 | 調整 |
|---------|------|
| 靜止 | +2 |
| 緩慢移動 | +0 |
| 正常移動 | −2 |
| 奔跑 | −5 |
| 深色衣物 | +1 |
| 輕傷 | −1 |
| 重傷 | −3 |

### 敵軍察覺機制

```
敵軍察覺檢定 = 3d6 + 敵軍察覺值 對抗 玩家隱蔽值
```

**察覺結果：**

| 檢定結果 vs 隱蔽值 | 效果 |
|-------------------|------|
| 低於 5+ | 完全未察覺 |
| 低於 1–4 | 略微疑心——下回合察覺值 +1 |
| 等於或超過 | 發現異常——進入警戒狀態，下回合優勢 |
| 超過 5+ | 明確發現——立即採取行動（呼叫支援、開火、追擊） |

**敵軍警戒狀態：**

| 狀態 | 察覺值調整 |
|------|-----------|
| 常規巡邏 | −2 |
| 警戒 | ±0 |
| 搜捕 | +3，察覺優勢 |

### 噪音系統（GM 工具）

| 噪音等級 | 傳播距離 | 典型行動 |
|---------|---------|---------|
| 0（無聲） | 0m | 屏息、手勢 |
| 1（極低） | 5m | 爬行、耳語 |
| 2（低） | 15m | 慢行、輕聲、開門 |
| 3（中） | 30m | 快走、對話、撬鎖 |
| 4（高） | 60m | 奔跑、碎玻璃、撞門 |
| 5（極高） | 150m | 槍聲、爆炸、尖叫 |
| 6（震耳） | 500m+ | 砲擊、連續槍戰 |

**噪音傳播規則：**
- 每道厚牆：距離減半
- 每扇關門：距離 −25%
- 空曠建築/隧道：距離 ×1.5
- 背景噪音（砲擊/大雨）：所有噪音等級 −1

**噪音後果：**
- 噪音範圍內有敵軍 → 察覺檢定（+2）
- 噪音等級 ≥5 → 自動進入搜捕狀態 + 可能呼叫增援

### 光線與視線

| 光線 | 察覺影響 | 隱蔽影響 |
|------|---------|---------|
| 明亮 | 正常 | 正常 |
| 昏暗 | 察覺劣勢 | 隱蔽 +2 |
| 黑暗 | 察覺劣勢，視野減半 | 隱蔽 +5 |
| 全黑 | 無法視覺察覺 | 無聲即自動隱蔽 |

> **GM 提醒：** 讓玩家記住——任何光源都是燈塔。手持電筒讓你看得見 20 公尺，但也讓敵軍在 200 公尺外看見你。

### 集體潛行

```
集體隱蔽值 = 最低隱蔽值 − (人數 − 1)
```

| 人數 | 減免 |
|------|------|
| 1 | −0 |
| 2 | −1 |
| 3 | −2 |
| 4–5 | −3 |
| 6+ | −5（自動發出噪音） |

### GM 潛行場景設計

為玩家提供多條路徑選擇：
- 標記巡邏路線讓玩家可以觀察和計劃
- 總是提供至少一條繞路選項（即使代價更高）
- 在不同的路徑中嵌入不同的風險/回報組合

## 第十一章：逃跑與追逐（完整規則）

### 追逐觸發

敵軍察覺檢定超過玩家隱蔽值 5+ → 追逐開始。

**先攻：** 所有參與者擲 `3d6 + 機敏`，由高到低行動。

### 距離帶系統

| 距離帶 | 範圍 | 效果 |
|--------|------|------|
| 近距 | 0–10m | 敵軍可近戰攻擊。無法躲藏 |
| 中距 | 11–30m | 可射擊。躲藏劣勢 |
| 遠距 | 31–60m | 可射擊。可躲藏 |
| 脫離 | 61–100m | 敵軍射擊劣勢。正常躲藏 |
| 逃脫 | 100m+ | 可重新建立隱蔽 |

### 玩家行動選項

| 行動 | 檢定 | 成功 | 失敗 |
|------|------|------|------|
| 全力奔跑 | 體魄 DC 10 | +2 帶 | +1 帶 + 力竭 |
| 靈活穿梭 | 機敏 DC 12 | +1 帶 + 追擊者劣勢 | 不變 |
| 利用障礙 | 機敏 DC 10 | +2 帶 | −1 帶 |
| 躲藏 | 機敏 DC 14 | 遠距以上：進入躲藏 | −1 帶 |

### 追擊者行為（GM 控制）

| 類型 | 每回合 |
|------|--------|
| 步兵/巡邏兵 | 移動 1 帶 + 1 次射擊（射程內） |
| 軍犬 | 移動 2 帶。無視障礙 |
| 車輛 | 移動 3 帶。無法進入窄巷 |
| 狙擊手 | 不移動。每次射擊致命威脅 |

### 重新建立隱蔽

1. 尋找藏身處：機敏 DC 12
2. 靜默 3 回合（無 ≥2 級噪音）
3. 等待敵軍放棄：1d6+1 回合（搜捕狀態則 2d6+3）

## 第十二章：絕望自衛系統（GM 完整規則）

> **GM 核心原則：** 本章的規則不是讓玩家「戰鬥」用的。如果玩家需要使用這些規則，他們已經處於極度危險之中。確保玩家在事前就知道這一點。

### 傷勢等級系統（無 HP）

本遊戲不使用生命值。所有傷害透過傷勢等級追蹤：

| 平民承受… | 傷勢 |
|----------|------|
| 1 次命中 | 輕傷 |
| 2 次命中 | 重傷 |
| 3 次命中 | 致命傷 |
| 槍械（步槍） | 至少重傷 |
| 狙擊步槍 | 至少致命傷，可能直接死亡 |

### 自衛回合結構（約 6 秒）

1. 宣告意圖
2. 先攻順序（3d6 + 機敏）
3. 每個角色：1 主要行動 + 1 移動行動
4. 結算持續效果 + 噪音

### 攻擊公式

```
攻擊檢定 = 3d6 + 體魄（或機敏）
目標 DC = 防禦值 = 5 + 機敏 + 掩體加成 + 護甲加成
```

| 防禦因子 | 加值 |
|---------|------|
| 無掩體站立 | +0 |
| 半掩體（翻倒桌子、車輛後方） | +3 |
| 全掩體（厚牆後、只露眼睛） | +5 |
| 厚重衣物 | +1 |
| 臨時護甲（木板） | +1 |
| **全力防禦**（放棄攻擊，專心閃避/格擋） | **+5** |

> **GM 參考：** 平民無掩體（機敏 3）→ 防禦 8，巡邏兵命中約 84%。同一平民全掩體 + 全力防禦 → 防禦 18，巡邏兵命中約 5%。讓玩家知道掩體的重要性。

**傷勢判定：**

| 檢定 vs 防禦值 | 傷勢 |
|---------------|------|
| 剛好達標 | 輕傷 |
| 超過 3–6 | 重傷 |
| 超過 7+ | 致命傷 |
| 自然骰 ≥17 且達標 | 致命傷 + 特殊效果 |

### 死亡規則

**觸發條件（任一）：**
1. 體力歸零且無法恢復
2. 致命傷 24 小時內無醫療

4. 第 4 級傷勢
5. 直接致命事件（狙擊爆頭、壓埋 10+ 分鐘、火災被困）

**臨終時刻：** 意志 DC 16 → 清醒 d4 分鐘做最後一件事；DC 10 → 昏迷中離世；<10 → 痛苦中離世。

## 第十五章：環境危害（GM 參考）

### 炮擊/空襲

**觸發：** 劇本事件或每日隨機（d20：1–3）

**三階段：**
1. **尖嘯**（1 回合）：可做 1 個反應

|------|------|-----|---------|
| 輕度 | 20m | 10 | 結構 −1 |

| 重度 | 80m | 18 | 結構 −1d6+2，30% 未爆彈 |

3. **餘波**：灰塵、火災、坍塌、倖存者被埋

### 建築坍塌

- 第一反應：機敏 DC 14（跳出）→ 失敗：被埋
- 被埋：體魄 DC 16（呼吸空間）→ 失敗：重傷 + 每 10 分鐘 −1 體力
- 救援：手藝 DC 14（定位）+ 體力 5（挖掘）+ d20 風險

每 5 分鐘蔓延：起火點 → 相鄰房間 → 整層 → 整棟（每回合 1-5 坍塌風險）

### 未爆彈

遭遇機率依地點風險（DC 5–20）。發現：機敏 DC 14（被動）/ DC 10（主動）。繞過：機敏 DC 12。拆除：手藝 DC 20（失敗 → 直接死亡）。

> **永遠告訴玩家：不要碰。繞過去。**

# 第五部份：GM 運行指南

## 第二十章：敘事技巧

### 感官敘事法

不要只說「你走進一條街道」。描述：
- **視覺：** 灰塵在斜陽中飄浮，對面大樓的窗戶像空洞的眼窩
- **聽覺：** 遠方斷斷續續的槍聲，近處某處傳來嬰兒的哭聲
- **嗅覺：** 腐爛的氣味、燒焦的橡膠、雨水浸透的灰泥
- **觸覺：** 腳下碎玻璃的嘎吱聲，冰冷的門把
- **味覺：** 嘴裡灰塵的味道，最後一口水的珍貴

### 微光法則

每次重大失去或黑暗時刻之後，給予一絲微小的希望：
- 看到兒童屍體 → 轉角發現一盒未開封的蠟筆
- 同伴死亡 → 他的口袋裡有一張你從未見過的、你的素描
- 避難所被發現 → 撤離時發現了一條你從未走過的祕密通道

微光不是為了讓遊戲「變輕鬆」——而是為了讓黑暗中的人有理由繼續前進。

### 絕望量表（1–10）

| 等級 | 描述 | GM 調整 |
|------|------|---------|
| 1–3 | 緊張但可控 | 正常難度 |
| 4–6 | 壓力增加 | 提高遭遇頻率，減少物資 |
| 7–8 | 瀕臨絕望 | 提高 DC 1–2，增加道德困境 |
| 9–10 | 崩潰邊緣 | 劇情高潮——重大抉擇或結局觸發 |

### 難度五槓桿

調整遊戲難度不用改規則，只需調整這五個槓桿：
1. **物資出現率**——搜刮 DC 和獎勵
2. **遭遇頻率**——隨機遭遇的觸發機率
3. **NPC 可靠性**——NPC 說實話的機率
4. **環境危險**——砲擊頻率和強度
5. **資訊可得性**——線索的模糊程度

## 第二十一章：單人玩家 GM 技巧

### NPC 同伴扮演三原則

1. **NPC 是人，不是工具**——他們有自己的需求、恐懼和極限
2. **不替玩家做決定**——NPC 提供意見但從不越俎代庖
3. **NPC 也會犯錯**——他們的建議可能是錯的

### 三幕結構

每場遊戲可依三幕設計（約 3–4 小時）：

| 幕 | 佔比 | 內容 |
|----|------|------|
| **第一幕** | 25% | 日常生存、避難所維護、NPC 互動 |
| **第二幕** | 50% | 外出搜刮/任務、遭遇、道德抉擇 |
| **第三幕** | 25% | 返回、後果處理、鋪墊下一場 |

### 失敗不是終點

單人角色失敗時，提供「代價」而非「死亡」：
- 被捕（開啟逃脫劇情線）
- 失去物資（增加生存壓力）
- 受傷（增加恢復壓力）
- NPC 付出代價（情感衝擊）
- 被迫接受不利交易

## 第二十二章：道德抉擇設計

### 六大道德困境類型

1. **資源分配**——誰得到最後的藥/食物？
2. **信任**——開門讓陌生人進來嗎？
3. **手段與目的**——偷竊/傷害他人來救自己人？
4. **犧牲**——為他人冒生命危險？
5. **真相與謊言**——告訴同伴殘酷的真相還是善意的謊言？
6. **離開與留下**——自己逃走還是留下來保護他人？

### GM 呈現守則

- **絕不說教**——不要暗示「正確答案」。每個選擇都有代價
- **展示後果而非評判**——不要說「你做了壞事」，而是展示第二天街上的屍體
- **讓 NPC 記住**——NPC 會記得你做的每個選擇，並因此改變對你的態度
- **沒有重置鍵**——後果是永久的，但也不是世界末日

## 第二十六章：劇本三「終局之門」——難度 ★★★★☆

### 概述
圍城進入第一百天。結局即將到來，但以何種形式？玩家必須做出最終的抉擇——而這個抉擇將永久改變剩下的一切。

### 多方勢力最終邀請

| 勢力 | 提議 | 代價 |
|------|------|------|
| 聯邦軍（KFA） | 加入最後的突圍行動 | 極高的死亡風險 |
| 黑河商會（BRS） | 秘密撤離通道（名額有限） | 鉅額代價——所有物資或一個祕密 |
| 自由之聲（VoL） | 參與最終抵抗行動 | 幾乎注定犧牲 |
| 國際人道團（IHA） | 談判撤離（限平民） | 需證明「平民身份」——可能需放棄武裝同伴 |
| 教會 | 留在城市、守護留下的人 | 承受圍城的最後階段 |

### 關鍵 NPC 終局選擇
每個 NPC 在終局中都有自己的選擇——他們的選擇與玩家的選擇互相影響。安德烈神父選擇留下守護教堂、雅娜考慮帶領社區突圍、「教授」準備自己的撤離計劃、迪米特里面臨最後的救贖機會等。（完整 NPC 數據見第七部份）

### 終極道德困境——「信號」

玩家獲得一個無線電頻率——圍城方的指揮頻率。他們可以：
- **選項 A：** 將頻率交給自由之聲 → 可能扭轉戰局，但必然引發報復性屠殺
- **選項 B：** 將頻率交給黑河商會 → 換取安全撤離，但城市中的其他人將被拋棄
- **選項 C：** 使用頻率談判 → 嘗試為自己爭取安全通行，成功率極低
- **選項 D：** 摧毀頻率 → 什麼都不做，讓命運自然發展

### 結局條件
根據劇本一和二的累積選擇、NPC 關係、資源狀態、以及劇本三中的最終抉擇，觸發六種結局之一（見第八部份）。

> **🟢 創傷緩解節點：** 當玩家在 S3 中完成一項核心任務（如成功處理「信號」困境、幫助關鍵 NPC 完成他們的終局選擇、或做出最終抉擇），可獲得一次性創傷累積 −5。這是長戰役中唯一的重大喘息機會——代表角色在終局找到了某種和解或意義。

### 困境設計公式（GM 即興創作）

```
困境 = 稀有資源 + 兩個（或多個）需要它的人 + 時間壓力 + 沒有完美答案
```

範例：一份抗生素（稀有資源）+ 受傷的同伴 vs 發燒的孩子（兩個需要者）+ 「必須在天亮前決定因為巡邏路線會改變」（時間壓力）。沒有選項能讓所有人都活下來。

## 第三十一章：特殊事件

### 空襲

觸發：劇本指定或 DM 裁量。描述砲彈破空的尖嘯聲 → 衝擊波 → 灰塵與瓦礫。可摧毀或損壞避難所、改變地形、創造新的搜刮機會（廢墟中）。

### 停火談判

圍城方與守城方進行短暫談判。期間：白晝外出風險大幅降低、可能有物資車隊進入城市、黑市價格暴跌。但談判可能隨時破裂——製造虛假的安全感。

### 補給空投

人道組織空投物資——食物、藥品、水。但：空投地點是危險的開闊地帶、多個勢力會同時前往搶奪、可能引發暴力衝突。

### 暴動

當謠言（真或假）引發恐慌時：人群湧向某處、踩踏和混亂、避難所可能被衝擊。玩家必須決定：加入人群、躲藏、還是試圖幫助他人。

### 瘟疫爆發

骯髒的環境 + 營養不良 + 缺乏醫療 = 瘟疫。疾病在避難所/社區中傳播，玩家需尋找藥品、隔離病患、決定如何分配有限的醫療資源。

# 第九部份：結局系統

## 第三十二章：六種結局

### 結局一：解放（Liberation）

友軍突破圍城防線，城市重獲自由。

**觸發條件：** 存活超過圍城總天數（GM 設定），且至少維持一個運作中的避難所。

**敘事框架：** 「砲聲在黎明前停止了。然後你聽到了——不是砲彈的尖嘯，而是歡呼。從街道的遠端，從廢墟的深處，從每一個還有人活著的角落。裝甲車上的旗幟不是敵軍的。你站在門口，陽光刺痛了你習慣黑暗的眼睛。戰爭結束了。但你還不是完整的人——也許永遠不會是了。」

### 結局二：撤圍（Lifting of Siege）

外交壓力或戰略轉移導致圍城解除。

**觸發條件：** 擁有無線電並接收到相關情報，且成功將情報傳遞給關鍵勢力。

### 結局三：陷落（Fall）

敵軍突破最後防線，全面佔領城市。

**觸發條件：** 無法阻止敵軍最終攻勢。玩家必須在陷落前逃離或躲藏。

**敘事框架：** 「坦克的履帶碾過自由廣場的石板——那些你曾在上面喝咖啡、約會、抗議、生活的石板。城市沒有投降，它只是不再抵抗了。你看著窗外的旗幟被換掉，然後拉上了窗簾。」

### 結局四：逃亡（Escape）

你找到了離開城市的路。

**觸發條件：** 透過黑市購買安全通道，或參加突圍行動。

### 結局五：凍餓而死——沒有達成任何結局

**觸發條件：** 資源耗盡，無法維持基本生存。

### 結局六：開放式（Open Ending）

適用於想繼續遊戲的團隊——圍城仍在繼續，故事尚未結束。

## 第三十三章：結局判定框架

```
結局 = 世界設定（40%）+ 玩家影響力（30%）+ 關鍵事件（20%）+ 隨機（10%）
```

GM 根據四個因素的加權，決定圍城的最終走向。玩家不能「決定」結局，但他們的每個選擇都在影響結果。

### 結局後處理

1. **角色總結：** 每個存活角色獲得結局敘述——基於選擇、關係、創傷
2. **遺留問題：** 提出「後來呢？」的問題——角色之後去了哪裡？關係是否持續？
3. **集體回顧：** 讓玩家分享最難忘的時刻
4. **GM 的結語：** 為這場圍城畫上句點

# 第十一部份：多人模式 GM 指南

## 多人模式調整

《市井倖存者》預設單人遊玩。多人模式（2–4 位玩家）需進行以下調整：

### 創角協調
- 建議玩家選擇不同職業——互補技能組合讓團隊更有韌性
- 角色關係需在創角時協商（圍城前認識？圍城後相遇？）

### 共享避難所
- 結構/密封度取全員最高值；舒適度取平均值
- 儲備容量 = 10 + (人數 × 5) 單位
- 每位成員獨立消耗食物和水

### 難度調整
- 遭遇頻率：+25%（多人活動更容易被察覺）
- 資源消耗：每位成員各自消耗
- 集體潛行更困難（使用集體隱蔽值公式）

### 角色衝突管理
- 資源分配衝突是多人模式的核心張力——不要迴避
- 不同玩家的「保護對象」可能互相矛盾——這是精彩的劇情素材
- 若玩家間無法達成共識，使用對抗社交檢定（社交對抗社交）

### 時間管理
- 團隊可分工（一人搜刮、一人留守），同時進行多個行動
- GM 輪流處理每位玩家的行動段落（每人約 10–15 分鐘）

### 車輛規則
- 每駕駛 1 小時消耗 1 單位汽油
- 車輛噪音等級 5（引擎聲）——會引來方圓 150 公尺內的注意
- 車輛提供移動速度 ×3（3 距離帶/回合）
- 車輛可作為臨時掩體（防禦值 +3）
