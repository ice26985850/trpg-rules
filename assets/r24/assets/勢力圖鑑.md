### 5.6.3 八個預設NPC地城（核心外交對象）

#### 1. 「鐵骨侯爵」馬爾薩斯——亡靈之主 Lv8
- **地城**：永眠迴廊（純白骨骼構成的優雅迷宮）
- **屬性**：深度(DEP)8 / 惡名(INF)7 / 防禦(DEF)5 / 財富(WLH)6 / 魔力(MAG)9
- **特產**：高級骷髏兵（戰力(CP)1/經營(MV)1, 維護免費）、骨鴿（遠程即時通信）、靈魂精華
- **性格**：沉默寡言，崇尚效率。極度厭惡光明教團
- **態度**：中立(0)。同是亡靈領主→友好+3。有光明教團共同敵人→好感+2
- **外交鉤子**：教團聯合防禦、亡靈勞工技術交流、失落的骨冢遺址線索、請求調解骨冢議會爭端

#### 2. 「裂地者」巴爾澤克——深淵惡魔 Lv10
- **地城**：焚天堡（熔岩河環繞的巨型黑曜石城堡）
- **屬性**：深度(DEP)9 / 惡名(INF)9 / 防禦(DEF)7 / 財富(WLH)5 / 魔力(MAG)6
- **特產**：地獄犬（戰力(CP)3/經營(MV)1）、火焰符文石（陷阱附魔）、惡魔僕從
- **性格**：暴躁傲慢，蔑視弱小。"力量即正義"。對亡靈之主天然鄙視
- **態度**：冷淡(-3)。需展示力量（DOM檢定或擊敗特定冒險者）→改善
- **外交鉤子**：火焰試煉（證明力量）、聯合遠征地表、指定冒險者目標獵殺、炎湖深淵魔獸爲患

#### 3. 「織網者」維拉——暗影議會 Lv6
- **地城**：暗廳迷宮（走廊會自行移動的暗影迷宮）
- **屬性**：深度(DEP)7 / 惡名(INF)10 / 防禦(DEF)5 / 財富(WLH)8 / 魔力(MAG)7
- **特產**：各類情報（品質最高）、暗影信鴿、情報屏蔽服務
- **性格**：神祕莫測，永遠微笑。"情報比軍隊更值錢"
- **態度**：中立偏友好(+2)。情報交易極度熱情。對惡魔冷淡(-2："太吵")
- **外交鉤子**：情報交換、聯合暗殺行動、請求調查某冒險者背景、暗影網絡入會邀請

#### 4. 「大工匠」扳手——地精工程師 Lv5
- **地城**：齒輪要塞（蒸汽管道交織的機械迷宮，永遠響着鉚接聲）
- **屬性**：深度(DEP)5 / 惡名(INF)5 / 防禦(DEF)6 / 財富(WLH)9 / 魔力(MAG)3
- **特產**：機械哨兵（戰力(CP)2/經營(MV)1, 構裝體）、稀有建材（產量×2）、自動陷阱套件
- **性格**：熱情話癆，技術癡迷。"你看這個自動鉚接裝置！"
- **態度**：非常友好(+5)。對所有地城開放貿易。崇拜IND≥4的領主
- **外交鉤子**：技術研討會、向他展示你的新發明、聯合研發、建材大訂單折扣

#### 5. 「千面者」莫瑞斯——瘋狂巫師 Lv7
- **地城**：扭曲實驗室（瓶罐雜亂、牆壁滲出彩色液體、重力時有時無）
- **屬性**：深度(DEP)6 / 惡名(INF)7 / 防禦(DEF)4 / 財富(WLH)7 / 魔力(MAG)11
- **特產**：突變怪物（CP隨機2-5+隨機經營能力）、禁忌知識、變異藥劑
- **性格**：瘋癲而友善。科研狂熱，不在乎政治。態度隨機（每回合初擲d6）
- **態度**：隨機(d6)：1-2=友好, 3-4=中立, 5=冷淡, 6=極度熱情（附贈免費變異藥劑）
- **外交鉤子**：混沌突變實驗（可能極好也可能極壞）、分享"有趣的現象"、禁忌知識交換

#### 6. 「古鱗」瑟拉希爾——遠古巨龍 Lv12
- **地城**：龍眠深淵（黃金堆積如山的巨型洞窟，金幣滑落的叮噹聲是唯一背景音）
- **屬性**：深度(DEP)10 / 惡名(INF)8 / 防禦(DEF)8 / 財富(WLH)14 / 魔力(MAG)5
- **特產**：暗金幣貸款、遠古魔法物品、龍裔守衛（戰力(CP)5/經營(MV)3）
- **性格**：高傲冷漠。"你可以仰望我，但不要打擾我數金幣。"
- **態度**：冷淡(-2)。不關心任何地城的政治。只對高額貿易感興趣（單次交易≥◆50才願意談）
- **外交鉤子**：足夠的金幣、遠古神器線索（能打動她的好奇心）、貸款利息談判

#### 7. 「虛空編織者」艾瑟琳——瘋狂巫師 Lv5
- **地城**：虛空織坊（空間扭曲的紫羅蘭色魔法工坊，處處是傳送門）
- **屬性**：深度(DEP)5 / 惡名(INF)6 / 防禦(DEF)3 / 財富(WLH)6 / 魔力(MAG)12
- **特產**：空間摺疊袋（攜帶上限翻倍）、維度跳躍符文（單次傳送）、微型維度監獄（高級囚牢）
- **性格**：安靜專注，偶爾走神。"啊抱歉，我剛纔在另一個維度。"
- **態度**：對ARC≥3的領主友好(+3)。尤其歡迎魔力交流
- **外交鉤子**：空間魔法合作研究、傳送門網絡建設（減少遠征時間）、維度異常警告

#### 8. 「鏽蝕公爵」科爾溫——亡靈之主 Lv6
- **地城**：鏽蝕聖堂（墮落聖騎士的最終歸宿，聖徽倒懸於天花板）
- **屬性**：深度(DEP)6 / 惡名(INF)5 / 防禦(DEF)7 / 財富(WLH)5 / 魔力(MAG)6
- **特產**：墮落聖騎士（戰力(CP)4/經營(MV)2，可抵抗聖光）、聖光抗性訓練、教團內部情報
- **性格**：沉默、憂傷。"我曾是他們的英雄……現在我是他們的噩夢。"——渴望被理解
- **態度**：中立偏友好(+2)。對願意傾聽他故事的領主額外+2
- **外交鉤子**：教團情報（無人比他更瞭解光明教團）、聖光抗性訓練、幫他找回失落的聖徽碎片
