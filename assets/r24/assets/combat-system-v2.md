> **設計版本**: Draft v2.0（交叉評審修訂版）  
> **骰子系統**: d6骰池（5-6爲成功，6可爆擊追加1骰）  
> **對抗規則**: 攻擊方骰池 − 防禦方骰池 = 淨成功數 = 效果

## 一、戰鬥框架

### 1.1 回合結構

戰鬥採用**階段制回合結構**，每輪包含以下階段：

```
┌──────────────────────────────────────────────────┐
│              戰鬥輪結構 (Combat Round)             │
├──────────────────────────────────────────────────┤
│ 階段0: 預警階段 (Preparation Phase)               │
│   · 偵察檢定（CUN）揭示入侵者情報                   │
│   · 緊急徵召：經營怪物→戰鬥（可選）                 │
│   · 領主施展戰前儀式/法術                          │
├──────────────────────────────────────────────────┤
│ 階段1: 先攻階段 (Initiative Phase)                │
│   · 入侵方擲先攻：1d6 + 冒險者Tier修正             │
│   · 防禦方擲先攻：1d6 + 領主CUN修正                │
│   · 勝方決定本層誰先行動                           │
├──────────────────────────────────────────────────┤
│ 階段2: 行動階段 (Action Phase)                    │
│   · 雙方輪流執行單位行動                           │
│   · 每單位每輪：1移動 + 1標準動作 + 1附贈動作       │
│   · 先攻方先完成所有單位，後攻方接力                │
├──────────────────────────────────────────────────┤
│ 階段3: 環境階段 (Environment Phase)               │
│   · 陷阱觸發（按陷阱類型自動結算）                  │
│   · 持續效果結算（灼燒、中毒、詛咒等）              │
│   · 房間特殊效果結算                               │
├──────────────────────────────────────────────────┤
│ 階段4: 士氣階段 (Morale Phase)                    │
│   · 檢查雙方士氣狀態                               │
│   · 觸發潰逃/動搖檢定（WAR或DOM對抗）               │
│   · 怪物忠誠度變動檢定                             │
├──────────────────────────────────────────────────┤
│ 階段5: 推進階段 (Advance Phase)                   │
│   · 入侵方決定是否推進至下一防禦層                  │
│   · 防禦方決定是否戰術撤退                          │
│   · 戰損統計、俘虜判定                              │
└──────────────────────────────────────────────────┘
```

### 1.2 先攻規則

**先攻擲骰**：
- 入侵方：1d6 + [冒險者Tier]（T1=+0, T2=+1, T3=+2, T4=+3, T5=+4）
- 防禦方：1d6 + [領主CUN值]

**先攻效果**：
- 先攻勝方選擇本輪「先行」或「後行」
- 所有單位在所屬方回合內按任意順序行動
- Boss怪物擁有「先攻干預」：可花費1魔力結晶，在敵方回合插入一次行動

**可選變體 —— 個體先攻**（適合小型戰鬥）：
- 每個單位單獨擲 1d6 + CUN修正
- 按結果從高到低依次行動
- 適合：俘虜暴動、小型遭遇、PC親自出戰

### 1.3 動作體系

每單位每輪擁有：

| 動作類型 | 數量 | 說明 |
|---------|------|------|
| **移動** (Move) | 1 | 移動至相鄰房間/區域。某些怪物有特殊移動（飛行、穿牆、暗行） |
| **標準動作** (Standard) | 1 | 攻擊、施法、使用能力、防禦姿態、指揮等 |
| **附贈動作** (Bonus) | 1 | 快速能力、切換武器、喝藥水、簡短命令 |
| **反應** (Reaction) | 1 | 藉機攻擊（敵方從鄰接格移動時）、護衛（替鄰接友方承受攻擊）、觸發式能力 |

**常見標準動作**：

| 動作 | 消耗 | 效果 |
|------|------|------|
| 近戰攻擊 | 標準 | 擲CP骰池 vs 目標防禦骰池 |
| 遠程攻擊 | 標準 | 擲CP骰池 vs 目標防禦骰池（-1骰，除非有遠程特性） |
| 施法 | 標準 | 消耗魔力結晶/靈魂精華，擲ARC骰池 |
| 防禦姿態 | 標準 | 本回合防禦骰池+2，但不能攻擊 |
| 指揮 | 標準 | WAR檢定，成功則指定友方單位本回合攻擊+1骰 |
| 使用物品 | 標準/附贈 | 根據物品決定 |
| 援助 | 標準 | 給鄰接友方下一次檢定+1骰 |
| 威嚇 | 標準 | 戰策(WAR) vs 敵方WIL，成功則目標士氣-1 |
| 撤退 | 標準 | 從當前防禦層撤至下一層（需通過CUN檢定避免被藉機） |

### 1.4 戰鬥狀態追蹤

| 狀態 | 效果 | 持續 |
|------|------|------|
| **灼燒** | 每輪環境階段受到1火焰傷害 | 1d3輪，或用水/魔力熄滅 |
| **中毒** | 每輪行動階段骰池-1 | 1d3輪，或解毒 |
| **石化** | 無法行動，防禦骰池+2 | 1d3輪，或被解除 |
| **恐懼** | 攻擊骰池-2，無法主動接近恐懼源 | 1d3輪，或WAR檢定克服 |
| **眩暈** | 失去附贈動作和反應 | 1輪 |
| **倒地** | 近戰對其攻擊+1骰，其近戰攻擊-1骰 | 消耗移動起身 |
| **束縛** | 無法移動，防禦骰池-1 | 掙脫檢定（CP vs 束縛強度） |
| **詛咒** | 所有檢定骰池-1 | 需儀式/法術解除 |

## 二、傷害系統

### 2.1 傷害公式

**核心公式**：

```
攻擊檢定 = 攻擊方骰池（擲d6，5-6=成功，6爆擊+1骰）
防禦檢定 = 防禦方骰池（擲d6，5-6=成功，6爆擊+1骰）

淨成功數 = 攻擊成功數 − 防禦成功數
傷害 = max(1, 淨成功數) + 武器/能力修正
```

**骰池來源**：
- 攻擊骰池 = 單位CP + 武器加成 + 能力加成 + 環境加成 − 負面狀態
- 防禦骰池 = 單位CP + 護甲加成 + 掩體/DV加成 + 防禦姿態 − 負面狀態

**爆擊規則**：
- 每擲出1個「6」，除計爲1成功外，額外追加擲1d6
- 追加骰同樣5-6=成功，6繼續爆擊
- 爆擊鏈無上限（理論上可無限追加）

**傷害閾值**：
- 若淨成功數 ≤ 0：攻擊被完全格擋/閃避，造成0傷害
- 若淨成功數 = 1：擦傷/輕擊，造成1傷害
- 若淨成功數 ≥ 3：重擊！額外效果觸發（擊退/破甲/流血等，取決於攻擊類型）

### 2.2 傷害類型

| 傷害類型 | 典型來源 | 特殊規則 |
|---------|---------|---------|
| **劈砍** (Slashing) | 劍、斧、爪擊 | 對無甲目標淨成功數+1 |
| **穿刺** (Piercing) | 箭矢、矛、尖牙 | 無視1點護甲加成 |
| **鈍擊** (Bludgeoning) | 錘、拳、落石 | 對重甲目標淨成功數+1 |
| **火焰** (Fire) | 龍息、火球、地獄火 | 命中後附加「灼燒」狀態（50%概率） |
| **冰凍** (Frost) | 冰霜吐息、寒冰魔法 | 命中後目標下回合移動減半 |
| **雷電** (Lightning) | 閃電束、雷暴 | 對金屬護甲目標淨成功數+1 |
| **酸蝕** (Acid) | 史萊姆、酸液陷阱 | 命中後永久降低目標護甲加成1點 |
| **毒素** (Poison) | 毒液、毒氣陷阱 | 傷害延遲：下回合開始時結算 |
| **死靈** (Necrotic) | 亡靈魔法、詛咒 | 無法被常規治療恢復 |
| **光耀** (Radiant) | 聖光、神聖魔法 | 對亡靈/惡魔傷害翻倍 |
| **心靈** (Psychic) | 精神攻擊、恐懼光環 | 無視護甲，直接對抗WIL |

### 2.3 防禦與抗性

**防禦值（DV）來源**：

| 來源 | DV加成 | 說明 |
|------|--------|------|
| 基礎 | 0 | 無防護 |
| 輕甲 | +1 DV骰 | 皮甲、鍊甲衫 |
| 中甲 | +2 DV骰 | 鎖子甲、鱗甲 |
| 重甲 | +3 DV骰 | 板甲、龍鱗甲 |
| 盾牌 | +1 DV骰 | 需佔用一隻手持用 |
| 掩體 | +1~2 DV骰 | 半掩+1, 全掩+2 |
| 房間防禦 | +房間DV | 取決於房間類型和等級 |
| 防禦姿態 | +2 DV骰 | 消耗標準動作 |

**抗性/弱點/免疫**：

| 抗性等級 | 效果 | 示例 |
|---------|------|------|
| **免疫** (Immune) | 該類型傷害=0 | 火元素免疫火焰 |
| **抗性** (Resistant) | 該類型傷害減半（向下取整，最低1） | 石像鬼抗性劈砍 |
| **弱點** (Vulnerable) | 該類型傷害翻倍 | 冰元素弱點火焰 |
| **吸收** (Absorb) | 該類型傷害轉爲HP恢復 | 史萊姆吸收酸蝕 |

## 三、特殊能力體系

### 3.1 法術/技能等級框架

戰鬥能力分三類，各自獨立但可組合：

| 類別 | 驅動屬性 | 資源 | 典型效果 |
|------|---------|------|---------|
| **戰技** (Combat Arts) | 戰策(WAR) | 無（每戰限用次數） | 指揮、威嚇、戰術機動 |
| **詭術** (Cunning Tricks) | 詭計(CUN) | 無（環境依賴） | 伏擊、佯攻、陷阱激活 |
| **法術** (Arcane Spells) | 魔力(ARC) | 魔力結晶(MC) | 攻擊魔法、防禦魔法、詛咒 |
| **儀式** (Rituals) | 魔力(ARC)/威儀(DOM) | 靈魂精華(SE) | 戰前詛咒、召喚、獻祭 |

### 3.2 法術等級與消耗

| 法術等級 | 所需ARC | MC消耗 | 效果骰池加成 | 示例 |
|---------|---------|--------|------------|------|
| 戲法 (Cantrip) | 1 | 0 | +0 | 法師之手、光亮術 |
| 1環 (1st Circle) | 2 | 1 MC | +1 | 魔法飛彈、護盾術 |
| 2環 (2nd Circle) | 3 | 2 MC | +2 | 火球術、隱形術 |
| 3環 (3rd Circle) | 4 | 3 MC | +3 | 閃電束、飛行術 |
| 4環 (4th Circle) | 5 | 5 MC | +4 | 冰風暴、放逐術 |
| 5環 (5th Circle) | 5+ | 8 MC | +5 | 流星爆、時間停止 |

**法術檢定**：擲 ARC骰池 + 法術等級加成，每個成功=法術命中/生效。對抗法術需目標擲對應防禦骰。

**專注機制**：
- 部分法術需要「專注」維持（每輪消耗1個附贈動作）
- 受到傷害時需進行ARC檢定（難度=所受傷害），失敗則專注中斷
- 同一時間只能專注1個法術
- 構裝體/亡靈免疫專注中斷

**法術射程**：

| 射程 | 覆蓋範圍 |
|------|---------|
| 接觸 | 同一房間內鄰接單位 |
| 近距 | 同一房間內任意單位 |
| 中距 | 當前防禦層任意房間 |
| 遠距 | 相鄰防禦層的任意房間 |
| 地城 | 整個地城範圍（需儀式廳支持） |

## 四、怪物與NPC（雙維度模板）

### 4.1 怪物屬性模板

每個怪物擁有**戰鬥維度**和**經營維度**兩套屬性：

#### 戰鬥維度

| 屬性 | 縮寫 | 含義 | 範圍 |
|------|------|------|------|
| 戰力 | 戰力(CP) | 戰鬥骰池（攻防通用） | 1-8 |
| 生命值 | HP | 承受傷害上限 | 3-20 |
| 忠誠 | 忠誠(LOY) | 服從程度，影響戰鬥中是否叛變 | 1-5 |
| 護甲 | ARM | 額外防禦骰 | 0-3 |
| 速度 | SPD | 每輪可移動房間數 | 1-3 |

## 五、怪物分配機制

### 5.1 經營 vs 戰鬥部署

每個怪物在每個經營回合必須被分配到**經營**或**戰鬥**之一（二選一）：

```
┌──────────────────────────────────────────────────────┐
│                  怪物部署決策                          │
├──────────────────────┬───────────────────────────────┤
│    部署到「經營」     │      部署到「戰鬥」             │
├──────────────────────┼───────────────────────────────┤
│ · 不計入防禦層戰力    │ · 計入防禦層戰力（CP骰池）      │
│ · 產生資源/建設進度   │ · 放棄經營產出                 │
│ · 經營能力被動生效    │ · 經營能力仍可被動生效          │
│ · 按經營值貢獻產出    │ · 參與入侵防禦戰鬥             │
├──────────────────────┼───────────────────────────────┤
│ 切換部署：消耗1行動    │ 切換部署：消耗1行動             │
│ （緊急徵召除外）       │                               │
└──────────────────────┴───────────────────────────────┘
```

**經營部署產出表**：

| 經營值(BIZ) | 資源產出/回合 | 建設進度/回合 | 可選房間加成 |
|-------------|-------------|-------------|------------|
| 1 | 對應資源×1 | 0 | — |
| 2 | 對應資源×2 | 1 | — |
| 3 | 對應資源×3 | 1 | 爲所在房間+1級效率 |
| 4 | 對應資源×4 | 2 | 爲所在房間+1級效率 |
| 5 | 對應資源×5 | 2 | 所在房間效果翻倍 |

**對應資源**由怪物的「最佳房間(BR)」決定：
- 礦場 → 建材+暗金幣
- 研究密室 → 魔力結晶
- 祭壇 → 靈魂精華
- 寶庫 → 暗金幣
- 其他房間 → 按房間產出類型

### 5.2 緊急徵召規則

當入侵發生時（預警階段），可將任意數量的經營部署怪物緊急調回戰鬥：

```
緊急徵召流程：
┌──────────────────────────────────────────┐
│ 1. 預警階段宣言緊急徵召                    │
│ 2. 選擇目標怪物（不限數量）                │
│ 3. 怪物立即從經營切換爲戰鬥部署            │
│ 4. 支付代價                               │
└──────────────────────────────────────────┘
```

**代價**：
- **資源中斷**：該怪物本回合經營產出清零（已產出的不追溯）
- **混亂懲罰**：被緊急徵召的怪物在戰鬥首回合骰池-1
- **忠誠衝擊**：LOY≤2的怪物被緊急徵召後立即進行忠誠檢定（1成功則叛變）

**減免條件**：
- 若怪物部署於「訓練場」：無視混亂懲罰
- 若領主WAR≥4：混亂懲罰從-1骰降爲-0骰（即無懲罰）
- 若怪物LOY=5：無視忠誠衝擊

### 5.3 BOSS戰最低防線

**核心層守護規則**：
- 核心層（王座廳所在防禦層）**必須始終保留至少1只怪物**處於戰鬥部署
- 該怪物可以是任意CP，但必須能夠戰鬥
- 違反此規則 = 地城暴露，入侵者可直接攻擊王座廳（DEF=0，領主孤身應戰）

**君主護衛**：
- 默認情況下，領主從怪物中指定1只爲「君主護衛」
- 君主護衛LOY+1，且在王座廳戰鬥時CP+1
- 君主護衛不可被部署到經營（永遠處於戰鬥部署）
- 君主護衛被擊敗後，領主可指定新的護衛（下一經營回合生效）

## 七、防禦層與房間類型對齊

### 7.1 防禦層結構

地城從外到內分爲4個防禦層，每個防禦層對應地城深度範圍和可建造的房間類型：

├─────────────┼──────────┼────────────────┼───────────────┤
│ 外層防線     │ 深度(DEP) 1-2  │ 偵察前哨       │ 預警+1輪      │
│ (Outer)     │          │ 陷阱工坊       │ 陷阱骰+2      │
│             │          │                │ 基礎DV=1      │
├─────────────┼──────────┼────────────────┼───────────────┤
│ 中層防線     │ 深度(DEP) 3-4  │ 怪物巢穴       │ 怪物容量+2    │
│ (Middle)    │          │ 訓練場         │ 怪物LOY+1     │
│             │          │ 囚牢           │ 基礎DV=2      │
├─────────────┼──────────┼────────────────┼───────────────┤
│ 內層防線     │ 深度(DEP) 5-6  │ 礦場           │ 資源保護      │
│ (Inner)     │          │ 研究密室       │ 基礎DV=2      │
│             │          │ 寶庫           │ 路障可強化    │
├─────────────┼──────────┼────────────────┼───────────────┤
│ 核心防線     │ 深度(DEP) 7+   │ 王座廳 ★       │ 最終防線      │

## 八、入侵系統

### 8.1 入侵觸發公式

**入侵檢定**：每個經營回合結束時，GM進行入侵檢定：

```
入侵檢定 = 惡名(INF) + 1d6

若結果 ≥ 8 → 入侵觸發
若結果 < 8 → 本回合平安無事
```

**入侵頻率期望**：

| 惡名(INF) | 觸發所需d6 | 概率 | 期望入侵間隔 |
|-----|-----------|------|------------|
| 1 | 7+ | 0% → 下限調整爲1/6（保底） | 約6回合 |
| 2 | 6+ | 16.7% | 約6回合 |
| 3 | 5+ | 33.3% | 約3回合 |
| 4 | 4+ | 50% | 約2回合 |
| 5 | 3+ | 66.7% | 約1.5回合 |
| 6 | 2+ | 83.3% | 約1.2回合 |
| 7+ | 自動觸發 | 100% | 每回合 |

**設計說明**：INF≥7後每回合都有入侵，代表地城已成衆矢之的。玩家需要通過降低INF或強化防禦來應對。

### 8.2 INF與冒險者Tier對應

| INF範圍 | 入侵檢定結果 | 冒險者Tier | 個體骰池 | 小隊戰力(4人) | 小隊總HP |
|---------|------------|-----------|---------|-------------|---------|
| 1-3 | 8-9 | T1 新手 | 2-3骰 | 8-12骰 | 18-24 |
| 4-6 | 10-11 | T2 熟練 | 4-5骰 | 16-20骰 | 30-40 |
| 7-9 | 12-13 | T3 精英 | 6-7骰 | 24-28骰 | 45-60 |
| 10-12 | 14-15 | T4 英雄 | 8-9骰 | 32-36骰 | 65-88 |
| 13-15 | 16+ | T5 傳奇 | 10+骰 | 40+骰 | 95-120 |

**特殊入侵事件**（擲1d6，出6觸發）：
- 惡名(INF) 1-3：「冒失的新手」——T1隊伍但帶了意外的好裝備（掉落+50%）
- 惡名(INF) 4-6：「賞金獵人」——T2隊伍中有1個T3隊長
- 惡名(INF) 7-9：「冒險者公會遠征」——雙倍規模的T3隊伍
- 惡名(INF) 10-12：「英雄集結」——T4隊伍+1個T5傳奇英雄
- 惡名(INF) 13-15：「諸神試煉」——T5隊伍+神祇化身（CP=12的BOSS級冒險者）

### 8.3 波次生成

**標準波次生成算法**：

```
輸入：INF值
輸出：入侵波次配置

Step 1: 擲入侵檢定 (惡名(INF) + 1d6)
Step 2: 若 ≥ 8，查表得基礎Tier
Step 3: 擲1d6確定隊伍規模：1-2=2人, 3-4=3人, 5-6=4人
Step 4: 爲每人擲職業：1d6 → 戰士/法師/盜賊/牧師/遊俠/隨機
Step 5: 擲特殊事件：1d6，出6則觸發特殊入侵
Step 6: 生成每人具體戰鬥數據（骰池、HP、能力）
Step 7: 計算小隊總戰力 = Σ(個體骰池)
Step 8: 與防禦方總戰力對比 → 確定難度等級
```

**難度等級**：

| 攻防比 (入侵方總骰池 : 防禦方總骰池) | 難度 | GM提示 |
|----------------------------------|------|--------|
| < 0.5:1 | 輕鬆 | 碾壓局，怪物們可以大快朵頤 |
| 0.5:1 ~ 0.8:1 | 簡單 | 防禦方有明顯優勢 |
| 0.8:1 ~ 1.2:1 | 勢均力敵 | 經典挑戰，勝負難料 |
| 1.2:1 ~ 2:1 | 困難 | 防禦方處於劣勢，需要策略取勝 |
| > 2:1 | 絕望 | 可能失守，準備緊急方案 |

## 九、遭遇設計指南

### 9.1 難度預算

**防禦方戰力預算公式**：

```
防禦總骰池 = Σ(戰鬥部署怪物CP) 
            + Σ(陷阱骰池) 
            + 房間DV骰加成
            + 領主參戰加成（若親自出戰=WAR值）
            + 經營能力加成（戰術家、堡壘大師等）
```

**每層推薦防禦戰力**（按冒險者Tier）：

| 防禦層 | T1目標 | T2目標 | T3目標 | T4目標 | T5目標 |
|--------|--------|--------|--------|--------|--------|
| 外層 | 4-6骰 | 6-8骰 | 8-10骰 | 10-12骰 | 12-15骰 |
| 中層 | 6-8骰 | 8-10骰 | 10-13骰 | 13-16骰 | 16-20骰 |
| 內層 | 4-6骰 | 6-8骰 | 8-10骰 | 10-13骰 | 13-16骰 |
| 核心 | 6-8骰 | 8-10骰 | 10-12骰 | 12-15骰 | 15-20骰 |

**設計原則**：冒險者需要在突破每一層時消耗戰力（HP損失、法術消耗），外層消耗試探、中層主力消耗、內層資源消耗、核心決戰。

### 9.2 遭遇構築原則

#### 原則1：層層遞進
- 外層：偵察 + 陷阱爲主，消耗入侵者資源和HP
- 中層：主力怪物集結，正面對抗
- 內層：保護資源房間，防守反擊
- 核心：Boss戰，所有剩餘力量的總決戰

#### 原則2：多樣性
- 每層至少配置2種不同傷害類型的怪物
- 陷阱類型與怪物能力互補（如蛛羣+陷阱工坊）
- 避免全部怪物同一CP——高低搭配

#### 原則3：資源博弈
- 給玩家留下「部署權衡」空間：哪些怪物經營？哪些戰鬥？
- 緊急徵召帶來短期收益但長期代價
- 讓經營能力的選擇產生實際戰鬥影響

#### 原則4：敘事整合
- 入侵者不是隨機的——他們的職業構成反映冒險者公會對地城的瞭解
- Boss怪物應有名字、性格、與領主的淵源
- 戰鬥結果影響地城敘事（惡名漲跌、倖存者復仇、公會態度轉變）

### 9.3 快速遭遇搭建表

| 步驟 | 內容 | 耗時 |
|------|------|------|
| 1 | 確定入侵Tier（INF檢定） | 10秒 |
| 2 | 擲隊伍規模和職業 | 15秒 |
| 3 | 快速生成戰鬥數據 | 30秒 |
| 4 | 對比防禦方戰力 | 10秒 |
| 5 | 調整難度（如需） | 20秒 |
