# 第一章：核心規則

## 1.1 骰子系統

本規則採用 **d6骰池（D6 Dice Pool）** 系統。

| 骰面 | 結果 |
|------|------|
| **6** | 成功 + **爆擊**：計入1成功，額外追加1骰（可連鎖爆擊） |
| **5** | 成功：計入1成功 |
| 1-4 | 無效果 |

每顆骰子期望成功數 = 0.40（5-6成功制，1/3概率 + 爆擊遞推）。

### 骰池構成

```
骰池 = 屬性骰 + 技能骰 + 環境修正
```

| 來源 | 說明 | 上限 |
|------|------|------|
| 屬性骰 | 屬性值 = 基礎骰數（1-5） | 5d6 |
| 技能骰 | 技能等級提供額外骰（0-5） | +5d6 |
| 環境加成 | 裝備/地形/援助等臨時加骰 | +3d6 |
| 環境減成 | 不利條件移除骰 | -3d6 |
| 優勢 | 投前追加固定骰 | +2d6 |
| 劣勢 | 投前移除骰池中最高N顆骰 | -2d6 |

**骰池上限**：單次檢定不超過 **10d6**。

### 成功度等級

| 淨成功數 | 結果等級 | 描述 |
|----------|---------|------|
| 0 | **失敗** | 行動未達成目標，可能有輕微負面後果 |
| 1 | **部分成功** | 達成目標但有代價、延遲、或效果打折 |
| 2 | **完全成功** | 乾淨利落地達成目標 |
| 3 | **大成功** | 超出預期，附帶額外收益 |
| 4+ | **傳奇成功** | 效果翻倍或解鎖隱藏收益 |

### 難度等級

| 難度 | 所需成功數 | 典型場景 |
|------|-----------|---------|
| 簡單 | 1 | 命令忠誠僕從、基礎建造 |
| 標準 | 2 | 建造房間、審訊T2俘虜、招募怪物 |
| 困難 | 3 | 審訊高意志俘虜、魔法陷阱、深層挖掘 |
| 極難 | 4 | 轉化傳奇俘虜、終極儀式 |
| 史詩 | 5+ | 改變世界格局的魔法 |

## 1.3 檢定類型

### 標準檢定

1. GM宣佈難度等級
2. 玩家組建骰池
3. 擲骰計算成功數
4. 淨成功數 ≥ 難度則成功

### 對抗檢定

雙方各自組建骰池並同時擲骰。**淨成功數 = 主動方成功數 - 對抗方成功數**。

### 大成功與大失敗

- **大成功**：淨成功數 ≥ 3 或 出現3顆以上6 → 額外收益
- **大失敗**：成功數=0 且 骰池中出現3顆以上1 → 意外負面事件

## 1.5 遊戲範例

> 以下是一段典型的回合流程示例，幫助新手理解遊戲節奏。

**經營階段**：
*GM*：「又一個深淵周。你的王座廳裏，石像鬼蹲在角落擦拭翅膀，邪教徒在研究密室裏翻閱古籍。礦場傳來有節奏的敲擊聲——骷髏兵不需要休息。」

*玩家（遠古巨龍，Lv2）*：「好。我先分配怪物崗位——石像鬼去戰鬥崗守外層，邪教徒繼續在研究密室搞研究，骷髏兵丟去礦場。然後我要用建材挖掘第二個小空間。」

*GM*：「擲IND+工程檢定。」

*玩家擲骰*：「匠造(IND)=4，工程=1…我擲5d6。出了6、5、3、2、1——2成功！追骰…3。總成功=2。」

*GM*：「完全成功！你挖出了一箇中型洞穴——而且巖壁上閃爍着魔力結晶的光芒。你發現了一處魔力節點，該空間魔力房間效率永久+1骰。」

*玩家*：「太好了！我消耗◇建一個陷阱工坊在這裏。然後回合結束——擲入侵檢定？」

**入侵階段**：
*GM*：「擲 惡名(INF)(2)+1d6…出了5。2+5=7，不到8——本週安全。但你的偵察前哨注意到遠處有火光。下回合，可能會有人來。」

**第二回合**：
*GM*：「入侵檢定：惡名(INF)(2)+1d6=7…等等，這次擲出6。2+6=8——入侵！兩名冒險者接近中。」

*玩家*：「我部署石像鬼到外層，邪教徒調回戰鬥崗協助。陷阱工坊的落石陷阱已經就位。」

*GM*：「冒險者進入外層。戰士艾倫踩到了落石陷阱——傷害2d6=7點！但他還有3HP，繼續推進。盜賊米拉偵察到了石像鬼。戰鬥開始！」

> 這就是深淵領主的節奏循環：擴張→建設→分配→（可能）入侵→戰後結算→再次循環。

## 2.4.2 附魔系統 ⭐⭐⭐

附魔是將魔力結晶中的深淵能量注入裝備或怪物，賦予其超自然屬性。

### 附魔流程

1. **準備**：擁有鍛造房Lv2+研究密室（滿足「魔導工坊」協同效應）
2. **選擇目標**：一件已鍛造的裝備 或 一隻怪物
3. **選擇附魔類型**：從下方附魔錶中選取
4. **附魔檢定**：擲 `魔力(ARC) + 附魔學技能`，難度見附魔錶
5. **消耗資源**：支付◇和●
6. **檢定結果**：
   - 失敗（0成功）：資源消耗，附魔未生效。可重試
   - 部分成功（1成功）：附魔生效但強度減半（持續3回合後失效，需重新附魔）
   - 完全成功（2成功）：附魔穩定生效
   - 大成功（3+成功）：附魔強度翻倍 或 追加隨機額外效果

## 2.6 怪物分配系統 ⭐

> 每隻怪物有兩個用途維度——經營 vs 戰鬥。分配是核心策略。

### 怪物雙維度屬性

| 屬性 | 含義 | 用途 |
|------|------|------|
| **經營(MV)**（經營貢獻值） | 部署到生產/經營時的貢獻 | 經營骰池 |
| **戰力(CP)**（戰力值） | 部署到防禦/戰鬥時的貢獻 | 戰鬥骰池 |

### 分配規則

- 每回合初，每隻怪物必須分配到**經營組**或**戰鬥組**
- 一隻怪物同一回合不能同時貢獻經營和戰鬥
- 分配爲免費行動（不消耗行動點數）
- 緊急徵召：入侵發生時，可將經營中怪物緊急調入戰鬥，消耗1行動 → 首回合骰池-1 → 忠誠(LOY)≤2的怪物需做忠誠衝擊檢定

### 經營派遣骰池

> 經營總骰池 = 匠造(IND) + 相關技能 + floor(Σ經營(MV) ÷ 2)

### 生產產出公式

> 生產檢定成功後，按以下規則產出資源：

| 骰池來源 | 分配 |
|---------|------|
| IND骰 + 技能骰成功數 | 分配至**產出房間**（每成功 = 該房間Lv產出×1）。優先分配至礦場(■)、研究密室(◇)、寶庫(◆)。無房間吸收的成功→◆×1 |
| 怪物MV加骰成功數 | 分配至**怪物所屬房間**（如礦場中的骷髏兵→產出建材，研究密室中的邪教徒→產出魔力結晶）。無指定房間→對應怪物維護資源×1 |

> **示例**：遠古巨龍（匠造(IND)=4，工程學=1）擲5d6→3成功。2只石像鬼（ΣMV=4，加骰2d6）→1成功。礦場Lv1在場，Lv1研究密室在場。分配：IND的3成功→礦場產出3■（礦場Lv1=■×1/成功）。怪物MV的1成功→石像鬼在礦場→額外1■。本回合總產出：4■。

### 戰鬥防禦骰池

> 戰鬥總骰池 = 戰策(WAR) + 怪物指揮/戰術部署 + floor(Σ戰力(CP) ÷ 2)

### 效率指引

| 怪物組 | Σ經營(MV)/戰力(CP) | 加骰 | 效率(骰/怪物) |
|--------|--------|------|-------------|
| 4骷髏兵(戰力(CP)1×4) | 4 | 2 | 0.50 |
| 2地獄犬(戰力(CP)3×2) | 6 | 3 | 1.50 |
| 1元素構裝體(戰力(CP)4) | 4 | 2 | 2.00 |

> floor(Σ/2)公式使高質量怪物比低質量羣更高效，鼓勵追求精英而非堆量。

### 逃跑判定

每回合末，意志(WIL)≥2的俘虜嘗試逃跑：
- 俘虜擲 WIL骰池 vs 地城擲 DEF骰池 + 囚牢等級
- 俘虜成功 > 地城 → 逃跑啓動，進入追擊階段
- 追擊：俘虜擲 PL骰池 vs 地城擲 戰策(WAR)+威懾戰術（地獄犬+2骰）
- 俘虜逃脫 → 移除俘虜，可能暴露地城情報

### 核心資源詳解

**暗金幣（◆）**：深淵流通的黑暗貨幣。非普通金幣——每枚暗金幣由深淵魔力鑄造，在黑暗中發出暗紅色微光。地表金幣無法在地下世界使用，冒險者攜帶的金幣需在寶庫中"轉化"爲暗金幣（1地表金幣=1d2暗金幣，擲骰決定）。暗金幣是地下城經濟的基礎，可用於貿易、招募、賄賂、魔法材料購買。遠古巨龍原型對其有天然親和（寶庫利息）。

**魔力結晶（◇）**：深淵魔力的固態凝結。在魔力節點附近自然形成，呈紫黑色半透明晶體。觸摸時有微弱脈衝感——那是奈克西斯的心跳。魔力結晶是驅動魔法儀式、釋放戰技、激活魔法陷阱的能量來源。魔力密集型地城（魔力(MAG)≥8）可自行緩慢生成。瘋狂巫師和亡靈之主消耗大量魔力結晶。

**建材（■）**：地下挖掘出的石塊、木材（地底真菌木）、金屬礦石的標準計量單位。1單位建材可建造1格牆壁、1扇門、或3平方米地板。建材品質分三級：粗石（基礎）、黑曜石（防禦+1）、深淵合金（防禦+2且魔法傳導）。礦場產出基礎建材，高品質建材需通過貿易或特殊挖掘獲取。

**靈魂精華（●）**：擊敗冒險者後從其生命力中提取的深淵能量。呈飄浮的幽藍色光球，內含被擊敗者的最後一縷意識——訓練有素的深淵領主可以從中讀取模糊記憶。靈魂精華是亡靈法術的核心燃料、獻祭儀式的代價、以及招募亡靈/惡魔類怪物的貨幣。光明教團視靈魂精華爲最深重的褻瀆——被發現大量持有靈魂精華會引來宗教審判。

#### 鍛造材料詳解

**鐵錠**：深淵鐵礦提煉的暗灰色金屬錠。比地表鐵更緻密——在地下高壓環境中自然形成，礦場中隨處可見。是鍛造基礎裝備的入門材料，也可作爲貿易中的"零錢"流通（2暗金幣=1鐵錠的公開匯率）。

**黑曜鋼**：鐵錠在魔力節點附近長期浸染形成的強化金屬。表面有紫黑色玻璃光澤，敲擊時發出水晶般的聲音。需要鍛造房Lv2的熔爐溫度才能塑形。精良裝備的核心材料——供需緊張，地精工程師地城對其需求最大。

**深淵合金**：最深層的稀有礦石，只在奈克西斯之息滲透最深處形成。呈暗綠色，自身會微弱發光。鍛造時不需要燃料——深淵合金在接觸魔力結晶時自動加熱至鍛造溫度。史詩和傳奇裝備的唯一材料。產量極低——Lv15全套深淵裝備需要長期積累或大量貿易。

> **存儲**：三種鍛造材料不佔用核心資源存儲上限，但每種最大存儲量=財富(WLH)×5單位。

## 2.11 角色創建流程（快速指南）

創建地下城主角色只需以下七步：

### 第一步：選擇原型
從六大原型中選一個。每個原型決定你的屬性加成、核心能力和玩法風格。
> 新手推薦：**深淵惡魔**（正面碾壓，直觀）或 **遠古巨龍**（經濟流，容錯高）。
> 進階挑戰：**瘋狂巫師**（高風險高回報）或 **暗影議會**（情報流，需預判）。

### 第二步：分配領主屬性
你有 **12點** 屬性分配。五項屬性初始均爲1，提升1點消耗1點。
原型加成在分配後疊加（如瘋狂巫師 魔力(ARC)+2 → 分配ARC=3+2=5）。
- 建議優先加滿你的原型主屬性至4（原型加成後達5）
- 至少給DOM（威儀）分配2點——審問俘虜和外交必需

### 第三步：分配技能點
你有 **6點初始技能點**。Lv0→Lv1消耗1點，Lv1→Lv2消耗1點。
- 優先升級原型相關技能（亡靈之主→儀式大師，惡魔→戰術指揮…）
- 至少給1個工程/建造技能投點——挖掘擴張必須有

### 第五步：配置初始地城
### 第四步：記錄原型能力
寫下你的原型被動能力和主動能力。這是你的核心戰鬥/經營優勢。

### 第五步：配置初始地城
所有原型統一初始配置：
- 王座廳 Lv1（免費）
- 2個小型空間（未開發，需挖掘）
- 初始怪物見原型表（3-5只）
- 初始資源見原型表

### 第六步：記錄怪物並擲經營能力
爲每隻初始怪物擲d66獲取隨機經營能力（見§2.7）。在地城佈局草圖上標記怪物位置。

### 第七步：命名與填卡
給地城和城主起名，填寫角色卡。完成！

### 快速上手建議
| 第1回合做什麼 | 建議 |
|------|------|
| 分配怪物崗位 | 至少1只戰鬥崗（防禦），其餘經營崗（產出資源） |
| 首次挖掘 | 消耗1行動+建材×2，擲IND+工程檢定，挖出第1個小空間 |

> **新手GM提示**：Lv1的初次入侵用2名T1冒險者（戰士+盜賊），讓玩家體驗完整戰鬥循環但不至於太困難。

## 2.12 多人共管模式（1 GM + 2~4 玩家）

當多名玩家共同遊戲時，所有玩家**共同管理同一座地下城**。每人扮演一位"深淵副官"——地下城主的左膀右臂。

### 角色分工

| 玩家角色 | 負責領域 | 主屬性 | 每回合專屬行動 |
|------|------|------|------|
| **首席領主** | 最終決策、外交、遠征 | 威儀(DOM)/戰策(WAR) | 1次外交/遠征行動 |
| **防禦指揮官** | 戰鬥部署、怪物調配、陷阱規劃 | 戰策(WAR)/詭計(CUN) | 1次免費怪物重新部署 |
| **經營總管** | 建造、資源產出、俘虜管理 | 匠造(IND) | 建造/升級檢定+1骰 |
| **魔法顧問** | 魔法研究、儀式、法術準備 | 魔力(ARC) | 施法◇消耗-1（最少1） |

**角色可選**：1~4名玩家，未選的角色職能由GM代管或玩家兼任。

### 決策機制

- **領主會議**：每回合開始前，玩家討論並決定本回合策略（5分鐘限時）
- **否決權**：首席領主每回合有1次否決權，可推翻任何單人的決定
- **專家尊重**：涉及特定領域的檢定，由該領域負責人主投，其他人可協助(+1骰)
- **平局**：擲1d6，單數=維持現狀，雙數=首席領主決定

### 衝突與樂趣

| 機制 | 效果 |
|------|------|
| **副官野心** | 每3回合，每位副官暗投1d6。出6=該副官提出一個"個人目標"（如"這回合我要主持審訊"、"我要親自部署陷阱"）。完成→獲得1EXP獎勵 |
| **忠誠考驗** | 若首席領主連續兩回合無視同一位副官的建議，該副官的輔助檢定骰池-1（士氣受挫） |
| **聯合儀式** | 多人蔘與的儀式檢定，每多一名玩家+1骰（上限+3骰） |

### 戰鬥中的多人操作

- 每位副官可親自指揮1-2只怪物（直接控制其行動）
- 首席領主控制全局戰術
- 各防禦層可由不同副官分別指揮

> **設計意圖**：共管模式的核心是"合作決策+角色分工"，避免多人各自爲政。副官野心機制爲長期合作注入適度的競爭趣味。

## 2.10 地下城主的種族特性

地下城主並非凡人——他們是深淵的原生存在，或徹底墮入深淵的轉化者。每種原型對應一個獨特的深淵種族，擁有與生俱來的種族特質。

### 2.10.1 亡靈之主 — 巫妖/死靈 (Lich / Necroid)

> *"死亡不是終點——只是另一種存在形式。"*

| 種族特質 | 效果 |
|---------|------|
| **不死之軀** | 不需要呼吸、食物、飲水。毒素和疾病免疫。HP歸零時不會昏迷——直接進入驅逐流程 |

| **死者低語** | 可與亡靈怪物無距離溝通（心靈感應）。骷髏兵LOY+1 |

> *"當你的心智觸碰了奈克西斯的思緒——你就不再是凡人了。"*

## 3.1 戰鬥框架

### 回合結構（六階段制）


冒險者必須逐層突破地城防線。四層遞進：

## 3.7 特殊戰術規則

### 伏擊/突襲

防禦方可在自己地城施行伏擊（詭計(CUN)+隱匿 vs 冒險者偵察）。成功則首輪獲得突襲——敵方全體防禦骰池-2，己方攻擊骰池+2。

### 地城領主親自出戰

領主可以親自加入任意防禦層戰鬥。詳情請參閱§5.1「領主戰鬥系統」（領主HP、骰池、動作經濟、被擊敗懲罰）。

### 俘虜炮灰

可將俘虜趕上前線充當炮灰。俘虜戰力=PL。每場戰鬥俘虜STA-1。若俘虜被擊倒，有1/3概率永久死亡。俘虜逃跑風險翻倍。

### 主動撤退/焦土戰術

防禦方可選擇放棄一層防禦。撤退時所有怪物撤回下一層，但冒險者推進至該層後半段。可花費1行動執行焦土——摧毀該層所有陷阱（對追擊冒險者造成最大1次陷阱傷害）。

## 3.8 魔法體系

魔法是地下城主除戰技外的第二套戰鬥能力系統。戰技是"武道"（消耗附贈動作或◇的物理/混合技能），魔法是"術道"（消耗◇+行動的純ARC施法）。兩者可自由搭配。

### 3.8.1 魔法學習

領主並非天生掌握所有法術。學習新法術需要時間、資源與研究。

**學習新法術的三種途徑**：

| 途徑 | 條件 | 消耗 | 時間 |
|------|------|------|:---:|
| **自行研究** | 研究密室Lv1+，ARC檢定 vs 法術等級難度 | ◇×(法術等級×2) | 1-3回合 |
| **從俘虜處學習** | 俘虜法師(PL≥2)，DOM審訊成功揭示其已知法術 | 無需額外資源 | 俘虜失去該法術記憶 |
| **從盟友處交換** | 與NPC地城關係≥5，對方領主掌握該法術 | ◆×(法術等級×5) 或等價交換 | 立即學會 |

**自行研究檢定**：

| 法術◇消耗 | 研究難度 | 研究時間 |
|:---:|:---:|:---:|
| 1◇法術 | 標準(2成功) | 1回合 |
| 2-3◇法術 | 困難(3成功) | 2回合 |
| 4-5◇法術 | 極難(4成功) | 3回合 |
| 6◇法術 | 史詩(5成功) | 3回合+特殊條件 |

**法術位上限**（最大可學會的法術數量）：
| 條件 | 法術位 |
|------|:---:|
| 魔力(ARC)≥2 | 2個 |
| ARC每+1 | +1（魔力(ARC)=5時共5個） |
| 技能「儀式大師」Lv1/2/3/4 | 各+1 |
| 技能「詛咒術」Lv3+ | +1 |
| 研究密室Lv2/3 | 各+1 |
| 深淵領主協助 | +1傳奇法術位 |

**最大法術位**：約10-12個法術（領主可選擇性學習，不強制填滿）。

> 領主可在戰鬥前從已學會的法術中選擇至多「魔力(ARC)+2」個作爲當次入侵的「準備法術」。未準備的法術無法在戰鬥中施放。準備法術在預警階段免費執行。

### 3.8.2 法術施放

> 施法骰池 = ARC骰池 + 奧術知識技能骰 + 研究密室加值

施放法術消耗1標準動作 + ◇魔力結晶（每法術消耗不同）。施法距離：同層任意房間。


> ▶ 完整法術列表已獨立收錄於 `魔法圖鑑.md`，請參閱。

### 3.8.5 附魔術法（第七派系）

附魔術法是將深淵魔力永久注入裝備或生物的魔法流派——與戰鬥法術不同，附魔的效果是**永久或長效**的，在經營階段而非戰鬥輪中施放。

| 法術 | ◇ | 等級 | 效果 |
|------|:---:|:---:|------|
| **初級附魔** | 2 | 魔力(ARC)≥2 | 對1件裝備施加1項基礎附魔（鋒利/堅韌/輕盈）。需鍛造房Lv1。永久效果 |
| **元素注入** | 4+●1 | 魔力(ARC)≥3 | 對1件裝備施加1項元素附魔（火焰/冰霜/雷電/暗蝕/聖光抗性）。需魔導工坊協同。永久效果 |
| **生物強化** | 3 | 魔力(ARC)≥3 | 對1只怪物施加1項生物附魔（魔化皮膚/暗影親和/忠誠印記）。不佔裝備槽。永久效果 |
| **高級附魔** | 5+●2 | 魔力(ARC)≥4 | 對1件裝備施加1項強化附魔（吸血/不毀/再生）。需鍛造房Lv2+。永久效果 |
| **羣體元素灌注** | 8+●3 | 魔力(ARC)≥5 | 對同層最多3只怪物同時施加元素血脈附魔。需鍛造房Lv3+研究密室Lv3。永久效果 |
| **傳奇附魔** | 10+●5 | 魔力(ARC)=5+傳奇 | 對1件領主武裝同時施加2項附魔（自選組合）。需魔導工坊+祭壇Lv3。每場戰役限1次 |

**附魔術法特殊規則**：
- 附魔術法的施法時間=1個完整經營回合（而非戰鬥輪）
- 無法在戰鬥中使用附魔術法——戰鬥中有專門的強化法術（見變形/強化系）
- 附魔卷軸可在深淵黑市購買（價格=◇成本的3倍暗金幣）
- 瘋狂巫師的附魔檢定有1/12概率產生「意外附魔」——隨機額外獲得一項GM暗投的隱藏效果（可能是祝福也可能是詛咒）

## 3.10 儀式系統

儀式是比法術更宏大、更耗時的魔法行動。法術在戰鬥輪中施放（數秒），儀式在經營階段執行（數小時至數回合）。

### 儀式類型

| 儀式 | 需求 | 持續時間 | 消耗 | 效果 |
|------|------|:---:|------|------|
| **獻祭儀式** | 祭壇Lv1 | 1回合 | ●×3+俘虜1名（WIL歸零） | ARC檢定，每成功=地城MAG臨時+1（持續3回合） |
| **強化儀式** | 祭壇Lv1 | 1回合 | ◇×5 | 選擇1只怪物，其CP或MV永久+1（上限各3次） |
| **詛咒儀式** | 祭壇Lv2 | 2回合 | ◇×8+●×5 | 對下波入侵的冒險者施加全體詛咒——所有檢定-1骰（持續整場入侵） |
| **召喚大儀式** | 祭壇Lv2 | 3回合 | ◇×10+●×8 | ARC檢定，每成功召喚1只隨機精英怪物（忠誠(LOY)=3）。戰後保留 |
| **地城祝福** | 祭壇Lv3 | 3回合 | ◇×15+●×10 | 全地城檢定+1骰，怪物LOY+1，俘虜逃跑-2骰。持續5回合 |
| **終極儀式** | 祭壇Lv3 | 5回合 | ◇×25+●×20 | 見原型專屬終極儀式表（下方）。每場戰役限1次 |

### 儀式檢定

儀式使用 `魔力(ARC) + 儀式大師技能` 骰池。部分儀式可多人協助（每名協助者+1骰，上限+3骰）。

儀式的「淨成功數」決定效果強度而非成功與否——儀式不失敗（資源已消耗），但低成功數=效果打折。

| 淨成功數 | 儀式效果 |
|:---:|------|
| 0 | 最低效果——僅50%效能 |
| 1-2 | 標準效果——按表中執行 |
| 3+ | 強化效果——效果×1.5或追加額外收益 |

### 原型專屬終極儀式

| 原型 | 終極儀式 | 效果 |
|------|---------|------|

| 深淵惡魔 | **深淵裂隙** | 地城獲得永久惡魔之門——每場戰鬥可額外召喚1只惡魔僕從 |
| 瘋狂巫師 | **現實扭曲** | 自身ARC永久+1（可突破上限至6）；但獲得一個永久隨機負面變異 |

## 4.1 世界觀設定

### 核心翻轉

在這個世界，**地下城不是怪物的巢穴，而是地下城主的王國**；**冒險者不是英雄，而是入侵者和掠奪者**。本規則從地下城的視角重新定義經典奇幻。

### 創世神話

世界誕生於兩位太古神祇的衝突——**奧斯**（光明之神）與**奈克西斯**（深淵之母）。奧斯創造了地表的光明諸國，奈克西斯被放逐到地下深處。奈克西斯的鮮血滲透進岩石，成爲最初的魔力源頭；她的骨骼化作地下山脈；她的思緒碎片化作最初的深淵意識。

第一個地下城是奈克西斯的陵墓，也是通往深淵的門戶。而她被放逐後，世界的裂隙逐漸擴大，更多領主從深淵崛起。

### 世界地理：雙層結構

**地表世界**：
- **晨曦王國**：最強大的地表王國，光明教團總部所在地
- **白銀聯邦**：商業聯邦，冒險者公會的金主
- **聖輝教國**：宗教國度，狂熱的聖戰組織

**地下世界**：
- **暗影之海**：錯綜複雜的隧道迷宮，暗影議會和亡靈之主的傳統領地
- **熔岩平原**：深淵惡魔的炙熱王國
- **幽暗森林**：地底的詭異生態區，瘋狂巫師的實驗場
- **廢鐵峽谷**：古代矮人遺蹟，地精工程師的天堂
- **深淵核心**：最深處的原始魔力之海，傳說中奈克西斯的沉睡之地

## 4.4 GM運行指南

### GM的五大角色

1. **冒險者指揮官**：控制入侵的冒險者小隊
2. **世界引擎**：推動季節、天氣、世界事件
3. **NPC配音**：扮演俘虜、黑暗商人、鄰接地城領主
4. **規則裁判**：判定難度、仲裁爭議
5. **敘事節奏師**：平衡經營與戰鬥的節奏

### 入侵構建六步流程

1. **入侵檢定**：惡名(INF) + 1d6 ≥ 8 觸發
2. **入侵源**：1d6 決定來自哪個派系
3. **規模與Tier**：對照INF→Tier映射表，擲d6決定小隊人數
4. **職業組成**：擲d6：1-2=混合, 3=偏物理, 4=偏魔法, 5=偏偵察, 6=全牧師(教團)
5. **敘事鉤子**：1d6：1=復仇, 2=救人, 3=尋寶, 4=奉命, 5=試煉, 6=迷路
6. **特殊事件判定**：1/6概率附加特殊事件（天氣影響、額外援軍、臨時盟友）

### 節奏控制

**經營階段**（地城平靜期）：
- 開場：「又一個平靜的深淵周…」描繪地城日常
- 時長：10-20分鐘，讓玩家充分討論和決策
- 結束信號：當玩家開始反覆猶豫時，擲入侵判定推動節奏

**入侵階段**（戰鬥緊張期）：
- 開場：「偵察前哨傳來動靜——地表又有人下來了」
- 時長：15-30分鐘，逐層推進形成遞進緊張感
- 結束信號：最後一層突破或冒險者撤退後進入結算

### 難度實時調節

| 手段 | 方向 | 適用情況 |
|------|------|---------|
| 調整小隊人數 | ±1-2人 | 微調 |
| 提前泄漏情報 | 降難度 | 玩家情報不足時 |
| 隱藏情報 | 升難度 | 玩家過於輕鬆時 |
| 天氣/環境修正 | ±骰 | 增添變數 |
| 中段插入Boss | 升難度 | 高潮需要 |

## 4.6 起始模組：「初次入侵」

### 場景1：建立初始地城

GM描繪：
> "你是新晉的地下城主。王座廳的魔力火把已經點亮——這是你的第一座地城。目前只有三間洞室：你的王座廳，以及兩個尚未開發的漆黑隧道盡頭。幾隻剛招募的怪物不安地在你腳邊徘徊。遠處傳來地表人類的微弱聲響——他們來了嗎？"

玩家需要：熟悉屬性、分配初始怪物、規劃先挖掘哪一側。

### 場景2：第一次挖掘擴張

玩家消耗1行動+建材×2，擲IND+工程檢定進行首次挖掘。GM引導探索發現的敘事——可能摸到礦脈，可能發現古遺蹟裏的殘破日記。

### 場景3：第一波入侵

預警：偵察技能檢定揭示「2名T1冒險者接近中」。

預設冒險者：
- **艾倫**（戰士T1）：CP=1d6, HP=5, 盾牌, "忠誠憨厚，爲妹妹籌藥費"
- **米拉**（盜賊T1）：戰力(CP)=2d6, HP=3, 可偵察陷阱, "急躁冒進，想證明自己"

入侵路線：外層→中層。玩家指揮防禦。

### 場景4：首次俘虜與審訊

若擊敗冒險者（HP歸零=昏迷）：可俘虜。GM引入審訊機制教學——讓玩家選擇手段（審訊？折磨？懷柔？）。艾倫的弱點："提到妹妹就眼神閃爍"。

### 場景5：戰後結算與第二次擴張

分配戰利品，用獲得的資源進行第二次挖掘。首次體驗完整的"挖→建→分→防"循環。

## A. 速查表

### 檢定速查

```
骰池 = 屬性 + 技能 + 環境修正 (上限10d6)
擲全部d6 → 5-6=1成功, 6=+1骰追加
成功數 ≥ 難度 → 成功

成功度: 0=失敗 / 1=部分 / 2=完全 / 3=大成功 / 4+=傳奇
難度: 簡單=1 / 標準=2 / 困難=3 / 極難=4 / 史詩=5+
```

### 核心公式

```
經營骰池 = 匠造(IND) + 相關技能 + floor(Σ經營(MV) ÷ 2)
戰鬥骰池 = 戰策(WAR) + 怪物指揮/戰術部署 + floor(Σ戰力(CP) ÷ 2)
攻擊傷害 = 攻擊骰池成功數 - 防禦骰池成功數 + 加值

俘虜意志對抗 = 威儀(DOM) + 審訊技能 vs 俘虜WIL
俘虜逃跑對抗 = 俘虜WIL vs DEF骰池 + 囚牢等級
俘虜勞動效率 = STA骰池 + PL骰 (特定職業額外+1)

挖掘檢定 = 匠造(IND) + 工程學技能 vs 空間難度
入侵觸發 = 惡名(INF) + 1d6 ≥ 8
```

### 地城屬性映射

```
防禦(DEF) → 直接骰池（俘虜逃跑對抗）
惡名(INF) → WAR檢定加骰（每3點+1骰）
財富(WLH) → IND檢定加骰（每5點+1骰）
魔力(MAG) → ARC檢定加骰（每3點+1骰）
深度(DEP) → 房間總數上限 + 挖掘次數上限
```

3. **冒險者扮演模式**：翻轉視角，扮演冒險者進攻地城
4. **擴展怪物庫**：可根據世界設定按需添加更多怪物種類
5. **魔法物品詳細表**：可後續擴展完整的魔法物品/裝備體系
