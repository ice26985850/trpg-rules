## 一、骰子系統

### 1.1 基礎規則

本規則採用 **d6骰池（D6 Dice Pool）** 系統：

| 骰面 | 結果 |
|------|------|
| 6 | **成功** + **爆擊**：計入1成功，且額外追加1骰（可連鎖爆擊） |
| 5 | **成功**：計入1成功 |
| 1-4 | 無效果 |

**設計意圖**：5-6成功制（1/3成功率）提供適中的成功期望。6爆擊引入"驚喜時刻"，讓每擲骰都有戲劇性可能。每顆骰子期望成功數 = 0.4，使得骰池增長時產出可預測但保有波動。

### 1.2 骰池構成

```
骰池 = 屬性骰（Attribute Dice） + 技能骰（Skill Bonus） + 環境修正（Modifier Dice）
```

| 來源 | 說明 | 上限 |
|------|------|------|
| **屬性骰** | 屬性值 = 基礎骰數（1-5） | 5d6 |
| **技能骰** | 技能等級提供額外骰（0-5） | +5d6 |
| **環境加成** | 裝備/地形/援助等臨時加骰 | +3d6 |
| **環境減成** | 不利條件移除骰（從低到高移除） | -3d6 |
| **優勢** | 投前追加固定骰（罕見，通常來自原型能力或魔法） | +2d6 |
| **劣勢** | 投前移除骰（取屬性骰+技能骰中最高N顆移除） | -2d6 |

**骰池上限**：單次檢定骰池不超過 10d6。

### 1.3 成功度等級

| 淨成功數 | 結果等級 | 描述 |
|----------|---------|------|
| 0 | **失敗** | 行動未達成目標，可能有輕微負面後果 |
| 1 | **部分成功** | 達成目標但有代價、延遲、或效果打折 |
| 2 | **完全成功** | 乾淨利落地達成目標 |
| 3 | **大成功** | 超出預期，附帶額外收益 |
| 4+ | **傳奇成功** | 效果翻倍或解鎖隱藏收益 |

**設計意圖**：0成功≠災難（除非難度極高）。1成功即可推進遊戲，避免"什麼也沒發生"的挫敗感。3+成功製造高光時刻。

### 1.4 難度等級

| 難度 | 所需成功數 | 典型場景 |
|------|-----------|---------|
| 簡單（Easy） | 1 | 命令忠誠僕從、基礎建造、簡單儀式 |
| 標準（Standard） | 2 | 建造房間、審訊T2俘虜、製造陷阱、招募怪物 |
| 困難（Hard） | 3 | 審訊高意志俘虜、魔法陷阱、深層挖掘、精英儀式 |
| 極難（Extreme） | 4 | 轉化傳奇俘虜、終極儀式、對傳奇冒險者的威壓 |
| 史詩（Epic） | 5+ | 改變世界格局的魔法、深淵領主間的決鬥 |

### 1.5 關鍵概率速查

| 骰池 | P(≥1成功) | P(≥2成功) | P(≥3成功) | 期望成功數 |
|------|-----------|-----------|-----------|-----------|
| 1d6 | 33.3% | 5.6% | — | 0.40 |
| 2d6 | 55.6% | 18.5% | 3.1% | 0.80 |
| 3d6 | 70.4% | 33.3% | 11.1% | 1.20 |
| 4d6 | 80.2% | 48.1% | 21.0% | 1.60 |
| 5d6 | 86.8% | 60.5% | 32.2% | 2.00 |
| 6d6 | 91.2% | 70.8% | 43.7% | 2.40 |
| 7d6 | 94.1% | 78.9% | 54.4% | 2.80 |
| 8d6 | 96.1% | 85.1% | 64.1% | 3.20 |

> **甜蜜區間**：3d6-5d6是大多數玩家檢定的主力區間。3d6時標準難度（需2成功）成功率約33%，略有挑戰性；4d6時升至約48%；5d6時達到約60%，手感最佳。

### 2.3 屬性點分配

| 項目 | 規則 |
|------|------|
| **初始分配點數** | **12點**（修訂：原15點降至12點，因角色原型提供屬性加成，低起點創造更大差異化） |
| **各屬性底限** | 1（不可低於1） |
| **初始屬性上限** | 4（不可在創建時達到5，原型加成可突破） |
| **原型加成** | 選擇原型後疊加（如瘋狂巫師 魔力(ARC)+2，初始可達5） |
| **成長** | 地城等級每提升1級，獲得 **1點屬性點** |
| **終局上限** | 5（傳奇級別） |

**分配示例**（12點，屬性從1起步）：
- **均衡型**: 詭計(CUN) 3 / 威儀(DOM) 3 / 魔力(ARC) 3 / 匠造(IND) 3 / 戰策(WAR) 3（各屬性+2，共消耗10點，餘2點自由分配）
- **專精型**: 詭計(CUN) 2 / 威儀(DOM) 2 / 魔力(ARC) 4 / 匠造(IND) 3 / 戰策(WAR) 4（側重戰策與魔力）
- **偏門型**: 詭計(CUN) 4 / 威儀(DOM) 2 / 魔力(ARC) 2 / 匠造(IND) 4 / 戰策(WAR) 2（側重詭計與匠造）

> **設計意圖**：12點意味着平均屬性約2.4，即"合格偏上"。原型加成將驅動玩家將最高屬性推向4-5，形成清晰的長短板差異。數學驗證表明，骰池3-5的甜蜜區間不受影響——只是初始階段的屬性更分散，玩家對原型加成的依賴更強。

## 四、檢定規則

### 4.1 標準檢定（Standard Check）

**何時使用**：玩家主動行動，結果不確定且有意義的失敗後果。

**流程**：
1. GM 宣佈難度等級（所需成功數）
2. 玩家組建骰池（屬性骰 + 技能骰 + 環境修正）
3. 玩家擲骰，計算成功數
4. 對照難度判定結果

**規則條目**：
> 擲骰池中所有d6。每顆出5-6計1成功。每顆出6在計入成功後追加1骰（可連鎖）。淨成功數 ≥ 難度則行動成功。

**示例**：
> 亡靈之主想要審訊一名T3聖騎士俘虜。GM判定難度爲"困難（3成功）"。玩家DOM=4，審訊技能=2，囚牢Lv2提供+1環境骰，骰池=7d6。擲出：6,6,5,5,3,2,1 → 兩顆6各計1成功+各追1骰，兩顆5各計1成功。追骰：5,2 → 再+1成功。總計5成功，淨成功數=5-難度3=大成功（MoS=2）。俘虜意志崩潰，GM額外給予一條冒險者公會高層情報。

### 4.2 對抗檢定（Opposed Check）

**何時使用**：雙方都在主動對抗（審訊 vs 意志、潛行 vs 偵察、逃跑 vs 追擊）。

**流程**：
1. 雙方各自組建骰池
2. 雙方同時擲骰
3. **淨成功數 = 主動方成功數 - 對抗方成功數**
4. 淨成功數 ≥ 0：主動方勝出（淨成功數即成功度）

**規則條目**：
> 俘虜WIL對抗審訊：審訊方擲 DOM骰池 + 審訊技能，俘虜擲 WIL骰池。審訊方成功數 > 俘虜成功數則意志降低；成功數差值決定降低幅度。

**示例**：
> 深淵惡魔審訊T3俘虜（WIL=5）。惡魔 威儀(DOM)=4 + 審訊2 = 6d6。俘虜 意志(WIL)=5d6。惡魔擲出：6,5,5,4,2,1 → 3成功+追骰(3)無=3成功。俘虜擲出：6,5,4,3,2 → 2成功+追骰(5)=3成功。淨成功=0——平手！俘虜咬緊牙關扛住了這一輪審訊，但惡魔也探知了俘虜的弱點（下輪審訊+1骰）。

### 4.3 團隊檢定（Team Check）

**何時使用**：多名角色協作同一目標。

**規則條目**：
> 指定一名主檢者擲完整骰池。每名有意義的協助者提供+1環境骰（最多+3）。若主檢者失敗且協助者中有該技能等級≥3者，可消耗1資源重投一次（每場景限一次）。

**示例**：
> 地精工程師（IND=5，工程=4）主持深層挖掘，兩名邪教徒（工程技能=1和0）協助。主骰池=匠造(IND)5+工程4=9d6，協助+2d6=11d6，觸上限縮至10d6。擲出10d6……

### 4.4 大成功與大失敗

**大成功（Critical Success）**：
- 觸發條件：淨成功數 ≥ 3 或 出現3顆以上6（以先達到者爲準）
- 效果：除達成目標外，GM給予一項額外收益（降低後續難度、發現隱藏資源、獲得情報、額外產出等）

**大失敗（Critical Failure）**：
- 觸發條件：成功數=0 且 骰池中出現3顆以上1
- 效果：行動失敗且伴隨意外負面事件（參考各子系統的事故/風險表）

### 4.5 優勢與劣勢

**優勢（Advantage）**：
- 投前追加X顆骰子
- 來源：原型能力、魔法增幅、完美情報、高地/地利
- 上限：+2d6

**劣勢（Disadvantage）**：
- 投前從骰池中移除X顆最高值的骰子（非隨機移除——移除最大的）
- 來源：受傷、詛咒、惡劣環境、恐懼效果
- 下限：骰池不低於1d6

> **設計意圖**：劣勢移除"最高值"而非"隨機"——這比隨機移除更嚴厲，更符合"運氣不在你這邊"的敘事。一個5d6的專家在劣勢-2時失去兩顆最好的骰子，剩下3d6中最好的已被移除，大幅降低爆擊概率。

### 5.1 地城五大派生屬性

## 六、領地擴張骰池機制

> **核心新增**：地下城主向外挖掘擴張，拓展地城版圖。

### 6.1 挖掘檢定

**何時觸發**：玩家消耗1行動並支付資源，進行擴張挖掘。

| 項目 | 內容 |
|------|------|
| **骰池** | 匠造(IND) + 工程(Engineering)技能 |
| **對抗難度** | 初始難度2，每成功擴張一次後難度+1（累計遞增） |
| **資源消耗** | 建材×(當前DEP÷2，向上取整)，暗金幣×2 |
| **行動消耗** | 1行動 |

**規則條目**：
> 地下城主擲 IND骰池 + 工程技能骰。成功數 ≥ 當前擴張難度則挖掘成功。淨成功數決定挖掘成果等級。

**示例**：
> 地精工程師首次擴張（難度=2）。匠造(IND)=4 + 工程=3 = 7d6。擲出6,5,5,4,3,2,1 → 3成功+追骰(3)=3成功。淨成功=3-2=1成果。挖出1個小空間，可建1間基礎房。下一次擴張難度升至3。

|----------|---------|------|

## 七、怪物分配骰池機制

> **核心新增**：每隻怪物在經營與戰鬥之間分配，底層骰池支撐兩維度切換。

### 7.1 怪物雙維度屬性

每隻怪物擁有兩個貢獻值：

| 屬性 | 含義 | 用途 |
|------|------|------|
| **經營貢獻值** (Management Value, 經營(MV) | 怪物部署到生產/經營時的貢獻 | 擲 IND骰池 時使用 |
| **戰鬥貢獻值** (Combat Value, CV) | 怪物部署到防禦/戰鬥時的貢獻 | 擲 WAR骰池 時使用 |

### 7.2 分配規則

- 每隻怪物在每回合初被分配到 **經營組** 或 **戰鬥組**
- 一隻怪物在同一回合內 **不可同時貢獻經營和戰鬥**
- 分配爲免費行動（不消耗行動點數）
- 若回合中途發生入侵，戰鬥組的怪物立即進入防禦位置；經營組的怪物需要消耗1行動才能轉爲戰鬥（代表從礦區/工坊緊急召回）

### 7.3 經營派遣骰池

**何時使用**：怪物被分配到經營組，進行生產活動時。

**規則條目**：
> 經營組每隻怪物貢獻其MV。將所有經營組怪物的MV求和，除以2（向下取整，最少1），得到經營骰池加骰數。地下城主擲 匠造(IND) + 相關技能 + 經營骰池加骰 進行生產檢定。

```
經營總骰池 = 匠造(IND) + 技能 + floor(Σ經營(MV) / 2)
```

**示例**：
> 遠古巨龍將2只石像鬼（MV各=2）和1只邪教徒（MV=1）分配到礦場生產。ΣMV=5，加骰=floor(5/2)=2d6。巨龍 匠造(IND)=4 + 採集=2 + 怪物加骰2 = 8d6。擲出8d6進行礦場產出檢定。

### 7.4 戰鬥防禦骰池

**何時使用**：怪物被分配到戰鬥組，參與地城防禦時。

**規則條目**：
> 戰鬥組每隻怪物貢獻其CV。將所有戰鬥組怪物的CV求和，除以2（向下取整，最少1），得到戰技骰池加骰數。地下城主擲 戰策(WAR) + 怪物指揮/戰術部署 + 戰技骰池加骰 進行防禦/戰鬥檢定。

```
戰鬥總骰池 = 戰策(WAR) + 怪物指揮/戰術部署 + floor(ΣCV / 2)
```

**示例**：
> 深淵惡魔將2只地獄犬（CV各=3）和1只石像鬼（CV=3）部署到防線。ΣCV=9，加骰=floor(9/2)=4d6。惡魔 戰策(WAR)=4 + 怪物指揮=2 + 戰技加骰4 = 10d6（上限10d6）。擲出10d6進行戰鬥指揮檢定。

### 7.5 怪物基礎MV/CV值

| 怪物 | MV（經營） | CV（戰鬥） | 說明 |
|------|-----------|-----------|------|
| 骷髏兵 | 1 | 1 | 廉價通用，但效率低 |
| 史萊姆 | 0 | 2 | 無法從事精細經營 |
| 暗影 | 1 | 2 | 伏擊型，戰鬥偏向 |
| 石像鬼 | 2 | 3 | 均衡型，建造+守衛 |
| 地獄犬 | 1 | 3 | 戰鬥偏向，追蹤特化 |
| 元素構裝體 | 3 | 4 | 頂級均衡，但維護高昂 |
| 蛛羣 | 1 | 2 | 陷阱協同型 |
| 邪教徒 | 2 | 1 | 經營偏向（人類智能優勢） |
| 死亡騎士 | 4 | 5 | 精英均衡 |
| 深淵魔 | 0 | 6 | 純戰鬥型 |
| 嵌合獸 | 2 | 5 | 戰鬥偏向 |
| 龍裔守衛 | 3 | 5 | 頂級守衛 |
| 暗殺大師 | 1 | 4 | 特種戰鬥 |
| 機械巨像 | 4 | 6 | 頂級構裝 |
| 骨龍 | 2 | 7 | 傳奇怪物 |
| 深淵領主 | 3 | 8 | 傳奇戰鬥 |
| 遠古魔像 | 5 | 8 | 傳奇構裝 |

> **設計意圖**：MV/CV分化爲怪物分配提供策略深度。經營型地城（地精工程師、遠古巨龍）偏好高MV怪物；戰鬥型地城（深淵惡魔）偏好高CV怪物。公式 floor(Σ/2) 使得怪物羣的邊際收益遞減——2只CV3怪物（共6CV→+3骰）比4只CV1怪物（共4CV→+2骰）更高效，鼓勵玩家追求質量而非純數量。

## 九、俘虜系統核心判定

> **交叉評審簡化**：保留底層意志對抗、逃跑判定、勞動效率骰池公式。六階段流程管理（審訊/折磨/懷柔/孤立/洗腦→意志歸零結局表）由角色系統接管。

### 9.1 意志對抗（WIL Resistance）

**何時使用**：地下城主對俘虜施加審訊/威壓/懷柔等影響意志的手段時。

**規則條目**：
> 地下城主擲 **DOM骰池 + 審訊(Interrogation)技能骰**。俘虜擲 **WIL骰池**（WIL值=d6數）。城主成功數 > 俘虜成功數則意志降低。差值決定降低幅度：

| 淨成功數（城主-俘虜） | WIL變化 | 附帶效果 |
|---------------------|---------|---------|
| ≤0 | 無變化 | 俘虜抵抗成功，城主可能獲得一條模糊情報（GM暗投決定） |
| 1 | 意志(WIL) -1 | 俘虜開始動搖 |
| 2 | 意志(WIL) -1 | 俘虜動搖，下輪審訊時俘虜WIL骰池-1骰 |
| 3+ | 意志(WIL) -2 | 意志大幅削弱，同時城主獲得一條確定情報 |

**示例**：
> 暗影議會審訊T2盜賊俘虜（WIL=4）。議會 威儀(DOM)=3 + 審訊=2 = 5d6。俘虜 意志(WIL)=4d6。
> 城主擲出：6,5,4,3,2 → 2成功+追骰(4)=2成功。俘虜擲出：5,3,2,1 → 1成功。淨成功=1 → 意志(WIL) -1（降至3）。

### 9.2 逃跑判定（Escape Check）

**何時使用**：每回合末，每個WIL≥2的俘虜進行逃跑檢定。

**規則條目**：
> 俘虜擲 **WIL骰池**。地城擲 **DEF骰池**（直接使用地城DEF屬性值對應骰數）+ 囚牢等級額外骰。
> - 若俘虜成功數 > 地城成功數 → 逃跑嘗試啓動，進入追擊階段
> - 若俘虜成功數 ≤ 地城成功數 → 逃跑被遏制

**追擊階段**（逃跑嘗試啓動後）：
> 俘虜擲職業骰池（PL值=d6數，若有盜賊/遊俠背景+1骰）。
> 地城擲 **WAR骰池 + 威懾戰術/怪物指揮**（若有地獄犬部署則+2骰）。
> - 若俘虜成功數 > 追擊成功數 → 俘虜逃脫（移除，可能暴露地城情報）
> - 若俘虜成功數 ≤ 追擊成功數 → 逃跑失敗，俘虜WIL-1，STA-1

**示例**：
> T3戰士俘虜（WIL=3, PL=3）試圖逃跑。地城DEF=4，囚牢Lv2（+1骰）。
> 俘虜 意志(WIL)=3d6 → 擲出6,5,2 → 2成功+追骰(4)=2成功。
> 地城 防禦(DEF)=4d6+1d6=5d6 → 擲出6,5,3,2,1 → 2成功+追骰(2)=2成功。平手→逃跑被遏制。
> 若俘虜成功數爲3，則逃跑啓動→追擊階段：俘虜PL=3d6，地城WAR+威懾戰術+地獄犬追蹤加值→判定。

### 9.3 勞動效率骰池公式

**何時使用**：分配俘虜從事勞動時，計算其產出效率。

**規則條目**：
> 每名俘虜的基礎勞動骰池 = **STA骰池 + 技能加骰**（根據職業和勞動類型）。

| 勞動類型 | 骰池公式 | 產出計算 |
|----------|---------|---------|
| **挖掘擴建** | STA骰池 + PL骰（若爲戰士+1骰） | 每個成功產建材×1 |
| **陷阱製作** | STA骰池 + PL骰（若爲盜賊+1骰） | 每個成功製造1個基礎陷阱組件 |
| **魔法研究** | STA骰池 + PL骰（若爲法師+1骰） | 每個成功產魔力結晶×1 |
| **資源生產** | STA骰池 + PL骰 | 每個成功產對應資源×1 |
| **戰鬥炮灰** | PL骰池（戰力=PL，非骰池產出） | 每場戰鬥STA-1，戰力=PL |
| **特殊儀式** | PL骰池（不消耗STA，消耗WIL） | 每個成功強化儀式效果+1 |

**示例**：
> T2法師俘虜（STA=4, PL=2）分配到魔法研究。骰池 = STA4d6 + PL2d6 = 6d6。
> 擲出6,5,5,3,2,1 → 3成功+追骰(4)=3成功。產出魔力結晶×3。STA-1（降至3）。

## 十、技能樹與原型能力雙軌說明

> **交叉評審確認**：雙軌制——技能樹 + 原型能力，兩者疊加不衝突。

### 10.1 雙軌架構

```
┌────────────────────────────────────────────────┐
│                地下城主能力體系                    │
├─────────────────────┬──────────────────────────┤
│   技能樹（通用成長）   │   原型能力（專屬天賦）       │
│   · 20項通用技能      │   · 6大原型各1被動+1主動    │
│   · 所有原型共享       │   · 原型專屬，不可跨原型獲取  │
│   · 通過技能點提升     │   · 通過地城等級解鎖進階     │
│   · 代表後天學習       │   · 代表先天稟賦/血脈      │
├─────────────────────┴──────────────────────────┤
│  疊加規則：檢定中技能加骰 + 原型能力被動加骰可同時生效  │
│  示例：亡靈之主 威儀(DOM)=3 + 審訊技能=2 + 殘酷審訊官=1   │
│        = 6d6審訊骰池（屬性3+技能2+原型1）          │
└────────────────────────────────────────────────┘
```

### 10.2 衝突處理

- 若技能與原型能力提供**同類加值**（如都是"審訊+1骰"），則疊加（來源不同）
- 若技能與原型能力提供**同名能力**（如"殘酷審訊官"同時出現在原型專屬和通用輔助中），原型版優先且效果更強
- 原型進階能力（Lv3/6/9）提供的是**新獨立動作**或**改變規則的效果**，不與技能樹衝突

## 十一、數學驗證

### 11.1 核心檢定甜蜜區間驗證

**設定**：中等難度（需2成功），玩家主力屬性3-4，相關技能2-3，骰池5-7d6。

| 場景 | 骰池 | P(≥2成功) | 手感評價 |
|------|------|-----------|---------|
| 新領主（屬性2+技能1） | 3d6 | 11.1% | 挑戰性高，需環境加成或消耗資源 |
| 合格領主（屬性3+技能2） | 5d6 | 32.2% | 有挑戰性，合理的標準難度體驗 |
| 專精領主（屬性4+技能3） | 7d6 | 54.4% | 手感流暢，成功率過半 |
| 滿配專精（屬性5+技能5） | 10d6 | ~80% | 傳奇級碾壓標準難度，但困難(3成功)仍有挑戰 |

**結論**：甜蜜區間3-5d6維持。初始12點分配下，玩家主力屬性3-4（原型加成後4-5），輔以技能2-3，標準難度成功率在32-54%區間——符合"有挑戰但可達成"的設計目標。

### 11.2 領地擴張難度曲線

匠造(IND) + 工程 組合 vs 遞增難度：

| 擴張次數 | 難度 | 匠造(IND)4+工程3(7d6) P(≥難度) | 匠造(IND)5+工程5(10d6) P(≥難度) |
|----------|------|------------------------|--------------------------|
| 第1次 | 2 | 78.9% | 96.1% |
| 第3次 | 4 | 28.3% | 70.8% |
| 第5次 | 6 | 5.4% | 32.2% |
| 第8次 | 9 | <1% | 6.5% |
| 第10次 | 11 | — | <1% |

**結論**：擴張具有自然減速效應。地精工程師（IND+2原型加成）在第4-5次擴張時仍保有合理成功率，而其他原型在第3-4次後需依賴環境加成、原型能力或承擔更高風險。這創造出"擴張深度"的戰略選擇——是繼續深挖還是鞏固現有地城。

### 11.3 怪物分配效率曲線

| 怪物組 | Σ經營(MV)/CV | 加骰 | 效率(加骰/怪物數) |
|--------|--------|------|------------------|
| 4只骷髏兵 (CV1×4) | 4 | 2 | 0.50 |
| 2只地獄犬 (CV3×2) | 6 | 3 | 1.50 |
| 1只元素構裝體 (CV4×1) | 4 | 2 | 2.00 |
| 2石像鬼+1邪教徒 (經營(MV) | 5 | 2 | 0.67 |
| 3只龍裔守衛 (經營(MV)3×3) | 9 | 4 | 1.33 |

**結論**：floor(Σ/2)公式下，高質量怪物（高個體MV/CV）比大量低質量怪物更高效。1只元素構裝體(CV4)的+2骰相當於4只骷髏兵的總和。這驅動玩家追求精英和傳奇怪物，而非無限堆疊低級怪物。

### 11.4 俘虜意志對抗平衡

威儀(DOM)+審訊 vs WIL對抗：

| 城主骰池 | 俘虜WIL | 城主勝率 | 平均WIL降低/次 |
|----------|---------|---------|---------------|
| 威儀(DOM)3+審訊1=4d6 vs | 意志(WIL)3=3d6 | 55% | 0.6 |
| 威儀(DOM)4+審訊2=6d6 vs | 意志(WIL)4=4d6 | 60% | 0.8 |
| 威儀(DOM)4+審訊3=7d6 vs | 意志(WIL)5=5d6 | 57% | 0.7 |
| 威儀(DOM)5+審訊4=9d6 vs | 意志(WIL)5=5d6 | 72% | 1.1 |

**結論**：意志對抗設計爲緩慢推進——即使是審訊專精領主，平均也需要3-5次審訊才能將高意志俘虜（WIL5）降至崩潰邊緣。這符合"俘虜是長期投資"的設計理念，也爲角色系統的六階段流程管理提供了充足的敘事空間。

## 附錄A：快速檢定參考卡

### 標準檢定
```
骰池 = 屬性 + 技能 + 環境修正
擲全部d6 → 5-6=1成功，6=+1骰追加
成功數 ≥ 難度 → 成功
```

### 對抗檢定
```
雙方各擲骰池
淨成功 = 主動方成功數 - 對抗方成功數
淨成功 ≥ 0 → 主動方勝
```

### 成功度
```
0 = 失敗
1 = 部分成功
2 = 完全成功
3 = 大成功
4+ = 傳奇成功
```

### 難度參考
```
簡單=1 / 標準=2 / 困難=3 / 極難=4 / 史詩=5
```
