# 序章：歡迎來到登艦隊

你隸屬於人類星際協約（人類星際協約，TSC）的星艦登艦突擊隊（星艦登艦突擊隊，SABT）。你不是艦橋裡發號施令的軍官——你是被彈射艙打到敵艦外殼上、用等離子切割器（等離子切割器）切開裝甲、在零重力的走廊裡跟外星生物面對面的登艦突擊隊員。

每一艘敵艦都是一張獨立的戰術地城。今天你切進一艘人類驅逐艦的輪機艙，明天你可能在一個昆蟲族生物艦（昆蟲族生物艦）的蠕動器官中爬行。你不會知道下一扇門後面是走廊還是胃——直到你切開它。

**核心體驗：** 密閉空間的壓迫感、團隊配合的緊張默契、敵艦自毀倒數中的絕望衝刺、以及回到母艦氣閘裡喘著氣笑出來那一刻。

# 第一章：核心規則

## 1.1 骰子系統

本遊戲使用 **d20 擲骰系統（d20 擲骰系統）**。這是全球最普遍的桌上角色扮演遊戲（TRPG）擲骰系統，學習門檻極低。

### 核心公式

```
檢定結果 = 1d20 + 屬性修飾值（屬性修飾值） + 熟練加值（熟練加值） + 環境修飾值（環境修飾值）
```

**判定方式：** 檢定結果 ≥ 難度等級（難度等級，DC）即為成功。

**特殊規則：**
- **自然 20（自然 20）：** 骰子擲出 20 — 無論難度等級（難度等級，DC）為何，一律視為成功。這稱為「大成功（大成功）」。
- **自然 1（自然 1）：** 骰子擲出 1 — 無論修飾值多少，一律視為失敗。這稱為「大失敗（大失敗）」。

### 優勢與劣勢

**優勢（優勢）：** 當情境對你有利時（如目標受限、擁有精準情報、使用針對性裝備），擲 **2d20 取較高者**。  
**劣勢（劣勢）：** 當情境對你不利時（如能見度低、處於高重力環境、裝備受損），擲 **2d20 取較低者**。

優勢（優勢）和劣勢（劣勢）互相抵消——無論各有多少個來源。最終狀態非此即彼，不存在「雙重優勢」或「雙重劣勢」。

優勢（優勢）在中等難度區間等效於約 **+5 修飾值**（成功率約 +25%）；劣勢（劣勢）等效於約 **−5 修飾值**。

## 1.4 檢定規則

### 屬性檢定（屬性檢定）

當你嘗試一個有失敗風險且無特定技能涵蓋的行動時，遊戲主持人（遊戲主持人，GM）可要求進行屬性檢定（屬性檢定）。擲 1d20 + 對應屬性修飾值，結果 ≥ 難度等級（難度等級，DC）即為成功。

> **範例：** 你在敵艦走廊中忽然遭遇重力逆轉。遊戲主持人（遊戲主持人，GM）要求進行一次機動（機動，MOB）屬性檢定，難度等級（難度等級，DC）為 13。你的機動（機動，MOB）屬性值為 14（修飾值 +2），擲出 d20 = 11，合計 13——恰好成功！你在重力逆轉瞬間抓住扶手，穩住身形。

### 技能檢定（技能檢定）

當你的行動落入某項技能的涵蓋範圍時，進行技能檢定（技能檢定）：

```
技能檢定結果 = 1d20 + 關聯屬性修飾值 + 技能熟練加值 + 環境修飾值
```

即使你在該技能上未受訓（未受訓）（熟練加值 +0），你仍然可以嘗試檢定。

> **範例：** 你嘗試破解敵艦的武器控制系統。這是一次工程（工程，ENG）屬性的系統破解（系統破解）技能檢定。你的工程（工程，ENG）屬性值為 16（修飾值 +3），系統破解（系統破解）熟練等級為熟練（熟練）（+2），合計基礎修飾值為 +5。遊戲主持人（遊戲主持人，GM）設定難度等級（難度等級，DC）為 16。你擲出 d20 = 12，合計 17——成功破解武器控制系統！

### 難度等級階梯

| 難度等級（DC） | 難度標籤 | 範例行動 |
|:---:|------|---------|
| **5** | 瑣碎（瑣碎） | 打開未鎖的艙門、在 1G 重力下正常行走 |
| **8** | 簡單（簡單） | 使用標準急救包、在低重力下保持平衡 |
| **10** | 容易（容易） | 射擊近距離靜止目標、識別常見敵艦型號 |
| **13** | 中等（中等） | 在零重力下穩定推進、破解標準門禁系統 |
| **16** | 挑戰（挑戰） | 在交火中破解敵艦系統、從高重力區起身 |
| **19** | 困難（困難） | 破解自毀程序的緊急延遲、遠距離狙擊移動目標 |
| **22** | 極難（極難） | 在自毀倒數最後一回合解除全部系統封鎖 |
| **25** | 傳奇（傳奇） | 完全解除已鎖定的自毀序列 |

### 對抗檢定（對抗檢定）

當兩個角色的行動互相對抗時（如潛行（潛行）vs. 威脅偵測（威脅偵測）），雙方各自進行對應的技能檢定。檢定結果較高者勝出。平局時，主動方勝出。

**成功度（成功度，MoS）** = 勝方檢定結果 − 敗方檢定結果。成功度（成功度，MoS）決定效果的強度。

### 團隊協作檢定

當多名角色協作完成同一任務時，指定一名角色為主要執行者（主要執行者）進行檢定。每名提供協助的角色若在相關技能上至少有熟練（熟練）等級，則提供 **+1 協助加值**，最多累計 **+3**。

**風險：** 若任何協助者的協助檢定失敗（1d20 + 熟練加值，難度等級（DC）10），該協助者對主要執行者（主要執行者）施加劣勢（劣勢）。

# 第二章：角色創建

## 步驟一：兵種選擇（兵種選擇）

| 兵種 | 核心定位 | 主屬性加成 | 一句話 |

## 步驟三：屬性配點（屬性配點）

所有屬性起始值為 **8**。你有 **25 點** 自由分配。

**配點規則：**

## 5.2 攻擊與傷害

### 攻擊檢定

```
攻擊檢定值 = 1d20 + 戰術（TAC）修飾值 + 武器熟練加值 + 環境修正
```

**武器熟練加值：** 本兵種專精武器 +2、非本兵種武器 +1（未受訓武器 +0）

攻擊檢定值 ≥ 目標防禦等級（防禦等級，DEF）→ 命中。

**目標防禦等級（DEF）：** 有護甲目標 = 10 + 機動（MOB）修飾值 + 護甲加值。無護甲目標 = 10 + 機動（MOB）修飾值。

### 傷害計算

```
傷害值 = 武器基礎傷害 + clamp(攻擊檢定值 − 防禦等級（DEF）, 0, +3)
```

- 武器基礎傷害：各武器固定的傷害骰
- 檢定差值加成：攻擊檢定超出 DEF 的部分，每 1 點轉為 +1 傷害，最高 +3（超出部分無效）
- 最低傷害：檢定差值為 0 或負數時，仍造成武器基礎傷害最小值（差值下限為 0）
- 護甲處理：傷害先扣除目標裝甲完整度（ARMR）池，溢出部分才扣除生命值（HP）（見 5.3 節）

### 暴擊（暴擊）

攻擊檢定自然骰值為 20 → **暴擊**。
- 自動命中（無視 DEF）
- 武器基礎傷害取最大值
- 附加 D6 暴擊效果：

| d6 | 附加效果 |
|:--:|------|
| 1 | 護甲裂口：目標裝甲完整度（ARMR）額外 −3 |
| 2 | 武器損壞：目標攻擊檢定劣勢直到修復 |
| 3 | 擊倒：目標需消耗 1 AP 起身 |
| 4 | 大量出血：每回合額外 −2 HP |
| 5 | 系統短路（機械目標）：下回合無法行動 |
| 6 | 即死威脅：目標 HP < 50% → 立即重傷 |

> **暴擊附加效果的持續與修復規則：**
> - **武器損壞（效果 2）：** 目標武器受損，攻擊檢定劣勢直到修復。修復需花費 1 個行動進行設備維修（設備維修）檢定（DC 15）；非工程兵種可花費 2 個行動嘗試（DC 18）。
> - **大量出血（效果 4）：** 每回合開始時額外 −2 生命值（HP），持續 3 回合後自然止血；或由醫療兵花費 1 個行動進行醫療檢定（DC 15）立即止住。
> - **系統短路（效果 5）：** 僅對機械／自動目標生效，效果等同暈眩（暈眩）1 回合。

## 5.6 團隊協同行動

協同行動需兩個特定兵種在同一區域、彼此視線範圍內。每個協同行動每場任務可用一次（特別標註除外）。

### 突擊爆破（突擊爆破）——突擊手 + 工程師

1. 工程師進行工程（ENG）檢定（DC 12）設置定向爆破
2. 爆破成功 → 艙壁炸開 2m 破口。爆炸半徑 3m 內敵方承受 3d6 傷害
3. 突擊手獲得先鋒突入雙倍效果：先攻（INIT）+10、免費移動加倍
4. **突入後第一回合內，區域所有敵方混亂（混亂）**

### 戰地急救（戰地急救）——醫療兵 + 突擊手

1. 突擊手消耗全部 AP，守在醫療兵和傷員旁進行近距離防禦
2. 救治期間敵方對醫療兵和傷員的攻擊劣勢
3. 若攻擊命中，突擊手可選擇承受該傷害
4. **醫療兵的救治效果加倍**（戰地穩定恢復 2d6 HP）

### 雙軌壓制（雙軌壓制）——重火力手 + 偵察兵

1. 偵察兵進行戰術標記：感知（PER）檢定（DC 12）標記所有敵方位置
2. 重火力手在同一回合進行火力壓制
3. **壓制範圍加倍**。每個被壓制敵方額外承受 1d8 精確傷害。敵方抵抗 DC +2
4. 此協同行動每任務可用 **2 次**

### 緊急撤離（緊急撤離）——工程師 + 任意隊員

1. 工程師在撤離點進行工程（ENG）檢定（DC 15，因有人掩護 −3）建立臨時出口
2. **全隊撤離檢定優勢（優勢）**
3. 即使倒數歸零，可進行一次絕望撤離（韌性（RES）DC 20）——成功則被母艦牽引光束抓住，全員 HP 歸零但存活

## 6.4 艦隊配額（FQ）經濟系統

艦隊配額（FQ）是艦隊指揮部核發的「高階資源配額點數」。基礎武器、標準護甲與基本氧氣由母艦**免費配額**供應；但重型武器、特種／原型裝備、額外消耗品補給與軌道支援等超出基礎配額的物資，須以 FQ 兌換。**FQ 跨任務累積，不會因任務結束而清零。**

### FQ 獲取

| 來源 | FQ |
|------|:--:|
| 任務主要目標完成 | +10 |
| 次要目標完成（每個） | +3 |
| 全員生還撤離 | +5 |
| 任務評級 S 級 | +5 |
| 任務評級 A 級 | +2 |
| 首次擊破新型敵艦（首殺） | +2 |
| 回收高價值戰利品 | +3 |
| 傑出團隊協同 | +1 |

### FQ 兌換成本

每件物品的 FQ 兌換成本**直接等於其「聲望階級」對應值**，不另立裝備類型對照表：

| 聲望階級 | FQ 成本 |
|------|:--:|
| 未知 | 0 |
| 認可 | 3 |
| 信任 | 6 |
| 尊敬 | 10 |
| 傳奇 | 15 |

> 例：等離子步槍（認可）兌換成本 3 FQ；等離子砲（尊敬）10 FQ；原型動力裝甲（傳奇）15 FQ；基礎輕／中型武器與標準護甲（未知）屬母艦免費配額，0 FQ。各物品詳細成本見《物品圖鑑》。

### 消耗品與軌道支援

所有消耗品皆屬「未知」階級，FQ 成本為 0，由母艦免費配額供應（見 §4.5）。軌道支援（如軌道轟炸）屬特殊申請，由 GM 依任務規模以 FQ 核發，建議基準 30 FQ。

### 規則要點
- FQ 於任務間累積，可跨多個任務存儲。
- 母艦免費配額：每名隊員每任務可免費攜帶基礎武器、標準護甲與基本氧氣，無須消耗 FQ。
- 超出免費配額的聲望門檻裝備（認可以上），依其聲望階級以 FQ 兌換（見上表）。
- 單次任務出發前，玩家向 GM 提交「裝備申請單」，GM 依當前 FQ 結餘核准。
