## 第一章：核心規則

### 骰子系統

本遊戲使用 **d20 擲骰系統**。核心公式：

```
檢定結果 = 1d20 + 屬性修飾值 + 熟練加值 + 環境修飾值
```

檢定結果 ≥ 難度等級（難度等級，DC）即為成功。自然 20 = 大成功（大成功）；自然 1 = 大失敗（大失敗）。

**優勢（優勢）：** 擲 2d20 取較高者。  
**劣勢（劣勢）：** 擲 2d20 取較低者。  
兩者互相抵消。等效於約 ±5 修飾值（±25% 成功率）。

### 五大屬性（1–20）

| 屬性 | 縮寫 | 含義 |
|------|:---:|------|
| 戰術（戰術） | TAC | 近距離戰鬥、武器使用、戰術判斷 |
| 工程（工程） | ENG | 技術操作、設備破解、環境分析 |
| 機動（機動） | MOB | 在各種重力環境中的移動能力 |
| 感知（感知） | PER | 環境察覺和戰術預判 |
| 韌性（韌性） | RES | 身體承受力和意志力 |

屬性修飾值 = (屬性值 − 9) ÷ 2（向下取整）。

### 技能體系（20 項技能，4 級熟練）

| 屬性 | 關聯技能 |
|------|------|
| 戰術（TAC） | 近戰攻擊、遠程射擊、爆破、戰術指揮 |
| 工程（ENG） | 系統破解、設備維修、電子戰、艦船工程 |
| 機動（MOB） | 零重力移動、規避、潛行、跳躍突進 |
| 感知（PER） | 環境掃描、威脅偵測、追蹤、先制 |
| 韌性（RES） | 承受傷害、意志抵抗、缺氧耐受、超載極限 |

熟練等級：未受訓（未受訓）+0 / 熟練（熟練）+2 / 專家（專家）+4 / 大師（大師）+6。

## GM-1：完整檢定機制與 DC 設定指南

### 設定 DC 的核心原則

遊戲主持人（GM）在設定難度等級（DC）時，請參考以下原則：

1. **以敘事為先**——先想像行動在虛構世界中的難度，再選擇對應的 DC
2. **55% 基準線**——專精角色（屬性修飾值 +3、熟練 +2，合計 +5）面對「挑戰」級 DC 16 時成功率為 50%。這是本系統的設計甜區
3. **環境是關鍵**——同樣的行動，在交火中比在安靜環境中 DC 至少高 3
4. **失敗有看頭**——如果失敗只是「沒發生任何事」，考慮降低 DC 或讓失敗帶來有趣的後果

### DC 快速設定參考

| 情境 | 建議 DC |
|------|:---:|
| 破解標準門禁（無人注意） | 10 |
| 破解標準門禁（交火中） | 13 |
| 破解指揮級系統 | 16 |
| 破解自毀程序（基礎 DC 15，每經過一回合 +2） | 15–25 |
| 零重力下穩定推進 | 13 |
| 零重力下精確射擊 | 15 |
| 感知到埋伏（標準敵方） | 13 |
| 感知到埋伏（菁英敵方潛行） | 對抗檢定 |
| 在 4G 重力下站起來 | 15 |
| 找出敵艦結構弱點 | 13（人類艦）/ 16（外星艦） |

### 隱藏 DC 與公開 DC

| DC 公開策略 | 使用時機 |
|------------|------|
| **公開 DC** | 當角色能合理評估行動難度時（如「這扇門的鎖看起來是軍規級的——相當棘手」） |
| **隱藏 DC** | 當角色無法評估難度時（如外星裝置、未知環境、敵方心靈攻擊） |
| **公開結果後補充 DC** | 當玩家需要學習機制時（如「你需要擲出 15 以上——你剛剛好差了一點」） |

## GM-2：完整的戰鬥規則（含敵方行為與 AI 邏輯）

### 回合結構

每個完整回合（一輪）分為三個階段：

```
1. 回合開始階段 → 持續效果觸發、環境變化、重力狀態確認
2. 行動階段 → 依先攻（INIT）順序，角色使用行動點（AP）執行動作
3. 回合結束階段 → 持續效果結算、狀態持續時間 −1、氧氣消耗、倒數 −1
```

### 反應（每回合 1 次）

| 反應 | 觸發 | 效果 |
|------|------|------|
| 警戒射擊 | 預先宣告 | 敵方進入視線時立即攻擊（劣勢） |

### 先攻（INIT）

```
先攻值（INIT） = 機動（MOB）修飾值 + 1d10
```

- 突擊手進入新區域首輪：先攻（INIT）骰優勢
- 伏擊方：+3
- 偵察兵成功偵察：全隊 +2
- 被伏擊方：劣勢
- 混亂中：−5

敵方同類單位共用一個先攻值——遊戲主持人（GM）一次性為同類敵方擲骰。

### 突襲輪（突襲輪）

突襲輪發生在正式戰鬥前，僅伏擊方可行動：
- 每位伏擊角色獲得 1 AP（僅可攻擊或移動）
- 敵方處於混亂（混亂）
- 突襲輪後正常擲先攻

**破門突襲效果：**

| 破門方式 | 突襲輪效果 |
|---------|-----------|
| 爆破破門（協同） | 全員 2 AP，敵方混亂 + 壓制 |
| 切割破門 | 標準突襲輪。最近敵方可能不在混亂 |
| 駭入開門 | 敵方完全未察覺。突襲輪後仍需一輪察覺 |

### 攻擊檢定與傷害

**攻擊檢定：** 1d20 + 戰術（TAC）修飾值 + 武器熟練加值 + 環境修正 ≥ 防禦等級（DEF）

**傷害公式：**
```
傷害 = 武器基礎傷害 + clamp(攻擊檢定 − DEF, 0, +3)
```

**暴擊（自然 20）：** 自動命中 + 基礎傷害最大化 + 附加 D6 效果。

> **暴擊附加效果的持續與修復規則：**
> - **武器損壞（效果 2）：** 目標武器受損，攻擊檢定劣勢直到修復。修復需花費 1 個行動進行設備維修（設備維修）檢定（DC 15）；非工程兵種可花費 2 個行動嘗試（DC 18）。
> - **大量出血（效果 4）：** 每回合開始時額外 −2 生命值（HP），持續 3 回合後自然止血；或由醫療兵花費 1 個行動進行醫療檢定（DC 15）立即止住。
> - **系統短路（效果 5）：** 僅對機械／自動目標生效，效果等同暈眩（暈眩）1 回合。

> **傷害類型：** 本系統定義七種傷害類型——實彈傷害、能量傷害、爆炸傷害、生化傷害、火焰傷害、真空燒灼傷害、精神傷害。完整互動規則見《玩家規則書》4.1。其中精神傷害（精神傷害）來自心靈攻擊，無視裝甲完整度（ARMR）池、對機械與能量單位無效，命中後 50% 機率附加混亂（混亂）。

### 自毀破解 DC（工程師專屬）

自毀破解採用單一遞增模型，與《玩家規則書》3.2 工程師能力完全一致：

- **基礎難度等級（DC）：** 15
- **遞增規則：** 每經過一回合，DC +2（即 DC = 15 + 已流逝回合數 × 2）
- **每次嘗試：** 消耗 1 次系統破解上限 + 1 回合（破解期間不能做其他行動）
- **成功效果：** 自毀倒數延遲 1d4 回合（計時暫停）
- **大失敗（自然 1）：** 倒數減半（無條件）
- **工程師嘗試：** DC −3（最低 12）
- **非工程兵種嘗試：** DC +3，且即使成功也只能延遲、無法「完全解除」
- **終極專長「系統主宰」：** DC 不再隨時間增加（固定 15）
- **團隊協作：** 主要執行者為工程師，每名協助者（系統破解熟練以上）提供 +2 協助加值（上限 +4）；若有 2 名協助者，破解成功可「完全解除」自毀

> **設計基準：** 啟動初期 DC 15（專精工程師成功率約 55%）；若拖延到第 5 回合，DC 已升至 25（成功率僅約 5%），凸顯「儘早破解」的緊迫感。

### 自毀期間特殊規則

- **時間壓力：** 每回合結束大聲倒數。玩家有 30 秒（現實時間）宣告行動——超時則該角色採取「全力撤離」
- **加速行動：** 本回合 AP +1，但所有檢定 −3
- **放棄目標：** 移動速度 ×2，無需攻擊和互動檢定。但任務失敗
- **最後一扇門：** 撤離路線的最後一道艙門永遠鎖住（DC 15 + 1d6）
- **爆炸前最後回合：** 未在氣閘/撤離點 3 格內者——死亡（無豁免）

| **增援登艦隊** | 尊敬 | 呼叫另一支突擊隊支援——獲得 2 名 AI 隊友協助 3 回合 | 每戰役 3 次 |

## GM-13：節奏控制

### 五階段情緒曲線

```
      緊張度
        ↑
        │          ╱‾‾‾‾‾‾‾╲
        │         ╱  目標完成  ╲
        │        ╱             ╲  撤離
        │  突入 ╱               ╲╱‾‾‾‾
        │   ╱  ╱ 推進
        │  ╱  ╱
        │ ╱  ╱
    切入╱  ╱
        └──────────────────────────→ 時間
```

- **切入：** 低緊張——建立氛圍。描述敵艦外觀、太空環境
- **突入：** 緊張上升——第一次交火。不應太難
- **推進：** 波動上升——每層甲板設置不同挑戰。在連續緊張後給予短暫喘息
- **目標完成：** 最高緊張——首領戰或最後挑戰。此時啟動自毀
- **撤離：** 持續緊張——時間壓力下的追逐。最後的艙門是高潮

### 自毀的觸發時機

| 觸發方式 | 效果 | 使用建議 |
|---------|------|------|
| 目標完成後 | 目標區域的最後守軍被消滅 → 指揮官啟動自毀 | 最自然的觸發方式 |
| 警報 9+ | 警報系統累積到 9 點 → 自動觸發 | 懲罰性觸發——使用需謹慎 |
| 劇情觸發 | 特定劇情事件觸發（如奪取關鍵物品） | 用於高潮節奏控制 |
| 玩家引爆 | 玩家故意引爆反應爐作為撤離掩護 | 獎勵創意——但後果自負 |

### 自毀倒數時長建議

- 短劇本（一輪遊戲）——使用固定的 5–8 回合
- 中劇本——起始設定 8–12 回合，允許工程師延長
- 長劇本——起始設定 12–15 回合，多次破解機會

## GM-17：即興創作指南

### 核心應對原則

| 原則 | 說明 | 範例 |
|------|------|------|
| **「是的，而且…」** | 玩家想法可行 + 增加有趣的後果 | 玩家想用維修管道繞過守軍 →「是的，而且管道裡還有未標記的電纜——工程（ENG）檢定成功你可以順便癱瘓這層的通訊」 |
| **「是的，但是…」** | 玩家想法可行 + 代價或風險 | 玩家想射擊重力板讓敵方飄浮 →「是的，但是你和隊友也會受影響。而且重力板破裂可能引發連鎖反應」 |
| **「不行，但是…」** | 玩家想法不可行 + 替代方案 | 玩家想遠端關閉自毀 →「不行，自毀是獨立系統無法遠端存取。但是你可以從終端機找到自毀控制室的實際位置」 |

### 玩家意外行動應對範例

| 意外情況 | 應對策略 |
|---------|------|
| 玩家想從外殼繞過所有內部防禦 | 外殼攀爬 = 全程真空。但到了目標區域還是要切開裝甲進入——裡面守軍已經知道你們來了 |
| 玩家試圖與敵方指揮官談判 | 同盟指揮官可能願意談（DC 20 戰術指揮）。蟲巢和光裔無法溝通。AI 可能提出邏輯悖論 |
| 玩家想把整艘船炸了而不是登艦 | 母艦指揮官：「我們需要那艘船的數據。登艦。」但如果是緊急情況——軌道轟炸是選項（需聲望傳奇） |
| 玩家分兵 | 分兵的每一邊遭遇強度不變——但沒有隊友支援。戲劇性極高但風險也極高 |

### 即興資源池

當你需要快速生成內容時，擲 1d6 從以下表格選擇：

**NPC 名稱：** 凱恩、維拉、索恩中士、艾可博士、幽靈（Ghost）、鐵壁（Bastion）

**環境危害：** 輻射洩漏、重力異常、電弧放電、冷卻劑煙霧、管線爆裂、結構塌陷

**意外發現：** 敵方屍體（帶著地圖標記）、未加密的資料板、廢棄的醫療站（含補給）、卡住的維修機器人（可重新編程）、未引爆的魚雷、敵方私人物品（帶照片）

**複雜情況：** 兩個敵方派系正在內鬥、發現俘虜需要救援、通訊收到友方艦隊的求救信號、母艦下令立即撤離（目標未完成）、發現比你更早登艦的另一支突擊隊的痕跡、敵方指揮官主動提出投降——但有條件

**道德困境：** 完成目標會犧牲俘虜、救俘虜會讓目標失敗、敵方指揮官挾持平民、自毀會炸毀整艘船（包括船上的非戰鬥人員）、回收的科技可能被母艦用於開發更可怕的武器、隊友被困——你是否冒險回去救人？

## GM-18：可選規則與變體

### 硬核模式

- 無孤狼加成（即使是單人玩家）
- 自毀破解只能延遲（完全解除 DC 30）
- 裝甲破裂無法在任務中修復
- 氧氣耗盡後直接死亡（無窒息檢定——3 回合後即死）
- 適合：追求最高緊張感的遊戲

### 英雄模式

- 每場任務一次「英雄時刻」——自動通過一個檢定（由玩家敘述如何做到）
- 所有角色 HP 最大值 +10
- 自毀倒數延長 50%
- 適合：敘事導向的遊戲、新手玩家

### 戰役模式

- 母艦隨著戰役進度升級（更多補給、更好突擊艙）
- 敵方會學習——同一種族的艦艇，玩家遇到的防禦策略會進化
- 隊友陣亡後——引入新角色從 1 級開始但獲得老兵傳承加成（經驗獲取速度 +50%）
- 母艦關係會隨時間改變——艦長可能調任、新艦長可能有不同風格

### 零重力專精變體

- 增加「零重力戰鬥」技能（機動（MOB）屬性）
- 允許所有兵種在零重力中獲得精通（而非只有受訓者不受罰）
- 新的零重力戰術：旋轉射擊、慣性飄移、三維包夾
- 適合：以太空為主的戰役

## GM-19：AI 隊友系統

當玩家呼叫母艦支援「增援登艦隊」（聲望 尊敬，每戰役 3 次），或單人模式需要戰友時，登場的 **AI 隊友（AI 隊友）** 使用本節規則。AI 隊友是由母艦人工智慧操控的自律戰鬥單元，行為可靠但缺乏人類的即興創造力。

### 簡化行動規則

AI 隊友每回合自動獲得 **3 點行動點（行動點，AP）**，由玩家（或遊戲主持人（GM））代為決定其單一主要行動：

| 行動選項 | 說明 |
|---------|------|
| 攻擊 | 對視線內最近／最高威脅敵方進行一次標準攻擊（數值見下方模板） |
| 掩護 | 佔據掩體，為相鄰隊友提供防禦等級（DEF）+1（持續到其下回合） |
| 治療（僅醫療型） | 為一名受傷隊友恢復 2d6 點生命值（HP） |
| 支援（僅工程／偵察型） | 工程型可進行一次 DC 15 破解；偵察型可揭示一個相鄰區域的敵情 |
| 跟隨 | 移動至隊友身邊並進入防禦姿態（不主動攻擊） |

AI 隊友**不單獨承擔重力接管、自毀破解等需兵種能力的特殊行動**——它們專精於基礎交火與支援。AI 隊友死亡（生命值（HP）歸零）後消失，不永久減員。

### 五個 AI 隊友模板

| 名稱 | 定位 | 生命值（HP） | 防禦等級（DEF） | 先攻（INIT） | 攻擊 | 特殊 |

## 單回合 GM 運行清單

```
□ 1. 回合開始階段
   □ 結算所有「回合開始時」觸發的效果
   □ 可變重力區域：擲重力變化（1d6）
   □ 所有角色進行適應檢定（如需）
   □ 確認環境危害狀態（毒氣擴散、輻射等）

□ 2. 行動階段（依先攻（INIT）順序）
   對每位角色（由高至低）：
   □ 告知當前重力狀態和環境
   □ 角色宣告行動並消耗 AP
   □ 結算行動（檢定 → 效果 → 反應）
   □ 記錄狀態變化

□ 3. 回合結束階段
   □ 結算「回合結束時」觸發的效果
   □ 所有持續狀態 −1 回合
   □ 氧氣消耗結算（真空區域）
   □ 自毀倒數 −1（如適用）
   □ 檢查是否觸發新事件（增援、警報升級）
```
