## 閱讀說明

### 數據格式

每招武功包含以下字段：

| 字段 | 說明 |
|------|------|
| **類型** | 外功(劍法/掌法/刀法/棍棒/暗器/指法/徒手/爪法)、內功(心法/橫練)、輕功、特殊(醫武/毒暗/暗器) |
| **層級** | 入門 / 進階 / 上乘 / 絕學 |
| **勁力** | 快/重/剛/柔/遠/巧 —— 決定招式剋制關係（詳見戰鬥系統 §4.4.3） |
| **真氣消耗** | 每次使用消耗的真氣值。內功心法標註維持消耗或被動增益 |
| **命中加成** | 命中檢定的額外加值（內功心法標註"—"） |
| **傷害** | 基礎傷害 + 屬性加成方式（內功/輕功標註"—"或增益效果） |
| **傷害類型** | 外傷 / 內傷 / 中毒 / 混合 / 封脈 |
| **特殊效果** | 招式獨有的戰術效果 |
| **屬性需求** | 習得和使用此招式的最低屬性要求 |
| **所屬門派** | 劍宗 / 氣宗 / 金剛宗 / 毒宗 / 影宗 / 機宗 / 藥宗 / 散人通用 |
| **精進要求** | 需要達到的武功精進境界（初窺門徑 / 小有所成 / 融會貫通 / 爐火純青 / 出神入化） |

### 數值平衡參考

| 層級 | 真氣消耗 | 命中加成 | 傷害範圍 | 備註 |
|------|---------|---------|---------|------|
| 入門 | 0–2 | +1 ~ +3 | 1d6 ~ 2d6 + 屬性 | 簡單實用，低成本 |
| 進階 | 3–4 | +3 ~ +5 | 2d6 ~ 3d6 + 屬性 | 開始有特殊效果 |
| 上乘 | 5–7 | +4 ~ +7 | 3d6 ~ 4d6 + 調整值×2 | 強力效果，重擊聯動 |
| 絕學 | 8–10 | +6 ~ +9 | 4d6 ~ 6d6 + 特殊效果 | 可改變戰局 |

### 武功覆蓋總覽

| 維度 | 覆蓋情況 |
|------|---------|
| 武功類型 | 外功 18 招、內功 5 招、輕功 4 招、特殊 3 招 |
| 武功層級 | 入門 8 招、進階 10 招、上乘 8 招、絕學 4 招 |
| 勁力類型 | 快 ×7、重 ×5、剛 ×6、柔 ×4、遠 ×3、巧 ×6（均 ≥3） |
| 門派覆蓋 | 劍宗 ×4、氣宗 ×3、金剛宗 ×4、毒宗 ×3、影宗 ×4、機宗 ×3、藥宗 ×2、散人通用 ×7 |

### 1. 華山劍法·白虹貫日

> "一劍既出，如白虹貫日，凜然不可擋。"

- **類型**: 外功（劍法）
- **層級**: 入門
- **勁力**: 快
- **真氣消耗**: 1
- **命中加成**: +2
- **傷害**: 1d8 + 膂力調整值
- **傷害類型**: 外傷

- **所屬門派**: 劍宗（華山派）
- **精進要求**: 初窺門徑
