# Prologue: Welcome to the Galaxy

## 0.1 Game Overview

*Galaxy Civilization* is a **galaxy-scale** civilization-management TRPG. You do not control a single adventurer, but an **entire interstellar civilization** — starting from a single homeworld, you explore the galaxy, colonize planets, research technology, maneuver through diplomacy, wage war among the stars, and ultimately leave your mark upon galactic history.

| Role | Count | Responsibility |
|------|:---:|------|
| **Galactic Master (GM)** | 1 | Controls the galaxy itself: NPC civilizations, space creatures, anomalies, crises and cataclysms |
| **Player Civilization** | 1~4 | Each controls one interstellar civilization, formulating strategy, developing national power, and writing its epic |

## 0.2 Required Materials

- Several ten-sided dice (d10), at least 10 per player
- Civilization character sheet (see Appendix C)
- Star map (drawn or generated by the GM)
- This rulebook

## 0.3 Core Loop

Each session of *Galaxy Civilization* proceeds through the following loop:

```
┌─────────────────────────────────────────────────┐
│                 Stellar Turn (ST)                 │
│                                                  │
│  ① GM announces galactic events (anomaly, diplo-  │
│    macy, crisis)                                  │
│  ② Players spend Action Points (AP) to take actions│
│  ③ Roll dice to resolve action results            │
│  ④ NPC civilizations act automatically per AI      │
│  ⑤ Settle turn income (resource output, tech       │
│    progress, war exhaustion, etc.)                 │
│  ⑥ Advance to the next turn                        │
└─────────────────────────────────────────────────┘
```

> **Time Scale**: 1 Stellar Turn (ST) ≈ 1 in-game year. A complete campaign usually runs 50~100 turns.

# Chapter One: Core Rules

## 1.1 Dice System: d10 Dice Pool (Success-Count System)

### Core Mechanic

Roll **N** ten-sided dice (d10); each die showing a result **≥ Target Number (TN)** counts as 1 **success**. If the actual number of successes **S** ≥ the Required Successes **RS**, the check succeeds.

| Parameter | Code | Meaning | Source |
|------|------|------|------|
| Dice pool size | N | How many d10 to roll | Corresponding attribute value (1-10) |
| Target Number | TN | Minimum per-die result to count as success (3-9) | Set by GM by difficulty |
| Required Successes | RS | How many successes to accumulate (default 1) | Set by GM by complexity |
| Actual successes | S | Final number of dice ≥ Target Number (TN) | Roll result |

### Difficulty Ladder

| Difficulty | Target Number (TN) | Per-die success rate | Typical Scenario | Suggested Required Successes (RS) |
|------|:---:|:---:|------|:---:|
| Trivial | 3 | 80% | Routine administration, trade between friendly civs | 1 |
| Routine | 5 | 60% | Standard diplomacy, routine construction | 1 |
| **Standard** | **6** | **50%** | **Combat command, tech research, covert ops (default)** | **1-2** |
| Challenging | 7 | 40% | Complex negotiation, reverse engineering, infiltration into enemy territory | 2 |
| Hard | 8 | 30% | Breakthrough research, desperate defense | 2-3 |
| Very Hard | 9 | 20% | Miracle engineering, galaxy-level diplomacy | 3+ |
| Near Impossible | 10* | 10% | Reshaping the galactic order | 4+ |

> \*Target Number (TN) = 10 special rule: a die showing 10 counts as 1 success and **crits** — roll again, and if another 10 is rolled keep accumulating.

|------|------|--------|:---:|:---:|

## 1.4 Check Procedure

### Standard Check

```
1. Declare Intent: Player states the action goal
2. Determine Parameters: GM sets —
   · Related Attribute (A): attribute value = dice pool size N
   · Target Number (TN): inherent task difficulty (default 6)
   · Required Successes (RS): task complexity (default 1)
3. Apply Modifiers: tech bonus (+die), scale mod (±Target Number (TN)), assist (+die), trait (±Target Number (TN) or +die), full prep (Target Number (TN) -1)
4. Roll & Resolve: roll N d10, count successes S ≥ Target Number (TN)
5. Compare Results:
   · S ≥ Required Successes (RS) → Success
   · S = Required Successes (RS) -1 → Partial Success
   · S < Required Successes (RS) -1 → Failure
```

### Summary of Modifier Sources

| Modifier Source | Effect | Cap |
|----------|------|:---:|
| Leader skill level | +1 die per level | +5 dice |
| Tech bonus | Key tech in matching field +1~3 dice | +3 dice |
| Scale advantage | Large civ vs small civ, MIL/ECO Target Number (TN) -1~2 | Target Number (TN) min 3 |
| Scale disadvantage | Large civ in stealth/intel Target Number (TN) +1~2 | — |
| Assist participation | +1 die to lead side per assisting party | +3 dice |
| Civ trait | Species/ethics trait ±Target Number (TN) or +die | ±2 Target Number (TN) / +2 dice |
| Full preparation | Spend 1 extra Action Points (AP), Target Number (TN) -1 | Stack once |
| Rushed action | No Action Points (AP) spent but Target Number (TN) +2 | — |

### Degree of Success

| Result | Condition | Effect |
|------|------|------|
| **Great Success** | S ≥ Required Successes (RS) +3 or all dice succeed | Over-fulfilled, triggers extra gains |
| **Success** | S ≥ Required Successes (RS) | Expected goal achieved |
| **Partial Success** | S = Required Successes (RS) -1 | Basic goal met but with attached cost / side effect |
| **Failure** | S < Required Successes (RS) -1 and S > 0 | Goal not achieved |
| **Critical Failure** | S = 0 and at least one die shows 1 | Catastrophic result, severe side effect |

## 1.5 Contest Check

Applicable scenarios: diplomatic negotiation, tech race, intel confrontation, military standoff.

**Procedure**:
```
1. Both sides roll their respective attribute dice pools (with mods)
2. Compute successes S_A and S_B separately
3. Compare:
   · S_A > S_B → A wins, Degree of Victory DoV = S_A - S_B
   · S_A = S_B → compare in order: number of 10s → number of 1s (fewer wins)
   · Exact tie → Stalemate
```

## 1.6 Ongoing Action (Tech, Megastructure, Tradition)

Long-term projects spanning multiple turns use a progress-point system:

| Check Result | Progress Points |
|----------|:---:|
| Great Success | 3 |
| Success | 2 |
| Partial Success | 1 |
| Failure | 0 |
| Critical Failure | -1 (setback / rework) |

**Project Progress Threshold Reference**:
- Basic tech: 10 progress
- Intermediate tech: 20 progress
- Advanced tech: 30 progress
- Breakthrough tech: 40+ progress
- Galactic Wonder (Megastructure): 50-100 progress

### Team Cooperation

Multi-civilization joint action:
- **Lead side** uses its own attribute to roll
- **Assisting side** contributes +1 die each (max cumulative +3)
- Each assisting side spends 1 Action Points (AP) (or 0 Action Points (AP) if only providing intel / diplomatic support)
- Consequences are shared by all participants by contribution

## 1.7 Population System

Population is the foundation of a civilization — each point of population both produces and consumes resources. Total population determines the civilization's bulk and burden.

### Population Count

Each planet has an independent population count:

| Planet Type | Starting Population |
|----------|:---:|
| Homeworld | 5 |
| New colony (colony ship arrives) | 1 |
| Conquered planet (after occupation) | Current population - d3 (war losses) |

**Population Cap**: each planet's base capacity = 5 + habitability mod (80%+ → +3, 60-79% → +1, 40-59% → +0). Can be raised by building "Habitat" buildings.

### Population Growth

Each planet performs a population growth check each turn:

```
Population Growth Check: roll 1d10
- Base growth threshold: 8+ (i.e. 30% chance per turn to grow 1 population)
- Food surplus mod: net food output ≥ 2 → threshold lowered to 7+ (40% chance)
                 net food output ≥ 4 → threshold lowered to 6+ (50% chance)
                 net food output ≥ 6 → threshold lowered to 5+ (60% chance)
                 net food deficit → threshold raised to 9+ (20% chance), population may drop
- Habitability mod: 80%+ → no mod | 60-79% → threshold +1 | 40-59% → threshold +2
- Trait mod: Rapid Breeders → threshold -1 | Low Fertility → threshold +1
```

> Quick example: homeworld (80% habitability, food surplus 4) → growth threshold 6+, i.e. 50% chance per turn for +1 population.

### Per-Capita Output & Consumption

Each population's **base net contribution** (output - consumption):

| Item | Per capita / turn | Description |
|------|:---:|------|
| Energy Credit output | +2 | From basic energy facilities |
| Mineral output | +1.5 | From basic mines |
| Food output | +2 | From basic agriculture |
| Alloy output | +1.0 | From basic industry |
| Consumer Goods output | +0.5 | From basic light industry |
| Food consumption | -1 | Must be consumed per capita |
| Consumer Goods consumption | -0.25 | Basic living needs |

**Mineral consumption**: construction ship upkeep 0.5 MIN/turn, each mining station 0.5 MIN/turn (equipment wear), each research station 0.5 MIN/turn.

> The above are base values. **Planet type mods** (Gaia world +20% all, desert world minerals +30%, etc.) and **buildings** further adjust output.

### Planet Management Quick Table

| Planet | Pop | Habitability | Growth Threshold | Net Output Energy (EC) / Mineral (MIN) / Food (FOOD) / Alloy (ALLOY) / Consumer Goods (CG) |
|------|:---:|:---:|:---:|------|
| Homeworld (Continental) | 5 | 80% | 7+ | +10 / +7.5 / +5 / +5 / +1.25 |
| Colony (Ocean) | 1 | 80% | 8+ | +2 / +1.5 / +1 / +1 / +0.25 |

> Net output = (per-capita output - per-capita consumption) × population count. 80%+ habitability has no output mod (see 4.5.2 habitability table). Below 80% habitability, reduce by the mod ratio. Detailed formula in Excel.

## 1.8 Stability System

Stability represents social order, public sentiment, and productivity state on a planet. Computed independently per planet.

### Stability Formula

```
Planet Stability = UNI (civ Unity baseline)
            + Consumer Goods mod (sufficient +10 / shortage -15)
            + War mod (own civ at war -5 / enemy fleet in-system -10)
            + Race mod (per discriminated-species pop group -5)
            + Faction mod (satisfied faction +5 each / dissatisfied faction -5 each)
            + Governor mod (governor skill level ×2)
            + Event mod (GM ruling ±5~20)
```

### Stability Threshold Effects

| Stability | State | Effect |
|:---:|------|------|
| 90-100 | Utopia | All output +20%, population growth threshold -1 |
| 70-89 | Prosperous | All output +10% |
| 40-69 | Stable | No mod |
| 20-39 | Unrest | All output -20%, 10% chance per turn to trigger **Protest Event** |
| 1-19 | Crisis | All output -50%, 30% chance per turn to trigger **Rebellion** |
| 0 or below | Collapse | Planet immediately declares independence or defects to enemy |

**Protest Event (d6)**: 1-2 Strike (output -10% more for 2 turns) / 3-4 Riot (requires 1 Action Points (AP) to suppress or concede) / 5-6 Local Autonomy Movement (GM narrative event)

**Rebellion**: planet spawns rebels (strength = population × 20 Military Strength (MP) in ground forces). Requires deploying ground armies to suppress or diplomatic concession.

### Ways to Raise Stability

- Spend 1 Action Points (AP) on "Internal Stabilization" → roll Unity (UNI) check, success gives target planet Stability +5~15
- Ensure sufficient consumer goods (check each planet: consumer goods output ≥ population × 0.25)
- Appoint a high-skill governor
- Satisfy faction demands (see 1.10)
- Propaganda Campaign (special action, Unity (UNI) = 7, success +10 Stability for 3 turns)

## 1.9 Empire Size & Penalties

Empire Size represents the administrative burden of a civilization. The larger the territory, the harder centralized management.

### Size Calculation

```
Empire Size = total systems × 2 + colonized planets × 5 + total population × 0.3
```

> Example: starting civ (1 home system + 1 colony = 2 systems, 2 planets, 6 population) → size = 2×2 + 2×5 + 6×0.3 = 4 + 10 + 1.8 = 15.8 ≈ 16

### Size Penalty Thresholds

| Size | State | Tech Research Target Number (TN) | Tradition Unlock Cost |
|:---:|------|:---:|:---:|
| ≤50 | Lean & Efficient | No mod | Baseline |
| 51-100 | Management Pressure | +1 | +30% |
| 101-200 | Bureaucratic Bloat | +2 | +60% |
| ≥201 | Bloated Empire | +3 | +100% |

> Specialization "Efficient Administration": all penalty effects -20% (i.e. thresholds become 60/120/240).
> Tech "Stellar Administration T1/T2/T3": each level raises size penalty threshold by +20.

## 1.10 Faction System (Brief)

Factions are internal political groups within a civilization. Every civilization produces factions once it reaches a certain size.

### Faction Generation

- Civilization population ≥ 10 → first faction appears
- Every +15 population → possible new faction (GM ruling, usually based on ethics conflict)
- Max factions = 3 + ⌊Civilization Level/4⌋

### Faction Demands

Each faction has 1-2 **core demands**, e.g.:
- Militarist faction: "Launch a war outward"
- Pacifist faction: "Sign non-aggression treaties with all neighbors"
- Science faction: "Maintain at least 1 Tier ahead of neighbors"
- Religious faction: "Protect holy sites from heathen desecration"

### Faction Influence

| Faction Satisfaction | Effect |
|:---:|------|
| Satisfied (demands met) | Planet with that faction +5 Stability; influence output +1/turn |
| Neutral | No mod |
| Dissatisfied (demands ignored) | Planet with that faction -5 Stability; may trigger protest or secession event |

> GM may use factions as a narrative engine — a dissatisfied faction leader may become the core of a rebellion, while a satisfied faction may offer unexpected help.

### Void Disturbance (Psionic Civs Only)

Psionic civilizations (Psionic species / Psionic Awakening origin) have a natural connection to the Void dimension. This is a double-edged sword.

**At end of each turn**, the GM makes a **hidden roll of 1d10** for the psionic civ (player cannot see result, but GM may describe omens):

| d10 | Result | Effect |
|:---:|------|------|
| 1 | **Void Storm** | Random planet Stability -15, psionic fleet launch speed -2 this turn |
| 2-3 | **Void Whisper** | GM privately tells player a vague prophecy / warning (truth uncertain) |
| 4-5 | **Void Gift** | This turn psionic checks +1 die; gain 5 Psionic Points |
| 6-10 | Nothing Happens | Void is calm |

**Psionic Points**: psionic civs gain 2 Psionic Points per turn (cap 20), used for special psionic combat abilities (see 3.8).

> After Psionic Ascension, Void Disturbance frequency doubles (hidden roll becomes 2d10 per turn, take lower value — more frequent triggering).

## 2.11 Leader System

### Leader Types

| Type | Core Attribute | Effect Domain | Level Range |
|------|----------|----------|:---:|
| Ruler | By government | Empire-wide efficiency | 1-10 |
| Governor | Economy Power (ECO) / Unity (UNI) | Manage planet / star sector | 1-10 |
| Scientist | Science Power (SCI) | Research speed / anomaly investigation | 1-10 |
| Admiral | Military Power (MIL) | Fleet command | 1-10 |
| General | Military Power (MIL) | Ground army combat | 1-10 |

- **Skill Level**: +1 die per level in related checks
- **Leader Trait**: 1-3 (gained as level rises)
- **Max Leaders**: 3 + ⌊Civilization Level/4⌋

### Leader Recruitment

Recruiting a new leader costs **1 Action Points (AP) + 10 Influence**. Obtained from the following channels:
- Every time a corresponding level threshold is reached (Level (Lv.) 2/5/9/13/17), gain 1 **free recruit** (no Action Points (AP) and influence spent)
- May purchase elite leaders from Enclave powers (mercenary exchange / curator) (resource cost doubled, starting level +1)
- May promote a subordinate of an existing leader (GM ruling, suited to narrative)

### Leader Death & Succession

- **Natural Lifespan**: every 10 turns a leader performs an **aging check** (1d10, result ≤ current level → lifespan exhausted, natural death)
- Long-Lived trait: check threshold becomes `level - 2`
- Short-Lived trait: check threshold becomes `level + 2`
- Machine / synthetic leaders: immortal, no natural death
- **Combat Death**: flagship destroyed → fleet admiral rolls 1d10, result ≤ 3 → killed in action
- **Succession**: after ruler death, auto-succession per government rules (election / hereditary / appointed)
- **Inheritance**: new leader starting level = predecessor level - d3 (min 1)

### Leader Leveling

- Leaders accumulate XP by completing actions
- Each turn lead side: check success +1 XP, great success +2
- Level up: XP accumulates to `current level × 3` → level +1
- Each level up GM offers 3 random leader traits, player picks 1

## 3.2 Fleet Movement

Uses the **Hyperspace Lanes** network connecting adjacent systems:

| Ship Class | Systems Moved per Turn |
|----------|:---:|
| Corvette / Destroyer | 2 |
| Cruiser | 1.5 (3 systems every two turns) |
| Battleship / Titan | 1 |
| Juggernaut | 0.5 (1 system every two turns) |

### Interception

Intercepting side rolls `Sensor Level + Admiral Tactics d10 vs Target Number (TN) = target speed + stealth mod`.
- **Success**: fleet battle forced to occur
- **Failure**: target passes through system (consumes double movement)

### Retreat

Emergency hyperspace jump check: `Speed + Admiral Tactics d10 vs Target Number (TN) = enemy sensor + intercept mod`
- **Success**: retreat to adjacent friendly system, suffers 10%-30% retreat loss
- **Failure**: must fight

## 3.3 Fleet Battle Turn Structure

```
Phase 1: Tactical Recon → Phase 2: Commander Decision → Phase 3: Long-range Exchange
→ Phase 4: Mid-range Exchange → Phase 5: Close-range Melee
→ Phase 6: State Settlement → Phase 7: Battle Assessment
```

### Initiative Rules

Initiative = Sensor Level + Admiral Maneuver attribute + die mod (ambush +2, tech advantage +diff×2).

The initiating side settles damage first in all firing phases — if damage is enough to destroy a target ship, that ship cannot counterattack this phase.

### Damage Calculation Flow

```
Final Damage = Base Damage × Hit Mod × Penetration Mod × Type Mod − Mitigation

① Hit: roll Military Power (MIL) dice pool (with weapon accuracy bonus) vs Target Number (TN) = target speed + evasion mod
   Guided weapons ignore evasion mod; point defense rolls its own intercept dice pool

② Penetration: shield penetration rate determines how much damage bypasses shield to hit armor / hull

③ Armor mitigation: actual damage = post-armor-pierce damage - target armor value (min 1)

④ Type mod:
   · Energy vs armor -10% | Kinetic vs shield +30%~50% | Explosive vs armor +50%
   · Strike craft (bomber) vs large ships +30%
```

### Damage Absorption Order

```
Hit → Evasion (direct weapons) → Shield Absorb → Shield Depleted → Armor Mitigation → Subtract Hull

Damage allocation defaults to "front-line priority" (Corvette → Destroyer → Cruiser → Battleship → Titan)
Player may use "Focus Fire" order to designate target
```
