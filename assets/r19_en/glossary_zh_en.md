# 星海文明 — 中英術語表（Glossary: Galaxy Civilization TRPG）

> Stellaris-inspired galactic civilization-management TRPG. 本表鎖定官方英譯，所有翻譯 agent 優先套用。
> 格式慣例：中文全稱（縮寫）→ English Full Name (ABBR)。

## 一、六大文明屬性（Civilization Attributes）
- 軍事力（MIL）→ Military Power (MIL)
- 科研力（SCI）→ Science Power (SCI)
- 經濟力（ECO）→ Economy Power (ECO)
- 外交力（DIP）→ Diplomacy Power (DIP)
- 凝聚力（UNI）→ Unity (UNI)
- 情報力（INT）→ Intelligence Power (INT)

## 二、核心機制（Core Mechanics）
- d10 骰池成功計數制 → d10 Dice Pool Success-Count System
- 行動點數（AP）→ Action Points (AP)
- 星曆週期（ST）→ Stellar Turn (ST)
- 目標值（TN）→ Target Number (TN)
- 難度階梯 → Difficulty Ladder；難度等級（DC）→ Difficulty Class (DC)
- 成功度 → Degree of Success
- 對抗檢定 → Contest Check
- 延續性行動 → Ongoing Action
- 文明規模等級（Scale, 1-5）→ Civilization Scale Level (Scale, 1-5)
- 派生屬性 → Derived Attributes
- 人口系統 → Population System；人口 Population
- 穩定度系統 → Stability System；穩定度 Stability
- 帝國規模與懲罰 → Empire Size & Penalties
- 派系系統 → Faction System；派系 Faction
- 虛空擾動 → Void Disturbance（靈能文明專屬 psionic civs only）
- 特質點數（TP）→ Trait Points (TP)
- 五時代 → Five Eras；文明等級 → Civilization Level
- 專長系統 → Specialization System；專長 Specialization
- 科技樹 → Tech Tree
- 標準行動清單 → Standard Action List
- 修正來源彙總 → Summary of Modifier Sources

## 三、文明創建（Civilization Creation）
- 物種 → Species（十大可選物種 ten selectable species）
- 特質系統 → Trait System（正面特質 positive traits / 負面特質 negative traits）
- 倫理軸系統 → Ethics Axis System：
  - 軍國主義 ↔ 和平主義 → Militarism ↔ Pacifism
  - 排外主義 ↔ 親外主義 → Xenophobia ↔ Xenophilia
  - 威權主義 ↔ 平等主義 → Authoritarianism ↔ Egalitarianism
  - 唯物主義 ↔ 唯心主義 → Materialism ↔ Spiritualism
- 政體（7 種）→ Government (7 types)
- 起源（8 個）→ Origin (8)
- 文明創建流程（10 步）→ Civilization Creation Flow (10 steps)

## 四、圖鑑主題（Codex Topics）
- 倫理圖鑑 → Ethics Codex（社會結構 Social Structure；外交態度 Diplomatic Stance；生活形態 Life Form；科技觀 Technology View）
- 政體圖鑑 → Government Codex
- 武器圖鑑 → Weapon Codex
- 物種圖鑑 → Species Codex
- 特質圖鑑 → Trait Codex
- 科技圖鑑 → Tech Codex（物理（PHYS）Physics；社會（SOC）Society；工程（ENG）Engineering）
- 艦船圖鑑 → Ship Codex
- 起源圖鑑 → Origin Codex

## 五、戰鬥與武器（Combat & Weapons）
- 武器 slot：S / L / X → Slot: S (Small) / L (Large) / X (XL)
- 傷害 → Damage；射程 → Range（近 Close / 中 Medium / 遠 Long）；命中 → Accuracy
- 護盾穿透 → Shield Penetration；裝甲穿透 → Armor Penetration；特殊 → Special
- 武器剋制 → Weapon Counter
- 船艦 → Vessel / Ship
