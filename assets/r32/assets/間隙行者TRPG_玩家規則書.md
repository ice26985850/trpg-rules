## 1. 骰子系統

### 1.1 基礎機制：d20 + 屬性值 vs 難度等級（DC）

「間隙行者」採用 **d20 + 屬性值** 對抗 **難度等級（DC, Difficulty Class）** 的判定系統。擲一顆 20 面骰，加上對應屬性值，結果大於等於 難度等級（DC） 即為成功。

**選擇理由**：d20 的線性分佈使每個 +1 都精確等值（+5% 成功率），讓屬性配點的每一點都意義明確，支撐系統「謹慎資源管理」的設計哲學。

### 1.2 屬性值範圍

| 屬性值 | 描述 | 含義 |
|:---:|:---|:---|
| 1 | 缺損 | 天生不具備此方面天賦，幾乎無法依賴此屬性 |
| 2–3 | 薄弱 | 低於間隙行者平均水準 |
| 4–6 | 勝任 | 間隙行者的標準能力範圍 |
| 7–8 | 卓越 | 在此領域有顯著天賦，同行中的佼佼者 |
| 9–10 | 大師 | 已觸及人類在此維度的極限 |

- **創角上限**：單一屬性最高 8（可透過長期遊戲成長至 10）
- **創角下限**：單一屬性最低 1
- **配點總額**：25 點

|:--:|:--------:|:------------:|:------------:|:------------:|:---|
| 6 | 1+ | 100%* | 100%* | 85% | 瑣碎 |
| 8 | 3+ | 90% | 95% | 75% | 極易 |
| 10 | 5+ | 80% | 95% | 65% | 容易 |
| 12 | 7+ | 70% | 85% | 55% | 普通 |
| 14 | 9+ | 60% | 75% | 45% | 稍難 |
| 15 | 10+ | 55% | 70% | 40% | 困難 |
| 16 | 11+ | 50% | 65% | 35% | — |
| 18 | 13+ | 40% | 55% | 25% | 極難 |
| 20 | 15+ | 30% | 45% | 15% | — |

### 1.4 優勢 / 劣勢

| 優勢（Advantage） | 劣勢（Disadvantage） |
|:---|:---|
| 擁有對應的專業工具或物品 | 在間隙耐力低於 25% 時行動 |
| 另一角色成功協助 | 受到間隙病影響 |
| 花費額外時間準備（至少 10 分鐘） | 在時間流速異常區域行動 |
| 擁有前置情報或研究結果 | 受到創傷或恐懼狀態 |
| 自然 20 後的連鎖檢定 | 自然 1 後的恢復檢定 |
| GM 根據敘事情境裁定 | GM 根據敘事情境裁定 |

**機制**：優勢時擲 2d20 取高，劣勢時擲 2d20 取低。優勢/劣勢互不疊加。

**概率影響**（屬性 5 對 難度等級（DC） 12）：正常 70% / 優勢 91% / 劣勢 49%

### 1.5 大成功（自然 20）與大失敗（自然 1）

**大成功（自然 20）**：檢定自動成功。獲得以下之一：洞察（發現意外資訊）、恢復（+1 間隙耐力）、餘韻（下次相關檢定優勢）、共鳴（間隙生物態度提升一級）。

**大失敗（自然 1）**：檢定自動失敗。承受以下之一：消耗（額外 -1 耐力）、注意（引起不友善存在注意）、震顫（下次相關檢定劣勢）、裂痕（當前位置間隙結構不穩定）。

## 2. 屬性系統

### 2.1 五大屬性

**覺察（Awareness）**：察覺異常、感知間隙入口、注意到表層世界中不該存在的東西。

**穿梭（Traversal）**：在表層與間隙之間移動的流暢度，以及在間隙內部導航的能力。

**拾遺（Retrieval）**：辨識並取回遺失物的能力。感知物品的情感共鳴，理解它的「被遺忘的故事」。

**交涉（Negotiation）**：與間隙中的「居民」溝通——理解它們的邏輯並找到共存的方式。

**定錨（Anchoring）**：保持與現實的連結，不被間隙同化的核心能力。定義間隙耐力上限、恢復速度、抵抗間隙病的門檻。

### 2.2 屬性值含義表

| 屬性值 | 標籤 | 在間隙行者社群中的含義 |
|:---:|:---|:---|
| 1 | 缺損 | 此領域幾乎無天賦，每次依賴都伴隨巨大風險 |
| 2 | 薄弱 | 勉強能應付基礎情境，但不可依賴 |
| 3 | 入門 | 受過基礎訓練或有些許天賦 |
| 4 | 初成 | 能在非壓力情境中可靠使用 |
| 5 | 勝任 | 間隙行者的一般水準，可獨立作業 |
| 6 | 熟練 | 在團隊中常被依賴處理此類事務 |
| 7 | 精進 | 在間隙行者社群中以此能力聞名 |
| 8 | 卓越 | 創角階段的巔峰，同行中的權威 |
| 9 | 宗師 | 數十年經驗或天生奇才（僅可透過成長達成） |
| 10 | 傳奇 | 人類在此維度的理論極限 |

### 2.3 25 點配點規則

1. 五大屬性起始值均為 0，投入點數即為屬性值
2. 每點投入使屬性值 +1
3. 單一屬性 **下限 1**（必須至少投入 1 點）
4. 單一屬性 **上限 8**（創角階段不可超過 8）
5. 總投入 **恰好 25 點**

## 4. 檢定規則

### 4.1 被動檢定

**被動值 = 10 + 屬性值**

| 被動檢定 | 公式 | 用途 |
|:---|:---|:---|
| 被動覺察 | 10 + 覺察 | 自動感知範圍內的間隙入口、異常 |
| 被動殘留感知 | 10 + 覺察 + 拾遺 | 察覺其他存在經過的痕跡 |
| 被動意志防線 | 10 + 定錨 + 交涉 | 抵抗持續性的間隙環境影響 |

### 4.2 主動檢定流程

1. GM 宣告檢定屬性與 難度等級（DC）
2. 玩家可提出優勢理由
3. 擲 d20 + 屬性值
4. 比較結果與 難度等級（DC）

### 4.3 難度等級（DC） 難度階梯

| 難度 | 難度等級（DC） 範圍 | 範例 |
|:---|:---:|:---|
| 瑣碎 | 5–7 | 注意到明顯的間隙波動 |
| 極易 | 8–9 | 穿過天然門檻、取回普通遺失物 |
| 容易 | 10–11 | 標記一個清晰的錨點 |
| 普通 | 12–13 | 穿過人造門檻、取回善意遺留物 |
| 稍難 | 14–15 | 在間隙中快速移動、應對不友善居民 |
| 困難 | 15–16 | 穿過創傷門檻、取回記憶結晶 |
| 極難 | 17–19 | 穿過記憶門檻、取回間隙造物 |
| 近不可能 | 20–23 | 密封裂縫、取回被遺忘者 |
| 傳說 | 24+ | 修復一個正在崩解的間隙區域 |

### 4.4 對抗檢定

雙方各擲 d20 + 對應屬性值。結果較高者獲勝。平手時局勢維持現狀。

### 4.5 協助規則

協助者在該檢定屬性上 ≥ 3，且能合理提供幫助。被協助者獲得優勢。單次檢定最多一名協助者。

- 進入間隙：1–4（依門檻類型）

- 搜索：1 / 次
- 互動：1–3 / 次
- 維持：1 / 場景
- 標記：2
- 緊急撤離：3
- 密封裂縫：3

### 耐力狀態速查
- \>50% 穩定：無懲罰

# 第二章：角色創建

> **設計要旨**：你不是戰士、法師、或盜賊。你是「間隙行者」——一個能在對的時間、站在對的門檻上，滑入空間之間夾層的人。你的角色不由職業定義，而由你失去過什麼、你在找什麼、以及你在哪道門檻前猶豫過定義。

---

## 2.1 角色創建總覽

創建一名間隙行者需要七個步驟。每一步都同時建立數值與故事——這裡沒有「先填屬性再想背景」的順序。你的屬性來自你的經歷，你的經歷來自你的屬性。

| 步驟 | 名稱 | 產出 |
|---|---|---|
| 一 | 第一次穿越 | 角色的起源故事；確定「你為什麼看得見」 |
| 二 | 屬性配點 | 五大屬性數值；25點分配 |
| 三 | 你的第一個門檻 | 一個具體地點的命名與描述 |
| 四 | 定錨物 | 一件物品（或一個空缺——你的劇情目標） |
| 五 | 你丟過的東西 | 一件失物及其故事 |
| 六 | 間隙中的熟人 | 一個間隙生物關係 |
| 七 | 你不願再去的門檻 | 一個創傷地點 |

---

## 2.2 步驟一：第一次穿越

> 「每個人第一次掉進間隙的方式都不一樣。但有一件事是相同的——從那之後，你看世界的方式變了。」

### 規則說明

你的角色第一次進入間隙是什麼時候？這決定了你與間隙的初始關係。選擇以下一個起源，或與 GM 共同創作：

#### 起源選項

**A. 童年意外**（穿梭 +1 背景修正）
你在小時候追著什麼東西跑過了門檻——一顆彈珠、一隻貓、或者只是因為那扇門半開著，你想看看門後面有什麼。你不見了十五分鐘。沒有人相信你去過「另一個地方」。你自己也花了很多年才確定那不是夢。

- *引導問題*：你那年幾歲？你在追什麼？回來之後，有誰相信你嗎？

**B. 瀕死經驗**（定錨 +1 背景修正）
你曾經死過——短暫地。或者非常接近。心跳停止的那幾秒鐘，你沒有看到光——你看到了一道門。你選擇了回頭。但從那之後，你開始注意到其他門。

- *引導問題*：你怎麼「死」的？在手術台上？車禍？溺水？你看到的那道門長什麼樣子？

**C. 被人帶進去的**（交涉 +1 背景修正）
有一個人——另一個間隙行者——在你生命中的某個時刻，牽著你的手，帶你穿過了一道門檻。也許是為了救你。也許是為了展示。也許那個人自己也在尋找什麼。那個人現在在哪裡？你還找得到他嗎？

- *引導問題*：帶你進去的人是誰？你們是什麼關係？他/她還在嗎？你欠他什麼，或者他欠你什麼？

**D. 被拉進去的**（覺察 +1 背景修正）
你不是自願進去的。某個東西——某個在間隙中的東西——拉了你。也許是一隻手從門縫中伸出來。也許是一陣你無法抵抗的風。也許只是一個念頭：*進來。*你進去了，你出來了，但你不確定自己是不是「完整地」出來了。

- *引導問題*：拉你的東西是什麼？你看到它了嗎？你覺得它還在等你回去嗎？

**E. 刻意尋找的**（拾遺 +1 背景修正）
你丟了某樣非常重要的東西。你知道它沒掉在地上——它消失了。你在網路上找到了一些奇怪的討論串，在圖書館的地下室找到了一本沒有書名的書，然後你在某個凌晨兩點，故意站在你確定的那道門檻上。你進去了。你沒找到你要的東西——但你知道它在裡面。

- *引導問題*：你丟的是什麼？你現在還在找嗎？你為了找到進入間隙的方法，付出了什麼代價？

#### 背景修正說明

你選擇的起源賦予某個屬性一個「背景修正」+1。這個修正**不計入**步驟二的25點配點上限。換句話說，你可以讓該屬性達到9（背景修正可突破上限），這是唯一在角色創建時突破屬性上限8的方式。

如果你與 GM 共同創作自定義起源，與 GM 商量對應哪個屬性獲得背景修正。

## 2.3 步驟二：屬性配點

### 2.3.1 屬性定義

| 屬性 | 含義 | 在遊戲中的典型用途 |
|---|---|---|
| **覺察** | 感知異常、發現間隙入口 | 找到門檻、察覺空間扭曲、被動感知 |
| **穿梭** | 在表層與間隙之間移動的流暢度 | 進入/退出間隙、間隙中移動、迴避危險 |
| **拾遺** | 辨識並取回遺失物的能力 | 搜索遺失物、判斷物品來源與歸屬 |
| **交涉** | 與間隙中的「居民」溝通 | 間隙生物互動、密封裂縫交涉、交換協商 |
| **定錨** | 保持與現實的連結、不被間隙同化 | 抵抗間隙病、標記路徑、記住自己是誰 |

### 2.3.2 屬性值含義

| 屬性值 | 含義 |
|---|---|
| 1 | 普通人水準——你在這方面沒有特殊天賦 |
| 2 | 略高於常人——經過一些基礎訓練或生活經驗 |
| 3 | 有能力的間隙行者——你能可靠地使用這項屬性 |
| 4 | 熟練的間隙行者——這是你的舒適領域 |
| 5 | 專家級——其他間隙行者會認可你這方面的能力 |
| 6 | 卓越——你能做到大多數間隙行者做不到的事 |
| 7 | 頂尖水準——你在這方面是圈子裡公認的高手 |
| 8 | 人類巔峰——角色創建時可達到的極限 |
| 9 | 傳奇——僅能透過背景修正達到；你的天賦本身改寫了規則 |
| 10 | 超越——僅能透過成長系統達到；你重新定義了這項能力的可能性 |

### 2.3.3 配點規則

1. **總點數**：25點，分配給五大屬性（覺察、穿梭、拾遺、交涉、定錨）。
2. **屬性範圍**：每項屬性最低為1，最高為8（不含背景修正）。
3. **起點**：每個屬性起始為0。投入點數 = 屬性值。投入1點即為屬性值1，投入8點即為屬性值8。
4. **下限**：每項屬性至少需投入1點（五項屬性最低共需5點，剩餘20點自由分配）。
5. **步驟一的背景修正**：在配點完成後，將背景修正+1加到對應屬性上。該屬性可以因此達到9。
6. **無法保留點數**：25點必須全部用完。

#### 配點計算示範

```
起始（每屬性=0）：0 / 0 / 0 / 0 / 0（剩餘25點）

每項屬性至少投入1點（共5點），剩餘20點自由分配：

方案一：均衡型
覺察5 + 穿梭5 + 拾遺5 + 交涉5 + 定錨5 = 25點
最終：5 / 5 / 5 / 5 / 5（全屬性均衡，專家級水準）

方案二：專家型
覺察8 + 穿梭8 + 拾遺3 + 交涉3 + 定錨3 = 25點
最終：8 / 8 / 3 / 3 / 3（專注覺察/穿梭，其他維持基礎能力）

方案三：全能型（無法達到）
試圖 8 / 8 / 8 / 8 / 8 = 40點 → 遠超25點上限。
25點無法讓你成為全能者——你必須做出取捨。
```

**設計說明**：全5（專家級均衡）是完全可行的——這代表角色在各方面都達到可靠水準。全8則不可能——你必須做出取捨，選擇哪些屬性是優勢、哪些是弱點。25點的設計讓角色必然有參差：總會有些事你做得好，有些事你需要依靠隊友。屬性之後仍可透過成長系統提升至10（見2.12節），但成長是稀有且意義重大的。

### 2.3.4 快速創建：屬性陣列

若想快速創建角色，從以下陣列中選擇一組，再套用背景修正：

| 陣列名稱 | 覺察 | 穿梭 | 拾遺 | 交涉 | 定錨 | 適合風格 |
|---|---|---|---|---|---|---|
| **搜尋者** | 7 | 5 | 7 | 2 | 4 | 專注尋找遺失物，不擅與生物打交道 |
| **溝通者** | 4 | 4 | 4 | 8 | 5 | 善於交涉，較少依賴技術性能力 |
| **穿越者** | 5 | 8 | 4 | 5 | 3 | 移動高手，但定錨薄弱——容易迷失 |
| **守門人** | 7 | 4 | 5 | 3 | 6 | 感知與定錨雙高，穩定可靠 |
| **拾荒者** | 4 | 5 | 7 | 6 | 3 | 拾遺與交涉專家，但覺察與定錨一般 |
| **均衡者** | 5 | 5 | 5 | 5 | 5 | 各方面均衡發展 |

### 2.3.5 衍生屬性計算

從五大屬性可衍生出三個關鍵數值。公式保持不變，以下提供 1-10 範圍下的計算範例。

| 衍生屬性 | 公式 | 說明 |
|---|---|---|
| **間隙耐力上限** | 定錨 × 3 + 5 | 你在間隙中能承受的總耐力消耗 |
| **門檻感知範圍** | 覺察 × 5 公尺 | 你能被動感知到門檻存在的距離 |
| **間隙病閾值** | 定錨 × 2 + 穿梭 | 抵抗間隙病惡化的個人防護值（見 §2.10.2） |

#### 計算範例

以三種典型配點展示衍生屬性：

| 屬性配置 | 定錨 | 穿梭 | 覺察 | 間隙耐力上限 | 門檻感知 | 間隙病閾值 |
|---|---|---|---|---|---|---|
| 均衡型（5/5/5/5/5） | 5 | 5 | 5 | 20 | 25m | 15 |
| 專家型（8/8/3/3/3） | 3 | 8 | 8 | 14 | 40m | 14 |
| 定錨特化（4/4/4/5/8+背景=9） | 9 | 4 | 4 | 32 | 20m | 22 |

**解讀**：
- **均衡型**（定錨5/穿梭5）：間隙病閾值15，d20+5需≥15方可抵抗，成功率55%
- **專家型**（定錨3/穿梭8）：高穿梭帶來高閾值（14）與高感知（40m），但低定錨使檢定加值僅+3，抵抗成功率50%
- **定錨特化**（定錨9/穿梭4）：閾值高達22，d20+9需≥13方可抵抗（成功率40%）；真正的優勢在於極高的間隙耐力（32點）——可以在間隙中停留更久

> **設計說明**：間隙病閾值同時受定錨與穿梭影響——定錨是「你多穩固地連結現實」，穿梭是「你在間隙中多熟練地移動」。一個高穿梭低定錨的角色（移動高手但連結薄弱）和一個高定錨低穿梭的角色（鐵錨但行動笨拙），在抵抗間隙病時各有優劣。

## 2.4 步驟三：你的第一個門檻

> 「每個間隙行者都有一個『起點』——那道你不需要找就能感覺到的門檻。你第一次穿越時透過它，之後每一次，你都認得它。」

### 規則說明

選擇或創造一個具體地點作為你的第一個門檻——你最早能穩定進出間隙的那個入口。

#### 你必須定義以下三項：

1. **地點描述**：它在哪裡？在現實世界的哪個角落？它是一道門？一段樓梯？一座橋？一個特定的走廊轉角？
2. **門檻的「名字」**：你給它取了什麼名字？這名字不必告訴任何人——它是你和這道門檻之間的秘密。
3. **門檻類型**：根據以下分類決定它的類型（這影響穿梭難度等級（DC））：

| 門檻類型 | 穿梭 難度等級（DC） | 說明 |
|---|---|---|
| 天然門檻 | 8 | 老建築的門檻、橋的兩端、樓梯轉角——這些地方天生就是「之間」 |
| 人造門檻 | 12 | 反覆穿越的習慣性門檻——每天走過的陽台、辦公室的同一道門 |
| 創傷門檻 | 15 | 發生過重大事件的地點——某人在此死去、某段關係在此結束 |
| 記憶門檻 | 18 | 你曾經穿越過的間隙入口——它記得你，你也記得它。若此門檻同時是角色的第一個門檻，穿梭檢定獲得優勢（等效 難度等級（DC） 約 13） |

#### 你的第一個門檻的特殊效果

你對你的第一個門檻有情感連結。當你從這道門檻進入間隙時：
- **穿梭檢定獲得優勢**（你太熟悉它了）
- **進入間隙時不需消耗額外耐力**（第一回合的基礎耐力消耗免除）

這是你最安全的入口——也是你最脆弱的入口。如果有人知道你的第一個門檻在哪裡，他們就掌握了你與間隙連結的關鍵。

#### 引導問題
- 你多久回去一次？
- 有人知道那是你的門檻嗎？
- 如果你站在那道門檻上但選擇*不*穿越——那一瞬間你看到什麼？

## 2.5 步驟四：定錨物

> 「定錨物不是護身符。它不是保護你——它是提醒你。當你在間隙中待太久，開始忘記藍色是什麼顏色、忘記你媽媽的聲音——你摸一下這東西，然後你想起來：對。我是從那一邊來的。」

### 2.5.1 什麼是定錨物？

定錨物是一件與你個人歷史深度連結的實體物品。它在間隙中不會改變——當間隙扭曲一切時，定錨物**保持原樣**。這就是它之所以能定錨的原因：它是唯一不受間隙影響的東西。

定錨物**不能**是：
- 你在間隙中找到的東西（間隙造物無法定錨——它來自間隙，無法提醒你表層是什麼）
- 不具備個人情感連結的普通物品（一把普通的鑰匙不行——除非那是你已故祖母給你的那把）

定錨物**可以是**：
- 一件家族傳承物（祖母的戒指、父親的手錶）
- 一件與你生命重大轉折相關的物品（大學錄取通知書、第一次出國的機票票根）
- 某人留給你的東西——尤其是已經不在了的人
- 你親手做的東西——因為你投注了時間，所以它記得你

### 2.5.2 定錨物的狀態

角色創建時，定錨物有三種可能狀態：

| 狀態 | 說明 | 機械效果 |
|---|---|---|
| **已擁有** | 你已經找到了你的定錨物，帶著它 | **被動**：間隙耐力上限+5、間隙病惡化檢定獲得優勢、中期以下間隙病症狀緩解。**主動**：在間隙中每回合可花費1行動「觸碰定錨物」來獲得該回合的定錨檢定優勢（不限於間隙病，包含標記路徑、確認所在層級、抵抗迷失等）。**冥想**：在間隙中每日一次，花費10分鐘專注於定錨物冥想，恢復 定錨值×3 點間隙耐力 |
| **未找到（已知）** | 你知道它可能是什麼，但還沒找到 | 無即時機械效果。這是你的個人劇情目標。GM應將找到定錨物設計為一個重要劇情里程碑 |
| **未找到（未知）** | 你不知道你的定錨物是什麼 | 創建時留空。GM可在劇情中安排「發現定錨物」的時刻——通常是在你最需要它的時候 |

### 2.5.3 定錨物的「磨損」

定錨物不是無敵的。當你處於以下情境時，定錨物會磨損：

- 在間隙耐力歸零之後仍強行停留
- 目睹極其嚴重的「不可解釋現象」
- 親手密封一道裂縫

定錨物磨損時，GM會告訴你：「你摸了一下你的定錨物——它比平常涼了一點。」或「那上面出現了一道你以前沒見過的裂痕。」此時定錨物的效果暫時失效：間隙耐力加成仍保留，但「觸碰定錨物」優勢、定錨物冥想恢復耐力、以及間隙病惡化檢定被動優勢均不可用。磨損持續直到角色在表層連續生活3天以上。

### 2.5.4 失去定錨物

如果你在劇情中失去了定錨物（被偷、遺失、或在間隙中被某物奪走）：

1. **立即觸發間隙病檢定**（見2.10節），使用你的間隙病閾值進行對抗
2. **間隙耐力上限恢復為基礎值**（失去+5加成）
3. **在間隙中每次耐力消耗後，需進行定錨檢定（難度等級（DC） 12）**——失敗則當回合所有其他檢定劣勢
4. 找回定錨物成為角色的**最優先劇情目標**

#### 引導問題
- 如果你已經擁有定錨物——它怎麼到你手上的？是誰給你的？還是你自己找到的？
- 如果你還沒找到——你最後一次看見它是什麼時候？你為什麼知道「就是它」？
- 如果有人想奪走你的定錨物——他們為什麼這麼做？

## 2.6 步驟五：你丟過的東西

> 「不是每一件遺失物都會掉進間隙。但你失去的那一件——你知道它在裡面。因為你偶爾會感覺到它。」

### 規則說明

定義一件對你的角色極其重要但已經失去的物品。這件物品可能掉進了間隙——你可能還在找它。

你必須定義：

1. **物品描述**：它是什麼？長什麼樣子？有什麼特殊標記？
2. **失去的經過**：你是怎麼失去它的？在什麼地方？在什麼情境下？
3. **為什麼重要**：這件物品為什麼對你如此重要？它跟誰有關？它代表什麼？
4. **你的態度**：你還在找它嗎？還是你已經放棄了？還是你害怕找到它——因為找到它意味著你必須面對某件事？

### 遺失品質（可選，與 GM 討論）

若你想在遊戲中真的找到它，與 GM 討論這件失物可能屬於哪種品質：

| 品質 | 拾遺 難度等級（DC） | 說明 |
|---|---|---|
| 普通遺失物 | 8 | 情感價值遠大於實際價值 |
| 善意遺留物 | 12 | 被刻意留在間隙中——也許是另一個間隙行者放的 |
| 記憶結晶 | 15 | 包含一段記憶——找到它時，你會看到失去它的那一刻 |
| 間隙造物 | 18 | 不是來自表層——是間隙本身生成的東西。用途不明 |
| 被遺忘者 | 22 | 不是物品——是一個人。被困在間隙中的活人 |
> 詳見 §3.12 遺失物的保留與使用規則。|

### 機械效果

你的失物為你的拾遺檢定提供**一次性的靈感加成**：當你在間隙中尋找與你失去之物「類似的東西」時（例如你丟的是戒指，你在找另一枚戒指），你可以宣告使用「失物共鳴」——該次拾遺檢定獲得優勢。每次遊戲章節（session）只能使用一次。

#### 引導問題
- 如果你在間隙中真的找到它——你會物歸原主（你自己）嗎？還是將它留在間隙中？
- 失去這件東西之後，你變成了什麼樣的人？跟失去之前有什麼不同？
- 有沒有人因為你失去這件東西而責怪你——或者責怪自己？

## 2.7 步驟六：間隙中的熟人

> 「牠不是你的朋友。你甚至不確定牠有沒有『朋友』這個概念。但你們互相認得。你在牠的領域中走動時，牠不會擋你。有一次，牠還幫了你。」

### 規則說明

定義一個你認識的間隙生物。你們不是朋友——但你們之間有一種「互相認得」的關係。牠幫過你一次。你欠牠一個人情——或者牠欠你。

### 你必須定義：

1. **生物類型**：選擇以下之一，或與 GM 共同創作：

| 類型 | 牠是什麼 | 牠幫了你什麼（範例） |
|---|---|---|
| **門檻徘徊者** | 一個在門檻前猶豫了太久的人——現在牠永遠跨不過去 | 牠告訴你某個門檻「不安全」——牠比你先看到危險 |
| **遺失物收集者** | 一個被遺忘的前代間隙行者，如今囤積遺失物 | 牠給了你一件關鍵物品——但你不知道牠為什麼願意放手 |
| **鏡像** | 間隙本身的產物——一個模仿你動作的倒影 | 當時你在間隙中迷路，牠模仿你模仿到一半突然指向另一個方向——那是出路 |
| **通道守衛** | 一個巨大的生物，擋在某條重要路徑上 | 有一次牠沒有擋你。你至今不知道為什麼 |
| **密封看守者** | 守在密封空間裂縫旁的存在 | 牠的眼神告訴你「還不是時候」——你聽了，後來證明牠是對的 |

2. **關係細節**：
   - 牠幫了你什麼？（具體事件）
   - 你欠牠什麼？（或者牠欠你什麼？）
   - 牠怎麼認你？（氣味？動作？某個特定的聲音？）
   - 上一次見到牠是什麼時候？

3. **牠的「名字」**：你怎麼稱呼牠？（間隙生物沒有本名——或者有，但你不知道。所以你給牠取了一個。）

### 機械效果：熟人呼喚

每兩個遊戲章節（sessions）一次，你可以嘗試呼喚你的熟人。在間隙中花費3個行動專注地「想牠」。進行交涉檢定（難度等級（DC） 由 GM 根據劇情決定，通常 12-15）：

- **成功**：牠在某種程度上回應了你——出現、給出指引、或提供一個交換機會
- **失敗**：牠沒來。或者更糟——來的是別的什麼東西
- **大成功（自然20）**：牠不只是出現——牠主動幫你，不需要你給出任何交換
- **大失敗（自然1）**：你意外呼喚了錯誤的東西。GM決定出現的是什麼

### 關係的演變

隨著遊戲進行，你與熟人的關係可能改變。GM會根據劇情推進和你的選擇調整關係狀態：

- 你履行了欠牠的 → 關係加深，交涉難度等級（DC）降低
- 你背叛了牠的信任 → 關係破裂，牠不再回應呼喚
- 你幫助牠完成了「過渡」→ 牠自由了，你獲得歸還印記，永遠失去這個熟人

#### 引導問題
- 如果你再次見到牠——你第一句話會說什麼？
- 你覺得牠為什麼幫你？牠從你身上得到了什麼？
- 如果有一天牠需要你幫助牠完成過渡——你願意嗎？（那意味著你將永遠失去牠）

## 2.8 步驟七：你不願再去的門檻

> 「每個間隙行者都有一道門檻——你寧可繞遠路也不會穿越它。不是因為它危險。是因為門的另一邊有你不願意面對的東西。」

### 規則說明

定義一道你永遠不想再穿越的門檻。你曾經在那裡經歷過某件事——可能是創傷、失落、或一個你無法挽回的決定。

### 你必須定義：

1. **門檻描述**：它在哪裡？長什麼樣子？是一道門？一個走廊？某個特定的時間點（例如「每年12月24日下午3點，我家老房子的後門」）？
2. **發生了什麼**：你在那裡經歷了什麼？你失去了誰？你做錯了什麼決定？還是你看到了什麼不該看到的東西？
3. **為什麼不願再穿越**：是因為你害怕——還是因為你內疚？還是因為穿越那道門檻會讓某件事情「成立」——而你不想讓它成立？
4. **後果**：如果你被迫穿越那道門檻——會發生什麼？（與GM討論可能的機械後果）

### 不願再去的門檻的特殊規則

- 你**無法**自願從這道門檻進入間隙——你需要通過一個 難度等級（DC） 20 的定錨檢定來強迫自己
- 如果有其他間隙行者試圖帶你穿越這道門檻——他們需要進行 難度等級（DC） 18 的交涉檢定來說服你
- 如果在劇情中你被迫從這道門檻進入間隙——進入後**立即觸發間隙病檢定**，且難度+5

### 這個門檻的敘事功能

這道門檻是你角色弧線的核心。它代表了你的角色最深的恐懼或遺憾。GM應將這個門檻納入主線劇情——不是立即強迫你穿越，而是讓它的存在成為一種持續的壓力。

一個好的「不願再去的門檻」會在遊戲的某個關鍵時刻發揮作用——也許結局時你必須穿越它才能拯救別人，也許穿越它是你完成某段旅程的唯一方法。

#### 引導問題
- 如果你站在那道門檻前一公尺——你感覺到了什麼？
- 有其他人知道這道門檻對你的意義嗎？
- 你覺得總有一天你會穿越它嗎？如果是——在什麼情況下？

## 2.9 歸還印記系統

> 「你把東西還給了它真正的主人。那一刻——在間隙中，在兩個空間之間——有什麼東西在你身上留下了一個記號。不是傷疤。更像是……一個簽名。間隙記得你做了這件事。」

### 2.9.1 什麼是歸還印記？

歸還印記是當你將遺失物歸還給原主時，在你身上留下的永久印記。它是一種形而上的標記——在表層看不見，但在間隙中，某些生物能「看到」你身上的歸還印記。牠們看你的眼神會不一樣。

### 2.9.2 獲得歸還印記

歸還印記可透過以下兩種方式獲得：

**方式A：歸還遺失物給原主**

當你滿足以下所有條件時，獲得一個歸還印記：

1. 你在間隙中找到了一件遺失物
2. 你辨識出了它的原主（透過拾遺檢定或劇情）
3. 你親自將它交還給原主
4. 原主真心感激——物品對他們確實有意義

此外，歸還遺失物給原主時，你立即恢復 **5點間隙耐力**——物歸原主的善意行為讓你暫時更穩固地連結現實。

**方式B：幫助間隙生物完成過渡**

當你幫助一個間隙生物完成過渡時（具體規則見 2.11.3 節），成功後你也獲得一個歸還印記。這代表你不只幫助了人類——你也幫助了那些被困在間隙中的存在。

**注意**：不能為了刷印記而刻意安排。GM有最終裁量權判斷歸還行為是否「真誠」。

### 2.9.3 歸還印記的層級與效果

歸還印記可以累積。每累積到一定數量，獲得新的效果：

| 累積印記數 | 層級名稱 | 效果 |
|---|---|---|
| 1 | 初印 | 在與間隙生物交涉時，交涉檢定+2（牠們感覺到你身上「歸還過什麼」——在1-10屬性範圍下，+2約等於一個屬性層級的差異） |
| 3 | 熟印 | 你可以感應到遺失物的「歸屬方向」——當你持有一件遺失物時，花費1行動進行拾遺檢定（難度等級（DC）由GM決定），成功後你模糊地感覺到原主所在的方位與距離。此外，當你處於**間隙病初期**時，間隙病惡化檢定獲得優勢（歸還印記在被動地保護你） |
| 5 | 深印 | 你在間隙中獲得一個「信譽」——非敵意的間隙生物不會先攻擊或阻擋你（牠們會先觀察）。交涉交換時，對方要求的代價降低一級（例如原本要求記憶結晶，現在接受普通遺失物）。此外，防護擴展至**間隙病中期**：當你處於中期時，間隙病惡化檢定獲得優勢 |
| 7 | 銘印 | 你可以幫助一個間隙生物完成過渡，而不需要知道牠的本名——你只需要了解牠的故事。這讓你能治療後期間隙病（見2.10節）而不必依賴GM安排的特定劇情 |
| 10 | 傳說之印 | 間隙本身認識你了。所有穿梭檢定獲得優勢。你可以感應到視線範圍內的所有門檻（無需覺察檢定）。你的名字會被其他間隙行者傳頌——雖然你不知道這件事。**歸還共鳴**：你可以選擇消耗你所有的歸還印記（歸零），將一個處於間隙病末期的角色逆轉至後期。使用後你失去所有歸還印記相關效果——但你會記得：你真正擁有的是你給出去的東西 |

### 2.9.4 歸還印記與定錨的互動

歸還印記在你身上形成一種不同於定錨物的「錨」——它來自你與世界之間的善意連結。

- 每擁有3個歸還印記，你的**有效定錨值**在與間隙病對抗時+1（僅影響間隙病檢定，不影響其他定錨檢定）
- 如果你失去了定錨物但擁有至少5個歸還印記——你不會觸發失去定錨物的即時間隙病檢定（但其他失去定錨物的懲罰仍適用）

### 2.9.5 無法獲得歸還印記的情況

- 歸還的物品是你自己的（自我歸還不產生印記）
- 物品是非自願取得的（偷來的遺失物歸還不產生印記——但你偷走後又歸還可能產生其他劇情後果）
- 原主已經死亡且沒有繼承人——此時將物品留在原主曾經居住的空間門口，由GM決定是否觸發印記

## 2.10 間隙病追蹤系統

> **本章定位**：此節提供間隙病的**玩家視角概述**——什麼是間隙病、四個階段的大致症狀、以及你作為玩家需要知道的基本風險。  
> **完整機械規則**（惡化對抗公式、詳細 難度等級（DC）、治療方式統一表）請見**第三章 §3.6**。創建角色時只需閱讀此節即可；實際遊戲中遭遇間隙病檢定時，GM 會引導你參照第三章。


> 「間隙裡沒有空氣，沒有食物，沒有水——但這些都不是問題。問題是間隙裡沒有『你』。待太久，你開始忘記自己是一個人。」

### 2.10.1 間隙病惡化的觸發條件

間隙病不會無故惡化。在以下情況觸發間隙病檢定（統一使用 §2.10.2 的閾值對抗）：

| 觸發條件 | 說明 |
|---|---|
| 間隙耐力歸零（回到表層後） | 最常見的觸發方式——你在間隙中耗盡了所有耐力 |
| 在間隙中連續停留超過10回合 | 每次額外5回合再檢定一次 |
| 從「不願再去的門檻」進入間隙 | 見步驟七——創傷之地的共振加劇侵蝕 |
| 失去定錨物 | 見 §2.5.4 節——失去現實之錨的衝擊 |
| 目睹「不可解釋現象」（GM判定） | GM可依現象強度給予檢定劣勢 |
| 嘗試從密封空間中逃脫 | 密封空間內沒有間隙——你等於在「否定你存在的合理性」 |

### 2.10.2 檢定方式：閾值對抗

間隙病檢定使用**閾值對抗**機制，取代舊有的固定 難度等級（DC） 系統。

**間隙病閾值** = 定錨 × 2 + 穿梭（角色卡已預計算）

當觸發條件發生時：
1. 擲 **d20 + 定錨修正值**
2. 對抗你的 **間隙病閾值**
3. **成功**（擲骰結果 ≥ 間隙病閾值）：間隙病未惡化，維持當前階段
4. **失敗**（擲骰結果 < 間隙病閾值）：間隙病惡化一個階段，立即生效
5. **大失敗（自然1）**：跳過一個階段——直接進入下兩個階段（例如從初期直接跳到後期）

**設計說明**：間隙病閾值同時包含定錨（你多穩固地連結現實）和穿梭（你在間隙中多熟練地移動）。兩者越高，閾值越高——但你的定錨也同時出現在檢定加值中。這創造了一種內在張力：高定錨讓你的檢定加值更高，但也提高了你需要達到的門檻。真正的防護來自定錨與穿梭的平衡——而非單一屬性的堆疊。

### 2.10.3 間隙病四階段詳細機械效果

#### 第一階段：初期（門檻發光）

**症狀描述**：你開始在表層看到不該看到的東西——門檻微微發光、走廊比實際上更長、角落裡有東西在動但你轉頭時什麼都沒有。

| 機械效果 |
|---|
| 你無法主動關閉覺察檢定——GM可以在任何時候要求你進行覺察檢定，即使你不想感知間隙 |
| 在表層與人交談時，每10分鐘需進行一次定錨檢定（難度等級（DC） 8），失敗則你短暫「恍神」——你看到了間隙的閃現，錯過了對方說的話 |
| 進入間隙時不需額外消耗（這階段間隙仍然接納你） |

**角色扮演提示**：你開始懷疑自己看到的是不是真的。你變得更謹慎——或者更煩躁。你不太確定自己是不是在「失去理智」。

#### 第二階段：中期（邊界模糊）

**症狀描述**：表層和間隙之間的界線開始溶解。你走進一個房間，不確定自己是不是還在表層。街上的人看起來像間隙生物。間隙生物看起來像街上的人。

| 機械效果 |
|---|
| **GM不再告知你當前所在層級**。你只能依靠自己的判斷和周遭的線索來推斷 |
| 在間隙中進行任何檢定時，如果失敗——你暫時「失去方向感」，下一回合必須花費1行動進行定錨檢定（難度等級（DC） 12）才能繼續行動 |
| 在表層進行社交互動時劣勢（你看起來心神不寧、反應遲鈍） |
| 進入間隙的第一回合，你需進行一次定錨檢定（難度等級（DC） 10）來「確認自己進來了」——失敗意味著你不確定自己現在在哪 |

**角色扮演提示**：你養成了觸摸東西的習慣——摸牆壁、摸桌面、摸自己的定錨物。你需要物理觸感來確認「這裡是真的」。你開始不信任自己的感官。

#### 第三階段：後期（半透明）

**症狀描述**：你的身體開始拒絕留在表層。在光線下，別人可以透過你看到後面的東西——不是完全透明，但足夠讓人在對話中突然停下來，皺著眉看著你。接近死亡的人可以看到你完整的身影。他們有時會主動跟你說話，以為你是來接他們的。

| 機械效果 |
|---|
| 所有與「正常人類」的社交檢定劣勢——他們下意識地不想看你 |
| 與「接近死亡者」（重症病患、老人、瀕死之人）的互動獲得優勢——他們能看到你真實的樣子，而且不怕你 |
| 在表層每經過24小時，需進行定錨檢定（難度等級（DC） 14），失敗則你發現自己「無意識地」站到了一道門檻上——你的身體在試圖回到間隙 |
| 你在間隙中移動時不消耗基礎耐力（你已經「半屬於」間隙了）——但這不是好事 |
| 間隙生物開始把你當作「同類」——交涉交換時代價可能提高（牠們覺得你不需要「優待」了） |

**角色扮演提示**：你開始避開人群。你不再照鏡子——或者你照鏡子的時間變得非常長，因為你需要確認自己還在。你考慮過是否應該「搬進間隙」——反正你已經半個人在裡面了。

#### 第四階段：末期（成為間隙生物）

**症狀描述**：你不是你了。

| 機械效果 |
|---|
| 角色由GM接管 |
| 角色成為一個NPC——具體來說，成為一個新的「遺失物收集者」或「門檻徘徊者」（由GM根據角色歷史決定） |
| 角色仍然存在於遊戲世界中——其他PC可能在間隙中遇到他們 |
| 該角色的玩家需要創建新角色 |
| 舊角色無法被「救回」——他們已經不是「被困在間隙中的人」，而是「間隙的一部分」 |

**角色扮演提示（對於該玩家的其他角色）**：你失去了你的前任角色。也許有一天你會遇到他們——但那已經不是你了。當你看到他們在間隙中囤積遺失物，或者在門檻前猶豫不決，你會怎麼做？

### 2.11.2 治療後的「免疫力」

- 從初期恢復後：接下來7天內不會因間隙耐力歸零而觸發間隙病檢定
- 從中期恢復後：接下來3天內間隙病檢定優勢
- 從後期恢復後：接下來24小時內間隙病檢定優勢
- 從任何階段恢復後，若再次惡化進入同一階段——該階段的難度等級（DC）永久+2（你的身體「記得」這個階段）

### 2.11.3 「幫助間隙生物完成過渡」的具體規則

這是治療後期間隙病最可靠的方法，也是遊戲中最有意義的行為之一。（末期的最後檢定見治療表#6，鏡像的犧牲見治療表#7。）

**完成過渡的步驟：**

1. **了解牠的故事**：透過交涉交換或觀察，了解這個間隙生物為什麼被困住。牠在等什麼？牠在猶豫什麼？牠失去了什麼？
2. **找到關鍵物品/人物/資訊**：通常需要回到表層尋找——一個名字、一件物品、或一個人。這構成一個小型的尋物委託。
3. **回到間隙，幫助牠完成**：將關鍵物品交給牠，呼喚牠的名字，或帶那個人來見牠最後一面。
4. **擲交涉檢定（難度等級（DC）由GM依劇情決定，通常15-18）**：成功——牠完成過渡，消失（去哪裡了？沒人知道）。你獲得歸還印記。失敗——牠猶豫了。你還可以再試，但下次難度等級（DC）+2。

**設計說明**：GM應讓每次「幫助過渡」都成為一個獨特的劇情高潮。不要讓它變成機械性的任務。每個間隙生物的過渡都是一個微型故事。

## 2.12 成長與進階系統

> 「你不會因為多穿越幾次間隙就變得更強。但每次你歸還一樣東西、幫助一個間隙生物、或者在自己不願面對的門檻前站了一分鐘——你變了。不是變強。是變得更……你自己。」

### 2.12.1 設計哲學

「間隙行者」不使用經驗值（XP）系統。角色成長來自三個層面：**敘事里程碑**、**關係深化**、和**稀有屬性提升**。

### 2.12.2 里程碑系統

遊戲分為「章節」（Chapters）和「弧線」（Arcs）。一個弧線通常包含3-5個章節，構成一個完整的故事單元。每個弧線結束時，GM根據以下標準給予角色成長：

#### 里程碑檢核表（每個弧線結束時）

| 成就 | 成長獎勵 |
|---|---|
| 歸還至少一件遺失物 | 獲得一個歸還印記 |
| 幫助一個間隙生物（不一定是完成過渡） | 獲得一個新的間隙熟人關係 |
| 發現一個新的門檻並成功穿越 | 該門檻加入你的已知門檻列表；之後從該門檻進入間隙時穿梭檢定優勢 |
| 面對自己的「不願再去的門檻」——即使沒有穿越，只是在門前站立或思考 | 該門檻的穿越難度等級（DC）降低2（你開始面對它了） |
| 學習一個密封空間的秘密 | 獲得一個關於特定密封空間的「知識標記」——之後與該密封空間相關的檢定優勢 |
| 角色完成了個人劇情目標（如找到定錨物） | 見下方屬性成長 |

### 2.12.3 屬性成長

屬性提升是稀有且意義重大的——這不只是數字變大，而是角色本質上變得更強。

| 條件 | 屬性成長 |
|---|---|
| 完成角色創建時設定的個人劇情目標（找到定錨物、找回失物、面對不願再去的門檻） | 任一屬性+1（不可超過10；背景修正屬性可達9後再以成長達10） |
| 完成一個完整的弧線（3-5章節），且弧線中角色經歷了深刻轉變 | GM可允許任一屬性+1（每個弧線最多一次） |
| 獲得第7個歸還印記（銘印） | 交涉或定錨+1（擇一） |

**屬性上限規則**：
- 創角階段：正常上限為8，背景修正屬性可達9
- 成長階段：屬性可從創建值逐步成長至最高10
- 成長計算：每項屬性可成長次數 = 10 − 該屬性創建時的數值（含背景修正）
  - 例：創建時定錨 5，該屬性最多可成長 10−5 = 5 次
  - 例：創建時定錨 8（背景修正後9），該屬性最多可成長 10−9 = 1 次
- 每次成長為 +1 屬性值，來自重大里程碑（見下表）
- 8→9 需故事級里程碑；9→10 需傳奇級成就（GM裁量）

**設計說明**：屬性成長不再是固定「上限3次」，而是與角色的起點掛鉤。起點愈低的屬性，成長空間愈大——你的弱點是最有故事可講的地方。一個從定錨 3 成長到定錨 8 的角色，在五個重大里程碑中不斷強化自己與現實的連結；而一個創建時就定錨 8 的角色，那方面已經接近人類極限，只能再成長至10（兩次傳奇級成就）。

### 2.12.4 非數值成長

這是最主要的成長方式。以下是角色可以在遊戲中獲得但不會改變屬性數字的能力：

#### 已知門檻網絡

每次你成功從一個新的門檻進入間隙並安全返回，該門檻加入你的「已知門檻列表」。這不是數字——這是你可以使用的地點。

| 門檻數量 | 效果 |
|---|---|
| 3個以上 | 你可以在城市中「串聯」門檻——從A進入間隙，不需要回到表層，直接從B出來（需進行穿梭檢定對抗兩門檻中較高者） |
| 5個以上 | 你在間隙中不再迷路——你總是知道最近的已知門檻的方向 |
| 10個以上 | 你被稱為「製圖師」——其他間隙行者會來找你問路 |

#### 間隙熟人網絡

除了步驟六創建的初始熟人，每次你幫助一個間隙生物（不一定是完成過渡），你可以嘗試建立新的關係。進行交涉檢定（難度等級（DC）由GM決定）：

- 成功：該生物成為新的「熟人」，加入你的熟人列表
- 失敗：該生物不會傷害你，但也不會特別幫你
- 大成功：該生物不只是熟人——牠主動提供一個關於間隙的重要情報

#### 特殊知識

透過劇情獲得、無法用屬性衡量的知識：

| 知識類型 | 獲得方式 | 用途 |
|---|---|---|
| **密封空間的來歷** | 調查表層的歷史記錄、訪問相關人物 | 知道某個密封空間為什麼被封起來——可能找到打開它的「鑰匙」 |
| **間隙生物的「本名」** | 從其他間隙生物口中交換得來、在遺失物（記憶結晶）中看到 | 呼喚本名可以讓該生物為你服務一次，之後牠自由了 |
| **間隙地理** | 反覆探索特定區域的間隙層 | 知道某區域的捷徑、危險區、重力異常區位置 |
| **時間流速模式** | 經驗積累（GM可在多次穿越後給予） | 對特定門檻的時間流速有一定預判——從完全隨機變為「你知道這道門通常會讓你晚回來」 |

### GM 角色創建引導提示

- 鼓勵玩家將每個步驟串聯成一個連貫的故事。例如：「我的定錨物就是我失去的那件東西裡的一部分——我祖母的戒指是一對的，我丟了一隻，另一隻我隨身帶著。」
- 讓步驟六和步驟七產生關聯——也許你不願再去的門檻跟你的熟人有關？
- 不要在創建時急著「解決」——留空的定錨物和未解決的失物是GM最好的劇情素材。
- 屬性全5（專家級均衡）是可以的——但全8不可能，玩家必須做出取捨。全5的角色在各方面都可靠但無突出優勢，他們的成長將更多來自敘事而非數字。

### 設計備註

**關於屬性範圍與配點**：25點分配到1-8範圍的五個屬性，意味著角色必然有參差——全8需要40點，遠超上限。你可以選擇均衡的5/5/5/5/5（專家級），或特化的8/8/3/3/3。這將玩家的注意力從「如何變得更強」轉移到「我的角色擅長什麼、不擅長什麼」。無論屬性多高，角色仍然脆弱——因為間隙病不看你的屬性，只看你待了多久。

**關於無職業系統**：所有PC共享「間隙行者」這個身份。角色間的差異來自他們的起源故事、他們失去的東西、他們認識的間隙生物、和他們不願面對的門檻。這創造了比職業系統更深刻的角色差異——因為這些差異來自敘事而非機制標籤。

**關於定錨物與歸還印記的互動**：這兩者形成一個互補的「錨定生態」。定錨物是內在的——它來自你個人的歷史。歸還印記是外在的——它們來自你與世界、與他人之間的善意連結。一個角色可以兩者兼具，也可以只有其一。同時失去兩者是最危險的狀態。

## §3.1 間隙行動經濟（2 行動點（AP） 系統）

### 3.1.1 間隙回合

間隙中的時間以「間隙回合」計算。每個間隙回合的主觀時間與表層一致，但表層實際經過的時間由時間流速決定（見 §3.4.3）。

每回合每個角色有 **2 個行動點（AP）**。角色可在回合內任意順序使用 行動點（AP）——移動、觀察、交涉、退出皆可混搭。

### 3.1.2 可用行動

| 行動 | 行動點（AP） | 關鍵屬性 | 難度等級（DC） | 失敗後果 |
|---|---|---|---|---|---|
| **進入間隙** | 1 | 穿梭 | 依門檻類型（8–22） | 仍進入但耐力 –2 |
| **移動** | 1 | 穿梭 | GM 依距離/扭曲設定 | 消耗雙倍間隙耐力 |
| **搜索遺失物** | 1 | 拾遺 | 依物品品質（8–22） | 未發現；GM 暗骰 |
| **觀察表層** | 1 | 覺察 | 12（一般） | 什麼都看不到，或看到錯誤資訊 |
| **交涉** | 1 | 交涉 | 依生物交涉 難度等級（DC）（10–20） | 交涉失敗，生物態度可能惡化 |
| **退出間隙** | 1 | 穿梭 | 等同進入時的門檻 難度等級（DC） | 偏差 1d10m（見 §3.7.2 偏差表） |
| **確認層級** | 1 | 定錨 | 12 | 無法確定當前所在層級深度 |
| **標記位置** | 2 | 定錨 | 10 | 標記失敗——下次無法使用該位置減免 |
| **密封裂縫** | 3 | 交涉 | 22 | 裂縫反而擴大——密封 難度等級（DC） 永久 +2 |
|> 詳細 難度等級（DC） 基準請參考第一章 §4.3 難度等級（DC） 難度階梯。|

### 3.1.3 第一回合特殊行動

| 行動 | 行動點（AP） | 關鍵屬性 | 說明 |
|---|---|---|---|
| **進入間隙** | 1 | 穿梭 | 從門檻進入。難度等級（DC） 取決於門檻類型（見 §3.1.4）。失敗仍進入但耐力 –2 |
| **確認所在層級** | 1 | 定錨 | 確定自己目前在間隙的第幾層。失敗則無法確定深淺 |

### 3.1.4 門檻與進入難度

| 門檻類型 | 穿梭 難度等級（DC） | 範例 |
|---|---|---|
| 天然門檻 | 8 | 老房子的門檻、橋的兩端、樓梯轉角平台 |
| 人造門檻 | 12 | 反覆穿越的同一個門、每天走上同一個陽台的瞬間 |
| 創傷門檻 | 15 | 發生過重大事件的地點——有人死去的房間入口、簽下關鍵合約的會議室門口 |
| 記憶門檻 | 18 | 你曾經穿越過的間隙入口——它記得你 |
| 密封裂縫 | 22 | 被刻意密封的空間的唯一裂痕——進入極難，一旦進去可能再也出不來 |

> **屬性範圍備註**：門檻 難度等級（DC） 在 1–5 系統中設定。改為 1–10 後，高屬性角色的穿梭（8–10）對低難度門檻（難度等級（DC） 8）有顯著優勢，這是設計意圖——熟練的間隙行者對於日常門檻應該駕輕就熟。記憶門檻（難度等級（DC） 18）和密封裂縫（難度等級（DC） 22）仍然構成挑戰。

## §3.2 間隙耐力五階段

### 3.2.1 耐力公式與上限

```
間隙耐力上限（間隙耐力（GE） Max）= 定錨 × 3 + 5
```

| 定錨值 | 間隙耐力（GE） 上限 | 定錨值 | 間隙耐力（GE） 上限 |
|---|---|---|---|
| 1 | 8 | 6 | 23 |
| 2 | 11 | 7 | 26 |
| 3 | 14 | 8 | 29 |
| 4 | 17 | 9 | 32 |
| 5 | 20 | 10 | 35 |

> 持有定錨物時 間隙耐力（GE） 上限 +5（見 Ch2 §2.5）。例如定錨 7 + 定錨物 = 間隙耐力（GE） 31。

### 3.2.2 耐力消耗

| 觸發條件 | 間隙耐力（GE） 消耗 |
|---|---|
| 每回合基礎消耗 | –1 |
| 穿梭檢定失敗 | –2 |
| 在重力異常區停留（每回合額外） | –2 |
| 與間隙生物深度交流（每次） | –2 |
| 目擊「不可解釋現象」（GM 判定） | –1～–3 |
| 密封空間中每回合 | –2（基礎） |
| 穿越門檻（跨層級） | –2（每次） |

### 3.2.3 五階段耐力狀態

| 階段 | 間隙耐力（GE） 百分比 | 效果 |
|---|---|---|
| **穩定** | > 50% | 一切正常。你可以清晰地感知間隙與表層的邊界 |
| **磨損** | 25%–50% | 定錨檢定劣勢。你開始忘記自己從哪個門檻進來的 |
| **侵蝕** | 10%–25% | 聽到間隙的低語——不是語言，是情緒碎片。GM 每隔 1d4 回合給你一段來自間隙的破碎感知——可能是真的，也可能不是 |
| **瀕臨** | < 10% | 每次行動前須先通過定錨檢定（難度等級（DC） 12）。失敗則「迷失」——GM 決定你該回合的移動方向與距離 |
| **耗盡** | 0 | 間隙病發作——流程：(1) 立即進行一次間隙病惡化對抗（見 §3.6）；(2) 角色被強制彈出至「最後穿越的門檻」所在表層位置；(3) 承受 1d4 天力竭（所有檢定劣勢）；(4) 返回表層後間隙病症狀持續。若最後穿越的門檻已不可用，彈至最近的天然門檻 |

### 3.2.4 耐力恢復

| 恢復方式 | 恢復量 | 條件 |
|---|---|---|
| 返回表層並長休息（8 小時） | 全部 | 每日一次。移除瀕臨與迷失狀態 |
| 表層短休息（1 小時） | 1d6 + 定錨 | 每間隙造訪限一次 |
| 定錨物冥想 | 定錨 × 3 | 每日一次，10 分鐘專注。**定錨物磨損則不可用**（見 Ch2 §2.5.3） |
| 歸還遺失物給原主 | +5 | 歸還瞬間觸發（見 Ch2 §2.9.2） |
| 幫助間隙生物完成過渡 | +1d6 | 見證過渡後恢復 |
| 另一行者協助 | +1d6 | 花 1 小時共處，行者進行 難度等級（DC） 12 定錨檢定 |

> **磨損備註**：涉及定錨物的恢復方式，若定錨物處於磨損狀態（Ch2 §2.5.3），則該方式不可用。失去定錨物者（Ch2 §2.5.4）所有依賴定錨物的恢復和防護效果失效。

## §3.4 傷害——以狀態形式出現

> 核心設計原則：間隙行者不對間隙生物造成「傷害」——間隙中的衝突不是以 生命值（HP） 為基礎。角色承受的是**狀態**而非扣除生命值。

### 3.4.1 衝突來源與狀態

| 衝突來源 | 後果 | 解除條件 |
|---|---|---|
| 被侵蝕體接觸 | **侵蝕狀態**：每回合失去 1d4 點最大間隙耐力。可累積 | 返回表層後自動解除；在間隙中需 難度等級（DC） 15 定錨檢定 |
| 鏡像的主動對抗 | **共鳴狀態**：你受到的間隙耐力消耗，鏡像也承受等量。反之亦然 | 任一方的間隙耐力降至 0 時解除——但輸的那一方承受間隙病惡化 |
| 迷失（瀕臨階段觸發） | **迷失狀態**：所有定向檢定劣勢，無法標記路徑。GM 決定你的移動 | 成功通過一次 難度等級（DC） 14 定錨檢定（花費 1 行動點（AP）） |
| 目擊不可解釋現象 | **震懾狀態**：失去 1 行動點（AP）（下一回合） | 自動解除 |
| 被通道守衛拒絕 | **排斥狀態**：該路徑 24 小時內不可再嘗試 | 等待時間流逝 |
| 密封空間中的孤絕 | **孤絕狀態**：定錨檢定 難度等級（DC） +5。你感覺表層正在遠離 | 離開密封空間後解除 |

### 3.4.2 狀態鏈

某些狀態可疊加形成狀態鏈——三個同類型狀態導致永久後果：

| 狀態鏈 | 3 次累積後果 |
|---|---|
| 侵蝕 ×3 | 最大間隙耐力永久 –2 |
| 迷失 ×3 | GM 秘密擲一次間隙病惡化——不告訴你結果，直到你回到表層 |
| 共鳴 ×3 | 鏡像獲得你的一個記憶。你不再記得那是什麼——但牠記得 |

### 3.4.3 沒有死亡規則

間隙行者不會在間隙中「死亡」——至少不是以傳統意義。當一個角色在間隙中承受過量狀態：

- 間隙耐力（GE） 耗盡 → 間隙病急性發作 → 角色被強制彈出間隙（回到最近的安全門檻），承受 1d4 天力竭
- 若角色在間隙病末期連續三次惡化對抗失敗 → 角色轉化為**遺失物收集者**（NPC，由 GM 接管）

**間隙行者不會死。他們會迷路。** ——這是設計核心。

## §3.9 表層世界的行動規則

> 間隙行者不只活在間隙中。大多數委託始於表層、終於表層——你需要訪談委託人、調查現場、翻找檔案、說服目擊者。本章定義你在表層世界可以做什麼。

### 3.9.1 表層行動類型

表層世界不使用回合制。以下行動可自由組合，GM 根據敘事節奏判定何時需要擲骰。

| 行動 | 主要屬性 | 典型 難度等級（DC） | 說明 |
|---|---|---|---|
| **訪談 NPC** | 交涉 | 10–16 | 從委託人、目擊者、關係人口中獲取資訊。難度等級（DC） 取決於對方的配合度和對真相的抗拒 |
| **現場勘查** | 覺察 | 8–15 | 在物理現場尋找線索——不尋常的痕跡、門檻的微光、空間的異常 |
| **翻找文件** | 拾遺 | 10–14 | 從檔案、報紙、數位資料中找出與間隙相關的歷史紀錄 |
| **暗中觀察** | 覺察 | 12–16 | 不介入地觀察某人或某地——可能發現對方在特定時間接近特定門檻 |
| **說服/安撫** | 交涉 | 12–18 | 讓普通人接受「有東西不對勁」而不驚慌；或讓委託人接受你無法解釋的調查方式 |
| **偽裝身份** | 交涉 | 10–14 | 以記者、研究員、保險調查員等身份進入限制區域（使用假的或半真半假的身分） |
| **研究間隙歷史** | 拾遺 | 12–16 | 在圖書館、網路、地方耆老口中尋找特定地點的間隙相關傳說 |

### 3.9.2 線索分層系統

表層調查的成果以「線索層級」分類。GM 應為每個重要資訊預設層級——較淺的線索容易取得，較深的線索需要更多投入。

| 層級 | 難度等級（DC） 基準 | 內容範例 |
|---|---|---|
| **淺層線索** | 8 | 基本事實——「陳老先生在養老院住了三年」、「洋樓建於 1910 年」 |
| **中層線索** | 12 | 需要主動追問或仔細觀察——「護士注意到老先生總在傍晚走向房門」 |
| **深層線索** | 16 | 隱藏的真相——「老醫師記得院長有個從不離身的銀色小盒」 |

**累積成功**：對於需要深入調查的深層線索，GM 可要求累積 3 次成功（不一定要連續）才能完整揭露。

### 3.9.3 社交 難度等級（DC） 基準

| 對象態度 | 難度等級（DC） 基準 |
|---|---|
| 友善／主動求助（如委託人） | 8–10 |
| 中立／願意配合 | 12 |
| 猶豫／有所隱瞞 | 14–16 |
| 抗拒／心懷恐懼 | 18 |
| 敵意／刻意誤導 | 20+ |

**調整值**：
- 持有與對方相關的遺失物：+5
- 對方是敏感者（能感知間隙但無法穿梭）：態度提升一級
- 玩家的間隙病後期（半透明）：對正常人 –5，對將死之人 +5

### 3.9.4 協助調查

表層調查中，多名角色可以分工：

- **分工**：每人負責不同行動（一人訪談、一人勘查、一人翻文件）。各自擲骰，但資訊共享。
- **協助**：一人主導，另一人提供協助（主導者獲得優勢，規則見 Ch1 §4.5）。
- **時間代價**：深入調查花費數小時到數天。GM 追蹤時間流逝——某些線索可能因時間經過而消失（證人忘記、現場被破壞）。

## §3.10 隊伍協作規則

> 間隙行者很少獨自行動。當 2–5 名行者同時進入間隙，他們的定錨可以互相支撐——但也可能一起迷失。

### 3.10.1 共享門檻

若多名角色從同一個門檻進入間隙，只需其中一人成功進行穿梭檢定——成功者可「引導」其他人通過。被引導者不需擲骰，但仍消耗對應的間隙耐力（見 §3.2.2）。

**限制**：每次引導最多 2 人。引導者當回合不可進行其他行動。

### 3.10.2 耐力護盾

高定錨角色（定錨 ≥ 6）可消耗自己的間隙耐力為隊友吸收傷害：

- 花費 1 行動點（AP），消耗自己的 間隙耐力（GE）（1–3 點，由玩家自選），為視線範圍內的一名隊友抵消等量的 間隙耐力（GE） 消耗。
- 此能力每場景最多使用 2 次。

**原理**：你的定錨如此穩固，以至於在間隙中形成了一個短暫的「安全半徑」——隊友在你的定錨範圍內時，間隙的消耗性影響會被你的存在感削弱。

### 3.10.3 走散與找回

當一名角色在間隙中迷失（瀕臨狀態觸發迷失），其他角色可以：

- **追蹤**：覺察 難度等級（DC） 14，找到迷失者的去向。花費 1 行動點（AP）。
- **呼喚**：交涉 難度等級（DC） 12，用聲音引導迷失者。迷失者的定錨檢定 難度等級（DC） –3。
- **共享定錨**：若迷失者曾觸碰過你的定錨物（在本次進入間隙期間），你可以花費 1 行動點（AP） 啟動「共鳴」——迷失者自動感知到你的方位。

### 3.10.4 定錨物互借

在極端情況下，一名角色可將自己的定錨物暫時借給另一人：

- **條件**：兩名角色之間有深厚信任（GM 裁定——通常需要至少共同經歷過一個完整劇本）
- **效果**：借用者獲得 間隙耐力（GE） 上限 +5 和惡化對抗優勢（如常），但出借者失去這些效果
- **限制**：每次出借最長 1 個場景。結束後定錨物自動回到出借者手中（間隙會記得「誰的」）
- **風險**：若借用者在持有期間定錨物磨損——出借者也承受磨損後果

### 3.10.5 多人退出間隙

- **各自退出**：每人獨立進行穿梭檢定，各自承受失敗後果。
- **同步退出**：所有人手牽手，指定一人進行穿梭檢定。成功則全體安全退出；失敗則全體承受退出偏差（各自擲偏差表）。
- **強制彈出**：當任一角色 間隙耐力（GE） 歸零時，只彈出該角色——隊友可選擇是否一起退出。

### 3.10.6 間隙中的通訊

- **短距離**（視線範圍內）：正常對話。但間隙會輕微扭曲聲音——對方聽起來比實際上遠。
- **中距離**（同區域但看不見）：交涉 難度等級（DC） 10 才能讓對方聽清楚。
- **長距離**（不同間隙區域）：無法通訊。除非雙方都有已知門檻網絡且彼此為熟人（見 Ch2 §2.7），可進行 難度等級（DC） 16 交涉來「感應」對方的存在與大致方向。

## §3.11 幕間：休整期規則

> 兩次冒險之間的時間，不是空白——它是角色生活、恢復、和成長的土壤。

### 3.11.1 休整期活動

每次劇本結束後，角色進入休整期。休整期的長度由 GM 根據劇情決定（通常 1–4 週）。角色可從以下活動中選擇 **2 項**：

| 活動 | 屬性檢定 | 效果 |
|---|---|---|
| **表層靜養** | 無需檢定（自動） | 如處於間隙病初期，7 天後恢復健康。期間不可選擇其他活動 |
| **研究門檻** | 拾遺 難度等級（DC） 12 | 找到一個新的門檻位置。成功則加入已知門檻列表；大成功則發現一個記憶門檻 |
| **拜訪熟人** | 交涉 難度等級（DC） 10 | 加深與一個間隙熟人的關係——交涉 難度等級（DC） 永久 –1。大成功則獲得一個情報 |
| **尋找委託** | 交涉 難度等級（DC） 10 | 透過敏感者網絡接獲一個新的委託線索（GM 以此為下一劇本的引子） |
| **整理遺失物** | 拾遺 難度等級（DC） 12 | 從手中未歸還的遺失物中辨識出一個原主的身份或位置 |
| **強化定錨物** | 定錨 難度等級（DC） 12 | 在表層花時間與定錨物「共處」——下次進入間隙時，定錨物冥想恢復量 +2（一次性） |
| **打工謀生** | 無需檢定 | 維持表層生活。間隙行者過著雙重生活——你可能在咖啡店打工，同時等待下一道門檻發光 |

### 3.11.2 獲得新委託

新委託通常來自：
- **前一個委託的漣漪**：上次歸還遺失物的失主，推薦了另一個需要幫助的人
- **敏感者網絡**：無法穿梭但能感知間隙的人——古書店老闆、深夜咖啡館店主、殯葬業者——他們會留意「不對勁的事」
- **間隙中的訊息**：上次在間隙中遇到的生物給了你一個情報——「往東三個門檻，有人在等你」

GM 應讓委託來源自然融入劇情，而非憑空出現。

### 3.11.4 雙重生活：間隙行者的表層生存

大多數間隙行者過著雙重生活。白天——或者說「表層時間」——他們有工作：可能是圖書館員、便利商店店員、自由攝影師、或者任何可以「突然消失幾小時」而不被追問的職業。

**為什麼需要工作？**
間隙探索不支付房租。歸還遺失物的回報是歸還印記——形而上的財富，無法用來買食物。行者需要在表層維持最低限度的生存。

**GM 指引**：
- 不需要追蹤金錢數字。假設角色有足夠的收入維持基本生活。
- 當劇情需要時間壓力時，GM 可以使用「你請了太多假，主管開始注意你」作為敘事槓桿。
- 角色可以選擇投入更多時間打工 → 減少幕間可用的活動數量（從 2 項減為 1 項）。
- 角色可以選擇「全職間隙行者」生活——但這意味著依靠敏感者網絡的接濟、住在廉價旅館、或睡在 24 小時營業的場所。這不提供機制懲罰，但提供豐富的角色扮演素材。

**敏感者的角色**：
無法穿梭但能感知間隙的「敏感者」經常成為行者的支持網絡。他們可能提供：
- 臨時住處（「我店鋪樓上有個空房間」）
- 委託引介（「有個客人說她家裡最近不太對勁」）
- 物質支援（「這些罐頭快過期了，你拿去吧」）

這不是經濟系統——這是社群。間隙行者的生存不依靠金錢，而依靠「那些知道但不說破的人」。

## §3.12 遺失物的保留與使用

> 歸還遺失物給原主能獲得歸還印記——但不是每件遺失物都能找到原主。有些物品的原主已逝、有些記憶的歸屬已不可考、有些東西你暫時不想放手。本章定義當你「保留」遺失物時，它們能做什麼。

### 3.12.1 遺失物保留機制

當你選擇保留一件遺失物（而非歸還），適用以下規則：

**歸屬檢定**：每個月（遊戲內時間），保留中的遺失物需通過一次**歸屬檢定**（拾遺 難度等級（DC） 10 + 物品品質層級）。失敗則物品從你的口袋中消失——它找到了原主，或間隙將它收回。大失敗（自然 1）會附加一段 GM 敘述的微妙後果（原主在夢中看到你拿著他的東西）。

**持有上限**：一名角色最多同時保留 **3 件**遺失物。超過此數量的遺失物會在下次進入間隙時被間隙「吸回」。

### 3.12.2 各品質遺失物的保留效果

| 品質 | 拾遺 難度等級（DC） | 保留效果 | 歸屬檢定 難度等級（DC） |
|---|---|---|---|
| **普通遺失物** | 8 | **情感共鳴**：持有時，與該物品情感主題相關的交涉檢定 +1。例如一把舊鑰匙，對「與家有關的對話」提供加成。 | 10 |
| **善意遺留物** | 12 | **善意的回聲**：一次性使用。消耗此物品（它回到間隙），在間隙中立即恢復 1d6+2 點耐力。物品完成了它的使命。 | 10 |
| **記憶結晶** | 15 | **記憶閃回**：專注 1 分鐘啟動。GM 提供一段 30 秒的「記憶場景」——你短暫看到原主失去它那一刻。可使用 3 次，之後結晶碎裂。每次使用後 GM 可暗骰一個情報——可能是線索、名字、或地點。 | 12 |
| **間隙造物** | 18 | **不可預測的用途**：效果由 GM 根據物品設計。典型用途：打開特定密封空間的鑰匙、揭示一個未知門檻的位置、召喚特定間隙生物一次、或在特定區域提供穿梭優勢。**單次使用**——使用後物品消失。GM 不需要事先告知用途——玩家可能需要拾遺檢定來「推測」造物的功能。 | 15 |
| **被遺忘者** | 22 | **無法保留**。被遺忘者不是物品——是人。取回後必須在 24 小時內幫助其完成過渡（見 Ch2 §2.11.3），否則他/她會再次消失在間隙中。成功過渡後獲得歸還印記。 | — |

### 3.12.3 遺失物作為交涉籌碼

保留的遺失物可用於與間隙生物的交涉（見 Ch3 §3.3.2）。一件與生物「有關聯」的遺失物價值為「中～高」，一件完全無關的遺失物價值為「低～中」。遺失物用於交涉後，無論成功與否，物品被生物收下——從你的保留列表中移除。

## §3.13 探索工具與消耗品

> 間隙行者不帶武器——但他們會帶手電筒。不是為了照亮黑暗，是為了確認影子還是影子。

### 3.13.2 消耗品設計原則

間隙行者不使用魔法藥水或強化道具。消耗品的設計遵循以下原則：
- **來自表層**：所有工具都是日常物品，不是魔法物品
- **解鎖選項，不提供加值**：工具讓你「能做某件事」，而非「讓某件事的成功率 +X」
- **有代價**：手電筒需要電池、筆記本會寫滿、粉筆會用完——GM 應偶爾提醒資源消耗，但不需要嚴格追蹤（除非處於生存壓力場景）

## 4.0 設計哲學：世界的背面

在開始建構世界之前，先確立本章的核心設計原則。這些原則支撐著後續所有設定，GM 在做出任何裁定時都應該回到這裡。

### 四個核心原則

**原則一：間隙不是異世界**
間隙不是另一個維度、異次元或平行宇宙。它是同一個世界的「背面」——就像硬幣的反面、鏡子的另一側、你在房間裡感覺到的「好像少了什麼」。最好的間隙場景讓玩家感到：「這一直存在，只是我之前看不到。」

**原則二：間隙由缺席構成**
間隙中的一切都是由「不在表層的東西」構成的——被遺忘的記憶、遺失的物品、被壓抑的情感、未完成的建築、被取消的計畫。間隙的「物質」是負空間的實體化。

**原則三：間隙記得**
間隙不是中性的。它有某種「記憶」——不是意識，更像是沉積岩。在間隙中待得越久，越能感受到過去的層層堆積。這也是間隙病的根源：你的自我意識開始與沉積的他人記憶混淆。

**原則四：穿梭是有代價的**
每次穿越門檻都是一次微小的撕裂——對世界、對行者自身。沒有免費的通道。這個原則在機制層面支撐著間隙病、時間流速差異和門檻的危險性。

### 美學參考坐標

| 概念 | 來源 | 在間隙行者中的對應 |
|------|------|-------------------|
| **Liminal Space** | 網路美學 / 過渡空間 | 間隙層的基本視覺——空無一人的辦公大樓、凌晨四點的機場、從未完工的地鐵站 |
| **Kenopsia** | John Koenig《The Dictionary of Obscure Sorrows》 | 空無一人的空間帶來的奇異感受——間隙層的空氣質地 |

## 4.1 雙層世界觀

### 4.1.1 表層：我們熟知的世界

#### 時代設定

**預設時代：當代（靈活的「現在」）**

間隙行者的預設設定是**當代都市**，原因有三：

1. **Liminal Space 的當代性**：空無一人的辦公大樓、凌晨的便利商店、打烊後的購物中心、廢棄的工業區——這些最具 liminal 感的空間都是當代產物。
2. **對比的張力**：當表層充滿人群、科技、資訊洪流時，間隙的寂靜才最有力量。
3. **遺失物的共鳴**：當代人遺失的東西（手機、鑰匙、童年照片的數位副本）玩家能立刻理解其意義。

**時代調節建議**：

| 時代 | 適合的調性 | 注意事項 |
|------|-----------|---------|
| **1980s** | 類比時代的溫暖恐怖——沒有手機、監控攝影機稀少、失蹤更容易被忽略 | 遺失物偏向實體（錄音帶、底片、手寫信）；間隙行者社群更依賴口耳相傳 |
| **近未來** | 科技疏離感——AR 永遠開啟的世界中，間隙行者是唯一「看到空白」的人 | 遺失物可能包含數位存在（被刪除的 AI、遺棄的虛擬人格）；門檻可能出現在伺服器機房 |
| **1990s-2000s** | 過渡期的不安——網路剛興起，舊世界正在消逝 | 兩個時代的遺失物共存（底片與快閃記憶體）；間隙行者見證世界的加速 |
| **任何時代皆可** | 間隙存在於所有時代——但 GM 應調整遺失物的質感以匹配時代 | 中世紀的遺失物是羊皮紙與蠟封；江戶時代是木版畫與髮簪 |

> **GM 提示**：不要過度指定年份。說「像是現在，但不確定是哪一年」反而更好——間隙行者本身就活在時間的模糊地帶。

#### 表層世界對間隙的感知

普通人對間隙**幾乎一無所知**。但「幾乎」是重要的：

- **直覺**：正常人有時會「感覺哪裡不對」——走進一個房間忘記為何進來、找不到剛剛放下的鑰匙、在空無一人的停車場感到莫名的視線。這些都是對間隙的微弱感知。
- **敏感者**：約千分之一的人有更高的敏感度——他們更容易在 liminal 空間中感到不安、常做關於「另一側」的夢、偶爾能看到間隙生物的殘影。他們不是間隙行者，但可能成為行者的線人或委託人。
- **機構的無知**：政府、企業、學術界對間隙的認知為零。任何試圖「科學化」間隙的嘗試都以失敗告終——不是因為間隙抗拒研究，而是因為研究者會逐漸「忘記」他們在研究什麼。
- **民間傳說**：各地的鬼故事、都市傳說、禁忌之地……許多其實是人類文化對間隙的粗淺解釋。間隙行者知道：不是鬼，是間隙。
