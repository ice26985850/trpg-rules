# 第一章：間隙生物

## §3.3 間隙生物——不可殺死，只能幫助過渡

> 核心設計原則：間隙生物不是怪物。牠們是**被困在過渡狀態中的存在**。沒有 生命值（HP），沒有 護甲等級（AC），沒有武器骰——只有交涉 難度等級（DC） 與解放條件。

### 3.3.1 五種間隙生物

#### A. 門檻徘徊者

| 項目 | 內容 |
|---|---|
| **由來** | 在做出人生重大決定的瞬間猶豫了太久的人。現在他們永遠跨不過那道門檻 |
| **行為** | 反覆走向同一道門，觸碰門把，但永遠不打開 |
| **屬性** | 定錨 2（×2 = 4），交涉 難度等級（DC） **10** |
| **解放條件** | 幫他們「完成那一步」——你需要知道他們在猶豫什麼。從他們的記憶片段（拾遺 難度等級（DC） 12）或從表層調查（覺察 難度等級（DC） 10）中獲得線索 |
| **解放獎勵** | 獲得 1 個歸還印記；該門檻從此成為你的記憶門檻（進入 難度等級（DC） 自動 –3） |

#### B. 遺失物收集者

| 項目 | 內容 |
|---|---|
| **由來** | 曾經是間隙行者——但停留太久，忘記了自己屬於表層 |
| **行為** | 囤積遺失物，按他們自己也不記得的邏輯分類 |
| **屬性** | 拾遺 4（×2 = 8），交涉 難度等級（DC） **14** |
| **弱點** | 對「新的遺失物」有無法抗拒的渴望 |
| **交涉方式** | 用一件他們沒見過的遺失物交換——可以是你在間隙中剛找到的，也可以是你從表層帶進來的 |
| **可能給予** | 情報（密封空間裂縫位置）、一件他們收藏中的稀有遺失物、一條間隙捷徑 |

#### C. 鏡像

| 項目 | 內容 |
|---|---|
| **由來** | 不是被困住的——是間隙本身的產物。牠們是「被反射的空間中的倒影」 |
| **行為** | 模仿你的動作。你走牠走。你停牠停。但有的時候——牠不跟著你停 |
| **屬性** | 等同於遭遇者的完整屬性值 |
| **交涉 難度等級（DC）** | **16**（對抗檢定：你的交涉 vs 鏡像的交涉；鏡像使用與你相同的交涉值） |
| **核心規則** | **永遠不要背對鏡像。** 看著牠退出間隙——否則下次進來，牠可能在你上次站的位置等你 |
| **特殊互動** | 若角色與鏡像建立了特殊連結（見 Ch2 鏡像的犧牲規則），可觸發特殊互動。犧牲鏡像可逆轉一個間隙病階段，代價是永久失去鏡像 |

#### D. 通道守衛

| 項目 | 內容 |
|---|---|
| **由來** | 某個被間隙困住的大型生物——一匹永遠跨不過橋的馬、一隻在門口猶豫的狗 |
| **行為** | 擋住某條重要的間隙路徑。不是敵意——牠不知道該不該讓你過去 |
| **屬性** | 穿梭 3（×2 = 6），交涉 難度等級（DC） **12** |
| **解放條件** | 給牠一個「理由」跨過去——一根胡蘿蔔、一個名字、或幫牠找到牠在等的主人 |
| **若解放** | 獲得 1 個歸還印記；該路徑從此對你永久開放，且該區域間隙耐力消耗 –1 |

#### E. 密封看守者

| 項目 | 內容 |
|---|---|
| **由來** | 守在密封空間裂縫旁邊的存在。不是敵意——是牠不知道該不該讓你過去 |
| **行為** | 擋住裂縫，凝視你。不說話 |
| **屬性** | 定錨 5（×2 = 10），交涉 難度等級（DC） **18** |
| **通過條件** | 證明你「需要過去」——給牠看一件遺失物，那件物品必須跟密封空間有關（從表層調查或記憶結晶中獲得線索） |
| **強行通過** | 難度等級（DC） 22 穿梭檢定。失敗：被拒絕——該裂縫對你永久封閉，且間隙病立即惡化檢定 |

### 3.3.2 交涉交換表

與間隙生物不使用語言——使用 **「交換」**。每一次交涉都是一筆交易。

#### 你可以給出：

| 給出 | 價值層級 | 說明 |
|---|---|---|
| 一個記憶（從記憶結晶中獲得） | 高 | 間隙生物以記憶為食。這是你最珍貴的籌碼 |
| 一件遺失物 | 中～高 | 取決於物品的情感重量。遺失物收集者特別重視「沒見過的」 |
| 一段時間 | 中 | 在間隙中多停留 X 回合陪牠。你消耗的是你的間隙耐力 |
| 一個名字 | 最高 | 呼喚牠的本名——需要從別處獲得。使用後牠自由了 |
| 一個承諾 | 中 | 「我會回來」——若你食言，該生物的解放 難度等級（DC） 對你從此 +5 |
| 一段你的故事 | 低～中 | 講一個關於你自己的真實故事。間隙中的存在對「表層的故事」有天然的好奇 |

#### 你可以獲得：

| 獲得 | 價值層級 | 說明 |
|---|---|---|
| 通過牠守護的路徑 | 中 | 一條間隙捷徑——可縮短兩點之間的距離 |
| 一個情報 | 中～高 | 密封空間裂縫位置、另一個遺失物的下落、某人的本名 |
| 牠的協助 | 中 | 幫你搜索遺失物（該區域拾遺 難度等級（DC） –5）或引導你到特定位置 |
| 一次服務 | 高 | 僅以「名字」交換可得。之後牠自由了——你會看到牠跨過那道門檻 |
| 歸還印記 | — | 不是交換獲得——是解放牠時自動獲得 |

#### 交涉難度基準

| 交涉 難度等級（DC） | 說明 |
|---|---|
| 8 | 交換價值明顯對牠有利——牠幾乎一定會接受 |
| 12 | 公平交換——需要成功檢定 |
| 16 | 交換對牠不利——牠會猶豫 |
| 20 | 你要求牠做違背本質的事——可能拒絕，可能要求額外代價 |

**交涉調整值**：
- 歸還印記每層級（初印/熟印/深印/銘印/傳說之印）：交涉檢定 +1（見 Ch2 §2.9.3）
- 持有與該生物相關的遺失物：+5
- 曾拒絕過對該生物的承諾：–5
- 知曉該生物的本名：+5 且可進行「名字交換」
