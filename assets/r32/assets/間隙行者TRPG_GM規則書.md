# 第一章：間隙生物

> ▶ 五種間隙生物（由來、屬性、解放條件、交涉方式、可能給予）的完整圖鑑請見 **assets/ 間隙生物圖鑑.md**，本處僅保留與 GM 主持直接相關的規則與判定表。

## §3.3 間隙生物——不可殺死，只能幫助過渡

> 核心設計原則：間隙生物不是怪物。牠們是**被困在過渡狀態中的存在**。沒有 生命值（HP），沒有 護甲等級（AC），沒有武器骰——只有交涉 難度等級（DC） 與解放條件。

### 3.3.1 五種間隙生物

#### A. 門檻徘徊者

| 項目 | 內容 |
|---|---|
| **由來** | 在做出人生重大決定的瞬間猶豫了太久的人。現在他們永遠跨不過那道門檻 |
| **行為** | 反覆走向同一道門，觸碰門把，但永遠不打開 |
| **屬性** | 定錨 2（×2 = 4），交涉 難度等級（DC） **10** |
| **解放條件** | 幫他們「完成那一步」——你需要知道他們在猶豫什麼。從他們的記憶片段（拾遺 難度等級（DC） 12）或從表層調查（覺察 難度等級（DC） 10）中獲得線索 |
| **解放獎勵** | 獲得 1 個歸還印記；該門檻從此成為你的記憶門檻（進入 難度等級（DC） 自動 –3） |

#### B. 遺失物收集者

| 項目 | 內容 |
|---|---|
| **由來** | 曾經是間隙行者——但停留太久，忘記了自己屬於表層 |
| **行為** | 囤積遺失物，按他們自己也不記得的邏輯分類 |
| **屬性** | 拾遺 4（×2 = 8），交涉 難度等級（DC） **14** |
| **弱點** | 對「新的遺失物」有無法抗拒的渴望 |
| **交涉方式** | 用一件他們沒見過的遺失物交換——可以是你在間隙中剛找到的，也可以是你從表層帶進來的 |
| **可能給予** | 情報（密封空間裂縫位置）、一件他們收藏中的稀有遺失物、一條間隙捷徑 |

#### C. 鏡像

| 項目 | 內容 |
|---|---|
| **由來** | 不是被困住的——是間隙本身的產物。牠們是「被反射的空間中的倒影」 |
| **行為** | 模仿你的動作。你走牠走。你停牠停。但有的時候——牠不跟著你停 |
| **屬性** | 等同於遭遇者的完整屬性值 |
| **交涉 難度等級（DC）** | **16**（對抗檢定：你的交涉 vs 鏡像的交涉；鏡像使用與你相同的交涉值） |
| **核心規則** | **永遠不要背對鏡像。** 看著牠退出間隙——否則下次進來，牠可能在你上次站的位置等你 |
| **特殊互動** | 若角色與鏡像建立了特殊連結（見 Ch2 鏡像的犧牲規則），可觸發特殊互動。犧牲鏡像可逆轉一個間隙病階段，代價是永久失去鏡像 |

#### D. 通道守衛

| 項目 | 內容 |
|---|---|
| **由來** | 某個被間隙困住的大型生物——一匹永遠跨不過橋的馬、一隻在門口猶豫的狗 |
| **行為** | 擋住某條重要的間隙路徑。不是敵意——牠不知道該不該讓你過去 |
| **屬性** | 穿梭 3（×2 = 6），交涉 難度等級（DC） **12** |
| **解放條件** | 給牠一個「理由」跨過去——一根胡蘿蔔、一個名字、或幫牠找到牠在等的主人 |
| **若解放** | 獲得 1 個歸還印記；該路徑從此對你永久開放，且該區域間隙耐力消耗 –1 |

#### E. 密封看守者

| 項目 | 內容 |
|---|---|
| **由來** | 守在密封空間裂縫旁邊的存在。不是敵意——是牠不知道該不該讓你過去 |
| **行為** | 擋住裂縫，凝視你。不說話 |
| **屬性** | 定錨 5（×2 = 10），交涉 難度等級（DC） **18** |
| **通過條件** | 證明你「需要過去」——給牠看一件遺失物，那件物品必須跟密封空間有關（從表層調查或記憶結晶中獲得線索） |
| **強行通過** | 難度等級（DC） 22 穿梭檢定。失敗：被拒絕——該裂縫對你永久封閉，且間隙病立即惡化檢定 |

### 3.3.2 交涉交換表

與間隙生物不使用語言——使用 **「交換」**。每一次交涉都是一筆交易。

#### 你可以給出：

| 給出 | 價值層級 | 說明 |
|---|---|---|
| 一個記憶（從記憶結晶中獲得） | 高 | 間隙生物以記憶為食。這是你最珍貴的籌碼 |
| 一件遺失物 | 中～高 | 取決於物品的情感重量。遺失物收集者特別重視「沒見過的」 |
| 一段時間 | 中 | 在間隙中多停留 X 回合陪牠。你消耗的是你的間隙耐力 |
| 一個名字 | 最高 | 呼喚牠的本名——需要從別處獲得。使用後牠自由了 |
| 一個承諾 | 中 | 「我會回來」——若你食言，該生物的解放 難度等級（DC） 對你從此 +5 |
| 一段你的故事 | 低～中 | 講一個關於你自己的真實故事。間隙中的存在對「表層的故事」有天然的好奇 |

#### 你可以獲得：

| 獲得 | 價值層級 | 說明 |
|---|---|---|
| 通過牠守護的路徑 | 中 | 一條間隙捷徑——可縮短兩點之間的距離 |
| 一個情報 | 中～高 | 密封空間裂縫位置、另一個遺失物的下落、某人的本名 |
| 牠的協助 | 中 | 幫你搜索遺失物（該區域拾遺 難度等級（DC） –5）或引導你到特定位置 |
| 一次服務 | 高 | 僅以「名字」交換可得。之後牠自由了——你會看到牠跨過那道門檻 |
| 歸還印記 | — | 不是交換獲得——是解放牠時自動獲得 |

#### 交涉難度基準

| 交涉 難度等級（DC） | 說明 |
|---|---|
| 8 | 交換價值明顯對牠有利——牠幾乎一定會接受 |
| 12 | 公平交換——需要成功檢定 |
| 16 | 交換對牠不利——牠會猶豫 |
| 20 | 你要求牠做違背本質的事——可能拒絕，可能要求額外代價 |

**交涉調整值**：
- 歸還印記每層級（初印/熟印/深印/銘印/傳說之印）：交涉檢定 +1（見 Ch2 §2.9.3）
- 持有與該生物相關的遺失物：+5
- 曾拒絕過對該生物的承諾：–5
- 知曉該生物的本名：+5 且可進行「名字交換」

## §3.4 傷害——以狀態形式出現

> 核心設計原則：間隙行者不對間隙生物造成「傷害」——間隙中的衝突不是以 生命值（HP） 為基礎。角色承受的是**狀態**而非扣除生命值。

### 3.4.1 衝突來源與狀態

| 衝突來源 | 後果 | 解除條件 |
|---|---|---|
| 被侵蝕體接觸 | **侵蝕狀態**：每回合失去 1d4 點最大間隙耐力。可累積 | 返回表層後自動解除；在間隙中需 難度等級（DC） 15 定錨檢定 |
| 鏡像的主動對抗 | **共鳴狀態**：你受到的間隙耐力消耗，鏡像也承受等量。反之亦然 | 任一方的間隙耐力降至 0 時解除——但輸的那一方承受間隙病惡化 |
| 迷失（瀕臨階段觸發） | **迷失狀態**：所有定向檢定劣勢，無法標記路徑。GM 決定你的移動 | 成功通過一次 難度等級（DC） 14 定錨檢定（花費 1 行動點（AP）） |
| 目擊不可解釋現象 | **震懾狀態**：失去 1 行動點（AP）（下一回合） | 自動解除 |
| 被通道守衛拒絕 | **排斥狀態**：該路徑 24 小時內不可再嘗試 | 等待時間流逝 |
| 密封空間中的孤絕 | **孤絕狀態**：定錨檢定 難度等級（DC） +5。你感覺表層正在遠離 | 離開密封空間後解除 |

### 3.4.2 狀態鏈

某些狀態可疊加形成狀態鏈——三個同類型狀態導致永久後果：

| 狀態鏈 | 3 次累積後果 |
|---|---|
| 侵蝕 ×3 | 最大間隙耐力永久 –2 |
| 迷失 ×3 | GM 秘密擲一次間隙病惡化——不告訴你結果，直到你回到表層 |
| 共鳴 ×3 | 鏡像獲得你的一個記憶。你不再記得那是什麼——但牠記得 |

### 3.4.3 沒有死亡規則

間隙行者不會在間隙中「死亡」——至少不是以傳統意義。當一個角色在間隙中承受過量狀態：

- 間隙耐力（GE） 耗盡 → 間隙病急性發作 → 角色被強制彈出間隙（回到最近的安全門檻），承受 1d4 天力竭
- 若角色在間隙病末期連續三次惡化對抗失敗 → 角色轉化為**遺失物收集者**（NPC，由 GM 接管）

**間隙行者不會死。他們會迷路。** ——這是設計核心。

# 第二章：密封空間

## §3.5 密封空間風險

### 3.5.1 密封空間特性

密封空間是「沒有間隙」的空間——正常空間之間有裂縫、門檻、縫隙，間隙行者可以利用。密封空間完全封死：

- 不能從間隙進入（唯一的裂縫 難度等級（DC） 22）
- 不能從間隙觀察內部
- 內部的東西永遠不會掉進間隙
- 進入後，裂縫可能在你身後消失

### 3.5.2 密封原因

| 原因 | 特徵 | 線索 |
|---|---|---|
| **被刻意封印** | 裂縫有規則的邊緣——是人為的 | 可能有封印者的標記 |
| **空間尚未完成** | 裂縫周圍的間隙是「空的」——沒有扭曲，只是什麼都沒有 | 新建築、新房間 |
| **間隙災難後癒合** | 裂縫周圍有疤痕組織——空間被過度撕裂後自行癒合 | 該區域的間隙生物特別多 |
| **裡面關著東西** | 裂縫周圍有防禦性封印——不是防止入侵，是防止逃脫 | 裂縫附近有感應型間隙生物巡邏 |

### 3.5.3 開封方法與風險

| 方法 | 難度 | 風險 |
|---|---|---|
| **找到密封裂縫** | 覺察 難度等級（DC） 22 | 裂縫可能在你進入後消失——你被困在密封空間中 |
| **在表層製造創傷事件** | 中等（敘事難度） | 事件本身有後果——你願意為了打開密封空間而縱火嗎？ |
| **找到密封者留下的鑰匙** | 特殊劇情 | 鑰匙可能是一件遺失物、一個記憶結晶、或密封者本人 |
| **用間隙造物打開** | 隨機（拾遺 難度等級（DC） 18 獲得間隙造物） | 某些間隙造物的唯一用途是打開特定密封空間——但你無法事先知道 |
| **說服密封看守者** | 交涉 難度等級（DC） 18 | 需出示與密封空間相關的遺失物（見 §3.3.1-E） |

### 3.5.4 密封空間內的規則

- 基礎間隙耐力消耗翻倍（–2/回合）
- 不能退出到間隙——只能從表層離開（如果建築物存在表層出口）
- 若建築物沒有出口：你必須從內部製造一個新的門檻（定錨 難度等級（DC） 20，花費 3 行動點（AP））
- 裡面的時間流速可能是表層的十倍——或十分之一（GM 暗擲 d6）

## §3.6 間隙病系統（對抗制）

### 3.6.1 間隙病階段

| 階段 | 觸發條件 | 症狀 |
|---|---|---|
| **初期** | 間隙耐力（GE） 耗盡後第一次惡化對抗失敗 | 在表層時偶爾「看到」間隙——門檻在發光、走廊比實際上長。覺察檢定被動觸發（你無法關掉） |
| **中期** | 第二次惡化對抗失敗 | 表層和間隙開始混淆——你不知道自己現在在哪一層。GM 不再告訴你 |
| **後期** | 第三次惡化對抗失敗 | 你開始半透明化——表層的人有時會「透過你看到後面的牆」。社交劣勢。將死之人可以看到你 |
| **末期** | 第四次惡化對抗失敗 | 你變成間隙生物。角色由 GM 接管——成為新的遺失物收集者 NPC |

> **末期轉化前的最後機會**：見 §3.6.4 末期最後檢定（難度等級（DC） 22）。

### 3.6.2 惡化對抗（數值重縮放後）

```
間隙病惡化對抗：d20 + 定錨  vs  定錨 × 2 + 穿梭
```

> **公式說明**：對抗目標值 = 定錨 × 2 + 穿梭。這代表間隙病是一個自我對抗——你的定錨（與現實的連結）對抗你的定錨與穿梭的組合（你在間隙中的「深度」）。穿梭越高，你在間隙中越自如——但越自如也意味著陷得越深。

| 角色範例 | d20 + 定錨 | vs | 定錨×2 + 穿梭 | 成功率 |
|---|---|---|---|---|
| 定錨 8, 穿梭 3 | d20 + 8 | vs | 16 + 3 = **19** | 需擲 11+（50%） |
| 定錨 5, 穿梭 5 | d20 + 5 | vs | 10 + 5 = **15** | 需擲 10+（55%） |
| 定錨 10, 穿梭 6 | d20 + 10 | vs | 20 + 6 = **26** | 需擲 16+（25%） |
| 定錨 3, 穿梭 8 | d20 + 3 | vs | 6 + 8 = **14** | 需擲 11+（50%） |

> **設計意圖**：高定錨高穿梭的角色——最強大的間隙行者——反而面對最高的對抗難度。這反映遊戲的核心張力：你在間隙中越強大，你就越接近成為它的一部分。

### 3.6.3 惡化對抗優勢來源

| 優勢來源 | 觸發條件 | 類型 |
|---|---|---|
| 持有定錨物 | 被動——持有即生效 | Ch3 / Ch2 §2.5 |
| 觸碰定錨物 | 主動——花費 1 行動點（AP），該回合所有定錨檢定（含惡化對抗）優勢 | Ch2 §2.5.2 |
| 3+ 歸還印記（熟印） | 被動——僅限**初期**間隙病惡化對抗 | Ch2 §2.9.3 |
| 5+ 歸還印記（深印） | 被動——**中期及以下**間隙病惡化對抗 | Ch2 §2.9.3 |

> 優勢不疊加（d20 系統標準規則：多次優勢仍只擲兩次取高）。

### 3.6.4 末期最後檢定

當角色進入末期（第四次惡化對抗失敗），在轉化為間隙生物之前，有一次最後機會：

```
末期最後檢定：難度等級（DC） 22 定錨檢定（持有定錨物時優勢）
成功 → 末期逆轉至後期。角色被強制彈出間隙，承受 1d6 天力竭。
失敗 → 轉化不可逆。角色成為遺失物收集者。
```

- **僅一次機會**。不可重試，不可由他人協助
- 這不是常規治療——是最後一道門檻

### 3.6.5 治療方式（統一表）

與 Ch2 §2.11.1 完全對齊：

| # | 治療方式 | 效果 | 限制 | 來源 |
|---|---|---|---|---|
| 1 | **表層靜養** | 連續 7 天不進間隙，每日 難度等級（DC） 10 定錨，7 次成功 → 初期消除 | 期間進入間隙則計數重置 | 合併 |
| 2a | **首次找到定錨物** | 中期 → 初期（一次性敘事里程碑） | 僅觸發一次 | Ch2 |
| 2b | **持續持有定錨物** | 間隙耐力（GE） 上限 +5、惡化對抗優勢、耐力消耗感知減緩 | 定錨物磨損/失去則中斷 | Ch3 |
| 3 | **幫助間隙生物完成過渡** | 後期以下逆轉一個階段 | 需成功解放生物（見 §3.3.1） | 一致 |
| 4 | **歸還印記防護** | 3 印記 → 初期惡化優勢；5 印記 → 中期以下惡化優勢 | 被動 | 合併 |
| 5a | **他人定錨輔助** | 任何行者協助 → 下次惡化對抗優勢（短期） | 難度等級（DC） 14 定錨 | Ch3 |
| 5b | **大師治療** | 7+ 歸還印記行者協助 → 中期 → 初期 | 8 小時儀式 | Ch2 |
| 6 | **末期最後檢定** | 難度等級（DC） 22，成功 → 末期 → 後期；失敗 → 轉化不可逆 | 僅一次 | Ch3 |
| 7 | **鏡像的犧牲** | 逆轉一個階段，永久失去鏡像 | 需與鏡像建立特殊連結 | Ch2 |

## §3.7 間隙物理異常

### 3.7.1 距離扭曲——關係距離

間隙中兩點之間的距離不取決於物理空間，取決於這兩點在表層的**關係**：

| 關係類型 | 間隙距離 | 範例 |
|---|---|---|
| 血脈相連 | 極近（1 回合可達） | 祖傳老宅中祖母的房間 ⇄ 孫女的房間 |
| 情感共鳴 | 近（2 回合可達） | 在這間教室告白過 ⇄ 在那間教室分手 |
| 功能相關 | 中等（3 回合可達） | 廚房 ⇄ 餐廳 |
| 歷史交疊 | 遠（4 回合可達） | 同一條街上 50 年前是同一家工廠的兩棟建築 |
| 毫無關聯 | 極遠（5+ 回合或不可達） | 隨機的兩個現代辦公大樓 |

> GM 在建構場景時需為每個重要地點標註 1–3 個關係線索，供玩家推論間隙中的捷徑。

### 3.7.2 方向傾斜

間隙中的「上」不一定是表層的「上」：

- 穿梭檢定失敗可能導致你退出間隙時位置或方向異常。擲 d6 決定偏差：

| d6 | 偏差類型 | 效果 |
|---|---|---|

# 第四章：世界與敘事

### 4.1.2 間隙層：世界的背面

#### 間隙是什麼？

間隙不是被「創造」出來的——它是**累積**出來的。

每當一個東西被遺失、一個瞬間被遺忘、一個決定被猶豫不決地懸置——就會在現實的織物上產生一個微小的褶皺。數十億個褶皺，數千年來，累積成了間隙。

把表層世界想像成一張巨大的布料。間隙不是布料下方的另一個空間——它是布料本身的**厚度**。正常情況下，這厚度可以忽略不計。但當褶皺堆積、織線鬆脫、經緯交錯……厚度成為可進入的空間。

#### 間隙的「地理」

間隙沒有自己的地理——它是表層地理的**扭曲鏡像**。

- **對應關係**：間隙中的每一處都「對應」表層的某處。但對應不是一對一的——一個表層的十字路口可能在間隙中分裂成三個不同的交匯點，一個表層的房間可能在間隙中無限延伸。
- **密度差異**：間隙在不同區域的「深度」不同。被人類頻繁使用、充滿明確意義的空間（如繁忙的辦公室）間隙較「薄」。被遺忘、過渡性的空間（廢棄建築、地下通道、關門後的商店街）間隙較「厚」。
- **間隙深淵**：在某些極其古老的遺忘疊加處（古老城市的底層、被淹沒的聚落、從未被記載的戰場），間隙變得極深。行者稱之為「深間隙」——連老手都不敢輕易進入。

#### 間隙的起源（GM 背景知識）

以下不是玩家角色能確知的事實。這是 GM 建構世界時的内在一致性工具。選擇最適合你團務調性的一種——或混合使用。

**理論一：沉積說（預設）**
間隙是意識的副產品。每個有自我意識的存在都會在現實中留下「意識的指紋」。當注意力從某處移開，指紋留下但主人離去——這就是間隙的原材料。此說法解釋了為何間隙在人類密集區最深（意識活動最多），以及為何間隙生物似乎有殘留的「意圖」。

**理論二：創世殘餘說**
宇宙誕生時，不是所有空間都被「完成」。間隙是創世過程中的填充料——就像雕塑家留在石像周圍的碎石。此說法解釋了密封空間的存在（從未被打開的創世殘餘）以及間隙的某種「非人類」特質。

**理論三：遺忘的排水系統說**
此說法認為間隙是一種宇宙機制——回收被現實捨棄的「可能性」。每條未走的路、每句未說的話、每個未被選擇的選項都流入間隙。間隙不是缺陷，而是功能。這個理論暗示間隙有某種「目的性」——密封空間的存在是為了「隔離危險的可能性」。

**理論四：行者創造說（邊緣信仰）**
少數間隙行者相信：間隙是第一個間隙行者「發現」時才開始存在的。在此之前，遺忘就是遺忘，遺失就是遺失。是觀測賦予了間隙形態。這是最令行者不安的理論——因為它意味著他們的每一次穿梭都在讓間隙變得更「真實」。

> **GM 提示**：選擇一種理論作為你團務的「真相」——但永遠不要直接告訴玩家。讓不同 NPC 提出不同理論。最好的世界建構是讓玩家自己拼湊。

### 4.1.3 間隙的「規則」

間隙沒有自然法則——但它有**模式**。這些模式不是定律，而更像是「間隙的習慣」。GM 可以打破它們，但打破時應該是有意義的。

#### 門檻的規則

**為什麼門檻有不同類型？**

門檻是表層與間隙之間的「薄膜」。薄膜的質地取決於它形成的「原因」：

| 門檻類型 | 形成原因 | 薄膜質地 | 情感共振 |
|---------|---------|---------|---------|
| **天然門檻** | 空間本身在特定條件下自然變薄 | 穩定、可預測、緩慢開合 | 寂靜中的期待 |
| **人造門檻** | 人類活動反覆在同一處「磨損」現實 | 粗糙、有時不穩定、因人而異 | 工業式的冷漠 |
| **創傷門檻** | 強烈情感事件撕裂現實 | 鋒利、危險、帶有「回音」 | 痛苦、憤怒、絕望的殘留 |
| **記憶門檻** | 集體記憶長期疊加在同一處 | 半透明、溫暖或陰冷、有畫面感 | 鄉愁、遺憾、未完成 |
| **密封裂縫** | 曾被刻意或自然地封閉的門檻 | 不透、冰冷、被「疤痕組織」覆蓋 | 被壓抑的恐懼、不該被打開的東西 |

**門檻的共通法則**：

1. **門檻需要「之間」**：門檻從不出現在空間的正中央。它們在邊界上——門與牆之間、樓梯的轉角、電梯門的縫隙、兩個路燈之間陰影的交界處。
2. **門檻會被注意稀釋**：當太多人注意到同一個門檻，它會「變薄」甚至暫時關閉。這是間隙行者保持隱密的原因之一——公開展示門檻會破壞它。
3. **門檻記得誰用過它**：重複使用同一門檻的行者會與之建立某種「關係」。老門檻會變得更容易通過，但也會對行者產生某種引力——你總是想回到那裡。

#### 遺失物的規則

**為什麼東西會掉進間隙？**

不是所有遺失物都進入間隙。一件物品要「掉落」，需要滿足以下條件之一：

1. **情感充能**：物品被其主人賦予了足夠的情感意義（不是貴重，是意義）。一把普通的鑰匙因為伴隨某人二十年而「沉重」到足以穿透現實。
2. **在「之間」遺失**：物品在過渡狀態中遺失——旅途中的口袋、搬家時的紙箱、等待被歸類的抽屜。在兩個確定狀態之間的東西最容易滑入間隙。
3. **被刻意遺棄卻未被遺忘**：被丟掉的東西如果仍被記住，它會同時存在於兩個狀態中——物理上被丟棄，心靈上未被放下。這種矛盾產生足夠的「褶皺」。
4. **集體記憶的引力**：當足夠多人記得某種東西的「存在感」（不一定是具體物品），間隙中可能會生成其對應物。這解釋了為何間隙中有看起來很古老卻不屬於任何時代的東西。

**善意遺留物的特殊規則**：

善意遺留物不同於普通遺失物——它們不是「掉落」的，而是「被放置」的。當一個人刻意將物品留在某處，「為了某個可能需要它的人」，這個意念會在物品上形成一層……保護。善意遺留物在間隙中不會劣化，有時甚至會微妙地「移動」到需要它的人附近。這是間隙行者最無法解釋卻最珍惜的現象。

### 4.1.4 間隙行者社群

#### 有多少人？

沒有人確切知道。多數行者的估計是：**全世界約 500-1000 名能主動穿梭的間隙行者**，加上大約三倍數量「能感知間隙但無法（或不願）穿梭」的敏感者。

這個數字維持著某種穩定——新行者覺醒的速度大致等於舊行者消失的速度。

#### 如何成為間隙行者？

沒有人選擇成為間隙行者。以下是最常見的「覺醒」路徑：

1. **瀕死穿越（約40%）**：在生死邊緣，靈魂短暫滑入間隙又回來。回來後，你再也無法「看不到」。
2. **繼承覺醒（約25%）**：父母之一是行者。不是遺傳——是你在成長過程中吸收了太多間隙的「存在感」，直到有一天你也能看到。
3. **失落觸發（約20%）**：經歷重大的失落（摯愛離世、失去一切財產、被徹底遺忘），現實的裂縫在你面前打開。
4. **地點觸發（約10%）**：在特定的 liminal 空間中度過了太多時間（夜班警衛、地下停車場管理員、長途卡車司機），直到空間開始向你展示它的另一面。
5. **未知（約5%）**：有些行者就是不知道為什麼——某天醒來就看到了。這是最令人不安的類型。

#### 他們如何認識彼此？

間隙行者沒有名片、沒有 LinkedIn、沒有年度大會。他們的相認方式極為獨特：

- **間隙中的痕跡**：有經驗的行者會在間隙中留下微妙的記號——不是塗鴉（太明顯），而是「整理」某個角落、將遺失物排列成特定圖案、在門檻附近留下善意遺留物。其他行者會認出這些不是隨機的。
- **表層中的眼神**：兩個行者在表層相遇時，可能會注意到對方看門縫的方式——那是一種特殊的「確認」，不是出於恐懼，而是出於辨識。
- **敏感者的引介**：無法穿梭但能感知的「敏感者」有時成為行者的中間人。他們經營古書店、當鋪、深夜咖啡館——這些地方成為非正式的聯絡點。
- **老帶新**：多數行者是被另一個行者「找到」的。資深行者會注意到剛覺醒者周遭的異常——身邊頻繁出現的遺失物、對 liminal 空間的異常反應。

#### 有組織嗎？

**沒有正式組織。**原因很簡單：

1. **太大太明顯的組織會引來注意**——而間隙不需要注意就會變薄
2. **行者對權威有天生的不信任**——他們見過太多「規則」在間隙中失去意義
3. **聚集會加速間隙病**——太多行者在同一地點會讓間隙「注意到」

但存在**非正式網路**：

| 網路類型 | 規模 | 例子 |
|---------|------|------|
| **城市節點** | 3-8人 | 「澀谷組」——東京五名行者在深夜拉麵店交換情報 |
| **師徒鏈** | 2-5人，跨代 | 老行者→覺醒者→覺醒者的學徒，三代人可能從未同時見面 |
| **委託網路** | 流動性 | 透過敏感者仲介的付費委託系統。匿名、單次、不可追蹤 |
| **守護者** | 1-3人 | 自願看守特定密封空間的行者。孤獨的工作，有些人已看守了數十年 |
| **分裂派系** | 已消亡 | 歷史上曾有人試圖組織化。都失敗了。有些「失敗」的後果仍封存在密封空間中 |

#### 行者的不成文規則

這些不是法律——但違反它們的行者通常不會有好下場：

1. **不要帶普通人進入間隙**。不是保護他們——是保護現實。
2. **不要在間隙中留下你的名字**。名字是自我意識的錨點。把它留在間隙中，間隙就會開始認得你。
3. **不要打開你不打算關上的門**。密封空間被密封是有原因的。
4. **如果你看到另一個行者在間隙中迷路——幫他們**。今天是他，明天可能是你。
5. **不要在同一個門檻連續穿梭超過三次**。門檻會開始「期待」你回來。

#### 行者的日常

成為間隙行者不是全職工作。多數行者有表層的「掩護生活」：

- 夜班工作（保全、便利商店、物流中心）——給你理由在深夜活動
- 自由職業——靈活的時間表讓你可以追逐門檻
- 古董商 / 二手書店店主——接觸遺失物的完美掩護
- 都市探險家 / 攝影師——去不該去的地方的合理理由
- 無業 / 流浪者——最誠實的選擇，雖然最難維持

少數行者靠委託維生——幫普通人找回遺失物（以「私家偵探」的名義）、處理間隙生物溢出到表層的事件、看守或修補脆弱的密封空間。

## 4.2 間隙層深度設定

### 4.2.1 視覺與感官描述

本節是 GM 的**描寫工具箱**。每個類別提供多個選項，用於不同的場景調性。

#### 光線

間隙中的光線沒有明確來源。它不是陽光，不是燈光，更像是——

- 所有東西都在微微發光，但你看不到光源
- 像陰天的午後，永遠的灰白色調
- 影子比應有的更長，且方向不一致
- 某些區域「太暗」——不是缺乏光線，而是光線不願進入
- 遠處總有微弱的、不確定顏色的光暈——但你永遠走不到
- 物品的影子有時比物品本身更「實在」

> **描寫範例**：「你站在一個沒有燈的走廊裡。但你能看見——像有人把『看得見』這件事調到最低亮度。你的影子投在三個不同的牆上，分別指向不同的方向。」

#### 聲音

- 絕對寂靜——但你會聽到自己的心跳、血液流動、骨頭的微響
- 遠處傳來無法定位的聲音：金屬撞擊、門關上、低語、腳步
- 聲音的延遲很奇怪——你的腳步聲晚半秒才響起
- 有些地方有持續的低頻嗡鳴，感覺像在胸腔中共振
- 間隙中的「風」沒有來源，但你能聽到它穿過不存在的窗戶
- 遺失物有時會發出微弱的聲音——手錶滴答、音樂盒旋律、一個聲音在叫名字

> **描寫範例**：「這裡很安靜。不是『沒有人說話』的安靜——是『聲音本身忘記了這裡』的安靜。你的腳步踩在地板上，但聲音像是從隔壁房間傳來的。」

#### 氣味

- 灰塵的氣味——但灰塵本身並不存在
- 臭氧、雨前的空氣、潮濕的水泥
- 老舊紙張、乾燥的木頭、冷卻的蠟
- 特定區域有與場景不匹配的氣味——花店在間隙中可能聞起來像海風
- 無法辨識但引起強烈 nostalgia 的氣味
- 密封空間附近有「無味」——像是嗅覺的負空間

> **描寫範例**：「這條走廊聞起來像小學放學後的教室。粉筆灰、木頭課桌、還有某種你叫不出名字但立刻想起八歲那年的味道。」

#### 觸感

- 空氣比表層稠密，像在微溫的糖漿中移動
- 某些區域的空氣是「粒狀的」——皮膚上能感覺到微小的存在
- 物品的表面溫度不對——金屬可能是溫的，布料可能是冰的
- 間隙中的「風」拂過皮膚時，感覺像被遺忘的觸碰
- 重力不是消失——是變得「漫不經心」。有時你覺得自己被輕輕推向某個方向

> **描寫範例**：「你伸手觸摸牆壁。它應該很冷——這裡是地下停車場。但它很溫暖。不只是溫暖，是『有人不久前靠過這裡』的溫暖。但這裡沒有人。」

#### 空間感知

這是最難描寫的維度，但也是間隙最本質的特徵：

- **透視不穩定**：走廊的遠端可能比近端更大——或者更小。不是透視錯覺，是真的。
- **熟悉的空間陌生化**：你認得這是你的公寓大樓的走廊。但有什麼不對——轉角的弧度、門與門之間的距離、天花板的紋理。像有人在你不注意的時候微調了一切。
- **空間的「厚度感」**：有些區域讓你覺得空間本身很「厚」——像你正在穿過一層看不見的膜。長時間停留會讓人頭痛。
- **負空間的顯現**：間隙中，「空的空間」本身幾乎是可見的——像熱浪中的空氣扭曲，像水面下的東西。

> **描寫範例**：「這是你每天走過的走廊。但今晚它比昨天長了大概三公尺。不是幻覺——你數了腳步。而且牆壁的顏色不太對。不是變了顏色，是……像顏色本身有點猶豫。」

### 4.2.2 距離扭曲的敘事呈現

距離不固定是間隙最核心也最難駕馭的特性。以下不是數學公式——是敘事工具。

#### 距離的「關係法則」

在間隙中，兩點之間的距離取決於它們在表層的**關係**，而非物理距離：

| 關係類型 | 距離效果 | 敘事範例 |
|---------|---------|---------|
| **同類空間** | 距離縮短 | 所有「廢棄的更衣室」之間可能只需走幾步 |
| **共享記憶** | 距離縮短 | 兩個人同時記得的地點之間會出現捷徑 |
| **因果連接** | 距離不穩定 | 犯罪現場與兇手的藏身處之間——距離隨時間波動 |
| **情感對立** | 距離延長 | 幸福回憶的地點與痛苦回憶的地點——在間隙中可能隔得很遠 |
| **無關係** | 距離隨機 | 兩個毫無關聯的地點——距離可能任何數字 |

#### 距離扭曲的三種敘事模式

**模式一：迷宮化**
同一段走廊走了三次，每次都看到不同數量的門。轉角後的空間不該存在——大樓的平面圖上沒有這一塊。

> **使用時機**：懸疑場景、玩家在尋找特定目標但方向不明時

**模式二：捷徑**
穿過間隙中的一個房間，回到表層時發現自己跨越了半個城市。經驗豐富的行者利用這一點——但捷徑不是穩定的。

> **使用時機**：需要快速移動劇情、展示間隙的實用性與不可靠性並存

**模式三：延展**
一條走廊在表層只有十公尺。在間隙中，它延伸了……很遠。看不到盡頭。腳步聲開始有回音。你走了多久？

> **使用時機**：緊張場景、展示間隙的危險性、加速間隙病的發作

#### GM 實用工具：關係地圖

準備冒險時，與其畫精確的間隙地圖（不可能），不如畫**關係地圖**：

```
[廢棄工廠入口] 
    |--- "曾經發生過的事故" --- [工廠地下室]（距離：很近）
    |--- "老闆逃走路線" --- [城市另一端的安全屋]（距離：有時近有時遠）
    |--- "工人懷念的家鄉" --- [300公里外的鄉村]（距離：很遠但可到達）
    |--- "與此地無關" --- [隨機地點]（距離：不可預測）
```

每條關係線標註一個**情感/因果關鍵詞**，決定距離傾向。玩家可以透過蒐集線索來「解鎖」關係——例如發現工廠事故的真相，就能使用事故關係的捷徑。

### 4.2.3 門檻類型：場景描寫範例

#### 天然門檻

**本質**：空間在特定條件下自然變薄。最古老的門檻類型。
**特徵**：通常位於自然界的「之間」——海岸線（海與陸之間）、洞穴入口（山與空之間）、霧中（可見與不可見之間）、特定時刻（晝夜交替時）。

> **場景描寫**：
> 退潮時，海蝕洞的入口露出了大約兩小時。洞內的空氣不同——不是潮濕的，是乾燥的，像舊書頁。浪聲在洞的深處變得奇怪——不是變小，而是變得……延遲。像浪在另一個地方拍打，聲音經由長長的隧道傳到你耳中。
>
> 洞壁上有鹽的結晶，但排列得太整齊了。不是自然的圖案——像是有人在牆上寫了什麼然後擦掉。在洞的最深處——退潮後還剩一個半小時——你看到岩壁上有一條裂縫。不是裂開的岩石，是岩石之間的空間裂開了。

#### 人造門檻

**本質**：人類活動反覆磨損現實。最常見的門檻類型。
**特徵**：出現在被人類頻繁過渡使用的空間——地鐵站的某個特定轉角（上下班人潮反覆穿過）、醫院的特定走廊（生與死之間的過渡）、圖書館的特定書架之間（閱讀與現實之間的過渡）。

> **場景描寫**：
> 地鐵最後一班車開走後二十分鐘。月台空了。但第三節車廂位置的黃線旁邊，空氣在微微顫動——不是熱浪，是像有人剛穿過珠簾，珠簾還在晃動。如果你站在那個位置，你會聞到不屬於地鐵的味道：舊報紙、咖啡、某種老舊的香水。然後你會注意到，月台邊緣的瓷磚有一塊的顏色不太對——比周圍的稍微灰一點，像它同時存在於兩個不同的年代。

#### 創傷門檻

**本質**：強烈情感撕裂現實。最危險的門檻類型。
**特徵**：一個月內都不會完全「癒合」。舊的創傷門檻可能被類似的情感重新撕開。周圍的空間有「回音」——聲音、影像、情緒碎片反覆播放。

> **場景描寫**：
> 這個十字路口在白天很正常。但在凌晨兩點四十七分——事故發生的確切時間——柏油路上的裂縫會開始滲出不是水的東西。空氣變得沉重，充滿金屬味。你站的位置正好是撞擊點，而你會感到胸膛中有一個不屬於你的劇痛——那是三年前那位機車騎士最後感受到的東西。視線邊緣，黃色的警示燈開始閃爍——但這個路口根本沒有警示燈。它們在間隙的那一側閃爍。

#### 記憶門檻

**本質**：集體記憶長期疊加。最「溫暖」但也最令人迷失的門檻。
**特徵**：通常位於「很多人同時記得的地方」——舊校舍、拆除前的電影院、即將改建的老街區。半透明——你能看到另一側的「記憶場景」重疊在現實上。

> **場景描寫**：
> 這間老電影院下週就要拆了。但今晚，放映廳的第十一排第七個座位——曾經有人在那裡度過了人生中最快樂的兩小時——座位微微發光。如果你坐在那個位置上，你會同時看到兩個畫面：眼前剝落的牆壁，和另一層透明的、正在放映老電影的銀幕。兩種畫面重疊著，像雙重曝光。你能聞到爆米花的味道——來自三十年前。如果你閉上眼睛，你會聽到那場電影的對白，還有某個人的笑聲。

#### 密封裂縫

**本質**：被刻意封閉的門檻。最令人不安的類型。
**特徵**：表面看起來完全正常——這正是問題所在。周圍的空間「太正常了」——沒有灰塵、沒有磨損、沒有時間的痕跡。靠近時感到被排斥——不是恐懼，而是確切的、物理性的「你不想待在這裡」的感覺。

> **場景描寫**：
> 醫院地下二層，走廊盡頭的儲藏室。門牌上寫著「檔案室 B」，但字體是錯的——這種字體在這間醫院從未被使用過。門把是乾淨的——太乾淨了，上面沒有一點刮痕、沒有一點油脂。你的手伸向門把時，手臂上的汗毛豎起來——不是因為冷。空氣在門周圍是靜止的。不是沒有風，是空氣不願意靠近這扇門。如果你把耳朵貼在門上——你不會這麼做的，但如果你做了——你會聽到門的另一側沒有任何聲音。不是安靜。是虛無。

### 4.2.4 不可解釋現象列表

以下是 GM 可以插入任何間隙場景的**隨機細節**。它們不解釋、不推進劇情、不給線索——它們純粹是為了讓間隙感覺「不對」。每個場景使用 1-2 個。

#### 輕微異常（可頻繁使用）

1. 一面鏡子反映出的房間與你所在的房間不完全相同——多了一扇窗、家具的位置略有偏移
2. 地板上有一排濕腳印，但只延伸了三步就消失了——沒有來處，沒有去處
3. 某個房間裡的鐘全部停在同一個時間——不是整點，是 4:37
4. 窗戶外的景色是對的，但季節錯了——外面在下雪，現在是七月
5. 一陣風吹過走廊，帶著很明確的、不屬於這裡的音樂片段
6. 牆上的標誌字體在你看第二眼時變了
7. 你聽到有人在遠處叫你的名字——用你小學老師的語調
8. 一個房間裡的桌椅被排列成一場會議的布置，桌上放著一杯還在冒熱氣的咖啡
9. 電梯按鈕有一個你從未見過的符號——不是樓層數字，不是字母
10. 某個角落的光線來自錯誤的角度——影子投向光源的方向

#### 中度異常（每場劇本用 2-3 個）

11. 走廊中的某扇門打開後，通往一個物理上不可能存在的空間——比如大樓內部的一片田野
12. 所有電子設備同時顯示同一個畫面——一張模糊的、無法辨識的臉
13. 牆紙的圖案在你視線移動時輕微改變——當你直視時又恢復原樣
14. 你在三個不同的房間看到同一件物品——同一道刮痕、同一個汙漬
15. 一段樓梯的階梯數量每次走都不一樣
16. 你看到自己的背影——你的 doppelgänger 在你前方十公尺處轉過轉角
17. 空氣突然充滿了某種明確的情緒——不屬於你的悲傷、憤怒或喜悅
18. 整個房間微微傾斜了——不是地震，是空間本身傾斜了約一度
19. 牆上的影子在動，但對應的物品沒有動
20. 你走了很長一段路後，發現自己回到了原點——但你的腳印顯示你一直在走直線

#### 深度異常（每場劇本最多 1 個）

21. 你看到一個人在走廊另一端走過——但那個人的穿著、步伐和你的父親一模一樣。你的父親從未來過這座城市
22. 天花板消失了。不是「天花板很高」——是沒有天花板。上面是陰天。但你在地下三層
23. 所有聲音突然消失——然後你聽到自己的心跳聲，但它不來自你的胸腔，而是來自走廊的另一端
24. 你進入了應該是隔壁房間的門——卻走進了你自己的童年臥室。一切都在：海報、床單、窗外那棵樹。但窗外沒有街道——只有更多房間
25. 你找到了一面全身鏡。鏡中的你穿著不同的衣服，臉上有你沒有的傷疤。鏡中的你也在看著你——而且表情比你更恐懼

## 4.3 間隙生物敘事指南

### 設計哲學

間隙生物不是「怪物」。它們不是為了被擊敗而存在的。每一種間隙生物都是間隙的某個面向的**體現**——它們的行為有內在邏輯，它們的「敵意」往往是防禦、困惑、飢餓或無法被理解的溝通嘗試。

在設計遭遇時，記住這個優先級：
1. **理解**：玩家能理解這個生物為什麼在這裡、想要什麼？
2. **選擇**：玩家能做出有意義的選擇（交涉/繞過/幫助/對抗）？
3. **後果**：這個遭遇改變了什麼？

---

### 4.3.1 門檻徘徊者

#### 本質

門檻徘徊者曾經是人類——間隙行者。他們在某次穿梭中「沒能完全回來」。不是死亡——是卡在門檻本身之中，既不在表層也不在間隙中，永遠在通過的過程中。

#### 深度背景

每一個門檻徘徊者都曾有一個名字、一段人生、一個讓他們成為間隙行者的原因。他們的徘徊不是詛咒——是困惑。他們不知道自己在哪裡、自己已經這樣多久了。他們被困在「即將進入」的瞬間——永遠正要跨過門檻，永遠跨不過去。

有些徘徊者是主動選擇留下的——他們在門檻中看守著什麼：一個密封空間、一個只有他們知道的危險門檻、或一個尚未覺醒但即將覺醒的年輕行者。

#### 外觀

- 人形輪廓，但邊緣模糊——像一張被過度曝光的照片
- 移動時身後拖著殘像，像是在多個瞬間同時存在
- 「臉」的部位有時能看到五官的痕跡——某個瞬間你會看到一雙驚恐的眼睛、一張正在說話的嘴
- 穿著模糊——可能是一件外套、一件制服、或任何你可能在任何時代看到的普通衣物
- 周圍有微弱的「門檻效應」——空氣微微顫動、溫度異常

#### 行為模式

- 在特定門檻附近反覆徘徊——通常是他們失蹤的那個門檻
- 對靠近門檻的行者表現出警戒或困惑
- 有時會試圖與行者「溝通」——聲音聽起來像隔著很厚的玻璃
- 不會主動攻擊，但被干擾時可能無意識地防衛
- 偶爾會「引導」行者——指出危險的門檻、或用殘像標示安全的通道

#### 扮演提示

| 維度 | 指導 |
|------|------|
| **語氣** | 空洞、遙遠、斷續——像收音機在兩個頻道之間。不是恐怖片中的低沉威脅，而是更接近困惑和疲憊 |
| **動作** | 緩慢、不連續——他們在兩個瞬間之間跳躍。有時會「快轉」一段動作，然後又回到緩慢 |
| **情感核心** | **困惑與等待**。他們不是憤怒的鬼魂，是迷路的人。最悲傷的時刻是當玩家意識到徘徊者在等的人永遠不會來了 |

#### 範例遭遇場景

**場景：地下道的最後一個守夜人**

*地點*：城市地下通道系統中一個被遺忘的區段，牆上有三十年前的路標。

*表層*：封閉的地下通道入口，鐵柵欄上掛著「施工中」的褪色告示。但告示的日期是二十七年前。

*間隙層*：通道暢通，但牆壁被一層銀灰色的薄膜覆蓋。通道的深處，一個門檻徘徊者站在一扇生鏽的鐵門前——姿勢像是在等門打開。

*遭遇*：
- 徘徊者曾是一名市政維修工人，二十七年前在檢查通道時誤入間隙。他一直在等「隊長回來開門」。
- 他會用斷續的語句警告玩家「門後面不安全」——他指的是鐵門後面的密封空間
- 如果玩家尊重他的看守，他可能透露：這扇門的鑰匙在「值夜室」——但他不記得值夜室在哪裡了
- 如果玩家試圖強行打開門，他會暴走——不是攻擊，而是他的時間碎片化會干擾玩家，導致所有人的時間感知錯亂（d6 時間流速變為 d20）

*關鍵選擇*：玩家可以幫助徘徊者完成他的看守（找到鑰匙、確認門仍然密封、告訴他「隊長說你可以休息了」），讓他終於能離開門檻。或者可以利用他獲取資訊，然後無視他的命運。

### 4.3.2 遺失物收集者

#### 本質

遺失物收集者是一種對「遺失」本身具有本能反應的生物。它們收集遺失物——但不是為了擁有它們。更像是它們被遺失物的「未被持有」狀態吸引，就像飛蛾被光吸引。

#### 深度背景

沒有人確定收集者從何而來。一種理論認為它們是極其古老的遺失物本身的意識——一把在漢朝遺失的銅鏡，在間隙中待了兩千年後，開始收集其他遺失物。另一種理論認為它們是間隙生態系統的自然組成部分——就像表層世界的清道夫。

收集者是有用的。它們知道間隙中遺失物的位置。與收集者建立關係是間隙行者的重要生存技能——但這種關係永遠是交易性的。

#### 外觀

- 最難以描述的間隙生物——收集者的外觀取決於它們「最近在收集什麼」
- 基本型態是模糊的人形或動物形影子，但身上掛滿了遺失物——鑰匙、眼鏡、手錶、信件、照片
- 移動時發出輕微的碰撞聲和沙沙聲——像風鈴、像落葉
- 如果它們最近收集了某種特定物品，它們的外觀會朝那個方向傾斜——收集了許多照片的收集者會有相紙般的質感

#### 行為模式

- 不斷地在間隙中移動，從不停留超過幾分鐘
- 撿起物品、檢查、有時保留、有時放下——有某種外人無法理解的選擇標準
- 對行者通常中性——除非行者持有它們「想要」的物品
- 可以被交易：用有意義的遺失物換取資訊或服務
- 對善意遺留物表現出異常的尊重——它們不會碰善意遺留物。沒人知道為什麼

#### 扮演提示

| 維度 | 指導 |
|------|------|
| **語氣** | 沙沙的、細碎的、像是很多人同時在小聲說話。不是威脅，而是難以聚焦 |
| **動作** | 多動、碎步、不斷調整身上的物品。看起來像一隻用後腳站立的、掛滿裝飾的狐獴 |
| **情感核心** | **強迫性的收集與無法被滿足的渴望**。收集者收集是因為它們無法不收集——它們在尋找某樣東西，但不知道是什麼。這讓它們成為間隙中最悲劇性的生物之一 |

#### 範例遭遇場景

**場景：收集者的交易**

*地點*：廢棄百貨公司的四樓——曾經的家具展示區。

*表層*：封閉的百貨公司，櫥窗被木板封住，門上掛著「招租」的牌子。

*間隙層*：展示區像一個巨大的洞穴。展示用的沙發和床鋪排列成奇怪的角度，上面堆滿了遺失物——像某種巢穴。空氣中有舊布料的氣味和淡淡的樟腦味。

*遭遇*：
- 玩家的目標遺失物（一份關鍵文件）被這個收集者收進了它的「巢穴」
- 收集者願意交易——但它不想要錢、不想要武器。它想要**一個故事**
- 「這把鑰匙——誰丟的？為什麼重要？告訴我，你就可以拿走文件。」
- 玩家可以選擇誠實地講述鑰匙的故事、編造一個更好的故事、或試圖偷走文件
- 如果玩家講出了真誠的故事，收集者可能會透露額外的資訊——關於這棟百貨公司裡另一件極有價值的遺失物的位置

*關鍵選擇*：收集者要的不是物品——是**物品的意義**。這給了玩家一個機會去思考遺失物的情感重量，也給了 GM 一個機會去深化玩家的角色故事。

### 4.3.3 鏡像

#### 本質

鏡像不是生物——它們是**殘留**。當一個人在極度強烈的情感狀態中經過間隙附近，他們的情感會「印」在間隙中。鏡像就是那個印象。

#### 深度背景

鏡像沒有自我意識。它們只是重複——重複一個瞬間、一個動作、一句話。大多數鏡像只是模糊的影像，幾小時到幾天後就會消散。但極其強烈的印象——瀕死、徹底的心碎、無法抑制的狂喜——會留下持久的鏡像。

最危險的鏡像是那些「注意到自己被觀看」的。當玩家觀察一個鏡像太久，鏡像有時會開始觀察回來。這不是覺醒——這是某種更原始的、鏡像式的回應。它開始模仿觀看者。

#### 外觀

- 半透明的人形，通常只有單色調——灰色、藍灰色、琥珀色
- 動作是循環的——每幾秒到幾分鐘重複一次
- 細節模糊——臉部特徵像被雨水沖刷過的粉筆畫
- 周圍有「情緒殘留」——悲傷的鏡像周圍空氣變冷；憤怒的鏡像周圍有微弱的嗡嗡聲
- 「注意到觀看者」的鏡像會開始轉向玩家——動作流暢得不像循環播放

#### 行為模式

- 大多數鏡像只是重複——它們是過去的回音，沒有互動性
- 極少數鏡像會「回應」——通常是模仿觀察者的動作
- 危險鏡像會試圖「完成」它們被凍結的瞬間——並可能將周圍的人拉進那個瞬間
- 聚集在創傷門檻附近——一個嚴重的創傷可能產生數十個鏡像
- 可以被「安撫」——幫助鏡像完成它們被困住的動作（如幫一個永遠在找鑰匙的鏡像找到鑰匙）

#### 扮演提示

| 維度 | 指導 |
|------|------|
| **語氣** | 無聲。鏡像不說話——即使它們的嘴在動，也沒有聲音。如果你想給他們聲音，讓它像風中的殘響 |
| **動作** | 精確重複的動作——同一個手勢、同一個轉頭的角度。讓重複本身變得令人不安 |
| **情感核心** | **被困住的瞬間**。每個鏡像都是一個未被完成的時刻——未說出的話、未做到的擁抱、未完成的逃跑。它們的悲劇在於，完成它們被困住的瞬間，意味著承認那個瞬間永遠過去了 |

#### 範例遭遇場景

**場景：月台上的告別**

*地點*：老舊火車站的第四月台——二十年前關閉，但從未被拆除。

*表層*：月台被鐵鍊封住，長椅上堆滿落葉。時刻表顯示器是空的。

*間隙層*：月台上擠滿了鏡像——幾十個半透明的身影，全部在做同一件事：與某人告別。擁抱、揮手、轉身離開。所有鏡像都在以不同速度播放他們的告別——快的像快轉、慢的像水中舞蹈。

*遭遇*：
- 其中一個鏡像「注意到」了玩家——一個年輕女子的影像停止了循環，轉頭直視玩家
- 她開始模仿玩家的動作——舉手、往前走、停下
- 如果玩家繼續互動，她會指向月台的邊緣——那裡有一個記憶結晶在軌道上閃爍
- 記憶結晶是她的——一封未寄出的信。如果玩家取回並在月台上「寄出」（投入月台上的舊郵筒），所有鏡像會同時停下，轉向玩家——然後消散

*關鍵選擇*：這個遭遇可以純粹是氛圍性的——玩家可以簡單地觀察並離開。但如果玩家選擇深入，他們會獲得一個記憶結晶（強大的遺失物），並體驗一次與過去對話的瞬間。

### 4.3.4 通道守衛

#### 本質

通道守衛是間隙中最古老的存在之一。它們不是轉化的人類，不是殘留的情感——它們是間隙**本身**的一部分，是間隙對「某些通道不該被使用」的集體記憶的體現。

#### 深度背景

如果門檻徘徊者是困在門檻中的行者，那麼通道守衛就是**門檻本身獲得了臨時意識**。它們出現在特定類型的通道中——連結危險區域的捷徑、通向密封空間的路徑、或曾被濫用的門檻。

通道守衛不是邪惡的。它們是保護性的——保護通道不被不該通過的人通過。問題在於，「不該通過」的判斷標準只有守衛自己知道。

#### 外觀

- 所有通道守衛看起來都不一樣——它們反映了所守衛通道的特質
- 共同點：它們的身體部分與通道結構融合——手臂可能從牆壁中伸出、腿可能融入地板
- 通常有某種「門」的元素——它們的臉可能是門的形狀、胸膛上可能有門把、背後拖著門框的碎片
- 身體材質與通道的建築材料相同——水泥、磚塊、金屬管線
- 不能離開守衛的通道——超出範圍時，身體會像煙霧般拉回通道中

#### 行為模式

- 站在通道入口或關鍵節點，一動不動——可能被誤認為建築的一部分
- 當行者接近時，它會「醒來」——從牆壁中浮現出更多身體
- 溝通方式不是語言——是直接的意圖傳遞（行者會「感覺」到守衛的要求）
- 要求通常是：證明你的意圖、展示你的通行權、或回答一個問題
- 如果被拒絕，守衛會強制關閉通道——物理性地封鎖或扭曲通道的空間
- 極少數情況下可以被欺騙，但欺騙的後果通常比被拒絕更糟

#### 扮演提示

| 維度 | 指導 |
|------|------|
| **語氣** | 無語調、共鳴的、像是建築本身在說話。不是威脅——是不可協商的確定性 |
| **動作** | 極其緩慢但極其確定——守衛不急，因為它不在乎時間。當它移動時，你會聽到建材的摩擦和呻吟 |
| **情感核心** | **邊界的不可侵犯性**。守衛不關心你的理由，不關心你的急需，不關心你有多絕望。它只關心一件事：你是否被允許通過。這是它的全部存在意義 |

#### 範例遭遇場景

**場景：深處的守衛**

*地點*：一個被遺忘的地下捷運隧道——建造於 1970 年代，從未開通。隧道的遠端連接一個密封空間。

*表層*：地面上的施工入口已被水泥填平。城市規劃局的文件中沒有這條隧道的記錄。

*間隙層*：隧道完好，但牆壁長滿了銀灰色的苔蘚（間隙中的「植物」——被遺忘的工程計畫的殘留）。隧道中段，牆壁上有一扇不屬於這裡的門——一扇老式的木門，嵌入水泥牆中。

*遭遇*：
- 木門是通道守衛的「臉」——當玩家接近時，門會打開，門後的黑暗中有東西在動
- 守衛從門框中浮現——一個由鋼筋、水泥和門框碎片構成的巨大人形
- 它不說話，但玩家會「感覺到」一個問題在腦中浮現：**「你為什麼要過去？」**
- 正確的答案不是「我有權力」或「我很強」——而是誠實。守衛能分辨謊言
- 如果玩家誠實地說出他們的目的（即使目的是自私的），守衛會讓開——但只讓說出真相的那個人通過
- 如果玩家說謊，守衛不會攻擊——但隧道會開始「忘記」他們。每走一步，他們就忘記一點關於自己的事（暫時性失憶效果）

*關鍵選擇*：這個遭遇測試的不是玩家的戰鬥力——是他們的自我認知。為什麼要進入危險？理由是什麼？這是間隙行者必須不斷面對的問題。

### 4.3.5 密封看守者

#### 本質

密封看守者是最危險也最令人心碎的間隙生物。它們是間隙對「被密封的東西」的反應——當一個密封空間存在太久，間隙會「生長」出看守者來確保它保持密封。

#### 深度背景

密封看守者不是被創造的——它們是**結晶**。密封空間本身就是一個悖論（被封閉的東西仍然在間隙中佔據空間），這個悖論會逐漸累積張力。當張力達到閾值，看守者就結晶了。

它們最悲劇的特質是：看守者與密封空間的內容物有深層聯繫。如果密封空間封印著一場火災的記憶，看守者會表現出火的特質。如果封印著一個被遺忘的人，看守者可能會有那個人的某些特徵。

#### 外觀

- 體型最大的間隙生物——通常填滿整個密封空間附近區域
- 外觀與密封內容相關：封印著洪水的空間旁，看守者可能由不停流動的水構成
- 身體部分與密封空間的「封印」融為一體——鎖鏈、封條、符號刻在它的軀體上
- 不需要光線就能被看見——它們的存在本身會發出微弱的、顏色取決於密封內容的光
- 這個生物看起來很**疲憊**——不是虛弱，而是承受著巨大的、長期的負擔

#### 行為模式

- 極少離開密封空間的範圍——它們的存在與空間相連
- 對接近者展現精確遞增的警告：先是存在感（讓你不想靠近）→ 視覺展示（讓你看見它）→ 物理阻擋 → 攻擊
- 攻擊不是出於敵意——是出於**必要性**。守護是它們存在的唯一理由
- 無法被殺死——只能被壓制、繞過或安撫。摧毀守護者會破壞封印，釋放密封的內容
- 可以與之溝通——但它們的思維被密封的內容染色了。與看守火災記憶的守護者說話，你的話語中會出現燒焦的味道

#### 扮演提示

| 維度 | 指導 |
|------|------|
| **語氣** | 沉重、共鳴、每一個字都像從很遠的地方運來的。它們不是威脅——它們是**負擔**。與看守者對話應該感覺像與一座山對話 |
| **動作** | 極其緩慢但不可阻擋。看守者移動時，周圍的間隙空間會因為它的質量而微微變形 |
| **情感核心** | **永恆的警惕與無法卸下的責任**。看守者不想在這裡。沒有人問過它們。但它們無法不做這件事——這是它們的存在定義。摧毀看守者不是勝利，是悲劇 |

#### 範例遭遇場景

**場景：被封印的教室**

*地點*：一所廢棄小學的三樓教室——二十年前一場火災後被封鎖。

*表層*：教室的門被磚塊封死。窗戶被鐵板遮擋。學校的其他部分已被改建為社福機構，但三樓從未被重新開放。

*間隙層*：走廊通向教室的路比表層長了三倍。牆壁上浮現出燒焦的痕跡——像影子，但不對應任何物體。空氣乾燥，每一次呼吸都帶著微弱的煙味。

*遭遇*：
- 教室門前站著密封看守者——一個由灰燼、燒焦的木頭和融化的塑膠構成的人形。它的「臉」是一個孩子畫的火災逃生圖——用蠟筆畫的，被火焰舔過邊緣
- 玩家被委託取回教室中的某樣東西——一個火災當天遺失的學生作品
- 看守者不會讓任何人進入。但它也不會主動攻擊——它只是站在那裡，像一堵牆
- 溝通：看守者用燒焦的聲音說：「裡面只有……」然後停了下來。它忘記了裡面有什麼。它已經看守了太久，以至於忘記了為什麼看守
- 解法：幫助看守者「記起」它看守的是什麼。這需要玩家去其他地方尋找線索（舊報紙、倖存者的記憶結晶、另一處的遺失物），拼湊出火災當天的故事。當看守者重新記起它看守的是什麼——不是火焰，而是孩子們在火災前最後一堂課畫的畫——它會讓開
- 如果玩家暴力突破：看守者崩解，封印破裂，教室中湧出的不是火焰——是三十個孩子的鏡像，永遠困在最後一堂課的瞬間。這是一場災難——但不是戰鬥型的災難。玩家現在必須處理三十個被困住的兒童鏡像

*關鍵選擇*：這個遭遇的核心是**記憶與遺忘**。密封看守者本身就是一個被遺忘的故事。幫助它記起，就是幫助它完成它的使命——然後它終於可以消散。

## 4.4 GM 運行指南

### 4.4.1 準備雙層地圖

#### 為何必須同時繪製兩層

間隙行者的核心遊戲循環是**在兩層之間穿梭**。如果只有表層地圖，GM 在玩家進入間隙時會措手不及。如果只有間隙地圖，表層的 NPC、事件和物理限制就會被忽略。

更重要的是：**兩層之間的關係本身就是遊戲內容**。表層的這個位置對應間隙的什麼？為什麼門檻在這裡？兩層的差異說明了什麼故事？

#### 雙層地圖的繪製方法

**步驟一：先繪製表層**

用正常方式繪製場景的表層。不需要太複雜——重點標註：
- 主要空間與通道
- 空間的功能（辦公室、走廊、儲藏室等）
- 人群密度（繁忙/普通/冷清/空無一人→這暗示間隙厚度）
- 潛在的「之間」位置（門與門之間、樓梯轉角、走廊交匯處等）

**步驟二：標註關係熱點**

在表層地圖上圈出：
- 紅色圈：情感強烈的位置（曾發生過什麼）→ 可能是創傷門檻
- 藍色圈：長期被遺忘/廢棄的位置 → 間隙較厚
- 綠色圈：過渡性空間（走廊、樓梯、出入口）→ 可能有人造門檻
- 黑色圈：你已經設計好門檻的位置

**步驟三：繪製間隙層**

將表層地圖放在旁邊，畫一張對應的間隙層地圖。但——
- 不要試圖讓間隙地圖「準確」。它是扭曲的
- 改變一些房間的大小（被遺忘的房間在間隙中更大）
- 添加表層不存在的通道（捷徑）
- 標註距離傾向（哪些房間之間的距離比表層短/長）
- 標註間隙生物的領地
- 標註遺失物的位置和密封空間

**步驟四：建立關係註解**

在兩張地圖之間畫連線，標註：
- 每個門檻在兩層中的對應位置
- 哪些表層位置在間隙中有不同的功能
- NPC 在兩層中的狀態（普通人在間隙中不存在/敏感者在間隙中有殘影）

#### 雙層地圖範例

以下是一個完整場景的雙層地圖文字描述：

---

**場景名稱**：深夜的社區圖書館

**表層地圖**：

```
[正門（玻璃門，已鎖）]
    |
[入口大廳] — [借還書櫃檯（空無一人）]
    |
[走廊] — [樓梯（通往二樓）]
    |
[閱覽室 A（報紙期刊）] — [閱覽室 B（一般藏書）]
    |
[走廊延伸] — [廁所（左）] — [儲藏室（右，門上有「員工專用」標誌）]
    |
[兒童閱覽區（有彩色地毯和小桌椅）]
    |
[後門（鐵門，通往停車場）]
```

**標註熱點**：
- 🔴 儲藏室：十年前館員在此心臟病發作，無人知曉。第二天才被發現。
- 🔵 兒童閱覽區：平日熱鬧，深夜空無一人→間隙此時極厚
- 🟢 入口大廳→走廊的轉角：反覆被推門/經過/穿梭→人造門檻
- ⚫ GM 設計的門檻位置：儲藏室門口（創傷門檻）、走廊轉角（人造門檻）

**間隙層地圖**（對應）：

```
[入口大廳] ←距離拉長→ [借還書櫃檯（堆滿遺失信件）]
        |
[走廊（比表層長兩倍，牆上有孩子的蠟筆畫——圖書館建於40年前）]
        |
[「中間空間」——這裡在表層是走廊的一部分，但間隙中變成一個沒有窗戶的等候室]
        |
[閱覽室 A] ←距離極短→ [閱覽室 B]（在間隙中兩間房間融為一體）
        |
[走廊（牆壁上有呼吸聲——來自儲藏室方向）]
        |
[儲藏室門前——密封看守者（灰塵與舊書構成的人形）]
        |
[兒童閱覽區（比表層大三倍；地毯上散落幾十個遺失的玩具）←捷徑→後門外的停車場]
        |
[？？？——一個不屬於圖書館的空間：看起來像某人的書房，桌上放著一杯不冷的茶]
```

**關係註解**：
- 走廊的蠟筆畫→暗示這棟建築曾是學校→可能指向更深層的間隙
- 等候室→在人造門檻的對面生成；所有通過這個門檻的人都會先經過這裡
- 密封看守者的存在→儲藏室不僅是創傷門檻，裡面還有密封空間
- 捷徑→兒童閱覽區直接通往停車場，跳過了後門和走廊

### 4.4.2 管理時間流速

#### 時間流速 d6 表

| d6 | 回到表層的時間 | 敘事效果 |
|----|-------------|---------|
| 1 | 只過了幾秒 | 幾乎沒人注意到你離開——但時間的「缺失」讓你的身體感到一陣眩暈 |
| 2 | 過了幾分鐘 | 你的短暫消失可能被注意到。如果有人在你消失的地方等你，他們剛開始擔心 |
| 3 | 過了幾十分鐘 | 明顯的時間缺口。需要解釋。手機上有未接來電 |
| 4 | 過了幾小時 | 嚴重後果。約定錯過。日出/日落可能改變了場景。夜班警衛換班了 |
| 5 | 過了半天到一天 | 你被通報失蹤了（如果你有在乎你的人）。場景完全改變。委託人可能放棄了 |
| 6 | 過了數天 | 災難性。你的掩護生活可能崩潰。如果你有依賴你的人，他們陷入了危機 |

#### 時間流速的使用原則

**原則一：提前決定何時擲骰，並告知玩家**

不要偷偷擲骰。玩家應該在進入間隙前就知道：回來時時間可能不同。這不是懲罰——這是間隙的基本規則，是他們選擇冒險的代價。

讓玩家在穿越門檻**進入**間隙時擲 d6——不是回來的時候。這樣他們在整個間隙探索過程中都知道自己面臨的時間壓力（或幸運的寬裕）。緊張感來自**知道代價但不確定**。

**原則二：時間流速不是隨機的——部分由情境決定**

d6 是基準，但 GM 可以根據情境調整：
- 在深間隙中：改為擲 d6+2（最低 3，最高 8 天）
- 使用熟悉的門檻：擲 2d6 取最低
- 匆忙穿梭（未專注於門檻）：擲 2d6 取最高
- 被間隙生物干擾：自動取 6
- 帶著普通人穿梭：所有人各自擲骰，取最差的結果

**原則三：時間流速是敘事工具，不只是後勤問題**

「回到表層發現已經過了三天」不只是「你錯過了約定」。GM 應該讓時間的流逝產生意義：

- 季節/天氣改變了——原本晴天的場景現在在下雨
- 有人在你消失期間來過——留下了紙條、物品、或痕跡
- 原本危險的狀況（如被追趕）可能緩解了——但也可能惡化了
- 新聞報導了你的失蹤——或者更糟，沒有任何人注意到

**原則四：明確追蹤**

在團務筆記的顯眼位置保持時間追蹤：
- 表層時間：____年__月__日 __：__（進入間隙前）
- 間隙中感知時間：____（由 GM 根據敘事決定）
- 預期流速（d6 結果）：____
- 實際返回時間：____年__月__日 __：__

讓玩家也能看到這個追蹤（至少看到進入時間和 d6 結果）。透明度創造緊張感。

### 4.4.3 營造氛圍：寂靜、孤獨、發現

#### 間隙的三種核心氛圍

**寂靜——不是「沒有聲音」**

真正的寂靜在表層世界幾乎不存在。總有空調的嗡嗡聲、遠處的車輛、鄰居的腳步。間隙中的寂靜是**壓倒性的**——它讓你意識到表層世界的聲音汙染有多嚴重。

但這種寂靜不是空的。它充滿了**潛在的聲音**——你自己的心跳、衣服的摩擦、吞嚥的聲音。最輕微的聲音在間隙中變得巨大。

> **GM 技巧**：讓玩家描述「你的角色聽到了什麼」而不是你描述寂靜。這創造更深的沉浸感。

**孤獨——不是「沒有人」**

孤獨感來自**缺席的證據**。間隙中令人孤獨的不是空無一人——而是到處都是「不久前有人在這裡」的痕跡。椅子上殘留的體溫（但沒有人）、喝了一半的咖啡（還溫的）、書本翻到一半（但書籤在另一頁）。

> **GM 技巧**：每次描述場景時，插入一個「缺席的證據」。一張桌上放著兩副餐具但只有一副用過。一個掛著外套的衣架，但外套的款式是三十年前的。

**發現——不是「找到寶藏」**

間隙中的發現感來自**連結**。當玩家發現一個遺失物，他們不只是獲得道具——他們觸及了另一個人的生命片段。最好的發現讓玩家想：「這是誰的？他們還記得這個嗎？他們在哪裡？」

> **GM 技巧**：每個遺失物都是一個微型故事。不是「你找到一把鑰匙」而是「你找到一把鑰匙，鑰匙圈上有一個褪色的笑臉吊飾，背面刻著『第一天上班——2003.3.15』。」

#### 氛圍工具箱

**過渡技巧——從表層進入間隙**

進入間隙的瞬間是氛圍轉換的關鍵時刻。不要跳過它。放慢速度。

推薦的三步轉換：

1. **感官減法**：先移除一層感官——通常是聲音。表層的背景音逐漸消失。
2. **感官轉換**：一個感官被迫適應——光線的顏色變了、溫度下降低、空氣的質地不同。
3. **第一印象**：玩家在間隙中注意到的第一個東西——永遠是一個具體的、可感知的細節。不是「你進入了間隙」，而是「你注意到的第一件事是灰塵——它在空中靜止，不像飄浮，像是被忘記了該往下掉。」

**持續氛圍維持**

- 使用**重複主題**——某個物件、某個氣味、某個聲音在場景中反覆出現。讓它獲得累積的意義
- 使用**感知模糊**——偶爾讓玩家不確定某個東西是真的還是他們在想像。不要澄清。間隙本身就不提供確定性
- 使用**沉默的長度**——在對話中插入比平常更長的沉默。讓玩家在沉默中待著。不要急著填滿

**退出技巧——從間隙回到表層**

回到表層應該感覺像**醒來**。感官衝擊——表層世界突然變得太吵、太亮、太滿了。讓玩家意識到他們在間隙中已經習慣了那種寂靜，而現在正常世界感覺不正常。

> **GM 技巧**：回到表層後，讓玩家描述「你的角色注意到表層世界的什麼不同了？」這強化了間隙改變了他們的感知。

### 4.4.4 設計有意義的遺失物

遺失物是間隙行者的核心驅動力——委託、線索、情感載體。但遺失物不能只是 MacGuffin（「找到這個東西因為劇情說要找到它」）。

#### 遺失物的四個意義層次

**層次一：實用價值**
物品本身的功能。一把鑰匙開一扇門。一副眼鏡幫助你看清楚。這是最淺的意義——但仍然是必要的。

**層次二：情感價值**
物品對失主的意義。那支鋼筆不是普通的筆——是爺爺在失主考上大學時送的。它的價值不在筆，在於「你是我們家第一個大學生」。

**層次三：象徵價值**
物品代表了什麼。一個在廢棄工廠中遺失的婚戒——不是戒指本身的價值，而是它象徵了一段在工廠倒閉的壓力下崩潰的婚姻。遺失的不只是戒指，是對婚姻的信任。

**層次四：系統價值**
物品如何影響遊戲系統/世界。這個遺失物能被用作穿梭的錨點嗎？它包含的記憶能打開特定的門檻嗎？它是某個密封空間的鑰匙嗎？

#### 遺失物設計模板

```
名稱：[物品名稱]
外觀：[具體的、可感知的描述。包含磨損、顏色、缺陷]
來源：[誰丟的？何時？什麼情境？]
情感層：[這個物品對失主意味著什麼？失去它改變了什麼？]
象徵層：[這個物品在更大的故事中代表了什麼？]
系統層：[遊戲中的用途——線索/道具/錨點/交易物品]
標籤：[普通遺失物/善意遺留物/記憶結晶/間隙造物/被遺忘者]
```

#### 遺失物設計範例

**範例一：半張照片**

- **外觀**：一張被撕成兩半的拍立得照片。剩下的一半中，一個年輕女人在笑，手臂伸向畫面外——她正在牽著某個人的手，但那個人被撕掉了。照片背面寫著「2007.8.12 我們的第一天」。
- **來源**：一個女人在分手後撕掉了所有合照。這張沒丟進垃圾桶——它從她顫抖的手指間滑落，掉進了現實的裂縫。攜帶著十七年的後悔。
- **情感層**：撕掉照片是為了假裝不在乎。照片掉進間隙是因為她無法真正丟掉它。它在間隙中等待了十七年——照片中的笑容從未褪色。
- **象徵層**：未完成的分手、從未被允許的哀悼、半個答案
- **系統層**：記憶結晶。可以用作通往 2007 年那天場景的錨點。如果玩家找到另一半照片（可能在失主身邊或在另一處間隙），兩半合併會釋放被封鎖的記憶，揭示一個秘密。
- **標籤**：記憶結晶

**範例二：無人接聽的手機**

- **外觀**：一支十年前的手機型號，螢幕有裂痕但仍在運作。電量顯示為 1%。鎖定畫面是母親抱著嬰兒的照片。有 47 通未接來電，全部來自同一個號碼，標註為「媽」。
- **來源**：一個年輕人在都市中失蹤。他的手機在失蹤當天掉進了間隙。47 通未接來電——每一通都是他母親打來的。她打了十年。手機在間隙中仍有 1% 的電量，像在等待什麼。
- **情感層**：不是手機本身的價值——是那 47 通未接來電。每一通都是一個母親拒絕放棄的證明。1% 的電量是一個永遠無法被回答的問題：他為什麼不接？
- **象徵層**：等待、無法放手的愛、科技時代的悲劇（手機讓我們以為可以永遠聯繫，但有些人還是消失了）
- **系統層**：善意遺留物（母親的愛透過不斷打電話注入其中）。如果玩家能將手機帶回表層，那 1% 的電量足夠回撥最後一通電話——母親會接。這觸發的不是戰鬥，是對話。
- **標籤**：善意遺留物

### 4.4.5 密封空間設計原則

#### 什麼值得被封起來？

密封空間是間隙行者世界中最沉重的元素。每一次密封都代表一個決定：**這個東西不該存在於任何地方**。

不是所有危險都需要密封。以下是密封空間設計的判斷框架：

**值得密封的條件**（至少滿足兩項才考慮設計為密封空間）：
1. **具有傳染性**：內容物會擴散、感染、或複製自己（記憶、情感、或物理實體）
2. **無法被摧毀**：不是「很難摧毀」——是「摧毀的概念對它不適用」。它只能被隔離
3. **被刻意遺忘**：有人（或一群人）選擇封印它，而不是面對它。密封是遺忘的極端形式
4. **對現實有害**：內容物的存在會主動損害表層現實的織物
5. **悖論性存在**：內容物本身是一個矛盾——一個不該存在但確實存在的東西

#### 密封空間的四種起源（敘事展開）

**刻意封印**

最常見的類型。某個人或群體刻意將某物封入間隙。關鍵問題：**誰做的？為什麼？他們還在看守嗎？**

*設計提示*：
- 封印者可能早已死亡——但他們留下的守護機制仍在運作
- 封印的「鑰匙」通常是一個遺失物——與密封內容有情感連結的物品
- 時間會削弱封印——一百年前的封印可能已經在滲漏
- 最好的刻意封印故事中，封印者的動機是可以理解的——甚至同情的

*範例概念*：一個物理學家在 1950 年代發現了「觀察現實會改變現實」的數學證明。不是量子力學的隱喻——是真正的、可操作的證明。他封印了自己的研究，因為他知道這證明一旦被理解，現實本身會開始因被觀察而崩潰。

---

**空間未完成**

宇宙的「未完成區塊」。這些空間在現實被「編織」時被跳過了。
*設計提示*：
- 內部沒有完成的物理規則——重力可能不存在、時間可能不流動、物質可能沒有確定的形態
- 不像其他密封空間那樣「危險」——更像是「不適合存在」的區域
- 裡面的東西是**潛在的**而非**實際的**——它們可能是任何東西，但尚未成為任何東西
- 這類空間的「守護者」通常不是看守者——而是不知道該怎麼處理這個空間的生物

*範例概念*：一棟大樓的第十三層（建築師刻意跳過的樓層）在間隙中真實存在——但裡面的房間沒有確定的形狀。每扇門打開後看到的都不同。在這一層的最深處，有一個房間……正在等待被定義。

---

**間隙災難癒合**

間隙本身有某種「自癒」機制——就像皮膚受傷後結痂。當某次間隙災難（大量行者同時穿梭、門檻被炸開、深間隙溢出）被控制後，癒合過程可能將災難的核心封入密封空間。

*設計提示*：
- 這類密封空間是「疤痕組織」——它們的邊界粗糙、不規則
- 內部可能仍在發生微弱的事件回音
- 封印不是完美的——偶爾會有「滲漏」
- 這類空間最容易被打開（疤痕比健康組織脆弱）

*範例概念*：十五年前，八名間隙行者試圖同時打開一個門檻——他們想要創造一個永久性的通道。災難發生了。災難的核心被間隙自癒封入密封空間。但每年在災難的周年日，密封空間會「流血」——滲出十五年前那八個人的記憶碎片。

---

**關著不該存在的東西**

最危險也最不該被打開的類型。裡面的東西不是「被遺忘」——是被**否認**。它們的存在本身就是對現實的挑戰。

*設計提示*：
- 這類密封空間的守護者是最強大/最絕望的
- 封印通常不是人類能創造的——可能是間隙本身的反應
- 內容物可能不是「邪惡」的——可能只是無法與現實共存。一個被所有人徹底遺忘的人。一個被從歷史中抹去的城市。一個從未被發生的時間線的殘餘
- 打開這類密封空間的後果不該是「放出了怪物」——而應該是「放出了一個無法處理的問題」

*範例概念*：一個密封空間中封印著「一個沒有發生過的戰爭」——一個被成功避免的核戰的殘餘。它不該存在，因為戰爭從未發生。但它也不該不存在，因為它曾經如此接近發生。這個悖論被困在密封空間中——打開它不會釋放核彈，但會釋放「我們差點毀滅自己」的集體記憶，這記憶的重量可能壓垮所有感受到它的人。

#### 密封空間設計模板

```
名稱：[空間的名稱/編號]
類型：[刻意封印/空間未完成/間隙災難癒合/關著不該存在的東西]
封印時間：[多久以前？]
封印者：[誰做的？（如果已知）]
內容物：[裡面是什麼？不只是物品——是狀態/存在/悖論]
封印狀態：[完好/輕微滲漏/嚴重退化/即將破裂]
守護者：[密封看守者的描述]
鑰匙/解法：[打開的條件是什麼？不是用鑰匙——用行為/物品/真相]
打開的後果：[如果不該打開的東西被打開了，會發生什麼？]
相關遺失物：[與密封內容有連結的遺失物，可作為線索]
```

### 4.4.6 間隙病的敘事運用

#### 間隙病的本質

間隙病不是疾病——它是**自我的稀釋**。在間隙中待得越久，你的「存在」越容易被間隙的「缺席」所混淆。你不會變成怪物——你只是漸漸變得……不像自己。

#### 間隙病的進程階段

**第一階段：感知模糊（暴露 1-3 小時累計）**
- 症狀：輕微的時間感錯亂、對自己是否關了門/帶了鑰匙的過度懷疑、在表層也偶爾看到間隙的殘影
- 敘事運用：提到「你不太確定你是否真的看到」，但不影響行動
- 玩家感知：不安，但可以忽略

**第二階段：記憶滲透（暴露 4-8 小時累計）**
- 症狀：開始混淆自己的記憶與間隙中的記憶殘留。在對話中使用不屬於自己的詞彙。對陌生人產生無法解釋的情感反應
- 敘事運用：GM 可以「修正」玩家的敘述——「你說的是他的名字，但你的嘴巴說出了另一個名字。你不認識那個名字。」
- 玩家感知：明顯的失控感

**第三階段：存在稀釋（暴露 9-16 小時累計）**
- 症狀：影子變淡、鏡子中的倒影延遲、別人開始「忘記」關於你的事。表層中不太熟悉你的人可能完全看不見你
- 敘事運用：NPC 的反應改變——有些人無視玩家、有些人看著玩家但表情困惑（「我認識你嗎？」）
- 玩家感知：恐懼——你正在被世界擦除

**第四階段：邊界溶解（暴露 17-24 小時累計）**
- 症狀：你不再能分辨表層和間隙。對你來說，兩層同時可見。你也同時存在於兩層中——你的行動在兩層都產生效應，但你無法控制哪一層的效應更大
- 敘事運用：GM 描述兩個版本的場景同時發生。玩家與表層 NPC 的互動可能在間隙中被扭曲
- 玩家感知：徹底的失控——但也是某種奇異的自由

**第五階段：門檻化（暴露 25+ 小時累計）**
- 症狀：你正在變成一個門檻——一個活著的、有意識的通道。你的身體周圍開始出現門檻效應。其他間隙生物開始繞過你，像繞過一個固定裝置。你仍然活著，但「你」正在變成一個地方
- 敘事運用：這不一定是角色的終結——但一定是角色的轉化。變成門檻的行者可能成為一個固定的 NPC 地點——「老周的通道」，其他行者可以通過他穿梭
- 玩家感知：角色的終極變形——你成為了一直在穿越的東西

#### 何時推進間隙病

**推進的原則**：
- 不要在玩家**剛剛**做出重要選擇後立刻懲罰他們（「你選擇幫助徘徊者？很好，現在你患上第二階段間隙病」）
- 使用間隙病來創造**張力**而非**挫折**。症狀應該是令人不安但有趣的——不是讓玩家想退出遊戲
- 間隙病的最佳時機是**當緊張感已經很高、玩家已經感受到間隙的壓力時**——讓症狀放大已有的焦慮
- 提供**緩解的希望**——回到表層、與真人進行有意義的互動、觸摸一個帶有強烈歸屬感的物品——這些可以減緩或暫時逆轉症狀

**推進時機的具體建議**：
- 玩家在深間隙中待了較長時間而未休息
- 玩家目睹了極度令人不安的間隙現象
- 玩家與大量鏡像或記憶殘留互動
- 玩家在沒有錨點（與表層的連結物）的情況下穿梭
- 其他玩家角色的間隙病正在惡化——集體效應

### 4.4.7 平衡線索與神秘感

這是間隙行者 GM 面臨的核心張力：給玩家足夠的線索讓他們有所行動，但保留足夠的神秘感讓間隙仍像間隙。

#### 黃金比例：80/20

每個場景中，約 80% 的資訊應該是可以被理解和推理的。20% 保持不可解釋。如果你解釋了 100%，間隙變成了一個「科學現象」——失去了它的魔力。如果你只解釋了 20%，玩家會感到目標不明確、無法做出有意義的決定。

#### 具體技巧

**給予的線索**：
- 間隙生物的**行為模式**——為什麼它這樣做，它在保護/尋找什麼
- 遺失物的**來源與情感意義**——讓玩家能推測它為什麼在這裡
- 門檻的**形成原因**——這讓玩家能預測其他門檻的位置
- 密封空間的**歷史**——封印的原因和封印者的身分

**保留的神秘**：
- 間隙的**終極本質**——永遠不要解釋間隙「為什麼」存在
- 間隙生物的**起源**——它們是怎麼「成為」的可以暗示，但不要確認
- 深間隙的**底層**——沒有任何角色能到達並回來描述
- 其他行者的**完整故事**——讓 NPC 行者保留他們的秘密

#### 線索分層法

每個謎團設計三層線索：

**表層線索**（明顯，細心的玩家必定發現）：
- 視覺描述中的異常（牆上的痕跡、重複的符號）
- NPC 的明顯異常行為
- 物品的不合邏輯位置

**中層線索**（需要調查才能獲得）：
- 需要技能檢定才能發現的細節
- 需要訪問特定地點才能看到的證據
- 需要與特定 NPC 對話才能知道的資訊

**深層線索**（需要推理和付出代價才能獲得）：
- 需要進入深間隙才能找到的證據
- 需要承擔間隙病風險才能回收的記憶結晶
- 需要與間隙生物交易才能獲得的秘密

#### 當玩家要求解釋時

有時候玩家會直接問：「所以這裡到底發生了什麼？」這時 GM 有幾個選擇：

1. **角色視角回答**：「你的角色基於目前的線索，推測……」（讓玩家自己拼湊，但提供思考框架）
2. **部分確認**：「關於 [A]，你的推測是對的。但關於 [B]……你不確定。」（確認一個，保留另一個）
3. **反問**：「你的角色覺得呢？」（讓玩家參與建構）
4. **無法解釋**：「有些事情你的角色可能永遠不會知道。這是間隙的本質。」（使用這個選項要謹慎——每次團務最多一兩次）

## 4.5 劇本框架

### 4.5.1 尋物委託

**核心問題**：找到某個遺失物——但為什麼這個物品如此重要？

**調性**：最接近「偵探故事」的類型。探索、對話、發現——戰鬥較少。

**三幕結構**：

**第一幕：委託**
- 委託人登場——為什麼這個遺失物無法在表層找到？委託人隱瞞了什麼？
- 線索蒐集——物品最後出現的地點、物品與失主的關係、物品的意義
- 門檻定位——與物品相關的門檻在哪裡？（可能在物品遺失的地點、在失主情感最強烈的地點、或在物品本身「想要去」的地方）

**轉折點**：物品不只是「遺失」——物品希望被找到/不希望被找到。物品在間隙中有了自己的「意圖」。

**第二幕：追蹤**
- 間隙中的線索——其他遺失物、收集者的提示、環境中的記憶殘留
- 遭遇收集者/徘徊者——他們可能見過物品或知道它的去向
- 距離扭曲的利用——玩家需要理解物品與失主之間的關係來縮短距離

**轉折點**：物品的位置與預期不同——它在某個與失主有深層連結但失主從未提及的地方。這個地方揭示了委託人隱瞞的秘密。

**第三幕：取回**
- 最終位置的挑戰——可能是危險的間隙區域、或物品被某個生物守護
- 道德選擇——取回物品可能傷害某個與物品建立了連結的間隙生物/徘徊者
- 歸還——當物品回到失主手中，揭露的真相改變了他們的關係

**關鍵場景範例**：
- 物品在「失主記憶中最快樂的地方」的間隙對應位置——但那不是失主告訴玩家的地點
- 收集者持有物品——但它要的不是錢，是「失主為什麼真的需要它回來」

**成功劇本的要點**：
- 遺失物的意義必須比物品本身更重要
- 委託人必須有祕密——但祕密不一定是惡意的
- 間隙中的旅程應該反映遺失物的情感故事

---

### 4.5.2 密封調查

**核心問題**：某個密封空間開始出現異常——為什麼現在？裡面是什麼？

**調性**：恐怖/懸疑。密封空間的壓力逐漸累積，滲漏越來越頻繁。

**三幕結構**：

**第一幕：異常**
- 異常現象——表層出現不該存在的東西、人們做相同的噩夢、某種「不存在」的記憶開始傳播
- 初步調查——追蹤異常的源頭，發現它們指向一個已知的密封空間（或一個未知的）
- 歷史挖掘——找到關於這個密封空間的記錄、傳說、或其他行者的筆記

**轉折點**：密封空間的封印正在失效——不是因為外力破壞，而是因為**內部發生了變化**。裡面的東西……變了。

**第二幕：滲漏**
- 滲漏加劇——異常現象頻率和強度增加。間隙生物開始逃離該區域
- 尋找封印者——如果有封印者的後裔/繼承者，他們可能知道如何修補封印
- 進入密封空間的準備——玩家需要找到鑰匙（往往是一個遺失物）或理解封印的邏輯

**轉折點**：封印不是被入侵者破壞的——是**從內部**。裡面的東西正在主動想要出來。為什麼是現在？

**第三幕：面對**
- 進入密封空間——或決定不進入（加強外部封印可能是更安全的選項）
- 內部真相——裡面的東西不一定是邪惡的。它可能只是想被記住、想被理解、想被釋放
- 最終選擇——完全打開（釋放但需要處理後果）、修補封印（回到原狀）、或……改變內容物（幫助裡面的東西轉化/安息/被記住，從根本上解決問題）

**關鍵場景範例**：
- 玩家發現封印者的日記——但日記的最後幾頁揭示了封印者不是英雄。他們封印這個東西出於恐懼，而不是責任
- 密封空間的看守者開始與玩家對話——它累了。它請求玩家做出封印者沒有做出的選擇

**成功劇本的要點**：
- 密封空間的內容物必須在道德上複雜——不是純粹的怪物
- 歷史必須是可追溯的——玩家能透過調查拼湊出故事
- 最終選擇必須是真的選擇——每個選項都有真實的代價

---

### 4.5.3 間隙氾濫

**核心問題**：間隙正在「溢出」到表層——某處出現了裂口。必須封鎖。

**調性**：災難/動作。時間壓力大，表層與間隙的邊界正在模糊。

**三幕結構**：

**第一幕：溢出**
- 第一個跡象——表層出現明顯的間隙現象（遺失物憑空出現、普通人在 liminal 空間中短暫「滑入」間隙、野生間隙生物在表層被目擊）
- 確認源頭——多個溢出點指向同一個源頭。一個不再穩定的門檻變成了裂口
- 緊急召集——玩家的城市節點動員。不是所有行者都願意幫忙——有些人認為這是「間隙的意志」，不該干預

**轉折點**：裂口不是自然形成的——有人（或某物）刻意製造了它。

**第二幕：控制**
- 封鎖溢出點——玩家需要暫時關閉次要的溢出點來集中處理源頭
- 尋找裂口的「邏輯」——裂口為什麼在這裡？是什麼讓這個門檻爆炸？
- 遭遇表層的混亂——普通人對異常的反應（恐慌、否認、政府介入的初期跡象）

**轉折點**：裂口的製造者現身——另一個行者、一個被間隙改變的普通人、或一個具有意圖的間隙生物。他們的理由可能不是純粹的惡意。

**第三幕：縫合**
- 對抗製造者——不一定是戰鬥。可能是對話、說服、或交易
- 修補裂口——需要某種犧牲（一個遺失物作為錨點、一段記憶作為縫線、或一個行者自願留在門檻中作為「填充」）
- 善後——表層受到的影響無法完全消除。有些人「看到了」。世界變得稍微不如之前穩固

**關鍵場景範例**：
- 玩家在淹沒的間隙區域中前進——空間本身在「融化」，距離和方向完全不可靠
- 裂口的製造者是一個曾經的行者——他認為表層和間隙應該合併，因為「分離是痛苦的」。他的理由來自於失去——他失去了某個無法從間隙中帶回來的人

**成功劇本的要點**：
- 時間壓力必須真實——每次玩家回到表層，狀況都在惡化
- 裂口的製造者必須有可理解的動機
- 最終的解決方案需要玩家付出真實的代價——不是輕鬆的勝利

---

### 4.5.4 迷途者

**核心問題**：一個普通人（非行者）被困在間隙中。必須在間隙病殺死他/她之前找到並帶回。

**調性**：救援/生存。情感核心是連結——幫助一個完全無助的人。

**三幕結構**：

**第一幕：失蹤**
- 委託——來自敏感者（被困者的家屬、朋友、或目擊被困者消失的人）
- 重構事件——被困者為什麼會在間隙中？他們在哪裡、何時、如何滑入？（通常是在 liminal 空間中，在強烈情感狀態下）
- 定位——使用與被困者相關的遺失物作為導航，找到他們的「蹤跡」

**轉折點**：被困者不是意外滑入的——他們是被某個間隙生物「帶走」的。或者更糟：他們是自己走進來的。

**第二幕：追蹤**
- 間隙中的蹤跡——被困者留下的痕跡（他們碰過的遺失物、他們經過時鏡像的反應、收集者的目擊）
- 間隙對被困者的影響——玩家沿途發現被困者的物品，這些物品顯示出被困者的心理狀態正在惡化
- 遭遇引誘/誤導——某個間隙生物可能在誤導玩家，讓被困者保持在間隙中

**轉折點**：找到被困者——但他們不想離開。間隙給了他們表層無法給予的東西（與逝者的重逢、被遺忘的記憶、或被需要的感覺）。

**第三幕：說服**
- 對話——玩家必須說服被困者回到表層。這不是說服檢定——這是角色扮演。玩家需要理解被困者為什麼想留下，並提供一個更好的回去的理由
- 間隙生物的干擾——帶走被困者的生物可能不願放手
- 緊急逃脫——說服成功後，必須在被困者的間隙病達到臨界點之前返回（時間壓力）
- 回到表層——被困者忘記了在間隙中的大部分經歷……但某些東西留下了

**關鍵場景範例**：
- 玩家在間隙中找到被困者——被困者正在與一個鏡像對話。那個鏡像是被困者死去的孩子。孩子看起來如此真實，以至於玩家一瞬間也以為那是真的
- 最終的逃脫——玩家與被困者手牽手在崩潰的間隙空間中奔跑，後方是追趕的間隙生物。被困者不斷回頭——不是看追趕者，是看那個鏡像在遠方揮手

**成功劇本的要點**：
- 被困者必須是有血有肉的角色——有名字、有故事、有讓玩家在乎的理由
- 被困者想留在間隙的原因必須是真實的、令人心碎的
- 最終的說服不是「說教」——是「陪伴」。玩家通過行動展示回去的價值

### 4.5.5 鏡像追逐

**核心問題**：一個強大的鏡像「醒來」了——它不再只是重複，而是開始行動。它想要什麼？

**調性**：心理驚悚。自我認知、身分、鏡像與本體的關係。

**三幕結構**：

**第一幕：覺醒**
- 異常的鏡像——玩家在間隙中遇到的鏡像做出了不該做的事：它回應了。它說了不在循環中的話。它看著玩家——不是模仿，是觀察
- 追蹤——玩家發現這個鏡像在間隙中移動，做著某件事（重複但不完全相同地出現在不同地點）
- 鏡像的「主人」——玩家調查這個鏡像是誰的影像。他們發現這是一個還活著的人——可能是一個普通人，可能是一個敏感者

**轉折點**：鏡像找到了它的「主人」並開始在表層中影響他/她——不是附身，而是更微妙的：主人開始做出鏡像在間隙中做過的動作、說出鏡像說過的話。

**第二幕：雙重身分**
- 接觸主人——主人不知道自己有鏡像。但最近他們開始感到「不對」——記憶缺失、在奇怪的地方醒來、做出自己沒有印象的決定
- 鏡像的意圖——玩家追蹤鏡像的行動，試圖理解它想要什麼。它不是想取代主人——它想做主人從未做過的事。說主人從未說出的話。活出主人壓抑的人生
- 鏡像與主人的同步——隨著鏡像變強，主人變弱。不是被吸取——而是被「解放」。主人不再需要壓抑那些部分了，因為鏡像在替他活出那些部分

**轉折點**：主人知道他/她有鏡像了——不是從玩家那裡得知的，而是自己發現的。而主人不希望鏡像被消滅。鏡像做到了他/她一直想做但不敢做的事。

**第三幕：面對**
- 三方對峙——玩家、主人、鏡像。誰決定鏡像的命運？
- 可能的結局：鏡像被安撫（透過完成它被困住的「未完成的事情」）、鏡像與主人融合（主人變得完整但不同了）、鏡像被分離（成為獨立的間隙存在——某種全新的東西）、或鏡像被強行消散（主人失去了一部分自己）
- 沒有一個結局是完全勝利的。每一個都有代價

**關鍵場景範例**：
- 玩家跟蹤鏡像到表層——發現鏡像站在主人的家門外，看著窗口的燈光。鏡像轉頭看向玩家，說：「我只是想讓他知道……不孤單。」這是鏡像說的第一句原創的話
- 主人在鏡子前與鏡像對話——玩家看著兩個一模一樣的人隔著玻璃交談。一個是「做了一切對的選擇的人」；另一個是「做了所有被放棄的選擇的人」。他們能不能合而為一？

**成功劇本的要點**：
- 主人和鏡像之間的差異必須具體而細膩——不是「好人 vs 壞人」
- 玩家不能只是旁觀者——他們的選擇必須影響結局
- 結局不該是「鏡像被消滅恢復正常」——那太簡單了。最好的結局是某種新的平衡

## 4.6 樣本劇本：〈最後一班車〉

**劇本類型**：尋物委託（混合迷途者元素）
**建議玩家數**：3-5 人
**預估時間**：3-4 次聚會（每次約 3-4 小時）
**調性**：都市孤獨 × 記憶的重量 × 沒有說出口的愛

---

### 劇本摘要

在深夜的最後一班公車上，一名老婦人將一個舊餅乾盒忘在了座位上。這不是普通的遺失物——盒子裡裝著她六十年來寫給已故丈夫的信，從未寄出。當她發現盒子不見時，她開始沿著公車路線尋找——但盒子不在表層了。它滑進了間隙。

玩家被一名敏感者（公車站旁的深夜咖啡館老闆）引介給老婦人。他們必須追蹤盒子在間隙中的蹤跡——沿著夜間公車路線的間隙對應，逐站前進，在盒子被間隙徹底吸收（或被收集者帶走）之前找到它。

但盒子不只是遺失物。老婦人對丈夫的愛、未寄出的信中的每一個字——六十年來，這些情感在間隙中形成了一個微弱的通道。一個門檻。通往她丈夫最後一天所在的地方。

---

### 第一幕：鐵盒子裡的六十年

#### 場景一：深夜咖啡館（表層）

*時間*：凌晨 1:00。最後一班公車開走後半小時。

*地點*：47 號公車路線旁的小咖啡館——「夜航」。老闆阿凱（50 多歲，男性，敏感者）是當地的行者聯絡人。

*氛圍*：咖啡館空無一人，螢光燈的嗡嗡聲比音樂還大。阿凱在擦杯子——擦了十分鐘同一個杯子。

*進入點*：玩家因為各自的原因來到「夜航」。阿凱認識所有本地的行者。他放下杯子，說：「有位太太需要幫忙。不是普通的尋物委託。」

*關鍵對話*：
- 阿凱的描述：「她大概八十歲。每晚都搭最後一班 47 號。今晚她下車時忘了帶一個鐵盒子——舊的、生鏽的餅乾盒。回來找的時候，車已經開走了。我叫她去總站找——車應該停在那裡。但她回來的時候……臉色不對。」
- 阿凱的觀察：「她說車上的盒子不見了。但她說的方式——不是『被偷了』的憤怒。是……恐懼。像盒子不可能不見，但它不見了。我覺得盒子沒有被偷。我覺得它掉下去了。你知道的——『掉下去』。」
- 阿凱無法自己處理——他是敏感者，不是行者。他知道間隙存在，但他無法穿梭。

*線索*：
- 老婦人的名字：林阿嬤（林秀琴）
- 她每晚搭末班車的原因：四十年前她丈夫在醫院過世，她每天去醫院探病——他死後，她沒有停止。每晚搭末班車去醫院，在關閉的大廳坐一小時，然後搭末班車回家。四十年。
- 阿凱手中的另一個線索：今天下午，林阿嬤的丈夫的忌日。她在醫院待得比平常久。

#### 場景二：林阿嬤的公寓（表層）

*時間*：凌晨 2:00。

*地點*：老城區一棟老公寓的五樓。沒有電梯。樓梯間的牆壁貼滿了四十年前的瓷磚圖案。

*氛圍*：公寓整潔但被時間填滿——每一面牆上都掛著照片（大部分是同一對夫婦，從年輕到年老）。電視開著但靜音。茶壺還溫的。

*林阿嬤（NPC）*：
- 外表：八十多歲，背微駝，但眼神清亮。穿著整潔——像是隨時準備出門。
- 性格：溫和但固執。她不是那種「可憐的老人」——她很清楚自己在做什麼。她只是有些事情無法不做。
- 關於盒子：「那不是什麼值錢的東西。只是一個舊餅乾盒。裡面裝的是信。寫給我家老頭的。他走後……我一直寫。寫了六十年。沒有寄出去的信。」
- 關鍵陳述：「我知道這聽起來很蠢。他已經不在了。但我每晚帶著盒子搭車，就好像……他還坐在我旁邊。他知道我在寫什麼。今晚我太匆忙了——我想趕在雨下之前到家。然後盒子就……」
- 她猶豫了。然後說：「你們會覺得我老糊塗了。但我覺得盒子不是被偷的。我覺得它是……自己走的。」

*玩家可以獲得的情報*：
- 老夫婦的完整故事：相識於 1960 年代、結婚、丈夫在工廠工作、丈夫罹病、在醫院過世。四十年來她每天搭末班車去醫院。
- 盒子的詳細描述：紅色鐵盒，原本裝的是喜餅（他們的結婚喜餅）。盒蓋上有輕微的凹痕。裡面大概有兩千多封信。最早的信紙已經泛黃。
- 今晚的特殊性：忌日。她今天在醫院寫了一封新信——「跟他說了孩子們的事。孫子今年考上大學了。他會很高興的。」
- 一個關鍵細節：這封信中斷在一個句子的一半——「我一直想問你……」後面沒有了。她不知道為什麼沒寫完。

#### 場景三：公車總站（表層→間隙入口）

*時間*：凌晨 2:30。

*地點*：47 號路線的公車總站。夜間停車場。十幾輛公車整齊排列。

*表層描述*：停車場的燈光間歇閃爍。老婦人指的那輛公車停在角落——車牌與她描述的一致。車門沒鎖（老司機的習慣）。車內空無一人。空氣中有清潔劑和舊皮革的味道。

*搜尋車內*：
- 座位底下有微弱的痕跡——不是盒子本身，而是盒子「曾經在這裡」的證據。老婦人座位上有一小片剝落的紅色漆片。
- 如果玩家有感知間隙的能力：這個座位的空氣比其他位置更「厚」。老婦人四十年來每晚坐在同一個位置，她的存在磨薄了這裡的現實——這就是盒子滑落的地方。

*間隙入口*：
- 門檻位置：公車的後門。不是門本身——是門與座位之間的空間。一個四十年來被老婦人的儀式性搭乘反覆磨損的位置。
- 門檻類型：記憶門檻（老婦人對丈夫的持續記憶）+ 人造門檻（公車門的反覆開關）的混合。
- 進入間隙：玩家從公車後門的「門與座位之間」穿過。正常的物理動作——側身擠過縫隙——但如果動作正確，你擠進去的不是車外，而是……

#### 場景四：進入間隙——車站候車大廳（間隙層）

*時間*：間隙時間——不確定。

*地點*：中央車站的間隙對應。不是公車站——是火車站。一座不存在於表層的巨大的、空洞的候車大廳。

*氛圍描述*：
第一印象是聲音——或者更確切地說，是聲音的缺乏。你的腳步聲在大廳中迴盪了太長時間，音調比應有的更低。大廳的天花板消失在黑暗中——但不是「太暗看不見」的黑暗，而是「上面本來就沒有東西」的空白。

大廳中央，時刻表顯示器掛在牆上。所有時刻表都停在 23:47。不是故障——是指針拒絕移動。螢幕上的目的地名稱不是你認識的城市。「下一站——」後面沒有字。

牆壁上有四十年來來去去的乘客留下的殘影——一條條模糊的、人形的輪廓，像曝光過度的照片。

*關鍵細節*：
- 地板上有一條微弱的紅色痕跡——鏽跡。像是有人拖著一個鐵盒子走過。從大廳的一端延伸到另一端。
- 沿著鏽跡，每隔一段距離有一小片紙——信紙的碎片。第一片上面寫著：「……今天醫院的花開了，可惜你看不到……」
- 鏽跡指向大廳深處的一扇門——門上標示著「47 號月台」（中央車站沒有 47 號月台）。

*可能的遭遇*：
- 門檻徘徊者出現在大廳的另一端——一個穿著舊式公車司機制服的模糊人影。如果玩家接近，他會指著 47 號月台的方向，然後消失。
- 他是什麼？四十年來載過老婦人的所有末班車司機的集體殘影。他們記得她。

### 第二幕：沿著 47 號路線——逐站的記憶

#### 場景五：醫院等候層（站牌 A 的間隙對應）

*門檻穿過 47 號月台的門後抵達*。

*氛圍描述*：
這是一個永遠在「等候」的空間。走廊向兩端無限延伸，每一扇門後面都是相同的病房——白色床單、空床、窗戶外面只有白色的光。空氣中有消毒水的味道，但不是刺鼻的——是微弱的、舊的，像味道本身也快要被遺忘了。

遠處傳來心跳監視器的聲音——不是一台，是幾十台，在不同的節奏上。有些節奏很穩定，有些……越來越慢。

*關鍵要素*：
- 其中一間病房（唯一一間門半開的）與其他不同——這間的床上有一束乾燥的花。床邊的椅子上有一個凹陷的痕跡——有人在這裡坐了四十年。
- 這是老婦人丈夫最後的病房。她在這裡坐了四十年，每晚，在同一個位置。她的存在如此強烈，以至於間隙中的病床永遠保持了有人來過的狀態。
- 床頭櫃上有一封寫了一半的信——不是盒子裡的。是老婦人丈夫最後一天試圖寫給她但沒寫完的信。紙張泛黃到幾乎透明。能辨認的字：「秀琴，我知道你每天來。我每次都假裝睡著，因為我不知……」

*門檻徘徊者遭遇*：
一個穿著病袍的模糊人影站在病房門口。不是老婦人的丈夫——是一個更古老的徘徊者，一個曾經在這裡迷失的行者。他不知道自己的名字了，但他知道這間病房是「重要的」。他自願站在這裡，確保沒有東西打擾這間病房的記憶。

- **如果玩家尊重他的看守**：他會告訴玩家，盒子「往下走了——往水的方向」。這指向河濱公園（站牌 C）。
- **如果玩家無視他並進入病房**：房間開始「記起」玩家也是病人。玩家需要通過檢定來抵抗空間的暗示（「你應該躺在床上的。你生病了。你需要休息。」）

#### 場景六：老城區舊街道（站牌 B 的間隙對應）

*沿著鏽跡從醫院層往下走（或使用捷徑——醫院的「悲傷」與老城區的「初戀」之間有一條情感通道）*。

*氛圍描述*：
這裡是 1960 年代和現在的雙重曝光。老婦人記憶中的舊街道重疊在現代街道的骨架上——木頭電線桿穿過柏油路長出來；老式腳踏車靠在智慧型手機店門口；一家早已消失的冰果室的招牌在半空中閃爍。

天空是黃昏——永遠的黃昏。這條街的空氣中有烤番薯的香味和某種老牌香皂的味道。

*關鍵要素*：
- 一間舊戲院——在表層已被拆除四十年。但在間隙中，戲院還在營業。海報上的電影是 1963 年的。
- 戲院門口的售票亭中，坐著一個鏡像——年輕的老婦人（二十歲出頭），正在等待某人。她每三十秒轉頭看一次街角。
- 戲院對面——一間冰果室。冰果室裡面的桌子上，有一個紅色的鐵盒子。餅乾盒。

*遺失物收集者遭遇*：
但盒子不是無人看守的。一個遺失物收集者正坐在盒子旁邊——它今天收集的是「情書」。它的身上掛滿了各種年代的信封、紙條、卡片。

- 收集者注意到玩家。它不會主動攻擊——但它對這個盒子特別感興趣。
- 「這個盒子——」（收集者的聲音是許多信紙摩擦的聲音重疊）「——它自己來到這裡的。我只是在看著它。」
- 收集者願意讓玩家拿走盒子，但有條件：它想要盒子中的**一封**信。不是特定的哪一封——是「最誠實的那封」。它要玩家讀完盒子中的信，選出最誠實的一封給它。
- 如果玩家同意並執行：閱讀信件是一個角色扮演場景——玩家大聲讀出老婦人六十年來寫的信。GM 應該準備 3-5 封具體的信的內容。玩家需要選擇。沒有正確答案——但選擇揭示了玩家的價值觀。
- 無論選擇哪一封，收集者接過後會仔細折疊信紙，放入自己身上的「收藏」中。然後它會說：「你們知道嗎——這個盒子本來要去更遠的地方。它不想被帶回去。它不是被遺失的——它是自己走的。」
- 然後收集者指向河的方向。「它在找它的另一半。那些信……它們都在往同一個方向流。」

#### 場景七：河濱的記憶長椅（站牌 C 的間隙對應）

*沿著河的方向，穿過越來越濃的「記憶密度」*。

*氛圍描述*：
一條河——但不是水。河裡流的是……畫面。記憶的碎片。如果你仔細看，你可以看到一對年輕情侶手牽手散步、一個男人單膝跪地、一個老人在夕陽下坐著。

河岸上有一張長椅。長椅面向河。在表層，這張長椅在河濱公園，是老夫婦最喜歡的地方。

在間隙中，長椅周圍的空間被壓縮成了永恆的黃昏。數十個鏡像在此循環——不同年齡的老夫婦，在不同的季節，做著相同的事：一起坐著。

*關鍵要素*：
- 長椅上坐著一個鏡像——老年版本的丈夫。不是年輕的，是老年的——他看起來像他在最後一天的樣子。他是老婦人記憶中丈夫的模樣：消瘦但眼神溫柔。
- 這個鏡像的品質與其他不同——他更「實在」。不只是因為老婦人記得他。而是因為四十年來，她每天帶著那些信經過這裡——她的情感將他「印」得太深了。
- 當玩家接近時，這個鏡像轉頭看他們。其他鏡像都在循環——但他沒有。他只是在等待。

*鏡像丈夫（特殊 NPC）*：
- 他不會說話——不是不能，而是他沒有話要說。他只想聽。
- 如果玩家拿出盒子中的信，讀給他聽——鏡像會閉上眼睛。不是消失，而是變得平靜。
- 如果玩家沒有拿出信——鏡像會伸出手，掌心向上。一個請求。

*情報揭露*：
當玩家在長椅場景中，他們會注意到河中的記憶碎片不只是老婦人的——還有其他人的。這條河是由所有「未說出口的話」構成的。如果玩家在河邊停留太久，他們會開始聽到——不是聲音，而是自己的記憶中的遺憾浮上心頭。間隙病的進程在此加速。

*轉折點*：
玩家在長椅下找到盒子中「缺失的那封信」——老婦人今天寫的、只寫到一半的信：「我一直想問你……」信到這裡斷了。

但如果玩家把這封未完成的信和丈夫的鏡像放在一起——如果把信放在長椅上，坐在鏡像旁邊——信會自己完成。不是魔法，而是老婦人四十年來一直知道答案。她只是不敢寫下來。

完成的信：「我一直想問你——你走的那天，我握著你的手，你最後想說什麼？我知道你盡力了。但我每晚都在想這件事。今晚我終於知道答案了，對不對？你想說的是：『謝謝你每天都來。』我也是。謝謝你每天都在。」

### 第三幕：終點——信件的天空

#### 場景八：情感通道（間隙深處）

*從長椅出發，跟隨已經「完成」的信的指引*。

*氛圍描述*：
空間開始失去建築物和街道的偽裝。玩家正在進入「純粹的間隙」——沒有對應的表層結構。周圍是紙。信紙——從地面長出來、在空中飄浮、構成了牆壁和天花板。墨水的河流在腳下蜿蜒。每一張紙上都寫滿了老婦人的字跡。

這不是盒子裡的兩千封信——這是四千封、六千封。老婦人寫了一輩子的信，從丈夫在世時就開始寫。有些從未被放進盒子。但它們都流向這裡。

*距離扭曲*：
在這裡，距離由「你對收信人的了解程度」決定。如果你理解老婦人為什麼寫這些信——你往前走。如果你不理解——你原地踏步。

#### 場景九：紙與墨的房間（終點）

*通道的盡頭*。

*氛圍描述*：
一個由信件構成的房間。牆壁是層層疊疊的信紙，地板是展開的信，天花板垂掛著信封。房間中央，一個老人坐著——不是鏡像，不是徘徊者。他是……

*GM 選項（選擇一個，不要告訴玩家哪一個）*：

**選項 A**：他是老婦人丈夫在間隙中的「回音」——不是靈魂，不是鬼魂，而是四十年書信創造的集合體。他有自我意識，但知道自己不是真實的。他等待著，因為信指向他——老婦人六十年來的每一個字都在間隙中找到了他。

**選項 B**：他是間隙本身對老婦人的回應。間隙記得她——四十年來每晚同一路線、同一時間、同一個座位。她是間隙見過的最堅持的人。間隙為她創造了這個——不是丈夫，而是「可以被說再見的地方」。

**選項 C**：什麼都沒有。房間是空的。但當玩家走進房間，他們每個人都感覺到了——一個存在。不是視覺的，不是聽覺的，而是……像是有人剛剛離開。椅子上還有餘溫。桌上有一杯不冷的茶。空氣中有一種確切的感覺：被等待的、被愛的感覺。

*選項 C 推薦為預設*——它最符合間隙的哲學（缺席的證據），也最讓玩家參與建構意義。

#### 場景十：決定（終點房間）

無論選擇哪個選項，這個場景的核心是讓玩家做出決定：

*如果選項 C*：
- 玩家到達了一個空房間，但房間中充滿了「他剛離開」的證據。
- 最重要的發現：桌上有一封回信。是老婦人丈夫的筆跡——雖然老婦人說他不識字（這是她後來教他的）。
- 信念完了，所有玩家都聽到了。
- 他們現在需要決定：把這封回信帶給老婦人嗎？還是把盒子放回房間，讓老夫婦的通信在間隙中繼續？

*選擇分支*：

**帶回盒子與回信**：
- 回到表層。見老婦人。把盒子和回信交給她。
- 老婦人讀了回信。她哭了——但哭完之後，她問：「所以我不用再繼續搭末班車了嗎？」
- 她的儀式結束了。下週開始，她不再每晚搭 47 號末班車。
- 但相應地——玩家注意到，河濱公園長椅上的鏡像消失了。那個空間恢復了「正常」的間隙狀態。老夫婦的故事結束了。
- 這是一個結束。不是快樂的，不是悲傷的——是完成的。

**把盒子留在間隙中**：
- 玩家決定不帶走盒子。老婦人的信繼續流向那個房間。
- 回到表層。老婦人仍然沒有盒子。但玩家可以告訴她：「盒子在一個好地方。有人收到了。」
- 老婦人沉默了一陣。然後她笑了。「那麼——我繼續寫。」
- 什麼都沒有改變。但什麼都改變了。因為老婦人現在知道——不是相信，是知道——有人在那邊收信。
- 玩家的回報：他們發現自己多了一個穩定的門檻——47 號末班車。只要老婦人還在寫信，這個門檻就保持開放。這是極其罕見的禮物。

**第三種可能**（如果玩家想到了）：
- 複製回信。將複製品帶回老婦人，原件留在房間中。
- 這是最接近「完美」的結局——但不是免費的。複製回信需要一個記憶結晶作為「紙」。玩家需要犧牲一個自己的記憶——一個具體的、珍貴的記憶——來印出回信。那個記憶會變得模糊，像隔著霧看。

---

### 劇本結語

無論玩家做出什麼選擇，〈最後一班車〉的結局都不是「任務完成」。而是：

- 他們見證了一場持續六十年的對話。
- 他們理解了一個事實：有些東西之所以在間隙中，不是因為被遺忘——而是因為還沒有到達目的地。
- 他們在 47 號末班車的路線上留下了一些東西——可能是一個新的門檻、一個記憶、或者只是老婦人不再需要獨自搭車的改變。

最後的場景：玩家回到「夜航」咖啡館。阿凱在擦杯子——同一個杯子。他抬起頭。

「所以——她還好嗎？」

玩家回答。然後窗外，47 號末班車開過。車內亮著燈，空無一人。

或者——裡面坐著一個老人，看向窗外，微微點頭。

（GM 決定。）

## 4.7 快速參考：GM 檢核表

### 每次團務前

- [ ] 確認了時間流速的觸發條件
- [ ] 準備了至少一個有意義的遺失物（使用設計模板）
- [ ] 每個關鍵 NPC 有：名字、動機、一個祕密
- [ ] 間隙生物的遭遇有：理解線索、玩家選擇、後果

- [ ] 進入間隙時使用三步轉換（感官減法→感官轉換→第一印象）
- [ ] 保持 80/20 線索比例
- [ ] 推進間隙病時確保它是「有趣的不安」而非「挫折」
- [ ] 回到表層時讓玩家描述感知差異
- [ ] 每個場景至少有一個「缺席的證據」

### 每次團務後

- [ ] 記錄玩家建立/改變的門檻關係
- [ ] 記錄被帶回表層的遺失物及其命運
- [ ] 記錄未解決的線索——它們可能在未來的劇本中回歸
