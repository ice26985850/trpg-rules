# 劇本 1：〈醒來〉
| 項目 | 內容 |
|------|------|
| **類型** | 角色起源（教學） |
| **適合印記** | 0（創角後第一場） |
| **聚會次數** | 1 次 |
| **核心屬性** | 全部（教學性檢定） |
| **難度** | ☆（教學） |

### 開場

你不是接到委託才來的。你是**醒了**。

今天早上你像往常一樣走進辦公室的玻璃門——但玻璃的另一側不是大廳。是一條走廊。一條你從未見過的、比應有的長了三倍的走廊。你回頭——玻璃門還在，但門外是灰白色的光，沒有街道、沒有人。

你被困在間隙中了。

### NPC

| NPC | 類型 | 資訊 |
|-----|------|------|
| **老莫** | 前代行者／導師 | 60多歲退休行者。在間隙中「釣魚」——用記憶結晶的碎片當餌 |
| **鏡像（玩家）** | 鏡像（非敵意） | 在走廊另一端模仿你的動作——但牠先你一步發現了出口 |

### 場景

1. **醒來**：玩家在間隙中醒來。GM 描述間隙的感官（光線來自錯誤方向、腳步聲延遲、空氣比表層稠密）。玩家進行第一次被動覺察（10+覺察）感知空間異常。（引用：玩家手冊 §4.1 被動檢定）

2. **遇見老莫**：老莫坐在走廊中間的折疊椅上，旁邊放著保溫瓶。「新人啊？別緊張。你現在在間隙——空間之間的夾層。先深呼吸。」老莫教玩家三個基本行動：確認層級（定錨 難度等級（DC） 10）、移動（穿梭 難度等級（DC） 8）、觀察表層（覺察 難度等級（DC） 10）。（引用：玩家手冊 §5.1 行動清單）

3. **第一次搜索**：老莫指向走廊轉角——「看到那個發光的東西嗎？那是遺失物。去拿回來。」拾遺 難度等級（DC） 6（全局-2後）找到一個普通遺失物（一串鑰匙）。（引用：玩家手冊 §5.1 遺失物品質表）

4. **鏡像出現**：走廊另一端出現玩家的鏡像。老莫：「別怕。鏡像不會傷害你——至少現在不會。但你必須看著牠退出間隙。永遠不要背對鏡像。」玩家需進行交涉 難度等級（DC） 8（與鏡像的非語言互動——保持眼神接觸，緩慢後退）。（引用：GM手冊 §3.3.1-C 鏡像規則）

5. **找到出口**：老莫指出門檻——辦公室的玻璃門（天然門檻 難度等級（DC） 6）。穿梭檢定。成功→回到表層。失敗→老莫幫你穩住，再試一次（優勢）。（引用：玩家手冊 §5.1 穿梭檢定）

6. **回到表層**：玩家回到辦公室。時間只過了 3 分鐘。同事沒注意到你離開。但你注意到了——玻璃門的門框上有一道微弱的金色殘光。你看得到間隙了。永遠看得到。

### 獎勵

- 歸還印記 × 0（教學劇本不計入）
- 老莫成為聯絡人（幕間可拜訪——拾遺知識 +2）
- 獲得第一件遺失物：一串舊鑰匙（普通遺失物——來源不明）

### 夥伴招募

- **老莫**：在此劇本無法招募（他是導師型 NPC，在 Tier 3 後可成為夥伴）
