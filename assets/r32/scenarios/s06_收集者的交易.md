# 劇本 6：〈收集者的交易〉
| 項目 | 內容 |
|------|------|
| **類型** | 交涉 / 情報蒐集 |
| **適合印記** | 4-6 |
| **聚會次數** | 1-2 次 |
| **核心屬性** | 交涉、拾遺 |
| **難度** | ★★★ |

### 開場

你在間隙中注意到一個異常——某個區域的遺失物正在「移動」。它們不是被拾取——而是自己在改變位置。追蹤這現象，你發現了一個極其古老的遺失物收集者。牠不是普通的收集者——牠已經在間隙中待了超過一千年。牠的「收藏」中包含著失傳的間隙知識。

### NPC

| NPC | 資訊 |
|-----|------|
| **千年收集者** | 最古老的間隙生物之一。不是人類轉化的——是一把漢朝銅鏡在意識沉積中「醒來」 |
| **三個小型收集者** | 千年收集者的「子嗣」。各自守護一件關鍵物品 |
| **老莫（可選）** | 若已招募為夥伴，可提供千年收集者的歷史背景 |

### 遺失物

| 遺失物 | 品質 | 單人 難度等級（DC） | 守護者 |
|--------|------|:---:|------|
| 漢朝銅鏡碎片 | 間隙造物 | 16 | 收集者 A（需要一首詩） |
| 失傳的間隙地圖 | 記憶結晶 | 13 | 收集者 B（需要一段沉默） |
| 密封空間鑰匙 | 間隙造物 | 16 | 收集者 C（需要一個名字） |

### 場景

1. **追蹤現象**：覺察 難度等級（DC） 8 發現遺失物的移動軌跡。穿梭 難度等級（DC） 8 追蹤至一個「收集者巢穴」。
2. **第一次接觸**：千年收集者不敵意——牠好奇。交涉 難度等級（DC） 12 建立初步對話。牠說話的方式像「許多信紙摩擦的聲音重疊」。
3. **三個試煉**：千年收集者願意分享知識——前提是你通過三個「子嗣」的考驗：
   - **收集者 A**：要一首詩。玩家需即興創作或背誦一首與「失去」相關的詩。
   - **收集者 B**：要一段沉默。玩家需保持沉默 3 回合——期間 GM 描述間隙中的異常現象，測試玩家是否開口。
   - **收集者 C**：要一個名字。需從老莫或其他行者處獲得銅鏡主人的名字。
4. **收穫**：完成試煉後，千年收集者展示失傳的間隙地圖——顯示附近一個從未被發現的密封空間位置（為劇本 9/10 埋下伏筆）。
5. **額外收穫**：可選擇用一件遺失物與千年收集者交換「間隙知識標記」——永久性的交涉優勢（對所有收集者交涉 難度等級（DC） -2）。

### 獎勵

- 歸還印記 × 1（不來自歸還——來自「知識的交換」）
- 銅鏡碎片（間隙造物——可在密封空間中作為光源，照亮隱藏的封印標記）
- 間隙知識標記（對收集者交涉永久優勢）
- 解鎖新密封空間位置（劇本 9/10 的伏筆）
