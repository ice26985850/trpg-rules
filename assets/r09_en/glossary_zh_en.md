# 奧祕溯源 TRPG — English Glossary (locked terms)

Set English name: **Arcane Origins TRPG**
Working title in docs: `# Arcane Origins TRPG — Player Rulebook` / `# Arcane Origins TRPG — GM Rulebook`

## Core dice / checks
- 2d10 骰系統 / 核心引擎：2d10 + 屬性值 → **2d10 system; check result = 2d10 + Attribute + Proficiency + Facility bonus + other modifiers**
- 大成功（雙10）→ **Critical Success (double 10)**
- 大失敗（雙1）→ **Critical Failure (double 1)**
- 優勢 → **Advantage** (roll 4d10, take highest two; ≈ +3.3 expected)
- 劣勢 → **Disadvantage** (roll 4d10, take lowest two; ≈ −3.3 expected)
- 難度等級（DC）→ **Difficulty Class (DC)**
- 專精加值 → **Proficiency bonus**
- 設施加值 → **Facility bonus**

## Five Attributes (五大屬性) — keep abbreviations
- 感知 → **Perception (PER)**
- 理論 → **Theory (THY)**
- 技藝 → **Craft (CRA)**
- 意志 → **Will (WIL)**
- 博學 → **Erudition (ERU)**
- Note: attribute value is used directly as a modifier (attribute 5 = +5).

## Derived stats (衍生屬性) — keep abbreviations
- 靈性池 → **Spirit Pool (SP)** = Will×3 + Theory
- 安全閾值 → **Safety Threshold (ST)** = Craft + floor(Will/2) + Lab Level
- 研究行動點 → **Research Action Points (RAP)** = 3 + (Theory≥5: +1) + (Chief Apprentice: +1), max 5
- 碎片容量 → **Shard Capacity (SC)** = Theory + Erudition + Library Level
- 生命值 → **HP** = 15 + Will
- 法術書容量 → **Spellbook Capacity (SBC)** = Theory + Erudition
- 瀕死 → **Dying**
- 死亡豁免 → **Death Saving Throw**
- 短休 → **Short Rest**; 長休 → **Long Rest**
- 重擊 → **Critical Hit**

## Spell-invention system (發明法術)
- 碎片 → **Shard**
- 法術 = 元素（1–3）+ 形式（1–2）+ 介質 + 約束 → **Spell = Element (1–3) + Form (1–2) + Medium + Constraint**
- 元素 → **Element**; 形式 → **Form**; 介質 → **Medium**; 約束 → **Constraint**
- 品質（★ 到 ★★★★★）→ **Quality** (Apprentice ★ … Legendary ★★★★★)
- 學徒級 → **Apprentice-grade**; 傳奇級 → **Legendary-grade**
- 法術書 → **Spellbook**

### Elements (元素) — rarity tiers
- 基礎元素：火/水/風/土 → **Basic Elements: Fire / Water / Wind / Earth**
- 進階元素：雷/冰/光/暗 → **Advanced Elements: Lightning / Ice / Light / Dark**
- 高階元素：空間/時間/生命/死亡 → **High Elements: Space / Time / Life / Death**
- 禁忌元素：血液/靈魂/混沌 → **Taboo Elements: Blood / Soul / Chaos**

## Research loop (研究迴圈)
- 觀察 → **Observe** (Perception)
- 假設 → **Hypothesize** (Theory)
- 實驗 → **Experiment** (Craft)
- 文獻研究 → **Bibliographic research** (Erudition)
- 安全閾值 → **Safety Threshold** (exceeded → accident)
- d20 事故表 → **d20 Accident Table**
- 實驗室 → **Laboratory**; 實驗室等級 → **Laboratory Level**
- 圖書館 → **Library**; 圖書館等級 → **Library Level**
