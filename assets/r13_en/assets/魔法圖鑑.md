# Exiles of the Empire TRPG — Psychic Power Compendium (Psychic Powers)

> This compendium compiles the "Universal Psychic Powers" and "Librarian Exclusive" ability tables from the Player's Handbook §3.9 Psychic System, for quick reference by Psykers and Librarian characters. In this game, "magic" is Psychic Powers drawn from the Warp.

## Psychic Use Procedure

```
1. Declare the psychic power and its Intensity
2. Pay Psychic Points (PP)
3. Roll Psychic Test: d100 ≤ Mind×10 + Psi×5
4. vs Difficulty Class (DC)
5. Success → takes effect; Failure → triggers Warp phenomenon
```
