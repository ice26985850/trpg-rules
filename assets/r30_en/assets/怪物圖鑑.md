# Monster Compendium

> An independent database of enemies, Bosses, and Epic Monsters for the *League of Legends TRPG*.
> This file is for reference/lookup purposes. For rules (enemy AI, damage benchmarks, encounter design), see `英雄聯盟TRPG_GM規則書.md`.
> Values use the "Full Name (ABBR)" format. The "Five-Player Party" column is the baseline for a standard 5-player squad; the "Solo" column is the scaled value for Duet (1 player + 1 GM) mode.
