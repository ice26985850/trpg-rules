# League of Legends TRPG — DLC Augment Device v0.2

> This document is an optional expansion module for League of Legends TRPG, adapted from the League of Legends Arena (random single-mid: big melee) augment system.
> Before use, read the main rulebook `LOL_TRPG_Rulebook_v0.2.md`.

---

## I. System Overview

Augment Devices are the core mechanic of Arena mode — in each match, players acquire random enhancements at key rounds, building unique combat styles. This DLC converts them into a Roguelike growth system usable in TRPG.

### Correspondence with the Original Arena

| Arena Original | TRPG Adaptation |
|-----------|----------|
| Silver Augment | Common Augment |
| Gold Augment | Rare Augment |
| Prismatic Augment | Legendary Augment |
| Champion-Exclusive Augment | Archetype-Exclusive Augment |
| Pick augment each round | Acquired at chapter milestones |
| Arena 2v2 | Standard 5-person party |

---

## II. Core Rules

### 2.1 Slots

Each hero may hold up to **4 Augment Devices** at once. A 5th requires discarding one.

### 2.2 Acquisition Timing

| Timing | Rarity | Method |
|------|:--:|------|
| Chapter start | Common | GM grants 2 Common (player picks 1) |
| After Boss fight | Rare–Legendary | Each player draws 1 after defeating Boss (d20 determines rarity) |
| Key story point | Rare | GM reward |
| Shop | Common–Rare | Common 500 gold / Rare 1,500 gold (limit 1 per Recall) |

### 2.3 Draw Method (d20)

| d20 | Rarity | Count |
|:--:|:--:|:--:|
| 1–10 | Common (Silver) | Draw 3 from Common pool, pick 1 |
| 11–16 | Rare (Gold) | Draw 2 from Rare pool, pick 1 |
| 17–19 | Rare (Gold) | Draw 3 from Rare pool, pick 1 |
| 20 | Legendary (Prismatic) | Draw 2 from Legendary pool, pick 1 |

### 2.4 Campaign Retention

At the end of each chapter, players may choose **1** Augment Device to keep into the next chapter. The rest all dissipate. This lets long campaigns gradually build a signature combo.

## VIII. GM Quick Run Guide

### Augment Distribution Pace for a Single Session (2–4 hours)

| Timing | Distribution |
|:--:|------|
| Session start | 2 Common each (pick 1) |
| First Recall (around round 10) | Shop sells Common |
| Before Boss fight | Draw 1 Rare each |
| Before final battle | Draw 1 Legendary each (d20 ≥ 17) |

### Theme Pools

| Pool Name | Suitable Campaign |
|------|------|
| Arena Standard Pool | Universal (all augments mixed) |
| Offense-Specialized Pool | Fast-paced combat parties |
| Survival-Specialized Pool | High-difficulty Boss fights |
| Spell-Themed Pool | Mage/Support-heavy parties |

### Balance Adjustments

| Problem | Adjustment |
|------|------|
| Legendary too strong | Max 1 person per party may hold a Legendary |
| Too many | Lower per-person cap to 3 |
| Choice paralysis | Switch to random distribution (no choice) |
