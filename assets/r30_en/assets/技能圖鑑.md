## I. Skill Structure

### Level Growth Rules
- Q / W / E: max level 5, each level increases damage/range/duration
- R (Ultimate): max level 3; unlocked at Lv.6 (Lv.1), auto Lv.2 at Lv.11, auto Lv.3 at Lv.16
- Cooldown Reduction (CDR) cap 40%; every 10% CDR reduces cooldown by 1 round (minimum 1 round)

### Hit Type Legend

| Tag | Meaning | Check Formula |
|------|------|----------|
| **[Auto-Hit]** | single-target lock-on / self-buff / aura | no roll needed |
| **[Directed Projectile]** | projectile skill requiring aim direction | d20 + attribute modifier + PB vs Evasion DC (10 + MS modifier) |
| **[Area Check]** | AOE area skill | same as above, center cell DC-2 |
| **[Locked Target]** | aimed single-target skill | auto-hit (must be within range and line of sight) |
| **[Channeled]** | skill requiring sustained casting | can be interrupted while channeling (on taking damage requires DC12 Constitution (CON) save) |

### Attribute Modifier Sources
- **AGI modifier** (physical/ranged): Assassin Q/W/R, Warrior Q/E/R, Marksman Q/E/R
- **INT modifier** (magic projectile): Mage Q/W/R, Support E
- **Mixed modifier** ((AGI+INT)/2): Assassin E, Warrior W
- **Auto-Hit**: self-buff, locked target, aura, heal/shield types

## IX. Skill Design Notes

### Numerical Benchmarks
- Lv.1 Q ≈ 90-110 damage (vs ~600 HP, about 15-18%) ✓
- Lv.18 full-build Q ≈ 300-450 damage (vs ~3500 HP, about 8-13%) ✓
- Lv.1 R ≈ 180-240 damage (vs ~600 HP, about 30-40%) ✓
- Lv.18 R ≈ 600-900 damage (vs ~3500 HP, about 17-26%) ✓

### Expected Hit Rate
- Directed Projectile vs Evasion DC=12 (Lv.1 base hit 55%) → fits MOBA "small skills can miss"
- Area Check center DC-2 (=10, hit 65%) → AOE center should be easier to hit
- Auto-Hit / Locked Target → guaranteed mechanic, ensures every archetype has steady damage output

### Room for Expansion
- Each archetype reserves slots for templates 6-8 (can be added in later versions)
- Templates can be mixed (players may pick skills across templates with GM permission)
- Custom skill rules: GMs may reference the existing template value framework to let players create their own skills

## XI. Cross-Archetype Skill Mixing (Optional Rule)

The GM may allow players to mix skills across templates within the same archetype (e.g., Assassin A-Q + Assassin B-W + Assassin C-E + Assassin D-R). When mixing, follow these principles:

### Mixing Rules
1. Q/W/E/R each come from a different template (encourages tactical diversity)
2. Total cooldown sum does not exceed 25 rounds (Q+W+E+R cooldown total)
3. At least 1 [Auto-Hit] skill (ensures guaranteed damage output)
4. At least 1 [Directed Projectile] or [Area Check] skill (ensures a skill-shooting experience)

### Recommended Mix Examples

**"Versatile Assassin"**:
- Q = Template A · Shadow Strike (burst)
- W = Template B · Shadow Clone (mobility)
- E = Template D · Shadow Step (stealth)
- R = Template C · Lethal Toxin (harvest)
→ Burst + mobility + stealth + DoT harvest, an all-round assassin

**"Control Mage"**:
- Q = Template A · Arcane Missile (poke)
- W = Template B · Curse of Weakness (debuff)
- E = Template C · Static Blast (damage amplifier setup)
- R = Template F · Spellban Ward (counter)
→ Poke → debuff → amplify → counter, a perfect control chain
