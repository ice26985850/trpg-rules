# s10_Solo Scenario Supplement (1 Player + 1 GM Duet Mode · Solo Scenario)

# League of Legends TRPG — Solo Scenario Supplement v0.2

> This document is a scenario adaptation guide for the 1 Player + 1 GM (Duet) mode.
> Must be used together with `adventures_campaign_v0.2.md` (Campaign Script Collection) and `solo_rules_v0.2.md` (Solo Rules Supplement).
> Each chapter references the specific encounters of the original scenario and provides adjustment data for the solo version.

---

## I. General Adaptation Principles

All encounters in the campaign scenarios are automatically adjusted by the following rules (no need to calculate each one by hand):

| Adjustment | Formula | Source |
|------|------|------|
| Enemy Count | Original Count × 0.4 (round up, minimum 1) | `solo_rules_v0.2.md` §4.1 |
| Boss HP | Original HP × 0.35 | `solo_rules_v0.2.md` §4.2 |
| Boss Phases | 3 phases merged into 2 | `solo_rules_v0.2.md` §4.3 |
| Group Check | Changed to solo check, DC −5 | — |
| EXP Reward | Keep original value (fast solo leveling) | — |
| Gold Reward | Keep original value | — |

> Reference: Original boss data in `adventures_campaign_v0.2.md`, Part One Boss fight, original HP 800.

| Attribute | Value |
|------|:--:|
| HP | **280** (orig. 800 × 0.35) |
| AD | 60 (unchanged — already painful enough for solo) |

- **P1 (100%-40% HP)**: Alternately uses Spell-Suppression Bomb + Spell-Suppression Field; summons **1 Forge Golem** (HP 200)
