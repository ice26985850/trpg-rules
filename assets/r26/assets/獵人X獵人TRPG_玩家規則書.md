# 第一章：核心規則

本章定義本遊戲的骰子系統、屬性框架、技能檢定與難度階梯——一切遊戲行動的判定基礎。

---

## 1-1 骰子系統

本遊戲使用 **d20 核心系統**：所有行動成敗由一顆 20 面骰決定。

**基本公式：**
```
d20 + 屬性修正 + 熟練加值 ≥ DC（難度等級） → 成功
```

---

## 1-2 六大基礎屬性

所有角色由六項核心屬性定義，數值範圍為 1-20（人類常規範圍 8-18）。

| 屬性 | 縮寫 | 含義 | 主要影響 |
|------|------|------|----------|
| 體質 | 體質（CON） | 身體強度、耐力、生命力 | 生命值（HP）、負重、強化系適性 |
| 敏捷 | 敏捷（DEX） | 速度、反應、靈活度 | 防禦等級（AC）、先攻、變化系適性 |
| 感知 | 感知（PER） | 觀察力、直覺、感官敏銳 | 察覺、追跡、放出系適性 |
| 智力 | 智力（INT） | 分析、記憶、策略 | 戰術、念知識、具現化系適性 |
| 意志 | 意志（WIL） | 精神力、決心、抗壓 | 念量（SP）、念防禦、操作系適性 |
| 魅力 | 魅力（CHA） | 領袖氣質、說服、存在感 | 交涉、威嚇、特質系適性 |

### 屬性值 → 修正值映射

```
修正值 = ⌊(屬性值 - 10) / 2⌋（向下取整）
```

| 屬性值 | 修正值 | 描述 |
|:---:|:---:|------|
| 1 | −5 | 幾乎無法自理 |
| 2-3 | −4 | 極度虛弱 |
| 4-5 | −3 | 明顯缺陷 |
| 6-7 | −2 | 低於常人 |
| 8-9 | −1 | 稍弱 |
| 10-11 | +0 | 普通人水準 |
| 12-13 | +1 | 略高於常人 |
| 14-15 | +2 | 明顯優秀（獵人考試合格者常見） |
| 16-17 | +3 | 天賦異稟（專業獵人水準） |
| 18-19 | +4 | 頂尖級別（星級獵人） |
| 20 | +5 | 人類極限（會長級別） |

## 1-6 檢定規則

### 標準檢定

```
d20 + 屬性修正 + 熟練加值 + 其他加值 ≥ DC → 成功
```

**自然 20（大成功）：** 自動成功，主持人（GM） 給予額外好處。
**自然 1（大失敗）：** 自動失敗，可能附帶輕微副作用。

### 對抗檢定

```
主動方：d20 + 屬性修正 + 熟練加值
被動方：d20 + 屬性修正 + 熟練加值
主動方 ≥ 被動方 → 主動方勝出
```

平手時屬性修正較高者勝；仍平手則維持現狀。

### 團隊檢定

- 協助者需具有該技能的**熟練**或以上等級
- 協助者擲 難度等級（DC） 10 檢定，成功則主力 +2（不疊加）
- 多人同時嘗試：至少半數成功則團隊成功

### 優勢／劣勢

- **優勢：** 擲 2d20，取較高者
- **劣勢：** 擲 2d20，取較低者
- 優勢/劣勢互斥，有其中之一時忽略其他情境加值

| 基礎成功率 | 優勢後 | 劣勢後 | 等效加值 |
|:---:|:---:|:---:|:---:|
| 30% | 51.0% | 9.0% | ≈ +4.2 |
| 50% | 75.0% | 25.0% | ≈ +5.0 |
| 65% | 87.8% | 42.3% | ≈ +4.6 |

## 2-5 念能力設計系統（制約與誓約）

這是本系統最核心的特色。玩家不只是選技能，而是**從零設計自己的念能力**。

### 設計流程

```
1. 確認主系 → 確定能力類型
2. 定義基本效果（決定基礎 SP 消耗）
3. 疊加制約與誓約（獲取 BP）
4. 消耗 BP 增強能力（增加傷害／範圍／持續／效果）
5. 計算最終 SP 消耗
6. GM 審核
```

## 3-1 戰鬥框架

### 回合結構（每回合 10 階段）

| 階段 | 內容 |
|:---:|------|
| 1 | 先攻判定 |
| 2 | 回合開始（持續效果觸發） |
| 3 | **宣告行動**（先攻低者先宣告，模擬「先讀」） |
| 4 | **念量分配**（攻擊／防禦／特殊三區） |
| 5 | 執行行動（先攻高者先行動） |
| 6 | 防禦反應（閃避／對抗／藉機攻擊） |
| 7 | 命中判定 |
| 8 | 傷害計算 |
| 9 | 狀態效果結算 |
| 10 | 回合結束 |

### 先攻規則

- **先攻值** = 敏捷修正 + 感知修正
- 先攻值最高者先行動
- 平手時敏捷修正高者優先，仍平手則擲 d20 決定
- **延遲：** 可自願降低先攻順位
- **準備：** 宣告「若 X 發生則執行 Y」，X 發生時以反應動作執行 Y
- **突襲輪：** 未被察覺的一方獲得一整輪先行動

### 動作經濟

| 動作類型 | 每回合 | 念量（SP） 消耗 | 說明 |
|------|:---:|------|------|
| **標準動作** | 1 次 | — | 攻擊、念能力、使用物品 |
| **移動動作** | 1 次 | 0 | 移動力 = 敏捷值（公尺） |
| **輔助動作** | 1 次 | 依動作 | 切換武器、喝藥水、簡短對話 |
| **反應動作** | 1 次 | 依動作 | 藉機攻擊、閃避、已準備行動 |
| **自由動作** | 不限 | 0 | 說話、放手、表情 |

### 宣告逆序制

- **先攻低者先宣告行動**，先攻高者可後發制人
- 宣言後不可更改（除非使用「流」的即時調整）
- 這是獵人戰鬥的獨有特色——模擬戰鬥中的「先讀」

## 3-2 命中與傷害

### 命中公式

**攻擊檢定 = d20 + 對應屬性修正 + 對應戰鬥技能熟練加值**

| 攻擊類型 | 對應技能 | 屬性修正 | 對抗 |
|------|------|------|:---:|
| 物理近戰（精準型） | 近戰（精準型） | 敏捷修正 | 防禦等級（AC） |
| 物理近戰（力量型） | 近戰（力量型） | 體質修正 | 防禦等級（AC） |
| 物理遠程 | 射擊 | 敏捷修正 | 防禦等級（AC） |
| 念攻擊（直擊型） | 念攻擊（直擊型） | 意志修正 | 防禦等級（AC） |
| 念攻擊（操控型） | 念攻擊（操控型） | 智力修正 | 防禦等級（AC） |

> **熟練加值來自技能熟練等級：** 未熟練 +0／熟練 +2／專精 +4／大師 +6。創角時如未將熟練點分配給戰鬥技能，該項攻擊使用 +0。

### 防禦等級（AC）

```
AC = 10 + 敏捷修正 + 念防禦加成 + 掩護加成 + 裝備加成
```

- 攻擊方 d20 + 加值 ≥ 目標 防禦等級（AC） → 命中
- 自然 20：必定命中，暴擊（武器傷害骰 ×2）
- 自然 1：必定失手

### 物理傷害

```
物理傷害 = 武器基礎傷害骰 + 屬性修正 + 其他加成 − 目標物理減傷
```

### 念攻擊傷害

```
念攻擊傷害 = 能力基礎傷害骰 + 意志修正 + 念量分配加成 + BP 增強 − 目標念防禦
```

- **念防禦對物理攻擊：** 僅提供 防禦等級（AC） 加成（不直接減傷）
- **念防禦對念攻擊：** 直接從傷害中扣除（例如念防禦 3 → −3 點念傷害）

### 傷害倍率

## 3-6 念量分配系統（流）

### 三區分配公式

每回合宣告念量在三個區域的分配比例（合計 100%）：

| 區域 | 公式 | 上限 |
|------|------|:---:|
| 攻擊區（A%） | 攻擊加成 = ⌊練加成 × (A% + 40%)⌋ | 70%（練 Lv.3+ 可 80%） |
| 防禦區（D%） | 防禦加成 = ⌊練加成 × (D% + 40%)⌋ | 70%（同上） |
| 特殊區（S%） | 效果倍率 = 1 + ((練加成 × (S% + 40%)) ÷ 10) | 70%（同上） |

**下限：** 任一區域最低 10%。

**範例——練 Lv.3（加成 +5），分配 A50% / D30% / S20%：**
- 攻擊加成 = ⌊5 × (0.5 + 0.4)⌋ = ⌊4.5⌋ = **+4**（未分配則 +2）
- 防禦加成 = ⌊5 × (0.3 + 0.4)⌋ = ⌊3.5⌋ = **+3**（未分配則 +2）
- 特殊倍率 = 1 + ((5 × (0.2 + 0.4)) ÷ 10) = 1 + 0.3 = **1.30**

> **設計意圖：** +40% 基準確保即使只分配最低 10%，也能獲得 50% 的練加成效果（而非接近零）。分配差異從 +2~+7 之間變化——足以讓每回合的分配決定產生意義。

### 流（Ryu）的即時調整

| 流 Lv. | 調整時機 |
|:---:|------|
| Lv.1 | 僅在回合開始時分配 |
| Lv.2 | 可在標準動作後進行一次微調（調整上限 20%） |
| Lv.3 | 可在任意時點調整（維持上限 20%） |
| Lv.4 | 可在任意時點無限制調整 |

### 戰術欺騙

玩家可「宣告」一種分配比例（讓對手聽到），但在自己回合實際行動時使用不同的分配——前提是擁有足夠的流熟練度。這是再現獵人戰鬥中「互相欺騙念量配置」的核心機制。

## 3-9 死亡與重傷
