# 第二章：怪物與 非玩家角色（NPC） 設計

> ▶ 敵方角色完整數值與弱點／掉落資料請見《怪物圖鑑》；傳說級與特殊物品請見《物品圖鑑》。

## 2-1 挑戰等級（CR）與 遭遇點數（EP）

> **遭遇點數（EP）（遭遇點數，Encounter Points）** 是 主持人（GM） 用於構建遭遇預算的內部數值，**不是**發給玩家的角色 經驗點（XP）。角色 經驗點（XP） 請參閱玩家手冊 §2-9。

| 挑戰等級（CR） | 對應成長階段 | 遭遇點數（EP） 值 | 威脅程度 |
|:---:|------|:---:|------|
| 1/4 | 新人雜魚 | 25 遭遇點數（EP） | 單人可輕鬆應對 |
| 1/2 | 新人 頭目（BOSS） | 50 遭遇點數（EP） | 新人團的階段性威脅 |
| 1 | 見習獵人級 | 100 遭遇點數（EP） | 見習獵人的對等挑戰 |
| 2-3 | 見習→合格級 | 150-300 遭遇點數（EP） | 需要團隊合作 |
| 4-5 | 合格獵人級 | 400-500 遭遇點數（EP） | 合格獵人的硬仗 |
| 6-8 | 專業獵人級 | 600-900 遭遇點數（EP） | 專業獵人面臨的真正威脅 |
| 9-12 | 星級獵人級 | 1200-1800 遭遇點數（EP） | 星級獵人級的強敵 |
| 13-15+ | 傳說級 | 2000+ 遭遇點數（EP） | 會長級／王級威脅 |

## 2-2 三級 非玩家角色（NPC） 模板

### 雜魚級（CR 1/4 ~ 1）

| 屬性 | 範圍 |
|------|:---:|
| 生命值（HP） | 15-40 |
| 防禦等級（AC） | 10-12 |
| 主要攻擊 | 1d6 ~ 2d6 |
| 念量（SP） | 10-25 |
| 念能力 | 0-1 個（基礎） |

**典型角色：** 普通黑幫成員、業餘格鬥家、魔獸幼體

**戰術 AI：** 直接攻擊最近目標、生命值（HP）<50% 時逃跑

### 中堅級（CR 2 ~ 5）

| 屬性 | 範圍 |
|------|:---:|
| 生命值（HP） | 40-90 |
| 防禦等級（AC） | 12-15 |
| 主要攻擊 | 2d6 ~ 3d6+ |
| 念量（SP） | 25-60 |
| 念能力 | 1-2 個 |

**典型角色：** 職業獵人、幻獸、黑幫幹部、天空競技場樓主

**戰術 AI：** 優先攻擊施法者/遠程、會利用掩護、使用念能力

### 頭目（BOSS） 級（CR 6 ~ 14+）

| 屬性 | 範圍 |
|------|:---:|
| 生命值（HP） | 90-250+ |
| 防禦等級（AC） | 15-20 |
| 主要攻擊 | 3d6+ ~ 6d6+ |
| 念量（SP） | 60-150+ |
| 念能力 | 2-4 個（含制約誓約） |

**典型角色：** 幻影旅團成員、高階念能力者、傳說級魔獸

**戰術 AI：** 針對 玩家角色（PC） 弱點、使用環境、利用制約誓約

## 2-3 非玩家角色（NPC） 快速生成五步驟

1. **決定 挑戰等級（CR）** → 從上表取得數值框架
2. **分配屬性** → 主要屬性 14-16，次要屬性 10-12
3. **設計念能力** → 1-2 個符合 挑戰等級（CR） 等級的念能力（可用 制約誓約點（BP） 系統輔助設計）
4. **設定戰術 AI** → 從下方 5 種 AI 中選擇
5. **添加特色** → 獨特外觀、口頭禪、弱點／生態弱點

### 五種戰術 AI

| AI 類型 | 行為模式 | 適合 |
|------|------|------|
| **猛攻型** | 攻擊最弱目標，不考慮防禦 | 野獸、狂戰士 |
| **謹慎型** | 先試探、保持距離、生命值（HP）<50% 撤退 | 智將、暗殺者 |
| **防禦型** | 優先保護自己/重要目標，反擊為主 | 護衛、守護獸 |
| **戰術型** | 分析 玩家角色（PC） 弱點、利用環境、團隊配合 | 獵人、軍人 |
| **混亂型** | 隨機目標、不可預測、可能自毀 | 被操控者、失控念獸 |

## 2-4 頭目（BOSS） 三階段機制

| 階段 | 觸發條件 | 行為變化 |
|------|------|------|
| **試探** | 預設 | 使用基礎能力，測試 玩家角色（PC） 戰術，保留念能力 |
| **認真** | 生命值（HP） 70% 或第 3 回合 | 開始使用念能力，攻擊模式升級，可能揭露部分制約資訊 |
| **極限** | 生命值（HP） 30% 或觸發誓約 | 使出全力，制約效果加倍，可能有自毀傾向，揭開 頭目（BOSS） 真正目的 |

### 觸發方式建議

| 方式 | 描述 |
|------|------|
| 生命值（HP） 閾值 | 固定血量百分比（最常見） |
| 時間觸發 | 第 N 回合後自動觸發 |
| 環境觸發 | 玩家角色（PC） 摧毀特定物品／保護對象死亡 |
| 誓約觸發 | 玩家角色（PC） 滿足 頭目（BOSS） 的制約條件 |

## 2-5 幻獸／魔獸設計指南

### 四級分類

| 級別 | 挑戰等級（CR） | 特徵 | 範例 |
|------|:---:|------|------|
| 普通級 | 1/4-1 | 無念能力，可馴化 | 大型野獸 |
| 危險級 | 2-5 | 擁有天生念能力 | 念獸、幻獸 |
| 災害級 | 6-10 | 高智能+多重念能力 | 嵌合蟻兵隊長 |
| 傳說級 | 11+ | 可改變生態系統 | 嵌合蟻王、黑暗大陸生物 |

### 魔獸設計公式

```
魔獸 CR = 基礎體格 + 天生念能力 + 特殊生態特徵
```

### 八種特殊能力範例

| 能力 | 效果 | 適合 挑戰等級（CR） |
|------|------|:---:|
| 堅殼 | 物理傷害 −1d4 | 2+ |
| 毒性分泌 | 近戰觸發中毒 Lv.1 | 1+ |
| 擬態 | 潛行檢定優勢 | 1+ |
| 念波感知 | 感知範圍內所有念能力者 | 3+ |
| 再生 | 每回合回復 1d4 生命值（HP） | 4+ |
| 念吸收 | 對其使用念能力 念量（SP） 消耗 ×2 | 5+ |
| 分身 | 創造 1d4 個低血量分身 | 6+ |
| 領域展開 | 範圍內念能力者全檢定劣勢 | 8+ |

### 部位破壞與生態弱點

- 大型魔獸可設計可破壞的部位（角、尾、甲殼），各部位有獨立 生命值（HP）
- 每種魔獸應有 1-2 個生態弱點（特定音頻、光線、氣味等）
- 生態弱點的發現需要「念知識」或「生存」檢定（DC 15-22）

### 捕獲規則

- 目標 生命值（HP） 降至 25% 以下
- 進行「生存」或對應知識檢定（DC = 15 + 挑戰等級（CR））
- 失敗則目標逃脫或進入狂暴狀態

# 第三章：遭遇設計指南

## 3-1 遭遇點數（EP） 預算系統

> **遭遇點數（EP）** 僅用於 主持人（GM） 構建遭遇，**不發給玩家**。玩家 經驗點（XP） 見玩家手冊 §2-9。

### 每日 遭遇點數（EP） 預算

| 玩家成長階段 | 每日 遭遇點數（EP） 預算（4 人團） |
|------|:---:|
| 新人 | 100 遭遇點數（EP） |
| 見習獵人 | 300 遭遇點數（EP） |
| 合格獵人 | 800 遭遇點數（EP） |
| 專業獵人 | 1,600 遭遇點數（EP） |
| 星級獵人 | 2,800 遭遇點數（EP） |
| 傳說級 | 4,000+ 遭遇點數（EP） |

### 遭遇難度倍率

| 難度 | 遭遇點數（EP） 預算使用率 |
|------|:---:|
| 簡單 | 25% |
| 中等 | 50% |
| 困難 | 75% |
| 致命 | 100% |

**範例：** 4 人見習獵人團，中等難度遭遇的 遭遇點數（EP） 預算 = 300 × 50% = 150 遭遇點數（EP）。可以安排 1 隻 CR1（100 遭遇點數（EP））+ 2 隻 挑戰等級（CR） 1/4（25 遭遇點數（EP） × 2 = 50 遭遇點數（EP））。

**玩家實際獲得的角色 經驗點（XP）：** 參照玩家手冊 §2-9，不從 遭遇點數（EP） 換算。

## 3-2 念能力戰鬥五原則

這是主持獵人X獵人TRPG 戰鬥的核心心法：

| 原則 | 說明 | 主持人（GM） 操作 |
|------|------|------|
| **資訊不對稱** | 玩家不知道對手的念能力全貌 | 分階段揭露 頭目（BOSS） 能力，先只描述視覺效果 |
| **念量博弈** | 念量（SP） 是有限資源，分配決定勝負 | 提示 玩家角色（PC）「對手看起來念量還很充沛／開始喘了」 |
| **制約利用** | 每個念能力都有弱點 | 給 玩家角色（PC） 察覺制約的機會（念知識 難度等級（DC） 15-22） |
| **環境即武器** | 獵人戰鬥善用地形 | 每個戰鬥場景準備 3 個可互動物件 |
| **非戰鬥解決** | 最強的念能力也無法解決所有問題 | 設計可以透過交涉／潛行／計謀避開的戰鬥 |

## 3-3 四種遭遇類型平衡

| 類型 | 建議佔比 | 消耗資源 | 檢定重點 |
|------|:---:|------|------|
| 社交遭遇 | 25% | 資訊、人情、念量（SP）（魅惑/威壓） | 交涉、洞察、欺騙 |
| 探索遭遇 | 30% | 生命值（HP）（陷阱）、念量（SP）（解謎）、時間 | 察覺、調查、生存 |
| 戰鬥遭遇 | 30% | 生命值（HP）、念量（SP）、消耗品 | 戰鬥系統 |
| 休息／過場 | 15% | 回復、角色互動 | 自由扮演 |

### 社交遭遇深度機制

獵人世界的社交不只是擲骰檢定——信念的交鋒、資訊不對等的博弈、道德立場的碰撞。主持人（GM） 可使用以下機制增強社交遭遇的深度：

#### 社交立場（Stance）

非玩家角色（NPC） 對 玩家角色（PC） 的初始立場分為五級，影響社交檢定 難度等級（DC）：

| 立場 | 難度等級（DC） 調整 | 觸發轉變的條件 |
|------|:---:|------|
| 敵對 | 難度等級（DC） +5 | 玩家角色（PC） 展示壓倒性力量或誠意 |
| 懷疑 | 難度等級（DC） +2 | 玩家角色（PC） 提供可信證據或共同利益 |
| 中立 | 難度等級（DC） 0 | 預設；玩家角色（PC） 提出合理提案 |
| 友善 | 難度等級（DC） −2 | 玩家角色（PC） 曾有恩於此 非玩家角色（NPC） 或有共同目標 |
| 信賴 | 難度等級（DC） −5 | 長期盟友；不會背叛 |

#### 社交衝突三要素

當 玩家角色（PC） 試圖說服一個重要 非玩家角色（NPC） 時，主持人（GM） 判斷以下三要素是否滿足：

| 要素 | 含義 | 若未滿足 |
|------|------|------|
| **利益** | 玩家角色（PC） 的提案對 非玩家角色（NPC） 有什麼好處？ | 難度等級（DC） +3 |
| **信任** | 非玩家角色（NPC） 為什麼要相信 玩家角色（PC） 說的是真的？ | 難度等級（DC） +3 |
| **可行** | 玩家角色（PC） 的提案是否真的可以執行？ | 難度等級（DC） +3 |

> **使用方式：** 基礎 難度等級（DC） = 15。非玩家角色（NPC） 立場調整 ±難度等級（DC）（如上表）。玩家角色（PC） 每滿足一個要素，難度等級（DC） −3。最終 難度等級（DC） 最低為 5。

**範例——玩家角色（PC） 說服艾德蒙·雷撤退：**
- 基礎 難度等級（DC） 15；立場「懷疑」→ 難度等級（DC） 17
- 利益：玩家角色（PC） 提出替代方案（黑暗大陸可控資源交換）→ 難度等級（DC） −3 = 14
- 信任：玩家角色（PC） 展示了五大災難的本質證據 → 難度等級（DC） −3 = 11
- 可行：玩家角色（PC） 有守門人背書，證明代管方案可行 → 難度等級（DC） −3 = 8
- 最終 難度等級（DC） 8 → 正常交涉檢定即可成功

## 4-4 主持人（GM） 運行指南

### 創角主持要點（30-60 分鐘）

1. **引導背景故事**——讓玩家說出角色的動機與羈絆
2. **協助配點**——推薦配點方案給新手（均衡型）
3. **水見式儀式感**——擲骰後描述水見式的變化，為每個系別準備一段獨特的視覺描述
4. **念能力設計引導**——先問「你想做什麼」，而非「你想要什麼數值」。例如：
   - 「我想讓敵人無法動彈」→ 操作系／具現化系
   - 「我想一拳粉碎任何東西」→ 強化系
   - 「我想讀取別人的記憶」→ 特質系／操作系
5. **制約獎勵**——鼓勵玩家給自己設限，「你的制約越有趣，能力越強」

### 念能力審核五維標準

| 維度 | 評估問題 | 紅線提示 |
|------|------|------|
| **系別合理性** | 能力是否在該系的範疇內？ | 跨系能力需付出效率代價 |
| **制約平衡** | 制約誓約點（BP） 收支是否平衡？代價是否真的有限制力？ | 「每日1次」對長團實際限制很小 |
| **戰鬥公平** | 是否會讓其他 玩家角色（PC） 覺得自己毫無作用？ | 注意「一人獨秀」型設計 |
| **敘事潛力** | 這個能力是否能創造有趣的劇情？ | 純數值能力缺乏敘事深度 |
| **弱點存在** | 是否留下了明確的弱點或限制？ | 完美能力 = 拒絕 |

### 審核對話模板

當需要拒絕或調整玩家的念能力設計時：

```
「這個能力的概念非常有趣，[誇獎具體點]。
但我注意到 [具體問題]。我們可以試試看 [替代方案]，
這樣既能保留你想要的感覺，又能讓其他玩家也有發揮空間。

你覺得呢？」
```

### 冨樫流敘事風格

- **資訊不對稱**：玩家角色（PC） 所見的世界 ≠ 真實的世界。每場遭遇準備「玩家角色（PC） 知道的」和「玩家角色（PC） 不知道的」兩份筆記
- **三層真相**：表面說法 → 內部情報 → 終極真相。每個委託至少準備兩層反轉
- **敗北 ≠ 結束**：這回合失去的，下回合可能成為逆轉的契機。設計不致命的失敗後果（被捕、失去關鍵物品、被迫合作）
- **策略空間**：給 玩家角色（PC） 充分的資訊來做出有意義的戰術選擇
- **道德灰色**：沒有純粹的邪惡，每個反派都有可理解的原因

### 灰色地帶設計（6 種道德難題模板）

| 難題 | 情境 | 玩家選擇 |
|------|------|------|
| 必要之惡 | 委託人是罪犯，但任務本身是正當的 | 拒絕／接受／協商條件 |
| 兩難抉擇 | 必須在救人 vs 完成任務之間選擇 | 考驗角色價值觀 |
| 後果代價 | 任務成功會傷及無辜 | 尋找第三條路 |
| 情報控制 | 告訴 非玩家角色（NPC） 真相可能害死他 | 隱瞞／揭露／折衷 |
| 敵友難辨 | 對手實際上是受迫的工具人 | 擊敗／理解／轉化 |
| 秩序 vs 自由 | 協會規則與正義感衝突 | 遵守體制／打破規則 |

