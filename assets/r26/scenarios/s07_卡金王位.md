# 劇本七：卡金王位——血與念的繼承

> **玩家角色（PC） 階段：** 傳說級（251+ 經驗點（XP））
> **時長：** 8-12 小時
> **前提：** 劇本五之後，玩家角色（PC） 在黑暗大陸已有立足點

---

## 背景

卡金王國的第十四王子爭奪戰已經進入白熱化階段。現任國王納斯比·灰郭肉宣布：誰能從黑暗大陸帶回最有價值的「證明」，誰就成為下一任國王。

十四位王子的遠征隊同時進入黑暗大陸。玩家角色（PC） 被其中一位王子（或公主）僱傭——或被迫參與——這場王位爭奪。

## 王位爭奪的遊戲規則

| 規則 | 內容 |
|------|------|
| 證明 | 從黑暗大陸帶回任意「無人見過」的物品或情報 |
| 手段 | 不限制——可交易、搶奪、合作、暗殺 |
| 時限 | 三個月 |
| 贏家 | 國王的「壺」會判定誰的證明最有價值（標準未知） |
| 輸家 | 歷史慣例：不是被流放，而是被處決 |

## 關鍵事件表（每 2 天觸發一次，擲 d10）

| d10 | 事件 |
|:---:|------|
| 1 | **王子來信**：僱主傳來新指示（或絕望的求助） |
| 2 | **敵對遠征隊**：另一王子的隊伍與 玩家角色（PC） 遭遇（可戰鬥/交易/結盟） |
| 3 | **壺的顯現**：玩家角色（PC） 中的一人夢到「壺」——它給了一個模糊的提示（GM 選擇一個黑暗大陸的祕密位置） |
| 4 | **卡金內鬥**：兩個王子的隊伍在 玩家角色（PC） 面前交戰，玩家角色（PC） 決定幫誰——或袖手旁觀 |
| 5 | **黑暗大陸威脅**：遭遇五大災難之一的痕跡（擲 d5 選災難） |
| 6 | **背叛**：玩家角色（PC） 隊伍中的 非玩家角色（NPC） 嚮導被另一個王子收買 |
| 7 | **意外發現**：發現一個未被記錄的黑暗大陸遺跡（GM 現場設計） |
| 8 | **國王的信使**：卡金國王直接送來一條訊息——他在觀察 |
| 9 | **雙重遭遇**：同時觸發兩個事件（先擲 d8 再擲 d8） |
| 10 | **守門人來訪**：翁或他的傳人出現，給予警告或建議 |

## 結局路線

| 結局 | 條件 | 結果 |
|------|------|------|
| 王子勝利 | 玩家角色（PC） 協助的王子當選 | 獲得卡金的永久庇護和資源 |
| 壺的真相 | 玩家角色（PC） 發現壺的本質（它是黑暗大陸的古代遺物） | 可選擇摧毀壺→終結王位爭奪制度 |
| 獨立勢力 | 玩家角色（PC） 不幫助任何王子，建立自己的黑暗大陸據點 | 成為卡金以外的第三勢力 |
| 全員存活 | 玩家角色（PC） 設計讓所有王子都「證明失敗」但免於處決（具體方法見下方） | 獲得所有王子的秘密人情 |

### 全員存活路線的具體方法

主持人（GM） 提供 玩家角色（PC） 以下可選路徑（PC 選擇一種或組合多種）：

| 方法 | 規則 | 難度 |
|------|------|:---:|
| **替換證明** | 玩家角色（PC） 潛入國王的「壺之間」，用仿製品替換壺在判定時讀取的證明。需潛行 難度等級（DC） 22 + 巧手 難度等級（DC） 20。壺判定時所有證明都「不合格」——但同樣不合格 = 全部免於處決（國王無法判定誰最差）。 | ★★★★ |
| **說服國王** | 玩家角色（PC） 直接面見國王納斯比，說服他改變規則。「讓所有王子都活著，讓他們欠彼此一條命——這比一個死去的繼承人更有價值。」交涉 難度等級（DC） 25（每有一位王子為 玩家角色（PC） 背書 難度等級（DC） −2）。 | ★★★ |
| **公開壺的真相** | 玩家角色（PC） 在繼承式上公開壺是黑暗大陸的古代遺物，其判定標準是「對人類的威脅程度」而非「價值」。一旦公開，王位爭奪制度本身失去正當性——所有王子都是受害者。需智力（念知識）難度等級（DC） 22 分析壺 + 魅力 難度等級（DC） 20 公開說服。 | ★★★★ |
| **互相抵消** | 玩家角色（PC） 私下安排兩位最強的王子互相宣告：「如果他失敗，我也不繼承。」當最強的兩位王子互相綁定命運，國王無法處決任何一人而不引發內戰。需交涉 難度等級（DC） 22（兩位王子各一次）。 | ★★★ |
| **守門人介入** | 如果 玩家角色（PC） 之一已成為守門人（劇本八），守門人可以宣布黑暗大陸的「門」只承認一種證明：「放過你的兄弟」。壺在面對守門人時會尊重門的意志——所有王子自動失敗。 | 需要成為守門人 |
