## 劇本 SA-4：「深巢的唯一」

**難度：** 高 | **審判官：** 馬格努斯·鐵（激進）  
**目標區域：** 深巢（第 2300 層以下），被遺忘的古代地下神殿  
**推薦屬性：** 4-5 級 | **挑戰等級（CR） 預算：** 3（困難）

### 背景

馬格努斯需要那件古代聖物——他不在乎代價。他給了你最少的資源，和一個他不介意失去的助手。

### NPC 夥伴

**老兵塔洛斯（前帝國衛隊中士，被判「逃兵」罪名）**

| 項目 | 內容 |
|------|------|
| 一句話描述 | 50 歲的灰髮老兵，眼神疲憊但手仍然穩。他見過太多 |
| 動機 | 完成贖罪後退休——找一個安靜的巢都角落等死 |
| 底線 | 絕不拋下受傷的戰友 |
| 初始態度 | +1（信任——他聽說過你之前的任務） |
| 屬性 | 信仰 2 / 體魄 3 / 心智 3 / 技藝 4 / 命運 2 |
| 關鍵技能 | 遠程射擊（受訓）、醫療（受訓） |
| 裝備 | 雷射槍（1d6+1）、防彈甲（護甲值（AR） 2）、舊戰友狗牌 |
| 特殊能力 | **老兵直覺：** 每劇本 1 次，GM 必須告知一個即將到來的危險（「我覺得前面不對勁」）。**戰地急救：** 使用醫療包時恢復額外 1d4 生命值（HP） |

### 關鍵檢定

| 場景 | 檢定 | 成功 | 失敗 |
|------|------|------|------|
| 穿越毒氣區域 | 堅韌（困難），塔洛斯分享防毒面具 | 安全通過 | 生命值（HP） −1d4/回合 |
| 面對盲先知 | 佈道（標準） | 獲得警告和捷徑 | 無法取得信任 |
| 抵抗聖物汙染 | 信仰（極限） | 腐化獲取減半 | 每分鐘腐化 +1 |

### 內部誘惑觸發點

在神殿最深處，手持聖物時：

> *「塔洛斯已經老了。他活不了多久——這是他自己說的。如果你需要在這裡犧牲一個人來完成任務——他是最合理的選擇。他甚至可能會自願。」*
