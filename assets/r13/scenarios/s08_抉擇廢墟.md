## 劇本 SB-3：「異形的交換」

**難度：** 中 | **地點：** 機械教廢棄設施「塔納托斯-7 前哨站」  
**推薦屬性：** 3-4 次成長

### 背景

運輸船的修復需要一個關鍵零件——它就在廢棄的機械教設施中。但當你抵達時，你發現已經有人在這裡了——一個靈族遊俠。他也在找東西。他提出了一個交易。

### NPC 夥伴

**凱拉（延續自 SB-1——如果她在 SB-1 存活）** 或 **卡拉（延續自 SB-2——如果 SB-2 已跑）**

如果前兩個夥伴都死亡或不在，則引入新夥伴：

**機械教士 歐米克隆-7（殘存的機械教技術僧侶）**

| 項目 | 內容 |
|------|------|
| 一句話描述 | 半機械化的技術僧侶，被困在這個設施中已經 6 個月 |
| 動機 | 回收設施中的 標準模板構造（STC） 碎片——這是他畢生的使命 |
| 底線 | 絕不損壞古代科技 |
| 初始態度 | 0（中立——他只關心科技） |
| 屬性 | 信仰 2 / 體魄 3 / 心智 5 / 技藝 5 / 命運 1 |

| 裝備 | 電擊棒（1d4+3 能量）、重型甲殼甲（護甲值（AR） 4）、機械教診斷器 |
| 特殊能力 | **機魂溝通：** 可與機械設施互動而不觸發防禦系統。**科技祝福：** 每劇本 1 次，為一件武器提供 +10 命中直到戰鬥結束 |

### 誓約衝突點（內部化）

靈族遊俠艾蘭迪爾提出交易——水晶換幫助修船。

- **帝皇的聲音（優先級高的誓約——拒絕異形）：** 「異形不可信。拒絕他。你可以自己找到零件——即使要多花幾週。」
- **良知/生存的聲音（優先級低的誓約——但現在更急迫）：** 「你被困在這顆星球上。你需要那艘船。接受他的幫助——為了你自己，為了你的戰友。」
