## 劇本 SB-2：「兩人的廢墟」

**難度：** 低 | **地點：** 廢墟城市「艾爾登菲爾」  
**推薦屬性：** 創角後 1-2 次成長

### 背景

跟隨運輸船的坐標，你抵達了廢墟城市。在這裡你發現的不是運輸船，而是一群平民倖存者。其中一個人讓你停下了腳步——一名前帝國衛隊軍官，她身上有你戰團的印記。

### NPC 夥伴

**卡拉·瓦爾（前帝國衛隊中尉，曾在你的戰團麾下服役）**

| 項目 | 內容 |
|------|------|
| 一句話描述 | 堅韌的中年女軍官。她認識你的戰團——她的連隊曾在你們的支援下守住了一座橋 |
| 動機 | 保護她剩下的平民。她不相信帝國會回來——但她相信你 |
| 底線 | 絕不拋棄平民 |
| 初始態度 | +2（忠誠的前夕——她認出了你的戰團標記） |
| 屬性 | 信仰 3 / 體魄 3 / 心智 3 / 技藝 3 / 命運 3 |
| 關鍵技能 | 指揮（受訓）、遠程射擊（受訓） |
| 裝備 | 自動槍（1d8+1）、甲殼甲（護甲值（AR） 3）、破損戰團旗幟碎片（從當年那場戰役中保留） |
| 特殊能力 | **老兵指揮：** 為玩家提供一次免費優勢（每場戰鬥 1 次）。**旗幟的記憶：** 持有破損旗幟時，她和玩家的信仰檢定 +5 目標值（TN） |

### 誓約衝突點

卡拉請求你保護平民，帶他們去運輸船。但運輸船坐不下所有人——如果你帶上平民，就意味著你可能無法撤離。

- **選擇 A：** 答應她——誓約「對無辜者的誓言」被兌現（信仰 +2），但後續劇本中平民的命運將壓在你心上
- **選擇 B：** 拒絕她——誓約「對任務的誓言」被兌現（更高效的撤離），但卡拉態度 −2
