# 帝國棄子 TRPG —— 玩家手冊

> **版本：** v0.3  
> **核心判定：** d100 擲低制（Roll-Under）  
> **核心命題：** 帝國已經放棄了你，你的信仰還剩下多少？

---

# 第一章：核心規則

## 1.1 核心判定公式

```
目標值（TN） = 屬性值 × 10 + 技能加值 + 難度調整 + 環境調整
```

擲 d100（兩個十面骰），結果 ≤ 目標值（TN） 即為成功。

> **目標值（TN） 上限規則：** 任何檢定的最終 目標值（TN） 不得超過 **95**。即使計算結果 ≥ 95，擲出 96-00 仍為大失敗。這確保了即使是傳說級角色也永遠有失敗的可能——在 40k 宇宙中，沒有什麼是百分之百確定的。

### 成功度（DoS）

| 公式 | 含義 |
|------|------|
| **成功度（DoS） = ⌊(目標值（TN） − 擲值) / 10⌋** | 每超出 10 點 = 1 級成功度 |
| **失敗度（DoF） = ⌊(擲值 − 目標值（TN）) / 10⌋** | 每不足 10 點 = 1 級失敗度 |

### 大成功與大失敗

| 擲值 | 結果 | 效果 |
|------|------|------|
| **01-05** | 大成功 | 自動成功 + 最大 成功度（DoS） + 額外正面效果 |
| **96-00** | 大失敗 | 自動失敗 + 最嚴重的負面後果 |

## 1.4 優勢與劣勢

| 狀態 | 規則 | 目標值（TN）=50 時成功率 |
|------|------|---------------|
| **優勢** | 擲 d100 兩次，取較低值 | 75% |
| **劣勢** | 擲 d100 兩次，取較高值 | 25% |
| 雙優勢/雙劣勢 | 不疊加 | — |
| 優勢+劣勢 | 互相抵消，正常擲骰 | 50% |

**獲得優勢：** 合適的工具或裝備、花費額外時間準備（一回合）、隊友協助成功、信仰能力「神聖狂熱」、GM 判定敘事合理性。

**獲得劣勢：** 凡人 vs 阿斯塔特物理對抗（自動）、黑暗中無照明作業、生命值（HP） < 50%、受到恐懼或壓制效果、腐化階段「汙染」及以上（社交檢定）。

## 1.6 協助與團隊檢定

**協助：** 隊友進行相同技能檢定（僅需屬性×10，無需技能）。成功則主要角色獲得優勢。

**團隊檢定：** 全隊進行同一屬性檢定。半數以上成功 → 團隊成功。GM 根據失敗人數調整後果。

---

## 1.7 對抗檢定

雙方各擲 d100，比較 成功度（DoS）。成功度（DoS） 高者勝。

**平局處理：**
- 物理對抗 → 體魄高者勝
- 社交對抗 → 命運高者勝
- 靈能對抗 → 信仰高者勝
- 仍平局 → 防禦方勝

**凡人 vs 阿斯塔特物理對抗：** 凡人自動劣勢。擁有特殊裝備或環境優勢時可取消。

### 創傷效果

當單次攻擊造成的傷害 **超過創傷上限** 時，觸發創傷效果：

| 成功度（DoS）（超出量） | 凡人效果 | 阿斯塔特效果 |
|---------------|---------|-------------|
| 超過 0-4 點 | **輕微創傷：** 下回合劣勢 | 無（超人韌性） |
| 超過 5-9 點 | **中等創傷：** 1d3 回合震懾 + 永久疤痕角色扮演（RP） | **輕微創傷：** 下回合劣勢 |

| 超過 15+ 點 | **致命創傷：** 即死（凡人）/ 立即進入最終守望（阿斯塔特） | **重創：** 失去肢體功能、生命值（HP） 上限 −1（永久） |

**治療創傷：** 中等及以上創傷需要醫療檢定（困難）+ 醫療包消耗 1 次。重創需要戰團藥劑師或同等級醫療設施。

**擺脫靈魂的黑夜：** 需要通過一次特別的「信仰重燃」行動——可能是完成一個重大善行、接受戰友的佈道（佈道檢定，困難）、或見證帝皇的奇蹟（帝皇之眼現象）。成功後信仰池恢復至公式值的 25%（向上取整）。

```
近戰：d100 ≤ 體魄 × 10 + 近戰技能 − 目標防禦值 − 難度修正
遠程：d100 ≤ 技藝 × 10 + 遠程射擊技能 − 目標防禦值 − 距離修正
```

### 防禦值

```
目標防禦值 = 技藝 ÷ 2（向上取整）+ 護甲防禦加值 + 掩體加值（阿斯塔特 +1）
```

### 掩體

| 掩體 | 攻擊方 目標值（TN） 懲罰 |
|------|---------------|
| 輕掩體 | −10 |
| 中掩體 | −20 |
| 重掩體 | −30 |
| 全掩體 | 無法瞄準 |

### 距離修正

| 距離 | 目標值（TN） 調整 |
|------|---------|
| 近距（≤ 射程 1/4） | +0 |
| 中距（≤ 射程 1/2） | −10 |
| 遠距（≤ 射程） | −20 |

### 傷害公式

```
最終傷害 = 武器基礎傷害 + 成功度（DoS） × 2 − 目標護甲減免護甲值（AR）（最低 1）

暴擊（大成功 01-05）：傷害最大化 + 成功度（DoS） × 2 − 護甲減免護甲值（AR）
```

### 傷害類型

| 類型 | 來源 | 護甲交互 |
|------|------|---------|
| 彈道 | 自動槍、爆彈槍 | 標準 護甲減免護甲值（AR） |
| 能量 | 雷射、電漿、熱熔 | 甲殼甲效果 −2 |
| 爆炸 | 手雷、火箭 | 輕甲 +2 |
| 火焰 | 火焰噴射器 | 無視 護甲減免護甲值（AR） 2 點 |
| 撕裂 | 鏈鋸劍、動力武器 | 對 護甲減免護甲值（AR） 效果 −2，暴擊時無視 |
| 腐蝕 | 強酸、混沌武器 | 每次命中永久 −1 護甲減免護甲值（AR） |
| 精神 | 靈能攻擊 | 無視物理 護甲減免護甲值（AR） |
| 神聖 | 聖水、祝福武器 | 對混沌生物 ×2 |

## 3.5 死亡與瀕死

### 凡人瀕死

生命值（HP） ≤ 0：倒地，每回合結束擲 d20：
- ≥15：穩定（生命值（HP） 0）
- 10-14：下回合繼續擲
- 5-9：生命值（HP） −1
- 1-4：生命值（HP） −3
- 自然 1：即死

真實死亡：生命值（HP） ≤ −(體魄 + 心智)

### 阿斯塔特最終守望

生命值（HP） ≤ 0：進入「最終守望」
- 不會自動倒地
- 每回合僅 1 個行動
- 每次行動後 生命值（HP） −2
- 生命值（HP） ≤ −(體魄 × 2 + 20) → 休眠昏迷

休眠昏迷：生理休眠，藥劑師才能喚醒，可維持 1d100+100 年。
