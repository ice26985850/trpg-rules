# 帝國棄子 TRPG —— 魔法圖鑑（靈能）

> 本圖鑑由玩家手冊 §3.9 靈能系統的「通用靈能」與「智庫專屬」能力表彙整，供靈能者與智庫角色快速查閱。本作的「魔法」即為亞空間靈能（Psychic Powers）。

## 靈能使用流程

```
1. 宣告靈能和強度
2. 支付 靈能點數（PP）
3. 擲靈能檢定：d100 ≤ 心智×10 + Psi×5
4. vs 難度等級（DC）
5. 成功→生效，失敗→觸發亞空間現象
```
