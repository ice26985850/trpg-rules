- **恆星：** 「鏽日」（Rust-Sun）——微紅色衰老恆星

> **星區諺語：** 「帝皇的光芒抵達這裡時，已經很微弱了。」

# 第二章：GM 運行原則

## 2.1 七條 GM 鐵律

1. **帝皇不是答案——是問題。** 不要告訴玩家帝皇是否存在、是否眷顧他們。讓這個問題永遠懸在角色頭頂。
2. **勝利是暫時的，代價是永久的。** 每次成功必須附帶代價——資源消耗、腐化增長、關係破裂。
3. **環境是最強大的敵人。** 巢都本身會殺人。饑餓、黑暗、毒氣、塌陷——比混沌教眾更致命。
4. **選擇不是答案。** 給玩家的不是「對」與「錯」的選擇，而是「壞」與「更壞」。
5. **希望存在——但必須掙扎才能獲得。** 在最黑暗的時刻給予一線微光。足夠讓角色前進，但不夠照亮整個世界。
6. **恐懼是真實的——但不廉價。** 不要每回合都擲恐懼檢定。保留給真正重要的時刻。
7. **信任是最稀缺的資源。** 誘惑紙條讓信任永不完整。誓約衝突讓信任變複雜。

## 2.2 40k 版「是的，而且」

> **「是的，而且……它讓事情更複雜了。」**

當玩家提出創意方案時，不要直接拒絕。說「是的」——然後加一個 40k 轉折：「但帝國官僚不會批准這個」「但那東西可能已被汙染」「但你的審判官不會喜歡這個。」

## 2.3 敘事節奏：呼吸循環

```
緊張（戰鬥/潛行/威脅）
    │
    ▼
釋放（短暫安全/軍營時間/隊友互動）
    │
    ▼
更深絕望（資源更少/腐化更深/新的真相）
    │
    ▼
終局（撤離/犧牲/抉擇）
```

- 一個遊戲夜 = 2-3 個循環
- 一次完整任務 = 3-5 個循環

---

## 2.4 凡人模式 GM 要點

- **保密誘惑紙條。** 永遠不要在公開場合討論紙條內容。用私下紙條或簡訊傳遞。
- **不催促背叛。** 讓玩家自己決定何時行動。壓力來自環境，不是來自你。
- **安排「揭露時刻」。** 在中後期任務中讓某個誘惑紙條的效果浮現——但不要指名道姓。
- **資源是真正的壓力。** 嚴格追蹤彈藥、醫療包、照明彈。

## 2.5 阿斯塔特模式 GM 要點

- **不提供「正確答案」。** 誓約衝突沒有最優解。讓玩家承受選擇的後果。
- **讓倖存者有意義。** 平民不僅僅是「被拯救的對象」——他們有意見、需求、可能成為盟友或負擔。
- **控制撤離終局節奏。** 不要過早揭示撤離可能性。讓絕望充分發酵。
- **尊重所有選擇。** 留下的戰士應該獲得一個有尊嚴的結局。

## 2.7 調查與情報收集系統

審判庭任務的核心是調查——在戰鬥之前，贖罪者需要找到目標、識破謊言、拼湊真相。

### 線索鏈設計

每個任務應包含 **3-5 條關鍵線索**，形成一條從「已知」到「真相」的鏈條。線索分為三類：

| 線索類型 | 取得方式 | 必定可獲得？ | 範例 |
|---------|---------|-------------|------|
| **核心線索** | 無需檢定，到達正確地點即可發現 | ✅ 是 | 屍體上的教派紋身、聖堂祭壇的混沌符號 |
| **隱藏線索** | 需要成功檢定才能發現 | ❌ 否 | 藏在暗格中的日記、被加密的數據板 |
| **獎勵線索** | 需要創意或高難度檢定 | ❌ 否 | NPC 無意中洩露的資訊、被忽略的細節 |

> **三線索原則：** 每個核心結論至少要有三條不同的路徑可以推導出來——確保玩家不會因為一次失敗檢定而卡住。

### 調查檢定

| 行動 | 技能 | 難度 | 成功獲得 |
|------|------|------|---------|
| 搜索犯罪現場 | 調查 | 標準 | 1 條核心線索 + 可能隱藏線索 |
| 審訊俘虜/證人 | 佈道（友善）/ 欺瞞（欺騙）/ 威嚇（恐懼） | 標準-困難 | 1 條資訊 |
| 分析文件/數據 | 學識（帝國/混沌） | 標準-困難 | 破解加密或理解內容 |
| 追蹤痕跡 | 警覺 | 標準 | 得知目標去向 |
| 辨識混沌物品 | 靈能感知 或 學識（混沌） | 困難 | 確認汙染等級和危險性 |
| 破解門禁/終端 | 技術 | 標準-困難 | 進入限制區域或獲取資料 |
| 滲透偽裝 | 欺瞞 | 困難 | 不被識破地進入敵方區域 |

### 情報品質（DoS 影響）

| 成功度（DoS） | 情報品質 |
|-----|---------|
| 0 | 基本資訊——知道下一步該去哪裡 |
| 1 | 有用細節——敵人的弱點或環境的危險 |
| 2 | 關鍵情報——敵人的真正動機或隱藏的陷阱 |
| 3+ | 完整真相——GM 應給予一個關鍵的劇情揭示 |

### 審訊規則

- 俘虜的初始態度決定基礎難度：合作（簡單）、中立（標準）、敵對（困難）、狂熱（極限）
- 可通過威脅、利誘、或展示證據來改變態度（+1 級）
- 每次審訊最多 3 次檢定嘗試。3 次後俘虜不再提供新資訊
- 對俘虜使用暴力：凡人腐化 +1（非必要暴力），阿斯塔特不增加

### 時間壓力

調查不是無限時間的。每次調查行動消耗 **1 個時間單位**時間單位（TU）。GM 暗中追蹤：

| 時間單位（TU） 消耗 | 後果 |
|---------|------|
| 3 時間單位（TU） | 敵人開始察覺異常——部分敵人進入警戒 |
| 5 時間單位（TU） | 敵人準備應對——增加 1-2 名額外敵人 |
| 7 時間單位（TU） | 敵人實施撤退/銷毀證據——失去 1 條核心線索 |
| 10 時間單位（TU） | 任務客觀時限到達——強制進入最終階段 |

| 被轟炸巢都 | 倒塌建築、地下通道 | 避難所、儲藏室 | 變異體巢穴、不穩定結構 |
| 廢棄機械教設施 | 生鏽機甲、聖油殘留 | 零件、工具 | 混亂的機魂、防禦系統 |

# 第四章：誓約衝突與撤離終局

## 4.1 誓約衝突設計

### 衝突一：保護無辜 vs 服從命令

| 選擇 | 效果 | 長遠後果 |
|------|------|---------|
| 保護平民 | 消耗資源、獲得情報 | 終局時空間危機 |
| 執行滅絕令 | 快速推進 | 腐化 +2~5，信念危機 |
| 勸離平民 | 信仰檢定（困難） | 折衷，但有風險 |

### 衝突二：絕不後退 vs 保護戰友

| 選擇 | 效果 | 長遠後果 |
|------|------|---------|
| 堅守死戰 | 50% 全滅 | 若存活：傳說誕生 |
| 戰術撤退 | 扛起戰友撤退 | 誓言裂痕，但戰友存活 |
| 犧牲掩護 | 獨自斷後 | 存活概率極低 |

### 衝突三：拒絕異形 vs 生存至上

| 選擇 | 效果 | 長遠後果 |
|------|------|---------|
| 拒絕幫助 | 尋找其他方案 | 時間消耗、更多危險 |
| 接受合作 | 腐化 +3~5，獲「靈族之債」 | 未來異形聯繫 |
| 欺騙背刺 | 更高腐化 +5~8 | 永遠失去信用 |

## 4.2 撤離終局五階段

```
1. 希望曙光：發現撤離可能性
2. 集結：全隊趕往撤離點
3. 計算：「船坐不下所有人。」
4. 留下：留下的戰士獲得「最後使命」
5. 起飛：尾聲。留下的戰士的命運
```

### 最後使命類型

| 使命 | 描述 |
|------|------|
| **斷後** | 守住撤離點對抗追擊敵人 |
| **封印** | 永久封閉亞空間裂縫或汙染源 |
| **守護** | 留下保護無法撤離的平民 |
| **贖罪** | 完成未竟誓言後光榮戰死 |
| **資訊傳遞** | 留在通訊裝置旁持續發送情報 |

## 5.5 非戰鬥亞空間現象表（d20）

當靈能者在非戰鬥情境中使用靈能（心靈感應、靈能感知、占卜等），或角色長時間處於腐化環境時使用此表：

| d20 | 現象 | 效果 |
|-----|------|------|
| 1-6 | **平靜** | 無事發生。亞空間暫時安寧 |
| 7-8 | **耳語** | 所有人聽到模糊的低語——可能是一個名字、一個詞、或一小段破碎的句子。GM 可以選擇給予一個隱晦提示，或只營造氛圍 |
| 9-10 | **寒意** | 溫度驟降。體魄檢定（標準）避免 1 點疲勞（凡人）。阿斯塔特：盔甲恆溫系統短暫失靈——技術檢定（簡單）重啟 |
| 11-12 | **殘影** | 每個角色看到不同的影像——凡人看到死去的親人，阿斯塔特看到死去的戰友。心智檢定（標準）避免腐化 +1。成功則影像中可能含有有用資訊 |
| 13-14 | **時間漣漪** | 感知時間與客觀時間不同步。所有角色 1d3 回合困惑（凡人）/ 1 回合困惑（阿斯塔特） |
| 15-16 | **誘惑低語** | 一個聲音對每個角色低語——提供一個看似合理的建議，但帶有微妙的混沌汙染。若角色接受建議，腐化 +1 但獲得一個優勢 |
| 17 | **低階顯現** | 一個小型亞空間實體在附近凝聚（非敵對——至少一開始不是）。它可能會回答一個問題（不一定真實）或提出交易 |
| 18 | **真理之窗** | 短暫凝視亞空間的真實面貌。腐化 +1d6（凡人）/ +1d3（阿斯塔特）。但 GM 必須給予一個真相碎片——可能是隱藏劇情的關鍵 |
| 19 | **時間裂縫** | 角色短暫看到過去或未來的片段（GM 給予一個預言性場景）。腐化 +2。在場的靈能者額外獲得一個可消耗的預知（下一個重要檢定可重擲一次） |
| 20 | **帝皇之眼** | 金色光芒閃現。所有在場者腐化 −2、信仰 +3。獲得一次免費「帝皇之手」（本場遊戲內有效）。靈能者的亞空間風險降至最低 24 小時 |
