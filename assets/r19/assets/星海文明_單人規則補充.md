# 星海文明 — 單人規則補充

> **適用**：1 名玩家 + 1 名 GM
> **版本**：v1.0（基於主規則 v1.3）
> **引用**：本補充文件所有章節參照均指向《星海文明玩家規則書》及《星海文明 GM 規則書》
>
> 在主規則中，遊戲設計為 1~4 名玩家各控制一個星際文明。當只有 1 名玩家時，核心系統無需改動，但以下維度需要針對性調整以確保完整的單人體驗。

---

## 第一章：單人遊戲核心調整

### 1.1 行動點數（AP）增幅

**參照**：《玩家規則書》1.3 節「行動經濟」

單人遊戲中，玩家需要處理的事務範圍不變（科研、建造、外交、軍事全由一人承擔），但缺少了其他玩家分擔多線壓力。因此對 行動點數（AP） 公式略作上調：

```
單人 行動點數（AP） = 4 + ⌊經濟力（ECO） / 3⌋
```

| 經濟力（ECO） | 單人 行動點數（AP）/週期 | 相比多人版 |
|:---:|:---:|:---:|
| 1-2 | 4 | +1 |
| 3-5 | 5 | +1 |
| 6-8 | 6 | +1 |
| 9-10 | 7 | +1 |

> 額外的 1 行動點數（AP） 用於補償缺少的玩家協作空間，GM 可根據實際遊戲節奏選擇是否啟用此調整。

### 1.2 危機規模調整

**參照**：《GM 規則書》第一章（原第四章）4.6 節「危機系統」

多人遊戲中，危機天災由多個文明共同對抗。單人遊戲中，危機按以下規則縮減：

| 玩家文明數 | 危機艦隊規模 | Boss 船體值（HP） 修正 | 階段推進速度 |
|:---:|:---:|:---:|:---:|
| 4 人（原始） | 100%（基準） | 100% | 基準 |
| 3 人 | 80% | 85% | 基準 |
| 2 人 | 65% | 70% | ×0.8 |
| **1 人** | **50%** | **55%** | **×0.6** |

> NPC 夥伴文明（見第二章）可根據其 軍事力（MIL） 屬性分擔壓力：每個忠誠 NPC 夥伴文明使危機規模等效 +1 玩家（即 1 玩家 + 2 個 NPC 夥伴 → 按 3 人折算）。

### 1.3 銀河共同體投票調整

**參照**：《GM 規則書》第一章（原第四章）4.3 節「銀河共同體」

單人遊戲中，銀河共同體的投票動態改為 GM 主導：

- 玩家提出的提案：按照常規 外交力（DIP） 檢定流程
- NPC 提出的提案：GM 每 5 週期隨機觸發一次 NPC 提案，為玩家提供外交抉擇機會
- 投票結果：以敘事為優先，不必嚴格計算所有 NPC 的票數——GM 只需決定「這次提案通過與否，以及這對故事意味著什麼」

### 1.4 GM 敘事節奏調整

**參照**：《GM 規則書》第一章（原第四章）4.7 節「GM 運行指南」

單人遊戲的核心優勢是 GM 可以將全部注意力放在一個玩家身上。調整要點：

- **「放大鏡」原則深化**：由於只有一個玩家文明，GM 可以更深入地描寫該文明內部的人物、事件和情感
- **三線敘事重構**：銀河線 + 文明線 + **英雄線**（代表性人物的個人故事成為主軸，而非點綴）
- **週期節奏**：每 3~4 週期穿插一次純敘事事件（不需消耗 行動點數（AP）），保持角色扮演的密度

## 第二章：NPC 夥伴文明系統

> 這是單人遊戲最重要的補充系統。夥伴文明是 GM 控制的、與玩家文明有長期合作關係的 NPC 文明。他們不是普通的外交對象——他們有性格、有成長弧線、有自己的目標，甚至可能背叛或被犧牲。

### 2.1 夥伴創建

使用《GM 規則書》第四章的 NPC 文明生成器，但額外設定以下維度：

| 維度 | 說明 |
|------|------|
| **性格原型** | 見 2.2 節 |
| **初始忠誠度** | 1~10（見 2.3 節） |
| **個人目標** | 該文明的核心追求（可能與玩家一致或衝突） |
| **關鍵人物** | 1~2 名有名字、有故事的領袖（GM 為其設計簡單背景） |
| **特殊羈絆** | 與玩家文明之間的歷史淵源（如何相識、共同經歷了什麼） |

#### 夥伴創建範例

> **文明名稱**：翠綠護衛星（Verdant Protectorate）
> **性格原型**：忠誠守護者
> **初始忠誠度**：8
> **個人目標**：「在銀河中證明小型文明也能有尊嚴地存在」
> **關鍵人物**：大德魯伊瑟蘭（Seran the Arch-Druid）——一位沉穩而固執的植物型族領袖，曾見證自己的母星被掠奪者摧毀，現在視玩家的文明為「值得保護的未來」
> **特殊羈絆**：玩家在翠綠護衛星最危難時伸出了援手（這是多年前的事了，GM 可與玩家共同編寫這段歷史）

### 2.2 夥伴性格原型

| 原型 | 行為傾向 | 忠誠度變化敏感點 |
|------|------|------|
| **忠誠守護者** | 主動提出軍事援助、資源分享 | 玩家背叛信任 → 大幅下降；共同戰鬥 → 大幅上升 |
| **謹慎觀察者** | 不輕易承諾、傾向獨自行動 | 玩家展示實力 → 緩慢上升；玩家過度要求 → 快速下降 |
| **野心同盟** | 精明計算利益、討價還價 | 玩家提供利益 → 上升；利益不對等 → 下降 |
| **導師型文明** | 提供科技和知識、保護弱小的玩家 | 玩家尊重其智慧 → 上升；玩家濫用科技 → 極速下降 |
| **復仇者** | 對第三方有深仇大恨，尋求盟友 | 玩家幫助復仇 → 極速上升；玩家與其仇敵和解 → 背叛風險 |
| **流浪文明** | 居無定所、隨時可能離開 | 玩家提供歸宿 → 上升；束縛其自由 → 下降 |

### 2.3 忠誠度系統

忠誠度（1~10）是 NPC 與玩家合作意願的數值化表達。

#### 忠誠度變化事件

| 事件 | 忠誠度變化 |
|------|:---:|
| 玩家在戰爭中援助夥伴 | +1~2 |
| 玩家與夥伴的敵人結盟 | -2~3 |
| 玩家分享一項科技 | +1 |
| 玩家拒絕夥伴的求助 | -2 |
| 夥伴的關鍵人物被玩家拯救 | +3 |
| 玩家在銀河共同體中支持夥伴的提案 | +1 |
| 玩家在衝突中犧牲夥伴的利益 | -3 |
| 共同完成一個重大目標（如擊敗危機 Boss） | +4（上限 10） |

#### 忠誠度效果

| 忠誠度 | 狀態 | 效果 |
|:---:|------|------|
| 9-10 | 誓約 | 夥伴無條件支援；共享所有科技；艦隊可合併指揮 |
| 7-8 | 信任 | 積極軍事協作；資源互助；科技交流意願高 |
| 5-6 | 友好 | 正常外交互動；部分軍事協助 |
| 3-4 | 冷淡 | 僅執行既有協議；不再擴展合作 |
| 1-2 | 疏遠 | 可能退出同盟；拒絕所有新請求 |
| 0 | 決裂 | 敵對或倒向玩家對手（觸發 GM 敘事事件） |

### 2.4 夥伴成長系統

夥伴文明與玩家同步成長，但不使用完整的 文明經驗值（CXP） 系統。改為以下簡化規則：

- **等級同步**：夥伴文明始終保持在玩家等級 -1 ~ -2 的水平（GM 根據夥伴規模和投入度微調）
- **科技同步**：當玩家解鎖新 Tier，夥伴在 2~4 週期後自動跟進（GM 可設定具體延遲以反映夥伴的科技實力）
- **艦隊同步**：夥伴的艦隊總 軍事力量（MP） 為玩家艦隊總 軍事力量（MP） 的 40%~80%，具體比例取決於夥伴的 軍事力（MIL） 屬性和忠誠度

### 2.5 夥伴背叛機制

夥伴背叛是單人遊戲中最具戲劇性的轉折之一。觸發條件：

- 忠誠度降至 0
- 玩家長期（5+ 週期）無視夥伴的核心目標
- 第三方（敵對文明/墮落帝國/危機）提出的條件遠超玩家的提供

**背叛敘事模板**：
1. GM 提前 2~3 週期埋下暗示（夥伴行為變得可疑、通訊減少、關鍵人物態度轉變）
2. 背叛發生時，GM 設計一場重大的敘事轉折（艦隊叛變、共同防禦計劃洩漏、關鍵科技被竊）
3. 背叛後故事不結束——轉為新的衝突線，玩家的反應決定後續走向

## 第三章：單人戰役專用規則

### 3.1 時間尺度靈活性

**參照**：《玩家規則書》0.3 節「核心循環」

單人遊戲中，GM 可根據敘事需要放寬時間尺度：

- **常規週期**：1 週期 ≈ 1 年（與多人遊戲一致）
- **快轉週期**：當玩家進入大規模建設或科技研發的密集期，GM 可將 2~3 週期合併為一個「階段」，只進行關鍵檢定
- **慢速週期**：當敘事處於關鍵外交談判或角色互動時，GM 可放大一個週期內的事件，用多個場景來描寫

### 3.2 英雄單位的深度規則

**參照**：《玩家規則書》2.11 節「領袖系統」

單人遊戲中，領袖（統治者、提督、科學家等）的個人故事變得更加重要：

- **個人任務**：每位領袖可有一個與主線戰役交織的個人任務線（例如：提督尋找失落的家族、科學家追尋某個理論的證明）
- **領袖互動**：GM 定期讓NPC夥伴的關鍵人物與玩家的領袖進行對話和互動
- **犧牲與傳承**：領袖的死亡不再是機械的「投骰→更替」，而是重要的敘事節點

### 3.3 多線程任務系統

單人遊戲中，玩家可能需要同時處理多條故事線。GM 應：

- 每週期開始時，列出目前活躍的**所有故事線**及其當前狀態
- 讓玩家選擇本週期要推進的 1~2 條線（配合 行動點數（AP） 消耗）
- 未被推進的故事線不會完全停滯——GM 描述背景變化並可能引入壓力
