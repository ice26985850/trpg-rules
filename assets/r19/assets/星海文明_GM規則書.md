# 第一章：銀河世界

## 4.1 世界觀核心

**時代背景**：星聯紀元 847 年。銀河處於微妙平衡——各大文明在漫長的擴張後形成了不穩定的權力格局。超空間航道網絡連接着數千個星系，銀河共同體維繫着脆弱的和平，而古老的威脅在黑暗中蠢動。

### 宇宙起源（三版本可選，GM 挑選）

| 版本 | 名稱 | 核心敘事 | 對遊戲的影響 |
|:---:|------|------|------|
| A | **大過濾** | 無數文明在達到星際階段前自我毀滅。倖存者稀少，銀河空曠而危險。 | 適合硬科幻、生存主題 |
| B | **星神棋局** | 遠古"星神"將銀河視爲棋盤。各大文明是棋子，偉大的"命途"在虛空中編織。 | 兼容靈能/命途系統，敘事性強 |
| C | **遠古遺物** | 多個"先驅者文明"曾統治銀河後消失，留下遍佈銀河的遺蹟與科技。 | 適合探索、考古驅動 |

> **推薦 B 版本（星神棋局）**：與靈能飛昇、文明倫理驅動、危機敘事最爲兼容。

### 銀河共同體

**組織架構**：
- **銀河議會**：5 個常任理事席（按 外交力（DIP） 權重選舉）+ 10 個非常任席
- **公約系統**：銀河貿易公約、星海軍事公約、環境保護公約等
- **制裁機制**：外交孤立 → 經濟制裁 → 軍事幹預
- **投票權重** = 外交力（DIP） 屬性值 + 飛昇/專長修正

**提案與投票流程**：
1. 任何成員文明可提出**銀河共同體提案**（1行動點數（AP））
2. 提案發起方投 外交力（DIP） 檢定：難度等級（DC） = 7 + ⌊反對文明數/3⌋
3. GM 逐一確定各 NPC 文明投票意向（基於倫理和關係）
4. 每個文明票數 = 投票權重。簡單多數通過
5. 緊急提案（如危機共同防禦）難度等級（DC）-1，但需要 2/3 多數

**提案類型示例**：
- 經濟制裁某文明（難度等級（DC）8）→ 目標文明銀河市場交易稅翻倍
- 共同防禦（難度等級（DC）7）→ 全部成員自動加入防禦戰爭
- 環境保護（難度等級（DC）6）→ 禁止對蓋亞世界/聖地轟炸
- 譴責決議（難度等級（DC）6）→ 目標文明外交關係全銀河 -10

> 外交大師飛昇：投票權重 ×2。某些墮落帝國可能無視共同體決議。

## 4.5 探索行動規則

> 探索是《星海文明》的核心驅動力。在遊戲初期，玩家的大部分週期都在「探測→發現→調查→驚喜/危機」的循環中度過。本章提供完整的探索流程規則和 GM 工具。

### 4.5.1 科研船與探測行動

#### 科研船屬性

每艘科研船是執行探索的獨立單位：

| 屬性 | 含義 | 基礎值 |
|------|------|:---:|
| 船體值 (HP) | 結構完整性（歸零 = 科研船被摧毀） | 200 |
| 探測範圍 | 可探測周圍多少跳的星系（超空間航道連接數） | 1 |
| 調查速度 | 完成一個異常調查需要的進度 | 2 進度/週期 |
| 傳感器等級 | 影響異常發現率和探測 目標值（TN） | 1（隨科技提升） |

**建造科研船**：50 合金，1 週期，1 能源（EC）/週期維護費。

**科研船在戰鬥中的表現**：非戰鬥單位，不參與艦隊戰。如被敵對艦隊攔截，自動嘗試緊急撤退（航速檢定 難度等級（DC） 7）；撤退失敗則被俘獲或摧毀。

**可升級科技**：
- 超空間探測 T1 → 探測範圍 +1
- 重力傳感 T2 → 探測範圍 +1，傳感器 +1
- 超空間引擎 T3 → 探測範圍 +2
- 全知傳感 T5 → 探測範圍 +3，所有探測 目標值（TN）-1

#### 探測行動流程

當一艘科研船進入**未被任何文明探測過的星系**時，執行以下流程：

```
┌─────────────────────────────────────────────┐
│           星系探測流程（1行動點數（AP））                 │
│                                              │
│  ① 進入星系                                  │
│  ② 投探測檢定：科研力（SCI） 骰池 vs 目標值（TN）                │
│     目標值（TN） 基準 = 5                              │
│     星雲內 目標值（TN）+1 | 黑洞/中子星 目標值（TN）+2           │
│     傳感器每級 目標值（TN）-1                          │
│  ③ 按成功度確定探測結果：                    │
│     大成功 → 完整數據 + 自動發現異常         │
│     成功 → 完整數據（恆星+行星+資源）        │
│     部分成功 → 基礎數據（恆星+行星數，無詳情）│
│     失敗 → 僅恆星類型                        │
│     大失敗 → 數據錯誤 + 科研船受損(船體值（HP）-20%)   │
│  ④ 記錄星系數據到星圖                        │
│  ⑤ 如有異常發現，觸發異常調查階段             │
└─────────────────────────────────────────────┘
```

#### 探測 目標值（TN） 修正表

| 修正來源 | 效果 |
|----------|------|
| 星雲 | 目標值（TN）+1 |
| 黑洞系統 | 目標值（TN）+2 |
| 中子星/脈衝星 | 目標值（TN）+2 |
| 傳感器等級（每級） | 目標值（TN）-1 |
| 科學家領隊（每級技能） | 目標值（TN）-0.5（向下取整，即每2級-1） |

### 4.5.3 異常調查系統

#### 異常等級與 難度等級（DC）

| 異常等級 | 調查 難度等級（DC） | 典型類型 | 基礎調查進度需求 |
|:---:|:---:|------|:---:|
| Lv1 常見 | 6 | 地質異常、生物信號 | 4 進度 |
| Lv2 不尋常 | 7 | 引力波動、異常輻射 | 6 進度 |
| Lv3 罕見 | 8 | 遠古科技信號、亞空間回聲 | 9 進度 |
| Lv4 極度罕見 | 9 | 外星結構體、虛空裂隙 | 12 進度 |
| Lv5 傳奇 | 10 | 先驅者主遺蹟、銀河奇觀 | 16 進度 |

#### 調查行動流程

```
1. 科研船對已發現的異常執行調查（1行動點數（AP））
2. 投 科研力（SCI） 骰池檢定 vs 異常 難度等級（DC）
   大成功 → 3 進度 + 額外發現
   成功 → 2 進度
   部分成功 → 1 進度
   失敗 → 0 進度
   大失敗 → -1 進度（數據污染）+ 可能觸發危險事件
3. 累積進度 ≥ 需求 → 異常完成，獲得獎勵
4. 如果放棄調查 → 異常變爲"未解之謎"（其他文明可後來調查）
```

### 標準 GM 回合流程

```
① 銀河事件階段
   投事件骰 → 宣佈本週期銀河級事件（異常/外交變動/危機推進）

② 玩家行動階段
   各文明按順序消費 行動點數（AP） 執行行動 → 投骰判定

③ NPC 行動階段
   按 NPC 行爲 AI 決策樹自動執行 NPC 文明行動

④ 外交與互動階段
   玩家間外交 / 玩家-NPC 外交 / 銀河共同體投票

⑤ 結算階段
   資源產出結算 / 科技進度結算 / 厭戰度更新 / 領袖升級
```

### 「放大鏡」原則：文明經營中的敘事

> **在宏觀數據之下，始終關注微觀的人。**

- 一場艦隊戰不只是數值對抗——描述旗艦艦橋上的緊張氣氛、年輕艦長第一次指揮戰鬥
- 一顆行星被殖民不只是 +1 人口——描述第一批殖民者踏上新世界時的震撼
- 科技突破不只是解鎖新武器——描述實驗室中科學家看到突破性數據的狂喜
- 三條並行敘事線：**銀河線**（大局變化）+ **文明線**（國運起伏）+ **個人線**（代表性人物故事）

### NPC 文明行爲 AI

```
① 評估當前威脅等級（鄰居軍力 / 危機存在 / 邊境壓力）
② 檢查外交協定約束（同盟義務 / 互不侵犯 / 防禦條約）
③ 確定核心目標（擴張 / 科研 / 防禦 / 復仇）
④ 分配本週期 行動點數（AP）（基於性格權重）
   · 好戰型：軍事力（MIL） 60% / 經濟力（ECO） 20% / 科研力（SCI） 10% / 外交力（DIP） 10%
   · 科技型：科研力（SCI） 50% / 經濟力（ECO） 25% / 外交力（DIP） 15% / 軍事力（MIL） 10%
   · 外交型：外交力（DIP） 40% / 經濟力（ECO） 30% / 科研力（SCI） 15% / 軍事力（MIL） 15%
   · 孤立型：經濟力（ECO） 40% / 科研力（SCI） 30% / 軍事力（MIL） 20% / 外交力（DIP） 10%
⑤ 執行行動
⑥ 更新對其他文明的態度（友好↔敵對累計變化的閾值觸發）
```

### 三層信息結構

| 層級 | 內容 | 獲取方式 |
|:---:|------|------|
| **公開** | 銀河地圖已知部分、共同體決議、公開戰爭 | 自動可見 |
| **外交** | 文明態度、貿易意願、基本國力 | 外交力（DIP） 檢定或外交協議 |
| **祕密** | 具體艦隊位置、科技進度、諜報目標、危機真相 | 情報力（INT） 檢定、特殊事件 |

### 模組框架

**標準戰役結構**：鉤子（3 週期）→ 發展（5-8 週期）→ 轉折（2-3 週期）→ 高潮（3-5 週期）→ 結局（2 週期）

**預設戰役概念一：「銀河大探索」**
適合時代 I-II。玩家文明首次踏入深空，發現異常、接觸新文明、與太空生物遭遇。核心衝突：首次接觸的選擇、資源爭奪。

**預設戰役概念二：「危機降臨——虛空的飢餓」**
適合時代 IV-V。維度裂縫在銀河核心張開，虛空生物湧入。玩家必須抉擇：聯合對抗？趁機擴張？還是尋求墮落帝國的幫助？
