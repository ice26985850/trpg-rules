# 序章：歡迎來到銀河

## 0.1 遊戲概述

《星海文明》是一款**銀河尺度**的文明經營 TRPG。你不是操控一個冒險者，而是操控**一整個星際文明**——從單一母星起步，探索銀河、殖民行星、研發科技、縱橫外交、征戰星海，最終在銀河歷史中留下你的印記。

| 角色 | 人數 | 職責 |
|------|:---:|------|
| **銀河主宰（GM）** | 1 | 掌控銀河本身：NPC 文明、太空生物、異常事件、危機天災 |
| **玩家文明** | 1~4 | 各操控一個星際文明，制定戰略、發展國力、書寫史詩 |

## 0.2 所需材料

- 若干十面骰（d10），每位玩家至少 10 顆
- 文明角色卡（見附錄 C）
- 星圖（由 GM 繪製或生成）
- 本規則書

## 0.3 核心循環

每一局《星海文明》在以下循環中推進：

```
┌─────────────────────────────────────────────────┐
│              星曆週期 (Stellar Turn)              │
│                                                  │
│  ① GM 宣佈銀河事件（異常、外交、危機）             │
│  ② 玩家花費行動點數(AP)執行行動                   │
│  ③ 投骰判定行動結果                               │
│  ④ NPC 文明按行爲 AI 自動行動                     │
│  ⑤ 結算週期收益（資源產出、科技進度、厭戰度等）     │
│  ⑥ 進入下一週期                                   │
└─────────────────────────────────────────────────┘
```

> **時間尺度**：1 星曆週期(ST) ≈ 遊戲內 1 年。一局完整戰役通常 50~100 週期。

# 第一章：核心規則

## 1.1 骰子系統：d10 骰池（成功計數制）

### 核心機制

擲 **N** 個十面骰（d10），每個骰子結果 **≥ 目標值(TN)** 計爲 1 **成功**。實際成功數 **S** ≥ 要求成功數 **RS** 則檢定成功。

| 參數 | 代號 | 含義 | 來源 |
|------|------|------|------|
| 骰池大小 | N | 擲多少顆 d10 | 對應屬性值（1-10） |
| 目標值 | TN | 每顆骰子需要 ≥ 多少纔算成功（3-9） | GM 按難度設定 |
| 要求成功數 | RS | 需要累積多少成功（默認 1） | GM 按複雜度設定 |
| 實際成功數 | S | 最終 ≥目標值（TN） 的骰子數量 | 擲骰結果 |

### 難度階梯

| 難度 | 目標值（TN） | 每骰成功率 | 典型場景 | 建議 要求成功數（RS） |
|------|:---:|:---:|------|:---:|
| 輕而易舉 | 3 | 80% | 日常行政、友好文明間貿易 | 1 |
| 常規 | 5 | 60% | 標準外交、常規建造 | 1 |
| **標準** | **6** | **50%** | **戰鬥指揮、科技研發、祕密行動（默認）** | **1-2** |
| 有挑戰 | 7 | 40% | 複雜談判、逆向工程、敵境滲透 | 2 |
| 困難 | 8 | 30% | 突破性研究、絕境防禦 | 2-3 |
| 極難 | 9 | 20% | 奇蹟工程、銀河級外交 | 3+ |
| 近乎不可能 | 10* | 10% | 扭轉銀河格局 | 4+ |

> \*目標值（TN）=10 特殊規則：骰出 10 算 1 成功並**暴擊**——再擲一次，若再出 10 繼續累積。

## 1.4 檢定流程

### 標準檢定

```
1. 聲明意圖：玩家說明行動目標
2. 確定參數：GM 設定 —
   · 關聯屬性(A)：對應屬性值 = 骰池大小 N
   · 目標值(TN)：任務固有難度（默認 6）
   · 要求成功數(RS)：任務複雜度（默認 1）
3. 應用修正：科技加成(+骰)、規模修正(±目標值（TN）)、協助(+骰)、特質(±目標值（TN） 或 +骰)、充分準備(目標值（TN）-1)
4. 擲骰判定：擲 N 顆 d10，統計 ≥目標值（TN） 的成功數 S
5. 比對結果：
   · S ≥ 要求成功數（RS） → 成功
   · S = 要求成功數（RS）-1 → 部分成功
   · S < 要求成功數（RS）-1 → 失敗
```

### 修正來源彙總

| 修正來源 | 效果 | 上限 |
|----------|------|:---:|
| 領袖技能等級 | 每級 +1 骰 | +5 骰 |
| 科技加成 | 關鍵科技在對應領域 +1~3 骰 | +3 骰 |
| 規模優勢 | 大文明對小文明，軍/經 目標值（TN）-1~2 | 目標值（TN） 最低 3 |
| 規模劣勢 | 大文明在隱匿/情報 目標值（TN）+1~2 | — |
| 協助參與 | 每協助方 +1 骰給主導方 | +3 骰 |
| 文明特質 | 物種/倫理特質 ±目標值（TN） 或 +骰 | ±2目標值（TN） / +2 骰 |
| 充分準備 | 額外消耗 1行動點數（AP），目標值（TN）-1 | 疊加 1 次 |
| 倉促行動 | 不消耗 行動點數（AP） 但 目標值（TN）+2 | — |

### 成功度

| 結果 | 條件 | 效果 |
|------|------|------|
| **大成功** | S ≥ 要求成功數（RS）+3 或所有骰子都成功 | 超額完成，觸發額外收益 |
| **成功** | S ≥ 要求成功數（RS） | 達成預期目標 |
| **部分成功** | S = 要求成功數（RS）-1 | 基本目標達成但附帶代價/副作用 |
| **失敗** | S < 要求成功數（RS）-1 且 S > 0 | 未能達成目標 |
| **大失敗** | S = 0 且至少一個骰子顯示 1 | 災難性結果，嚴重副作用 |

## 1.5 對抗檢定

適用場景：外交談判、科技競賽、情報對抗、軍事對峙。

**流程**：
```
1. 雙方各擲對應屬性骰池（含修正）
2. 分別計算成功數 S_A 和 S_B
3. 比較：
   · S_A > S_B → A 勝，勝利度 DoV = S_A - S_B
   · S_A = S_B → 依次比較：10 的數量 → 1 的數量（少者勝）
   · 完全平局 → 僵局
```

## 1.7 人口系統

人口是文明的基礎——每一點人口既生產資源，也消耗資源。人口總數決定了文明的體量和負擔。

### 人口數量

每顆行星擁有獨立的人口數量：

| 行星類型 | 起始人口 |
|----------|:---:|
| 母星 | 5 |
| 新殖民地（殖民船到達） | 1 |
| 被征服行星（佔領後） | 現有人口 - d3（戰爭損耗） |

**人口上限**：每顆行星基礎容量 = 5 + 行星宜居度修正（80%+ → +3, 60-79% → +1, 40-59% → +0）。可通過建造「居住區」建築提升。

### 人口增長

每顆行星每週期進行人口增長檢定：

```
人口增長檢定：擲 1d10
- 基礎增長閾值：8+（即每週期 30% 概率增長 1 人口）
- 食物盈餘修正：食物淨產出 ≥ 2 → 閾值降低至 7+（40%概率）
                食物淨產出 ≥ 4 → 閾值降低至 6+（50%概率）
                食物淨產出 ≥ 6 → 閾值降低至 5+（60%概率）
                食物淨赤字 → 閾值提升至 9+（20%概率），人口可能減少
- 宜居度修正：80%+ → 無修正 | 60-79% → 閾值+1 | 40-59% → 閾值+2
- 特質修正：快速繁殖 → 閾值-1 | 低繁殖力 → 閾值+1
```

> 快速示例：母星（宜居度 80%、食物盈餘 4）→ 增長閾值 6+，即每週期 50% 概率 +1 人口。

### 每人口產出與消耗

每人口的**基礎淨貢獻**（產出 - 消耗）：

| 項目 | 每人口/週期 | 說明 |
|------|:---:|------|
| 能量幣產出 | +2 | 來自基礎能源設施 |
| 礦物產出 | +1.5 | 來自基礎礦區 |
| 食物產出 | +2 | 來自基礎農業 |
| 合金產出 | +1.0 | 來自基礎工業 |
| 消費品產出 | +0.5 | 來自基礎輕工業 |
| 食物消耗 | -1 | 每人口必須消耗 |
| 消費品消耗 | -0.25 | 基礎生活需求 |

**礦物消耗**：工程船維護費 0.5 MIN/週期，每個礦站 0.5 MIN/週期（設備損耗），每個研究站 0.5 MIN/週期。

> 以上爲基礎值。**行星類型修正**（蓋亞世界全+20%、荒漠世界礦物+30% 等）和**建築**會進一步調整產出。

| 行星 | 人口 | 宜居度 | 增長閾值 | 淨產出 能源（EC）/礦物（MIN）/食物（FOOD）/合金（ALLOY）/消費品（CG） |

## 1.8 穩定度系統

穩定度代表行星上的社會秩序、民心向背和生產力狀態。每顆行星獨立計算。

### 穩定度公式

```
行星穩定度 = UNI（文明凝聚力基線）
            + 消費品修正（充足 +10 / 短缺 -15）
            + 戰爭修正（本國處於戰爭 -5 / 敵艦隊在本星系 -10）
            + 種族修正（有受歧視種族人口 每類 -5）
            + 派系修正（滿意派系 +5 每類 / 不滿派系 -5 每類）
            + 總督修正（總督技能等級 ×2）
            + 事件修正（GM 裁定 ±5~20）
```

### 穩定度閾值效果

| 穩定度 | 狀態 | 效果 |
|:---:|------|------|
| 90-100 | 烏托邦 | 全產出 +20%，人口增長閾值 -1 |
| 70-89 | 繁榮 | 全產出 +10% |
| 40-69 | 穩定 | 無修正 |
| 20-39 | 動盪 | 全產出 -20%，每週期 10% 概率觸發**抗議事件** |
| 1-19 | 危機 | 全產出 -50%，每週期 30% 概率觸發**叛亂** |
| 0 或以下 | 崩潰 | 行星立即宣佈獨立或倒向敵國 |

**抗議事件（d6）**：1-2 罷工（產出再-10% 持續 2 週期）/ 3-4 騷亂（需要 1行動點數（AP） 鎮壓或讓步）/ 5-6 地方自治運動（GM 敘事事件）

**叛亂**：行星生成叛軍（實力 = 人口×20 軍事力量（MP） 的地面部隊）。需要派遣陸軍鎮壓或在外交上讓步。

### 提升穩定度的方法

- 消耗 1行動點數（AP） 執行「內部維穩」→ 投 凝聚力（UNI） 檢定，成功使目標行星穩定度 +5~15
- 確保消費品充足（每個行星檢查：消費品產出 ≥ 人口×0.25）
- 任命高技能總督
- 滿足派系要求（見 1.10）
- 宣發運動（特殊行動，凝聚力（UNI）=7，成功 +10 穩定度持續 3 週期）

## 1.9 帝國規模與懲罰

帝國規模代表文明的行政管理負擔。疆域越大，集中管理越困難。

### 規模計算

```
帝國規模 = 星系總數 × 2 + 殖民行星數 × 5 + 總人口 × 0.3
```

> 例：初始文明（1 母星系 + 1 殖民地 = 2 星系, 2 行星, 6 人口）→ 規模 = 2×2 + 2×5 + 6×0.3 = 4 + 10 + 1.8 = 15.8 ≈ 16

### 規模懲罰閾值

| 規模 | 狀態 | 科技研究 目標值（TN） | 傳統解鎖成本 |
|:---:|------|:---:|:---:|
| ≤50 | 精簡高效 | 無修正 | 基準 |
| 51-100 | 管理壓力 | +1 | +30% |
| 101-200 | 官僚膨脹 | +2 | +60% |
| ≥201 | 臃腫帝國 | +3 | +100% |

> 專長「高效行政」：所有懲罰效果 -20%（即閾值變爲 60/120/240）。
> 科技「星際行政 T1/T2/T3」：每級使規模懲罰閾值 +20。

## 1.10 派系系統（簡述）

派系是文明內部的政治團體。每個文明在達到一定規模後會產生派系。

### 派系產生

- 文明人口 ≥ 10 → 產生第一個派系
- 每增加 15 人口 → 可能產生新派系（GM 裁定，通常基於倫理衝突）
- 最大派系數 = 3 + ⌊文明等級/4⌋

### 派系訴求

每個派系有 1-2 個**核心訴求**，例如：
- 軍國派系：「對外發動一場戰爭」
- 和平派系：「與所有鄰國簽訂互不侵犯條約」
- 科技派系：「保持至少 1 項 Tier 領先鄰國」
- 宗教派系：「保護聖地不被異教徒玷污」

### 派系影響

| 派系滿意度 | 效果 |
|:---:|------|
| 滿意（訴求被滿足） | 該派系所在行星穩定度 +5；影響力產出 +1/週期 |
| 中立 | 無修正 |
| 不滿（訴求被忽視） | 該派系所在行星穩定度 -5；可能觸發抗議或分裂事件 |

> GM 可將派系作爲敘事引擎——不滿的派系領袖可能成爲叛亂核心，滿意的派系則可能提供意外幫助。

### 虛空擾動（靈能文明專屬）

靈能文明（靈能體物種 / 靈能覺醒起源）與虛空維度存在天然連接。這是雙刃劍。

**每週期末**，GM 爲靈能文明**暗投 1d10**（玩家不可見結果，但 GM 可描述徵兆）：

| d10 | 結果 | 效果 |
|:---:|------|------|
| 1 | **虛空風暴** | 隨機一個行星穩定度-15，靈能艦隊本週起航速-2 |
| 2-3 | **虛空低語** | GM私下告知玩家一條模糊的預言/警告（真僞不定） |
| 4-5 | **虛空饋贈** | 本週期靈能檢定+1骰；獲得 5 靈能點 |
| 6-10 | 無事發生 | 虛空平靜 |

**靈能點**：靈能文明每週期獲得 2 靈能點（上限 20），用於特殊靈能戰鬥能力（見 3.8）。

> 靈能飛昇後虛空擾動頻率翻倍（每週期改爲暗投 2d10，取較低值——更頻繁觸發）。

- **自然壽命**：領袖每 10 週期進行一次**衰老檢定**（1d10，結果 ≤ 當前等級 → 壽命耗盡，自然死亡）

- 短壽特質：檢定閾值改爲 `等級 + 2`
- 機械體/合成體領袖：不朽，無自然死亡
- **戰鬥死亡**：旗艦被摧毀 → 艦隊提督投 1d10，結果 ≤ 3 → 陣亡
- **更替**：統治者死亡後按政體規則自動更替（選舉/世襲/指定）
- **繼承**：新領袖起始等級 = 前任等級 - d3（最低 1）

### 領袖升級

- 領袖通過完成行動積累經驗
- 每週期主導方：檢定成功 +1 經驗，大成功 +2
- 等級提升：經驗累積到 `當前等級 × 3` → 等級 +1
- 每次升級 GM 提供 3 個隨機領袖特質，玩家選 1

## 2.14 殖民與擴張

### 殖民流程

1. **建造殖民船**：消耗 150 合金，2 週期建造

### 傷害計算流程

```
最終傷害 = 基礎傷害 × 命中修正 × 穿透修正 × 類型修正 - 減傷

① 命中：擲 軍事力（MIL） 骰池(含武器精度加成) vs 目標值（TN） = 目標航速+閃避修正
   制導武器忽略閃避修正；點防禦單獨投攔截骰池

② 穿透：護盾穿透率決定多少傷害繞過護盾直擊裝甲/船體

③ 裝甲減傷：實際傷害 = 穿甲後傷害 - 目標裝甲值（最低 1）

④ 類型修正：
   · 能量對裝甲 -10% | 動能對護盾 +30%~50% | 爆炸對裝甲 +50%
   · 打擊機(轟炸機)對大型艦船 +30%
```

### 傷害承受順序

```
命中 → 閃避(直射武器) → 護盾吸收 → 護盾耗盡 → 裝甲減傷 → 扣除船體值

傷害分配默認"前線優先"（護衛艦→驅逐艦→巡洋艦→戰列艦→泰坦）
玩家可使用"集火"指令指定目標
```
