# 建國模擬 TRPG —— 怪物圖鑑

---

## 使用說明

本圖鑑收錄《建國模擬 TRPG》中可能遭遇的怪物和敵對生物。每個條目包含完整的遊戲數據，GM 可直接用於遭遇設計。

| 欄位 | 說明 |
|------|------|
| 挑戰等級（CR） | 怪物強度指標，影響遭遇難度 |
| 生命值（HP） | 怪物的生命值 |
| 攻擊力（ATK） | 每次攻擊的基礎傷害 |
| 防禦力（DEF） | 減少受到的傷害 |
| 移動力（MOV） | 每回合可移動的距離（格） |
| 士氣 | 士氣降至 0 時逃跑或崩潰 |

## 遭遇難度設計指南

| 玩家軍隊總攻擊力 | 建議挑戰等級（CR）範圍 | 難度 |
|----------------|---------------------|------|
| 10-30 | 1-3 | 簡易 |
| 31-60 | 3-6 | 普通 |
| 61-100 | 5-8 | 困難 |
| 101-150 | 7-12 | 極難 |
| 151-200 | 10-16 | 史詩 |
| 200+ | 14-20 | 傳奇 |

GM 可根據英雄單位的有無和使用者戰術進行調整。
