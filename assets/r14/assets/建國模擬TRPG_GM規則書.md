## 第一章：遊戲概述

### 1.1 這是什麼遊戲？

《建國模擬 TRPG》是一套以「國家經營」為核心的桌上角色扮演遊戲。玩家扮演從零開始建立國家的統治者——從 50 人的小營地開始，經歷部落時代、城邦時代、王國時代、帝國時代，最終可能進入傳奇時代。

### 1.2 遊戲的核心循環

```
國家創建 → 回合開始（春季）→ 玩家宣告行動 →
檢定擲骰 → 行動結算 → 危機觸發 → 回合結束 →
下一回合（夏季）→ ...（一年四回合）→ 時代演進
```

### 1.3 核心術語表

| 術語 | 全稱 | 說明 |
|------|------|------|
| 人口（POP） | 人口 | 國家的國民總數，決定勞動力和兵源 |
| 資源（RES） | 資源 | 糧食、礦產、木材等自然資源的綜合產出能力 |
| 經濟（ECO） | 經濟 | 貿易網絡、貨幣體系、稅收效率 |
| 軍事（MIL） | 軍事 | 軍隊規模、裝備品質、戰略能力 |
| 科技（TEC） | 科技 | 技術水平、研發速度、魔法體系 |
| 民心（MOR） | 民心 | 國民忠誠度、文化凝聚力、幸福指數 |
| 國力（NP） | 國力 | 國家綜合影響力，用於外交對抗 |
| 難度等級（DC） | 難度等級 | 檢定需要達到的目標數值 |
| 調整值（MOD） | 調整值 | 屬性對檢定的加減值 |
| 遊戲主持人（GM） | 遊戲主持人 | 主持遊戲、扮演世界的人 |
| 優勢（ADV） | 優勢 | 擲 2d20 取較高 |
| 劣勢（DIS） | 劣勢 | 擲 2d20 取較低 |

## 第二章：核心規則——骰子與檢定

### 2.1 骰子系統：d20 + 調整值

**檢定公式：**

```
檢定結果 = 1d20 + 屬性調整值（MOD）+ 其他加減值

成功條件：檢定結果 ≥ 難度等級（DC）
```

### 2.2 屬性調整值（MOD）

| 屬性值範圍 | 調整值（MOD） |
|-----------|-------------|
| 1 – 4 | -2 |
| 5 – 9 | -1 |
| 10 – 14 | 0 |
| 15 – 19 | +1 |
| 20 – 24 | +2 |
| 25 – 29 | +3 |
| 30 – 34 | +4 |
| 35 – 39 | +5 |
| 40 – 44 | +6 |
| 45 – 49 | +7 |
| 50 – 54 | +8 |
| 55 – 59 | +9 |
| 60 – 64 | +10 |
| 65 – 69 | +11 |
| 70 – 74 | +12 |
| 75 – 79 | +13 |
| 80 – 84 | +14 |
| 85 – 89 | +15 |
| 90 – 94 | +16 |
| 95 – 99 | +17 |
| 100+ | 每 +5 增加 +1 |

**公式：** MOD = ⌊(屬性值 - 10) ÷ 5⌋（向下取整）

### 2.3 難度等級（DC）

| 難度 | DC | 說明 | 範例 |
|------|-----|------|------|
| 極簡易 | 5 | 幾乎不可能失敗 | 建造簡易木柵 |
| 簡易 | 10 | 有經驗者輕鬆達成 | 開墾小型農田 |
| 普通 | 15 | 需要一定能力 | 與中立鄰國建立貿易 |
| 困難 | 20 | 需要專業能力或運氣 | 說服敵對鄰國停戰 |
| 極難 | 25 | 即使是專家也有風險 | 在沙漠中建立綠洲城市 |
| 傳奇 | 30 | 凡人難以企及 | 說服兩國放下世仇聯手抗敵 |

### 2.4 優勢（ADV）與劣勢（DIS）

- **優勢（ADV）：** 擲 2d20，取較高結果
- **劣勢（DIS）：** 擲 2d20，取較低結果
- 優勢和劣勢互相抵消

### 2.5 大成功與大失敗

- **大成功（爆擊）：** 自然擲出 20 → 自動成功 + 額外好處
- **大失敗（災難）：** 自然擲出 1 → 自動失敗 + 負面後果

### 2.6 檢定類型

**標準檢定：** 宣告行動 → 決定屬性和難度 → 擲骰 → 比對結果。

**對抗檢定：** 兩方同時擲骰，比較結果。用於外交談判、戰爭等。

**集體檢定（多人模式）：** 至少半數玩家成功則整體成功。

**協助檢定（Aid）：** 協助者先進行 1d20 + 相關屬性 檢定（難度 10）；成功則主行動者 +2（大成功 +4），失敗無加值（大失敗主行動者 −2）。單人遊戲中 GM 扮演的顧問 NPC 亦可協助。

### 2.7 四季調整

| 季節 | 特效 |
|------|------|
| 春 | 外交檢定 +1 |
| 夏 | 建設檢定獲得優勢（ADV） |
| 秋 | 貿易檢定 +2 |
| 冬 | 建設檢定獲得劣勢（DIS）；糧食消耗 ×1.3 |

## 第七章：建設系統

每回合建設上限 = 人口（POP）× 0.05（至少 1 項）。

**建材存量池**：建築花費中的木材 / 石材 / 鐵礦 是獨立存量池（見第四章）。有對應生產建築時每回合自動產出；否則市場 1 金幣 = 1 建材（部落時代無市場則須先建生產建築或貿易）。

**持續性金幣消耗（金幣 sink）**：每回合結算扣除——建築維護費 = 所有已建築「金幣花費」總和 × 2%（四捨五入）；軍隊軍餉 = 全軍單位「花費」總和 × 2%（民兵免軍餉）。避免早期假性貧窮與後期金幣溢出。

**建造時間（城邦以上）**：部落建築已標示（1–2 回合）；城邦 2 回合、王國 2–3 回合、帝國 3–4 回合、傳奇 4–5 回合（GM 可依規模微調）。

### 回合結束結算清單

```
☐ 金幣（GOLD） += 稅收（TAX） − 建築維護費 − 軍隊軍餉 − 其他支出
☐ 糧食（FOOD） += 糧食產出（秋 ×2） − 糧食消耗（FOD）；若 FOOD < 0 → 歸零且民心（MOR）−5
☐ 研究點數（RP） += 科技（TEC）× 0.5（每滿 50 RP 可花費解鎖一項「科技突破」：科技（TEC）+2 或專精增益）
☐ 計算人口自然增減（公式見下）
☐ 檢查時代升級條件
☐ 記錄所有數據變化
☐ 檢查特殊事件觸發
```

**人口自然增長：** 基礎成長率 3%；民心（MOR）≥ 60 且 糧食（FOOD）> 0 → +1%（共 4%）；民心（MOR）< 40 → −1%（流失）；糧食（FOOD）= 0 → 額外流失 FLOOR(缺口÷2)。「自由城邦」建國理念的「人口成長 +20%」為 × 1.2（乘到成長率上，非加 20 個百分點）。人口變動 = 人口（POP）× 成長率 × 種族修正（巨人裔 ×0.5、半身人 ×1.2），上限人口上限（CAP）。

### 英雄屬性（0-20）

武力（ATK）、智謀（INT）、魅力（CHA）、潛行（STL）、學識（KNW）、戰術（TAC）、手藝（CRF）、口才（ELO）、創造（CRE）。

### 英雄忠誠度（1-10）

| 忠誠 | 效果 |
|------|------|
| 1-3 | 可能叛逃 |
| 4-6 | 正常 |
| 7-9 | 任務獲得優勢（ADV） |
| 10 | 失敗可重擲一次 |

### 英雄個人戰鬥

英雄可以脫離軍隊、獨自執行任務或下場戰鬥（英雄 vs 英雄、英雄 vs 怪物）。

**生命值（HP）**：英雄的生命值 = 20 + 武力（ATK）× 4 + 體質（CON）× 2（體質由 GM 依背景給 0–10，預設 5）。

**戰鬥行動經濟**：英雄戰鬥採回合制，每名英雄每回合可執行 **1 個主要動作 + 1 個移動動作**（移動力 移動（MOV）= 3 + FLOOR(武力（ATK）÷ 5)）。戰鬥開始擲 1d20 + 潛行（STL）或武力（ATK）決定先攻。

**英雄防禦（DEF）**：英雄基礎防禦（DEF）= 10，再加上護甲加值（見物品圖鑑）。例如穿皮甲（＋2）的英雄防禦（DEF）= 12。

**傷害計算**：

```
命中檢定：1d20 + 對應英雄屬性（近戰用武力（ATK），遠程用潛行（STL），法術用學識（KNW）） ≥ 敵人防禦值（DEF）
近戰每擊傷害 = 英雄武力（ATK） + 武器攻擊加值 + FLOOR(武力（ATK）÷ 3)
遠程每擊傷害 = 英雄潛行（STL） + 武器攻擊加值 + FLOOR(潛行（STL）÷ 3)
（武器基礎傷害以英雄對應屬性為基準，武器「攻擊力 ＋N」疊加其上）
```

**怪物對英雄**：怪物命中 = 1d20 + 怪物攻擊（ATK） ≥ 英雄防禦（DEF）；命中後實際傷害 = 怪物攻擊（ATK） − 護甲加值（最低 1）。護甲因此同時提供閃避機會與傷害減免。

**休息與恢復**：在安全地點休息每回合恢復**最大生命值（HP）× 10%**（四捨五入，至少 1）；法力值（MP）同回合恢復 5（城鎮／神廟 10）。

**死亡與倒地**：生命值（HP）降為 0 時英雄**倒地**（失去行動能力，處於瀕死）。倒地後若無人救助，3 回合內未恢復則**陣亡**（永久失去該英雄）。可使用治療藥水、休息或法術恢復生命值。

### 英雄技能與法術

每位英雄依類型擁有 2–3 個專精技能（見下表），並可透過任務與訓練學習通用技能。施放法術需消耗**法力值（MP）**（見第二十六章）。

| 英雄類型 | 專精技能（示例） | 關鍵屬性 |
|----------|----------------|----------|
| 將軍（GEN） | 戰術指揮（全軍 +2 攻擊）、衝鋒號令、堅守陣線 | 武力（ATK）、戰術（TAC） |
| 間諜（SPY） | 潛行滲透、情報竊取、下毒（目標 −3 屬性/回合，2–3 回合） | 潛行（STL）、智謀（INT） |
| 學者（SCH） | 奧術飛彈（傷害 2d6+學識）、鑑定、快速研究 | 學識（KNW）、智謀（INT） |
| 使節（ENV） | 說服（對抗 +3）、締約、外交情報 | 魅力（CHA）、口才（ELO） |
| 傳奇工匠（ART） | 附魔（裝備 +1）、速建（建設 −1 回合）、發明 | 手藝（CRF）、創造（CRE） |

**通用技能**（任何英雄可學）：偵察、急救（恢復 1d6+2 生命值）、騎乘、恐吓、攀爬。

### 英雄裝備

英雄可穿戴武器與護甲，效果直接疊加至英雄的攻擊與防禦：

- **武器**（如鐵劍 攻擊力 +2）：加入英雄的武器基礎傷害。
- **護甲**（如皮甲 防禦力 +2）：加入英雄的防禦值（DEF）。
- **特殊裝備**（如火繩槍 攻擊力 +8 遠程）：依物品圖鑑數值生效。

> 裝備對「國家屬性」與「軍事單位」的生效規則，詳見玩家書第十三章；GM 可直接參考物品圖鑑數值。

### 英雄成長

英雄透過任務與訓練持續變強：每完成 3 次英雄任務（或累積 3 場英雄勝利戰鬥）獲得 1 點屬性點（單項上限 20）；亦可花費 50 金幣／回合進行專項訓練 +1 指定屬性。詳見玩家書第十一章第九節。

## 第十三章：GM 工具——難度等級設定完整指南

### 13.1 一般任務難度原則（非危機專用）

> ⚠️ **危機檢定不適用本節。** 所有危機的難度（DC）統一以【第十五章危機牌組】卡面 DC 為基準，再疊加 15.3 國力調整與 13.2 情境微調（完整規則見 13.5 危機 DC 統一框架）。本節僅供一般任務（建造、外交、研發等非危機行動）參考。

一般任務的 DC 可隨國家成長微調，但**漲幅必須小於國家調整值（MOD）漲幅**（MOD 現為每 5 點 +1），避免「越強越難」抵消專精優勢。建議以玩家書 2.3 六階 DC 為主，必要時依下表輕微加壓：

| 國力（NP）範圍 | DC 微調 | 說明 |
|--------------|--------|------|
| 1 – 50（部落～城邦） | ±0 | 基準不動 |
| 51 – 120（王國） | +1 | 國際政治略複雜 |
| 121 – 200（帝國） | +2 | 內憂外患並存 |
| 200+（傳奇） | +3 | 神級挑戰 |

### 13.2 難度微調因子

根據以下因子調整基礎難度（DC）：

| 因子 | 調整 |
|------|------|
| 玩家資源充足（金幣 > 500） | DC +2（有錢能解決的事本就不該太容易） |
| 玩家處於弱勢（某屬性 < 20） | DC -2（給奮鬥中的小國一線生機） |
| 有英雄協助 | DC -3（英雄是專業的） |
| 玩家已成功處理過同類危機 | DC +2（重複挑戰變得更難，避免刷資源） |
| 這是玩家的建國理念相關行動 | DC -2（理念是國家專長） |
| 這行動違背建國理念 | DC +3（違背理念的代價） |

### 13.4 隱藏難度

GM 永遠不應直接告訴玩家難度（DC）數值。改為使用描述性語言：

| 不要說 | 應該說 |
|--------|--------|
| 「難度是 15」 | 「這項任務需要一定的外交手腕」 |
| 「難度是 25，太難了」 | 「你的顧問團一致認為這幾乎不可能——但並非完全沒有希望」 |
| 「難度降了 2 因為你有英雄」 | 「你的將軍站在地圖前，指出了幾個關鍵突破口」 |

### 13.5 危機 DC 統一框架（唯一標準）

為避免多套 DC 規則互相衝突，所有危機檢定統一採用以下單一算式，**不再套用 13.1 的時代基準 DC**：

```
危機最終 DC = 危機牌組卡面 DC（第十五章）
            + 15.3 國力（NP）嚴重度調整（−5 ~ +5）
            + 13.2 情境微調因子（如：英雄協助 −3、理念相關 −2、違背理念 +3 等）
```

- 牌組卡面 DC 已是設計者依危機強度標定的基準，勿再額外疊加 13.1 的時代 DC。
- 15.3 的國力調整範圍僅 −5 ~ +5，刻意壓低，使高發展國家的 MOD 優勢（每 5 點 +1）不被危機 DC 完全抵消。
- 一般任務（非危機）才適用 13.1 的輕微 DC 微調。

### 14.3 戰爭回合結構

進入戰爭後，每回合分為以下階段：

1. **情報階段：** 雙方獲得敵方部隊情報（需斥候/間諜）
2. **調度階段：** 移動部隊、部署陣型
3. **交戰階段：** 雙方擲骰對抗

```
戰役結果 = 1d20 + 軍事（MIL）調整值（MOD）+ 指揮官戰術（TAC）+ 地形調整

傷害計算：
若攻擊方勝出：
    傷害值 = 攻擊力 - 防禦力 + (擲骰差值 ÷ 2)
    敵方損失單位數 = 傷害值 ÷ 敵方單位防禦力（至少 1）
```

4. **戰果結算：** 計算傷亡，判定撤退/追擊
5. **士氣判定：** 損失過半時進行士氣檢定

### 14.4 士氣系統

| 士氣值 | 效果 |
|--------|------|
| 100 | 全軍優勢（ADV） |
| 75 – 99 | 正常作戰 |
| 50 – 74 | 每回合檢定是否潰散（難度 15） |
| 25 – 49 | 劣勢（DIS），每回合檢定（難度 12） |
| 0 – 24 | 自動潰散——全軍撤退 |

士氣受以下影響：
- 將領陣亡：-30
- 連續勝利：+10/場
- 連續失敗：-15/場
- 後方遭襲：-20
- 英雄將軍在場：+15

### 14.5 戰爭結束條件

| 條件 | 結果 |
|------|------|
| 一方全軍覆沒 | 另一方佔領領土 |
| 一方求和 | 談判條件（金幣/領土/資源賠償） |
| 雙方僵持 > 8 回合 | 自動進入和談（雙方國力各 -10） |
| 第三方介入 | 調停——GM 判定結果 |

### 14.6 戰爭對國家屬性的影響

每回合戰爭結束時：

```
人口（POP） 減少 = 損失單位數 × 2
資源（RES） 減少 = 戰爭回合數 × 1
經濟（ECO） 減少 = 戰爭回合數 × 0.5
軍事（MIL） 減少 = 損失單位數 × 0.5（暫時性）
民心（MOR） 減少 = 戰爭回合數 × 1（敗方 × 2）
```

## 第十六章：鄰國人工智慧系統

### 16.1 鄰國行為模式

GM 管理鄰國時，使用以下簡化流程：

每回合為每個鄰國執行：

```
1. 擲 1d6 決定行動傾向（ACTION）
2. 根據關係值和行動傾向執行行動
3. 更新鄰國自身屬性
```

| 行動傾向（1d6） | 行為 |
|----------------|------|
| 1 | 侵略性：發動攻擊/宣戰/擴張 |
| 2 | 外交性：提出協定/聯盟/聯姻 |
| 3 | 防禦性：建設防禦/加強邊境 |
| 4 | 經濟性：發展貿易/投資建設 |
| 5 | 內向性：處理內部事務 |
| 6 | 機會性：根據當前局勢選擇最有利行動 |

### 16.2 鄰國關係自動變化

每回合，根據以下因素自動調整鄰國關係：

| 因素 | 變化 |
|------|------|
| 邊境接壤 | -1（接壤帶來摩擦） |
| 活躍貿易 | +1（每條貿易路線） |
| 軍事同盟 | +2 |
| 國力差距 > 30 | -1（弱小方恐懼，強大方傲慢） |
| 相同種族佔比 > 50% | +1 |
| 長期無衝突（> 10 回合） | +1 |
| 間諜活動被發現 | -15 |

### 16.3 鄰國自主發展

每個鄰國也遵循相同的時代演進規則，但進度由 GM 根據劇情需要控制。建議：

- 初始鄰國與玩家同步發展
- 遠處的大國可以比玩家領先一個時代
- 傳奇時代僅限於玩家和極少數勢力

## 第十七章：世界觀設定——埃爾登大陸

### 17.1 世界概述

**埃爾登（Elden）** 是一片廣袤的新大陸。五百年前，舊大陸的文明在「大崩解」（The Sundering）中毀滅——一場原因不明的魔法災難撕碎了舊世界的秩序。倖存者乘坐殘破的船隊抵達埃爾登，發現這片土地已經存在著古老的遺跡、未知的魔力，以及許多在舊世界只是傳說中的智慧種族。

### 17.2 創世神話

埃爾登的原住民（精靈、矮人、龍裔等）流傳著一個共同神話：

> 在世界之初，五位創世神分別創造了五個種族：大地之神「格蘭（Gran）」塑造了矮人、生命之神「席爾瓦（Sylva）」喚醒了精靈、戰爭之神「卡恩（Karn）」賦予獸人生命、智慧之神「密涅瓦（Minerva）」點化了龍裔、命運之神「法圖姆（Fatum）」創造了人類。
>
> 但法圖姆覺得人類太過脆弱，於是向其他四位神明借來了力量——矮人的堅韌、精靈的靈巧、獸人的勇氣、龍裔的威嚴——混合成了人類的無限可能性。這也是為什麼人類能與任何種族和平共存的原因。

### 17.3 魔法系統

魔法在埃爾登是一種**自然力**——就像風和水一樣。魔法源自「魔力流（Ley Lines）」——貫穿大地的能量線。

| 魔法類型 | 來源 | 使用者 |
|----------|------|--------|
| 奧術魔法 | 魔力流（Ley Lines）直接提取 | 法師、巫師（需天賦 + 訓練） |
| 神聖魔法 | 神明賜予 | 祭司、聖騎士（需信仰） |
| 自然魔法 | 生命能量 | 德魯伊、遊俠（需與自然共鳴） |
| 符文魔法 | 古代符文 | 矮人符文匠（需傳承） |
| 煉金術 | 材料組合 | 任何人（需設備 + 知識） |

### 法力值（MP）系統

施法與部分英雄技能需消耗**法力值（MP）**：

- **法力上限（MP_MAX）** = 10 + 學識（KNW）× 2（學者類英雄通常最高）。
- **每回合恢復**：休息一回合恢復 5 點；城鎮 / 神廟休息恢復 10 點。
- **消耗**：普通法術 2–5 點；強力法術 6–10 點。
- **補充**：「初級法力藥水」恢復 10 點法力值（見物品圖鑑）。

### 施法規則

```
施法檢定：1d20 + 對應英雄屬性（原始值） ≥ 法術難度（DC）
施法屬性：奧術 / 自然 = 學識（KNW）；神聖 = 魅力（CHA）；符文 / 煉金 = 手藝（CRF）
失敗：浪費法力值（MP）且無效果；大失敗（自然 1）：法力值（MP）反噬，自身受到 1d6 傷害
```

> 完整法術清單與英雄技能細節，見[第二十六章：英雄技能與法術完整清單](#第二十六章英雄技能與法術完整清單)。

## 第二十一章：單人遊戲主持指南

### 21.1 單人遊戲的特殊性

預設模組相容單人（1 GM + 1 玩家）。以下是單人模式特有的注意事項：

1. **GM 必須同時扮演對手：** 你操控的鄰國必須有策略思維——不是隨機行動，而是有目標、有性格。
2. **沒有隊友分擔：** 玩家的每個決定都獨自承擔後果。確保失敗不是死路——永遠提供「第二方案」。
3. **配角 NPC 很重要：** 玩家的顧問、將軍、家人是填補空位的關鍵。

### 21.2 配角 NPC 設計

為玩家設計 3-5 個核心配角 NPC：

| 角色 | 功能 | 範例性格 |
|------|------|----------|
| **宰相/首席顧問** | 提供建議、管理日常 | 謹慎保守 / 激進改革派 |
| **將軍** | 軍事建議、指揮前線 | 忠誠老兵 / 野心勃勃 |
| **財政大臣** | 經濟數據分析 | 吝嗇精算 / 慷慨投資者 |
| **繼承人** | 個人情感線、未來保障 | 青澀但聰明 / 叛逆不羈 |
| **摯友/導師** | 情感支持、倫理指引 | — |

每個配角有：
- 名字、年齡、性格特質
- 對國家的忠誠度和個人目標
- 與玩家角色的關係

### 21.3 單人玩家的「安全網」

| 安全網機制 | 說明 |
|------------|------|
| **天命重擲** | 每個時代可重擲一次（不限於自己的行動） |
| **繼承機制** | 統治者死亡時，繼承人接管（保留 70% 國家數據） |
| **流亡政府** | 國家被滅時，可帶領殘部流亡他處重建（保留 50%） |
| **命運轉折點** | 重大失敗後，GM 提供一個「黑暗中的微光」選擇 |

### 21.4 多人模式變體（可選）

若玩家超過 1 人，可採用以下模式：

**A. 各自為政：** 每位玩家治理一個獨立國家（適合 2-4 人）。他們之間可以結盟或對抗。

**B. 共治內閣：** 所有玩家共同治理一個國家，每人負責一個領域：
- 國王（最終決策者）
- 將軍（軍事）
- 財政大臣（經濟）
- 大法師/首席學者（科技）
- 外交大臣

**C. 陣營對抗：** 玩家分為兩陣營，各自治理一個國家。

## 第二十三章：可選規則與變體

### 23.1 簡化模式（快速遊戲）

- 不使用英雄系統
- 不使用種族滿意度追蹤

- 時代門檻減半
- 建設不消耗回合（只消耗金幣）

### 23.2 硬核模式

適合喜歡挑戰的資深玩家：

- 危機難度 +3
- 糧食消耗 ×1.5
- 無安全網機制（取消天命重擲）
- 冬季持續 2 回合

### 23.3 和平模式

適合不喜歡戰爭的玩家：

- 無法主動宣戰
- 鄰國侵略性降低
- 外交成為主要衝突解決方式
- 增加貿易和文化勝利的可能性

### 23.4 神話模式

適合喜歡奇幻元素的玩家：

- 增加超自然危機的觸發率
- 加入神明互動系統

- 傳奇時代門檻降低

| 攀爬 | 力量/敏捷 | 攀爬牆壁/地形（DC 12） |

### 法術清單（消耗法力值 MP）

> ▶ **完整法術清單已獨立收錄於 `assets/魔法圖鑑.md`（含 `魔法圖鑑.yaml`）**，依魔法類型（奧術／神聖／自然／符文／煉金／時空）分類，含施法屬性、難度（DC）、法力（MP）、冷卻（CD）與效果，GM 與玩家請直接查閱該圖鑑。

**施法總則**：`1d20 + 對應英雄屬性（原始值） ≥ 法術難度（DC）`，失敗則浪費法力值（MP）且無效果。大成功（自然 20）法術效果 ×1.5 且不耗額外法力值（MP）；大失敗（自然 1）法力值（MP）反噬 1d6 自傷。標註 CD 的法術在施放後需等待該回合數才能再次施放；高階法術（隕星術、時間停止）受 CD 限制，避免單一英雄無限清場。


## 第二十七章：怪物戰鬥與戰爭整合

### 怪物數值生成

《怪物圖鑑》中的怪物分為兩類，GM 請依情境擇用，避免「圖鑑值」與「公式值」衝突：

1. **具名頭目（圖鑑手調值）**：圖鑑各條目（哥布林、年輕赤龍、墮落神明等）列出的生命值（HP）／攻擊（ATK）／防禦（DEF）／戰利品，是設計者依手感**手調的基準值**，適用於劇本關鍵戰、頭目戰與命名遭遇。直接套用圖鑑數值即可。
2. **通用野怪（公式生成）**：用於隨機遭遇、雜兵群與快速生成。依挑戰等級（CR）套用以下公式：

```
怪物生命值（HP） = 10 + CR × 5
怪物攻擊（ATK）= CR × 2 + 2
怪物防禦（DEF）= 8 + CR × 1.5（四捨五入）
怪物獎勵（經驗/資源）= CR × 10 金幣等值
```

> 注意：高挑戰等級（CR ≥ 10）怪物屬**軍隊或多人小隊尺度遭遇**，不建議由單一英雄獨自面對（詳見下方「英雄尺度遭遇表」）。

### 英雄 vs 怪物（個人戰鬥規則）

- **英雄命中**：1d20 + 對應英雄屬性 ≥ 怪物防禦（DEF）
- **怪物命中**：1d20 + 怪物攻擊（ATK） ≥ 英雄防禦（DEF）
- **英雄防禦（DEF）** = 10（基礎）＋ 護甲加值（皮甲 +2、鎖子甲 +4、板甲 +6、龍鱗甲 +10 等）
- **怪物傷害**：命中後造成 怪物攻擊（ATK） 點傷害，再扣除英雄**護甲加值**（最低 1 點）。即 實際傷害 = 怪物 ATK − 護甲加值（最低 1）

以此模型，護甲同時提供「閃避機會」（拉高英雄防禦（DEF）使怪物可能擲骰失敗）與「傷害減免」（降低命中後的實際傷害），不再形同虛設。

### 戰爭尺度 vs 英雄尺度

- **國家戰爭**（第十四章）：以軍事單位（攻擊力/防禦力/移動力）進行，影響國家六維。
- **英雄戰鬥**（本章及第十一章）：以個體生命值（HP）/防禦（DEF）進行，影響單一英雄生死。
- **交叉**：將軍在戰爭中可為所率部隊提供「戰術指揮」+2 攻擊（見第十四章軍事單位）；英雄潛入敵後可單獨擊殺敵將，直接削減敵軍士氣（士氣 −10）。
- **怪物對軍隊折算**：怪物攻擊軍事單位時，傷害 = 怪物 ATK − 單位防禦力（DEF）（最低 1），並依第十四章戰爭規則結算單位損失。

### 英雄尺度遭遇表

| 英雄規模 | 建議 CR 上限 | 說明 |
|----------|-------------|------|
| 單一英雄 | CR 6 | 超過建議值須仰賴地形、道具或撤退 |
| 英雄小隊（2–3 人） | CR 12 | 可合力應對頭目級怪物 |
| 英雄 + 軍隊 | CR 10+ | 套用「怪物對軍隊折算」共同作戰 |
