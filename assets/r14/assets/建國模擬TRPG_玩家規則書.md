## 第一章：遊戲概述

### 1.1 這是什麼遊戲？

《建國模擬 TRPG》是一套以「國家經營」為核心的桌上角色扮演遊戲。與傳統 TRPG 不同，你扮演的不是揮劍砍怪的冒險者，而是**一位從零開始建立國家的統治者**。

你的「生命值（HP）」是你的人口；你的「裝備」是你的基礎建設；你的「技能樹」是你的科技與魔法體系。從一個 50 人的小營地開始，經歷部落時代、城邦時代、王國時代、帝國時代，最終可能進入傳奇時代——建立飛行城市，與神明對話。

### 1.2 遊戲的核心循環

```
國家創建 → 回合開始（春季）→ 玩家宣告行動 →
檢定擲骰 → 行動結算 → 危機觸發 → 回合結束 →
下一回合（夏季）→ ...（一年四回合）→ 時代演進
```

### 1.3 你需要準備什麼？

| 物品 | 說明 |
|------|------|
| 本規則書 | 就是這份文件 |
| 國家角色卡 | 記錄你的國家數據（可使用 Excel 角色卡或列印空白卡） |
| 一組骰子 | 至少一顆二十面骰（d20），建議備一套標準骰子組 |
| 紙筆 | 記錄筆記、計算數據 |
| 一位 GM | 遊戲主持人負責運作世界、扮演鄰國和觸發事件 |

### 1.4 核心術語表

| 術語 | 全稱 | 說明 |
|------|------|------|
| 人口（POP） | 人口 | 國家的國民總數，決定勞動力和兵源 |
| 資源（RES） | 資源 | 糧食、礦產、木材等自然資源的綜合產出能力 |
| 經濟（ECO） | 經濟 | 貿易網絡、貨幣體系、稅收效率 |
| 軍事（MIL） | 軍事 | 軍隊規模、裝備品質、戰略能力 |
| 科技（TEC） | 科技 | 技術水平、研發速度、魔法體系 |
| 民心（MOR） | 民心 | 國民忠誠度、文化凝聚力、幸福指數 |
| 國力（NP） | 國力 | 國家綜合影響力，用於外交對抗 |
| 難度等級（DC） | 難度等級 | 檢定需要達到的目標數值 |
| 調整值（MOD） | 調整值 | 屬性對檢定的加減值 |
| 遊戲主持人（GM） | 遊戲主持人 | 主持遊戲、扮演世界的人 |

## 第二章：核心規則——骰子與檢定

### 2.1 骰子系統：d20 + 調整值

本遊戲採用 **d20 系統**——即擲一顆二十面骰（1d20），加上對應的屬性調整值，與目標難度等級（DC）比較。

**檢定公式：**

```
檢定結果 = 1d20 + 屬性調整值（MOD）+ 其他加減值

成功條件：檢定結果 ≥ 難度等級（DC）
```

### 2.2 屬性調整值（MOD）

國家六維屬性每 5 點提供 +1 調整值（⌊(屬性 − 10) ÷ 5⌋），讓高發展國家在專精檢定上保有明顯優勢，且漲幅大於危機難度（DC）的加壓幅度：

| 屬性值範圍 | 調整值（MOD） |
|-----------|-------------|
| 1 – 4 | -2 |
| 5 – 9 | -1 |
| 10 – 14 | 0 |
| 15 – 19 | +1 |
| 20 – 24 | +2 |
| 25 – 29 | +3 |
| 30 – 34 | +4 |
| 35 – 39 | +5 |
| 40 – 44 | +6 |
| 45 – 49 | +7 |
| 50 – 54 | +8 |
| 55 – 59 | +9 |
| 60 – 64 | +10 |
| 65 – 69 | +11 |
| 70 – 74 | +12 |
| 75 – 79 | +13 |
| 80 – 84 | +14 |
| 85 – 89 | +15 |
| 90 – 94 | +16 |
| 95 – 99 | +17 |
| 100+ | 每 +5 增加 +1 |

**公式：** MOD = ⌊(屬性值 - 10) ÷ 5⌋（向下取整）

### 2.3 難度等級（DC）

| 難度 | DC | 說明 | 範例 |
|------|-----|------|------|
| 極簡易 | 5 | 幾乎不可能失敗 | 建造簡易木柵 |
| 簡易 | 10 | 有經驗者輕鬆達成 | 開墾小型農田 |
| 普通 | 15 | 需要一定能力 | 與中立鄰國建立貿易 |
| 困難 | 20 | 需要專業能力或運氣 | 說服敵對鄰國停戰 |
| 極難 | 25 | 即使是專家也有風險 | 在沙漠中建立綠洲城市 |
| 傳奇 | 30 | 凡人難以企及 | 說服兩國放下世仇聯手抗敵 |

### 2.4 優勢（ADV）與劣勢（DIS）

某些情況下，GM 會給予「擲骰優勢」或「擲骰劣勢」：

- **優勢（ADV）：** 擲 2d20，取**較高**結果
- **劣勢（DIS）：** 擲 2d20，取**較低**結果

優勢和劣勢互相抵消（一個優勢 + 一個劣勢 = 正常擲骰）。

### 2.5 大成功與大失敗

- **大成功（爆擊）：** 自然擲出 20（d20 顯示 20）→ 自動成功，且獲得額外好處
- **大失敗（災難）：** 自然擲出 1（d20 顯示 1）→ 自動失敗，且伴隨負面後果

### 2.6 檢定類型

#### 標準檢定

玩家宣告行動 → GM 決定適用屬性和難度 → 玩家擲骰 → 比對結果。

```
玩家：「我要說服鄰國開放貿易路線。」
GM ：「這是外交談判，使用經濟（ECO）+ 民心（MOR）中較高者，難度 15。」
玩家：擲 1d20，經濟（ECO）30 → 調整值 +2，擲出 14 → 總計 16 → 成功！
```

#### 對抗檢定

兩方同時擲骰，比較結果。用於外交談判、戰爭、間諜行動等。

```
A 國（國力 45，MOD +7）vs B 國（國力 30，MOD +4）
A 國擲出 12 + 7 = 19
B 國擲出 7 + 4 = 11
→ A 國勝出，在貿易談判中佔據優勢
```

#### 集體檢定（多人模式）

當多位玩家的國家合作完成一件大事時，至少半數玩家成功則整體成功。

#### 協助檢定（Aid）

當一名角色（統治者本人、顧問或英雄）協助另一人的行動時，協助者先進行一次 `1d20 + 相關屬性` 的協助檢定（難度 10）：

- **成功**：主行動者獲得 **+2 加值**（同一行動只能被協助一次）。
- **大成功（自然 20）**：主行動者獲得 **+4 加值**。
- **失敗**：無加值；**大失敗（自然 1）** 則主行動者承受 **−2 罰值**。

單人遊戲中，GM 扮演的顧問非玩家角色（NPC）同樣可以發起協助檢定。

### 2.7 四季調整

不同季節為檢定帶來環境調整：

| 季節 | 特效 |
|------|------|
| 春 | 外交檢定獲得 +1 調整值（萬物復甦，使節往來頻繁） |
| 夏 | 建設檢定獲得優勢（ADV）（日照充足，施工效率高） |
| 秋 | 貿易檢定獲得 +2 調整值（收穫季節，商隊往來） |
| 冬 | 建設檢定獲得劣勢（DIS）；糧食消耗 ×1.3；疾病事件機率上升 |

## 第三章：國家創建

你不是創角色——你是創國家。以下是六步驟創國流程。

### 步驟一：選擇起源

你的第一批國民因何聚集在一起？選擇一個起源：

| 起源 | 描述 | 屬性影響 |
|------|------|----------|
| **逃亡者** | 逃離戰亂或迫害，尋找新家園 | 民心（MOR）+10，軍事（MIL）-5 |
| **拓荒者** | 懷抱夢想的開拓者，主動尋找新土地 | 資源（RES）+10，經濟（ECO）-5 |
| **叛軍** | 逃離暴政的前反抗軍，帶著軍事經驗 | 軍事（MIL）+10，民心（MOR）-5 |
| **探險隊** | 受僱或自發的探索者，發現了這片土地 | 科技（TEC）+10，人口（POP）-5 |
| **流亡貴族** | 失去領地的貴族和他們的追隨者 | 經濟（ECO）+10，資源（RES）-5 |
| **信仰追隨者** | 追隨宗教領袖尋找聖地的信徒 | 民心（MOR）+10，科技（TEC）-5 |

### 步驟二：選擇種族構成

選擇你的初始族群種族。可選**單一種族**或**雙種族混合**：

- **單一種族**：該種族的「專長加成」數值 **×2**（見第五章種族表），種族滿意度初始 **+10**；優點是單一特長極強，缺點是缺乏多樣性、對特殊需求更敏感。
- **雙種族混合**：兩個種族的「專長加成」各取 **100%**（原值，不加倍），但解鎖「文化融合」——特定融合建築享有 **20% 折扣**，且種族滿意度上限更高；缺點是初始種族滿意度僅 **50**（需透過政策經營提升）。

> 完成創國後，你的國家立即獲得 **起始金幣 150** 與 **起始糧食 200**（詳見第四章衍生值與資源存量池），足以在第一回合啟動建設。

**初始人口：** 無論選擇何種族構成，初始人口（POP）皆為 50（± 起源調整）。

詳見[第五章：種族系統](#第五章種族系統)。

### 步驟三：選擇地理位置

你的初始領地位於什麼環境？

| 地形 | 優勢 | 劣勢 | 資源產出 |
|------|------|------|----------|
| **森林** | 資源（RES）+10，木材豐富 | 軍事（MIL）-5，視野受限 | 木材、獵物、藥草 |
| **平原** | 人口（POP）+10，農業發達 | 軍事（MIL）-5，無天然屏障 | 糧食、牧場 |
| **山地** | 軍事（MIL）+10，易守難攻 | 資源（RES）-5，耕地有限 | 礦石、石材 |
| **海岸** | 經濟（ECO）+10，航運便利 | 人口（POP）-5，海洋威脅 | 魚獲、鹽、貿易港 |
| **河畔** | 資源（RES）+5，人口（POP）+5 | 軍事（MIL）-10，洪水風險 | 灌溉、漁獲、運輸 |
| **高原** | 科技（TEC）+10，視野開闊 | 經濟（ECO）-5，交通不便 | 特殊礦物、觀星 |

### 步驟四：分配初始屬性點數

國家六維基礎值為 **10點**。你有 **30 點額外點數** 可自由分配（共計 40 點分布於六維，加上起源和地形的加成）。

| 步驟 | 計算方式 |
|------|----------|
| 基礎值 | 每項屬性從 10 開始 |
| 自由分配 | 30 點分配到六維（每項至少 0，至多 +15） |
| 起源加成 | 加上起源選擇的加減值 |
| 地形加成 | 加上地形的加減值 |
| 種族加成 | 加上種族專長的加減值（見第五章） |

**初始值範圍：** 六維屬性初始值通常在 15 – 55 之間。

### 步驟五：選擇建國理念

選擇一個核心價值，決定國家長遠發展方向：

| 建國理念 | 核心效果 | 政策方向 |
|----------|----------|----------|
| **軍事強國** | 軍事（MIL）+10，軍事單位花費 -20% | 征服、擴張、軍事科技 |
| **貿易中心** | 經濟（ECO）+10，貿易收入 +30% | 商業、外交、海運 |
| **魔法國度** | 科技（TEC）+10，研究點數 +50% | 魔法、煉金、奧術研究 |
| **自由城邦** | 民心（MOR）+10，人口成長率 +20% | 文化、移民、民主實驗 |

詳見[第八章：建國理念與政策](#第八章建國理念與政策)。

### 步驟六：認識第一個鄰居

GM 會根據你選擇的起始區域，設定一個鄰近勢力。記錄：
- 鄰國名稱與種族構成
- 對你的初始態度（關係值：-100 至 +100）
- 他們的國力大致水準

## 第四章：國家屬性與衍生值

### 4.1 國家六維（六大屬性）

| 屬性 | 簡稱 | 核心功能 | 低值影響 | 高值影響 |
|------|------|----------|----------|----------|
| 人口（POP） | 人口 | 勞動力、徵兵上限、市場規模 | 人力不足、稅收薄弱 | 大市場、強軍力 |
| 資源（RES） | 資源 | 糧食產出、建材供給 | 饑荒風險、建設停滯 | 自給自足、出口 |
| 經濟（ECO） | 經濟 | 稅收、貿易、貨幣穩定 | 通脹、赤字、貧窮 | 國庫充盈、投資 |
| 軍事（MIL） | 軍事 | 軍隊品質、防禦能力 | 被侵略風險、海盜 | 威懾力、遠征 |
| 科技（TEC） | 科技 | 研究速度、魔法水平 | 落後、無法應對新威脅 | 技術領先、專利 |
| 民心（MOR） | 民心 | 忠誠度、文化、幸福度 | 叛亂、移民外流 | 愛國熱情、文化輸出 |

### 4.2 衍生屬性

#### 衍生能力值（每回合自動計算）

| 衍生屬性 | 簡稱 | 計算公式 | 用途 |
|----------|------|----------|------|
| 國力（NP） | 國力 | 人口（POP）× 0.5 + 資源（RES）+ 經濟（ECO）+ 軍事（MIL） | 國際影響力，外交對抗基準 |
| 稅收（TAX） | 稅收 | 經濟（ECO）× 人口（POP）× 0.01 | 每回合獲得金幣量 |
| 糧食消耗（FOD） | 糧食 | 人口（POP）× 0.8（冬季 × 1.3） | 每回合需消耗的糧食 |
| 研究點數（RP） | 研究 | 科技（TEC）× 0.5 | 每回合獲得的科技進度 |
| 人口上限（CAP） | 上限 | 10 + 資源（RES）× 5 | 當前基礎建設可支撐的最大人口 |
| 軍隊上限（MCP） | 軍限 | 人口（POP）× 0.1 + 軍事（MIL）× 0.5 | 可維持的軍隊單位總數 |

#### 資源存量池（需長期追蹤的變數）

| 資源 | 簡稱 | 初始值 | 變動規則 |
|------|------|--------|----------|
| 金幣（GOLD） | 金幣 | **150** | 每回合 + 稅收（TAX） − 建築維護費 − 軍隊軍餉 − 其他支出 |
| 糧食（FOOD） | 糧食 | **200** | 每回合 + 糧食產出（秋 ×2） − 糧食消耗（FOD）；若 < 0 則歸零並民心（MOR）−5 |
| 木材（MAT_WOOD） | 木材 | 30 | 由伐木場等生產建築每回合產出；或市場以 1 金幣 = 1 木材 購買 |
| 石材（MAT_STONE） | 石材 | 20 | 由採石場等生產建築每回合產出；或市場以 1 金幣 = 1 石材 購買 |
| 鐵礦（MAT_IRON） | 鐵礦 | 10 | 由礦坑等生產建築每回合產出；或市場以 1 金幣 = 1 鐵礦 購買 |

> 建材（木材 / 石材 / 鐵礦）是**獨立存量池**，與抽象屬性「資源（RES）」分開計算。當建築花費標註「石材 100」時，從石材存量扣除；若不足且已建造市場，可用金幣補購（1 金幣 = 1 建材）。部落時代若無市場，則必須先興建對應生產建築（伐木場→木材、採石場→石材、礦坑→鐵礦）或由鄰國貿易取得。

### 4.3 屬性變化

屬性會在遊戲過程中因以下原因變動：

| 原因 | 影響屬性 | 變化幅度 |
|------|----------|----------|
| 建設完成 | 依建築類型 | +1 ~ +10 |
| 時代升級 | 全屬性 | × 1.2（四捨五入） |
| 戰爭失敗 | 人口（POP）、軍事（MIL）、資源（RES） | -5 ~ -30 |
| 危機處理成功 | 依危機類型 | +1 ~ +5 |
| 危機處理失敗 | 依危機類型 | -3 ~ -15 |
| 貿易協定 | 經濟（ECO） | +2 ~ +10 |
| 英雄行動 | 依行動類型 | 變動 |

## 第五章：種族系統

### 5.1 種族列表

| 種族 | 簡稱 | 專長加成 | 人口成長 | 特殊需求 | 文化特質 |
|------|------|----------|----------|----------|----------|
| **人類（HUM）** | 人類 | 經濟（ECO）+5，民心（MOR）+5 | +0% | 無特殊需求 | 適應力強、外交中庸 |
| **矮人（DWA）** | 矮人 | 資源（RES）+10 | +0% | 需要山脈地形維持滿意度 | 鍛造大師、建築減耗 20% |

> **單一種族加成計算**：選擇單一種族時，上表「專長加成」數值 **×2**（例如人類單一種族 → 經濟 +10、民心 +10）。選擇雙種族時各自取原值（不加倍），但解鎖「文化融合」優勢（見步驟二）。「人口成長」欄的修正會套用於回合結算的人口自然增長公式（見第九章）。

### 5.2 種族滿意度

每個種族有獨立滿意度（0 – 100）。當某個種族的滿意度低於 30 時，可能引發**動亂**：

| 滿意度 | 效果 |
|--------|------|
| 80 – 100 | 該種族產出 +20%，可能自願參軍 |
| 50 – 79 | 正常運作，無特殊效果 |
| 30 – 49 | 該種族產出 -10%，有輕微不滿 |
| 10 – 29 | 該種族產出 -30%，抗議事件機率上升 |
| 0 – 9 | 可能叛亂——該種族人口可能獨立或投靠鄰國 |

**維持滿意度的方法：** 建設種族專屬建築、制定公平政策、避免偏好單一種族。

### 5.3 多種族國家

多種族國家可解鎖**文化融合科技**：

| 種族組合 | 融合獎勵 |

| 人類 + 任何其他種族 | 外交關係提升速度 +50% |

```

```

每個建築有：

| 參數 | 說明 | 範例 |
|------|------|------|
| 建造花費 | 金幣、石材、木材等 | 200 金幣 + 50 木材 |
| 建造時間 | 需要的回合數 | 2 回合 |
| 人力需求 | 佔用的人口數量 | 佔用 10 人口 |
| 前置建築 | 必須先建造的建築 | 需要「圖書館」 |

| 效果 | 建築提供的效益 | 經濟（ECO）+5 |

**建材存量池**：建築花費中的「木材 / 石材 / 鐵礦」是獨立存量池（見第四章資源存量池）。擁有對應生產建築（伐木場、採石場、礦坑）時每回合自動產出；否則可在市場以 **1 金幣 = 1 建材** 購買（部落時代無市場時，必須先興建生產建築或與鄰國貿易）。

**持續性金幣消耗（金幣 sink）**：為避免早期假性貧窮與後期金幣溢出，每回合結算扣除兩項：
- **建築維護費** = 所有已建築的「金幣花費」總和 × 2%（四捨五入）。
- **軍隊軍餉** = 全軍所有單位「花費」總和 × 2%（四捨五入）；民兵免軍餉。
（詳見第四章資源存量池與第九章回合結束結算）

**建造時間（城邦以上）**：部落建築已於各表標示（1–2 回合）；城邦時代建築統一 2 回合；王國時代 2–3 回合；帝國時代 3–4 回合；傳奇時代 4–5 回合（GM 可依規模微調）。

## 第九章：回合制遊戲流程

### 9.1 回合結構

遊戲以「回合」為單位推進。**每回合代表一個季度**（約三個月），**四回合 = 一年**。

每回合分為五個階段：

```
階段 1：季節宣告（GM）
階段 2：玩家行動宣告
階段 3：行動檢定與結算
階段 4：危機觸發與處理
階段 5：回合結束結算
```

### 9.2 階段詳解

#### 階段 1：季節宣告

GM 宣告當前季節和特殊效果：

| 季度 | 特殊效果 |
|------|----------|
| **春** | 外交行動獲得 +1 調整值；須決定種植計劃 |
| **夏** | 建設行動獲得優勢（ADV）；軍事行動窗口 |
| **秋** | 貿易行動獲得 +2 調整值；糧食產出結算 |
| **冬** | 建設行動獲得劣勢（DIS）；糧食消耗 ×1.3；疾病風險 |

#### 階段 2：玩家行動宣告

每回合可執行 **3 項主要行動**（由玩家選擇）：

| 行動類型 | 範例 |
|----------|------|
| 建設行動 | 建造/升級建築 |
| 外交行動 | 派遣大使、貿易談判、結盟提議 |
| 軍事行動 | 招募軍隊、邊境巡邏、發動戰爭 |
| 科技行動 | 投入研究、解鎖科技 |
| 內政行動 | 調整稅率、制定政策、安撫民心 |
| 英雄行動 | 派遣英雄執行任務 |

#### 階段 3：行動檢定與結算

玩家為每項行動擲骰檢定，GM 宣告結果和影響。

#### 階段 4：危機觸發與處理

GM 抽取 1-2 個危機（見[第十二章](#第十二章危機處理)），玩家即時反應。

#### 階段 5：回合結束結算

```
1. 金幣（GOLD） += 稅收（TAX） − 建築維護費 − 軍隊軍餉 − 其他支出
2. 糧食（FOOD） += 糧食產出（秋 ×2） − 糧食消耗（FOD）；若 FOOD < 0 → FOOD = 0 且 民心（MOR）−5
3. 研究點數（RP） += 科技（TEC）× 0.5 → 累積至科技進度（每滿 50 RP 可花費解鎖一項「科技突破」，見下）
4. 計算人口自然增減（公式見下）
5. 檢查時代升級條件
6. 記錄所有數據變化
```

**人口自然增長公式：**

```
基礎成長率 = 3%
若 民心（MOR）≥ 60 且 糧食（FOOD）> 0：成長率 +1%（共 4%）
若 民心（MOR）< 40：成長率 = −1%（人口流失）
若 糧食（FOOD）= 0：額外流失 = FLOOR(糧食缺口 ÷ 2)
種族修正：巨人裔 × 0.5、半身人 × 1.2；「自由城邦」建國理念的「人口成長 +20%」為 × 1.2（乘到成長率上，非加 20 個百分點）。
人口變動 = 人口（POP） × 成長率 × 種族修正（巨人裔 ×0.5、半身人 ×1.2）
人口（POP） = MIN(人口（POP） + 人口變動, 人口上限（CAP）)
```

**科技突破（研究點數（RP）的消耗出口）**：每累積滿 50 研究點數（RP），可花費該 50 RP 解鎖一項「科技突破」——擇一：① 永久 科技（TEC）+2；② 解鎖一項專精增益（如農業 +10% 糧食產出、軍事 +2、或解鎖一種魔法）。須在對應科技建設（工坊／圖書館／大學）所在地進行。

### 9.3 年度流程範例

```
第一年春：決定種植小麥 → 建造農田（成功）→ 派遣使節前往鄰國（成功）
    危機：野獸威脅 → 派獵人驅逐（成功）
    結算：金幣 +15，糧食 +50，研究點數（RP）+2

第一年夏：建造水井（成功）→ 招募民兵（成功）→ 與鄰國簽訂貿易協定（成功）
    危機：無
    結算：金幣 +20，糧食 +40，人口（POP）+5

第一年秋：收穫結算 → 擴大農田（成功）→ 舉辦豐收祭典（成功）
    危機：秋雨洪水（部分成功）
    結算：金幣 +25，糧食 +80，民心（MOR）+3

第一年冬：研發基礎鍛造（成功）→ 室內改建（失敗）→ 制定冬季配給令（成功）
    危機：寒流來襲（成功應對）
    結算：金幣 +10，糧食消耗 ×1.3，科技（TEC）+2
```

| 盟國（ALL） | +51 ~ +100 | 軍事同盟、自由貿易、科技共享 |

### 10.2 外交行動

| 行動 | 消耗 | 效果 |
|------|------|------|
| 派遣大使 | 1 回合 + 50 金幣 | 建立正式外交關係 |
| 貿易談判 | 1 回合，檢定：經濟（ECO） | 簽訂貿易協定 |
| 結盟提議 | 1 回合，需關係 > 30 | 建立軍事或防禦同盟 |
| 聯姻 | 特殊事件觸發 | 關係 +30，附帶家族義務 |
| 宣戰 | — | 關係降至敵對，進入戰爭狀態 |
| 求和 | 金幣 + 資源 | 結束戰爭，條件依戰況 |
| 送禮 | 100 金幣 | 關係 +5 ~ +15（依檢定結果） |

### 10.3 戰爭系統（概要）

（完整戰爭規則見 GM 規則書）

進入戰爭狀態後，每回合可執行：
- **調動軍隊：** 將軍隊部署至前線
- **發動戰役：** 使用軍事（MIL）對抗擲骰
- **攻城：** 攻擊敵方防禦工事
- **撤退：** 保存實力

戰爭消耗：每回合戰爭消耗金幣（軍餉、補給），長期戰爭會拖累經濟。

## 第十一章：英雄單位

### 11.1 什麼是英雄？

英雄是具有特殊能力的個體，可為你的國家執行特殊任務。每個英雄有獨立的屬性、忠誠度和個人目標。

### 11.2 英雄類型

| 類型 | 主要屬性 | 核心功能 |
|------|----------|----------|
| **將軍（GEN）** | 武力（ATK）+ 戰術（TAC） | 指揮軍隊，提供戰術加成 |
| **間諜（SPY）** | 潛行（STL）+ 智謀（INT） | 潛入敵國，收集情報或破壞 |
| **學者（SCH）** | 智謀（INT）+ 學識（KNW） | 加速研究，解鎖隱藏科技 |
| **使節（ENV）** | 魅力（CHA）+ 口才（ELO） | 外交專精，完成艱難協議 |
| **傳奇工匠（ART）** | 手藝（CRF）+ 創造（CRE） | 建造特殊建築，減少建設成本 |

### 11.3 英雄屬性

英雄使用獨立於國家屬性的個人屬性（每項 0 – 20）：

| 屬性 | 簡稱 | 用途 |
|------|------|------|
| 武力（ATK） | 武力 | 個人戰鬥、武力威懾 |
| 智謀（INT） | 智謀 | 策略規劃、破解謎題 |
| 魅力（CHA） | 魅力 | 社交說服、領導魅力 |
| 潛行（STL） | 潛行 | 潛入、隱匿行動 |
| 學識（KNW） | 學識 | 知識檢定、魔法使用 |
| 戰術（TAC） | 戰術 | 指揮作戰、軍事規劃 |
| 手藝（CRF） | 手藝 | 建築設計、物品製作 |
| 口才（ELO） | 口才 | 談判辯論、外交辭令 |
| 創造（CRE） | 創造 | 發明創造、藝術活動 |

英雄檢定公式：**1d20 + 對應英雄屬性**

### 11.4 英雄招募

| 招募方式 | 花費 | 難度 |
|----------|------|------|
| 國內發掘 | 100 金幣 | 普通（DC 12） |
| 國外招募 | 200 金幣 | 困難（DC 18） |
| 事件獲得 | 特殊事件 | 自動獲得 |

### 11.5 英雄忠誠度

每位英雄有忠誠度（1 – 10）。低忠誠度可能導致：
- **忠誠 1-3：** 可能叛逃或洩漏機密
- **忠誠 4-6：** 正常服務，但不會額外付出
- **忠誠 7-9：** 全心投入，任務獲得優勢（ADV）
- **忠誠 10：** 誓死效忠——失敗時可重擲一次

提升忠誠度：賞賜金幣、滿足個人目標、建設相關設施。

### 11.6 英雄個人戰鬥

英雄可以脫離軍隊、獨自執行任務或下場戰鬥（英雄 vs 英雄、英雄 vs 怪物）。

**生命值（HP）**：英雄的生命值 = 20 + 武力（ATK）× 4 + 體質（CON）× 2（體質由 GM 依背景給 0–10，預設 5）。

**戰鬥行動經濟**：英雄戰鬥採回合制，每名英雄每回合可執行 **1 個主要動作 + 1 個移動動作**（移動力 移動（MOV）= 3 + FLOOR(武力（ATK）÷ 5)）。

**英雄防禦（DEF）**：英雄基礎防禦（DEF）= 10，再加上護甲加值（見第十一章第八節與物品圖鑑）。例如穿皮甲（＋2）的英雄防禦（DEF）= 12。

**傷害計算**：

```
命中檢定：1d20 + 對應英雄屬性（近戰用武力（ATK），遠程用潛行（STL），法術用學識（KNW）） ≥ 敵人防禦值（DEF）
近戰每擊傷害 = 英雄武力（ATK） + 武器攻擊加值 + FLOOR(武力（ATK）÷ 3)
遠程每擊傷害 = 英雄潛行（STL） + 武器攻擊加值 + FLOOR(潛行（STL）÷ 3)
（武器基礎傷害以英雄對應屬性為基準，武器「攻擊力 ＋N」疊加其上）
```

**怪物對英雄**：怪物命中 = 1d20 + 怪物攻擊（ATK） ≥ 英雄防禦（DEF）；命中後實際傷害 = 怪物攻擊（ATK） − 護甲加值（最低 1）。護甲因此同時提供「閃避機會」與「傷害減免」，不再形同虛設。

**休息與恢復**：在安全地點（城鎮、營地、神廟）休息每回合恢復**最大生命值（HP）× 10%**（四捨五入，至少 1）；法力值（MP）同回合恢復 5（城鎮／神廟 10）。

**死亡與倒地**：生命值（HP）降為 0 時英雄**倒地**（失去行動能力，處於瀕死）。倒地後若無人救助，3 回合內未恢復則**陣亡**（永久失去該英雄）。可使用治療藥水、休息或法術恢復生命值。

### 11.7 英雄技能與法術

每位英雄依類型擁有 2–3 個專精技能（見下表），並可透過任務與訓練學習通用技能。施放法術需消耗**法力值（MP）**（見第十三章）。

| 英雄類型 | 專精技能（示例） | 關鍵屬性 |
|----------|----------------|----------|
| 將軍（GEN） | 戰術指揮（全軍 +2 攻擊）、衝鋒號令、堅守陣線 | 武力（ATK）、戰術（TAC） |
| 間諜（SPY） | 潛行滲透、情報竊取、下毒（目標 −3 屬性/回合，2–3 回合） | 潛行（STL）、智謀（INT） |
| 學者（SCH） | 奧術飛彈（傷害 2d6+學識）、鑑定、快速研究 | 學識（KNW）、智謀（INT） |
| 使節（ENV） | 說服（對抗 +3）、締約、外交情報 | 魅力（CHA）、口才（ELO） |
| 傳奇工匠（ART） | 附魔（裝備 +1）、速建（建設 −1 回合）、發明 | 手藝（CRF）、創造（CRE） |

**通用技能**（任何英雄可學）：偵察、急救（恢復 1d6+2 生命值）、騎乘、恐吓、攀爬。

### 11.8 英雄裝備

英雄可穿戴武器與護甲，效果直接疊加至英雄的攻擊與防禦：

- **武器**（如鐵劍 攻擊力 +2）：加入英雄的武器基礎傷害。
- **護甲**（如皮甲 防禦力 +2）：加入英雄的防禦值（DEF）。
- **特殊裝備**（如火繩槍 攻擊力 +8 遠程）：依物品圖鑑數值生效。

> 裝備對「國家屬性」與「軍事單位」的生效規則，詳見[第十三章：裝備、道具與魔法應用](#第十三章裝備道具與魔法應用)。

### 11.9 英雄成長與訓練

英雄不是招募即封頂——透過任務與訓練，英雄可持續變強，避免隨國家與怪物成長而貶值。

- **屬性點**：每完成 **3 次英雄任務**（或累積 **3 場英雄勝利戰鬥**），獲得 1 點屬性點，可分配至任一英雄屬性（單項上限 20）。
- **專項訓練**：花費 50 金幣／回合進行訓練，直接讓指定英雄屬性 +1（每英雄每回合至多 1 次），需停留在安全地點。
- **傳奇事蹟**：第二十三章「傳奇事蹟」系統給予的「英雄屬性 +1」獎勵併入此成長機制。
- **技能點**：每完成 3 次英雄任務另可解鎖 1 個新通用技能或專精技能（見第十一章第七節）。

## 第十二章：危機處理

### 12.1 危機系統

每回合結束時，GM 從危機牌組中隨機抽取 **1-2 個危機**。危機嚴重度隨國力（NP）增加。

### 12.2 五大危機類型

| 類型 | 範例事件 | 主要影響屬性 |
|------|----------|-------------|
| **自然災害（NAT）** | 洪水、乾旱、蝗災、瘟疫、地震 | 資源（RES）、人口（POP） |
| **經濟危機（ENC）** | 通貨膨脹、貿易中斷、財政赤字、貨幣貶值 | 經濟（ECO）、民心（MOR） |
| **外交危機（DIP）** | 邊境衝突、鄰國政變、貿易制裁、使節被扣 | 軍事（MIL）、民心（MOR） |
| **內部危機（INT）** | 貴族叛亂、宗教分裂、罷工浪潮、繼承爭議 | 民心（MOR）、人口（POP） |
| **超自然危機（SUP）** | 怪物入侵、魔法災難、異界裂縫、亡靈天災 | 全屬性 |

### 12.3 危機處理方式

每個危機通常有 2-4 種處理方式。玩家選擇一種並擲骰檢定：

| 處理方式 | 常用屬性 | 風格 |
|----------|----------|------|
| 武力鎮壓 | 軍事（MIL） | 快速直接，但可能損害民心 |
| 談判妥協 | 經濟（ECO）+ 民心（MOR） | 花費資源換取和平解決 |
| 技術解決 | 科技（TEC） | 使用科技或魔法永久解決 |
| 外交求助 | 經濟（ECO） | 向鄰國求援（可能附帶條件） |
| 英雄介入 | 英雄屬性 | 派遣英雄處理（高風險高回報） |

### 12.4 危機處理結果

| 檢定結果 | 效果 |
|----------|------|
| 大成功（自然 20） | 危機完美解決，額外獲得獎勵 |
| 成功（≥ DC） | 危機解決，屬性不受影響 |
| 部分成功（DC - 3 以內） | 危機減輕，屬性輕微受損（-2） |
| 失敗（< DC - 3） | 危機造成全額損害（-5 ~ -15） |
| 大失敗（自然 1） | 危機惡化，可能觸發連鎖事件 |

## 第十三章：裝備、道具與魔法應用

### 13.1 裝備對誰生效

物品圖鑑中的裝備依對象分為三類：

| 對象 | 生效方式 | 範例 |
|------|----------|------|
| **英雄** | 武器加至英雄武器傷害、護甲加至英雄防禦值（DEF） | 鐵劍 +2 攻擊、皮甲 +2 防禦 |
| **軍事單位** | 透過「鐵匠鋪」等建築，全軍某類單位攻防 +1（或依裝備說明） | 騎兵矛：騎兵攻擊 +3 |
| **國家** | 戰略性裝備影響國家屬性或戰爭 | 天神砲：攻城攻擊 +50 |

### 13.2 法力值（MP）系統

施法與部分英雄技能需消耗**法力值（MP）**。

- **法力上限（MP_MAX）** = 10 + 學識（KNW）× 2（學者類英雄通常最高）。
- **每回合恢復**：休息一回合恢復 5 點法力值；城鎮 / 神廟休息恢復 10 點。
- **消耗**：普通法術 2–5 點；強力法術 6–10 點。
- **補充**：「初級法力藥水」恢復 10 點法力值。

### 13.3 魔法類型與施法

五大魔法（奧術 / 神聖 / 自然 / 符文 / 煉金）各有對應屬性檢定：

| 魔法類型 | 施法檢定屬性 | 典型效果 |
|----------|--------------|----------|
| 奧術魔法 | 學識（KNW） | 奧術飛彈、魔法護盾 |
| 神聖魔法 | 魅力（CHA） | 治療、驅邪 |
| 自然魔法 | 學識（KNW） | 草木纏繞、動物溝通 |
| 符文魔法 | 手藝（CRF） | 附魔、守護符文 |
| 煉金術 | 手藝（CRF） | 炸藥、治療藥劑 |

施法：`1d20 + 對應英雄屬性（原始值） ≥ 法術難度（DC）`，失敗則浪費法力值且無效果。

> ▶ **完整法術清單（含難度 DC、法力 MP、冷卻 CD 與效果）已獨立收錄於 `assets/魔法圖鑑.md`（含 `魔法圖鑑.yaml`）**，依魔法類型（奧術／神聖／自然／符文／煉金／時空）分類，施法前請直接查閱。

## 附錄

### A. 快速參考——檢定公式

```
標準檢定：    1d20 + 屬性調整值（MOD）+ 其他加值 ≥ 難度等級（DC）
對抗檢定：    雙方 1d20 + MOD，較高者勝
英雄檢定：    1d20 + 對應英雄屬性
優勢（ADV）：    擲 2d20，取較高
劣勢（DIS）：    擲 2d20，取較低
屬性調整值：    FLOOR((屬性值 - 10) / 5)
```

### B. 快速參考——衍生屬性公式

```
國力（NP）    = 人口（POP）× 0.5 + 資源（RES）+ 經濟（ECO）+ 軍事（MIL）
稅收（TAX）    = 經濟（ECO）× 人口（POP）× 0.01
糧食消耗（FOD）  = 人口（POP）× 0.8（冬季 × 1.3）
研究點數（RP）   = 科技（TEC）× 0.5
人口上限（CAP）  = 10 + 資源（RES）× 5
軍隊上限（MCP）  = 人口（POP）× 0.1 + 軍事（MIL）× 0.5
金幣（GOLD）    = 起始 150 + 每回合（稅收（TAX） − 維護費）
糧食（FOOD）    = 起始 200 + Σ糧食產出（秋 ×2） − 糧食消耗（FOD）
木材/石材/鐵礦  = 由對應生產建築產出；市場 1 金幣 = 1 建材
人口自然增長    = 人口（POP）× 成長率（3%~4%）× 種族修正，上限人口上限（CAP）
英雄生命值（HP） = 20 + 武力（ATK）× 4 + 體質（CON）× 2
```
