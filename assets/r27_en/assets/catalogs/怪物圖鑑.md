# Beastman Warring States TRPG — Monster Compendium

> All monsters are listed here. Challenge Rating (CR) serves as the reference difficulty for a party of four of equal level.

---

## Usage Notes

### Data Card Format

| Field | Description |
|---|---|
| Name | The monster's name |
| Type | Beastman / Spirit / Undead / Yokai Beast / Humanoid |
| Challenge Rating (CR) | Suitable for a party of 4 of equal level |
| Attributes | Swordsmanship / Physique / Yokai Power / Agility / Spirit |
| Combat | HP / DV / DR / Speed |
| Attack | Attack name, hit bonus, damage |
| Special | The monster's unique abilities |
| Drop | Cultivation Points (XP) and items gained on defeat |
| AI | Simple behavior logic |

### Batch Processing Rules

4–5 identical minions → merge into 1 "cluster":
- Cluster HP = single HP × count × 0.7
- Cluster attack: roll 1 hit; each 3 points over DV deals 1 extra instance of base damage
- Cluster HP below 50%: attack −1
- Cluster HP below 25%: routs
