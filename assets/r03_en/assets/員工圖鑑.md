# Z Corporation TRPG — Employee & NPC Database

> This file compiles the data for all 40 numbered Sorcerers (including known employees and blank-numbered employees), the NPC database, plus the employee index and statistics.

## Rating Quick Reference

| Rating | Relative Strength |
|--------|-------------------|
| SSS, SS, S | Top-tier |
| AA, A, BB, B | Excellent |
| CC, C, DD, D | Average |
| EE, E, FF, F | Below Average |
| FF/F | Lowest |

> Attribute Range format: Lowest ~ Highest (growth potential)

## IV. Blank-Numbered Employee Generation Rules

> When the Scout Talent system randomly draws a number that already has data (i.e., all 01~48 + a-01 already have employees), this rule is no longer triggered. It is retained for future expansion.

### Attribute Generation

| Grade | Charisma | Intelligence | Cursed Energy | Stamina | Willpower |
|------|------|------|------|------|------|
| **Grade 4** | F ~ DD | F ~ DD | F ~ DD | F ~ DD | F ~ DD |
| **Grade 3** | F ~ D | F ~ D | F ~ D | F ~ D | F ~ D |

> Each attribute is independently and randomly determined for its high/low values. Suggested method: roll 1d10
> * 1-3: Limit at the lowest tier (Grade 4 F, Grade 3 F)
> * 4-6: Limit at the middle tier (Grade 4 EE/E, Grade 3 EE/E)
> * 7-10: Limit at the highest tier (Grade 4 D/DD, Grade 3 D)

### Core Ability Generation

1. **Naming Rules**: Format is "Innate Technique - XXX", "Heavenly Restriction - XXX", or "Special Curse - XXX"
   * Innate Technique: Innate ability (70% chance)
   * Heavenly Restriction: Exchange cost for enhancement (20% chance)
   * Special Curse: Curse-host type (10% chance)

2. **Ability Type Suggestions**:
   * Animal/Creature type: wolf transformation, catgirl, bird speech, etc.
   * Object/Cuisine type: ice cream, scissors, chopsticks, ladle, etc.
   * Element/Nature type: flame, water flow, light & shadow, plants, etc.
   * Mental/Cognitive type: hallucinations, memory, emotional contamination, etc.
   * Physical/Combat type: enhanced strength, speed, defense, etc.
   * Summoning/Control type: shikigami, puppets, etc.
   * Defense/Support type: barriers, healing, balance, etc.
   * Special/Quirky type: random creation

3. **Complexity Settings**:
   | Complexity | Intelligence Requirement | Suitable Type |
   |--------|---------|---------|
   | 1 | None | Simple, direct abilities |
   | 2 | Any EE suffices | Abilities with certain conditions |
   | 3 | Any D suffices | More complex abilities |
   | 4 | Any C suffices | High complexity |
   | 5 | Any A or above | Extremely high complexity |

4. **Sublimation Level**: Defaults to "No Sublimation", unless the Core Ability has potential, in which case Grade 4 / Grade 3 Sublimation may be granted.

### Defect/Limitation Generation (Optional)

There is a 30% chance to assign an extra defect:
* Fear of specific objects (silver, flame, cold water, etc.)
* Unable to use a certain attribute (locked/unmeasurable)
* Physical/mental limitations (advanced age, declining intelligence, etc.)
* Conditional Binding (requires specific companions, specific scenes, etc.)
