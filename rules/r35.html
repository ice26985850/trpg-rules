介紹

🎲 TRPG AI GM —— 你的個人 AI 遊戲主持人

TRPG AI GM 是一個讓你一個人也能跑團的開源工具。不需要找朋友排時間、不需要讀幾百頁規則書——打開瀏覽器，選擇一套規則系統，AI GM 就會帶你進入冒險。

它解決了什麼問題？

喜歡 TRPG 但湊不齊人？想試新系統但沒有人願意當 GM？深夜想跑團但朋友都在睡覺？AI GM 永遠在線。

核心特色

🧠 AI 當 GM —— 不是擲骰機器人。AI GM 會敘事、扮演 NPC、根據你的行動即興推進劇情

📦 規則包系統 —— 不綁定特定系統。任何 TRPG 規則都能打包成 briefing_package，拖進 App 就能跑

🗺️ 內建地圖面板 —— 支援節點式地圖（星圖、地下城、戰術地圖），AI GM 可以在遊戲中動態更新

🎭 引導式創角 —— AI GM 一步一步帶你創角色，不需要先搞懂複雜的屬性配點

🌐 瀏覽器即玩 —— 打開瀏覽器就是完整遊戲介面，不需要安裝任何客戶端

📝 規則分離 —— 框架本身不含任何 TRPG 規則，所有規則都以 briefing_package 形式獨立安裝

技術棧

Python + 瀏覽器原生 UI + 相容 OpenAI API（DeepSeek、OpenAI 等任何相容 API 均可）

適合誰？

  • 想一個人體驗 TRPG 的玩家
  • TRPG 規則設計師——把你的系統打包成 briefing_package，讓別人用 AI GM 單人體驗
  • 想在不 commit 完整團務的情況下快速試玩一個新系統的人
本站收錄各類 TRPG 規則，點開可看介紹、劇本、角色卡與地圖，並可下載 PDF / Excel / 整套 zip。
